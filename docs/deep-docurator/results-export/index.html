Deep Docurator 결과 확인과 내보내기

플로우를 실행하면 노드마다 결과가 남습니다. 이 페이지는 파싱 결과, 청크 결과, 메타데이터 결과를 읽는 곳과 원본과 대조하는 방법, 그리고 검토를 마친 플로우를 Deep Connector로 보내 실제 지식으로 쓰는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 노드별 결과를 여는 곳과 읽는 순서를 압니다.
  • PDF 원본과 블록, 청크의 위치를 나란히 대조합니다.
  • 노드 설정을 YAML 탭에서 확인합니다.
  • DeepConnect 배포로 플로우를 Deep Connector 문서 업로드에 공개합니다.
  • 결과를 밖으로 가져가는 방법과 화면에서 제공하지 않는 것을 구별합니다.

결과를 여는 곳​

결과여는 곳보이는 내용
파싱 결과파싱 노드 → 옵션 & 미리보기 탭 → Parse 결과블록 수와 블록 목록. 블록마다 종류(제목, 텍스트, 표, 목록, 이미지, 캡션, 차트, 기타), 쪽 번호, 본문
원본 문서파싱 노드 → 옵션 & 미리보기 탭 → 원본 문서원본 PDF. Parse 결과에서 블록을 누른 뒤 원본 문서로 바꾸면 해당 위치가 강조됩니다.
청크 결과청킹 노드 → 옵션 & 미리보기 탭청크 수와 평균 글자 수, 청크 칸, 고른 청크의 번호·원본 파일 이름·글자 수·본문
청크 결과 미리보기캔버스 왼쪽 아래 도구의 돋보기 버튼청크 목록과 원본 PDF를 나란히 봅니다. 청크에 마우스를 올리면 PDF 영역이 보이고, 누르면 해당 페이지로 이동합니다.
메타데이터 결과메타데이터 노드 → 옵션 & 미리보기 탭청크마다 뽑은 필드 값
노드 설정노드 → YAML 탭노드의 옵션과 상태를 YAML과 JSON으로 보여 줍니다. 보기 전용입니다.

실행 전에는 파싱 결과 자리에 "파싱 결과가 아직 없습니다."가, 청크 결과 미리보기 버튼에는 "청크 결과 미리보기 (실행 후 사용 가능)"이 보입니다. 실행이 끝나면 노드 아래 상태가 완료로 바뀌고 결과를 열 수 있습니다.

읽는 순서​

  1. 파싱 노드의 블록 수와 페이지 수가 원본 쪽수와 맞는지 봅니다.
  2. Parse 결과에서 표 블록을 펼쳐 숫자와 머리글이 그대로 읽혔는지 원본과 대조합니다.
  3. 청킹 노드에서 청크 칸을 차례로 눌러, 함께 읽혀야 할 조건이 같은 청크에 남았는지 봅니다.
  4. 메타데이터가 있다면 필드 값이 청크 본문과 맞는지 몇 개를 골라 확인합니다.
  5. 결과가 맞으면 프리셋으로 저장하거나 Deep Connector로 보냅니다.

파싱 결과에 없는 내용은 청킹이나 메타데이터에서 되살아나지 않습니다. 결과가 이상하면 앞 단계부터 거꾸로 확인하세요.

원본 위치 강조는 PDF에서만 동작합니다. PDF가 아닌 파일은 "원본 PDF 를 표시할 수 없습니다."가 보이므로, 원본 파일을 따로 열어 블록·청크 본문과 대조합니다.

Deep Connector로 보내기​

검토를 마친 플로우는 Deep Connector에 문서를 올릴 때 처리 파이프라인으로 고를 수 있습니다. 이것이 Deep Docurator 결과를 실제 지식 검색과 에이전트 답변에 쓰는 기본 방법입니다.

파이프라인 설정 대화상자

번호메뉴기능이런 때 사용하세요
1이름플로우 이름입니다. Deep Connector의 파이프라인 목록에 이 이름이 보입니다.업무 기준에 맞게 이름을 고칠 때
2DeepConnect 배포켜면 저장할 때 Deep Connector 쪽 파이프라인 목록에 공개됩니다. 켜면 "외부 /pipelines 에 노출 — 저장 시 적용"이 보이고, 저장한 뒤에는 "외부 /pipelines 에 노출"과 함께 공개 이름이 보입니다(화면에서는 흐림 처리).검토를 마친 플로우를 공개할 때
3저장바꾼 내용을 저장합니다. 배포 스위치도 저장할 때 적용됩니다.이름·설명·배포 여부를 확정할 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
설명플로우 설명입니다.어떤 문서에 쓰는지 적어 둘 때
취소저장하지 않고 닫습니다.설정을 잘못 건드렸을 때
  1. 편집기 위쪽 톱니바퀴 파이프라인 설정을 누릅니다.
  2. 이름과 설명을 확인합니다. Deep Connector의 파이프라인 목록에는 이 이름이 보이므로 문서 종류와 기준을 이름에 담습니다.
  3. DeepConnect 배포 스위치를 켭니다. 스위치 아래 상태 문구 끝에 "저장 시 적용"이 붙습니다.
  4. 저장을 누릅니다. 저장해야 배포가 반영됩니다.
  5. Deep Connector에서 컬렉션을 열고 문서 업로드를 누른 뒤, 파이프라인 목록에 이 플로우 이름이 있는지 확인합니다.
  6. 문서를 올린 뒤 문서 탭의 청크 수가 Deep Docurator 청킹 노드의 청크 수와 같은지 비교합니다.

파이프라인 설정은 저장된 플로우에서만 열리며, 플로우의 소유자나 관리자만 바꿀 수 있습니다. 권한이 없으면 소유자나 관리자만 수정할 수 있다는 안내가 표시됩니다. 배포를 끄고 저장하면 Deep Connector의 파이프라인 목록에서 숨겨집니다.

Deep Connector에서 처리 상태를 읽는 방법과 다시 적재하는 방법은 Deep Connector 매뉴얼의 시작하기와 반복 업무 페이지에 있습니다.

화면에서 가져갈 수 있는 것과 없는 것​

가져가려는 것방법
청크를 지식 검색과 에이전트에 쓰기DeepConnect 배포 후 Deep Connector 컬렉션에 올립니다.
노드 구성을 다른 담당자에게 주기프리셋으로 저장 후 설정 화면에서 YAML 내보내기
원본 PDF 내려받기원본 문서 보기의 PDF 도구 모음에서 다운로드
청크·메타데이터를 엑셀이나 파일로 내려받기편집기 화면에는 내려받기 메뉴가 없습니다. 필요한 값은 청크 본문을 복사해 쓰거나, Deep Connector에 올린 뒤 그곳의 화면에서 확인합니다.

메타데이터 값을 표로 모으는 기능은 화면에 없습니다. 여러 청크의 값을 한 표로 보아야 할 때에는 메타데이터 결과에서 값을 확인해 옮겨 적습니다.
