Deep Docurator 메뉴 안내

이 페이지는 Deep Docurator의 플로우 목록, 플로우 편집기, 검색 창의 메뉴를 번호 순서대로 설명합니다. 시작하기를 한 번 따라 한 뒤 읽으면 화면 이름을 익히기 쉽습니다. 노드 하나하나의 옵션은 노드 안내, 설정 화면의 프리셋 관리는 프리셋과 템플릿 플로우에 있습니다.

이 페이지에서 할 수 있는 일

  • 플로우 목록에서 플로우를 찾고, 정렬하고, 지웁니다.
  • 편집기 위쪽 버튼으로 실행·설정·프리셋 저장을 구분해 씁니다.
  • 캔버스 도구와 상태 표시줄을 읽습니다.
  • 검색 창으로 플로우와 작업에 바로 이동합니다.

플로우 목록​

사이드바의 플로우 또는 모든 플로우 보기를 누르면 열립니다. 위쪽에는 최근 플로우 카드가, 아래쪽에는 모든 플로우 표가 있습니다. 플로우는 모든 계정이 함께 볼 수 있습니다.

플로우 목록 화면

번호메뉴기능이런 때 사용하세요
1새로 만들기새 플로우 만들기 화면을 엽니다.새 문서용 플로우를 만들 때
2검색란이름, 소유자, 설명으로 플로우를 찾습니다."계약서"가 들어간 플로우만 볼 때
3범위 선택(전체)전체, 내 플로우, 템플릿 중 하나로 목록을 좁힙니다.내가 만든 플로우만 볼 때
4플로우 행이름, 소유자, 수정일, 생성일이 한 줄에 보입니다. 누르면 편집기가 열립니다.이름으로 찾아 열 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
표시 개수(20개씩)한 페이지에 보일 개수를 정합니다.플로우가 많아 한 번에 훑어볼 때
최근 플로우 카드최근에 고친 플로우의 이름, 소유자, 수정 시각입니다. 누르면 편집기가 열립니다.방금 작업한 플로우로 돌아갈 때
카드 삭제마우스를 올리면 보이는 휴지통으로 플로우를 지웁니다.연습용 플로우를 정리할 때
플로우 개수전체 플로우 수와 지금 보이는 범위입니다.목록이 몇 페이지인지 볼 때
정렬 머리글이름, 소유자, 수정일, 생성일을 누르면 그 기준으로 정렬합니다.오래전에 만든 플로우를 찾을 때
행 삭제마우스를 올리면 보이는 휴지통으로 플로우를 지웁니다. "이 플로우를 삭제할까요?"를 확인합니다.더 쓰지 않는 플로우를 지울 때

플로우 삭제는 소유자나 관리자만 할 수 있습니다. 소유자가 system인 "기본 파이프라인"은 Deep Connector 문서 처리에 쓰이는 공용 플로우이므로 지우거나 고치지 마세요.

플로우 편집기​

플로우를 열면 편집기가 나옵니다. 가운데 캔버스에 노드와 연결선이 있고, 위쪽에 실행과 저장 버튼이 있습니다. 아래 화면은 시작하기의 보고서를 실행한 뒤의 모습입니다.

플로우 편집기 화면

번호메뉴기능이런 때 사용하세요
1파이프라인 설정(톱니바퀴)이름, 설명, DeepConnect 배포 여부를 바꾸는 창을 엽니다.플로우를 Deep Connector에 공개할 때
2파이프라인 실행(파란 재생 버튼)입력 파일을 넣고 연결된 노드를 순서대로 실행합니다. 실행 중에는 파이프라인 중지로 바뀝니다.설정을 바꾼 뒤 결과를 다시 볼 때
3프리셋으로 저장지금 노드 구성에 이름을 붙여 프리셋으로 저장합니다.검토를 마친 구성을 다른 문서에도 쓸 때
4노드 추가노드와 프리셋 목록이 있는 패널을 엽니다.처리 단계를 더 넣을 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
플로우플로우 목록으로 돌아갑니다.다른 플로우를 열 때
플로우 이름지금 연 플로우 이름입니다. 누르면 이름을 고칠 수 있습니다. 소유자나 관리자만 바꿀 수 있습니다.이름에 버전을 붙일 때
입력 노드처리할 파일 이름, 용량, 실행 상태가 보입니다.어떤 파일로 실행했는지 볼 때
파싱 노드블록 수, 페이지 수, 첫 블록 내용이 보입니다.원본이 모두 읽혔는지 볼 때
청킹 노드전략, 청크 크기, 청크 겹침, 청크 수가 보입니다.몇 조각으로 나뉘었는지 볼 때
캔버스 도구위에서부터 확대, 축소, 화면 맞춤, 편집 잠금, 청크 결과 미리보기입니다.노드를 한 화면에 모을 때, 청크와 원본 PDF를 함께 볼 때
에이전트 열기(로봇 버튼)문장으로 플로우를 고치도록 요청하는 에이전트 창을 엽니다.설정 변경을 말로 맡길 때
상태 표시줄연결 상태(준비됨), 노드 수, 연결 수가 보입니다. 실행이 실패하면 실패 문구도 여기 나옵니다.실행이 끝났는지, 왜 실패했는지 볼 때

노드를 누르면 오른쪽에 작업 사이드바가 열립니다. 작업 사이드바에는 설정, 옵션 & 미리보기, 출력 스레드, YAML 탭과 노드 삭제 버튼이 있습니다. 노드 사이 연결선은 앞 노드 오른쪽 점에서 다음 노드 왼쪽 점으로 이어집니다.

노드에는 실행 상태가 대기, 처리 중, 완료, 오류, 건너뜀 등으로 표시됩니다. 실행 전에는 결과 자리에 데이터 없음이 보입니다.

따라 해 보기​

  1. 플로우 목록에서 시작하기에서 만든 플로우를 엽니다.
  2. 캔버스 도구에서 화면 맞춤을 눌러 세 노드가 한 화면에 들어오게 합니다.
  3. 상태 표시줄에 노드 3, 연결 2가 보이는지 확인합니다.
  4. 캔버스 도구 맨 아래 청크 결과 미리보기를 눌러 청크 목록과 원본 PDF를 함께 봅니다.

검색​

사이드바의 검색을 누르거나 ⌘K를 누르면 열립니다.

검색 창

번호메뉴기능이런 때 사용하세요
1검색 입력란찾을 플로우 이름이나 작업 이름을 입력합니다.이름 일부만 기억날 때
2플로우최근 플로우가 수정 시각, 소유자와 함께 보입니다.최근 작업한 플로우를 바로 열 때
3작업새 파이프라인, 사이드바 접기/펼치기, 키보드 단축키 보기를 실행합니다. 오른쪽에 단축키가 보입니다.마우스 없이 새 플로우를 만들 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
이동플로우 목록이나 설정 화면으로 이동합니다.프리셋을 정리하러 설정으로 갈 때
표시화면 언어를 영어로 바꿉니다.영문 화면으로 볼 때

정리​

  • 플로우는 목록에서 찾고, 편집기에서 노드를 눌러 결과를 봅니다.
  • 실행은 파이프라인 실행, 공개는 파이프라인 설정의 DeepConnect 배포, 재사용은 프리셋으로 저장입니다.
  • 설정은 한 번에 하나만 바꾸고, 바꾼 뒤에는 결과 본문을 다시 읽습니다.

다음 문서​

  • 노드 안내 — 노드 추가 패널의 노드 전체
  • 결과 확인과 내보내기 — 결과를 읽고 Deep Connector로 보내기
