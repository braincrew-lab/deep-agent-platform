Deep Docurator 주요 기능

화면별로 할 수 있는 일​

편집기는 처리 흐름을 만드는 곳이고, 노드 상세는 해당 단계의 설정과 결과를 읽는 곳입니다. 설정을 바꾸기 전에 어느 단계의 결과를 개선하려는지 정하면 불필요한 변경을 줄일 수 있습니다.

위치언제 쓰나요?입력하거나 선택할 것확인할 결과
플로우 목록기존 작업을 열거나 새 작업을 만들 때플로우 선택 또는 새로 만들기선택한 파이프라인 편집기
편집기 왼쪽 컴포넌트처리 단계를 추가할 때필요한 노드를 작업 공간으로 드래그추가된 노드와 연결할 지점
입력 노드처리할 파일을 지정할 때파일 선택 또는 드롭파일명·용량·지원되는 미리보기
파싱 노드 상세원본에서 추출한 내용을 검토할 때프로바이더와 필요한 옵션추출 결과와 원본 대조
청킹 노드 상세분할 기준을 지정하고 결과를 볼 때전략, 청크 크기, 청크 겹침 등청크 수와 각 조각의 본문
상단 파이프라인 실행구성을 실제 처리할 때입력 파일과 연결된 구성진행 상태 또는 오류
상단 파이프라인 설정작업 이름과 설명을 정리할 때이름과 설명저장한 작업 정보
상단 프리셋으로 저장구성을 다른 작업에 재사용할 때프리셋 이름왼쪽 프리셋 목록에 저장된 구성
청크 결과 미리보기최종 조각과 원본을 대조할 때결과 노드와 청크선택한 청크 내용과 제공 가능한 원본 화면

작업을 삭제하는 권한과 열람하는 권한은 같지 않습니다. 플로우 삭제는 소유자 또는 관리자에게 제한됩니다. 공유 작업의 설정을 바꾸기 전에는 자신이 수정할 수 있는 대상인지 확인하세요.

청킹 옵션을 이해하기​

전략은 어디를 기준으로 나눌지 정합니다. 재귀 방식은 마크다운 구조를 인식하는 분할을 사용하고, 고정 크기는 문자 크기를 기준으로 비교할 때 선택할 수 있습니다. 전략을 바꾸면 표시되는 옵션도 달라질 수 있으므로 이전에 입력한 항목이 그대로 적용된다고 가정하지 마세요.

청크 크기는 한 조각의 크기를 조정하는 값이고 청크 겹침은 인접 조각에서 겹쳐 담을 내용을 조정하는 값입니다. 결과가 잘게 갈라져 조건을 읽기 어려우면 크기와 겹침을 하나씩 바꾸어 비교합니다. 문서가 짧으면 값을 바꾸어도 청크 개수가 같을 수 있습니다. 결과 본문을 직접 읽어 변화가 있는지 확인하세요.

전략과 문서 유형에 따라 사용할 수 있는 설정이 다릅니다. 첫 실습에서는 시작하기의 PDF와 재귀 방식을 사용하고, 실제 업무 문서로 확장할 때 별도로 결과를 확인합니다.

파싱 결과와 청크 결과의 역할​

파싱 결과는 문서 내용이 읽혔는지 판단하는 자료입니다. 원본에 있는 제목이나 문장이 여기서 누락되었다면, 청킹 크기 변경보다 파싱 단계의 입력과 설정을 먼저 확인해야 합니다.

청크 결과는 그 내용을 사용할 단위로 나눈 결과입니다. 청킹 노드에서 청크 수와 본문을 읽고, 여러 조각이 있으면 앞뒤 조각으로 이동해 문맥이 유지되는지 봅니다. 원본 PDF 대조 화면은 PDF 파일과 대응 결과가 준비된 경우에 활용합니다. 다른 형식에 같은 원본 화면이 보장되는 것은 아닙니다.

프리셋을 사용하는 시점​

같은 구성으로 다른 문서를 처리하려면 프리셋으로 저장한 뒤 새로운 작업에 불러옵니다. 이름에는 문서 종류와 분할 목적을 담으면 찾기 쉽습니다. 프리셋은 처리 구성의 재사용 수단이므로 새 작업에서는 입력 파일을 다시 확인하세요.

이미 노드가 있는 작업에 프리셋을 적용하면 현재 구성을 대체하는 확인이 나올 수 있습니다. 검토 중인 결과를 보존하려면 새 플로우에서 적용하는 편이 좋습니다. 자세한 저장과 적용 순서는 반복 업무, 연습 입력과 확인 기준은 활용 사례를 참고하세요.
