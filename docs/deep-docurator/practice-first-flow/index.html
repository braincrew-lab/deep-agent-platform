Deep Docurator 실습 1: 가장 단순한 흐름 만들기

이 실습은 빈 캔버스에서 시작해 입력 노드와 파싱 노드를 직접 놓고 선으로 이은 뒤, 회의록 한 개를 읽어 결과를 확인합니다. 시작하기는 내장 프리셋으로 노드가 이미 연결된 상태에서 출발하지만, 이 실습은 노드를 고르고 놓고 잇는 손동작을 처음부터 익히는 것이 목표입니다.

이 페이지에서 할 수 있는 일

  • 빈 캔버스로 새 플로우를 만듭니다.
  • 노드 추가 패널에서 노드를 놓고 연결점을 끌어 연결선을 만듭니다.
  • 입력 노드에 파일을 넣고 파이프라인을 실행합니다.
  • 파싱 결과에서 블록 수와 블록 본문을 읽습니다.

목표​

항목내용
만들 흐름입력 → 파싱
결과물회의록이 제목·본문 블록으로 나뉜 파싱 결과
걸리는 시간노드 배치 3분, 실행 10초 안팎, 확인 5분
난이도★☆☆☆☆

준비물​

파일내용형식
회의록-영업본부-11월2주.docx브레인크루 영업본부 주간 회의록(가상). 회의 일시, 참석자, 논의 내용, 결정, 후속 조치 일곱 줄docx

같은 연습을 다른 형식으로 해도 됩니다. 입력 노드는 pdf, doc, docx, hwp, hwpx, pptx, xlsx, xls, txt, csv, md, html, htm, png, jpg, jpeg, tiff, tif, bmp, webp를 받습니다. 처음에는 글로 쓴 문서(docx, pdf, txt)가 결과를 대조하기 쉽습니다.

1단계. 빈 캔버스로 플로우 만들기​

빈 캔버스로 새 플로우 만들기

번호메뉴입력하거나 고를 값
1이름영업본부 11월 2주 회의록 읽기
2빈 캔버스고릅니다. 오른쪽 미리보기에 "빈 캔버스로 시작합니다."가 보입니다.
3플로우 만들기누르면 노드가 없는 편집기가 열립니다.
  1. 사이드바 최근 플로우 줄의 +(새 파이프라인)나 플로우 목록의 새로 만들기를 누릅니다.
  2. 이름과 설명(예: 회의록 docx를 읽어 제목·본문·표가 블록으로 나오는지 확인하는 첫 실습 흐름)을 적습니다.
  3. 시작점에서 빈 캔버스를 고르고 플로우 만들기를 누릅니다.

2단계. 노드 두 개 놓기​

노드 추가 패널에서 입력과 파싱 고르기

번호노드하는 일
1입력처리할 파일 한 개를 받습니다. 흐름의 맨 앞에 둡니다.
2파싱파일에서 제목, 본문, 표를 읽어 블록으로 만듭니다.
  1. 편집기 오른쪽 위 노드 추가를 누릅니다.
  2. 문서 처리 영역의 입력을 누르고, 이어서 파싱을 누릅니다. 누를 때마다 캔버스에 노드가 하나씩 생깁니다. 캔버스의 원하는 자리로 끌어 놓아도 됩니다.
  3. 패널 오른쪽 위 X(또는 Esc)로 패널을 닫습니다.
  4. 노드 머리글을 끌어 입력 노드를 왼쪽, 파싱 노드를 오른쪽에 나란히 둡니다.

3단계. 연결하고 파일 넣기​

노드 배치와 입력 파일

번호항목확인할 것
1입력 노드파일 이름 회의록-영업본부-11월2주.docx와 36 KB가 보입니다.
2파싱 노드왼쪽 연결점이 입력 노드의 오른쪽 연결점과 선으로 이어져 있습니다.
3입력 파일작업 사이드바에 DOCX / 36 KB가 보입니다.
4파이프라인 실행파일을 넣은 뒤 누릅니다.
  1. 입력 노드 오른쪽의 작은 원(연결점)을 눌러 파싱 노드 왼쪽 연결점까지 끌어 놓습니다. 화면 아래 상태 표시줄이 노드: 2, 연결: 1로 바뀝니다.
  2. 입력 노드를 누르고 작업 사이드바의 옵션 & 미리보기 탭을 엽니다.
  3. "파일을 드롭하거나 클릭" 영역에 회의록 파일을 끌어 놓습니다.
  4. 위쪽 파란 ▶(파이프라인 실행)을 누릅니다. 예시는 5초 안에 두 노드 모두 완료가 되었습니다.

4단계. 결과 확인하기​

파싱 결과 읽기

번호항목화면에 보이는 내용확인할 것
1파싱 노드7 블록 / 1 페이지, 첫 블록 제목원본 회의록 일곱 줄과 블록 수가 맞는지
2Parse 결과 · 7블록 목록블록마다 종류(텍스트)와 쪽 번호가 붙었는지
3원본 문서원본 보기로 바꾸는 탭docx는 원본 위치 강조가 되지 않으므로 원본 파일을 따로 열어 대조합니다
4첫 블록(가상) 영업본부 주간 회의록 — 11월 2주차제목이 빠지지 않고 읽혔는지

파싱 노드를 누르고 옵션 & 미리보기 탭을 열면 위 화면이 나옵니다. 마지막 블록 "후속 조치: 설명회 자료 목차(영업본부, 11/20), 제안서 템플릿 검토(김그루, 11/27)"까지 보이면 문서 전체가 읽힌 것입니다.

노드별 설정값​

노드설정값
입력파일회의록-영업본부-11월2주.docx
파싱프로바이더Brain Parser(처음 값 그대로)

흔한 실수와 해결​

증상원인해결
▶를 눌렀는데 "실행 실패: run has no input file or no nodes to execute"가 나옵니다.입력 노드에 파일이 없습니다.입력 노드의 옵션 & 미리보기에서 파일을 넣습니다.
파싱 노드가 대기에서 움직이지 않습니다.연결선이 없어 파싱 노드가 실행 대상이 아닙니다.상태 표시줄의 연결 수가 1인지 보고, 연결점을 다시 끌어 잇습니다.
연결선이 만들어지지 않습니다.연결점이 아닌 노드 본문에서 끌었습니다.노드 오른쪽 가장자리의 작은 원에서 시작해 다음 노드 왼쪽 원에 놓습니다.
노드가 겹쳐 하나만 보입니다.같은 자리에 연달아 추가되었습니다.위쪽 노드의 머리글을 끌어 옮기거나 캔버스 도구의 화면 맞춤을 누릅니다.

응용 과제​

  1. 같은 플로우에서 입력 파일을 회의메모-AI혁신팀-11월2주.txt로 바꿔 블록 수가 어떻게 달라지는지 비교해 보세요.
  2. 노드 추가 패널에서 청킹을 놓고 파싱 노드 뒤에 이어, 입력 → 파싱 → 청킹 흐름으로 늘려 보세요. 청크 결과 읽는 법은 시작하기에 있습니다.
  3. 영수증-가상식당-1110.png 같은 이미지 파일을 넣어 사진 속 글자도 블록으로 읽히는지 확인해 보세요.
