Deep Docurator 청킹 전략과 옵션

청킹 노드는 파싱 결과를 검색과 답변에 쓰기 좋은 크기의 조각으로 나눕니다. 같은 문서라도 전략과 크기에 따라 조각의 경계가 달라지고, 그 경계가 에이전트가 찾는 근거의 모양을 정합니다. 이 페이지는 청킹 노드의 전략 14가지와 자주 바꾸는 옵션, 전략을 고르는 기준을 설명합니다.

이 페이지에서 할 수 있는 일

  • 문서용 전략 9가지와 표용 전략 5가지의 차이를 압니다.
  • 최대 청크 길이, 최대 목표 겹침, 최소 청크 크기 같은 옵션을 바꿔 결과를 비교합니다.
  • 문서 종류에 맞는 전략을 고르는 기준을 익힙니다.

옵션을 여는 곳​

캔버스에서 청킹 노드를 누르고 작업 사이드바의 설정 탭을 엽니다. 처리 옵션에서 전략을 고르고, 고른 전략의 세부 옵션은 아래 고급 설정을 눌러 펼치면 나타납니다. 전략을 바꾸면 보이는 옵션도 바뀌므로, 바꾼 뒤에는 고급 설정의 값을 다시 확인하고 실행합니다.

전략 위에는 입력 파일의 문서 유형(Document, Slide, Excel)이 표시됩니다. 이 표시는 안내용이며, 전략 목록을 좁히거나 바꾸지 않습니다.

청킹 노드의 처리 옵션

번호메뉴기능이런 때 사용하세요
1전략나누는 방식을 고릅니다. 처음 값은 재귀 (마크다운 인식)입니다.문서 종류에 맞는 방식으로 바꿀 때
2고급 설정고른 전략의 세부 옵션을 펼치거나 접습니다.크기와 겹침을 바꿀 때
3최대 청크 길이 (글자)청크 하나가 넘지 않을 글자 수입니다.청크를 더 잘게 또는 크게 나눌 때
4최대 목표 겹침 (글자 수)이웃한 청크가 겹쳐 담을 글자 수의 상한입니다.문장이 경계에서 잘릴 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
최소 청크 크기 (글자)이보다 짧은 청크를 이웃과 합칩니다. 0이면 쓰지 않습니다.제목만 있는 짧은 청크가 많을 때
구분자 우선순위자를 때 먼저 볼 구분자 순서입니다. 화살표로 순서를 바꾸고 ×로 뺍니다.특별한 안내가 있을 때만 바꿉니다

문서용 전략​

보고서, 계약서, 회의록처럼 글이 중심인 문서에 씁니다.

전략나누는 방식이런 문서에
범용 (구조 + 토큰 예산)제목 구조를 따르면서 청크당 토큰 수를 맞춥니다.구조와 길이가 섞인 일반 문서
재귀 (마크다운 인식)제목 → 빈 줄 → 줄바꿈 → 공백 순서로 큰 단위부터 잘라 크기를 맞춥니다. 처음 값입니다.대부분의 문서, 첫 시도
고정 크기 (문자 기준)정한 글자 수마다 자릅니다.구조가 없는 긴 텍스트, 비교 기준용
LLM (고급, 모델 호출)모델이 내용을 읽고 의미 단위로 나눕니다. 프롬프트로 기준을 줄 수 있습니다.구조가 불규칙한 문서, 회의록
의미 기반문장 간 의미 거리가 크게 바뀌는 곳에서 자릅니다.주제가 자주 바뀌는 글
페이지페이지 단위로 자릅니다.쪽마다 독립된 내용인 서식, 발표 자료
마크다운마크다운 제목 깊이에 따라 자릅니다.md 문서, 제목이 뚜렷한 문서
블록 (파서 경계)파싱이 만든 블록 경계를 그대로 씁니다.파싱 결과를 그대로 보고 싶을 때
문장정한 문장 수마다 자릅니다.짧은 안내문, FAQ

표용 전략​

견적서, 판매 실적, 영수증 내역처럼 행과 열이 중심인 자료에 씁니다. 엑셀과 csv에 맞춘 전략이며, 파일 형식과 상관없이 목록에는 늘 보입니다.

전략나누는 방식이런 표에
라벨 행 (권장)행마다 "열 이름: 값" 형태로 풀어 씁니다.품목별·건별로 찾아야 하는 표
일반 행 + 헤더여러 행을 묶고 머리글을 반복해 붙입니다.행이 많은 큰 표
구조 인식엑셀 시트의 표 영역 구분점을 따라 자르고 표 주변 설명을 함께 붙입니다. 표 구조 정보가 없는 파일에서는 실패합니다.제목, 합계, 표가 섞인 엑셀 서식
열 기준기준 열과 나머지 열을 한 열씩 짝지어 열 단위로 묶습니다. 기준 열은 0부터 셉니다.항목별로 값을 모아 볼 표
고정 N행정한 행 수마다 자릅니다.형식이 단순한 목록

자주 바꾸는 옵션​

옵션쓰는 전략뜻처음 값
최대 청크 길이 (글자)재귀, 고정 크기, 문장, 마크다운, 의미 기반, 블록, LLM청크 하나가 넘지 않을 글자 수입니다. 넘는 부분은 글자 단위로 더 나눕니다.1000
최대 목표 겹침 (글자 수)재귀, 의미 기반이웃한 청크가 겹쳐 담을 글자 수의 상한입니다. 구분자 경계를 지키므로 실제 겹침은 더 적거나 없을 수 있습니다.200
겹침 (글자 수)고정 크기이웃한 청크가 겹치는 글자 수입니다. 입력한 값 그대로 씁니다.200
최소 청크 크기 (글자)범용을 뺀 모든 전략이보다 짧은 청크를 이웃과 합칩니다. 0이면 쓰지 않습니다.0
구분자 우선순위재귀자를 때 먼저 볼 구분자 순서입니다. 제목 6부터 제목 1, 코드 펜스, 빈 줄, 줄바꿈, 공백 순입니다.기본 순서
청크당 최대 토큰 수범용청크 하나가 넘지 않을 토큰 수입니다.512
프롬프트LLM나누는 기준을 문장으로 적습니다. 예: 안건별로 나누고 결정 사항은 따로 두세요.비어 있음
분할 기준의미 기반백분위, 표준편차, 사분위, 기울기 중에서 고릅니다.백분위
헤더 깊이마크다운몇 단계 제목까지 자를지 정합니다.3
최대 문장 수문장청크 하나에 넣을 문장 수입니다.3
청크당 최대 페이지 수페이지청크 하나에 넣을 페이지 수입니다.1
최대 데이터 행 수표용 전략청크 하나에 넣을 데이터 행 수입니다.50
최대 청크 길이 (글자)표용 전략, 페이지청크 하나가 넘지 않을 글자 수입니다.표용 1500, 페이지 1000
큰 행·셀 처리표용 전략한 행이나 셀이 최대 길이를 넘을 때 보존하고 경고, 요청 실패, 필드 경계 분할 중 하나를 고릅니다.보존하고 경고
원본 헤더 반복일반 행 + 헤더 등청크마다 표 머리글을 다시 붙입니다.켜짐
표 설명 메타데이터 생성라벨 행, 일반 행 + 헤더모델이 표 설명을 써서 메타데이터에만 기록합니다. 요약 청크를 따로 만들지는 않습니다.꺼짐

숫자 칸에 정수가 아닌 값이나 범위를 벗어난 값을 넣으면 "정수를 입력하세요." 또는 허용 범위 안내가 표시됩니다. 겹침이 청크 길이보다 크거나 같으면 겹침이 청크 크기보다 작아야 한다는 안내가 표시되고, 값은 자동으로 고쳐지지 않습니다.

전략을 고르는 기준​

  1. 처음에는 재귀 (마크다운 인식), 최대 청크 길이 1000, 최대 목표 겹침 200으로 실행해 기준 결과를 만듭니다.
  2. 표가 중심인 엑셀·csv라면 라벨 행 (권장)으로 바꿔 행이 한 청크씩 풀려 나오는지 봅니다.
  3. 조항·장 구조가 뚜렷한 문서라면 마크다운이나 범용으로 바꿔 제목 단위로 끊기는지 비교합니다.
  4. 구조가 불규칙한 회의 메모라면 LLM 전략에 프롬프트로 기준을 적어 비교합니다.
  5. 비교할 때에는 값 하나만 바꾸고, 청크 수보다 청크 본문을 읽어 조건이 끊기지 않았는지 봅니다.

여러 전략을 한 번에 비교하고 싶다면 내장 프리셋 Select 파이프라인 (기본)을 씁니다. 재귀, 의미 기반, 마크다운, LLM 네 전략으로 각각 나눈 뒤 평가 노드가 점수를 매기고, 전략 선택 노드가 점수가 가장 높은 결과를 고릅니다. 점수는 표본 평가이므로 결과 본문도 함께 읽어 확인하세요.

따라 해 보기​

  1. 시작하기에서 만든 플로우를 엽니다.
  2. 청킹 노드를 누르고 설정 탭에서 고급 설정을 펼친 뒤 **최대 청크 길이 (글자)**를 1000에서 500으로 바꿉니다.
  3. ▶(파이프라인 실행) 버튼을 누르고 청킹 노드의 청크 수가 어떻게 바뀌는지 봅니다.
  4. 청크 본문을 앞뒤로 읽어 문장이 중간에 잘리지 않았는지 확인합니다.
  5. 비교가 끝나면 값을 1000으로 되돌리거나, 더 나은 값을 프리셋으로 저장합니다.

이럴 때 쓰세요​

브레인크루 AI혁신팀 김그루 사원이 실제로 이 화면을 여는 순간들입니다.

이런 상황에서이렇게 하세요
규정 질문에 답이 조건 없이 잘려 나올 때재귀 전략의 최대 청크 크기를 키우거나 마크다운 전략으로 조항 제목 단위로 나눠 비교합니다(실습 2).
엑셀 판매 데이터를 행 하나씩 찾게 하고 싶을 때표용 전략 라벨 행 (권장)을 고르고 최대 데이터 행 수를 1로 둡니다(실습 3).
긴 보고서를 장과 절 단위로 나누고 싶을 때목차 노드 다음에 범용 전략을 씁니다(실습 9).
FAQ의 질문과 답이 서로 다른 청크로 갈라질 때고정 크기 대신 구분자를 보는 재귀 전략으로 바꾸고 평가 점수로 확인합니다(실습 13).
