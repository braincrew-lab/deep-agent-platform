Deep Docurator 에이전트로 플로우 만들기

편집기 오른쪽 아래 로봇 버튼을 누르면 에이전트 창이 열립니다. 하고 싶은 일을 문장으로 적거나 문서를 끌어 놓으면, 에이전트가 노드를 놓고 연결하고 옵션을 바꾼 뒤 실행해 결과까지 설명합니다. 이 페이지는 에이전트 창의 메뉴와 요청하는 요령, 에이전트가 바꾼 내용을 확인하는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 에이전트 창을 열고 문서를 첨부해 플로우를 맡깁니다.
  • 노드 추가, 옵션 변경, 실행 같은 요청을 문장으로 보냅니다.
  • 에이전트가 바꾼 노드와 값을 직접 확인하고 필요하면 되돌립니다.

에이전트가 하는 일​

할 수 있는 일예시 요청
노드를 놓고 연결하고 지우기청킹 다음에 메타데이터 노드를 붙여 주세요.
노드 옵션 바꾸기청킹 노드의 최대 청크 길이를 800으로 바꿔 주세요.
플로우 점검과 실행지금 플로우가 실행 가능한지 점검하고 실행해 주세요.
결과 읽고 설명하기청크 결과에서 조항이 중간에 잘린 곳이 있는지 알려 주세요.
첨부 문서 읽기첨부한 계약서의 조항 구조를 보고 알맞은 청킹 전략을 골라 주세요.

에이전트는 여러 단계가 필요한 요청을 받으면 먼저 계획을 보여 주고, 승인하면 구성과 실행, 결과 분석까지 이어서 진행합니다. 노드 하나 추가처럼 단순한 요청은 바로 처리할 수 있습니다. 문서만 끌어 놓고 요청을 적지 않으면 계획 확인 없이 그 문서에 알맞은 플로우를 스스로 구성합니다. 답변은 한국어로 합니다. 사용하는 모델은 운영 담당자가 정하며 창에서 고르지 않습니다.

에이전트 창 메뉴​

편집기 오른쪽 아래 로봇 버튼(Agent Chat 열기)을 누르면 아래 창이 열립니다. 그림은 입력란에 요청을 적고 보내기 전의 모습입니다. 보낸 뒤 입력 파일이 없어 실행하지 못한 모습은 문제 해결에 있습니다.

편집기 에이전트 창

번호메뉴기능이런 때 사용하세요
1머리글과 상태준비됨, 대기, 분석 중..., 구성 중..., 입력 대기 같은 상태가 보입니다. 누르면 대화를 펼치거나 접습니다.에이전트가 일을 마쳤는지 볼 때
2입력란"무엇을 변경하거나 만들고 싶으신가요?"에 요청을 적습니다.요청을 보낼 때
3문서 첨부파일 첨부와 같은 파일 선택 창을 엽니다. 두 버튼 모두 입력 노드와 같은 20가지 형식을 받습니다.문서를 골라 첨부할 때
4보내기요청을 보냅니다. Enter로도 보냅니다.요청을 다 적었을 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
접기창을 접습니다. 진행 중인 작업은 계속됩니다.캔버스를 넓게 보고 싶을 때
파일 첨부파일 선택 창을 엽니다. 문서를 창에 끌어 놓아도 됩니다.처리할 문서를 함께 줄 때

첨부한 문서는 입력 노드의 파일이 되고 에이전트 대화가 새로 시작됩니다. 입력 노드는 파일 한 개만 받으므로 한 번에 한 문서만 첨부하세요.

요청하는 요령​

  • 대상 노드와 바꿀 값을 함께 적습니다. 예: 청킹 노드의 전략을 라벨 행 (권장)으로 바꿔 주세요.
  • 결과 기준을 적습니다. 예: 조항 하나가 청크 하나가 되도록 나눠 주세요.
  • 한 번에 한 가지씩 요청하고, 바뀐 결과를 본 뒤 다음 요청을 보냅니다.
  • 메타데이터 필드가 필요하면 필드 이름과 뜻을 적습니다. 예: 메타데이터에 지급기한(문자열, 대금 지급 기한)을 추가해 주세요.

따라 해 보기​

  1. 시작하기에서 만든 플로우를 엽니다.

  2. 오른쪽 아래 로봇 버튼을 눌러 에이전트 창을 엽니다.

  3. 입력란에 아래처럼 적고 보내기를 누릅니다.

    프롬프트: 청킹 노드의 최대 청크 길이를 500으로 바꾸고 다시 실행해 주세요. 바뀌기 전과 후의 청크 수도 알려 주세요.

  4. 상태가 입력 대기로 바뀌고 계획이 보이면 "진행"이라고 답해 승인합니다.

  5. 상태가 입력 대기나 대기로 바뀔 때까지 기다립니다. 진행 중에는 "에이전트가 그래프를 구성하는 중"이나 "에이전트가 파이프라인을 처리하는 중"이 보이고, 편집기의 실행 버튼은 "에이전트 작동 중입니다. 잠시 후 시도하세요"로 잠깁니다.

  6. 에이전트의 답변에서 바뀐 값과 청크 수를 읽습니다.

  7. 청킹 노드를 눌러 설정 탭의 고급 설정을 펼치고 **최대 청크 길이 (글자)**가 500인지 직접 확인합니다.

에이전트가 바꾼 내용 확인하기​

에이전트가 고친 값은 반드시 해당 노드의 설정 탭에서 다시 확인합니다. 의도와 다르면 직접 값을 되돌리거나 에이전트에게 되돌려 달라고 요청합니다. 에이전트가 실행까지 시도했는데 입력 노드에 파일이 없으면 실행이 실패하므로, 먼저 입력 노드에 파일이 있는지 봅니다.

에이전트가 일하는 동안 편집기에서 다른 그래프나 파일을 고르면 "에이전트가 작업 중이라 선택한 그래프와 파일을 적용하지 못했습니다."가 표시될 수 있습니다. 상태가 입력 대기나 대기로 바뀐 뒤 다시 조작하세요.

안내 문구뜻과 조치
에이전트 세션이 아직 시작되지 않았습니다.문서를 첨부하거나 잠시 후 다시 보냅니다.
에이전트 세션을 시작하지 못했습니다.화면을 새로 고친 뒤 다시 엽니다. 반복되면 운영 담당자에게 알립니다.
메시지를 보내지 못했습니다.연결 상태를 확인하고 다시 보냅니다.
