Deep Docurator 입력 노드와 지원 파일 형식

입력 노드는 플로우가 처리할 파일을 받는 첫 단계입니다. 이 페이지는 입력 노드에 넣을 수 있는 파일 형식 20가지와 용량 한도, 형식마다 결과가 어떻게 다른지, 파일을 바꾸거나 지울 때 알아 둘 점을 정리합니다.

이 페이지에서 할 수 있는 일

  • 입력 노드에 넣을 수 있는 확장자 전체와 최대 용량을 확인합니다.
  • 형식에 따라 노드에 표시되는 문서 유형과 미리보기가 어떻게 다른지 압니다.
  • 한 번에 파일 한 개만 처리된다는 점과 파일을 바꾸는 방법을 익힙니다.
  • 받지 않는 형식을 가진 문서를 어떻게 바꿔 넣을지 정합니다.

지원하는 확장자 전체​

입력 노드, 파일 선택 창, 편집기 에이전트의 문서 첨부는 모두 같은 20가지 확장자를 받습니다.

분류확장자주로 쓰는 문서
PDFpdf보고서, 계약서, 규정, 스캔 문서
워드doc, docx계약서 초안, 회의록, 제안서
한글hwp, hwpx공문, 사내 규정, 기안문
발표 자료pptx보고 발표 자료, 교육 자료
엑셀xlsx, xls견적서, 판매 실적, 예산표
텍스트txt, csv, md회의 메모, 내보낸 표 데이터, 마크다운 문서
웹 문서html, htm저장한 웹 페이지, 사내 공지
이미지png, jpg, jpeg, tiff, tif, bmp, webp영수증 사진, 스캔한 서류, 화면 캡처

xls 파일은 파일 선택 창에서 고를 수 있지만 파싱 단계에서 처리되지 않고, xlsx로 바꿔 다시 시도하라는 영문 오류가 납니다. 엑셀에서 다른 이름으로 저장을 눌러 xlsx 형식으로 저장한 뒤 넣으세요.

위 목록에 없는 형식은 받지 않습니다. 자주 만나는 경우는 다음과 같이 바꿔 넣습니다.

가진 파일바꾸는 방법
ppt(파워포인트 97-2003)파워포인트에서 pptx로 다시 저장합니다.
xlsm, xlsb(매크로·바이너리 엑셀)엑셀에서 xlsx로 다시 저장합니다. 매크로는 처리에 쓰이지 않습니다.
json, xml내용을 표로 볼 수 있으면 csv로, 글이면 txt나 md로 저장합니다.
zip(여러 문서 묶음)압축을 풀어 문서를 한 개씩 넣습니다.

용량 한도​

파일 한 개의 최대 크기는 500MB입니다. 입력 노드의 파일 영역에 최대 500MB라고 표시되며, 넘는 파일을 고르면 "파일 크기가 500MB를 초과합니다."라는 안내가 나오고 파일이 올라가지 않습니다. 실행할 때에도 같은 한도를 다시 확인합니다.

운영 담당자가 서버의 최대 업로드 파일 크기를 바꿔 둔 경우 실제 한도가 다를 수 있습니다. 큰 파일이 실행 단계에서 거부되면 문제 해결의 용량 항목을 확인하세요. 용량보다 페이지 수가 처리 시간에 더 큰 영향을 줍니다. 수백 쪽짜리 문서는 연습할 때 필요한 장만 따로 저장해 넣으면 결과를 확인하기 쉽습니다.

형식마다 다른 점​

파일 형식에 따라 문서를 읽는 방식과 화면에 보이는 미리보기가 다릅니다. 같은 내용이라도 형식이 바뀌면 블록 구성이 달라질 수 있으니, 처음 쓰는 형식은 결과를 한 번 읽어 확인합니다.

형식읽는 방식입력 노드의 문서 유형노드 안 미리보기
pdf문서 분석기로 글자, 표, 이미지 위치를 읽습니다.문서PDF가 그대로 보입니다.
doc, docx, hwp, hwpx, html, htm문서 분석기로 제목, 본문, 표를 읽습니다.문서파일 이름과 형식·용량만 보입니다.
pptx문서 분석기로 슬라이드별 내용을 읽습니다.슬라이드파일 이름과 형식·용량만 보입니다.
png, jpg, jpeg, tiff, tif, bmp, webp문서 분석기가 이미지 속 글자와 표를 읽습니다.문서이미지가 보입니다. 브라우저가 그리지 못하는 tiff, tif는 보이지 않을 수 있습니다.
xlsx엑셀 시트를 표로 읽습니다.엑셀파일 이름과 형식·용량만 보입니다.
csv, txt글자를 그대로 읽습니다.엑셀(csv), 문서(txt)파일 이름과 형식·용량만 보입니다.
md마크다운 제목 구조를 살려 읽습니다.문서파일 이름과 형식·용량만 보입니다.

입력 노드에 보이는 문서 유형은 안내용 표시입니다. 문서 유형이 엑셀이라고 해서 청킹 전략이 자동으로 바뀌지는 않습니다. 표 파일을 행 단위로 나누려면 청킹 노드에서 표용 전략을 직접 고릅니다. 자세한 내용은 청킹 전략과 옵션에 있습니다.

파싱 결과의 원본 문서 보기와 청크 결과 미리보기에서 원본 위치를 강조하는 기능은 PDF에서만 동작합니다. PDF가 아닌 파일은 "원본 PDF 를 표시할 수 없습니다."가 보이므로, 원본 파일을 따로 열어 두고 대조하세요.

파일 넣기, 바꾸기, 지우기​

입력 노드를 누르면 오른쪽에 작업 사이드바가 열립니다. 옵션 & 미리보기 탭의 파일 영역에서 파일을 넣습니다.

  1. 캔버스에서 입력 노드를 누릅니다.
  2. 옵션 & 미리보기 탭을 엽니다.
  3. "파일을 드롭하거나 클릭"이라고 적힌 영역에 파일을 끌어 놓거나, 영역을 눌러 파일을 고릅니다.
  4. 입력 파일에 형식과 용량(예: PDF / 4 KB)이 보이는지 확인합니다.
  5. 캔버스의 입력 노드에도 파일 이름과 용량이 보이는지 확인합니다.

입력 노드 하나에는 파일 한 개만 들어갑니다. 다른 파일을 넣으면 앞의 파일을 대신하며, 이때 "새 업로드로 이전 Input 파일 연결을 교체했습니다."라는 안내가 나올 수 있습니다. 파일을 빼려면 파일 영역의 파일 제거 버튼을 누릅니다.

여러 문서를 같은 기준으로 처리하려면 문서마다 플로우를 따로 만들거나, 한 플로우에서 파일을 바꿔 가며 다시 실행합니다. 같은 구성을 여러 플로우에 쓰는 방법은 프리셋과 템플릿 플로우와 반복 업무에 있습니다.

출력 스레드와 입력값​

입력 노드의 옵션 & 미리보기 탭 파일 영역 아래 **출력 스레드 (코드가 쓰는 것)**에서는 파일 말고도 이름 붙인 값을 선언할 수 있습니다. 출력 스레드는 뒤에 오는 커스텀 노드의 코드가 읽는 값이고, 값은 이름 옆의 입력값 (JSON) 칸에 적습니다. 일반적인 문서 정리 작업에서는 이 값을 바꾸지 않아도 됩니다. 커스텀 노드에서 쓸 기준값(예: 부서 이름)을 넘길 때만 사용합니다.

형식을 고르는 요령​

상황추천
같은 문서가 hwp와 pdf로 모두 있음원본 대조가 쉬운 pdf를 먼저 넣고, 결과가 다르면 hwp로도 비교합니다.
표가 중심인 자료엑셀 원본(xlsx)이나 csv를 넣고 표용 청킹 전략을 고릅니다.
영수증·서류를 휴대폰으로 찍음글자가 잘 보이게 바로 찍은 jpg나 png를 넣고, 파싱 결과에서 숫자를 원본과 대조합니다.
발표 자료pptx를 넣으면 슬라이드 단위로 내용을 읽습니다. 그림 속 글자는 결과에서 한 번 더 확인합니다.
