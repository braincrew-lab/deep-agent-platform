Deep Docurator 흐름 만들기 실습

이 묶음은 빈 캔버스에서 노드를 직접 놓고 이어 흐름(플로우)을 만드는 실습 여덟 가지를 난이도 순으로 담았습니다. 실습마다 목표, 준비물, 노드 배치 그림, 노드별 설정값 표, 실행 결과, 흔한 실수와 해결, 응용 과제가 있습니다. 예시 인물은 브레인크루 AI혁신팀 김그루 사원이고, 파일과 금액, 고객 정보는 모두 연습용 가상 자료입니다.

이 페이지에서 할 수 있는 일

  • 실습 여덟 가지의 흐름 모양과 난이도를 한눈에 봅니다.
  • 내 업무에 가까운 실습을 골라 바로 이동합니다.
  • 모든 실습에 공통인 손동작(노드 놓기, 잇기, 실행, 결과 읽기)을 익힙니다.

실습 한눈에 보기​

실습만드는 흐름새로 익히는 것예시 파일난이도
실습 1: 가장 단순한 흐름입력 → 파싱빈 캔버스, 노드 놓기와 잇기, 파싱 결과 읽기docx★☆☆☆☆
실습 2: 청킹 전략 비교파싱 → 청킹 3개 → 평가 3개 → 전략 선택갈라지고 모이는 연결, 평가 점수 비교pdf★★☆☆☆
실습 3: 표와 필드 추출청킹(라벨 행) → 메타데이터 → 메타데이터 평가필드 정의(타입, 허용 값), 정확도 확인, 출력 스레드 표csv★★☆☆☆
실습 4: 여러 문서 일괄 처리흐름 배포 → Deep Connector 여러 파일 업로드DeepConnect 배포, 컬렉션 기본 파이프라인txt, docx, html, md★★★☆☆
실습 5: 프리셋과 YAML흐름 → 프리셋 저장 → 불러오기 → YAML 내보내기·가져오기프리셋 재사용, 구성 파일 전달yaml, yml★★☆☆☆
실습 6: 에이전트·지식과 연결흐름 배포 → Deep Connector 업로드 → Deep Agent Builder 질문세 제품 연결, 근거 확인pdf★★★★☆
실습 7: 조건 분기파싱 → 라우터 → 경로별 청킹라우터 규칙, 경로별 후속 노드csv, pdf★★★☆☆
실습 8: 개인정보 가리기와 치환 연쇄청킹 → PII → 텍스트 치환 2개 → 필터규칙 기반 탐지, 커스텀 정규식, 노드 연쇄csv★★★★☆

처음이라면 실습 1부터 차례로 하세요. 실습 4와 6은 Deep Connector, 실습 6은 Deep Agent Builder에도 들어갈 수 있는 계정이 필요합니다.

실습과 활용사례의 차이​

구분실습활용사례
목적흐름을 직접 만드는 방법을 손으로 익힙니다.업무 문서를 정리한 결과물을 봅니다.
시작점대부분 빈 캔버스에서 노드를 하나씩 놓습니다.내장 프리셋에서 시작해 옵션만 바꿉니다.
다루는 노드평가, 전략 선택, 메타데이터 평가, 라우터, 텍스트 치환까지입력, 파싱, 청킹, 메타데이터, PII, 필터

모든 실습에 공통인 손동작​

하고 싶은 일방법
노드 놓기편집기 오른쪽 위 노드 추가 → 노드 이름을 누르거나 캔버스로 끌어 놓기
노드 옮기기노드 머리글을 끌기. 여러 노드가 겹치면 캔버스 도구의 화면 맞춤
노드 잇기앞 노드 오른쪽 작은 원(연결점)에서 다음 노드 왼쪽 원으로 끌기. 상태 표시줄의 연결 수로 확인
설정 바꾸기노드를 누르고 작업 사이드바 설정 탭 → 고급 설정 펼치기
파일 넣기입력 노드 → 옵션 & 미리보기 탭의 파일 영역
실행위쪽 파란 ▶(파이프라인 실행)
결과 읽기노드 → 옵션 & 미리보기(요약·청크 본문), 출력 스레드(다음 노드로 넘긴 값 표)

노드마다의 설정 항목 전체는 노드별 설정 항목에 있습니다.

연습 파일 만들기​

실습직접 만들 때의 내용
1회의 일시, 참석자, 논의 두 줄, 결정, 후속 조치를 한 줄씩 적은 1쪽 회의록(docx)
2적용 범위, 지급 기준 표(일비, 숙박비, 사전 승인, 정산 기한), 교통 원칙이 있는 1쪽 규정(pdf)
3일자, 구분, 거래처, 품목, 금액 다섯 열에 20행 정도의 거래 표(csv 또는 xlsx)
4형식이 다른 회의록 세네 개(docx, html, md)
7실습 3의 표와 실습 2의 규정
8접수일, 고객명, 연락처, 이메일, 문의 유형, 문의 내용, 처리 결과 열의 가상 상담 기록(csv)

실제 고객 정보나 영업 비밀이 들어 있는 문서로 연습하지 마세요.
