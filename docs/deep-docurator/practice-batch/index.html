Deep Docurator 실습 4: 여러 문서 일괄 처리 흐름

편집기의 입력 노드는 파일 한 개만 받습니다. 같은 기준으로 문서 여러 개를 한 번에 처리하려면, Deep Docurator에서 흐름을 만들어 시험한 뒤 DeepConnect 배포로 공개하고, Deep Connector 컬렉션에 파일 여러 개를 한 번에 올려 그 흐름으로 처리합니다. 이 실습은 회의록 네 개를 "회의록 일괄 정리" 흐름 하나로 처리하는 과정을 처음부터 끝까지 따라 합니다.

이 페이지에서 할 수 있는 일

  • 문서 한 개로 흐름을 시험한 뒤 Deep Connector에 배포합니다.
  • 배포한 흐름을 컬렉션의 기본 파이프라인으로 지정합니다.
  • 파일 여러 개를 한 번에 올려 같은 흐름으로 처리합니다.
  • 문서별 청크 수로 처리 결과를 확인합니다.

목표​

항목내용
만들 흐름입력 → 파싱 → 청킹(재귀 600자) → 메타데이터(summary, 결정사항, 담당자)
결과물회의록 여러 개가 같은 기준으로 청크와 메타데이터가 붙은 Deep Connector 컬렉션
걸리는 시간흐름 시험 5분, 배포·업로드 5분, 처리 1~3분
난이도★★★☆☆

준비물​

파일내용형식
회의메모-AI혁신팀-11월2주.txtAI혁신팀 주간 회의 메모. 1단계의 Docurator 흐름 시험에만 씁니다.txt
회의록-영업본부-11월2주.docx영업본부 주간 회의록docx
회의록_AI업무혁신_20261110.htmlAI 업무혁신 회의록 웹 문서html
회의록-표준양식.md회의록 표준 양식md

두 제품이 받는 확장자가 다르므로, 일괄 처리할 파일은 Deep Connector 기준에 맞춥니다.

제품받는 확장자
Deep Docurator 입력 노드pdf, doc, docx, hwp, hwpx, pptx, xlsx, xls, txt, csv, md, html, htm, png, jpg, jpeg, tiff, tif, bmp, webp
Deep Connector 업로드pdf, png, jpg, jpeg, webp, tiff, tif, bmp, doc, docx, pptx, md, html, htm, xlsx, xls, hwp, hwpx

txt와 csv는 Deep Docurator에서는 처리되지만 Deep Connector 지원 형식이 아닙니다. 이 실습에서는 일부러 txt를 함께 골라 보았는데, 업로드 화면에서는 제외 0개로 통과했지만 처리된 문서 목록에는 들어오지 않았습니다. 실제 업무에서는 txt를 md로, csv를 xlsx로 저장해 올리세요.

1단계. 문서 한 개로 흐름 시험하기​

  1. 빈 캔버스로 새 플로우를 만듭니다. 이름: 회의록 일괄 정리. 설명: 회의록·회의 메모를 600자 청크로 나누고 요약·결정사항·담당자를 붙이는 흐름.
  2. 입력 → 파싱 → 청킹 → 메타데이터 네 노드를 놓고 잇습니다.
  3. 아래 표대로 설정하고, 입력 노드에 회의메모-AI혁신팀-11월2주.txt를 넣어 실행합니다.
노드설정값
청킹전략 / 최대 청크 크기 (글자 수) / 최대 목표 겹침 (글자 수)재귀 (마크다운 인식) / 600 / 50
메타데이터필드 summary(문자열)이 청크 내용을 한국어 한 문장으로 요약
메타데이터필드 결정사항(배열(문자열))청크에 적힌 결정 사항. 없으면 빈 배열
메타데이터필드 담당자(배열(문자열))후속 조치를 맡은 사람이나 부서 이름. 없으면 빈 배열

예시는 3초 안에 끝났고, 메타데이터 노드에 summary "AI혁신팀 주간 회의에서 회의록 양식 통합, 보고서 검토 절차 개선, 견적서 비교 방법 시범 도입을 논의…", 결정사항 세 개, 담당자 "김그루"가 붙었습니다. 결과가 기대와 다르면 여기서 설정을 고친 뒤 배포합니다.

2단계. Deep Connector에 배포하기​

흐름을 Deep Connector에 배포

번호메뉴하는 일
1DeepConnect 배포켜면 "외부 /pipelines 에 노출 — 저장 시 적용"이 보입니다.
2저장눌러야 배포가 반영됩니다.
  1. 편집기 위쪽 톱니바퀴 파이프라인 설정을 누릅니다.
  2. DeepConnect 배포를 켜고 저장을 누릅니다.

3단계. 컬렉션 만들고 파일 네 개 한 번에 올리기​

  1. Deep Connector에서 새 컬렉션을 누르고 이름 "AI혁신팀 회의록 모음", 설명 "AI혁신팀·영업본부 회의록과 회의 메모 (가상 자료)"를 적습니다.
  2. 기본 파이프라인에서 "회의록 일괄 정리"를 고르고 새 컬렉션 만들기를 누릅니다.
  3. 문서 업로드를 누르고 파일 추가에서 준비한 파일을 한 번에 고릅니다.

여러 파일 한 번에 올리기

번호항목확인할 것
1파일 확인 결과"전체 4개 중 4개 업로드 (43.3 KB), 제외 0개"와 파일마다 확인됨. txt도 여기서는 제외되지 않았습니다.
2파이프라인회의록 일괄 정리 (기본). 컬렉션 기본값이 미리 골라져 있습니다.
3문서 업로드 (4)누르면 네 파일이 대기열에 들어가 차례로 처리됩니다.

4단계. 처리 결과 확인하기​

일괄 처리 뒤 문서 목록

번호항목화면에 보이는 내용확인할 것
1문서 수총 3개docx, html, md 세 문서. Deep Connector 지원 형식이 아닌 txt는 문서 목록에 들어오지 않았습니다.
2청크 열docx 1, html 2, md 1문서마다 청크가 만들어졌는지

예시에서는 업로드 후 1분 안에 세 문서의 처리가 끝났습니다. 청크를 눌러 메타데이터(summary, 결정사항, 담당자)가 붙었는지 보는 방법은 Deep Connector 매뉴얼의 문서와 청크 확인 페이지에 있습니다.

흔한 실수와 해결​

증상원인해결
Deep Connector 파이프라인 목록에 흐름이 없습니다.DeepConnect 배포를 켜고 저장을 누르지 않았습니다.2단계를 다시 하고 업로드 화면을 새로 엽니다.
올린 파일 수보다 문서 수가 적습니다.Deep Connector 지원 형식이 아닌 파일(txt, csv, ppt 등)이 섞였습니다. 업로드 화면에서 제외로 표시되지 않아도 처리되지 않을 수 있습니다.txt는 md, csv는 xlsx, ppt는 pptx로 저장해 다시 올립니다.
흐름을 고친 뒤에도 예전 결과가 남아 있습니다.이미 처리된 문서는 자동으로 다시 처리되지 않습니다.Deep Connector 문서 목록에서 다시 적재를 누릅니다.
입력 노드에 파일 여러 개를 끌어 놓았는데 하나만 들어갑니다.입력 노드는 파일 한 개만 받습니다.여러 문서는 이 실습처럼 Deep Connector 업로드로 처리합니다.

응용 과제​

  1. 업로드 화면의 공통 메타데이터에 "부서: AI혁신팀"을 붙여 올리고, 흐름이 붙인 필드와 함께 검색 필터로 쓰는지 보세요.
  2. 폴더 추가로 회의록 폴더를 통째로 올려 보세요.
  3. 흐름의 청크 크기를 400으로 바꾼 뒤 문서 하나를 다시 적재해 청크 수가 어떻게 바뀌는지 비교하세요.
