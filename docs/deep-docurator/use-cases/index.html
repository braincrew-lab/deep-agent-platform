Deep Docurator 활용사례

이 묶음은 브레인크루 AI혁신팀 김그루 사원이 평소 업무 문서를 Deep Docurator로 정리하는 여섯 가지 사례를 담았습니다. 사례마다 목표, 준비물, 단계별 화면, 결과물 예시, 응용 팁을 차례로 보여 줍니다. 예시 문서와 금액, 일정은 모두 연습용 가상 자료입니다.

이 페이지에서 할 수 있는 일

  • 내 업무에 가까운 사례를 골라 바로 이동합니다.
  • 사례마다 쓰는 노드 조합과 파일 형식을 한눈에 봅니다.
  • 어떤 사례에서든 공통으로 쓰는 결과 검토 기준을 익힙니다.

사례 한눈에 보기​

사례하고 싶은 일노드 조합예시 파일
계약서 핵심 조항 추출조항 유형, 계약 금액·지급 조건, 기한을 조항별로 뽑기입력 → 파싱 → 청킹 → 메타데이터docx, pdf
영수증·견적서 표 정리품목·금액을 행 단위로 정리하고 영수증 사진의 금액 읽기입력 → 파싱 → 청킹(라벨 행) → 메타데이터xlsx, csv, png, jpg
보고서 요약본 만들기장마다 세 줄 요약과 핵심 수치 뽑기입력 → 파싱 → 청킹 → 메타데이터pdf, pptx
회의록 표준 양식으로 정리제각각인 회의 메모를 안건·결정·할 일 항목으로 정리입력 → 파싱 → 청킹(문장) → 메타데이터txt, docx, md
여러 문서 비교표 만들기개정 전후 규정을 같은 기준으로 처리해 차이 비교프리셋 하나로 문서마다 플로우 실행pdf, html
고객 문의 기록 개인정보 가리기상담 기록의 이름, 전화번호, 이메일을 가린 뒤 지식으로 쓰기입력 → 파싱 → 청킹 → PII → 필터csv, txt

사례를 고르는 기준​

이런 고민이 있다면먼저 볼 사례
긴 문서에서 몇 가지 값만 빨리 찾고 싶다계약서 핵심 조항 추출
엑셀 표를 에이전트가 품목별로 찾게 하고 싶다영수증·견적서 표 정리
보고서를 처음부터 끝까지 읽을 시간이 없다보고서 요약본 만들기
부서마다 회의록 형식이 달라 모아 보기 어렵다회의록 표준 양식으로 정리
개정판에서 무엇이 바뀌었는지 정리해야 한다여러 문서 비교표 만들기
고객 정보가 섞인 자료를 지식으로 쓰고 싶다고객 문의 기록 개인정보 가리기

결과를 검토하는 공통 질문​

확인 질문검토 기준
원본이 다 읽혔나요?파싱 결과의 페이지 수와 표 숫자가 원본과 같습니다.
조건이 함께 있나요?금액과 그 금액의 조건(기한, 비율, 대상)이 같은 청크나 바로 이웃한 청크에 있습니다.
표 머리글이 남았나요?표가 나뉘어도 각 청크에서 열의 뜻을 알 수 있습니다.
뽑은 값이 맞나요?메타데이터 값을 청크 본문과 몇 건 골라 대조합니다.
원본에 없는 말이 섞였나요?청크 본문과 메타데이터에 원본에 없는 내용이 없습니다. 모델이 만든 요약은 특히 확인합니다.

연습 자료 만들기​

사례의 예시 파일은 직접 만들어도 됩니다. 문서 작성 도구로 각 사례 페이지의 준비물 표에 적힌 제목과 내용을 입력하고, 표는 표 기능으로 넣은 뒤 해당 형식으로 저장합니다. 글자를 이미지로 붙이지 않아야 원본과 결과를 비교하기 쉽습니다. 실제 업무 문서로 시험할 때에는 개인정보와 영업 비밀을 지운 사본을 씁니다.
