Deep Docurator 운영 설정 (관리자)

운영 설정은 Deep Docurator의 모든 서비스에 함께 적용되는 서버 값을 바꾸는 관리자 화면입니다. 동시 처리 수, 모델 연결, 파싱 대기 시간, 청크 크기 기본값, 데이터 보존기간 같은 값이 여기 있습니다. 일반 사용자는 이 화면을 쓰지 않지만, 처리 속도나 모델 연결 문제를 운영 담당자에게 요청할 때 어떤 값이 어디 있는지 알아 두면 대화가 빨라집니다.

이 페이지에서 할 수 있는 일

  • 운영 설정 화면에 들어가는 방법과 권한 조건을 압니다.
  • 탭 8개와 탭 안의 설정 묶음이 무엇을 다루는지 압니다.
  • 값을 바꾸고 저장한 뒤 서비스별 적용 상태를 확인합니다.

들어가는 방법과 권한​

  1. 사이드바 아래 설정을 누릅니다.
  2. 프리셋 화면 위쪽의 **운영 설정 (관리자)**를 누릅니다.

관리자 계정이 아니면 "관리자만 운영 설정을 조회하고 수정할 수 있습니다."와 다시 불러오기만 보입니다. 로그인이 풀린 상태면 "로그인이 필요합니다."가 표시됩니다. API 키와 비밀번호는 이 화면에서 바꾸지 않고 서버 환경변수로 관리합니다.

화면 구성​

운영 설정 화면의 실행 탭

번호메뉴화면에 보이는 내용
1탭 8개실행, LLM, 파싱, 청킹, 메타데이터, 보존·캐시, 연결·로그, 고급
2설정 검색"설정 이름 또는 환경변수 검색". 아래에 지금 탭의 설정 수(실행 탭은 설정 25개)가 보입니다.
3항목 값 칸작업 동시 실행 수 5. 이름 옆 ⓘ(자세히)로 설명과 허용 범위를 봅니다.
4적용 상태 보기왼쪽의 "서비스 N/N개 적용됨"을 펼쳐 서비스별 적용 여부를 봅니다.

위 화면은 강혁신 팀장(관리자) 계정으로 연 모습입니다. 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
탭 8개실행, LLM, 파싱, 청킹, 메타데이터, 보존·캐시, 연결·로그, 고급 중 하나를 엽니다.바꿀 값의 분야를 고를 때
설정 분류탭 안의 묶음(예: 작업 동시 처리, 작업 대기열) 하나만 보거나 전체 설정을 봅니다.묶음 하나에 집중할 때
설정 검색설정 이름이나 환경변수 이름으로 모든 탭에서 찾습니다. 결과 수가 "설정 N개"로 보입니다.이름 일부만 알 때
변경한 항목만저장값으로 바꾼 항목만 남깁니다.기본값과 다른 값을 점검할 때
항목 값 칸숫자, 사용/사용 안 함, 선택 값을 바꿉니다. 옆에 단위(초, MB, 일 등)와 허용 범위가 보입니다.값을 바꿀 때
자세히항목 설명, 적용 시점(신규 진입부터, 새 실행부터, 새 데이터부터), 지금 값의 출처(저장값, 환경변수 / 기본값)를 보여 줍니다.바꾸면 언제부터 적용되는지 볼 때
환경변수로 복원저장값을 지우고 서버 환경변수 값으로 되돌립니다. 저장해야 반영됩니다.시험 삼아 바꾼 값을 되돌릴 때
묶음 이름 저장, 취소묶음 단위로 바꾼 값을 저장하거나 버립니다. 저장하지 않은 변경이 있으면 "변경 N개"가 보입니다.값을 확정할 때
적용 상태 보기, 적용 상태 새로고침서비스마다 새 값을 적용했는지(적용됨, 적용 대기, 응답 지연)와 "서비스 N/N개 적용됨"을 보여 줍니다. 최종 수정자와 최종 수정 시각도 보입니다.저장 뒤 실제로 반영됐는지 확인할 때

저장하면 서버를 다시 시작하지 않아도 적용됩니다. 이미 진행 중인 작업은 기존 값을 그대로 쓰고, 보존기간 변경은 새 데이터부터 적용됩니다. 저장은 됐지만 서비스 적용이 늦어지면 "저장은 완료됐으나 서비스 적용이 지연되고 있습니다."가 보입니다.

이 매뉴얼의 연습 환경에서 김그루 사원(일반 사용자) 계정으로 열면 권한 안내만 보였고, 관리자 계정으로 열었을 때 위 화면이 나왔습니다. 서버에서 운영 설정 기능이 꺼져 있으면 관리자 계정이어도 "운영 설정을 불러오지 못했습니다. 잠시 후 다시 시도하세요."가 보이므로, 이때는 서버 설정 담당자에게 기능 사용 여부를 확인합니다. 값은 운영 환경마다 다르므로, 바꾸기 전에 자세히의 허용 범위와 적용 시점을 먼저 확인하세요.
