Deep Docurator 실습 3: 표와 필드 추출 흐름

이 실습은 10월 영수증·견적 모음 표를 행 하나씩 나누고, 행마다 일자·구분·거래처·품목·금액 다섯 필드를 뽑은 뒤, 메타데이터 평가 노드로 뽑은 값이 맞는지 점검합니다. 마지막으로 결과를 표 형태로 확인하고 엑셀로 옮기는 방법까지 다룹니다. 영수증·견적서 표 정리 사례가 업무 결과물에 초점을 둔다면, 이 실습은 필드 정의와 검증 노드를 직접 구성하는 데 초점을 둡니다.

이 페이지에서 할 수 있는 일

  • 표용 청킹 전략으로 행 하나를 청크 하나로 만듭니다.
  • 메타데이터 노드에 필드 다섯 개를 타입과 허용 값까지 정의합니다.
  • 메타데이터 평가 노드로 필드별 정확도와 채움률을 확인합니다.
  • 출력 스레드 탭의 표로 결과를 읽고 엑셀로 옮깁니다.

목표​

항목내용
만들 흐름입력 → 파싱 → 청킹(라벨 행 (권장)) → 메타데이터 → 메타데이터 평가
결과물20행 × 5필드 표, 필드별 정확도와 채움률
걸리는 시간구성 10분, 실행 20초 안팎, 확인 10분
난이도★★☆☆☆

준비물​

파일내용형식
영수증_견적_모음.csv일자, 구분(영수증·견적서), 거래처(가상), 품목, 금액 다섯 열과 10월 거래 20행csv

엑셀 원본(xlsx)도 같은 방법으로 처리합니다. xls는 파싱 단계에서 처리되지 않으므로 xlsx로 다시 저장합니다. 영수증 사진(png, jpg, jpeg, tiff, tif, bmp, webp)은 표 대신 사례의 2단계처럼 파싱 결과에서 읽습니다.

1단계. 노드 다섯 개 놓고 잇기​

  1. 빈 캔버스로 새 플로우를 만듭니다. 이름 예: 10월 영수증·견적 품목 표 만들기.
  2. 노드 추가에서 입력, 파싱, 청킹, 메타데이터, 메타데이터 평가를 차례로 누르고 왼쪽에서 오른쪽으로 한 줄로 놓습니다.
  3. 앞 노드 오른쪽 연결점에서 다음 노드 왼쪽 연결점으로 네 번 끌어 잇습니다. 상태 표시줄에 노드: 5, 연결: 4가 보입니다.
  4. 입력 노드에 영수증_견적_모음.csv를 넣습니다.

2단계. 노드별 설정값 넣기​

노드설정값
청킹전략라벨 행 (권장)
청킹최대 데이터 행 수1(행 하나가 청크 하나)
청킹빈 셀 이름 표시, 표 설명 메타데이터 생성사용, 꺼짐(처음 값)
메타데이터배치 모드 / 배치당 최대 항목 수수동 / 30(처음 값)
메타데이터필드아래 표 다섯 개(처음 필드 title, summary, keywords, category는 제거)
메타데이터 평가원문 위치 표본 수20(처음 값)
필드 이름타입설명허용 값
일자문자열행의 일자를 YYYY-MM-DD 형식 그대로비움
구분문자열행의 구분 열 값영수증=실제 결제한 내역, 견적서=결제 전 받은 견적
거래처문자열행의 거래처(가상) 값을 원문 그대로비움
품목문자열행의 품목 값을 원문 그대로비움
금액정수행의 금액 숫자만, 원 단위비움(정수 필드에는 허용 값을 넣지 않습니다)

메타데이터 노드의 추출 필드 정의

번호메뉴하는 일
1필드 이름 입력란결과 표의 열 이름이 됩니다. 예: 구분
2타입문자열, 숫자, 정수, 불리언, 배열 중에서 고릅니다. 금액은 정수로 고릅니다.
3허용 값고를 수 있는 값 목록입니다. 2개처럼 개수가 보이고, 누르면 값과 설명을 적는 칸이 열립니다. 비어 있으면 자유값입니다.
4필드 추가필드 줄을 하나 더합니다.

메타데이터 노드를 누르고 설정 탭의 고급 설정을 펼치면 추출 필드가 보입니다. 각 필드 줄의 위 칸이 필드 이름과 타입, 아래 칸이 설명과 허용 값입니다.

3단계. 실행하고 정확도 보기​

  1. ▶(파이프라인 실행)을 누릅니다. 예시는 20초 안팎에 끝났습니다.
  2. 청킹 노드에 20 청크가 보이는지 확인합니다. 경고 (20)은 csv에 원본 위치 정보가 없다는 안내이며 결과에는 영향이 없습니다.
  3. 메타데이터 노드에 20/20 보강, 메타데이터 평가 노드에 정확도 100%, 채움률 100%가 보이는지 봅니다. 메타데이터 평가 노드의 옵션 & 미리보기 탭에는 필드마다 정확도·채움률(예: 금액 100% · 100%)이 나옵니다.

4단계. 결과를 표로 읽고 옮기기​

메타데이터 노드를 누르고 출력 스레드 탭을 열면, 다음 노드로 넘어가는 값이 이름별 탭으로 나뉜 표로 보입니다.

출력 스레드의 필드별 결과 표

번호항목화면에 보이는 내용확인할 것
1출력 스레드 탭content, doc.extension, metadata 같은 이름 탭메타데이터 노드를 고른 상태인지
2metadata 탭20 / 20, 열 metadata.거래처, metadata.구분, metadata.금액, metadata.일자, metadata.품목행 수가 원본 20행과 같은지
3첫 행 금액880000원본 첫 행(2026-10-01, 마바사케이터링, 노트북 거치대)의 금액과 같은지

예시 결과의 앞 다섯 행은 다음과 같습니다.

일자구분거래처품목금액
2026-10-01영수증마바사케이터링노트북 거치대880000
2026-10-02영수증가나다문구노트북 거치대280000
2026-10-03견적서가나다문구외부 교육430000
2026-10-04견적서아자차IT프린터 토너170000
2026-10-05견적서아자차IT노트북 거치대130000

Deep Docurator에는 결과를 엑셀 파일로 내려받는 버튼이 없습니다. 표가 필요하면 metadata 탭의 표를 마우스로 끌어 선택해 복사한 뒤 엑셀에 붙여 넣고, 열 이름이 metadata.금액처럼 붙은 열만 남깁니다. 결과를 지식 검색에 쓰려면 실습 6처럼 Deep Connector로 보내면 필드 값이 검색 필터가 됩니다.

흔한 실수와 해결​

증상원인해결
청크가 1개만 나오고 행이 한데 묶입니다.최대 데이터 행 수가 처음 값 50입니다.1로 바꿉니다.
금액이 "880,000원"처럼 글자로 나옵니다.타입이 문자열입니다.금액 필드 타입을 정수로 바꾸고 설명에 "숫자만"을 적습니다.
실행하자마자 메타데이터 노드가 실패합니다.정수·불리언 필드에 허용 값을 넣었습니다. 화면에 "이 타입엔 안 씀"이 보입니다.그 표시를 눌러 허용 값을 비웁니다.
구분 값이 "결제"처럼 목록 밖 값으로 나옵니다.허용 값이 없어 자유값입니다.허용 값에 영수증, 견적서를 넣습니다. 목록 밖 값은 비게 됩니다.
요약·키워드 열이 영어로 나옵니다.처음 필드 summary, keywords를 그대로 두었습니다.쓰지 않는 처음 필드는 제거합니다.

응용 과제​

  1. 구분 필드처럼 거래처에도 허용 값(가나다문구, 아자차IT, 마바사케이터링)을 넣고, 메타데이터 평가의 정확도가 그대로인지 보세요.
  2. 견적서-사무환경개선.xlsx처럼 표 위에 제목 줄이 있는 서식을 넣어 col1, col2 열 이름이 생기는지 확인하고, 사례의 해결법을 적용해 보세요.
  3. 금액이 50만 원을 넘는 행만 남기려면 메타데이터 다음에 커스텀 노드(역할: 청크 선별)를 붙여 보세요. 만드는 법은 노드별 설정 항목의 커스텀에 있습니다.
