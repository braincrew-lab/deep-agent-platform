Deep Docurator 프리셋과 템플릿 플로우

프리셋은 자주 쓰는 노드 구성을 이름 붙여 저장해 둔 것입니다. 한 번 검토를 마친 구성을 프리셋으로 남겨 두면, 다음 문서에서는 노드를 다시 놓지 않고 같은 기준으로 바로 시작할 수 있습니다. 이 페이지는 내장 프리셋 5가지, 내 프리셋을 저장하고 쓰는 법, YAML 파일로 주고받는 법, 템플릿 플로우를 설명합니다.

이 페이지에서 할 수 있는 일

  • 내장 프리셋 5가지의 노드 구성과 쓰임새를 압니다.
  • 편집기에서 지금 구성을 내 프리셋으로 저장합니다.
  • 새 플로우를 만들 때나 편집 중에 프리셋을 불러옵니다.
  • 설정 화면에서 프리셋을 YAML 파일로 내보내고 가져옵니다.

내장 프리셋​

프리셋노드 구성이런 때
Select 파이프라인 (기본)입력 → 파싱 → 청킹 4개(재귀, 의미 기반, 마크다운, LLM) → 청킹마다 평가 → 전략 선택 → 메타데이터어떤 전략이 맞을지 모를 때 여러 전략을 한 번에 비교
기본 파이프라인 (단일)입력 → 파싱 → 청킹 → 메타데이터조각마다 요약·키워드 같은 항목을 붙일 때
파싱만입력 → 파싱문서가 제대로 읽히는지만 볼 때
파싱 & 청킹입력 → 파싱 → 청킹처음 연습, 검색용 조각 만들기
PII + 필터 정제입력 → 파싱 → 청킹 → PII → 필터개인정보를 가리고 필요 없는 조각을 거를 때

Select 파이프라인 (기본)의 설명 문구에는 평가 노드가 적혀 있지 않지만, 실제로는 청킹 노드마다 평가 노드가 하나씩 붙어 있습니다. 모델을 여러 번 부르므로 처리 시간이 다른 프리셋보다 깁니다.

프리셋을 불러오는 두 곳​

위치방법미리보기
새 플로우 만들기시작점에서 프리셋을 누르고 프리셋 선택 상자에서 고릅니다. 내장 프리셋은 "내장:", 내가 저장한 것은 "내 프리셋:"이 앞에 붙습니다.프리셋 미리보기에 노드 순서와 노드 수가 보입니다.
편집기의 노드 추가 패널패널 아래 프리셋 영역의 프리셋 선택 상자에서 고르고 캔버스에 적용을 누릅니다. 내가 저장한 것은 커스텀 아래에 있습니다.내장 프리셋은 프리셋 미리보기로 구성을 보여 줍니다. 내 프리셋은 미리보기가 없습니다.

편집 중인 캔버스에 프리셋을 적용하면 "현재 캔버스의 내용이 대체됩니다."라는 확인이 나옵니다. 지금 캔버스의 노드와 결과를 남기고 싶다면 새 플로우를 만들어 그곳에 적용하세요.

프리셋은 노드와 옵션만 담습니다. 입력 노드의 파일은 따라오지 않으므로, 프리셋으로 만든 플로우에서는 파일을 새로 넣고 실행합니다.

내 프리셋으로 저장하기​

  1. 결과 검토를 마친 플로우를 엽니다.
  2. 편집기 위쪽 프리셋으로 저장을 누릅니다.
  3. 대화상자에 "현재 파이프라인을 이름과 함께 저장합니다."라는 안내가 보이면 이름을 입력합니다. 이름이 비어 있으면 저장이 눌리지 않고, 빈 칸에서 Enter를 누르면 "이름을 입력해주세요."가 표시됩니다.
  4. 저장을 누릅니다.
  5. 노드 추가 패널의 프리셋 선택 상자 커스텀 아래, 새 플로우 만들기의 "내 프리셋:", 설정 화면의 프리셋 카드에 저장한 이름이 보이는지 확인합니다.

프리셋으로 저장 대화상자

번호메뉴기능이런 때 사용하세요
1이름 입력란프리셋 이름을 입력합니다. 비어 있을 때는 "파이프라인 이름"이 흐리게 보입니다.문서 종류와 기준을 이름에 담을 때
2저장지금 플로우의 노드 구성을 프리셋으로 저장합니다.결과 검토를 마친 구성을 남길 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
취소저장하지 않고 닫습니다.아직 검토가 끝나지 않았을 때

이름에는 문서 종류와 기준을 함께 담으면 나중에 고르기 쉽습니다. 예: 계약서 조항 추출 v1, 견적서 라벨 행 정리.

설정 화면에서 관리하기​

사이드바 아래 설정을 누르면 프리셋 화면이 열립니다. 화면 제목 아래에 "컴포넌트와 파이프라인 프리셋을 관리하고 YAML로 가져오거나 내보냅니다."가 보입니다. 아래 화면은 시작하기의 보고서 플로우를 "보고서 기본 청킹 v1"로 저장한 뒤의 모습입니다.

설정 화면의 프리셋 목록

번호메뉴하는 일이런 때
1분류 버튼(전체, 파싱, 청킹, 메타데이터, 파이프라인)프리셋을 종류별로 좁혀 봅니다.파이프라인 프리셋만 보고 싶을 때
2새 프리셋파싱, 청킹, 메타데이터 중 한 노드의 옵션 묶음을 프리셋으로 만듭니다.청킹 옵션만 따로 저장해 둘 때
3YAML 내보내기지금 분류에 보이는 프리셋을 하나씩 YAML 파일로 내려받습니다.다른 담당자에게 구성을 전달할 때
4YAML 가져오기YAML 파일(yaml, yml)을 골라 프리셋으로 등록합니다.받은 구성 파일을 쓸 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴하는 일이런 때
운영 설정 (관리자)실행, LLM, 파싱, 청킹 등 운영 값을 바꾸는 관리자 화면으로 갑니다. 탭별 내용은 운영 설정 (관리자)에 있습니다. 관리자가 아니면 들어가도 "관리자만 운영 설정을 조회하고 수정할 수 있습니다."가 표시됩니다.관리자가 서버 기본값을 바꿀 때
프리셋 카드프리셋 이름, 종류(pipeline), 노드 순서(input → parse → chunk)가 보입니다. 파싱·청킹·메타데이터 프리셋 카드에는 편집이 함께 보입니다.저장한 구성이 맞는지 확인할 때
삭제프리셋을 지웁니다. "이 프리셋을 삭제하시겠습니까?"를 확인합니다.쓰지 않는 프리셋을 정리할 때

편집은 파싱·청킹·메타데이터 프리셋의 이름, 설명, 옵션을 고칩니다. 프리셋으로 저장으로 만든 파이프라인 프리셋은 편집할 수 없으므로, 고칠 때에는 플로우에서 다시 저장합니다.

YAML 파일에는 API 키가 들어 있지 않습니다. 가져온 뒤 모델 연결이 필요한 노드는 운영 담당자가 설정한 값으로 실행됩니다. 가져오기에 성공하면 API 키를 별도로 설정하라는 안내가 나오는데, 이 화면에는 키를 넣는 곳이 없으므로 모델 연결에 문제가 있을 때만 운영 담당자에게 문의합니다. 가져오기에 실패하면 "가져오기 실패:" 뒤에 이유가 표시됩니다.

템플릿 플로우​

템플릿 플로우는 모두가 복사해 쓸 수 있도록 공유된 플로우입니다. 새 플로우 만들기의 시작점에서 템플릿 플로우를 고르면 공유된 템플릿 수가 보이고, 고른 템플릿의 노드와 옵션을 그대로 복사해 새 플로우를 만듭니다. 원래 템플릿은 바뀌지 않습니다.

플로우 목록의 범위 선택에서 템플릿을 고르면 템플릿만 모아 볼 수 있고, 템플릿에는 템플릿 배지가 붙습니다. 화면에서 일반 플로우를 템플릿으로 바꾸는 메뉴는 없습니다. 부서 표준 구성을 템플릿으로 공유하려면 운영 담당자에게 요청하고, 그 전까지는 프리셋을 YAML로 내보내 전달하세요.

프리셋과 템플릿 중 무엇을 쓸까​

상황추천
내가 같은 기준을 계속 쓸 때내 프리셋
다른 담당자에게 구성을 보낼 때프리셋을 YAML로 내보내기
부서 전체가 같은 출발점을 써야 할 때운영 담당자가 등록한 템플릿 플로우
노드 하나의 옵션만 재사용할 때설정 화면의 새 프리셋(파싱, 청킹, 메타데이터)

이럴 때 쓰세요​

브레인크루 AI혁신팀 김그루 사원이 실제로 이 화면을 여는 순간들입니다.

이런 상황에서이렇게 하세요
팀에서 검토를 마친 회의록 처리 기준을 영업본부에도 쓰게 할 때프리셋으로 저장한 뒤 설정 화면에서 YAML 내보내기로 파일을 보냅니다. 받는 쪽은 YAML 가져오기로 등록합니다(실습 5).
개정된 출장비 규정을 작년과 같은 기준으로 처리할 때새 플로우 만들기에서 프리셋을 고르고 "내 프리셋:"을 선택합니다. 파일만 새로 넣고 실행합니다.
청킹 옵션만 여러 플로우에서 똑같이 쓰고 싶을 때설정 화면의 새 프리셋에서 청킹 프리셋을 만듭니다.
신규 입사자에게 연습용 출발점을 주고 싶을 때운영 담당자에게 템플릿 플로우 등록을 요청합니다. 그 전까지는 프리셋 YAML 파일을 전달합니다.
