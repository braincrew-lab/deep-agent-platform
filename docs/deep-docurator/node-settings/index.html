Deep Docurator 노드별 설정 항목

이 페이지는 노드 추가 패널의 노드 14가지를 하나씩 열어, 작업 사이드바의 설정 탭에 보이는 항목을 빠짐없이 표로 정리한 참조 페이지입니다. 노드가 하는 일과 조합은 노드 안내, 청킹 전략별 차이는 청킹 전략과 옵션에 있습니다. 화면을 직접 따라 하며 익히려면 흐름 만들기 실습부터 보세요.

이 페이지에서 할 수 있는 일

  • 작업 사이드바의 네 탭과 모든 노드에 공통인 입력 데이터 영역을 읽습니다.
  • 노드마다 설정 항목의 이름, 처음 값, 고를 수 있는 값을 확인합니다.
  • 값을 바꿀 때 실행이 실패하거나 결과가 달라지는 조건을 미리 압니다.

작업 사이드바 공통 구성​

캔버스에서 노드를 누르면 오른쪽에 작업 사이드바가 열립니다. 위쪽에는 노드 이름과 노드 식별값(화면에서는 흐림 처리)이 보이고, 아래쪽에는 노드 삭제가 있습니다.

작업 사이드바의 탭과 영역은 다음과 같습니다. 실제 화면은 실습 2의 평가 노드 설정 탭, 실습 3의 메타데이터 노드 설정 탭과 출력 스레드 탭 그림에서 볼 수 있습니다.

메뉴기능이런 때 사용하세요
설정 탭입력 데이터 연결과 처리 옵션을 바꿉니다.노드의 동작을 바꿀 때
입력 데이터앞 노드의 어떤 값을 이 노드가 읽을지 정합니다. 값마다 형식(예: str · 항목)과 연결된 앞 노드가 보입니다.앞 노드가 여러 개라 읽을 값을 골라야 할 때
처리 옵션노드의 주요 옵션입니다. 노드마다 항목이 다릅니다.전략이나 방식을 고를 때

옵션 & 미리보기 탭입력 노드는 파일 영역, 그 밖의 노드는 실행 결과를 보여 줍니다. 커스텀 노드는 코드를 만드는 곳입니다.결과를 읽을 때

변경 취소, 입력 설정 적용입력 데이터에서 바꾼 연결을 버리거나 적용합니다. 모든 값을 연결하지 않음으로 바꾼 앞 노드의 연결선은 지워집니다.입력 연결을 바꾼 뒤 확정할 때
노드 삭제선택한 노드를 지웁니다.잘못 놓은 노드를 없앨 때

입력 데이터에서 별표(*)가 붙은 값은 필수입니다. 필수 값이 비어 있으면 "필수 입력 또는 필드의 타입·범위를 확인해 주세요."가 표시되고 실행할 수 없습니다. 처음 연결한 노드에는 "기존 전체 입력 연결입니다."라는 안내가 보이는데, 앞 노드의 값을 모두 넘겨받는다는 뜻이며 대부분 그대로 두면 됩니다. 노드를 되돌아 잇는 연결은 "순환 연결은 만들 수 없습니다."로 막힙니다.

입력​

항목위치내용
파일 영역옵션 & 미리보기"파일을 드롭하거나 클릭"에 파일 한 개를 넣습니다. 최대 500MB이며, 넣을 수 있는 확장자는 pdf, doc, docx, hwp, hwpx, pptx, xlsx, xls, txt, csv, md, html, htm, png, jpg, jpeg, tiff, tif, bmp, webp입니다.
파일 제거옵션 & 미리보기넣은 파일을 뺍니다.
입력 파일옵션 & 미리보기형식과 용량(예: DOCX / 36 KB)과 미리보기가 보입니다.
출력 스레드 (코드가 쓰는 것)옵션 & 미리보기파일 말고도 이름 붙인 값을 선언합니다. 처음 값은 미선언이며, 선언하면 이름 옆 입력값 (JSON) 칸에 값을 적습니다. 커스텀 노드에 기준값을 넘길 때만 씁니다.

입력 노드의 설정 탭에는 바꿀 항목이 없습니다. 문서 유형(문서, 슬라이드, 엑셀)은 파일 확장자로 자동으로 정해집니다.

파싱​

항목처음 값고를 수 있는 값과 뜻
프로바이더Brain ParserBrain Parser 하나입니다. 제목, 본문, 표, 이미지 위치를 블록으로 읽습니다.

입력 데이터에는 앞 입력 노드의 원본 파일이 연결됩니다. 결과는 옵션 & 미리보기의 Parse 결과와 원본 문서에서 봅니다.

목차​

항목처음 값내용
LLM 제목·구조 검토사용제목 후보를 모델로 다듬습니다. 요청이 하나라도 실패하면 노드가 실패합니다. 모델을 쓸 수 없는 환경에서는 끕니다.
목차 구조 예시비어 있음검토를 켰을 때만 보입니다. 한 줄에 하나씩 "L1 계약서 제목", "L2 제N조 조항 제목"처럼 깊이와 제목 모양을 적습니다. 숫자는 N, 자유 문구는 꺾쇠로 감쌉니다.

입력 데이터는 파싱 노드의 본문, 문서 제목, 항목 종류, 페이지입니다. 검토를 끄면 모델을 부르지 않고 목차 페이지나 본문 제목만으로 목차를 만듭니다.

시맨틱 태그​

묶음항목처음 값내용
어휘대분류 목록 (domain)비어 있음문서 묶음 전체를 나누는 큰 분류입니다. 조각마다 정확히 1개가 붙습니다. 값과 설명(모델이 고르는 기준)을 한 줄씩 필드 추가로 넣습니다. 보통 5~15개입니다.
어휘중분류 목록 (aspect)비어 있음대분류와 상관없이 반복되는 조항 성격입니다(예: 신청절차, 자격조건, 제한사항). 해당하는 것은 모두 붙습니다.
어휘소분류 목록 (topic) — 비우면 자동비어 있음검색어 수준의 구체 표현입니다. 비우면 조각 본문에 있는 명사구를 그대로 뽑습니다(권장).
구조섹션 앵커자동목차 위치를 어디서 읽을지 고릅니다. 자동, PDF 목차, Layout Label, Markdown 제목, 앞의 목차 노드, 끔(문서 전체를 한 섹션으로) 중 하나입니다.
구조긴 문단 서브분할꺼짐긴 문단을 더 잘게 나눠 태그를 붙입니다.
구조문서 구조 문맥선택선택이면 목차가 있을 때만 상위 경로를 함께 씁니다. 필수면 앞에 목차 노드가 있어야 합니다.
LLM 비용구어체 동의어(kw) 슬롯 추가꺼짐구어체 동의어 태그를 더 붙입니다. 필요할 때만 켭니다.
LLM 비용배치당 element 수30한 번에 모델에 보내는 조각 수입니다(1~200).
LLM 비용LLM 동시 호출 수5동시에 보내는 요청 수입니다(1~256).
LLM 비용최대 element 수 (0 = 제한 없음)0이 수를 넘는 문서는 모델 태깅을 건너뜁니다.

구조와 LLM 비용 묶음은 고급 설정을 펼치면 보입니다. 입력 데이터의 본문, 항목 종류, 페이지는 필수입니다.

전략 선택​

항목처음 값내용

문서 구조선택필수로 바꾸면 앞에 목차 정보가 있어야 합니다.
필드title, summary, keywords, category고급 설정의 추출 필드입니다. 줄마다 필드 이름, 타입, 설명, 허용 값을 정하고 필드 추가, 제거로 늘리거나 줄입니다.

필드의 타입은 문자열, 숫자, 정수, 불리언, 배열(문자열), 배열(숫자), 배열(정수), 배열(불리언) 중 하나입니다. 허용 값은 "값=설명" 형식으로 적고, 비우면 자유값이 되어 검색 필터에는 쓰이지 않습니다. 숫자·불리언 필드에 허용 값을 넣으면 "이 타입엔 안 씀"이 표시되고 그대로 실행하면 실패합니다. 필드가 하나도 없으면 "추출 필드를 하나 이상 추가하세요."가 보입니다.

라우터​

항목처음 값내용
분류 방식규칙규칙은 조건으로, LLM은 경로마다 적은 기준 문장으로 문서를 분류합니다.
분류에 사용할 입력비어 있음판정에 쓸 앞 노드의 값입니다. 입력 추가로 늘립니다. 선택한 경로에는 판정에 쓰지 않은 값까지 모두 그대로 넘어갑니다.
추가 분류 지침, 모델비어 있음, 서버 기본 모델LLM 방식에서 모든 경로에 공통으로 줄 지침과 쓸 모델입니다.
판정 범위, 최대 문자 수전체, 20000앞부분만으로 바꾸면 정한 글자 수까지만 판정에 씁니다. 전체 모드에서 한도를 넘으면 오류입니다.
경로경로 1, 기타경로 추가로 늘리고, 화살표로 우선순위를 바꾸고, 경로 삭제로 지웁니다. 위에서부터 검사해 처음 맞는 경로 하나를 고릅니다.
경로 이름, 이 경로로 분류할 기준경로 1LLM 방식에서는 기준 문장을 적습니다.
조건 결합, 조건 추가모든 조건 만족 (AND)규칙 방식에서 입력 필드, 비교 방식(같음, 다름, 포함, 포함하지 않음, 초과, 이상, 미만, 이하, 값이 있음, 값이 없음), 비교 값을 정합니다. 문서 항목이 여러 개면 문서 항목 판정에서 하나 이상 일치, 모든 항목 일치를 고릅니다.
기본 경로기타어느 경로에도 맞지 않을 때 고르는 경로입니다.
후속 노드연결할 노드 선택경로마다 다음 노드를 하나씩 연결합니다. 비어 있으면 "실행 전에 이 경로의 후속 노드를 연결하세요."가 보입니다.

라우터에는 앞 노드 하나만 연결할 수 있습니다. 경로마다 노드 오른쪽에 출력 연결점이 따로 생기므로, 경로의 연결점에서 다음 노드로 선을 끕니다.

텍스트 치환​

항목처음 값내용
찾기 방식일반 문자열일반 문자열 또는 정규식입니다.
찾을 문자열 또는 패턴비어 있음필수입니다. 각 청크 안에서만 찾고, 청크 경계를 넘는 문자열은 찾지 않습니다.
바꿀 문자열비어 있음비우면 찾은 문자열만 지웁니다. 정규식에서는 그룹 참조와 줄바꿈을 쓸 수 있습니다.
대소문자 구분 안 함꺼짐영문 대소문자를 같게 봅니다.
줄마다 시작·끝 일치, 점(.)에 줄바꿈 포함꺼짐, 꺼짐정규식 방식에서만 보입니다.

청크 수, 순서, 페이지는 그대로이고 본문 글자만 바뀝니다. 결과에는 "전체 N개 · 변경 N개 · 치환 N회 · 빈 청크 N개"가 보입니다. 규칙이 여러 개면 노드를 이어 붙여 순서대로 적용합니다.

커스텀​

커스텀 노드의 옵션은 옵션 & 미리보기 탭에서 정합니다.

항목처음 값내용
역할본문 수정 (rewrite)본문 수정, 청크 생성, 시맨틱 태깅, 메타데이터 추출, 청크 선별 중 하나입니다. 앞 노드 종류에 따라 고를 수 있는 역할이 줄어듭니다.
입력 스레드 (코드가 읽는 것)미선언코드가 읽을 값(본문, 항목 종류, 페이지, 상위 제목 경로, 태그, 추출 메타데이터, 문서 제목 등)을 고릅니다.
출력 스레드 (코드가 쓰는 것)미선언코드가 쓸 값을 고릅니다. 선언하지 않으면 실행할 수 없습니다.
자연어로 설명, 변환 의도 (자연어)비어 있음하고 싶은 가공을 문장으로 적고 실행하면 코드가 만들어져 코드 탭에 들어갑니다.
코드비어 있음만들어진 코드나 직접 쓴 코드입니다. 지시문보다 우선합니다.
빠른 시작—표만 추출, 짧은 청크 제거, 중복 제거, 공백 정리 예시를 넣습니다.
코드·선언 저장—코드와 입력·출력 선언을 저장합니다.
선언 필드비어 있음메타데이터 추출 역할에서만 보입니다. 메타데이터 노드의 필드와 같은 형식입니다.
출력 개수 변경 허용사용본문 수정 역할에서 청크 수가 바뀌어도 되는지 정합니다.

코드는 파일과 네트워크에 접근하지 않는 데이터 변환만 할 수 있습니다.

항목처음 값내용

의미 판정 최대 호출 수비어 있음의미 판정에 모델을 부를 최대 횟수입니다.
의미 판정 입력·출력 추정 토큰비어 있음의미 판정에 쓸 토큰 예산입니다.
이 글자 수보다 짧으면 경고50이보다 짧은 청크를 경고로 표시합니다.

이 환경에서는 의미 판정 최대 호출 수와 추정 토큰을 비워 두면 평가 노드가 "Input should be a valid integer"로 실패했습니다. 두 칸에 숫자(예: 20과 60000)를 넣고 실행하세요. 전략 선택 점수는 의미 분할 40%, 메타데이터 추출 가능성 40%, 정보 보존 20%로 계산되며, 표본 평가이므로 전체 품질을 보증하지 않습니다.
