Deep Docurator 사례: 영수증·견적서 표 정리

김그루 사원은 11월 법인카드 사용 내역과 사무 환경 개선 견적서를 정리해야 합니다. 에이전트가 "가상식당에서 쓴 회의비가 얼마였지?"처럼 건별로 찾을 수 있도록, 표를 행 하나씩 풀어 청크로 만들고 사용처와 금액을 메타데이터로 붙입니다. 영수증 사진에서 금액을 읽는 방법도 함께 봅니다.

이 페이지에서 할 수 있는 일

  • 표 파일(csv, xlsx)을 표용 전략 라벨 행 (권장)으로 행 단위 청크로 나눕니다.
  • 메타데이터로 사용처·금액을 건별로 뽑습니다.
  • 영수증 사진(png, jpg)을 파싱해 금액과 품목이 읽혔는지 확인합니다.
  • 표 머리글이 여러 줄인 엑셀 서식에서 생기는 문제와 해결법을 압니다.

목표​

항목내용
하고 싶은 일사용 내역과 견적 품목을 건별로 찾을 수 있게 정리
결과물행 하나당 청크 하나, 청크마다 사용처·금액 값
노드 조합입력 → 파싱 → 청킹(라벨 행 (권장)) → 메타데이터. 영수증 사진은 입력 → 파싱
걸리는 시간실행 1분 안팎, 검토 10분

준비물​

파일내용형식
영수증내역-2026-11.csv사용일, 사용처, 분류, 금액(원), 사용자, 메모 열과 5건의 사용 내역csv
견적서-사무환경개선.xlsx위쪽에 제목·견적일, 아래에 품목·규격·수량·단가·금액 표와 합계·부가세·총액xlsx
영수증-가상식당-1110.png휴대폰으로 찍은 것과 같은 영수증 이미지. 품목 3개와 합계 112,000원png(같은 내용의 jpg도 가능)

표 파일은 xlsx, csv를 넣습니다. xls는 처리되지 않으므로 xlsx로 다시 저장합니다. 이미지는 png, jpg, jpeg, tiff, tif, bmp, webp를 넣을 수 있습니다.

1단계. 사용 내역을 행 단위로 나누기​

  1. "내장: 기본 파이프라인 (단일)" 프리셋으로 새 플로우를 만듭니다. 이름 예: 11월 법인카드 사용 내역 정리.
  2. 입력 노드에 영수증내역-2026-11.csv를 넣습니다.
  3. 청킹 노드의 설정 탭에서 전략을 라벨 행 (권장)으로 바꿉니다.
  4. 고급 설정을 펼치고 최대 데이터 행 수를 50에서 1로 바꿉니다. 행 하나가 청크 하나가 됩니다.
  5. 메타데이터 노드의 고급 설정에서 기본 필드 title, category를 줄 오른쪽 ✕(제거)로 지우고, summary 설명을 "사용 내역을 한국어 한 문장으로 요약", keywords 설명을 "한국어 키워드"로 바꿉니다. 이어서 필드 추가로 사용처(행의 사용처를 원문 그대로), 금액(행의 금액(원) 숫자만), 분류(사무용품, 회의비, 교통비, 도서구입 중 하나) 필드를 만듭니다. 결과 화면의 목록은 필드를 여섯 개까지만 보여 주므로 필요 없는 필드는 지웁니다.
  6. 파이프라인 실행을 누릅니다.

라벨 행 (권장)은 행마다 "사용일: 20261103 사용처: 가상문구 분류: 사무용품 금액원: 48000"처럼 열 이름과 값을 짝지어 풀어 씁니다. 그래서 청크 하나만 읽어도 어떤 값인지 알 수 있습니다.

건별로 나눈 사용 내역과 메타데이터

번호항목화면에 보이는 내용확인할 것
1청킹 노드라벨 행 (권장), 5 청크, 경고 (5)사용 내역 5건이 5 청크가 됐는지. 경고는 csv에 원본 좌표가 없다는 안내입니다.
2청크 칸다섯 칸 가운데 1번째를 고른 상태칸을 차례로 눌러 건별 값을 봅니다
3사용처가상문구원본 첫 행의 사용처와 같은지
4금액48000원본 첫 행의 금액과 같은지

결과물 예시​

청크사용처금액분류요약(모델이 쓴 문장)
1가상문구48000사무용품포스트잇, 화이트보드 마커 등 사무용품 구매
2가상카페36500회의비AI혁신팀 주간 회의를 위한 음료 구매
3가상택시18200교통비고객 미팅 이동을 위한 택시 이용
4가상도서64000도서구입데이터 분석 도서 2권 구입
5가상식당112000회의비협력사 킥오프 점심 회의 비용

summary 설명을 처음 값(Summary)으로 두었을 때는 요약과 키워드가 영어로 나왔습니다. 한국어 결과가 필요하면 설명에 "한국어"를 적습니다.

합계는 메타데이터에 따로 나오지 않습니다. 합계가 필요하면 원본 표에서 계산하거나, 이 플로우를 Deep Connector에 보낸 뒤 에이전트에게 계산을 맡깁니다.

2단계. 영수증 사진에서 금액 읽기​

  1. "내장: 파싱만" 프리셋으로 새 플로우를 만듭니다. 이름 예: 영수증 사진 금액 읽기.
  2. 입력 노드에 영수증-가상식당-1110.png를 넣고 실행합니다. 예시는 20초 안팎에 끝났습니다.
  3. 파싱 노드의 옵션 & 미리보기 탭에서 Parse 결과를 읽습니다.

영수증 사진의 파싱 결과

번호항목화면에 보이는 내용확인할 것
1입력 노드영수증-가상식당-1110.png, 38 KB사진 파일이 맞는지
2텍스트 블록가상식당, 사업자번호, 2026-11-10 12:48사용처와 날짜가 읽혔는지
3표 블록점심 정식 x6 90,000 / 음료 x6 18,000 / 디저트 x2 4,000. 펼치기로 전체를 봅니다.품목별 금액이 사진과 같은지
4텍스트 블록112,000원합계가 사진과 같은지

사진 속 숫자는 읽는 과정에서 "90, 000"처럼 쉼표 뒤에 빈칸이 생길 수 있습니다. 금액은 늘 사진과 한 번 더 대조합니다. 흐리거나 기울어진 사진은 숫자를 잘못 읽을 수 있으니 바로 찍어 다시 넣습니다.

3단계. 엑셀 견적서에서 주의할 점​

견적서-사무환경개선.xlsx처럼 표 위에 제목과 견적일 줄이 있는 서식을 라벨 행 (권장)으로 나누면, 첫 줄(제목)을 머리글로 읽어 "col1, col2" 같은 이름이 붙습니다.

머리글이 맞지 않은 견적서 청크

번호항목화면에 보이는 내용확인할 것
1청크 본문"(가상) 견적서 — 브레인크루 AI혁신팀 사무 환경 개선: 견적일 | col1: 2026-11-05 | col2: 유효기간 | col3: 30일 | col4:"열 이름이 품목, 규격, 수량 대신 col1, col2로 나왔는지

청크 결과 위의 경고는 엑셀에는 원본 위치 정보가 없다는 안내이며 결과에는 영향이 없습니다.

이럴 때는 엑셀에서 표 위의 제목·견적일 줄을 지우고 첫 줄이 품목, 규격, 수량, 단가(원), 금액(원)이 되도록 다시 저장해 넣습니다. 또는 제목·합계가 섞인 서식에 맞춘 구조 인식 전략으로 바꿔 비교합니다.

검토 기준​

확인 질문검토 방법
행 수와 청크 수가 같나요?사용 내역 5건이면 5 청크인지 봅니다.
열 이름이 맞나요?청크 본문에 col1, col2 대신 실제 열 이름이 보이는지 봅니다.
금액이 같나요?메타데이터 금액과 원본 행의 금액을 대조합니다.
합계·부가세 행이 섞였나요?견적서라면 합계 행이 품목처럼 취급되지 않았는지 봅니다.

응용 팁​

  • 행이 수백 개인 판매 실적표는 최대 데이터 행 수를 10~20으로 두어 청크 수를 줄이고, 원본 헤더 반복을 켜 둔 일반 행 + 헤더 전략과 비교합니다.
  • 분류 필드에 허용 값(사무용품, 회의비, 교통비, 도서구입)을 넣으면 값 표현이 통일되어 검색 필터로 쓸 수 있습니다.
  • 여러 장의 영수증 사진은 입력 노드가 파일 한 개만 받으므로 한 장씩 처리하거나, 사용 내역을 csv로 정리한 뒤 1단계 방식으로 처리합니다.
  • 검토를 마친 구성은 "사용 내역 라벨 행 정리"처럼 이름을 붙여 프리셋으로 저장합니다.
