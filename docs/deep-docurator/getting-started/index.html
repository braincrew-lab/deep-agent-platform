Deep Docurator 시작하기

첫 목표와 준비물​

한 페이지 PDF를 입력 → 파싱 → 청킹으로 처리하고, 만들어진 청크에서 예약과 취소 조건을 읽는 과정입니다. 문서 작성 도구로 제목을 회의실 안내로 정하고 “예약은 이용 전날까지 신청합니다. 취소는 이용 시작 두 시간 전까지 신청합니다.”를 넣어 PDF로 준비하세요. 실제 업무 규정이 아닌 연습 자료입니다.

파싱 서비스를 사용할 수 있는 계정 설정을 준비합니다. 설정 담당자가 따로 있다면 시작 전에 확인하세요. 본문의 청크 크기와 겹침은 연습용 값이며, 모든 문서에 최적인 값이라는 뜻은 아닙니다.

1. 빈 파이프라인에 노드 놓기​

  1. 플로우 목록 상단의 새로 만들기를 누릅니다. 빈 파이프라인 편집기가 열립니다.
  2. 왼쪽 컴포넌트 패널에서 입력, 파싱, 청킹을 하나씩 작업 공간으로 끌어 놓습니다. 패널이 닫혀 있으면 컴포넌트 열기를 사용합니다.
  3. 입력을 왼쪽, 파싱을 가운데, 청킹을 오른쪽에 배치합니다.
  4. 입력 노드 오른쪽 연결점에서 파싱 노드 왼쪽 연결점으로 끌어 연결합니다. 이어서 파싱 오른쪽에서 청킹 왼쪽으로 연결합니다.
  5. 연결선이 두 개이며 입력 → 파싱 → 청킹의 순서가 이어지는지 확인합니다.

이 과정에서 시맨틱 태그나 평가 노드는 추가하지 않아도 됩니다. 먼저 세 노드만으로 원하는 결과를 확인하세요.

2. 파일과 분할 조건 입력하기​

입력 노드를 열어 파일 선택 영역을 클릭하거나 파일을 끌어 놓습니다. 준비한 PDF의 이름과 용량이 표시되는지 확인하세요. 파일이 지정되지 않은 채로 다음 단계에 넘어가지 않습니다.

파싱 노드에서는 프로바이더가 사용할 서비스로 설정되어 있는지 확인합니다. 첫 실습은 페이지 범위의 기본값을 유지합니다. 청킹 노드를 열고 옵션에서 다음 값을 확인하거나 입력합니다.

항목연습 값선택 이유
전략재귀 (마크다운 인식)기본 분할 흐름을 먼저 확인
청크 크기1000짧은 문서로 시작해 결과를 읽기 쉽게 비교
청크 겹침200인접 조각 사이에 일부 내용을 겹쳐 담는 설정 확인
이미지 주석끔글로만 만든 연습 문서에 필요한 범위부터 확인

설정값을 바꾼 뒤 노드와 연결선이 유지되는지 봅니다. 작은 문서가 청크 하나로 나뉘어도 오류는 아닙니다. 특정 개수보다 본문 보존 여부를 확인합니다.

3. 실행하고 단계별 결과 확인하기​

  1. 상단의 파이프라인 실행을 누릅니다. 필요한 서비스 설정이 빠졌다는 안내가 나오면 설정으로 이동에서 표시된 항목을 확인하고 담당자가 제공한 값으로 준비합니다.
  2. 노드의 진행 상태를 확인합니다. 실행 실패나 오류가 나타나면 반복 클릭하지 말고 오류가 발생한 노드와 메시지를 읽습니다.
  3. 실행이 끝나면 파싱 노드를 열어 원본의 예약·취소 문장이 추출되었는지 확인합니다.
  4. 청킹 노드를 열어 청크 결과와 본문을 확인합니다. 청크 결과 미리보기에서는 생성된 청크를 선택해 내용을 읽습니다. PDF 원본 대조가 제공되면 원문도 함께 봅니다.

성공 기준은 청크 결과가 존재하고 “이용 시작 두 시간 전까지”라는 조건을 원본과 대조할 수 있는 것입니다. 모든 노드의 완료 표시만으로 내용의 정확성을 판정하지 마세요.

다음 작업으로 이어가기​

내용은 보이는데 조건이 서로 다른 조각으로 갈라졌다면 반복 업무에서 분할 조건을 비교하세요. 각 메뉴와 옵션의 역할은 주요 기능에 있습니다. 파일이나 결과가 보이지 않으면 문제 해결을 따라 입력부터 점검합니다.
