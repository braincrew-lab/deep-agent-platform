Deep Docurator 시작하기

이 페이지는 보고서 PDF 한 개를 Deep Docurator에 넣고, 파싱 결과와 청크 결과를 읽는 데까지 화면 순서대로 안내합니다. 예시는 브레인크루 AI혁신팀 김그루 사원이 만든 가상 보고서 "보고서-3분기-AI활용현황.pdf"(1쪽)입니다. 따라 하는 데 10분 정도 걸립니다.

이 페이지에서 할 수 있는 일

  • 첫 화면과 왼쪽 사이드바 메뉴를 구별합니다.
  • 내장 프리셋 파싱 & 청킹으로 입력 → 파싱 → 청킹 플로우를 만듭니다.
  • 입력 노드에 PDF를 넣고 파이프라인을 실행합니다.
  • 파싱 결과에서 원문이 빠짐없이 읽혔는지, 청크 결과에서 내용이 끊기지 않았는지 확인합니다.

준비물​

항목내용
계정Deep Docurator에 로그인할 수 있는 계정
연습 파일글자로 작성한 1~3쪽 PDF 한 개. 예시는 요약, 부서별 사용 현황 표, 성과, 문제점, 4분기 계획 다섯 절로 된 보고서입니다.
다른 형식pdf 대신 doc, docx, hwp, hwpx, pptx, xlsx, csv, txt, md, html, htm, png, jpg, jpeg, tiff, tif, bmp, webp도 넣을 수 있습니다. 처음에는 원본 대조가 쉬운 pdf를 권합니다.

실제 고객 정보나 영업 비밀이 들어 있는 문서는 연습에 쓰지 않습니다.

1. 로그인하기​

Deep Docurator 주소로 접속하면 로그인 화면으로 이동합니다. Deep Agent Builder, Deep Connector와 같은 계정(이메일과 비밀번호)으로 로그인합니다.

로그인 화면

번호메뉴기능이런 때 사용하세요
1이메일회사 계정 이메일을 입력합니다. 그림에서는 흐림 처리했습니다.로그인할 때
2비밀번호비밀번호를 입력합니다. 오른쪽 눈 모양 버튼으로 입력한 글자를 보이거나 숨깁니다.로그인할 때
3로그인로그인하고 Deep Docurator로 돌아갑니다.이메일과 비밀번호를 다 적었을 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
비밀번호 찾기비밀번호 재설정 화면으로 갑니다.비밀번호가 기억나지 않을 때
회원가입새 계정을 신청합니다. 회사 설정에 따라 관리자 승인 뒤에 쓸 수 있습니다.계정이 없을 때

로그인한 뒤에는 화면 오른쪽 위에 이름 첫 글자(예: 김)가 보이고, 그 옆 로그아웃 버튼으로 로그아웃합니다. 로그아웃하면 "로그아웃되었습니다" 화면이 나오며, 로그인을 누르면 다시 로그인할 수 있습니다. 이 연습 환경에서는 로그아웃한 뒤 로그인을 누르면 로그인 화면에 남아 있는 로그인 상태로 같은 계정에 바로 다시 들어갔습니다. 다른 계정으로 바꾸려면 브라우저를 모두 닫았다가 다시 열고 로그인합니다. 권한이 없는 화면을 열면 권한 없음 화면이, 서비스 점검 중에는 점검 안내 화면이 나옵니다.

2. 첫 화면 살펴보기​

로그인하면 지식 그래프 화면이 열립니다. 왼쪽 사이드바에서 플로우를 만들고 여는 것이 모든 작업의 출발점입니다.

지식 그래프 첫 화면

번호메뉴기능이런 때 사용하세요
1검색플로우와 작업으로 바로 이동하는 검색 창을 엽니다. 키보드로는 ⌘K입니다.지난주에 만든 플로우를 이름으로 열 때
2플로우플로우 목록을 엽니다. 오른쪽 숫자는 템플릿을 뺀 플로우 개수입니다.모든 플로우를 훑어볼 때
3새 파이프라인(+)새 플로우 만들기 화면을 엽니다. 최근 플로우 줄에 마우스를 올리면 보입니다.새 문서용 처리 흐름을 만들 때
4설정프리셋을 관리하는 설정 화면을 엽니다.저장한 프리셋을 정리하거나 내보낼 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
사이드바 접기왼쪽 사이드바를 접어 작업 공간을 넓힙니다.노드가 많은 플로우를 넓게 볼 때
지식 그래프지금 보고 있는 첫 화면으로 돌아옵니다.다른 화면에서 첫 화면으로 돌아올 때
최근 플로우 접기아래 최근 플로우 목록을 접거나 펼칩니다.사이드바를 짧게 정리할 때
최근 플로우 항목최근에 고친 플로우 이름과 수정 시각입니다. 누르면 편집기가 열립니다.어제 작업하던 플로우를 이어서 열 때
모든 플로우 보기플로우 목록 화면으로 이동합니다.최근 목록에 없는 플로우를 찾을 때
언어 전환(한국어)화면 언어를 영어로 바꿉니다. 다시 누르면 한국어로 돌아옵니다.영문 화면으로 볼 때
저장된 파이프라인내가 저장한 파이프라인 프리셋이 보입니다. 처음에는 "저장된 파이프라인이 없습니다."가 보입니다.저장한 구성을 확인할 때
최근 업데이트제품 버전별 변경 내용이 날짜와 함께 보입니다.어떤 기능이 추가됐는지 볼 때

가운데 그래프는 문서 처리 경험을 쌓아 보여 주는 보기 전용 화면입니다. 이 매뉴얼은 플로우 화면을 중심으로 설명합니다.

3. 새 플로우 만들기​

사이드바 최근 플로우 줄의 + 버튼이나 플로우 목록의 새로 만들기를 누르면 새 플로우 만들기 화면이 열립니다. 처음에는 내장 프리셋 파싱 & 청킹으로 시작하세요. 입력·파싱·청킹 세 노드가 이미 연결된 상태로 편집기가 열립니다.

새 플로우 만들기 화면

번호메뉴기능이런 때 사용하세요
1이름플로우 이름을 입력합니다. 필수이며 최대 120자입니다.문서 종류와 처리 내용을 이름에 담을 때
2프리셋미리 구성된 노드 묶음으로 시작합니다. 내장 프리셋 수와 내 프리셋 수가 보입니다.처음 플로우를 만들거나 저장한 구성을 쓸 때
3프리셋 선택 상자쓸 프리셋을 고릅니다. 내장 프리셋은 "내장:"이 앞에 붙습니다.필요한 단계만 있는 구성을 고를 때
4플로우 만들기입력한 내용으로 플로우를 만들고 편집기를 엽니다.이름과 시작점을 다 정했을 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
설명플로우의 용도를 한 줄로 적습니다. 선택 항목입니다.결과를 어디에 쓸지 메모할 때
빈 캔버스노드 없이 시작합니다.노드를 하나씩 직접 놓고 싶을 때
템플릿 플로우공유된 템플릿 플로우를 복사해 시작합니다.공유 템플릿이 있을 때
프리셋 미리보기고른 프리셋의 노드 순서와 노드 수를 보여 줍니다.만들기 전에 어떤 노드가 들어오는지 확인할 때
취소만들지 않고 이전 화면으로 돌아갑니다.이름을 다시 정하고 싶을 때

따라 해 보기​

  1. 이름에 "3분기 AI 활용 현황 보고서 파싱·청킹"을 입력합니다. 위 그림의 이름은 다른 이름을 적은 예시입니다.
  2. 설명에 "보고서 PDF를 읽어 장별 청크로 나누고 지식 검색에 쓰는 처리 흐름"을 입력합니다.
  3. 시작점에서 프리셋을 누르고, 프리셋 선택 상자에서 "내장: 파싱 & 청킹"을 고릅니다.
  4. 프리셋 미리보기에 입력 → 파싱 → 청킹, 노드 3개가 보이는지 확인합니다.
  5. 플로우 만들기를 누릅니다.

4. 입력 노드에 파일 넣기​

편집기가 열리면 입력 노드를 눌러 오른쪽 작업 사이드바를 엽니다. 여기서 처리할 파일을 지정합니다.

입력 노드 작업 사이드바

번호메뉴기능이런 때 사용하세요
1입력 노드캔버스의 입력 노드입니다. 파일을 넣으면 파일 이름과 용량이 보입니다.어떤 파일을 처리하는지 확인할 때
2옵션 & 미리보기 탭파일 올리기 영역과 올린 파일 미리보기를 봅니다.파일을 넣거나 바꿀 때
3파일 영역파일을 끌어 놓거나 눌러서 고릅니다. 최대 500MB입니다. 올린 파일은 이름과 파일 제거 버튼이 보입니다.처리할 파일을 지정할 때
4입력 파일올린 파일의 형식과 용량(예: PDF / 4 KB)과 미리보기가 보입니다.맞는 파일을 올렸는지 실행 전에 확인할 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
설정 탭노드의 처리 옵션을 봅니다.다른 노드의 옵션을 바꿀 때
출력 스레드 탭이 노드가 다음 노드로 넘기는 값을 봅니다.넘어가는 값을 확인할 때
YAML 탭노드 설정을 YAML 형식으로 봅니다.설정을 그대로 전달해 문의할 때
노드 삭제선택한 노드를 캔버스에서 지웁니다.잘못 추가한 노드를 없앨 때

따라 해 보기​

  1. 캔버스에서 입력 노드를 누릅니다.
  2. 옵션 & 미리보기 탭을 누릅니다.
  3. 파일 영역을 눌러 "보고서-3분기-AI활용현황.pdf"를 고릅니다.
  4. 입력 파일에 PDF / 4 KB가 보이는지 확인합니다.
  5. 화면 위쪽 파란 ▶ 버튼(파이프라인 실행)을 누릅니다.
  6. 세 노드 아래에 차례로 완료가 표시될 때까지 기다립니다. 예시 문서는 1분 안팎이 걸렸습니다.

입력 노드에 파일이 없는 상태로 실행하면 실행 실패가 표시됩니다. 자세한 내용은 문제 해결에 있습니다.

5. 파싱 결과 확인하기​

실행이 끝나면 파싱 노드에 블록 수와 페이지 수가 표시됩니다. 청크를 보기 전에 파싱 결과에서 원문이 제대로 읽혔는지 먼저 확인합니다. 여기서 빠진 문장은 청킹 설정을 바꿔도 되살아나지 않습니다.

파싱 결과 화면

번호메뉴기능이런 때 사용하세요
1파싱 노드블록 수와 페이지 수, 첫 블록 내용, 프로바이더(Brain Parser)가 보입니다. 예시는 12 블록 / 1 페이지입니다.원본 쪽수만큼 읽혔는지 숫자로 먼저 볼 때
2Parse 결과블록 목록을 봅니다. 옆 숫자는 블록 수입니다.제목, 본문, 표가 블록으로 나왔는지 볼 때
3원본 문서원본 PDF를 보는 화면으로 바꿉니다.블록 내용을 원본과 나란히 대조할 때
4블록블록 종류, 쪽 번호, 본문이 보입니다. 마우스를 올리면 원본 문서 보기에서 해당 위치가 강조됩니다.숫자와 문장이 정확히 읽혔는지 볼 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
옵션 & 미리보기 탭파싱 결과와 원본 문서를 봅니다.파싱 노드를 눌러 결과를 읽을 때
블록 요약블록 수와 원본 위치 정보 수(12 블록 · bbox 12개)가 보입니다.모든 블록에 원본 위치가 붙었는지 볼 때

따라 해 보기​

  1. 캔버스에서 파싱 노드를 누르고 옵션 & 미리보기 탭을 엽니다.
  2. Parse 결과에서 "2. 부서별 사용 현황" 아래 표 블록을 찾습니다.
  3. 영업본부 행에 131명, +42%가 보이는지 원본 PDF와 대조합니다.

6. 청크 결과 확인하기​

청킹 노드는 파싱 결과를 정한 크기로 나눈 청크를 보여 줍니다. 지식 검색은 이 청크 단위로 근거를 찾으므로, 함께 읽혀야 할 내용이 같은 청크에 들어 있는지 확인합니다.

청크 결과 화면

번호메뉴기능이런 때 사용하세요
1청킹 노드전략, 청크 크기, 청크 겹침, 만든 청크 수가 보입니다.어떤 기준으로 몇 조각이 나왔는지 볼 때
2청크 결과청크 수와 평균 글자 수(1 청크 / 평균 895 자)가 보입니다.청크가 너무 잘거나 크게 묶이지 않았는지 볼 때
3청크 칸청크마다 칸 하나가 있습니다. 마우스를 올리면 번호와 글자 수가 보이고, 누르면 아래에 본문이 열립니다.원하는 청크를 바로 골라 읽을 때
4청크 정보원본 파일 이름과 글자 수(895 자)가 보입니다.이 조각이 어느 문서에서 나왔는지 볼 때

화면에 번호를 붙이지 않은 그 밖의 메뉴는 다음과 같습니다.

메뉴기능이런 때 사용하세요
이전 청크앞 번호 청크로 이동합니다.내용이 앞 청크에서 이어지는지 볼 때
