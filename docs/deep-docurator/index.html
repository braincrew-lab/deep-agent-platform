Deep Docurator 소개

Deep Docurator는 업무 문서를 읽고, 나누고, 필요한 정보를 뽑아 정리하는 처리 순서를 화면에서 직접 만드는 제품입니다. 계약서, 견적서, 보고서, 회의록처럼 형식이 제각각인 문서를 넣으면 글자와 표를 읽어 내고, 검색과 답변에 쓰기 좋은 조각으로 나눈 뒤, 조각마다 요약이나 금액 같은 항목을 붙일 수 있습니다.

이 페이지에서 할 수 있는 일

  • Deep Docurator가 문서를 입력 → 파싱 → 청킹 순서로 처리한다는 것을 이해합니다.
  • 노드, 플로우, 프리셋, 청크 같은 기본 용어를 익힙니다.
  • 지원하는 파일 형식과 용량 한도를 확인합니다.
  • 이 매뉴얼의 구성을 보고 지금 필요한 페이지로 이동합니다.

Deep Docurator로 하는 일​

문서 한 건을 처리하는 기본 흐름은 세 단계입니다. 단계 하나하나를 노드라고 부르고, 노드를 연결선으로 이은 처리 순서를 플로우라고 부릅니다. 같은 문서라도 어떤 노드를 어떤 설정으로 잇느냐에 따라 결과가 달라지므로, 결과를 화면에서 바로 확인하며 플로우를 다듬습니다.

단계하는 일화면에서 확인할 결과
입력처리할 파일 한 개를 지정합니다.파일 이름, 형식, 용량
파싱파일에서 제목, 본문, 표, 이미지 설명을 읽어 블록으로 만듭니다.블록 수와 페이지 수, 블록별 본문
청킹파싱 결과를 정한 기준과 크기로 나눕니다.청크 수와 평균 글자 수, 청크별 본문

세 단계 뒤에 필요한 노드를 더 붙일 수 있습니다. 조각마다 요약·금액·기한 같은 항목을 뽑는 메타데이터, 개인정보를 가리는 PII, 필요 없는 조각을 거르는 필터, 문서 종류에 따라 경로를 나누는 라우터 등이 있습니다. 노드 전체 목록은 노드 안내에 있습니다.

기본 용어​

용어뜻화면에서 보이는 곳
노드처리 단계 하나입니다. 입력, 파싱, 청킹, 메타데이터 등이 있습니다.편집기 캔버스의 상자
플로우노드를 연결선으로 이은 처리 순서입니다. 파이프라인이라고도 부릅니다.사이드바의 플로우, 플로우 목록
블록파싱이 문서를 읽어 만든 단위입니다. 제목, 텍스트, 표, 목록, 이미지 등으로 구분됩니다.파싱 노드의 Parse 결과
청크청킹이 블록을 나눈 조각입니다. 검색과 에이전트 답변은 이 조각 단위로 근거를 찾습니다.청킹 노드의 청크 결과
메타데이터청크마다 붙이는 항목 값입니다. 요약, 키워드, 금액, 기한처럼 필드를 정해 뽑습니다.메타데이터 노드의 결과
프리셋자주 쓰는 노드 구성을 저장해 둔 것입니다. 내장 프리셋 5개와 내가 저장한 프리셋이 있습니다.새 플로우 만들기, 노드 추가 패널, 설정

지원하는 파일 형식과 용량​

입력 노드에는 파일 한 개를 넣습니다. 받을 수 있는 확장자는 다음 20가지이고, 파일 한 개의 최대 크기는 500MB입니다.

분류확장자
문서pdf, doc, docx, hwp, hwpx, md, txt, html, htm
발표 자료pptx
표xlsx, xls, csv
이미지png, jpg, jpeg, tiff, tif, bmp, webp

xls 파일은 파일 선택 창에서 고를 수 있지만 파싱 단계에서 처리되지 않습니다. 엑셀 97-2003 형식은 xlsx로 다시 저장해 넣으세요. ppt, xlsm, json 같은 다른 형식은 받지 않습니다. 형식별로 어떤 점이 다른지는 입력 노드와 지원 파일 형식에 정리했습니다.

다른 제품과의 연결​

Deep Docurator에서 확인한 플로우는 Deep Connector의 컬렉션에 문서를 올릴 때 처리 파이프라인으로 고를 수 있습니다. 편집기의 파이프라인 설정에서 DeepConnect 배포를 켜고 저장하면, Deep Connector 문서 업로드 화면의 파이프라인 목록에 플로우 이름이 나타납니다. 그 컬렉션을 지식으로 연결한 Deep Agent Builder 에이전트는 이렇게 나뉜 청크를 근거로 답합니다.

단계제품하는 일
1. 처리 기준 만들기Deep Docurator문서를 넣어 파싱·청킹 결과를 보고 플로우를 다듬습니다.
2. 컬렉션에 올리기Deep Connector문서를 올릴 때 Deep Docurator 플로우를 파이프라인으로 고릅니다.
3. 답변에 쓰기Deep Agent Builder컬렉션을 지식으로 연결한 에이전트가 청크를 찾아 답합니다.

배포와 확인 순서는 결과 확인과 내보내기에 있습니다.

이 매뉴얼의 예시​

이 매뉴얼은 가상의 회사 브레인크루의 AI혁신팀 김그루 사원이 Deep Docurator로 업무 문서를 정리하는 장면을 예시로 씁니다. 예시 문서의 회사명, 금액, 일정은 모두 연습용 가상 자료입니다. 실제 업무 문서로 연습할 때에는 개인정보와 영업 비밀이 들어 있지 않은지 먼저 확인하세요.
