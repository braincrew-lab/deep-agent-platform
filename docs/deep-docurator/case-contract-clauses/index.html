Deep Docurator 사례: 계약서 핵심 조항 추출

브레인크루 AI혁신팀 김그루 사원은 협력사와 맺을 교육 콘텐츠 제작 용역계약서를 검토해야 합니다. 계약서 전체를 처음부터 읽기 전에, 조항마다 계약 금액·지급 조건·기한이 무엇인지 먼저 뽑아 보고 싶습니다. 이 사례는 입력 → 파싱 → 청킹 → 메타데이터 플로우로 조항별 핵심 값을 정리하는 방법을 보여 줍니다.

이 페이지에서 할 수 있는 일

  • 내장 프리셋 기본 파이프라인 (단일)으로 계약서용 플로우를 만듭니다.
  • 청크를 조항 단위에 가깝게 나누도록 최대 청크 길이를 줄입니다.
  • 메타데이터 노드에 조항유형, 금액, 기한 필드를 더해 조항별 값을 뽑습니다.
  • 뽑은 값을 원문과 대조하는 기준을 익힙니다.

목표​

항목내용
하고 싶은 일계약서에서 조항별 금액·지급 조건·기한을 빠르게 확인
결과물청크(조항 묶음)마다 붙은 조항유형, 금액, 기한 값
노드 조합입력 → 파싱 → 청킹 → 메타데이터
걸리는 시간실행 1~2분, 검토 10분

준비물​

항목내용
예시 파일용역계약서-교육콘텐츠-제작.docx(37 KB, 제1조~제9조)
같은 내용의 다른 형식용역계약서-교육콘텐츠-제작.pdf. pdf로 넣으면 원본 문서 보기에서 조항 위치를 함께 볼 수 있습니다.
넣을 수 있는 형식pdf, doc, docx, hwp, hwpx, md, txt, html, htm, pptx, xlsx, csv, png, jpg, jpeg, tiff, tif, bmp, webp
예시 계약서 내용제1조 목적, 제2조 계약 기간, 제3조 계약 금액과 지급 조건(4,800만원, 선금 30%, 잔금 70%), 제4조 납품과 검수, 제5조 지체상금, 제6조 비밀 유지, 제7조 지식재산권, 제8조 계약 해지, 제9조 분쟁 해결

예시 계약서의 회사명, 금액, 일정은 모두 가상입니다. 실제 계약서로 시험할 때는 상대방 정보와 금액을 지운 사본을 씁니다.

1단계. 플로우 만들고 계약서 넣기​

  1. 사이드바 최근 플로우 줄에 마우스를 올리면 보이는 + 버튼을 누릅니다.
  2. 이름에 "교육 콘텐츠 용역계약서 조항 추출"을 입력합니다.
  3. 시작점에서 프리셋을 고르고 "내장: 기본 파이프라인 (단일)"을 고릅니다. 프리셋 미리보기에 입력 → 파싱 → 청킹 → 메타데이터, 노드 4개가 보입니다.
  4. 플로우 만들기를 누릅니다.
  5. 입력 노드를 누르고 옵션 & 미리보기 탭에서 계약서 파일을 올립니다. 입력 파일에 DOCX / 37 KB가 보이는지 확인합니다.

2단계. 조항 단위로 나누기​

조항 하나하나가 짧은 계약서는 처음 값(최대 청크 길이 1000)으로 나누면 여러 조항이 한 청크에 섞입니다. 조항별 값을 뽑으려면 청크를 작게 만듭니다.

  1. 청킹 노드를 누르고 설정 탭에서 고급 설정을 펼칩니다.
  2. **최대 청크 길이 (글자)**를 400으로, **최대 목표 겹침 (글자 수)**을 50으로 바꿉니다.

계약서 플로우 구성

번호항목화면에 보이는 내용확인할 것
1입력 노드용역계약서-교육콘텐츠-제작.docx, 37 KB계약서 파일이 맞는지
2청킹 노드재귀 (마크다운 인식), 청크 크기 400, 청크 겹침 50(설정 탭의 최대 청크 길이·최대 목표 겹침)바꾼 값이 노드에 반영됐는지
3메타데이터 노드필드 목록: title, summary, keywords, 조항유형, 금액, 기한3단계에서 더한 필드가 보이는지

3단계. 뽑을 항목 정하기​

  1. 메타데이터 노드를 누르고 설정 탭에서 고급 설정을 펼칩니다.
  2. 추출 필드 아래 처음 들어 있는 필드 가운데 category는 이 사례에 필요 없으므로 지웁니다.
  3. 필드 추가를 눌러 아래 세 필드를 만듭니다. 타입은 모두 문자열입니다.
필드 이름설명(모델이 읽는 기준)
조항유형조항의 종류. 목적, 계약기간, 금액·지급, 납품·검수, 지체상금, 비밀유지, 지식재산권, 해지, 분쟁 중 하나
금액조항에 나온 금액과 비율을 원문 그대로. 없으면 비움
기한조항에 나온 날짜·기간·기한을 원문 그대로. 없으면 비움

메타데이터 추출 필드 설정

번호항목화면에 보이는 내용확인할 것
1조항유형 필드 이름조항유형. 옆에 타입(문자열), 아래 줄에 설명과 허용 값(자유값)이 있습니다.값의 표현을 통일하고 싶으면 허용 값에 목록을 넣습니다
2금액 필드 이름금액. 설명에 "원문 그대로"와 "없으면 비움"을 적었습니다.모델이 값을 지어내지 않도록 기준을 적습니다
3기한 필드 이름기한. 설명은 날짜·기간·기한을 원문 그대로 적게 합니다.설명이 구체적인지 봅니다
4필드 추가새 필드 줄을 만듭니다.뽑을 항목을 더할 때

필드 목록은 설정 탭의 고급 설정을 펼쳐야 보입니다. 필요 없는 필드는 줄 오른쪽 ✕(제거)로 지웁니다.

4단계. 실행하고 결과 읽기​

  1. 위쪽 파이프라인 실행을 누릅니다. 예시에서는 파싱 21 블록 / 1 페이지, 청킹 4 청크(평균 271 자), 메타데이터 4/4 보강까지 1~2분 걸렸습니다.
  2. 메타데이터 노드를 누르고 옵션 & 미리보기 탭을 엽니다.
  3. 필드별 채움 현황과 청크별 값을 읽습니다.

조항별로 뽑은 메타데이터

번호항목화면에 보이는 내용확인할 것
1청크 칸네 칸 가운데 2번째를 고른 상태칸을 차례로 눌러 청크마다 값을 봅니다
2조항유형금액·지급2번 청크가 제3조인지
3금액4,800만원, 1,440만원, 3,360만원원문 제3조와 숫자가 같은지
4기한계약 체결 후 14일 이내, 최종 검수 완료 후 30일 이내원문의 지급 기한과 같은지

결과 화면 위쪽에는 필드별 채움 현황(예: 조항유형 4/4, 금액 1/4, 기한 3/4)이 보이고, 청크 칸을 누르면 그 청크의 값 전체가 보입니다.

결과물 예시​

예시 실행에서 뽑힌 값을 조항별로 옮겨 적으면 다음과 같습니다. 화면에는 표로 모아 내려받는 메뉴가 없으므로, 필요한 값은 메타데이터 결과에서 확인해 옮겨 적습니다.

청크첫 조항 제목조항유형금액기한
1계약서 제목과 제1조·제2조목적(비움)2026년 12월 1일부터 2027년 3월 31일까지
2제3조 (계약 금액과 지급 조건)금액·지급4,800만원, 1,440만원, 3,360만원계약 체결 후 14일 이내, 최종 검수 완료 후 30일 이내
3제6조 (비밀 유지)비밀유지(비움)계약 종료 후 3년간
4제9조 (분쟁 해결)분쟁(비움)(비움)

청크 하나에 여러 조항이 들어가면 값은 그 청크의 대표 조항 기준으로 하나만 붙습니다. 예시의 2번 청크에는 제3조~제5조가 함께 들어 있어, 제5조 지체상금(1일 0.1%, 최대 10%)은 금액 필드에 따로 나오지 않았습니다. 조항마다 값을 빠짐없이 받으려면 최대 청크 길이를 더 줄이거나, 청크 본문을 함께 읽어 보완합니다.

검토 기준​

확인 질문검토 방법
금액이 원문과 같은가요?메타데이터의 금액을 원문 제3조와 한 글자씩 대조합니다.
비율이 빠지지 않았나요?예시 실행에서는 금액만 뽑히고 30%, 70% 같은 비율은 빠지기도 했습니다. 비율이 필요하면 금액 필드 설명에 "비율도 함께"를 적습니다.
비어 있는 값이 맞게 비었나요?금액이 빈 청크의 본문에 실제로 금액이 없는지 봅니다.
빠진 조항이 없나요?청크 본문을 앞뒤로 넘기며 제1조부터 제9조까지 모두 있는지 봅니다.

응용 팁​

  • 조항유형을 검색 필터로 쓰려면 허용 값에 고를 값 목록을 넣습니다. 허용 값이 없으면 자유 값이 되어 필터에 쓰이지 않습니다.
  • 조항 제목이 "제N조" 형식으로 일정하면 목차 노드를 파싱 다음에 넣고 목차 구조 예시에 "L1 계약서 제목", "L2 제N조 조항 제목"을 한 줄에 하나씩을 적어 비교해 봅니다.
  • 상대방 이름이나 연락처가 들어 있는 계약서는 청킹 다음에 PII 노드를 넣어 가린 뒤 메타데이터를 뽑습니다.
  • 검토를 마친 구성은 프리셋으로 저장해 "계약서 조항 추출 v1"처럼 이름을 붙여 다음 계약서에도 씁니다.
  • docx처럼 PDF가 아닌 파일은 청킹 노드에 원본 좌표가 없다는 경고가 붙을 수 있습니다. 결과에는 영향이 없으며, 원본 위치 강조만 쓸 수 없습니다.
