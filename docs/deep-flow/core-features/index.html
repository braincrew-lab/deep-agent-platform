Deep Flow 주요 기능

사용 목적​

이 문서는 Deep Flow에 앱을 연결한 뒤 자주 사용하게 되는 기능인 파일 첨부, 결과물 내보내기, 대화 기록 복원, 관리자 대시보드를 안내합니다.

화면 위치​

앱 대화 화면 하단에 파일 첨부 버튼이 있어 여러 형식의 문서를 대화에 함께 올릴 수 있습니다. 대화 중 HTML 형태의 결과물(아티팩트)이 만들어지면 화면에서 이를 다른 형식으로 내보내는 버튼을 볼 수 있습니다. 관리자 권한이 있는 사용자는 별도의 관리자 대시보드 화면에 접근할 수 있습니다.

단계​

  1. 파일 첨부: 대화 입력란 옆의 파일 첨부 버튼을 눌러 PDF, 이미지, 마크다운, 엑셀 파일 중 하나를 선택합니다. 첨부한 파일은 메시지와 함께 전송되어 대화의 맥락으로 사용됩니다.
  2. 결과물 내보내기: 대화 중 HTML 아티팩트가 만들어지면 해당 아티팩트 화면에서 내보내기 버튼을 눌러 PPTX 파일로 저장할 수 있습니다. 발표 자료가 필요할 때 유용합니다.
  3. 대화 기록 확인: 대화는 실시간으로 화면에 순차적으로 나타나며, 페이지를 새로고침해도 지금까지 나눈 대화 기록이 다시 불러와져 이어서 볼 수 있습니다.
  4. 관리자 대시보드: 관리 권한이 있다면 관리자 대시보드 화면에서 전체 현황을 확인할 수 있습니다. 세부 관리 항목은 계정 권한에 따라 다르게 표시되므로, 필요한 기능이 보이지 않으면 관리자에게 권한을 문의합니다.

결과 확인​

파일을 첨부해 전송하면 대화창에 첨부 파일이 함께 표시됩니다. 내보내기를 누르면 PPTX 파일 다운로드가 시작됩니다. 새로고침 후에도 이전 대화가 순서대로 다시 나타나면 정상입니다. 관리자 대시보드에 들어가면 화면 제목이 관리자 대시보드로 표시됩니다.

문제 해결​

파일 첨부가 안 된다면 지원 형식(PDF, 이미지, 마크다운, 엑셀)인지, 파일 용량이 지나치게 크지 않은지 확인합니다. PPTX 내보내기가 실패한다면 아티팩트가 완전히 생성된 뒤에 다시 시도합니다. 새로고침 후 대화가 보이지 않는다면 같은 계정, 같은 앱으로 접속했는지 확인합니다. 관리자 대시보드에 접근할 수 없다면 계정에 관리자 권한이 없는 경우이므로 담당자에게 요청합니다. 처음 사용하는 경우 Deep Flow 시작하기 문서를 먼저 참고하세요.
