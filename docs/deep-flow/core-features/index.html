Deep Flow 주요 기능

앱 목록과 연결 메뉴​

앱 목록은 일을 맡길 앱을 선택하는 출발점입니다. 새로운 앱 연결은 새 질문을 시작하는 버튼이 아니라 앱 자체를 등록하는 메뉴입니다. 연결할 때는 Dify, LangGraph, n8n 중 제공받은 종류를 선택합니다. 이름이 익숙한 탭을 고르기보다 담당자가 알려 준 종류와 일치시키세요.

Dify 탭에서는 API Key와 Endpoint를 입력하고 선택적으로 태그를 붙입니다. 앱 연결을 누르면 앱 정보 확인과 등록이 진행됩니다. 성공하면 등록된 앱 화면으로 자동 이동하므로 열린 앱이 맞는지 확인하세요. 앱 목록에 남아 있을 때만 등록한 앱을 선택합니다. 연결 오류는 입력값 또는 앱 측 상태 확인이 필요한 신호이며, 오류 안내만으로 원인을 단정할 수 없습니다.

대화 화면에서 사용하는 메뉴​

아래 설명은 Dify 대화형 앱 기준입니다. 연결 방식과 앱 구성에 따라 다른 화면이 표시될 수 있습니다. 첫 실습은 시작하기에 있습니다.

메뉴와 위치언제 사용하는가입력과 확인할 결과
대화목록이전에 진행한 업무로 돌아갈 때대화 제목을 선택하고 메시지 내용이 찾던 업무인지 확인합니다.
새 대화이전 업무와 분리된 질문을 시작할 때빈 대화에서 새 자료와 목적을 입력합니다. 앱이 요구하는 초기 입력도 다시 확인합니다.
메시지 입력란선택한 대화에서 질문하거나 수정 요청을 보낼 때질문·자료·원하는 형식을 함께 적고 자신의 메시지와 응답을 차례로 확인합니다.
대화 제목 변경비슷한 대화를 구별하기 어려울 때대화 항목의 점 세 개 메뉴에서 선택하고 식별하기 쉬운 제목으로 바꿉니다. 변경 성공 안내와 제목을 확인합니다.
고정·고정 해제자주 돌아갈 대화를 위쪽에 두고 싶을 때대화 항목 메뉴에서 선택합니다. 고정 표시와 목록 순서를 확인합니다.
대화 삭제더 이상 필요하지 않은 기록을 정리할 때대상 제목과 내용을 먼저 확인합니다. 다시 사용할 기록에는 고정이나 제목 변경을 우선 고려하세요.

앱을 바꾸는 일과 대화를 바꾸는 일은 다릅니다. 같은 질문도 다른 앱에서는 다른 구성을 사용하므로, 답변을 비교할 때 어떤 앱의 어떤 대화인지 함께 기억해 두는 것이 좋습니다.

파일 첨부를 사용할 때​

파일을 받도록 구성된 앱에서는 입력 영역의 첨부 기능을 사용할 수 있습니다. 사용 가능한 파일 형식은 선택한 앱의 허용 설정을 따릅니다. 다른 앱에서 열렸던 문서라고 해서 지금 선택한 앱에도 첨부할 수 있는 것은 아닙니다.

첨부하려는 파일을 선택한 뒤 파일명과 업로드 상태를 확인하세요. 오류 안내에 허용 형식이 표시되면 그 안내와 파일 확장자를 비교합니다. 파일이 첨부된 것과 앱이 내용을 정확히 해석한 것은 별도입니다. 첫 질문에는 “첫 문단의 핵심 내용만 정리해 주세요”처럼 확인 범위를 좁히고 원문과 대조하는 것을 권합니다.

어떤 기능부터 조합할까​

일회성 질문은 새 대화와 메시지 입력만으로 시작할 수 있습니다. 여러 차례 수정할 업무는 제목을 붙이고 고정해 두면 다시 찾기 쉽습니다. 기록 정리는 반복 업무, 입력 자료를 구성하는 방법은 활용 사례에서 이어서 확인하세요. 첨부나 기록에 문제가 생기면 문제 해결을 확인합니다.
