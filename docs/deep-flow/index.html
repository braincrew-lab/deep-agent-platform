Deep Flow 소개

여러 업무용 앱을 한곳에서 사용합니다​

Deep Flow는 연결된 업무용 앱을 선택하고 그 앱과 대화하는 작업 공간입니다. 사용자는 질문과 자료를 전달하고, 앱의 답변을 검토하며, 필요할 때 이전 대화로 돌아갑니다. 반복해서 사용하는 요약 도우미나 문장 작성 도우미를 한곳에서 찾아 쓰려는 사람에게 적합합니다.

앱은 일을 맡길 대상이고, 대화는 그 앱에서 진행한 개별 업무 기록입니다. 같은 앱을 사용해도 회의 정리와 안내문 작성은 서로 다른 대화로 나누면 맥락을 구별하기 쉽습니다. 앱을 연결했다는 사실만으로 모든 업무나 파일 형식이 지원되는 것은 아닙니다. 실제로 할 수 있는 일은 연결한 앱의 구성에 따라 달라집니다.

앱을 쓰는 사람과 연결하는 사람이 준비할 것​

이미 사용할 앱이 목록에 있다면 앱 제공 담당자에게 이름과 용도를 확인하고 바로 열어 보세요. 아직 연결하지 않았다면 담당자에게 앱 종류와 해당 종류에 맞는 연결 정보를 받습니다. 비밀번호와 앱 연결용 키는 서로 다른 값입니다. 연결용 키를 대화 본문에 입력하지 마세요.

이 매뉴얼의 첫 실습은 Dify 방식의 대화형 앱을 기준으로 합니다. 짧은 한국어 텍스트를 요약할 수 있고 별도 필수 입력이 없는 연습용 앱을 준비하면 그대로 따라갈 수 있습니다. LangGraph나 n8n 앱을 제공받았다면 해당 탭의 연결 항목과 앱별 사용 안내를 먼저 확인하세요. 다른 종류의 값을 Dify 입력란에 맞춰 넣지 않습니다.

화면을 읽는 순서​

앱 목록에서는 이번 업무에 사용할 앱을 선택합니다. 새로운 앱 연결은 제공받은 앱을 등록할 때 사용합니다. 앱 안의 돌아가기를 이용하면 목록으로 돌아가 다른 앱을 고를 수 있습니다.

Dify 대화형 앱에서는 대화목록과 메시지 영역을 구별해 보세요. 대화목록은 이전 업무를 찾는 곳이고, 메시지 영역은 선택한 업무의 질문과 응답을 읽는 곳입니다. 새 대화는 이전 대화에 이어 쓰지 않고 새 주제를 시작할 때 사용합니다. 첫 화면에 별도의 입력 항목이 있으면 해당 앱이 요구하는 정보부터 확인해야 합니다.

화면의 메뉴를 이해하기주요 기능에서 메뉴별 사용 시점과 결과를 확인합니다.
이전 업무를 이어가고 정리하기반복 업무에서 대화 선택·이름 변경·고정을 연결합니다.
실제 요청을 구성해 보기활용 사례에서 회의 메모를 안내문 초안으로 바꿉니다.
연결·입력·기록이 기대와 다르기문제 해결에서 증상별 확인 순서를 찾습니다.
