Deep Flow 소개

사용 목적​

Deep Flow는 여러 업무용 앱을 하나의 화면에서 연결해 대화형으로 사용할 수 있게 해 주는 플랫폼입니다. 이 문서는 Deep Flow의 전체 화면 구성과 기본적인 이동 방법을 처음 사용하는 사람 기준으로 소개합니다.

화면 위치​

로그인 후 접속하는 기본 화면은 지금까지 연결한 앱 목록입니다. 화면 상단에는 공지사항, 게시판, 문의하기, 새로운 앱 연결 메뉴와 사용자 아바타가 있습니다. 특정 앱 안에 들어가면 상단에 돌아가기 메뉴가 추가로 표시되어 앱 목록으로 되돌아갈 수 있습니다. 화면 한쪽에는 바로가기 메뉴가 떠 있어 자주 쓰는 기능으로 빠르게 이동할 수 있습니다. 관리자 권한이 있는 사용자는 관리자 대시보드 화면에도 접근할 수 있습니다.

단계​

  1. 로그인 화면에서 계정 정보를 입력하고 로그인합니다.
  2. 로그인 후 표시되는 앱 목록에서 원하는 앱을 눌러 대화형 화면으로 들어갑니다.
  3. 새로운 앱을 연결하고 싶다면 상단의 새로운 앱 연결 메뉴를 누릅니다. 연결 대화상자에서 Dify, LangGraph, n8n 중 사용하려는 앱 종류에 맞는 탭을 선택하고 안내에 따라 연결 정보를 입력합니다. 화면에 있는 연결 가이드 문서 링크를 참고하면 도움이 됩니다.
  4. 공지사항이나 게시판에서 새로운 소식이나 다른 사용자가 남긴 글을 확인할 수 있습니다.
  5. 궁금한 점이 있으면 문의하기 메뉴를 눌러 문의를 남깁니다.

결과 확인​

로그인이 완료되면 상단 메뉴와 앱 목록이 정상적으로 표시됩니다. 새로운 앱 연결을 마치면 앱 목록에 방금 연결한 앱이 추가됩니다. 앱 안에서 돌아가기를 누르면 다시 앱 목록 화면으로 이동합니다.

문제 해결​

로그인 화면에서 정보를 입력해도 진행되지 않는다면 입력한 계정 정보를 다시 확인하고, 문제가 계속되면 관리자에게 문의합니다. 앱 연결이 실패한다면 선택한 탭(Dify, LangGraph, n8n)이 사용하려는 앱 종류와 맞는지 확인하고, 연결 가이드 문서를 참고합니다. 자세한 사용 방법은 Deep Flow 시작하기와 Deep Flow 주요 기능에서 확인할 수 있습니다.
