Deep Flow 문제 해결

앱 연결이 완료되지 않습니다​

새로운 앱 연결 창에서 오류가 나오면 선택한 앱 종류부터 확인합니다. Dify 앱의 값을 LangGraph나 n8n 탭에 입력하지 않았는지 살펴보세요. Dify 탭이라면 API Key와 Endpoint가 담당자에게 받은 값인지, 앞뒤에 불필요한 공백이 없는지 비교합니다.

입력란 아래 주소 형식 안내가 있으면 그 내용을 먼저 해결합니다. 값이 정확한데도 앱 연결 오류가 반복되면 담당자에게 앱 종류, 오류가 발생한 단계, 표시된 오류 문구와 시간을 전달하세요. 키 자체는 문의 본문에 넣지 않습니다.

수정 후에는 앱 연결 성공 안내와 창 닫힘을 확인합니다. 등록된 앱 화면으로 자동 이동하면 열린 앱이 대상 앱인지 확인하고 첫 질문을 진행하세요. 앱 목록에 남아 있을 때만 해당 앱을 선택합니다. 창에 값을 모두 채운 것만으로 연결이 완료된 것은 아닙니다.

메시지 입력란이 보이지 않거나 답변이 없습니다​

Dify 대화형 앱에서 별도의 입력 양식이 먼저 표시되는지 확인합니다. 앱에 초기 입력 항목이 있으면 바로 메시지를 쓰는 화면과 다를 수 있습니다. 어떤 값을 넣을지 모르는 경우 앱 제공 담당자에게 입력 목적을 확인합니다.

메시지를 이미 보냈다면 자기 메시지가 화면에 있는지, 응답이 진행 중인지, 오류가 표시되는지를 구별하세요. 같은 요청을 연달아 보내기보다 현재 표시를 먼저 확인합니다. 응답이 종료되었고 다시 시도할 수 있다면 첨부 없이 짧은 연습 문장으로 한 번 확인합니다.

재확인에도 응답이 없으면 앱 이름, 발생 시간, 짧은 재현 문장, 화면의 오류를 담당자에게 전달합니다. 답변이 표시되었지만 내용이 틀린 문제라면 연결을 다시 만들기보다 활용 사례의 사실 대조 방법으로 요청을 수정하세요.

첨부한 파일이 거부됩니다​

선택한 앱의 허용 형식 안내와 파일 확장자를 비교합니다. 모든 앱이 같은 파일을 받는다고 가정하지 마세요. 오류에 표시된 조건에 맞는 연습용 파일이 있다면 작은 파일 하나로 다시 확인합니다. 확장자 이름만 바꾸어 다른 형식인 것처럼 제출하지 않습니다.

첨부 목록에 파일이 보이고 업로드가 끝났는지 확인한 뒤 질문을 보내세요. 업로드가 성공했더라도 원문 일부를 잘못 읽을 수 있으므로 응답을 원문과 비교합니다. 계속 실패하면 파일 형식, 대략적인 크기, 오류 문구를 제공하고 실제 파일 전달 필요 여부는 담당자에게 확인합니다.

이전 대화를 찾을 수 없습니다​

먼저 같은 계정으로 같은 앱을 열었는지 확인합니다. Dify 대화목록이 불러오는 중이면 목록 로딩을 확인한 뒤 제목을 찾습니다. 대화가 많으면 목록을 아래로 내려 이전 항목을 살펴보세요. 제목이 바뀌었다면 알고 있는 업무 내용과 메시지를 대조합니다.

계정과 앱이 맞는데도 기록이 없다면 복원이 가능하다고 단정하지 않습니다. 앱 이름, 마지막으로 대화를 본 시점, 기억나는 제목을 담당자에게 전달하세요. 제목 변경과 고정 방법은 반복 업무에서 확인할 수 있습니다.

도움 요청 전에 정리할 정보​

문제가 발생한 화면, 수행한 마지막 단계, 기대한 결과와 실제 표시를 짧게 적으면 담당자가 상황을 파악하기 쉽습니다. 연결 정보 전체나 업무 원문을 무조건 붙이기보다 비밀값을 제외한 오류 문구와 가상 자료의 재현 결과를 전달하세요.

해결 뒤에는 막혔던 단계부터 다시 확인합니다. 연결 오류라면 앱 열기와 첫 질문, 첨부 오류라면 업로드와 내용 확인, 기록 문제라면 대상 대화의 실제 메시지 확인까지 진행합니다. 기본 순서는 시작하기에 있습니다.
