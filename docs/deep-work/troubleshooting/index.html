Deep Work 문제 해결

로그인할 수 없습니다​

로그인 화면의 서버 URL, 이메일, 비밀번호를 제공받은 값과 비교합니다. 접속 오류, 계정 정보 오류, 승인 대기 안내는 서로 다른 상태입니다. 화면에 표시된 문구를 먼저 읽고 같은 비밀번호를 계속 입력하기보다 해당 상태를 확인하세요.

주소와 계정 정보가 맞는데도 실패하면 담당자에게 오류 문구와 발생 시간을 전달합니다. 승인 대기 안내라면 계정 승인이 필요한지 문의합니다. 비밀번호나 모델 키를 문의 본문에 넣지 않습니다. 해결 후에는 PC 에이전트를 선택할 수 있는 작업 화면까지 이동하는지 확인합니다.

메시지가 전송되지 않습니다​

현재 스레드와 작업 폴더를 먼저 확인합니다. 폴더가 없으면 메시지를 보낼 수 없습니다. 새 스레드를 선택하고 작업 폴더 선택으로 연습 폴더를 지정한 뒤, 입력란 아래에 폴더 이름이 나타나는지 확인합니다.

응답이 진행 중이면 입력이 비활성화될 수 있습니다. 진행 상태와 오류 표시를 구별하고, 이미 전송한 요청을 여러 번 반복하지 마세요. 폴더 선택을 해결한 뒤에는 첨부 없는 짧은 문장으로 다시 확인합니다. 같은 오류가 나면 스레드 제목, 선택한 폴더 여부, 오류 문구를 기록합니다.

모델 목록이 없거나 키 등록 안내가 나옵니다​

설정의 모델 탭은 선택된 스레드가 필요합니다. 활성 스레드가 없다는 안내라면 설정을 닫고 PC 에이전트에서 새 스레드를 선택한 뒤 다시 엽니다.

공급자에 키가 필요하다는 안내가 있으면 해당 공급자용으로 제공받은 키인지 확인합니다. 키를 등록한 뒤 목록에서 모델을 선택하고 선택 표시를 확인하세요. 키 저장만으로 사용 가능 여부를 확정하지 말고 짧은 요청에 실제로 응답하는지 확인합니다. 사용할 모델 자체가 없다면 임의의 모델 이름을 입력하지 말고 담당자에게 준비 상태를 문의합니다.

승인 요청에서 멈춘 것 같습니다​

대화 안에 승인 대기 작업이 있는지 확인합니다. 여러 요청이 보이면 각각의 대상과 내용을 읽습니다. 가능한 승인·거부 선택지는 작업에 따라 다를 수 있으므로 실제 표시된 동작을 사용합니다.

현재 업무와 맞는 요청인지 판단하기 어렵다면 진행을 허용하기 전에 담당자에게 작업 내용을 확인하세요. 버튼이 없다는 사실만으로 “아직 요청 생성 중”이라고 판단하지 않습니다. 승인 없이 진행되는 작업도 있습니다. 승인을 한 뒤에는 결과 응답과 실제 파일을 확인합니다. 승인이 완료되었다는 표시만으로 파일이 올바르게 완성된 것은 아닙니다.

완료했다고 하지만 파일이 없거나 내용이 다릅니다​

먼저 현재 스레드의 작업 폴더와 요청한 파일명을 확인합니다. 대화에서만 초안을 요청했는지, 실제 파일 저장까지 요청했는지도 읽어 보세요. 폴더가 맞으면 컴퓨터에서 해당 폴더를 직접 열어 파일 존재 여부와 내용을 확인합니다.

파일이 없다면 “현재 작업 폴더에 요청한 파일이 있는지 확인하고 결과를 알려 주세요”처럼 확인부터 요청합니다. 파일이 있다면 열어서 누락된 내용을 구체적으로 지적합니다. 전체 작업을 다시 시키기 전에 이미 완료된 부분을 확인하면 불필요한 덮어쓰기를 줄일 수 있습니다.

도움을 요청할 때​

PC 에이전트인지 원격 에이전트인지, 문제가 발생한 단계, 표시된 오류, 선택한 모델, 파일 존재 여부를 정리하세요. 폴더 전체 내용이나 원본 업무 자료 대신 가상 자료로 재현한 결과를 우선 전달합니다.

해결 후에는 막혔던 동작과 결과를 함께 다시 확인합니다. 첫 요청은 시작하기, 파일 검토 기준은 활용 사례에 있습니다.
