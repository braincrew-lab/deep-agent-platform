Deep Work 소개

컴퓨터의 작업 폴더를 정하고 일을 맡깁니다​

Deep Work는 컴퓨터에서 에이전트와 대화하며 작업을 진행하는 데스크톱 앱입니다. 업무 내용을 설명하고, 필요한 파일 작업을 맡기고, 실행 결과를 확인하는 흐름으로 사용합니다. 이 매뉴얼은 짧은 회의 메모 정리에서 시작해 검토한 내용을 연습용 파일로 남기는 과정까지 안내합니다.

텍스트로 결과를 받는 일과 실제 파일을 만드는 일은 구별해야 합니다. 대화에 “완료했습니다”라는 답이 있어도 파일이 필요한 업무라면 선택한 폴더에서 결과물을 직접 확인하세요. 작업 요청에 원하는 결과, 저장 위치, 변경 범위를 함께 적으면 무엇을 확인해야 하는지 분명해집니다.

먼저 알아둘 세 가지 개념​

스레드는 한 업무를 이어가는 대화 단위입니다. 이전 업무를 수정하려면 해당 스레드를 다시 선택하고, 별개의 업무를 시작하려면 새 스레드를 만듭니다.

작업 폴더는 PC 에이전트가 파일을 다루는 위치입니다. 메시지를 보내기 전에 현재 스레드에 작업 폴더를 선택해야 합니다. 첫 연습에는 업무 원본이 없는 빈 폴더를 준비하세요. 폴더 이름이 표시되는지 확인한 뒤 요청을 보냅니다.

모델은 요청을 해석하고 응답하는 데 사용하는 구성입니다. 사용할 모델과 접속 준비가 필요합니다. 모델 화면에 아무 항목도 없거나 키 등록 안내가 나오면 제공 담당자에게 사용 가능한 값을 확인합니다.

PC 에이전트와 원격 에이전트 선택​

PC 에이전트는 현재 컴퓨터의 작업 폴더를 중심으로 실습할 때 선택합니다. 이 매뉴얼의 시작하기와 활용 사례도 PC 에이전트를 기준으로 합니다.

원격 에이전트는 제공된 원격 에이전트를 선택해 사용하는 별도 모드입니다. 원격 모드의 새 대화는 에이전트를 먼저 선택해야 만들 수 있습니다. PC 실습을 시작하기 위해 원격 연결 설정까지 모두 입력할 필요는 없습니다. 어느 모드를 사용해야 할지 불분명하면 업무 제공 담당자에게 확인하세요.

학습 순서와 첫 완료 기준​

필요한 안내다음 문서
로그인 후 첫 요청을 보내고 싶습니다.시작하기에서 스레드·폴더·모델을 확인합니다.
화면 항목과 승인 표시를 이해하고 싶습니다.주요 기능에서 메뉴별 쓰임을 확인합니다.
이전 결과를 수정하고 새 업무로 넘어가고 싶습니다.반복 업무에서 스레드와 폴더를 관리합니다.
결과물을 실제 파일로 남겨 보고 싶습니다.활용 사례에서 가상 회의 메모를 정리하고 파일을 확인합니다.
전송·모델·승인·파일에서 막혔습니다.문제 해결에서 증상을 구별합니다.

첫 성공은 큰 자동화가 아니라 요청한 짧은 결과를 받고 사실이 유지되었는지 확인하는 것입니다. 이후 파일 생성까지 넓히되, 승인 요청이 나타나면 실행 내용과 대상을 읽고 판단하세요. 모든 작업이 반드시 승인 창을 거치는 것은 아닙니다.
