Deep Work 소개

사용 목적​

이 문서는 개인 컴퓨터(PC)에서 실행되는 에이전트 프로그램인 Deep Work를 처음 사용하는 분들을 위한 소개 안내입니다. Deep Work는 사용자의 컴퓨터에 설치되어 실행되며, 대화형으로 작업 지시를 내리면 파일을 다루고 여러 도구를 호출해 업무를 자동으로 진행하는 데스크톱 애플리케이션입니다. 이 소개 문서를 읽으면 프로그램의 전체 화면 구조와 어디에서 무엇을 할 수 있는지를 먼저 파악할 수 있습니다.

화면 위치​

Deep Work를 실행하면 가장 먼저 로그인 화면이 나타나며, 로그인을 마치면 왼쪽에 네 개의 메뉴가 있는 사이드바를 볼 수 있습니다.

  • PC 에이전트: 현재 컴퓨터에서 실행 중인 에이전트와 대화를 진행하는 화면입니다.
  • 원격 에이전트: 원격 환경에서 실행되는 에이전트를 확인하는 화면입니다.
  • 개요: 전체 작업 현황을 한눈에 보는 화면입니다.
  • 설정: 서버 연결, 모델 공급자, 브라우저 연결, MCP 도구 등을 구성하는 화면입니다.

단계​

  1. 프로그램을 실행하면 초기화 화면을 거쳐 로그인 화면으로 이동합니다.
  2. 로그인 화면에서 계정 정보를 입력해 로그인합니다.
  3. 로그인 후 사이드바에서 원하는 메뉴(PC 에이전트, 원격 에이전트, 개요, 설정)를 선택합니다.
  4. 작업 폴더를 지정하고 에이전트와 첫 대화를 시작합니다.

결과 확인​

로그인이 성공하면 왼쪽 사이드바에 네 개의 메뉴가 모두 나타나는지 확인합니다. PC 에이전트 화면에서 대화 입력창이 보이면 정상적으로 준비가 끝난 것입니다.

문제 해결​

로그인 화면에서 계속 초기화 문구만 보인다면 잠시 기다린 뒤 프로그램을 다시 실행합니다. 사이드바 메뉴가 비어 있거나 눌러지지 않는다면 설정 화면에서 서버 연결 상태를 다시 확인합니다. 처음 설치부터 첫 대화까지의 순서는 Deep Work 시작하기 문서를, 승인 절차나 브라우저 연결 같은 세부 기능은 Deep Work 주요 기능 문서를 참고합니다.
