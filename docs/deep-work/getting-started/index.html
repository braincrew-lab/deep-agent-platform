Deep Work 시작하기

준비물과 이번 실습의 결과​

PC 에이전트에서 가상 회의 메모를 세 항목으로 정리해 봅니다. 이번에는 응답을 대화에서 확인하고 파일 생성은 다음 실습으로 미룹니다. 짧은 텍스트 요청에도 작업 폴더가 필요하므로 컴퓨터에 “매뉴얼 연습”이라는 빈 폴더를 미리 준비하세요.

로그인에 사용할 서버 URL, 이메일, 비밀번호는 제공 담당자에게 받습니다. PC 에이전트에서 사용할 모델도 준비되어 있어야 합니다. 키가 필요한 환경이라면 담당자가 안내한 공급자의 키를 설정 화면에 등록합니다. 로그인 비밀번호와 모델 키는 서로 다른 값입니다.

1. 로그인하고 새 스레드 만들기​

  1. 프로그램의 로그인 화면에서 서버 URL, 이메일, 비밀번호를 입력합니다. 서버 URL은 담당자에게 받은 값을 사용합니다.
  2. 같은 주소를 다음에도 사용하려면 서버 URL 기억하기를 선택하고 로그인합니다.
  3. 왼쪽 사이드바에서 PC 에이전트를 선택합니다.
  4. 새 스레드를 누릅니다. 비어 있는 대화 영역과 작업 폴더 선택 안내가 나타나는지 확인합니다.

로그인 오류가 나오면 모델 설정을 바꾸기 전에 오류 안내부터 확인합니다. 계정 확인이 완료되어 작업 화면을 사용할 수 있어야 다음 단계로 진행할 수 있습니다.

2. 작업 폴더와 모델 확인하기​

  1. 대화 영역의 작업 폴더 선택을 누르고 준비한 “매뉴얼 연습” 폴더를 고릅니다.
  2. 입력란 아래의 폴더 선택 영역에 선택한 폴더 이름이 표시되는지 확인합니다. 다른 폴더라면 다시 선택합니다.
  3. 사이드바의 설정을 열고 모델 탭을 선택합니다. 현재 스레드에서 사용할 수 있는 공급자와 모델을 확인합니다.
  4. 사용할 수 있는 모델을 선택하고 선택 표시를 확인합니다. 키가 필요하다는 안내가 있으면 제공받은 키를 등록한 뒤 모델 목록을 다시 확인합니다.
  5. 설정을 닫고 대화 화면으로 돌아갑니다.

모델 설정에서 활성 스레드가 없다는 안내가 나오면 먼저 새 스레드를 선택했는지 확인하세요. 모델 키를 저장한 것과 실제 요청이 성공하는 것은 별도이므로 다음 짧은 요청으로 응답까지 확인합니다.

3. 첫 요청 보내기​

메시지 입력란에 다음 연습용 요청을 입력하고 전송합니다.

아래 가상 회의 메모를 결정 사항, 할 일, 미정 사항 세 항목으로 정리해 주세요. 대화에만 답하고 파일은 만들지 마세요. 메모: 모임은 금요일 오후 3시에 진행합니다. 장소는 작은 회의실입니다. 진행자는 책 목록을 준비합니다. 간식은 아직 정하지 않았습니다.

자신의 요청이 대화에 표시되는지 확인하고 응답을 기다립니다. 이 실습은 파일 변경을 요청하지 않습니다. 예상하지 않은 작업의 승인 요청이 나타나면 내용을 읽고, 요청 범위와 맞지 않을 때는 가능한 경우 거부를 선택합니다. 승인 버튼이 나오지 않는다고 해서 오류는 아닙니다.

4. 결과 확인하기​

결정 사항에는 금요일 오후 3시와 작은 회의실, 할 일에는 진행자의 책 목록 준비, 미정 사항에는 간식이 들어 있는지 확인합니다. 모델이 사용하는 제목이나 문장은 달라도 됩니다. 실제 자료에 없는 담당자 이름이나 기한을 만들어 넣었다면 수정이 필요합니다.

“간식은 미정으로 유지하고 나머지 내용은 바꾸지 마세요”처럼 구체적으로 후속 요청을 보내 보세요. 응답을 받았고 필요한 사실을 원문과 대조했다면 첫 실습을 마친 것입니다.

다음 업무로 이어가기​

메뉴별 의미와 승인 판단은 주요 기능에서 확인합니다. 같은 스레드를 이어서 사용하는 방법은 반복 업무, 검토한 결과를 파일로 만드는 연습은 활용 사례에 있습니다. 막힌 단계가 있으면 문제 해결을 참고하세요.
