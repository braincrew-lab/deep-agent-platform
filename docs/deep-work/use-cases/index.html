연습 상황: 회의 메모를 검토한 뒤 파일로 남기기​

다음은 가상의 독서 모임 기록을 정리하는 연습입니다. 실제 고객 사례나 자동화 성과를 뜻하지 않습니다. 처음에는 대화에서 초안을 검토하고, 내용이 맞으면 작은 텍스트 파일로 저장하도록 요청합니다. 답변과 파일 결과를 따로 확인하는 방법을 익히는 것이 목표입니다.

PC 에이전트의 새 스레드, 사용할 모델, 업무 원본이 없는 “매뉴얼 연습” 폴더를 준비합니다. 준비 순서는 시작하기를 참고하세요. 같은 이름의 결과 파일이 이미 있다면 다른 빈 연습 폴더를 사용합니다.

입력 자료와 검토 기준​

다음 자료를 사용합니다.

가상 독서 모임 회의 메모. 다음 모임은 금요일 오후 3시, 작은 회의실에서 진행한다. 진행자는 책 목록을 준비한다. 참석자는 읽고 싶은 책 제목 하나를 가져온다. 간식 제공 여부는 아직 정하지 않았다.

완성할 결과는 결정 사항, 할 일, 미정 사항으로 나눈 짧은 기록입니다. 담당자를 실명으로 만들거나 메모에 없는 마감일을 붙이면 안 됩니다. 최종 파일 이름은 “모임정리.txt”로 정합니다. 텍스트 파일을 사용하면 별도의 문서 편집 기능을 배우지 않고 내용부터 비교할 수 있습니다.

1. 대화에서 내용 먼저 검토하기​

위 메모와 함께 다음 요청을 보냅니다.

이 메모를 결정 사항, 할 일, 미정 사항으로 나누어 대화에 보여 주세요. 원문에 없는 사실은 추가하지 마세요. 아직 파일을 만들지 마세요.

응답에서 시간과 장소를 확인하고, 진행자와 참석자의 할 일이 각각 들어 있는지 살펴봅니다. 간식이 미정으로 남아 있어야 합니다. 잘못된 항목이 있다면 해당 부분만 수정해 달라고 요청하고 다시 읽습니다.

2. 확인한 내용을 파일로 만들기​

검토가 끝나면 다음과 같이 요청합니다.

방금 검토한 정리 내용을 현재 작업 폴더에 모임정리.txt라는 새 텍스트 파일로 저장해 주세요. 같은 이름의 파일이 있으면 덮어쓰지 말고 알려 주세요. 다른 파일은 변경하지 마세요. 저장 결과를 알려 주세요.

입력란 아래의 작업 폴더 이름을 마지막으로 확인한 뒤 보냅니다. 승인이 필요한 작업이 나타나면 대상과 내용을 읽고 현재 요청에 맞는지 판단합니다. 단순 파일 작업에서는 별도의 승인 요청이 없을 수도 있습니다.

완료 응답을 받은 뒤 파일 영역에서 “모임정리.txt”를 찾습니다. 목록에 바로 나타나지 않더라도 컴퓨터에서 선택한 폴더를 열어 파일 존재 여부를 확인합니다. 해당 파일을 열고 내용을 직접 읽습니다.

3. 결과물로 완료를 판단하기​

확인 대상완료 기준
위치와 파일명선택한 연습 폴더에 모임정리.txt가 있습니다.
결정 사항금요일 오후 3시와 작은 회의실이 유지됩니다.
할 일진행자의 책 목록 준비와 참석자의 책 제목 준비가 구별됩니다.
미정 사항간식 제공 여부가 미정으로 남아 있습니다.
요청 범위기존 파일을 덮어쓰거나 다른 파일을 바꾸지 않았는지 확인합니다.

“파일을 저장했다”는 답변만 있고 실제 파일이 없으면 완료가 아닙니다. 파일은 있지만 정보가 빠졌다면 빠진 항목을 지정해 수정 요청을 보낸 뒤 다시 파일을 열어 확인합니다. 모델이 정리하는 문구는 달라질 수 있으므로 사실과 분류를 중심으로 비교하세요.

다른 업무로 넓히기​

같은 방식으로 짧은 점검 메모나 초안 정리에도 적용할 수 있습니다. 자료 제공, 대화 검토, 파일 생성 요청, 실제 파일 확인의 순서를 유지하세요. 자동으로 외부에 전달하거나 배포했다고 가정하지 않습니다.

후속 수정과 스레드 정리는 반복 업무, 파일이 없거나 승인이 멈춘 것처럼 보일 때는 문제 해결을 확인하세요.
