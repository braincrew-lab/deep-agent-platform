Deep Work 주요 기능

사용 목적​

이 문서는 Deep Work의 핵심 기능인 승인 절차, 브라우저 연결, MCP 도구 추가, 모델 공급자 설정, PC 서브에이전트, 문서 스킬을 안내합니다. 처음 시작하는 방법은 Deep Work 시작하기 문서를 먼저 확인합니다.

화면 위치​

설정 화면 안에는 브라우저 연결, MCP 도구, 모델, PC 서브에이전트 탭이 있습니다. 에이전트가 승인이 필요한 작업을 수행할 때는 대화창 안에 승인 필요 배지와 함께 승인·거부 버튼이 나타납니다.

단계​

  1. 승인 절차: 에이전트가 신중한 확인이 필요한 작업을 요청하면 대화창에 승인 필요 배지가 표시됩니다. 승인 버튼을 누르면 작업이 진행되고 배지가 승인됨으로 바뀌며, 거부 버튼을 누르면 작업이 취소되고 배지가 거부됨으로 바뀝니다.
  2. 브라우저 연결: 설정 화면의 브라우저 연결 탭에서 네 단계를 차례로 진행합니다. 1단계 Chrome 확장 설치, 2단계 네이티브 호스트 설치, 3단계 MCP 서버 등록, 4단계 연결 테스트 순서로 진행하며, 각 단계를 마치면 다음 단계로 넘어갑니다.
  3. MCP 도구 추가: MCP 도구 탭에서 MCP 도구 추가 버튼을 누르면 대화상자가 열립니다. 전송 방식으로 stdio, http, sse 중 하나를 고르고 서버 이름과 표시 이름을 입력한 뒤, 전송 방식에 따라 명령어와 인자 또는 접속 주소와 헤더를 입력해 저장합니다.
  4. 모델 공급자 설정: 모델 탭에서는 Anthropic, OpenAI, Google 세 곳의 공급자 중에서 선택해 각 공급자의 접속 정보를 등록합니다.
  5. PC 서브에이전트: PC 서브에이전트 탭에서 에이전트 찾아보기 버튼을 누르면 서버에 등록된 에이전트 목록을 볼 수 있고, 원하는 에이전트를 선택해 가져올 수 있습니다.
  6. 문서 스킬: 대화 중 첨부한 문서가 한글(hwp, hwpx), 워드(docx), 엑셀(xlsx), 파워포인트(pptx), PDF 형식이면 에이전트가 해당 형식에 맞는 스킬을 사용해 문서 내용을 처리합니다.

결과 확인​

승인 버튼을 누른 뒤 배지가 승인됨으로 바뀌는지 확인합니다. 브라우저 연결의 마지막 단계인 연결 테스트가 성공 문구를 보여주면 연결이 완료된 것입니다. MCP 도구를 저장한 뒤 도구 목록에 새 항목이 나타나는지 확인합니다.

문제 해결​

승인·거부 버튼이 보이지 않으면 에이전트가 아직 요청을 완료하지 않은 것이므로 잠시 기다립니다. 브라우저 연결 중 특정 단계에서 멈추면 이전 단계를 다시 실행한 뒤 진행합니다. MCP 도구 저장이 되지 않으면 전송 방식에 맞는 필수 입력값(명령어와 인자, 또는 접속 주소)이 모두 채워졌는지 확인합니다. 모델 공급자 접속에 실패하면 선택한 공급자의 접속 정보를 다시 확인합니다.
