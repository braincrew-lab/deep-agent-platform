Deep Work 주요 기능

사이드바에서 업무를 선택합니다​

사이드바의 PC 에이전트와 원격 에이전트는 실행 환경을 바꾸는 선택 항목입니다. 처음에는 현재 컴퓨터에서 사용할 PC 에이전트를 선택하세요. 원격 에이전트를 이용할 때는 제공된 에이전트를 먼저 선택해야 새 원격 스레드를 만들 수 있습니다.

항목언제 사용하는가결과와 조건
새 스레드기존 업무와 다른 요청을 시작할 때새 대화를 만들고 작업 폴더를 확인합니다.
스레드 목록이전 업무로 돌아갈 때항목을 선택하고 이전 메시지와 현재 폴더를 읽습니다.
이름 변경업무 제목을 알아보기 쉽게 정리할 때스레드 항목의 메뉴에서 이름을 바꾸고 목록에 반영되는지 확인합니다.
개요PC 모드에서 작업을 둘러볼 때PC 에이전트 모드에서 표시됩니다. 원격 모드에서 같은 메뉴가 항상 보이는 것은 아닙니다.
설정모델이나 사용할 연결 구성을 확인할 때설정 창의 관련 탭으로 이동합니다.

대화 목록을 정리할 때는 이름 변경을 먼저 사용하세요. 삭제는 다시 참고할 업무인지 확인한 뒤 판단하는 편이 좋습니다.

작업 폴더와 모델의 역할​

작업 폴더 선택은 현재 스레드가 사용할 폴더를 정합니다. 선택 영역에 폴더 이름이 표시되고, 펼치면 현재 폴더와 변경 기능을 확인할 수 있습니다. 새 업무를 시작하거나 이전 스레드를 열었을 때 대상 폴더를 다시 읽어 보세요.

설정의 모델 탭은 현재 선택한 스레드의 모델을 고르는 곳입니다. 공급자를 고르고 사용할 모델을 선택하면 선택 표시를 볼 수 있습니다. 활성 스레드가 없으면 먼저 스레드를 선택합니다. 키가 필요한 공급자는 키 등록 안내를 확인하고 제공받은 값으로 등록합니다. 목록에 이름이 보이는 것만으로 실제 요청이 성공한다고 판단하지 말고 시작하기의 짧은 요청으로 확인하세요.

승인 요청을 읽는 방법​

승인이 필요한 작업은 대화 안에 실행 내용과 입력값을 보여 줍니다. 대상 파일이나 요청 내용이 이번 업무와 일치하는지 읽은 뒤 판단합니다. 승인·거부 중 실제로 제공되는 선택지는 작업별로 달라질 수 있습니다.

승인은 해당 작업의 진행을 허용하는 판단입니다. 승인됨 표시가 결과물의 완성을 뜻하지는 않습니다. 실행 후 응답이나 파일 내용을 다시 확인하세요. 거부한 경우에도 이전에 끝난 다른 작업까지 되돌아갔다고 가정하지 않습니다.

설정의 에이전트 동작에는 명령을 자동 승인하는 YOLO 모드가 있습니다. 첫 실습에서는 이 설정을 바꾸지 않고 현재 작업의 요청 범위를 확인하는 방법부터 익히세요. 승인 버튼이 없다는 이유만으로 대기 상태라고 판단하면 안 됩니다. 폴더 안의 파일 작업 등은 별도 승인 없이 진행될 수 있습니다.

파일 결과와 설정을 구별해서 보기​

파일 영역은 작업 폴더의 파일 목록을 확인하는 곳입니다. 빈 폴더로 시작했다면 파일 생성 요청 후 새 파일이 나타나는지 확인하고, 실제 내용은 컴퓨터에서 해당 파일을 열어 검토하세요. 목록에 보이는 것만으로 내용이 최신이라고 판단하지 말고 실제 파일과 비교합니다.

설정에는 서버 설정, 모델, 에이전트 동작, PC 서브에이전트, MCP 도구, 브라우저 연결, 스킬, 시스템 프롬프트, 고급 설정 탭이 있습니다. PC의 짧은 텍스트 실습에 모든 탭을 채울 필요는 없습니다. 외부 연결이 필요한 업무는 담당자가 제공한 연결 정보와 사용 절차를 확인한 뒤 시작합니다.

반복적으로 수정하는 절차는 반복 업무, 파일 결과를 검토하는 예시는 활용 사례, 예상과 다른 표시는 문제 해결에서 확인하세요.
