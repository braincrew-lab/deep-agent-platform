Deep Work Gateway 소개

누가 어떤 모델을 사용할지 관리하기​

Deep Work Gateway 운영자 콘솔은 사용자별 모델 권한, 접속 키, 사용 한도를 관리하고 사용량을 확인하는 곳입니다. 이용자를 처음 등록하는 운영자와 기존 사용자의 이용 범위를 점검하는 운영자를 위한 매뉴얼입니다.

사용자 등록, 모델 선택, 키 발급은 서로 다른 확인 단계입니다. 사용자가 목록에 있다는 이유만으로 모델 이용 준비가 끝난 것은 아닙니다. 해당 키에 허용 모델이 배정됐는지와 사용자·키의 상태까지 함께 확인합니다.

운영자와 이용자 구분하기​

콘솔에 로그인하는 운영자 계정과 사용자 메뉴에서 관리하는 이용자는 구분됩니다. 운영자 로그인에는 승인받은 사용자 이름과 비밀번호를 사용합니다. 이용자에게 발급하는 가상 키는 운영자 로그인 비밀번호를 대신하는 값이 아닙니다.

운영자 역할할 수 있는 관리 작업
조회 전용메뉴의 정보를 조회하고 사용자 한도·모델 권한·사용량을 확인합니다
관리자사용자 추가·수정, 키 발급과 모델 권한 변경을 수행합니다
최고 관리자관리자 작업에 더해 운영자 계정을 관리합니다

사용자 추가나 키 발급 영역이 보이지 않으면 자신의 역할을 확인하세요. 변경 권한이 필요하면 관리자 또는 최고 관리자에게 요청합니다.

처음 사용할 때 필요한 것​

승인된 운영자 계정, 관리할 이용자의 고정된 사용자 ID, 표시 이름, 허용할 모델과 한도 기준을 준비합니다. 모델을 배정하려면 선택 가능한 게시된 활성 모델이 있어야 합니다. 없다면 모델 게시 담당자에게 확인한 뒤 발급 작업을 진행하세요.

가상 키는 발급 직후 한 번만 표시됩니다. 값을 보관할 조직의 안전한 저장 위치와 전달 방법을 미리 준비합니다. 일반 문서나 공개 대화에 키를 붙이지 마세요.

목적별 안내​

하려는 일다음 문서
첫 사용자와 키 설정시작하기
메뉴와 입력값의 의미 확인주요 기능
한도 변경과 모델 권한 재점검반복 업무
같은 기간의 사용량 비교 연습활용 사례
모델 미표시, 차단, 빈 사용량 확인문제 해결

첫 설정의 완료 기준은 목록과 상세 화면에서 입력한 사용자, 한도, 키의 상태와 모델 배정을 확인하는 것입니다. 실제 이용 결과는 사용자 측 작업과 구분해 확인하세요.
