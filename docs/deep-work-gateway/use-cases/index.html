Deep Work Gateway 활용 사례

연습 상황: 같은 기간의 사용량 비교​

이 사례는 가상의 운영 검토 연습이며 실제 고객의 이용 기록이 아닙니다. 목표는 사용량이 많은 사용자와 모델을 찾고 어떤 추가 확인이 필요한지 정리하는 것입니다. 조회 전용 계정도 조회 작업을 수행할 수 있습니다.

실제 화면에 기록이 있는 사용자 두 명을 선택하되 여기서는 “사용자 가”와 “사용자 나”라고 부릅니다. 개인정보를 외부로 복사할 필요는 없습니다. 기록이 없다면 비교 결과를 만들어 내지 말고 기간을 바꾸거나 기록이 있는 대상을 담당자에게 확인하세요.

기간을 고정하고 상세 열기​

  1. 사용량 메뉴에서 최근 7일을 선택합니다. 화면에 표시된 시작일과 종료일을 기록합니다.
  2. 전체 토큰, 성공 요청, 사용액, 사용한 사용자를 확인합니다. 불러오는 중이면 완료될 때까지 기다린 뒤 값을 읽습니다.
  3. 사용자별 목록에서 대상 사용자를 누릅니다. 이 목록은 토큰이 많은 상위 10명만 표시하므로 전체 사용자 명단으로 해석하지 않습니다.
  4. 사용자 상세의 전체·입력·출력 토큰, 사용액과 모델별 값을 확인합니다.
  5. 같은 사용량 화면에서 다른 대상을 선택합니다. 기간을 바꾸지 않고 동일 항목을 비교합니다.

상위 목록에 없는 관리 대상은 사용자 메뉴에서 찾아 상세의 토큰 사용량을 확인할 수 있습니다. 이때 최근 7일을 다시 선택하고 표시 날짜도 비교하세요. 사용자 화면의 기간 선택은 사용량 메뉴와 별도입니다.

관찰값을 읽는 연습​

아래 숫자는 해석 연습을 위한 가상 값이며 실제 화면에서 그대로 나타나는 결과가 아닙니다.

항목사용자 가사용자 나
전체 토큰12,0006,000
입력 토큰10,0002,000
출력 토큰2,0004,000

사용자 가의 전체 토큰이 더 많다는 점과 사용자 나의 출력 토큰이 더 많다는 점을 구분할 수 있습니다. 이 정보만으로 어느 사용자가 불필요하게 사용했다고 결론 내리지 마세요. 작업 목적과 사용 모델이 다를 수 있으므로 모델별 값과 실제 업무 맥락을 함께 확인하는 것이 좋습니다.

사용액이 “—”이면 0으로 바꾸어 계산하지 않습니다. 표시된 사용액이 있는 대상끼리 비교하더라도 같은 기간인지 먼저 확인하세요.

검토 결과를 조치로 연결하기​

확인한 기간, 대상, 관찰값, 추가 확인할 질문을 정리합니다. 예를 들어 “입력 분량 차이가 크므로 어떤 작업을 수행했는지 확인”이라고 남길 수 있습니다. 콘솔이 원인을 자동 판정했다는 뜻은 아닙니다.

한도를 바꿀 필요가 확인되면 관리자가 반복 업무에 따라 변경합니다. 사용량이 크다는 이유만으로 곧바로 차단하거나 예산을 줄이지 않습니다. 기간과 대상이 확인되지 않았다면 문제 해결에서 조회 조건부터 점검하세요.
