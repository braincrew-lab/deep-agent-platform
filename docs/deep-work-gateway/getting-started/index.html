Deep Work Gateway 시작하기

준비: 연습할 사용자와 이용 기준 정하기​

관리자 또는 최고 관리자 계정으로 진행합니다. 아래는 연습용 설정이며 권장 요금이나 실제 운영 기준이 아닙니다. 조직에서 허용한 연습 대상이 있을 때 사용하고 실제 사용자의 ID와 한도는 담당자에게 받은 값으로 바꾸세요.

입력가상 연습 값의미
사용자 IDpractice-user-01이용자를 구분하는 고정 값
표시 이름연습 사용자목록에서 알아볼 이름
최대 예산10예산의 통화 단위는 USD
예산 기간매월예산 기간 선택
동시 요청 수2동시에 처리할 요청 수의 한도
키 별칭문서 정리 연습키의 용도를 구분할 이름

허용할 모델은 실제 선택 목록에서 담당자가 지정한 모델 한 개를 고릅니다. 예시 모델명을 임의로 입력하지 마세요. 게시된 활성 모델이 없으면 먼저 모델 담당자에게 확인합니다.

로그인하고 사용자 등록하기​

  1. 운영자 로그인 화면의 사용자 이름과 비밀번호를 입력하고 로그인을 누릅니다.
  2. 비밀번호 변경 화면이 나타나면 현재 비밀번호와 12자 이상의 새 비밀번호, 같은 새 비밀번호 확인 값을 입력하고 비밀번호 변경을 눌러 콘솔로 들어갑니다.
  3. 사용자 메뉴를 엽니다. 이름 또는 사용자 ID 검색으로 같은 대상이 이미 있는지 확인합니다. 이미 등록됐다면 새로 만들지 말고 해당 사용자의 상세를 엽니다.
  4. 새 대상이면 사용자 추가 영역에 사용자 ID와 표시 이름을 입력합니다. 사용 한도 설정을 켜고 위 예산·기간·동시 요청 값을 입력한 뒤 사용자 추가를 누릅니다.
  5. 목록에서 입력한 표시 이름과 ID를 찾고 상태 및 예산 / 동시 요청 값을 확인합니다. 생성 화면의 활성 체크만으로 저장 결과를 판단하지 마세요. 비활성이라면 이용 허용 여부를 확인한 뒤 수정에서 활성을 켜고 사용자 수정을 누릅니다.

사용 한도 설정을 끄거나 항목을 비워 두면 해당 제한이 없는 설정이 될 수 있습니다. 연습에서도 필요한 제한을 빠뜨리지 않았는지 저장 결과를 확인하세요.

모델을 지정하고 키 발급하기​

  1. 방금 확인한 사용자의 상세를 누릅니다. 상세 제목의 표시 이름이 목록에서 확인한 대상과 맞는지 확인합니다.
  2. 키 발급 영역의 모델 권한에서 허용할 활성 모델을 선택합니다. 아무 모델도 선택하지 않으면 모델 이용 권한이 없는 키가 만들어집니다.
  3. 키 별칭에 “문서 정리 연습”을 입력하고 키 발급을 누릅니다.
  4. “가상 키를 지금 저장하세요” 창에서 복사를 누르고 준비한 안전한 위치에 보관합니다. 복사됨 표시와 저장 여부를 확인한 뒤 확인 및 닫기를 누르세요. 이 값은 창을 닫으면 다시 볼 수 없습니다.

첫 설정의 완료 확인​

상세의 키 목록에서 별칭, 상태, 배정 모델 수를 확인하고 모델 권한 편집을 펼쳐 선택한 모델을 다시 확인합니다. 사용자 목록에서도 활성 상태와 한도를 확인하면 이번 콘솔 설정을 마칩니다. 실제 모델 요청 성공을 시험한 것은 아닙니다.

키가 있어도 모델이 0개이거나 차단 상태면 준비가 끝난 것이 아닙니다. 문제 해결에서 해당 상태를 확인하세요. 메뉴의 의미는 주요 기능, 이후 변경 작업은 반복 업무로 이어집니다.
