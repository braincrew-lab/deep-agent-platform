Deep Work Gateway 문제 해결

로그인하거나 관리 버튼을 찾을 수 없어요​

운영자 로그인에는 승인받은 사용자 이름과 비밀번호를 사용합니다. 이용자에게 발급한 가상 키를 입력하는 화면이 아닙니다. 잘못된 자격 정보라는 안내가 나오면 입력한 계정을 확인하고 최고 관리자에게 계정 상태 확인을 요청하세요.

비밀번호 변경 화면이 나오면 현재 비밀번호와 새 비밀번호, 확인 값을 안내대로 입력합니다. 새 값이 서로 다르면 일치시킨 뒤 다시 제출합니다. 비밀번호를 문의 내용에 포함하지 마세요.

조회 전용 계정에는 사용자 추가·수정과 키 발급 기능이 제공되지 않습니다. 자신의 역할을 확인한 뒤 변경할 대상과 필요한 작업을 관리자에게 요청합니다.

사용할 모델이 보이지 않아요​

사용자 상세의 키 발급 또는 모델 권한 편집에서 선택할 활성 모델이 있는지 확인합니다. “게시된 활성 모델이 없습니다”라는 안내가 보이면 모델 메뉴의 Gateway 모델 카탈로그에서 게시 상태를 확인하거나 담당 관리자에게 요청하세요.

모델을 선택하지 않은 키는 모델 이용 권한이 없습니다. 이미 발급했다면 해당 키의 모델 권한 편집에서 허용 모델을 선택하고 모델 권한 저장을 누른 뒤 배정 모델 수와 선택 상태를 확인합니다. 키를 반복 발급하는 것만으로 해결되지 않습니다.

키가 있는데 이용이 제한돼요​

화면에서 확인할 것안전한 다음 조치다시 볼 결과
키의 수동 차단 상태허용된 변경인지 확인한 뒤 수동 차단 해제상태와 사용자 활성 여부
사용자 비활성으로 차단이용 허용 대상인지 확인하고 사용자 수정사용자 상태와 키 상태
모델 배정 0개허용 모델을 선택해 저장배정 모델과 선택 상태
사용 한도설정값을 조직의 이용 기준과 비교저장된 예산·기간·동시 요청 값

이 항목은 원인을 좁히기 위한 확인 순서입니다. 특정 상태가 보인다는 이유로 모든 이용 오류의 원인을 확정하지 마세요. 사용자의 비활성 상태는 키의 수동 차단 해제만으로 바뀌지 않습니다.

발급한 키를 저장하지 못했어요​

발급 창이 열려 있다면 복사를 누르고 복사됨 표시와 안전한 보관 위치를 확인합니다. 복사 실패가 표시되면 창을 닫기 전에 화면의 값을 안전한 위치에 옮길 수 있는지 확인하세요.

이미 닫았다면 기존 비밀 값은 다시 표시되지 않습니다. 새 키가 필요하면 시작하기의 발급 절차를 진행합니다. 사용하지 않을 기존 키의 상태도 확인하고 조직의 처리 기준에 따라 수동 차단 여부를 결정하세요. 문의에는 키 별칭만 사용하고 비밀 값을 첨부하지 않습니다.

사용량이 없거나 수치가 다르게 보여요​

사용량 메뉴의 기간과 표시 시작일·종료일을 확인합니다. “불러오는 중”과 “기록된 사용량이 없습니다”를 구분하고, 실제 이용 날짜가 포함되도록 기간을 선택하세요.

사용자별 목록은 상위 10명이므로 대상이 없으면 사용자 메뉴에서 검색해 상세를 확인합니다. 이동한 화면은 기간을 다시 확인하세요. 사용량 메뉴는 7일·14일·30일, 사용자 상세는 7일·30일을 선택합니다.

“현재 관리 목록에는 없는 사용자”라는 안내는 사용 기록과 현재 관리 대상이 다르다는 뜻입니다. 과거 기록만 보고 같은 사용자를 새로 등록하지 마세요. 사용액의 “—”도 0으로 해석하지 않습니다.

해결되지 않을 때 전달할 내용​

메뉴 이름, 사용자와 키 별칭, 작업 시점, 선택 기간, 오류 안내, 확인한 상태를 정리하세요. 비밀번호와 키 비밀 값은 제외합니다. 저장 중 오류가 났다면 화면을 다시 조회해 실제 반영 여부를 확인한 뒤 문의합니다. 무조건 한도를 해제하거나 같은 사용자를 중복 등록하지 마세요.

상태의 의미는 주요 기능, 승인된 변경 절차는 반복 업무에서 확인할 수 있습니다.
