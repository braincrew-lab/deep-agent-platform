Deep Work Gateway 주요 기능

어디에서 작업하나요​

콘솔의 메뉴는 대시보드, 사용량, 사용자, 모델, MCP / 스킬, 운영 현황으로 나뉘며 관리자 메뉴는 최고 관리자에게 제공됩니다. 이 안내는 사용자·모델 권한·한도·사용량 관리에 집중합니다.

메뉴이 매뉴얼에서 확인할 일다음 행동
사용자등록 대상, 상태, 한도, 키와 모델 배정수정 또는 상세를 엽니다
모델Gateway 모델 카탈로그와 게시 상태배정할 모델이 없을 때 게시 담당자와 확인합니다
사용량기간별 전체·사용자별·모델별 기록같은 기간을 정한 뒤 상세를 비교합니다

MCP / 스킬의 배포나 운영자 계정 생성은 첫 이용자 설정의 필수 단계가 아닙니다. 맡은 관리 업무와 권한을 확인한 뒤 해당 메뉴를 사용하세요.

사용자: 고정 값과 표시 이름​

사용자 ID는 이용자를 구분하는 고정 값이며 수정 화면에서 변경할 수 없습니다. 표시 이름은 목록에 보이는 이름으로 수정할 수 있습니다. 이름 또는 사용자 ID 검색과 전체·활성·비활성 필터를 함께 사용해 대상을 찾습니다.

수정은 표시 이름, 활성 상태, 사용 한도를 변경할 때 사용합니다. 상세는 키, 모델 권한과 사용량을 볼 때 사용합니다. 조회 전용 계정은 내용을 확인할 수 있지만 사용자 추가·수정과 키 발급은 관리자에게 요청해야 합니다.

사용 한도: 예산과 동시 요청​

사용 한도 설정을 켜면 최대 예산, 예산 기간, 동시 요청 수를 지정합니다. 예산 단위는 USD이며 기간은 매월·매주·매일 중 선택합니다. 비워 둔 제한 항목은 제한 없음이므로 숫자를 지우는 작업을 단순 초기화로 생각하지 마세요.

저장 후 사용자 목록의 예산 / 동시 요청을 확인합니다. 예산 기간도 재확인하려면 수정을 다시 열어 선택 값을 확인한 뒤 변경하지 않을 때는 취소합니다. 한도 변경 절차는 반복 업무에 있습니다.

키와 모델 권한​

키는 사용자 상세에서 별칭을 지정하고 발급합니다. 값은 발급 직후 한 번만 표시되며 목록에는 별칭과 상태, 배정 모델 수가 나타납니다. 모델 권한 편집에서 선택을 바꾸고 모델 권한 저장을 눌러 반영합니다.

선택 가능한 모델은 활성 모델입니다. 0개를 선택하면 모델 이용 권한이 없습니다. “현재 비활성 배정” 안내가 있으면 저장할 때 그 배정이 제거되므로 필요한 이용 범위를 먼저 확인하세요.

수동 차단은 키별 설정이고 사용자 비활성에 따른 차단과 구분됩니다. 수동 차단 해제만으로 비활성 사용자가 활성화되는 것은 아닙니다.

사용량: 기간과 표시 범위​

사용량 메뉴는 최근 7일·14일·30일을 선택하고 전체 토큰, 성공 요청, 사용액, 사용한 사용자와 일자별 토큰을 보여 줍니다. 사용자별 목록은 토큰이 많은 상위 10명을 표시합니다. 목록에 없다는 이유로 해당 사용자의 기록이 없다고 판단하지 마세요.

사용자를 누르면 같은 기간의 입력·출력·전체 토큰과 모델별 내용을 확인합니다. 사용자 화면에서 열기는 현재 관리 목록에 있는 대상에 제공됩니다. 이동한 사용자 상세의 기간은 별도로 확인하세요. 그 화면의 토큰 사용량은 최근 7일·30일을 선택합니다.

사용액의 “—” 표시는 0원으로 해석하지 않습니다. 비교 연습은 활용 사례, 조회 문제는 문제 해결에서 확인하세요.
