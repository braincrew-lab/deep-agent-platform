Deep Admin 문제 해결

관리자 화면을 쓰다가 막히거나, 직원에게서 "모델이 안 보인다", "지식을 못 찾는다", "한도가 찼다"는 문의를 받았을 때 확인할 순서를 정리했습니다. 각 항목은 증상 → 먼저 볼 곳 → 조치 순서로 읽습니다.

이 페이지에서 할 수 있는 일

  • 로그인과 메뉴 표시 문제의 원인을 권한 기준으로 가립니다.
  • 직원 문의를 관리자 화면의 어느 메뉴에서 확인할지 찾습니다.
  • 사용량과 한도, 배포 심사, 기록 조회에서 자주 헷갈리는 동작을 확인합니다.

로그인과 화면 진입​

증상먼저 볼 곳조치
로그인은 되었는데 "접근 권한이 없습니다"와 "관리자 접근 권한이 필요합니다."가 나옵니다.안내 화면의 현재 계정그 계정에 관리자 접근 권한이 있는 권한 그룹이 배정되어 있어야 합니다. 다른 관리자가 사용자 메뉴에서 그 계정의 RBAC 그룹을 확인합니다.
관리 화면 선택에 Deep Connector나 Deep Work가 없습니다.사이드바 맨 위 관리 화면 선택제품별 관리 화면 진입 권한이 없으면 그 제품이 목록에서 빠집니다. 권한 메뉴의 RBAC 탭에서 그 관리자가 속한 그룹에 제품 진입 권한이 있는지 봅니다.
"이 페이지에 접근하려면 해당 권한이 필요합니다."가 나옵니다.안내 문구의 필요 권한 이름주소를 직접 열었거나 즐겨찾기로 들어왔지만 그 화면의 권한이 없는 경우입니다. 대시보드로 이동을 누르고, 필요하면 권한 담당 관리자에게 그룹 배정을 요청합니다.
사이드바에 있어야 할 메뉴가 보이지 않습니다.사이드바 묶음Agent Builder 관리 메뉴는 권한이 없으면 항목이 숨겨지고, 묶음의 모든 항목이 숨겨지면 묶음 제목도 사라집니다. Deep Connector와 Deep Work 메뉴는 숨기지 않고 흐리게 표시하며, 마우스를 올리면 "접근 권한이 없습니다"가 나옵니다.
인프라 모니터링이 흐리게 보이고 눌리지 않습니다.메뉴에 마우스를 올렸을 때의 안내"도입 예정" 메뉴입니다. 현재는 에러/장애 모니터링과 대시보드의 시스템 탭으로 상태를 봅니다.

사용자와 권한 문의​

증상먼저 볼 곳조치
신규 입사자가 사용자 목록에 없습니다.사용자 목록 검색사용자 목록은 플랫폼에 한 번 이상 로그인한 계정을 보여 줍니다. 관리자 화면에는 사용자를 직접 추가하는 버튼이 없으므로, 먼저 직원이 Deep Agent Builder에 로그인하도록 안내한 뒤 다시 검색합니다.
권한 그룹을 바꿨는데 직원 화면이 그대로입니다.직원의 로그인 상태권한 변경은 즉시 저장되지만 직원 화면은 새로 고침하거나 다시 로그인해야 반영되는 경우가 있습니다. 직원에게 화면을 새로 고치도록 안내합니다.
시스템 그룹에 사용자를 추가할 수 없습니다.그룹의 시스템 배지시스템 그룹은 로그인할 때 외부 인증의 역할에 따라 자동으로 배정됩니다. 수동으로 추가하거나 삭제할 수 없으니, 일반 그룹을 만들어 배정합니다.
직원이 지식함에서 컬렉션을 찾지 못합니다.지식 컬렉션 권한에서 컬렉션 상세의 접근 사용자 목록그 직원 행의 상태가 사용 가능인지, 기한 만료나 회수됨은 아닌지 봅니다. 기한이 지났으면 권한 변경으로 사용 기한을 늘리거나 다시 추가합니다.
사용자별 도구 권한이나 사용자별 지식 권한을 누르면 "요청한 경로를 찾을 수 없습니다."가 나옵니다.배포의 사용자별 권한 기능사용자별 권한 기능(사번 디렉터리와 사람 단위 권한 저장소)을 켠 배포에서만 열리는 화면입니다. 켜지 않은 배포에서는 ABAC 그룹과 지식 컬렉션 권한으로 범위를 정합니다.
접근 사용자 추가에서 직원 이름을 검색해도 "일치하는 사용자가 없습니다"가 나옵니다.검색어이름 전체가 일치해야 찾습니다. "김그"나 이메일 대신 "김그루"처럼 이름 전체를 적습니다.
사용자별 지식 권한에서 부여 버튼이 보이지 않습니다.화면 위 설명이 화면은 조회 전용입니다. 부여와 회수는 지식 컬렉션 권한에서 컬렉션을 골라 진행합니다.
도구 권한을 회수했는데 기록이 남아 있습니다.사용자별 도구 권한 상세의 상태 필터회수는 기록을 지우지 않고 상태를 회수됨으로 바꿉니다. 회수 제외 필터를 고르면 현재 쓸 수 있는 권한만 보입니다.

모델과 리소스 문의​

증상먼저 볼 곳조치
직원 화면의 모델 목록에 모델이 보이지 않습니다.모델 목록의 워크스페이스 열과 ABAC 열모델은 워크스페이스 단위로 등록됩니다. 직원이 쓰는 워크스페이스에 그 모델이 있는지, ABAC 그룹으로 사용 범위가 좁혀져 있지 않은지 봅니다.
모델을 새로 추가하려는데 모델 화면에 추가 버튼이 없습니다.모델 화면 위 안내문모델 원본은 Toolbox의 모델 탭에서 추가합니다. 추가한 뒤 워크스페이스에 할당하면 모델 목록에 나타납니다.
도구 추가가 눌리지 않습니다.도구 화면의 워크스페이스 선택도구는 워크스페이스에 추가하므로 워크스페이스를 먼저 골라야 버튼이 켜집니다.
도구가 외부 주소를 호출하지 못합니다.도메인 허용 목록의 모드와 목록모드가 허용 목록이면 목록에 있는 도메인만 호출할 수 있습니다. 호출할 주소를 도메인 추가로 등록하고 30초 뒤 다시 시도합니다. 자세한 내용은 툴박스 레지스트리에 있습니다.
외부 접근 키 발급 창에서 주체를 고를 수 없습니다.사번 디렉터리 연결주체는 사번으로 고릅니다. 사번 디렉터리가 연결되지 않은 배포에서는 발급할 수 없습니다.
API 토큰 값을 다시 보고 싶습니다.API 토큰 목록토큰 값은 만들 때 한 번만 보입니다. 잃어버렸으면 그 토큰을 취소(폐기)하고 새로 만듭니다.
Deep Connector 관리 화면의 LLM 커넥션에 "연동 서비스가 요청을 거부했습니다."가 나옵니다.통합 어드민의 Deep Connector 연동 계정 권한연동 계정에 커넥션 관리 권한이 없는 배포입니다. Deep Connector 화면의 관리자 메뉴에서 관리합니다.

사용량과 한도​

증상먼저 볼 곳조치
직원이 "토큰 한도를 초과했다"고 문의합니다.사용자별 통계 > 토큰 사용량 탭의 상태와 사용률상태가 한도 초과면 토큰 한도 설정의 개인 토큰 추가 부여로 이번 달에만 쓸 토큰을 더 줍니다. 당월 사용량이 새 한도보다 적어지면 차단이 풀립니다.
부서별로 한도를 다르게 정하고 싶습니다.토큰 한도 설정의 기본 한도 카드월 한도는 전 사용자에게 같은 값 하나만 정할 수 있고, 부서·워크스페이스·역할 단위 한도는 없습니다. 많이 쓰는 부서 직원에게는 개인 추가 부여로 보완합니다.
한도 값을 바꿀 수 없고 입력란이 잠겨 있습니다.카드 안 안내 문구설정 변경 권한이 없는 관리자는 값을 보기만 할 수 있습니다. 권한 담당 관리자에게 요청합니다.
개인 토큰 추가 부여에서 대상 사용자를 골랐는데 "대상 사용자를 찾을 수 없습니다."가 나옵니다.배포의 사번 디렉터리 연결추가 부여는 대상을 사번으로 확인합니다. 사번 디렉터리(인사 원장)가 연결되지 않은 배포에서는 부여할 수 없습니다. 운영 담당에게 연결을 요청하거나, 그동안은 월 한도를 조정합니다. 실패한 시도는 감사 로그에 실패로 남습니다.
상태가 판정 불가로 나옵니다.그 사용자의 사용량 집계사용량을 집계하지 못한 사용자에게 붙습니다. 잠시 뒤 다시 확인하고, 계속되면 플랫폼 운영 담당에게 알립니다.
LLM 토큰 사용량의 합계가 사용자별 통계와 다릅니다.두 화면의 집계 범위LLM 토큰 사용량은 LLM 관문이 받은 요청 중 성공한 것만 합산하고, 기간 버튼(최근 7일·14일·30일)을 기준으로 합니다. 사용자별 통계와 대시보드는 Builder 실행 기록 기준이고, 토큰 사용량 탭의 토큰 현황은 이번 달 누적이며 화면 위 워크스페이스·기간 필터를 쓰지 않습니다. 기준이 달라 숫자가 같지 않을 수 있으니 보고서에는 기준을 함께 적습니다.
LLM 토큰 사용량의 모든 구역에 "정보를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요."가 나옵니다.LLM 관문 연결LLM 관문(DeepGateway)이 연결되지 않은 배포입니다. 대시보드와 사용자별 통계의 토큰(Builder 실행 기준)은 그대로 볼 수 있습니다. 요청 단위 기록이 필요하면 운영 담당에게 연결을 요청합니다.
에이전트·워크스페이스별 사용량이 비어 있습니다.안내 문구Builder가 에이전트·워크스페이스·실행 식별값을 함께 보낸 요청만 집계합니다. 식별값을 보내지 않는 버전에서 들어온 요청은 일별·사용자별·모델별 탭에만 나옵니다.
CSV 내보내기에서 기간을 길게 잡으면 오류가 납니다.내보내기 시작일과 종료일한 번에 최대 92일까지 내보낼 수 있습니다. 분기(92일 이내)는 한 번에, 반기 이상은 나누어 내보냅니다.
내보낸 CSV 파일(.csv)의 행이 중간에 끊깁니다.내보내기 화면의 잘림 안내행 수 상한을 넘으면 잘립니다. 사용자 ID나 기간 조건을 좁혀 여러 번 내보냅니다.

에이전트 배포 심사​

증상먼저 볼 곳조치
직원이 공유 요청을 했다는데 배포 요청 심사에 없습니다.상태 필터와 검색어전체 상태로 바꾸고 에이전트명이나 요청자 이름으로 다시 찾습니다. 직원 쪽에서 요청을 취소하면 취소됨으로 남습니다.
반려를 누르면 진행되지 않습니다.심사 패널의 사유 입력란반려할 때는 사유를 꼭 적어야 합니다. 승인할 때 사유는 선택입니다.
배포된 에이전트를 잠시 내리고 싶습니다.배포된 에이전트 탭의 관리 버튼비공개로 전환을 씁니다. 삭제는 배포 회차 기록까지 지우고 되돌릴 수 없습니다.

기록 조회​

증상먼저 볼 곳조치
어떤 관리자가 어떤 화면을 열었는지 찾고 싶습니다.관리자 접근기록사번, 결과, 메뉴(화면 경로), 기간으로 검색합니다. 요청 본문은 저장하지 않으므로 무엇을 바꿨는지는 해당 화면의 변경 이력(예: 토큰 한도 변경 이력, 권한 이력)에서 확인합니다.
실행 로그를 파일로 받고 싶습니다.에이전트 실행 로그 화면현재 화면에는 실행 로그 다운로드 버튼이 없습니다. 토큰과 요청 단위 기록이 필요하면 LLM 토큰 사용량의 CSV 내보내기를 씁니다.
에러 원인을 직원에게 설명해야 합니다.에러/장애 모니터링의 에러 유형 안내에러 유형마다 무슨 일이 있었는지와 이렇게 해 보라는 안내가 있습니다. 해당 로그 행을 펼쳐 원인과 권장 조치를 함께 전달합니다.
