Deep Admin 실습 2: 권한

경영지원팀 윤지원 사원이 매월 관리자 작업을 점검하는 감사 업무를 맡게 되었습니다. 감사 로그는 봐야 하지만 권한·키·한도를 바꿀 수 있어서는 안 됩니다. 이 실습에서는 "운영 감사 담당" RBAC 그룹을 새로 만들어 조회 권한 다섯 가지만 체크하고, 윤지원 사원에게 배정합니다. 화면 전체 설명은 권한 관리에 있습니다.

이 페이지에서 할 수 있는 일

  • 새 RBAC 그룹을 만듭니다.
  • 권한 카테고리를 펼쳐 필요한 권한만 체크합니다.
  • 그룹을 직원에게 배정하고 결과를 확인합니다.

목표​

항목내용
만들 것RBAC 그룹 "운영 감사 담당"(관리 화면 진입 2개 + 감사 로그·대시보드·LLM 토큰 사용량 조회)
결과물윤지원 사원의 RBAC 그룹 열에 "운영 감사 담당"
걸리는 시간10분
난이도★★☆☆☆

준비물​

준비물내용
관리자 계정권한 관리(그룹 만들기·권한 부여) 권한이 있는 계정
배정할 직원한 번 로그인한 직원(예시: 경영지원팀 윤지원 사원)
정할 것새 그룹에 줄 권한 목록. 아래 표처럼 "꼭 필요한 것만"으로 정합니다.
권한카테고리줄까?이유
관리자 화면 접근관리자 진입줌없으면 통합 어드민에 들어올 수 없습니다.
DeepAgentBuilder 어드민 접근관리자 · 진입줌Agent Builder 관리 메뉴를 열기 위해 필요합니다.
감사 로그 조회관리자 운영 모니터링줌감사 업무의 핵심입니다.
대시보드 조회관리자 · 운영 모니터링줌운영 상태를 함께 봅니다.
LLM 토큰 사용량 조회관리자 사용자줌비용 점검에 씁니다. 본문 열람 권한은 주지 않습니다.
권한·키·한도 변경관리자 · 권한, 관리자 키·접근 통제 등주지 않음감사 담당이 직접 바꾸면 감사가 성립하지 않습니다.

화면에는 "관리자 진입"과 "관리자 · 진입"처럼 이름이 비슷한 카테고리가 따로 있습니다. 위 표의 카테고리 이름을 가운뎃점까지 그대로 맞춰 찾습니다.

1단계. 새 RBAC 그룹 만들기​

사이드바 접근 권한 > 권한을 누르고 RBAC 탭에서 그룹 추가를 누릅니다.

새 RBAC 그룹 만들기

번호메뉴입력할 값
1그룹 이름운영 감사 담당
2설명 (선택)감사 로그·대시보드·LLM 토큰 사용량 조회 (변경 권한 없음)
3만들기누르면 그룹 목록에 새 그룹이 생깁니다(권한 0개).
설정 항목이 실습의 값기본값
그룹 이름운영 감사 담당비움(필수)
설명위와 같음비움
기본 그룹끔끔. 켜면 새 사용자가 이 그룹에 자동으로 들어가므로 감사 그룹에는 켜지 않습니다.

2단계. 권한 체크하기​

그룹 목록에서 "운영 감사 담당"을 고르면 오른쪽에 권한 카테고리가 열립니다. 그룹이 많으면 위 그룹·권한 검색에 "운영 감사"를 적어 찾습니다. 카테고리 줄을 누르면 펼쳐지고, 안의 권한을 체크하면 저장 버튼 없이 즉시 반영됩니다.

권한 체크

번호메뉴할 일
1감사 로그 조회관리자 운영 모니터링을 펼쳐 체크합니다. 카테고리 오른쪽 숫자가 1/2로 바뀝니다.

체크하기 전에 위쪽 그룹 이름이 "운영 감사 담당"인지 확인합니다. 이름 옆에 활성 배지, 기본 그룹 스위치, 멤버 수, 권한 수가 있습니다.

같은 방법으로 관리자 진입의 관리자 화면 접근, 관리자 · 진입의 DeepAgentBuilder 어드민 접근, 관리자 · 운영 모니터링의 대시보드 조회, 관리자 사용자의 LLM 토큰 사용량 조회를 체크합니다. 권한 이름이 기억나지 않으면 위 검색 칸에 "조회"처럼 적어 찾습니다. 카테고리 체크 칸이 꽉 차면 그 안 권한이 모두 켜진 것이고, 까만 사각형이면 일부만 켜진 것입니다.

3단계. 윤지원 사원에게 배정하기​

사용자·승인 > 사용자에서 "윤지원"을 찾아 행 메뉴의 RBAC 그룹을 엽니다.

운영 감사 담당 배정

번호메뉴할 일
1그룹 검색"운영"을 적어 목록을 좁힙니다.
2운영 감사 담당체크합니다. 즉시 저장됩니다. 윤지원 사원은 기존에 "운영 조회 담당"이 있어 두 그룹의 권한을 함께 가집니다.
3닫기창을 닫습니다.

결과​

배정 결과

번호확인 위치기대 결과
1RBAC 그룹 열사용자, 운영 조회 담당, 운영 감사 담당
확인 위치기대 결과
권한 > RBAC > 운영 감사 담당멤버 1명, 권한 5개
윤지원 사원으로 통합 어드민 로그인사이드바에 권한이 있는 메뉴만 보이고, 감사 로그 주소를 열 수 있음
감사 로그RBAC 그룹 만들기, 권한 부여 5건, 그룹 배정 기록

흔한 실수​

실수증상바로잡기
관리자 화면 접근을 빠뜨림윤지원 사원이 로그인하면 "접근 권한이 없습니다"와 "관리자 접근 권한이 필요합니다."관리자 진입 카테고리의 권한을 체크합니다.
카테고리 전체를 체크필요 없는 권한(변경 권한 포함)까지 켜짐카테고리를 펼쳐 필요한 것만 남기고 풉니다.
기본 그룹을 켬새로 가입하는 모든 직원이 감사 그룹에 들어감스위치를 끕니다.
시스템 그룹을 고치려 함시스템 그룹은 삭제할 수 없고 자동 배정됨이번처럼 새 그룹을 만들어 씁니다.
바꾼 뒤 직원 화면이 그대로메뉴가 안 바뀜직원에게 새로 고침하거나 다시 로그인해 달라고 합니다.

응용 과제​

  1. ABAC 탭에서 리소스 타입이 "모델"인 "고성능 모델 사용" 그룹을 만들고, 리소스 > 모델에서 GPT-4.1에 일괄 ABAC로 지정해 보세요. 그 뒤 일반 직원 화면에서 모델 목록이 어떻게 바뀌는지 확인합니다.
  2. WBAC 탭에서 "문서 담당자" 그룹의 권한 카테고리를 열어, "사용자" 그룹과 무엇이 다른지 표로 정리해 보세요.
  3. 실습이 끝났다면 "운영 감사 담당" 그룹에서 윤지원 사원을 빼고, 실습 5에서 그 기록을 찾아보세요.
