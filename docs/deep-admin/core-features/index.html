Deep Admin 메뉴 안내

Deep Admin의 모든 관리 메뉴를 사이드바 묶음 순서대로 정리했습니다. 메뉴마다 무엇을 하는 화면인지, 언제 여는지, 자세한 설명이 어느 페이지에 있는지 한 줄로 찾을 수 있습니다.

이 페이지에서 할 수 있는 일

  • Agent Builder 관리 메뉴 여덟 묶음의 쓰임을 확인합니다.
  • Deep Connector와 Deep Work 관리 화면의 메뉴 구성을 확인합니다.
  • 지금 하려는 일에 맞는 메뉴를 고릅니다.

메뉴가 보이는 규칙​

사이드바에는 로그인한 관리자가 쓸 수 있는 메뉴만 나옵니다. 같은 Deep Admin이라도 관리자마다 사이드바가 다르게 보일 수 있습니다.

  • Agent Builder 관리 메뉴는 권한이 없으면 항목이 숨겨집니다. 한 묶음의 항목이 모두 숨겨지면 묶음 제목도 사라집니다.
  • Deep Connector와 Deep Work 관리 메뉴는 권한이 없으면 흐리게 표시되고, 마우스를 올리면 "접근 권한이 없습니다"가 나옵니다.
  • 인프라 모니터링처럼 "도입 예정"이라고 나오는 메뉴는 아직 열 수 없습니다.
  • 대시보드 권한이 없는 관리자가 처음 화면으로 들어오면 열 수 있는 첫 메뉴로 이동합니다.

관리자 권한 그룹은 권한 관리에서 정합니다.

운영 현황​

메뉴하는 일이런 때 여세요
대시보드사용자 수, 에이전트 수, 토큰 사용량, 실행 추이를 한 화면에 요약합니다. 탭은 운영 요약, 사용자 통계, 에이전트 통계, 시스템입니다.아침에 서비스 상태를 훑어볼 때
에이전트 실행 로그모든 에이전트 실행을 사용자, 워크스페이스, 유형, 상태, 기간으로 찾아봅니다. 행을 누르면 실행 타임라인과 도구·지식 호출, 입력과 답변을 봅니다.직원이 "답변이 이상했다"고 알려 왔을 때
에이전트 생성 로그에이전트 등록·수정 이력을 봅니다.누가 언제 에이전트를 바꿨는지 찾을 때
에러/장애 모니터링실행 수, 오류 수, 에러율, 실행 시간을 보고 최근 에러 로그의 원인과 권장 조치를 확인합니다.오류 문의가 몰렸을 때
관리자 접근기록관리 화면에서 관리자가 보낸 요청을 한 건씩 기록한 목록입니다. 성공, 권한 거부, 실패를 모두 남깁니다.관리 화면 사용 내역을 감사할 때
인프라 모니터링도입 예정 메뉴입니다.—

자세한 내용: 시작하기의 대시보드, 모니터링과 감사 기록

사용자·승인​

메뉴하는 일이런 때 여세요
사용자플랫폼 사용자를 이름, 사번, 워크스페이스, 권한 그룹으로 찾고 상세 정보와 권한 그룹(RBAC 그룹)을 관리합니다.신규 입사자에게 역할을 줄 때
사용자별 통계사용자별 실행 수, 에러율, 응답 시간, 토큰 사용량과 한도 사용률을 봅니다.많이 쓰는 사람과 한도에 가까운 사람을 찾을 때
토큰 한도 설정전 사용자 공통 월 토큰 한도를 정하고, 개인에게 이번 달 추가 토큰을 부여합니다.한도 초과 문의를 처리할 때
LLM 토큰 사용량Builder 에이전트의 LLM 토큰을 날짜·사용자·모델·에이전트·워크스페이스별로 집계하고 CSV 파일(.csv)로 내보냅니다.월별 사용량 리포트를 만들 때
승인 관리도구, 모델, 스킬, 미들웨어 등록·수정 요청을 승인하거나 거부합니다.리소스 등록 요청이 올라왔을 때

자세한 내용: 사용자와 워크스페이스, 토큰 사용량과 한도

접근 권한​

메뉴하는 일이런 때 여세요
권한플랫폼 전체 권한(RBAC), 워크스페이스 권한(WBAC), 리소스 단위 권한(ABAC) 그룹을 만들고 권한 항목을 체크합니다.새 역할을 만들거나 역할의 권한을 바꿀 때
사용자별 도구 권한사람을 골라 도구 사용 권한을 기한을 정해 부여하거나 회수합니다. 여러 사람에게 한꺼번에 배정할 수도 있습니다.특정 직원에게 외부 연동 도구를 열어 줄 때
사용자별 지식 권한사람별로 가진 지식 컬렉션 권한을 폴더 구조로 봅니다. 조회 전용입니다.한 직원이 볼 수 있는 지식 범위를 확인할 때
지식 컬렉션 권한컬렉션을 골라 접근 사용자를 추가하거나 회수합니다. 사용 기한을 정할 수 있습니다.사내 규정 컬렉션을 특정 부서에만 열 때

자세한 내용: 권한 관리

워크스페이스​

메뉴하는 일이런 때 여세요
워크스페이스 목록운영 중인 워크스페이스를 이름과 ID로 찾습니다.워크스페이스 ID를 확인할 때
워크스페이스 설정워크스페이스 구성원과 구성원별 워크스페이스 권한 그룹(WBAC 그룹)을 정합니다.구성원의 워크스페이스 내 역할을 바꿀 때
워크스페이스 템플릿워크스페이스 구성원이 새로 시작할 때 쓰는 에이전트 템플릿을 등록하거나 해제합니다.부서 공용 에이전트를 템플릿으로 제공할 때
사용량 관리워크스페이스별 실행 수, 에러율, 활성 사용자 수, 상위 사용자를 봅니다.부서 워크스페이스의 활용도를 볼 때

자세한 내용: 사용자와 워크스페이스

에이전트​

메뉴하는 일이런 때 여세요
전체 에이전트직원이 전체 에이전트(커뮤니티)에 공유해 달라고 요청한 에이전트를 심사하고, 배포된 에이전트의 공개 상태와 활용 현황을 관리합니다.공유 요청을 승인할 때, 쓰지 않는 공유 에이전트를 내릴 때

자세한 내용: 전체 에이전트와 배포 심사

리소스​

메뉴하는 일이런 때 여세요
도구워크스페이스에 배포된 도구를 보고, HTTP 요청 서버나 원격 MCP 같은 도구를 추가합니다.사내 시스템을 도구로 연결할 때
모델워크스페이스별로 등록된 모델과 리소스 권한(ABAC)을 보고, 구성원의 기본 모델을 지정합니다.새 모델을 부서에 열거나 기본 모델을 바꿀 때
미들웨어에이전트 실행 전후에 붙는 미들웨어 목록과 사용 범위를 봅니다.미들웨어 사용 범위를 정할 때
스킬전사 스킬과 배포 이력, 활용 현황을 봅니다.스킬이 어떤 에이전트에서 쓰이는지 볼 때
지식지식 컬렉션별로 그 컬렉션을 쓰는 전체·개인 에이전트 수를 봅니다.컬렉션을 정리하기 전에 영향 범위를 볼 때

자세한 내용: 모델과 리소스

툴박스 레지스트리와 시크릿·키​

메뉴하는 일이런 때 여세요
Toolbox도구와 모델의 원본을 등록하고 워크스페이스에 할당합니다. 모델 추가는 여기서 합니다.새 LLM을 플랫폼에 들일 때
도메인 허용 목록도구가 호출할 수 있는 외부·내부 주소를 관리합니다.새 사내 시스템 주소를 도구가 써야 할 때
워크스페이스(시크릿)워크스페이스별 시크릿(키와 값)을 등록합니다. 값은 가려서 보입니다.도구가 쓸 인증 키를 넣을 때
마스터키여러 워크스페이스에 나눠 쓸 원본 키를 등록합니다. CSV 파일(.csv)로 한꺼번에 올릴 수 있습니다.공용 키를 한곳에서 관리할 때
API 토큰워크스페이스의 API 토큰을 발급하고 폐기합니다.외부 시스템이 에이전트를 호출해야 할 때
외부 접근 키외부 시스템이 지식함을 직접 호출할 때 쓰는 키를 발급하고 폐기합니다.사내 포털이 지식 검색을 쓰려 할 때

자세한 내용: 모델과 리소스

Deep Connector와 Deep Work 관리 화면​

사이드바 맨 위 관리 화면 선택에서 제품을 바꾸면 그 제품의 관리 메뉴가 나옵니다. 각 화면의 자세한 사용법은 해당 제품 매뉴얼을 함께 보세요.

제품묶음메뉴
Deep Connector관리자적재 현황(문서 적재 상태와 통계, CSV 파일(.csv) 내보내기)
Deep Connector사용자와 팀스페이스사용자(로그인한 사용자 계정 켜기·끄기)
Deep Connector검색과 AI사전, 전사 용어사전, 메타데이터 관리, LLM 커넥션, MCP 도구
Deep Connector시스템감사 로그, 브랜드 설정, PII 볼트
Deep WorkDeep Work대시보드, 사용량, 사용자, 운영 현황, 모델 관리, 요청 로그, 실행 정책, 앱 원격 설정
Deep Work감사Desktop 감사 로그, 관리자 변경 이력, 사용자 접속기록, 관리자 접근기록
Deep Work권한권한(RBAC 그룹에 Deep Work 관리 권한 할당)

사전과 전사 용어사전은 CSV 파일(.csv)과 엑셀 파일(.xlsx)로 일괄 등록할 수 있고, 메타데이터 값은 JSON 파일(.json)로 올리고 내보냅니다. Deep Work 사용량을 CSV 파일(.csv)로 받으려면 Agent Builder 관리 화면의 LLM 토큰 사용량에서 내보내기 제품을 Deep Work로 고릅니다.
