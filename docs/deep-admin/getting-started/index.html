Deep Admin 시작하기

이 페이지는 플랫폼 관리자가 Deep Admin에 처음 로그인해 대시보드를 읽고, 사이드바에서 필요한 메뉴를 찾는 방법을 안내합니다. 예시는 브레인크루 AI혁신팀의 플랫폼 관리자 강혁신 팀장 계정입니다.

이 페이지에서 할 수 있는 일

  • 관리자 계정으로 Deep Admin에 로그인합니다.
  • 사이드바 메뉴 묶음과 관리 화면 선택을 보고, 지금 할 일이 어느 메뉴에 있는지 찾습니다.
  • 대시보드의 네 탭에서 사용자 수, 에이전트 실행, 토큰 사용량, 오류율을 확인합니다.
  • 사용자 메뉴에서 설정을 열거나 로그아웃합니다.

준비할 것​

항목내용
계정관리자 권한이 있는 권한 그룹(예: 관리자)에 배정된 계정. 일반 직원 계정으로는 들어올 수 없습니다.
브라우저최신 Chrome 또는 Edge. 표가 넓은 화면이 많아 가로 1,400픽셀 이상의 창을 권장합니다.
주소플랫폼 운영 담당이 알려 준 Deep Admin 주소

로그인​

Deep Admin 주소로 접속하면 로그인 화면으로 이동합니다. Deep Agent Builder와 같은 로그인 화면을 쓰므로, 이미 Deep Agent Builder에 로그인해 있다면 바로 대시보드가 열립니다.

로그인 화면

번호항목기능이런 때 사용하세요
1이메일 입력란관리자 계정의 이메일을 입력합니다.처음 Deep Admin에 접속할 때
2비밀번호 입력란비밀번호를 입력합니다.이메일 다음 칸에 비밀번호를 적을 때
3로그인입력한 계정으로 로그인합니다. 성공하면 Deep Admin이 열립니다.두 칸을 모두 채웠을 때

로그인했는데 "접근 권한이 없습니다"와 "관리자 접근 권한이 필요합니다."가 보이면, 그 계정에 관리자 권한이 없는 것입니다. 로그아웃을 누르고 관리자 계정으로 다시 로그인하거나, 다른 관리자에게 권한 그룹 배정을 요청합니다.

관리자 권한이 없는 계정의 안내 화면

번호항목화면에 보이는 내용이런 때 확인하세요
1안내 제목"접근 권한이 없습니다"와 함께 관리자 접근 권한이 필요하다는 안내가 나옵니다.일반 직원 계정으로 들어온 것은 아닌지 볼 때
2로그아웃지금 계정에서 나가 로그인 화면으로 돌아갑니다.관리자 계정으로 바꿔 들어갈 때

따라 해 보기​

  1. Deep Admin 주소를 엽니다.
  2. 관리자 계정의 이메일과 비밀번호를 입력하고 로그인합니다.
  3. 왼쪽 위에 "Admin"과 "Agent Builder"가 보이는 화면이 열리는지 확인합니다.

화면 구성: 사이드바와 관리 화면 선택​

로그인하면 왼쪽에 사이드바, 오른쪽에 선택한 메뉴의 화면이 열립니다.

Deep Admin 기본 화면 구성

번호항목기능이런 때 사용하세요
1관리 화면 선택(Admin, Agent Builder)관리할 제품을 Agent Builder, Deep Connector, Deep Work 중에서 고릅니다.Deep Connector 문서 적재 현황이나 Deep Work 사용량을 보러 갈 때
2사이드바 접기사이드바를 아이콘만 남기고 접거나 다시 폅니다.열이 많은 표를 넓게 볼 때
3메뉴 묶음 제목(예: 사용자·승인)메뉴가 운영 현황, 사용자·승인, 접근 권한, 워크스페이스, 에이전트, 리소스, 툴박스 레지스트리, 시크릿·키 순서로 묶여 있습니다. 권한이 없는 메뉴는 보이지 않습니다.다른 관리 화면으로 옮겨 갈 때
4사용자 영역로그인한 관리자 이름과 "슈퍼유저" 또는 "관리자" 표시가 보입니다. 누르면 사용자 메뉴가 열립니다.설정을 열거나 로그아웃할 때

화면 오른쪽 위 해 모양 아이콘(테마 변경)으로 라이트, 다크, 시스템 설정 중 화면 테마를 고를 수 있습니다.

관리 화면 선택을 누르면 관리할 수 있는 제품 목록이 열립니다. 지금 보고 있는 제품에는 체크 표시가 붙고, 관리 권한이 없는 제품은 목록에 나오지 않습니다.

관리 화면 선택 목록

번호항목기능이런 때 사용하세요
1DeepAgentBuilder에이전트, 사용자, 권한, 리소스, 사용량을 관리하는 기본 관리 화면입니다.대부분의 관리 업무
2DeepConnector문서 적재 현황, 사전, 용어사전, 개인정보 보관 등 Deep Connector 관리 메뉴로 바뀝니다.문서 적재 실패를 확인할 때
3DeepWorkDeep Work 사용자, 모델, 사용량, 실행 정책 관리 메뉴로 바뀝니다.Deep Work 사용자 한도를 볼 때

대시보드: 운영 요약​

사이드바 운영 현황 > 대시보드를 누르면 "Deep Agent Builder 관리 대시보드"가 열립니다. 월요일 아침에 지난주 사용량을 훑거나, 월말에 회사 전체 토큰 사용량을 볼 때 먼저 여는 화면입니다.

대시보드 운영 요약 탭

번호항목기능이런 때 사용하세요
1워크스페이스 선택숫자를 볼 범위를 고릅니다. 기본값은 전체 워크스페이스입니다.회사 전체 사용량을 볼 때
2기간 단축 버튼(예: 30일)오늘, 7일, 30일, 전체 중 하나로 조회 기간을 정합니다. 왼쪽 날짜 칸으로 직접 지정할 수도 있습니다.주간 회의 전에 최근 7일을 볼 때
3총 토큰기간 안에 쓴 토큰 합계와 실행 횟수를 보여 줍니다. 옆 카드에 입력 토큰과 출력 토큰이 있습니다.월간 모델 사용량을 보고서에 옮길 때
4전체 실행 로그빠른 작업의 바로가기로, 에이전트 실행 로그 화면을 엽니다. 옆의 시스템 모니터링은 에러/장애 모니터링을 엽니다.숫자가 평소와 달라 실행 기록을 바로 보고 싶을 때

같은 탭 위쪽에는 전체 사용자, 전체 에이전트, 신규 에이전트 (기간 내), 워크스페이스 수 같은 규모 지표가, 아래쪽에는 실행 횟수를 전체·성공·오류로 나눈 실행 추이 그래프가 있습니다. 탭은 운영 요약, 사용자 통계, 에이전트 통계, 시스템 네 가지입니다.

따라 해 보기​

  1. 대시보드에서 7일을 누릅니다.
  2. 총 토큰과 그 아래 실행 횟수를 확인합니다.
  3. 실행 추이에서 오류가 몰린 날이 있으면 전체 실행 로그를 눌러 그날 실행 기록을 엽니다.

대시보드: 사용자 통계·에이전트 통계·시스템 탭​

나머지 세 탭은 같은 조회 기간을 씁니다.

탭보여 주는 내용이런 때 사용하세요
사용자 통계실행 횟수가 많은 사용자 목록(팀명, 이름, 사번, 실행 횟수, 오류 횟수)과 전체 통계 보기 링크많이 쓰는 직원과 오류가 잦은 직원을 찾을 때
에이전트 통계최근 1시간·24시간·7일·30일 실행 수, 성공과 에러 건수, 최근 에이전트 생성 에러, 최근 실행 기록 10건최근 실행이 정상인지 빠르게 볼 때
시스템1시간·24시간·조회 기간의 오류율, 중간값과 상위 1% 응답 시간, 에러 유형별 건수응답이 느려졌다는 문의를 받았을 때

대시보드 에이전트 통계 탭

번호항목화면에 보이는 내용이런 때 확인하세요
1에이전트 통계 탭에이전트 실행 현황을 모아 봅니다.최근 실행이 정상인지 빠르게 볼 때
2실행 (30일)최근 30일 실행 횟수입니다. 옆에 1시간, 24시간, 7일 실행 수도 있습니다.오늘 사용량이 평소와 비슷한지 볼 때
3에러전체 실행 가운데 에러로 끝난 건수입니다.에러 비율이 늘었는지 볼 때
4최근 실행 기록의 상태 열최근 10건의 실행 결과(success 등)입니다. 같은 표에 에이전트명, 사용자, 워크스페이스, 작업 유형, 실행 시간, 소요 시간이 나옵니다.방금 직원이 실행한 기록을 찾을 때

사용자 메뉴와 설정​

사이드바 맨 아래 사용자 영역을 누르면 설정과 로그아웃이 나옵니다. 설정에서는 로그인한 계정의 이름, 이메일, 권한(슈퍼유저 또는 관리자)을 확인하고 화면 테마를 고릅니다.

사이드바 사용자 메뉴

번호항목기능이런 때 사용하세요
1설정프로필(이름, 사번, 이메일, 권한)과 테마를 봅니다.지금 어떤 계정으로 들어와 있는지 확인할 때
2로그아웃Deep Admin에서 나갑니다.자리를 비우거나 계정을 바꿀 때

팁: Deep Admin과 Deep Agent Builder는 같은 로그인을 씁니다. 같은 브라우저에서 직원 계정으로 Deep Agent Builder에 로그인하면 Deep Admin도 그 계정으로 바뀝니다. 직원 화면을 확인할 때는 다른 브라우저나 시크릿 창을 쓰세요.
