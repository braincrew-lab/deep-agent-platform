Deep Admin에서 Deep Connector 관리하기

Deep Admin 사이드바 맨 위 관리 화면 선택에서 DeepConnector를 고르면 사이드바가 Deep Connector 관리 메뉴로 바뀝니다. 문서 적재 상태, 검색 사전과 전사 용어사전, 메타데이터, LLM 커넥션과 MCP 도구, 감사 로그, 브랜드, 개인정보(PII) 볼트를 통합 어드민 안에서 관리합니다. Deep Connector 화면 자체의 관리자 메뉴는 Deep Connector 매뉴얼의 관리자 장에 있고, 이 페이지는 통합 어드민 쪽 메뉴를 설명합니다.

이 페이지에서 할 수 있는 일

  • Deep Connector 관리 메뉴 네 묶음의 쓰임을 확인합니다.
  • 문서 적재 실패를 기간·사유별로 찾습니다.
  • 검색 사전, 전사 용어사전, 메타데이터 값을 고치거나 파일로 한꺼번에 올립니다.
  • 감사 로그와 PII 볼트로 관리 작업과 개인정보 복원 기록을 확인합니다.

메뉴 구성​

묶음메뉴하는 일
관리자적재 현황문서 적재 성공·실패·진행 상태와 실패 사유
사용자와 팀스페이스사용자Deep Connector에 로그인한 사용자를 보고 계정을 켜거나 끕니다. 이메일로는 찾을 수 없고 이름이나 사용자 ID로 찾습니다.
검색과 AI사전검색이 대표어와 별칭을 맞춰 보는 사전
검색과 AI전사 용어사전포털과 함께 쓰는 회사 용어(용어명·약어·유의어·정의·분류)
검색과 AI메타데이터 관리문서·청크 메타데이터 필드와 값, 필드끼리의 관계
검색과 AILLM 커넥션Deep Connector가 쓰는 LLM 연결과 연결 상태
검색과 AIMCP 도구MCP 클라이언트에 보이는 도구 설명과 Deep Agent Builder(DAB) 등록 여부
시스템감사 로그관리 기능 호출 기록과 문서 변경 이력
시스템브랜드 설정Deep Connector 화면의 제품명·회사명·설명 문구·색
시스템PII 볼트문서에서 가려 둔 개인정보 원문의 복원·파기와 그 기록

권한이 없는 메뉴는 흐리게 보이고, 마우스를 올리면 "접근 권한이 없습니다"가 나옵니다.

적재 현황​

적재 현황

번호항목기능이런 때 사용하세요
1기간 버튼(예: 24시간)1시간, 6시간, 24시간, 7일, 30일, 직접 지정, 기간 무관 중에서 고릅니다. 옆 기준 시각과 새로고침으로 다시 셉니다.오늘 아침 올린 문서만 볼 때
2적재 실패실패 건수와 실패율입니다. 옆 카드에 적재 중(그중 멈춤), 완료(완료율), 전체(시도 횟수)가 있습니다.실패가 늘었는지 볼 때
3실패 사유별통계 구역의 탭입니다. 시작 시각별 추이, 실패 사유별, 컬렉션별 실패 상위 10을 봅니다. 출처(예: 파서), 로그 텍스트, 건수가 나옵니다. 예시의 2건은 파서가 엑셀 97-2003 파일(.xls)을 지원하지 않아 실패한 것입니다.같은 원인으로 실패한 문서를 묶어 볼 때
4목록의 상태 열문서마다 적재 상태입니다. 위 필터(상태, 컬렉션, 업로더, 파이프라인, 확장자)와 파일명 검색으로 좁히고, CSV 내보내기로 목록을 CSV 파일(.csv)로 받습니다.실패한 문서를 올린 사람에게 알릴 때

사전과 전사 용어사전​

사전 목록

번호항목기능이런 때 사용하세요
1업로드 양식 내려받기파일 적재용 양식을 받습니다.항목을 엑셀로 정리해 올리려 할 때
2사전 추가새 사전을 만듭니다.부서 전용 용어 사전을 만들 때
3검색 사용 열검색에 이 사전을 쓰는지 보여 줍니다. 같은 표에 종류(사용자 정의·표준), 항목 수, 버전, 수정 시각이 있습니다.어떤 사전이 검색에 들어가는지 볼 때
4편집사전 항목을 고치거나 파일 적재로 CSV 파일(.csv)·엑셀 파일(.xlsx) 항목을 한꺼번에 넣습니다.별칭을 한꺼번에 더할 때

파일 적재는 두 방식이 있습니다. 하나는 파일에 없는 기존 항목을 지우고 파일 내용으로 바꾸는 방식, 다른 하나는 파일 항목을 더하거나 고치고 나머지는 그대로 두는 방식입니다. 미리보기로 바뀔 내용을 확인한 뒤 적용합니다. "전사 용어사전" 원장 사전의 항목은 전사 용어사전 화면에서만 고칩니다.

전사 용어사전

번호항목기능이런 때 사용하세요
1분류 코드표 탭용어 분류(대·중·소분류) 코드표입니다. 첫 시트에 계층·코드·코드명 열이 있는 엑셀 파일(.xlsx, 20MB까지)로 코드표 전체를 바꿉니다. 미리보기가 없으니 주의합니다.분류 체계를 바꿀 때
2용어 등록용어 하나를 등록합니다. 용어명·약어·유의어는 검색 키가 됩니다.새 용어가 생겼을 때
3파일 일괄 등록CSV 파일(.csv)이나 엑셀 파일(.xlsx)로 용어를 한꺼번에 등록하거나 고칩니다. 용어명이 같으면 고치고 없으면 새로 등록합니다.부서에서 정리한 용어집을 넣을 때
4약어 열예시: 법인카드 → 법카. 같은 표에 정의, 분류, 사용 여부, 최종 변경이 있습니다.약어로 검색해도 찾히는지 볼 때

메타데이터 관리​

메타데이터 관리

번호항목기능이런 때 사용하세요
1필드 검색키, 라벨, 경로로 필드를 찾습니다. 위 탭은 필드와 관계, 아래 필터는 범위(문서·청크)와 컬렉션입니다.keywords 같은 필드를 찾을 때
2선택한 필드 정보(경로)고른 필드의 키, 경로, 범위·타입, 컬렉션 수, 등록 값 수, 개정 번호입니다. 편집과 비활성화가 옆에 있습니다.필드가 어디에 쓰이는지 볼 때
3JSON 업로드값 목록을 JSON 파일(.json)로 올립니다. 옆 값 등록은 하나씩 넣습니다.값 표준을 한꺼번에 맞출 때
4내보내기값 목록을 JSON 파일(.json)로 받습니다.값 목록을 검토용으로 받을 때

값 표에는 값, 라벨, 속성, 문서 수, 유닛 수, 상태가 나옵니다. 관계 탭은 필드끼리의 조합(튜플)을 JSON으로 올려 관리합니다.

LLM 커넥션과 MCP 도구​

메뉴화면에서 하는 일알아 둘 점
LLM 커넥션새 커넥션으로 Deep Connector가 쓸 LLM 연결을 등록하고 연결 상태를 확인합니다.통합 어드민이 Deep Connector에 접속하는 계정에 커넥션 관리 권한이 없으면 "연동 서비스가 요청을 거부했습니다. 관리자에게 문의해 주세요."가 나옵니다. 이때는 Deep Connector 화면의 관리자 메뉴에서 관리합니다.
MCP 도구도구마다 MCP 클라이언트에 보일 설명을 고치고, Deep Agent Builder 지식 도구로 등록할지(DAB 등록) 정합니다. 바꾼 뒤 수정 반영을 눌러야 적용됩니다.위쪽 DAB 연동 상태가 "설정 안 됨"이면 DAB 등록과 DAB 표시 설명을 바꿀 수 없습니다. 쓰기 도구는 DAB 등록 대상이 아닙니다.

감사 로그와 브랜드 설정​

Deep Connector 감사 로그

번호항목기능이런 때 사용하세요
1문서 변경 이력 탭문서 추가·수정·삭제 기록입니다. 옆 감사 로그 탭은 관리 API 호출 기록입니다.누가 문서를 지웠는지 찾을 때
2모든 분류분류로 거릅니다. 옆에 요청 방식 필터와 기간(오늘·7일·30일·전체)이 있습니다.특정 작업만 볼 때
3작업 내용 열무엇을 했는지입니다. 같은 표에 시각, 사용자, IP 주소·User-Agent, 요청 방식, 분류, 대상, 경로, 상태, 소요 시간이 있고 상세로 자세히 봅니다.호출 하나를 자세히 볼 때

브랜드 설정

번호항목기능이런 때 사용하세요
1초안 저장제품명(100자), 회사명(100자), 설명 문구(500자), 주 색상과 글자색을 초안으로 저장합니다. 비운 칸은 기본값을 씁니다.화면 문구를 회사에 맞게 바꿀 때
2발행저장한 초안을 사용자 화면에 반영합니다. 발행 전에는 바뀌지 않습니다.검토가 끝난 뒤
3발행된 설정지금 사용자 화면에 적용된 값입니다. 옆에 현재 버전, 마지막 저장, 마지막 발행이 있습니다.무엇이 적용 중인지 볼 때

PII 볼트​

문서를 적재할 때 이름, 전화번호 같은 개인정보를 토큰으로 가려 둔 경우, 원문은 PII 볼트에 따로 보관됩니다.

PII 볼트

번호항목기능이런 때 사용하세요
1탭(토큰 복원, 항목 파기, 감사 로그)복원, 파기, 기록 보기를 바꿉니다.할 일에 맞는 탭을 고를 때
2토큰이 든 문장문서나 검색 결과에 남은 PII 토큰이 든 문장만 붙여 넣습니다. 이미 원문 개인정보가 든 문장은 넣지 않습니다.가려진 이름을 확인해야 할 때
3복원 사유(필수, 100자)왜 원문을 보는지 적습니다. 사유에 개인정보 원문을 적지 않습니다.복원 근거를 남길 때
4복원원문을 이 화면에서만 잠시 보여 주고 5분 뒤 지웁니다.확인이 끝나면 바로 닫습니다.

항목 파기는 문서 ID나 값 해시로 볼트 원문을 지웁니다. 파기한 토큰은 복원하면 [파기됨]으로 바뀌고 되돌릴 수 없습니다. 복원과 파기는 모두 감사 로그 탭에 최신순으로 남습니다.

이럴 때 쓰세요: 영업팀이 올린 판매 데이터 엑셀 97-2003 파일(.xls)이 계속 적재 실패로 남아 있다는 문의가 왔습니다. 강혁신 팀장은 적재 현황에서 24시간을 고르고 실패 사유별 탭에서 파서가 이 형식을 지원하지 않는다는 사유를 확인합니다. 영업팀에 엑셀 파일(.xlsx)로 다시 저장해 올리도록 안내하고, 같은 날 전사 용어사전에 "법카(법인카드)" 같은 약어를 파일 일괄 등록으로 넣어 영업팀 질문이 약어로도 검색되게 합니다.
