Deep Admin 시크릿과 키

사이드바 시크릿·키 묶음에는 워크스페이스(워크스페이스 시크릿), 마스터키, API 토큰, 외부 접근 키 네 메뉴가 있습니다. 모델과 도구가 쓰는 인증 키를 넣고, 외부 시스템이 에이전트나 지식함을 부를 때 쓰는 자격 증명을 발급하고 거두는 곳입니다. 예시는 브레인크루 AI혁신팀 워크스페이스입니다.

이 페이지에서 할 수 있는 일

  • 워크스페이스 시크릿을 넣거나 마스터키에서 가져옵니다.
  • 여러 워크스페이스가 함께 쓸 마스터키를 등록하고 CSV 파일(.csv)로 한꺼번에 올립니다.
  • 외부 시스템용 API 토큰을 만들고 값을 옮겨 둔 뒤, 필요 없으면 취소합니다.
  • 지식함을 직접 부르는 외부 접근 키를 발급하는 항목을 확인합니다.

네 메뉴의 차이​

메뉴담는 것누가 쓰나값을 다시 볼 수 있나
워크스페이스(시크릿)한 워크스페이스의 키와 값(예: 모델 API 키)그 워크스페이스의 에이전트·도구아니요. 가려진 값(••••••••)만 보입니다.
마스터키여러 워크스페이스에 나눠 줄 원본 키관리자(워크스페이스 시크릿으로 가져감)아니요. 저장 뒤 조회할 수 없습니다.
API 토큰외부 시스템이 워크스페이스 에이전트를 부를 때 쓰는 토큰사내 포털, 자동화 스크립트만들 때 한 번만 보입니다.
외부 접근 키외부 시스템이 Builder를 거치지 않고 지식함을 부를 때 쓰는 키사내 포털 검색 등발급할 때 한 번만 보입니다.

워크스페이스 시크릿​

시크릿·키 > 워크스페이스를 누르고 워크스페이스를 고르면 그 워크스페이스의 시크릿 목록이 나옵니다.

워크스페이스 시크릿

번호항목기능이런 때 사용하세요
1워크스페이스 선택(예: AI혁신팀)시크릿을 볼 워크스페이스입니다. 고르기 전에는 목록이 비어 있습니다.부서 워크스페이스의 키를 확인할 때
2마스터 키로 추가마스터키 목록에서 골라 이 워크스페이스 시크릿으로 넣습니다. 이미 등록된 키는 "이미 등록됨"으로 고를 수 없습니다.회사 공용 키를 부서에 나눠 줄 때
3시크릿 추가키(필수)와 값(필수)을 직접 넣습니다.부서 전용 키를 넣을 때
4마스킹 값 열값은 늘 가려 보입니다. 같은 표에 이름, 마지막 수정, 작업(삭제)이 있습니다.키가 언제 바뀌었는지 볼 때

마스터키​

마스터 키 관리

번호항목기능이런 때 사용하세요
1CSV 업로드API_KEY, VALUE 두 열 머리글이 있는 CSV 파일(.csv)로 여러 키를 한꺼번에 등록합니다. 파일을 고르면 유효한 행만 유효 행 등록으로 넣습니다.새 공급사 키 여러 개를 한 번에 넣을 때
2마스터 키 추가이름(필수), 키 값(필수), 설명(선택)을 넣습니다.키 하나를 넣을 때
3상태 열활성 또는 비활성입니다. 작업 열의 수정에서 이름, 설명, 활성 여부를 바꿉니다. 키 값은 수정할 수 없습니다.쓰지 않는 키를 잠시 끌 때

API 토큰​

외부 시스템(예: 주간 보고를 자동으로 만드는 사내 스크립트)이 워크스페이스 에이전트를 부를 때 쓰는 토큰입니다.

API 토큰 목록

번호항목기능이런 때 사용하세요
1워크스페이스 선택토큰을 만들고 볼 워크스페이스입니다. 전체 워크스페이스에서는 목록만 봅니다.부서별 토큰을 확인할 때
2토큰 생성새 토큰을 만듭니다.외부 연동을 새로 열 때
3전체 취소이 워크스페이스의 토큰을 한꺼번에 무효로 만듭니다. 되돌릴 수 없습니다.토큰이 새어 나간 것 같을 때

API 토큰 생성 창

번호항목입력할 값
1토큰 이름어디에 쓰는 토큰인지 알 수 있게 적습니다(예: 주간 보고 자동화 연동).
2생성토큰을 만듭니다.

API 토큰 생성 완료

번호항목할 일
1토큰 값"토큰이 생성되었습니다. 이 값은 다시 표시되지 않으니 지금 복사해 두세요." 아래에 값이 한 번만 보입니다.
2복사값을 클립보드에 복사합니다. 사내 비밀번호 관리 도구에 바로 붙여 둡니다.
3닫기창을 닫습니다. 닫은 뒤에는 값을 다시 볼 수 없습니다.

목록에는 ID, 이름, 상태, 마지막 사용, 생성일이 나오고 행 끝 버튼으로 토큰을 취소(폐기)할 수 있습니다. 직원 개인이 만든 토큰은 사용자와 워크스페이스의 사용자 상세 보안 탭에서 봅니다.

외부 접근 키​

사내 포털처럼 Builder를 거치지 않고 지식함을 직접 검색하는 시스템에 주는 키입니다. 키 하나로 지식함 하나만 부를 수 있으며, 발급 뒤에는 컬렉션만 고칠 수 있습니다. 주체·지식함·만료·호출 한도를 바꾸려면 폐기하고 다시 발급합니다.

접근 키 발급 창

번호항목입력할 값
1이름폐기할 때 이 키를 알아볼 단서입니다(예: 사내 포털 규정 검색). 옆 발급 근거에는 요청 출처를 적습니다(예: AI혁신팀 요청 · 사내 포털 연동).
2주체이 키로 오는 호출을 누구 권한으로 판정할지 사번으로 고릅니다. 옆 주체 유형은 사번입니다.
3지식함키가 부를 지식함 하나를 고릅니다. 그 뒤 컬렉션에서 주체에게 권한이 있는 컬렉션을 하나 이상 고릅니다. 주체를 바꾸면 고른 컬렉션이 모두 해제됩니다.
4만료키가 끝나는 날짜와 시각입니다. 옆 분당 호출 한도는 재시도가 폭주할 때 막는 값입니다.
설정 항목처음 값범위
만료오늘부터 90일 뒤최대 365일
분당 호출 한도3,600회연동 시스템의 실제 호출량에 맞게 줄입니다.
이름, 발급 근거비움둘 다 필수

주체는 사번 디렉터리(인사 원장)에서 찾습니다. 사번 디렉터리가 연결되지 않은 배포에서는 주체를 고를 수 없어 발급되지 않습니다. 발급 직후 보이는 키 값은 해시로만 저장되어 다시 꺼낼 수 없습니다. 놓치면 폐기하고 다시 발급합니다. 발급된 키는 목록(이름, 주체, 컬렉션, 상태, 만료, 발급 근거)에서 보고 폐기합니다.

이럴 때 쓰세요: AI혁신팀은 매주 월요일 아침 주간 업무 보고서 초안을 자동으로 만드는 사내 스크립트를 운영합니다. 강혁신 팀장은 AI혁신팀 워크스페이스에 "주간 보고 자동화 연동" API 토큰을 만들어 스크립트 담당자에게 비밀번호 관리 도구로 전달합니다. 담당자가 퇴사하거나 스크립트를 바꾸면 그 토큰을 취소하고 새로 만듭니다.
