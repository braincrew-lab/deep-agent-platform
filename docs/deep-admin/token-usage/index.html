Deep Admin 토큰 사용량과 한도

에이전트가 LLM을 부를 때마다 토큰이 쓰이고, 토큰은 곧 비용입니다. 이 페이지는 사용자별 토큰 사용량을 확인하고, 전 사용자 공통 월 한도와 개인 추가 부여를 운영하고, 사용량을 CSV 파일로 내보내는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 사용자별 통계에서 실행 수와 토큰 사용량, 한도 사용률을 봅니다.
  • 전 사용자 월 토큰 한도를 정하고, 필요한 직원에게 이번 달 추가 토큰을 줍니다.
  • LLM 토큰 사용량을 날짜·사용자·모델·에이전트·워크스페이스별로 집계합니다.
  • 사용량을 CSV 파일(.csv)로 내보내 월별 리포트에 씁니다.

사용자별 통계​

사용자·승인 > 사용자별 통계는 사람 단위의 사용 현황입니다. 위쪽에서 워크스페이스와 기간을 고르고, 사용자 랭킹의 두 탭으로 실행과 토큰을 나누어 봅니다.

사용자별 통계

번호항목기능이런 때 사용하세요
1워크스페이스와 기간집계 범위를 정합니다. 기간은 오늘, 7일, 30일, 전체 또는 직접 지정합니다.영업팀 지난주 사용량처럼 범위를 좁힐 때
2요약 카드총 멤버 수, 총 실행 수, 평균 에러율, 평균 응답 시간범위 전체를 한눈에 볼 때
3토큰 현황당월 총 토큰 사용량, 한도 90% 이상 인원, 한도 초과 인원. 위쪽 워크스페이스·기간 필터와 관계없이 이번 달 누적입니다.한도가 찰 직원을 미리 찾을 때
4실행 통계 탭사용자, 워크스페이스, 실행 수, 에러 수, 에러율, 평균 응답 시간, 총 토큰. 행을 누르면 일별 실행 추이와 에이전트별 사용량이 열립니다.많이 쓰는 직원이 어떤 에이전트를 쓰는지 볼 때
5토큰 사용량 탭사용자, 워크스페이스, 입력·출력 토큰, 합계, 한도, 사용률, 상태(정상, 경고, 한도 초과, 판정 불가)한도 초과 문의를 받았을 때

그림은 월 한도를 정하기 전이라 토큰 현황 카드에 "기본 한도가 없어 판정이 서지 않습니다."가 보이는 상태입니다. 한도를 저장하면 한도 90% 이상과 한도 초과 인원이 숫자로 나옵니다.

토큰 한도 설정​

토큰 한도 설정은 두 가지를 정합니다. 하나는 전 사용자에게 똑같이 적용되는 월 한도, 다른 하나는 특정 직원에게 이번 달에만 더 주는 추가 토큰입니다. 부서·워크스페이스·역할별로 한도를 따로 두는 기능은 없습니다.

토큰 한도 설정의 기본 한도

번호항목기능이런 때 사용하세요
1전 사용자 월 한도입력 토큰과 출력 토큰을 더한 값의 월 한도입니다. 0은 "전원 차단"이라는 별도 의미이므로 주의합니다.회사 기준 한도를 처음 정하거나 바꿀 때
2초기화 주기, 다음 초기화매월 1일 00:00(한국 시간)에 고정으로 초기화되고, 개인 추가 부여분도 함께 사라집니다. 바꿀 수 없는 항목입니다.다음 달 초기화 시점을 확인할 때
3변경 사유한도를 바꾸는 이유를 꼭 적습니다. 저장하면 변경 전후 값과 수행한 관리자가 이력에 남습니다.변경 이력에 근거를 남길 때

같은 화면 아래에는 두 카드가 더 있습니다.

카드기능이런 때 사용하세요
개인 토큰 추가 부여대상 사용자(사번·이름 검색), 부여할 토큰(1 이상), 부여 사유를 적고 부여를 누릅니다. 이번 달에만 유효하고 다음 달 1일에 사라집니다.월말 보고서 작업으로 한도가 찬 직원을 도울 때
변경 이력한도 저장과 추가 부여 기록이 쌓입니다.누가 언제 한도를 바꿨는지 볼 때

한도를 저장하기 전에 화면이 영향 인원을 미리 보여 줍니다. "이미 새 한도를 초과한 사용자는 저장 즉시 차단됩니다"라는 안내와 함께 저장 전후 차단 인원과 경고 인원이 나오므로, 한도를 낮출 때는 이 숫자를 꼭 확인합니다.

상태뜻
정상한도의 90% 미만을 썼습니다.
경고한도의 90% 이상을 썼습니다.
한도 초과한도를 넘어 새 요청이 막힙니다. 추가 부여로 당월 사용량이 새 한도보다 적어지면 풀립니다.
판정 불가사용량을 집계하지 못했습니다.

설정 변경 권한이 없는 관리자에게는 입력란이 잠겨 보기만 할 수 있습니다.

LLM 토큰 사용량​

LLM 토큰 사용량은 Builder 에이전트가 LLM에 보낸 요청의 토큰을 모아 보는 화면입니다. 성공한 요청만 합산하며, 네 구역으로 나뉩니다.

항목기능이런 때 사용하세요
기간 버튼최근 7일, 최근 14일, 최근 30일(한국 시간 기준)주간·월간 사용량을 볼 때
요약 카드전체 토큰(입력·출력), 성공 요청 건수, 사용한 사용자 수기간 전체 규모를 볼 때
일별 토큰 추이날짜별 토큰 그래프특정 날에 사용이 몰렸는지 볼 때
일별, 사용자별, 모델별 탭기준별 전체·입력·출력 토큰, 성공 요청 건수, 집계 상태(확정, 미확정 포함, 기록 없음)비싼 모델을 누가 많이 쓰는지 볼 때
에이전트·워크스페이스별 사용량에이전트별, 워크스페이스별, 실행별로 총 토큰, 성공·실패 요청, 비용, 마지막 요청 시각사용량이 많은 에이전트를 찾을 때

아래쪽 요청 로그에서는 사용자 ID(사번), 모델, 결과, 기간, 에이전트 ID, 워크스페이스 ID, 실행 ID로 요청을 한 건씩 찾을 수 있습니다. 요청 본문은 별도 열람 권한이 있는 관리자만 본문 보기로 열 수 있고, 개인정보는 가려져 보이며 열람 사실이 기록됩니다.

사용량을 CSV 파일로 내보내기​

맨 아래 토큰 사용량 내보내기에서 요청 단위 기록을 CSV 파일(.csv)로 받습니다. 엑셀에서 열어 부서별 합계나 월별 리포트를 만들 수 있습니다.

항목기능이런 때 사용하세요
제품Builder 또는 Deep Work를 고릅니다. Deep Work 관리 권한이 있는 관리자에게만 보입니다.Deep Work 사용량도 함께 보고할 때
시작일, 종료일한국 시간 기준, 두 날짜 모두 포함입니다. 한 번에 최대 92일까지입니다.지난달 1일부터 말일까지 받을 때
사용자 ID, 에이전트 ID, 워크스페이스 ID비워 두면 전체를 받습니다. 에이전트와 워크스페이스 조건은 Builder에서만 쓸 수 있습니다.한 부서나 한 에이전트만 받을 때
CSV 내보내기조건에 맞는 요청을 한 줄에 한 건씩, 최신순으로 담은 CSV 파일을 내려받습니다. 행 수 상한을 넘으면 잘렸다는 안내가 나옵니다.월별 사용량 리포트를 만들 때

내보내기도 감사 기록으로 남습니다. 받은 파일에는 사번 같은 개인 식별 정보가 들어 있으므로 사내 보관 규정에 맞게 다룹니다.
