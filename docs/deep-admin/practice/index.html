Deep Admin 실습 묶음 안내

이 묶음은 플랫폼 관리자가 새 조직을 맞이해 권한을 나누고, 한도를 정하고, 사용 현황을 살피고, 감사 기록으로 마무리하는 운영 흐름을 다섯 개의 실습으로 따라 합니다. 앞 실습에서 만든 그룹과 설정을 다음 실습이 그대로 이어 씁니다. 실습마다 목표, 준비물, 단계별 화면과 번호 표, 설정값 표, 실제 결과, 흔한 실수, 응용 과제가 있습니다. 예시 회사는 브레인크루이고, 관리자는 AI혁신팀 강혁신 팀장, 직원은 AI혁신팀 김그루 사원과 이번 달 입사한 정신입 사원입니다. 회사와 인물, 숫자는 모두 연습용 가상 자료입니다.

이 페이지에서 할 수 있는 일

  • 실습 다섯 가지가 무엇을 만들고 무엇을 익히는지 한눈에 봅니다.
  • 실습끼리 무엇을 이어 쓰는지 확인하고 순서를 정합니다.
  • 실습에 필요한 계정, 권한, 파일을 준비합니다.
  • 실습과 시작하기, 활용사례의 차이를 압니다.

실습 한눈에 보기​

실습만드는 것새로 익히는 것쓰는 파일 형식난이도
실습 1: 신규 조직 세팅정신입 사원의 역할, 김그루 사원의 워크스페이스 역할, 부서 템플릿사용자 검색, RBAC 그룹 창, 워크스페이스 구성원 선택과 WBAC 그룹 설정, 템플릿 관리–★☆☆☆☆
실습 2: 권한RBAC 그룹 "운영 감사 담당"그룹 추가, 권한 카테고리 펼치기와 체크, 즉시 반영, 그룹 배정–★★☆☆☆
실습 3: 한도전 사용자 월 한도와 변경 이력저장 전 미리보기(새로 차단될 인원), 변경 사유, 개인 추가 부여 조건, 사용자별 통계의 상태–★★☆☆☆
실습 4: 모니터링오류 원인 메모와 월간 사용량 CSV 파일대시보드 시스템 탭, 실행 로그 상태 필터, 에러 원인·권장 조치, LLM 토큰 사용량 내보내기CSV 파일(.csv), 엑셀 파일(.xlsx)★★★☆☆
실습 5: 감사한 달 관리 작업 점검 기록관리자 접근기록의 권한 거부, 감사 로그 상세의 변경 전·후–★★★☆☆

처음이라면 실습 1부터 차례로 하세요. 한 번에 다 하면 1시간 정도 걸립니다. 실습 5는 실습 2·3에서 바꾼 기록을 감사 로그에서 다시 찾으므로, 실습 2·3을 먼저 해야 결과가 같게 나옵니다.

실습끼리 이어지는 흐름​

순서실습이어 쓰는 것다음 실습에 넘기는 것
1실습 1–역할이 정해진 신규 입사자와 부서 템플릿
2실습 2실습 1의 사용자 검색 방법"운영 감사 담당" 그룹과 권한 변경 기록
3실습 3–월 한도 8,000토큰, 한도 변경 이력
4실습 4실습 3의 한도(한도 초과 직원 확인)오류 원인 메모, 사용량 CSV 파일
5실습 5실습 2·3의 변경 기록월간 감사 점검 결과

준비물​

준비물내용
관리자 계정관리자 권한 그룹에 배정된 계정(예시: 강혁신 팀장). 실습 3·4에는 토큰 한도 설정 변경, LLM 토큰 사용량 조회 권한이 필요합니다.
연습 대상 직원한 번 이상 로그인한 신규 입사자 계정(예시: 정신입 사원)과 일반 직원 계정(예시: 김그루 사원)
사용 기록최근 한 달 사이 직원들이 에이전트를 쓴 기록. 실습 4의 화면이 비어 있지 않으려면 며칠치 사용이 있어야 합니다.
프로그램실습 4에서 내려받는 CSV 파일(.csv)을 열고 엑셀 파일(.xlsx)로 정리할 표 계산 프로그램
브라우저최신 Chrome 또는 Edge, 가로 1,300픽셀 이상의 창

연습 환경이 아니라 실제 운영 환경에서 따라 한다면, 실습 3의 월 한도는 실제 직원 업무를 막을 수 있으니 미리보기의 "새로 차단" 인원을 꼭 확인하고, 끝난 뒤 원래 값으로 되돌립니다.

모든 실습에 공통인 손동작​

하고 싶은 일방법
메뉴 찾기왼쪽 사이드바 묶음(운영 현황, 사용자·승인, 접근 권한, 워크스페이스 등)에서 고릅니다. 보이지 않으면 내 계정에 그 메뉴 권한이 없는 것입니다.
워크스페이스 고르기화면 위 워크스페이스 선택에서 부서를 고릅니다. 고르기 전에는 비어 있는 화면이 많습니다.
바꾼 내용 저장권한 체크와 그룹 배정은 즉시 저장됩니다. 한도와 WBAC 그룹 설정은 저장을 눌러야 합니다.
기록 확인바꾼 작업은 감사 로그와 각 화면의 변경 이력에 남습니다.
화면 공유 전 가리기이메일, 사용자 ID, 사번, IP, 토큰 값은 캡처나 화면 공유 전에 가립니다.

실습과 다른 페이지의 차이​

구분시작하기실습 묶음활용사례
목적로그인과 대시보드로 한 바퀴메뉴를 직접 눌러 손에 익히고 설정값과 기본값을 함께 봄운영 업무 하나를 끝까지 처리한 결과를 봄
다루는 범위로그인, 사이드바, 대시보드사용자, 권한, 한도, 모니터링, 감사업무별 처리 순서
결과물화면 구성 이해권한 그룹, 한도, CSV 파일, 점검 기록업무별 설정과 보고 자료

이럴 때 쓰세요: 브레인크루는 다음 달부터 경영지원팀 윤지원 사원에게 플랫폼 운영 일부를 맡기기로 했습니다. 강혁신 팀장은 윤지원 사원과 함께 실습 1~5를 순서대로 해 보며, 신규 입사자 처리부터 월말 감사 점검까지 관리자 업무 한 달 치를 1시간 만에 미리 겪어 보게 합니다.
