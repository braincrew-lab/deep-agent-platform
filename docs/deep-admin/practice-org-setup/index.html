Deep Admin 실습 1: 신규 조직 세팅

이번 달 AI혁신팀에 정신입 사원이 입사했고, 같은 팀 김그루 사원은 아직 AI혁신팀 워크스페이스 안의 역할이 비어 있습니다. 이 실습에서는 신규 입사자에게 플랫폼 역할(RBAC 그룹)을 주고, 팀원에게 워크스페이스 역할(WBAC 그룹)을 정하고, 회사 공용 워크스페이스에 신입이 바로 쓸 에이전트 템플릿을 올립니다. 화면 전체 설명은 사용자와 워크스페이스에 있습니다.

이 페이지에서 할 수 있는 일

  • 신규 입사자를 사용자 목록에서 찾아 RBAC 그룹 "사용자"를 배정합니다.
  • 워크스페이스 구성원을 골라 WBAC 그룹을 한꺼번에 정합니다.
  • 회사 공용 에이전트를 워크스페이스 템플릿으로 등록합니다.

목표​

항목내용
만들 것정신입 사원의 RBAC 그룹 "사용자", 김그루 사원의 AI혁신팀 WBAC 그룹 "사용자", 브레인크루 워크스페이스 템플릿 "주간 업무 보고서 도우미"
결과물사용자 목록의 RBAC 그룹 열, 워크스페이스 설정의 그룹 열, 템플릿 목록에 바뀐 값
걸리는 시간10분
난이도★☆☆☆☆

준비물​

준비물내용
관리자 계정사용자 수정, 워크스페이스 관리 권한이 있는 계정(예시: 강혁신 팀장)
신규 입사자Deep Agent Builder에 한 번 로그인한 계정. 로그인하지 않은 직원은 목록에 나오지 않습니다.
워크스페이스 권한관리자 본인이 AI혁신팀 워크스페이스의 WBAC 그룹(예: 관리자)에 들어 있어야 구성원 목록이 보입니다.
템플릿으로 올릴 에이전트브레인크루 워크스페이스에 있는 공용 에이전트 하나(예시: 주간 업무 보고서 도우미)

1단계. 신규 입사자 찾기​

사이드바 사용자·승인 > 사용자를 누릅니다.

신규 입사자 검색

번호메뉴할 일
1검색창"정신입"을 적습니다. 이름은 가려서(정**) 보입니다.
2RBAC 그룹 열아직 비어 있는(-) 것을 확인합니다.
3행 메뉴(…)누르면 상세 보기와 RBAC 그룹이 나옵니다. RBAC 그룹을 누릅니다.

2단계. RBAC 그룹 "사용자" 배정​

RBAC 그룹 관리 창이 열립니다.

RBAC 그룹 관리 창

번호메뉴할 일
1그룹 검색그룹이 많으면 이름이나 설명으로 찾습니다.
2사용자체크합니다. "지식 · 에이전트 조회 · 활용" 권한이 있는 일반 직원용 그룹입니다. 체크하는 즉시 저장됩니다.
3닫기창을 닫습니다.
설정 항목이 실습의 값다른 선택지
RBAC 그룹사용자개발자, 관리자(관리 화면 진입), 책임자, 에이전트(협력사 가상사번 전용), 문서 담당자, 지식 담당자, 운영 조회 담당
저장 방식체크 즉시체크를 풀면 바로 빠집니다.

창을 닫으면 사용자 목록의 RBAC 그룹 열에 "사용자"가 보입니다.

3단계. 워크스페이스 구성원 고르기​

사이드바 워크스페이스 > 워크스페이스 설정에서 워크스페이스 선택을 AI혁신팀으로 바꿉니다. 아래쪽 구성원 표에서 그룹이 비어 있는 김그루 사원 행을 찾습니다.

구성원 선택

번호메뉴할 일
1행 체크 칸김** 행을 체크합니다. 여러 명을 체크해도 됩니다.
2WBAC 그룹 설정 (1명)체크한 인원수가 버튼에 나옵니다. 누릅니다.

4단계. WBAC 그룹 "사용자" 저장​

WBAC 그룹 설정 창

번호메뉴할 일
1사용자체크합니다.
2저장누르면 구성원 표의 그룹 열이 "사용자"로 바뀝니다.

한 명만 골랐을 때는 체크한 목록으로 바꿉니다(체크를 푼 그룹은 빠집니다). 여러 명을 골랐을 때는 체크한 그룹을 더합니다.

5단계. 회사 공용 템플릿 등록​

사이드바 워크스페이스 > 워크스페이스 템플릿에서 브레인크루 워크스페이스를 고르고 템플릿 관리를 누릅니다.

템플릿 관리 창

번호메뉴할 일
1에이전트(주간 업무 보고서 도우미)이 워크스페이스의 에이전트 가운데 템플릿으로 올릴 것을 고릅니다. 상태 열이 준비 완료(ready)인 에이전트만 올립니다.
2등록누르면 템플릿 목록에 들어가고 버튼이 해제로 바뀝니다.

결과​

확인 위치기대 결과
사용자 목록에서 "정신입" 검색RBAC 그룹 열: 사용자
워크스페이스 설정 > AI혁신팀 구성원 표김** 행의 그룹: 사용자, 상태: 활성
워크스페이스 템플릿 > 브레인크루총 1개: 주간 업무 보고서 도우미(GPT-4.1)
감사 로그RBAC 그룹 배정, WBAC 그룹 설정, 템플릿 등록 기록

흔한 실수​

실수증상바로잡기
신규 입사자가 로그인하기 전에 검색목록에 이름이 없음직원에게 Deep Agent Builder에 한 번 로그인해 달라고 한 뒤 다시 찾습니다.
신규 입사자에게 관리자 그룹 체크직원이 관리 화면에 들어올 수 있게 됨바로 체크를 풉니다. 감사 로그에 배정·해제가 함께 남습니다.
내 계정의 그룹을 바꾸려 함바꿀 수 없음본인 계정은 다른 관리자가 바꿉니다.
구성원 표 대신 "접근 권한이 없습니다"워크스페이스 구성원이 안 보임관리자 본인이 그 워크스페이스의 WBAC 그룹에 들어 있어야 합니다.
여러 명을 골라 그룹을 "바꾸려" 함기존 그룹이 그대로 남음여러 명 선택은 더하기만 합니다. 빼려면 한 명씩 열어 체크를 풉니다.

응용 과제​

  1. 영업팀에 신규 입사자 3명이 들어왔다고 가정하고, 사용자 목록의 전체 권한 그룹 필터로 RBAC 그룹이 비어 있는 사람만 찾아 보세요.
  2. 영업팀 워크스페이스에 "이메일 초안 도우미"를 템플릿으로 올리고, 영업팀 직원 화면의 에이전트 템플릿에서 보이는지 확인해 보세요.
  3. 정신입 사원의 사용자 상세 개요 탭에서 소속 워크스페이스와 마지막 로그인을 확인해 보세요.
