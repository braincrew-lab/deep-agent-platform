Deep Admin 툴박스 레지스트리

사이드바 툴박스 레지스트리 묶음에는 Toolbox와 도메인 허용 목록 두 메뉴가 있습니다. Toolbox는 도구와 모델의 원본을 등록하고 워크스페이스에 나눠 주는 곳이고, 도메인 허용 목록은 도구가 부를 수 있는 사내망·클러스터 내부 주소를 정하는 곳입니다. 예시는 브레인크루 AI혁신팀 강혁신 팀장이 사내 일정 시스템을 도구로 연결하려고 주소를 허용하고, 부서 워크스페이스에 모델을 나눠 주는 장면입니다.

이 페이지에서 할 수 있는 일

  • Toolbox의 도구·모델·스토리지 탭과 하위 탭(관리, 워크스페이스, 시스템)의 차이를 압니다.
  • 도구와 모델 원본을 워크스페이스에 할당합니다.
  • 새 모델을 등록할 때 넣는 항목과 추론(reasoning) 설정을 확인합니다.
  • 도구가 호출할 도메인을 허용 목록에 넣고 모드를 정합니다.

원본과 복사본​

구분어디에 있나어떻게 생기나바뀌는 방식
시스템 원본Toolbox > 시스템 탭기본 카탈로그 저장소에서 동기화동기화 때 저장소 내용으로 갱신됩니다. 이미 배포된 복사본에는 자동 반영되지 않습니다.
관리 원본Toolbox > 도구 > 관리 탭관리자가 이 화면에서 직접 등록(MCP 서버 등록)동기화로 바뀌지 않습니다.
워크스페이스 복사본Toolbox > 워크스페이스 탭, 리소스 > 도구·모델관리자가 원본을 워크스페이스에 할당하거나, 모델 추가로 워크스페이스에 바로 등록복사본만 고치면 원본은 그대로입니다.
내 설치직원의 Deep Agent Builder 화면직원이 유틸리티에서 설치직원마다 따로입니다.

Toolbox: 도구 탭​

툴박스 레지스트리 > Toolbox를 누르면 도구 탭이 열립니다. 아래 하위 탭 숫자는 원본 개수입니다(예시: 관리 0개, 시스템 75개).

Toolbox 도구 탭

번호항목기능이런 때 사용하세요
1시스템 하위 탭기본 카탈로그에서 동기화된 원본입니다. 옆 관리는 관리자가 직접 등록한 원본, 워크스페이스는 고른 워크스페이스에 배포된 복사본입니다.어떤 도구 원본이 있는지 볼 때
2유형 칩(예: HTTP)도구, MCP 서버, HTTP, MCP-Stdio, 기본 제공, 사용자 정의, 지식 유형별 개수이며 누르면 그 유형만 남습니다.HTTP 호출형 도구만 볼 때
3MCP 서버 등록외부 MCP 서버를 관리 원본으로 등록합니다. 등록한 서버의 하위 도구는 동기화로 다시 읽습니다.사내 MCP 서버를 들일 때
4워크스페이스 선택하여 할당지금 목록의 도구를 고른 워크스페이스에 배포합니다. 옆 전체 워크스페이스에 할당은 모든 워크스페이스에 한 번에 배포합니다.영업팀에만 도구를 나눠 줄 때

할당은 지금 화면에 불러온 항목만 대상으로 합니다. 검색어와 유형 칩이 걸린 그대로 보내므로, 할당 전에 목록을 원하는 범위로 좁힙니다. 선택을 누르면 카드마다 체크 칸이 생겨 몇 개만 골라 할당할 수 있습니다. 같은 이름의 도구가 이미 있으면 "이 워크스페이스에 같은 이름의 다른 도구가 이미 있습니다."로 건너뜁니다. 끝나면 "워크스페이스 N개에 할당했습니다." 또는 성공·실패 개수가 나옵니다.

카드를 누르면 상세가 열려 버전, 상태, 유형, 카테고리, 서버 엔드포인트, 필수 환경 변수, 파라미터 스키마와 버전 히스토리를 봅니다. 버전 설명은 5~500자로 남길 수 있습니다.

Toolbox: 모델 탭​

모델 탭의 하위 탭은 시스템(기본 카탈로그 모델), 워크스페이스(워크스페이스에 배포된 모델), 사용자(직원이 직접 등록한 모델)입니다.

Toolbox 모델 탭

번호항목기능이런 때 사용하세요
1모델 탭모델 원본과 복사본을 봅니다. 카드에 공급사, 도구 호출·비전·구조화 출력 지원, 컨텍스트 크기가 보입니다.쓸 수 있는 모델을 훑어볼 때
2워크스페이스 하위 탭워크스페이스에 배포된 모델 복사본(예시 28개)입니다.부서마다 어떤 모델이 있는지 볼 때
3카드의 할당이 모델 하나를 워크스페이스에 배포합니다.영업팀에 경량 모델만 열 때
4모델 추가새 모델을 등록합니다. 아래 창이 열립니다.새 LLM을 들일 때

모델 추가 창

번호항목기능
1워크스페이스모델을 등록할 워크스페이스입니다. 처음엔 비어 있습니다.
2프로바이더모델 공급사입니다. 처음 값은 anthropic이며, OpenAI 호환 주소를 쓰는 사내 모델은 호환 공급사를 고릅니다.
3모델 식별자공급사가 쓰는 모델 이름입니다. 아래에 "최종 이름: 공급사:식별자"로 실제 등록 이름이 보입니다.
4스펙 조회공급사·식별자로 알려진 스펙(컨텍스트 크기, 최대 출력 토큰, 지원 파라미터)을 채웁니다. 접속 주소와 자격 증명, 이미 적은 식별자는 바꾸지 않습니다.
설정 항목기본값뜻
컨텍스트 크기, 최대 출력 토큰비움(스펙 조회로 채움)한 번에 넣을 수 있는 토큰과 한 번에 받을 수 있는 토큰
API 키 환경 변수 이름, API 키 값비움모델 호출에 쓸 키. 값은 저장 뒤 다시 볼 수 없습니다.
추론(Reasoning) 설정사용 안 함사용 안 함, 추론 강도 지정, 적응형 사고, 확장 사고 중 하나. 에이전트가 이 모델을 부를 때 추론 인자를 어떻게 보낼지 정합니다.
지원 파라미터 정의비어 있음파라미터 이름·타입·범위·선택지·권장값. 스펙을 고르면 권장값이 호출 기본값에도 들어갑니다.
설정(호출 기본값, 연결 설정)비어 있음호출 기본값에는 temperature 같은 추론 파라미터, 연결 설정에는 접속 주소 같은 연결 값을 넣습니다.

모두 채운 뒤 연결 테스트로 실제 호출이 되는지 보고, 등록 내용 확인에서 저장될 값을 검토한 다음 등록합니다. 등록한 모델 카드의 모델 수정에서는 표시 이름, 설명, 컨텍스트 크기, 최대 출력 토큰과 함께 입력 단가 ($/100만 토큰), **출력 단가 ($/100만 토큰)**를 넣습니다(0 이상의 숫자). 단가가 맞아야 Builder 화면과 사용량 집계의 비용이 정확합니다.

Toolbox: 스토리지 탭​

스토리지 탭은 도구 실행 파일과 아이콘 같은 Toolbox 저장소의 파일 목록(파일, 크기, 수정일)입니다. 조회, 새로고침, 업로드를 쓸 수 있습니다. 사용자 정의 도구를 고칠 때 파일이 올라갔는지 확인하는 용도이며, 평소에는 열 일이 거의 없습니다.

도메인 허용 목록​

도구(HTTP 요청 서버, 원격 MCP 등)가 부르는 주소가 사내망이나 클러스터 내부 주소라면 이 목록에 있어야 호출됩니다.

도메인 허용 목록

번호항목기능이런 때 사용하세요
1모드허용 목록, 전부 허용, 전부 허용 안함 중 하나입니다. 그림은 "전부 허용" 상태라 목록과 관계없이 내부 주소를 모두 부를 수 있습니다.보안 정책에 맞게 호출 범위를 정할 때
2도메인 추가허용할 주소를 등록합니다.새 사내 시스템을 도구로 연결할 때
3등록된 도메인도메인, 설명, 등록자, 등록일시, 작업(삭제)이 보입니다.무엇이 열려 있는지 점검할 때
모드동작
허용 목록목록에 있는 도메인의 내부 주소만 부를 수 있습니다. 운영 환경에 권장합니다.
전부 허용목록과 관계없이 클러스터 내부·사설망 주소를 모두 부를 수 있습니다. 연습 환경의 값입니다.
전부 허용 안함내부 주소를 하나도 부를 수 없습니다.

도메인 추가 창

번호항목입력할 값
1주소도메인(예: schedule.braincrew.example). 경로를 붙여도 도메인까지만 저장되며, 아래에 "등록 값"으로 실제 저장될 값이 보입니다.
2추가저장합니다. 최대 30초 안에 도구 호출 허용 대상에 들어갑니다.

설명(선택, 100자)에는 어떤 시스템인지 적어 두면 나중에 정리할 때 도움이 됩니다.

이럴 때 쓰세요: 김그루 사원이 "회의실 예약 확인" 에이전트를 만들려고 사내 일정 시스템을 HTTP 도구로 연결했는데, 호출이 막혔다고 문의했습니다. 강혁신 팀장은 도메인 허용 목록에 schedule.braincrew.example을 추가하고 30초 뒤 다시 시도해 보라고 안내합니다. 도구는 AI혁신팀 워크스페이스에서 만든 것이라 다른 부서에는 보이지 않습니다. 다른 부서도 쓰게 하려면 승인 관리로 등록 요청을 받아 처리합니다.
