Deep Admin 모델과 리소스

에이전트가 쓰는 모델, 도구, 미들웨어, 스킬, 지식 컬렉션을 리소스라고 부릅니다. 이 페이지는 리소스를 확인하고, 새 도구를 들이고, 누가 쓸 수 있는지 정하는 방법을 설명합니다. 모델·도구 원본은 툴박스 레지스트리, 키는 시크릿과 키에서 다룹니다.

이 페이지에서 할 수 있는 일

  • 리소스의 원본(Toolbox)과 워크스페이스 복사본의 차이를 이해합니다.
  • 모델과 도구를 확인하고, 사용 범위를 ABAC 그룹으로 정합니다.
  • 미들웨어, 스킬, 지식 컬렉션이 어떤 에이전트에서 쓰이는지 봅니다.
  • 도구 추가 유형과 스킬·지식의 활용 현황을 봅니다.

원본과 워크스페이스 복사본​

모델과 도구는 두 층으로 관리됩니다. 툴박스 레지스트리 > Toolbox에는 원본이 있고, 원본을 워크스페이스에 할당하면 그 워크스페이스에 복사본이 생깁니다. 리소스 묶음의 도구와 모델 화면은 워크스페이스에 배포된 복사본을 보여 줍니다. 직원이 자기 화면에서 도구나 모델을 "설치"하는 것은 또 다른 동작입니다.

동작누가어디서
원본 등록관리자Toolbox의 도구, 모델 탭
워크스페이스에 할당(배포)관리자Toolbox의 워크스페이스에 할당, 전체 워크스페이스에 할당
사용 범위 제한관리자도구, 모델, 미들웨어 화면의 ABAC 설정
내 에이전트에 설치직원Deep Agent Builder 화면

모델​

리소스 > 모델은 워크스페이스별 등록 모델과 리소스 권한(ABAC)을 보여 줍니다.

모델 목록

번호항목기능이런 때 사용하세요
1Toolbox에서 배포 현황 보기모델 원본이 있는 Toolbox로 이동합니다.새 모델을 들이려 할 때
2검색모델 이름으로 찾습니다. 오른쪽에서 워크스페이스로 거를 수 있습니다.특정 모델의 등록 위치를 볼 때
3ABAC 열모델마다 지정된 리소스 권한 그룹입니다. 같은 표에 모델 이름, 설명, 워크스페이스, 생성일이 있습니다.어떤 모델이 일부 부서에만 열려 있는지 볼 때
4기본 모델 강제 지정모델을 고르고 대상 구성원을 확인한 뒤 확인을 누르면 그 구성원의 기본 모델이 바뀝니다.회사 표준 모델을 바꿀 때

목록 왼쪽 체크 칸으로 여러 모델을 고르면 일괄 ABAC 버튼이 나타나, 고른 모델의 ABAC 그룹을 한 번에 지정할 수 있습니다. 고가 모델을 일부 부서에만 열 때 씁니다. 브레인크루 예시에서는 워크스페이스마다 DeepSeek V4 Flash, Claude Sonnet 4.6, GPT-4.1 mini, GPT-4.1 네 모델이 등록되어 있습니다.

새 모델은 Toolbox의 모델 탭에서 모델 추가로 등록하고, 100만 토큰당 입력·출력 단가는 모델 카드의 모델 수정에서 넣습니다. 단가를 정확히 넣어야 사용량 화면의 비용이 맞게 계산됩니다. 자세한 항목은 툴박스 레지스트리에 있습니다.

도구​

리소스 > 도구는 워크스페이스에 배포된 도구 목록입니다. 워크스페이스를 고르면 도구 추가가 켜지고, 다음 유형 중 하나로 도구를 만듭니다.

도구 추가 메뉴

번호항목기능이런 때 사용하세요
1워크스페이스 선택(예: AI혁신팀)도구를 넣을 워크스페이스입니다. 전체 워크스페이스에서는 도구 추가가 꺼져 있습니다.부서 도구를 만들 때
2도구 추가누르면 유형 메뉴가 열립니다.사내 시스템을 도구로 연결할 때
3유형 메뉴HTTP 요청 서버, 원격 MCP, Zapier·Dify·n8n·Connect MCP 서버 중에서 고릅니다. 유형별 설명은 아래 표에 있습니다.연결 방식을 고를 때
유형쓰임
HTTP 요청 서버사내 시스템의 주소 하나를 도구로 부릅니다. 엔드포인트 주소, HTTP 메서드, 파라미터(쿼리·헤더·본문), 인증 방식(인증 없음, 토큰 인증, API 키 인증, 커스텀 헤더 인증)을 정합니다.
원격 MCPMCP 서버 주소와 헤더, 환경 변수를 넣어 연결합니다. 설정 JSON을 가져올 수도 있습니다.
Zapier MCP 서버, Dify MCP 서버, n8n MCP 서버, Connect MCP 서버각 서비스가 제공하는 MCP 주소로 연결합니다.

도구 이름은 영문 소문자, 숫자, 밑줄만 쓸 수 있고 만든 뒤 바꿀 수 없습니다. 숨김 처리를 켜면 직원 목록에 보이지 않습니다. 도구를 누르면 상세와 활용 현황(이 도구를 쓰는 전체 에이전트, 개인 에이전트 목록)을 볼 수 있습니다.

도구가 사내 주소를 부르려면 도메인 허용 목록에 그 주소가 있어야 합니다. 모드와 추가 방법은 툴박스 레지스트리에 있습니다.

미들웨어와 스킬​

메뉴보는 것할 수 있는 일
미들웨어에이전트 실행 전후에 붙는 처리(예: 모호한 요청이면 먼저 되묻기)의 이름, 설명, 유형, 버전, 필수 환경변수, ABAC, 상태(사용가능, 제한됨)일괄 ABAC로 사용 범위를 정하고, 상세에서 ABAC 설정을 바꿉니다.
스킬전사 스킬의 이름, 설명, 배포 버전, 등록자, 최근 배포일, 파일 수, 사용 에이전트 수상세에서 파일, 배포 이력(승인·거부 기록), 활용 현황을 봅니다. 내장 스킬은 켜고 끌 수 있습니다.

미들웨어 목록

번호항목기능이런 때 사용하세요
1검색이름, 설명으로 찾습니다.특정 미들웨어를 찾을 때
2이름 열미들웨어 이름입니다. 옆에 설명, 유형, 버전, 필수 환경변수가 있습니다.어떤 처리가 들어 있는지 볼 때
3ABAC 열사용 범위 그룹입니다. 지정하지 않으면 미설정입니다.일부 부서에만 열린 미들웨어를 찾을 때
4상태 열사용가능 또는 제한됨지금 쓸 수 있는지 볼 때

스킬 목록​

스킬 관리

번호항목화면에 보이는 내용이런 때 확인하세요
1워크스페이스 선택스킬을 볼 워크스페이스입니다. 위 다시 불러오기로 목록을 새로 읽습니다.부서에 어떤 스킬이 있는지 볼 때
2배포 버전 열지금 배포된 스킬 버전입니다. 같은 표에 이름, 설명, 등록자, 최근 배포일, 파일 수가 있습니다.스킬이 언제 바뀌었는지 볼 때
3사용 에이전트 열이 스킬을 쓰는 에이전트 수입니다. 0이면 지금은 아무도 쓰지 않습니다.정리할 스킬을 고를 때

지식​

리소스 > 지식은 지식 컬렉션별로 그 컬렉션을 쓰는 전체 에이전트와 개인 에이전트 수를 보여 줍니다. 컬렉션을 지우거나 다른 컬렉션으로 옮기기 전에 영향을 받는 에이전트를 확인하는 데 씁니다. 직원이 컬렉션을 볼 수 있는지는 권한 관리의 지식 컬렉션 권한에서 정합니다.

지식 활용 현황

번호항목기능이런 때 사용하세요
1폴더(예: 전체 11)컬렉션 폴더로 거릅니다. 옆 버튼은 폴더 이름과 컬렉션 수입니다.한 부서 폴더만 볼 때
2컬렉션명 열지식 컬렉션 이름입니다.컬렉션을 찾을 때
3전체 에이전트 열이 컬렉션을 쓰는 전체(커뮤니티) 에이전트 수입니다. 옆 개인 에이전트는 직원 개인 에이전트 수입니다.영향 범위를 볼 때
4행 끝 > 버튼(활용 현황)누르면 컬렉션의 폴더, 문서 수, 청크 수와 이 컬렉션을 쓰는 에이전트 목록이 나옵니다.정리 전에 담당자에게 알릴 때

예시는 연습 환경이라 Builder 에이전트가 컬렉션을 지식 기능이 아니라 MCP 도구로 연결해, 에이전트 수가 모두 0으로 보입니다.

이럴 때 쓰세요: 마케팅팀이 "제품 소개" 컬렉션을 새 버전으로 바꾸려 합니다. 강혁신 팀장은 지식 화면에서 "제품 소개"의 전체·개인 에이전트 수를 보고, 활용 현황의 에이전트 담당자에게 교체 일정을 미리 알립니다.

키와 시크릿, 툴박스 레지스트리​

워크스페이스 시크릿, 마스터키, API 토큰, 외부 접근 키는 시크릿과 키에서, Toolbox와 도메인 허용 목록은 툴박스 레지스트리에서 화면과 함께 설명합니다.
