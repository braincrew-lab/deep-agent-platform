Deep Admin 권한 관리

Deep Admin의 권한은 세 겹으로 나뉩니다. 플랫폼 전체에서 무엇을 할 수 있는지(RBAC), 워크스페이스 안에서 무엇을 할 수 있는지(WBAC), 도구·모델·지식 같은 개별 리소스를 쓸 수 있는지(ABAC)를 따로 정합니다. 이 페이지는 세 가지 권한 그룹을 읽고 고치는 방법과, 사람별로 도구와 지식 컬렉션을 열고 거두는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • RBAC, WBAC, ABAC가 각각 무엇을 정하는지 구분합니다.
  • 권한 그룹을 만들고 그룹에 권한 항목을 체크합니다.
  • 직원에게 도구와 지식 컬렉션을 기한을 정해 부여하고 회수합니다.
  • 권한을 바꾼 기록을 이력에서 확인합니다.

세 가지 권한의 차이​

구분화면 이름정하는 것브레인크루 예시
RBAC전체 플랫폼 범위사용자 그룹이 플랫폼 수준에서 할 수 있는 일. 관리 화면 진입, 사용자 조회, 에이전트 배포 심사 같은 권한입니다.AI혁신팀 강혁신 팀장은 관리자 그룹이라 Deep Admin의 모든 메뉴를 씁니다.
WBAC워크스페이스 범위한 워크스페이스 안에서의 역할. 구성원 관리, 에이전트·도구·모델 사용, API 토큰 발급 같은 권한입니다.영업팀 워크스페이스에서 팀장은 책임자, 팀원은 사용자 그룹입니다.
ABAC리소스 단위특정 도구, 모델, 스킬, 미들웨어, 지식 컬렉션을 쓸 수 있는지계약서 검토 도구는 법무 담당 그룹에만 엽니다.

세 권한은 모두 통과해야 합니다. 예를 들어 영업팀 직원이 워크스페이스 사용자 그룹(WBAC)이어도, 계약서 검토 도구가 ABAC 그룹으로 막혀 있으면 그 도구를 쓸 수 없습니다.

권한 화면 열기​

접근 권한 > 권한을 누르면 "권한 관리" 화면이 열립니다. 위쪽 탭으로 개요, RBAC, WBAC, ABAC를 바꿉니다. 권한을 체크하거나 해제하면 저장 버튼 없이 즉시 반영됩니다.

권한 관리 RBAC 탭

번호항목기능이런 때 사용하세요
1RBAC 탭플랫폼 전체 권한 그룹을 엽니다. 옆 탭은 개요, WBAC, ABAC입니다.정하려는 권한이 어느 범위인지 정한 뒤
2그룹 추가새 RBAC 그룹을 만듭니다. 그룹 이름과 설명(선택)을 적고 만들기를 누릅니다.새 역할이 필요할 때
3그룹 목록의 그룹(예: 관리자)누르면 오른쪽에 그 그룹의 권한이 열립니다. 목록에는 구성원 수와 권한 수가 함께 보입니다.그룹을 골라 권한을 볼 때
4권한 카테고리(예: 문서)카테고리를 펼쳐 권한 항목을 체크합니다. 오른쪽 숫자는 켜진 권한 수와 전체 수입니다.그룹의 권한을 늘리거나 줄일 때

화면 위 요약 카드에는 권한 그룹 수와 정의된 권한 수가 나옵니다. 그림에서 그룹의 내부 식별 정보는 흐리게 처리했습니다.

그룹 상세에서 보는 것​

그룹을 고르면 오른쪽에 상세가 열립니다. 배지로 기본, 시스템, 활성 여부가 보이고, 기본 그룹 스위치를 켜면 새 사용자가 이 그룹에 자동으로 들어갑니다. 권한 검색에 "사용자"처럼 적으면 해당 권한 항목만 남습니다.

  • 시스템 그룹과 기본 그룹은 삭제할 수 없습니다.
  • Deep Work 관리 권한은 이 화면이 아니라 Deep Work 관리 화면의 권한 메뉴에서 정합니다.

WBAC: 워크스페이스 안의 역할​

WBAC 탭은 워크스페이스 범위의 권한 그룹을 관리합니다. 각 워크스페이스는 이 그룹을 독립적으로 씁니다. 구성원에게 어떤 WBAC 그룹을 줄지는 사용자와 워크스페이스의 워크스페이스 설정에서 정합니다.

권한 관리 WBAC 탭

번호항목기능이런 때 사용하세요
1WBAC 탭워크스페이스 범위 권한 그룹을 엽니다.워크스페이스 역할을 정할 때
2그룹(예: 개발자)개발자, 관리자, 사용자, 책임자, 문서 담당자, 지식 담당자 같은 그룹 가운데 하나를 고릅니다.역할별 권한 범위를 비교할 때
3기본 그룹켜면 새 구성원이 이 그룹에 자동으로 들어갑니다. 옆의 기본 워크스페이스 기본 그룹은 기본 워크스페이스에 적용됩니다.신규 입사자가 기본으로 받을 역할을 정할 때
4권한 설정API 토큰, 리소스 등록 요청, 에이전트 같은 카테고리별로 권한을 체크합니다.역할에 권한을 더하거나 뺄 때

WBAC 카테고리는 워크스페이스 기본, 멤버 관리, 권한 관리, 에이전트, 도구, 모델, 스킬, 자격증명, API 토큰, 리소스 등록 요청으로 나뉩니다.

ABAC: 리소스 단위 권한​

ABAC 탭은 리소스 하나하나를 누가 쓸 수 있는지 묶는 그룹을 관리합니다. 그룹을 만들 때 리소스 타입(전체, 도구, 스킬, 미들웨어, 모델, 컬렉션)을 고르고, 그룹 상세의 참조 탭에서 그 그룹이 어떤 리소스에 걸려 있는지 확인합니다.

권한 관리 ABAC 탭

번호항목기능이런 때 사용하세요
1ABAC 그룹(예: 포탈 사용 권한)리소스 묶음 그룹을 고릅니다. 목록에는 그룹 이름, 리소스 타입, 시스템 여부가 보입니다.어떤 리소스 묶음이 있는지 볼 때
2활성 스위치그룹을 잠시 끄거나 켭니다. 옆의 기본 스위치는 기본 그룹 지정입니다. 시스템 그룹은 바꿀 수 없습니다.리소스 제한을 잠시 풀 때
3참조 탭그룹을 참조하는 리소스 목록을 봅니다. 옆 권한 탭에는 그룹이 가진 권한이 있습니다.그룹을 지우기 전에 영향 범위를 볼 때

ABAC 그룹을 삭제하면 그 그룹의 참조와 배정이 함께 회수됩니다. 지우기 전에 참조 탭에서 걸린 리소스를 꼭 확인하세요.

사람별 도구 권한​

접근 권한 > 사용자별 도구 권한은 사람을 골라 도구를 쓸 수 있게 하거나 거둡니다. 목록에서 사용자, 사번, 부서, 권한 그룹, 부여된 도구 수를 보고 상세를 눌러 들어갑니다.

할 일방법
한 사람에게 도구 부여상세에서 도구 권한 부여를 누르고 워크스페이스, 도구(여러 개), ABAC 그룹, 사용 기한, 부여 사유를 적은 뒤 부여합니다.
기한 정하기사용 기한을 무기한 또는 기한 지정으로 고릅니다. 기한 지정은 고른 날짜의 23시 59분 59초(한국 시간)까지입니다. 오늘 이전 날짜는 고를 수 없습니다.
회수행의 회수를 누르거나 여러 행을 골라 선택 회수를 누릅니다. 기록은 지워지지 않고 상태가 회수됨으로 바뀝니다.
여러 사람에게 한꺼번에목록의 대량 배정에서 부여 또는 회수를 고르고, 사용자와 도구 조합을 일괄 적용합니다. 확인 체크를 해야 실행되며, 실패한 조합은 CSV 내려받기로 받아 볼 수 있습니다.

상태는 사용 가능, 기한 만료, 회수됨, 사용 불가 중 하나로 표시됩니다. 상세 화면의 상태 필터에서 회수 제외를 고르면 지금 쓸 수 있는 권한만 남습니다.

지식 컬렉션 권한​

지식 컬렉션은 Deep Connector에서 문서를 묶은 검색 범위이고, Deep Agent Builder에서는 "지식"으로 보입니다. 접근 권한 > 지식 컬렉션 권한에서 컬렉션을 골라 접근 사용자를 추가하거나 회수합니다.

지식 컬렉션 권한 상세

번호항목기능이런 때 사용하세요
1접근 사용자 추가사용자(여러 명), 사용 기한(무기한 또는 기한 지정), 부여 사유를 적어 컬렉션을 엽니다.부서에 사내 규정 컬렉션을 열 때
2상태 필터전체, 사용 가능, 기한 만료, 회수됨정리할 만료 권한만 볼 때
3사용자 검색이름이나 사번으로 접근 사용자를 찾습니다.한 직원의 권한만 확인할 때
4사용 기한 열사용자별 기한입니다. 같은 표에 상태, 사용자(사번), 부서, 부여·회수 일시가 있고, 끝의 조작 열에서 권한 변경(사용 기한만 변경), 회수(사유 필수), 권한 이력을 엽니다.누가 언제까지 볼 수 있는지 확인할 때

그림은 아직 접근 사용자를 추가하기 전 상태입니다.

사용자별 지식 권한은 같은 정보를 사람 기준 폴더 구조로 보여 주는 조회 전용 화면입니다. 부여와 회수는 지식 컬렉션 권한에서 합니다.
