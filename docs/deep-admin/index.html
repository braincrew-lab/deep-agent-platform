Deep Admin 소개

Deep Admin은 Deep Platform의 통합 어드민입니다. Deep Agent Builder, Deep Connector, Deep Work의 관리 화면이 한곳에 모여 있어, 플랫폼 관리자가 사용자와 권한, 모델과 리소스, LLM 토큰 사용량과 한도, 에이전트 배포 심사, 감사 기록을 한 화면에서 관리합니다. 일반 직원은 이 화면에 들어오지 않고, 관리자 권한이 있는 계정만 로그인할 수 있습니다.

이 매뉴얼의 예시는 가상의 회사 "브레인크루"를 기준으로 합니다. AI혁신팀이 플랫폼 운영을 맡아, 강혁신 팀장이 관리자로서 직원 계정과 권한, 사용량을 관리합니다. AI혁신팀 김그루 사원은 Deep Agent Builder로 에이전트를 만들어 쓰는 직원으로 등장합니다.

이 페이지에서 할 수 있는 일

  • Deep Admin이 어떤 일을 맡는지, 누가 쓰는지 확인합니다.
  • 관리 메뉴가 어떤 묶음으로 나뉘는지 보고, 지금 필요한 업무가 어느 묶음에 있는지 찾습니다.
  • 직원 화면(Deep Agent Builder 등)과 관리자 화면이 어떻게 이어지는지 확인합니다.
  • 매뉴얼 구성을 보고 지금 필요한 페이지로 이동합니다.

관리 메뉴의 묶음​

Deep Admin 왼쪽 사이드바는 Agent Builder 관리 메뉴를 업무 단위로 묶어 보여 줍니다. 사이드바 맨 위의 관리 화면 선택에서 Deep Connector나 Deep Work를 고르면 사이드바가 그 제품의 관리 메뉴로 바뀝니다. 메뉴는 로그인한 관리자가 가진 권한에 따라 보이거나 숨겨집니다.

묶음들어 있는 메뉴
운영 현황대시보드, 에이전트 실행 로그, 에이전트 생성 로그, 에러/장애 모니터링, 관리자 접근기록, 인프라 모니터링(도입 예정)
사용자·승인사용자, 사용자별 통계, 토큰 한도 설정, LLM 토큰 사용량, 승인 관리

다른 제품과의 연결​

관리자 화면에서 정한 내용은 직원이 쓰는 화면에 그대로 나타납니다. 자주 묻는 연결 고리는 다음과 같습니다.

직원 화면에서 일어나는 일Deep Admin에서 확인할 곳
Deep Agent Builder에서 만든 에이전트를 전체 에이전트에 공유해 달라고 요청합니다.에이전트 > 전체 에이전트의 배포 요청 심사 탭에 요청이 올라옵니다.
에이전트 설정의 모델 목록에 특정 모델이 보이지 않습니다.리소스 > 모델에서 그 워크스페이스에 모델이 등록되어 있는지, 리소스 권한(ABAC 그룹)으로 막혀 있지 않은지 봅니다.
지식함에 사내 규정 컬렉션이 보이지 않습니다.접근 권한 > 지식 컬렉션 권한에서 그 직원에게 컬렉션이 열려 있는지, 사용 기한이 지나지 않았는지 봅니다.
대화 중 "토큰 한도를 초과했다"는 안내가 나옵니다.사용자·승인 > 사용자별 통계의 토큰 사용량 탭에서 사용률을 보고, 토큰 한도 설정에서 추가 토큰을 부여합니다.
에이전트 답변이 오류로 끝납니다.운영 현황 > 에러/장애 모니터링에서 에러 유형과 권장 조치를 확인합니다.

이 매뉴얼의 구성​

처음이라면 시작하기로 로그인과 대시보드를 익힌 뒤, 메뉴 안내에서 전체 메뉴 지도를 훑어보세요. 메뉴별 페이지는 사이드바 묶음 순서를 따릅니다.
