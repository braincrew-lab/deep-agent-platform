Deep Admin 사용자와 워크스페이스

플랫폼을 쓰는 직원의 계정과 소속 워크스페이스를 확인하고, 직원에게 역할(RBAC 그룹)과 워크스페이스 안 역할(WBAC 그룹)을 배정하는 방법을 설명합니다. 예시는 브레인크루 AI혁신팀 김그루 사원의 계정입니다.

이 페이지에서 할 수 있는 일

  • 사용자 목록에서 직원을 찾고 상세 정보를 봅니다.
  • 직원에게 RBAC 그룹을 배정하거나 해제합니다.
  • 워크스페이스 구성원과 구성원별 WBAC 그룹을 정합니다.
  • 워크스페이스 템플릿과 워크스페이스별 사용량을 확인합니다.

사용자 목록​

사용자·승인 > 사용자를 누르면 "사용자 목록"이 열립니다. 플랫폼에 한 번 이상 로그인한 계정이 보입니다. 관리자 화면에서 계정을 직접 만들거나 초대하는 버튼은 없으므로, 신규 입사자는 먼저 Deep Agent Builder에 로그인해야 목록에 나타납니다.

사용자 목록

번호항목기능이런 때 사용하세요
1검색창이름, 사번, 사용자 ID로 찾습니다.문의한 직원을 찾을 때
2워크스페이스 필터고른 워크스페이스의 구성원만 봅니다. 오른쪽 전체 권한 그룹으로 RBAC 그룹별로도 거릅니다.한 부서 구성원만 볼 때
3RBAC 그룹 열직원마다 배정된 역할(사용자, 관리자 등)입니다. 왼쪽에 워크스페이스, 이름, 사번이 있습니다.직원의 현재 역할을 볼 때
4행 메뉴의 상세 보기행 끝 메뉴를 누르면 상세 보기와 RBAC 그룹(그룹 배정 창)이 나옵니다.역할을 바로 바꾸거나 자세히 볼 때

RBAC 그룹 창에서는 그룹을 검색해 체크하거나 해제합니다. 체크하는 즉시 반영되고, 닫기로 창을 닫습니다.

사용자 상세​

상세 보기를 누르면 한 사람의 정보가 다섯 탭으로 나옵니다.

사용자 상세 개요

번호항목기능이런 때 사용하세요
1개요 탭계정 정보를 봅니다. 옆 탭 리소스, 에이전트, 보안, 활동에서 도구·모델·스킬, 만든 에이전트, API 토큰, 실행 목록을 봅니다.직원 한 명을 자세히 볼 때
2그룹 추가RBAC 그룹을 골라 추가합니다. 배정된 그룹 행마다 해제 버튼이 있습니다. 시스템 그룹은 로그인할 때 자동 배정되어 수동으로 추가할 수 없습니다.역할을 더하거나 뺄 때
3소속 워크스페이스직원이 속한 워크스페이스(예: AI혁신팀)와 그 안의 RBAC 그룹입니다.소속 부서 워크스페이스를 확인할 때
4마지막 로그인기본 정보의 한 항목입니다. 같은 칸에 사용자 ID, 사번, 사용자 유형, 가입일, 수정일이 있습니다.최근에 로그인했는지 볼 때

화면 아래 실행 통계 카드에는 최근 30일 총 실행 수, 에러 수, 성공률, 평균 시간, 상태별 분포가 나옵니다.

위쪽 기본 정보에는 사용자 ID, 사번, 사용자 유형, 가입일, 마지막 로그인, 수정일이 나옵니다.

본인 계정의 RBAC 그룹은 바꿀 수 없습니다. 다른 관리자에게 요청하세요.

탭보여 주는 내용
리소스직원이 쓸 수 있는 도구, 모델, 스킬(이름, 원본, 설명)
에이전트직원이 가진 에이전트의 이름, 모델, 도구, 미들웨어, 스킬, 상태
보안직원이 발급한 API 토큰(이름, 접두사, 범위, 상태, 사용량, 마지막 사용, 만료)과 폐기 버튼
활동실행 목록(에이전트, 상태, 유형, 소요 시간, 생성일)

워크스페이스 목록과 설정​

워크스페이스는 부서나 프로젝트 단위로 에이전트와 리소스를 나누는 공간입니다. 브레인크루 예시에는 회사 공용 "브레인크루"와 AI혁신팀, 영업팀, 마케팅팀, 경영지원팀, 인사팀, 재무팀 워크스페이스가 있습니다. 워크스페이스 > 워크스페이스 목록에서 이름과 ID로 찾고, 관리를 누르면 워크스페이스 설정으로 이동합니다.

워크스페이스 설정

번호항목기능이런 때 사용하세요
1워크스페이스 선택관리할 워크스페이스를 고릅니다.부서 워크스페이스를 열 때
2기본 설치 모델의 모델 항목체크한 모델이 이 워크스페이스의 기본 설치 모델이 됩니다. 예시는 DeepSeek V4 Flash, Claude Sonnet 4.6, GPT-4.1 mini, GPT-4.1 네 개입니다.부서에서 기본으로 쓸 모델을 정할 때
3저장고른 기본 설치 모델을 저장합니다.모델을 고른 뒤

기본 설치 모델 아래에는 구성원 목록(사번, 그룹, 상태)이 나오고, 사번이나 사용자 ID로 검색할 수 있습니다. 그룹 칸을 누르면 WBAC 그룹 설정 창이 열립니다. 한 명이면 체크한 그룹으로 바꾸고, 여러 명을 골라 WBAC 그룹 설정을 누르면 체크한 그룹을 더합니다.

구성원 목록 대신 "접근 권한이 없습니다"와 "워크스페이스 권한 그룹에 배정되어 있는지 확인하세요"가 보이면, 로그인한 관리자가 그 워크스페이스의 WBAC 그룹에 없는 것입니다. 플랫폼 전체 관리자라도 워크스페이스 구성원 관리는 그 워크스페이스의 권한 그룹이 있어야 합니다.

워크스페이스 템플릿​

워크스페이스 템플릿은 워크스페이스 구성원이 새 에이전트를 만들 때 고를 수 있는 템플릿을 관리합니다. 워크스페이스를 고르면 등록된 템플릿(에이전트, 설명, 모델, 등록자)이 보이고, 템플릿 관리에서 워크스페이스 에이전트를 등록하거나 해제합니다.

예를 들어 브레인크루 영업팀 워크스페이스에 "주간 영업 보고서 작성 도우미" 에이전트를 템플릿으로 등록해 두면, 영업팀 신입 사원이 같은 형식으로 바로 시작할 수 있습니다.

워크스페이스 사용량​

사용량 관리는 워크스페이스 하나를 골라 기간 안의 총 실행 수, 에러율, 활성 사용자 수, 평균 응답 시간과 실행 추이, 상위 사용자 10명을 보여 줍니다. 워크스페이스를 고르지 않으면 내용이 나오지 않습니다.

워크스페이스 사용량

번호항목화면에 보이는 내용이런 때 확인하세요
1워크스페이스 선택볼 워크스페이스를 고릅니다.부서별 활용도를 비교할 때
230일기간을 최근 30일로 정합니다. 오늘, 7일, 전체나 날짜 직접 지정도 됩니다.월간 보고 기간에 맞출 때
3총 실행 수기간 안 실행 횟수입니다. 옆에 에러율, 활성 사용자 수, 평균 응답 시간이 있습니다.부서가 실제로 쓰고 있는지 볼 때
4실행 추이실행 횟수를 전체, 성공, 오류로 나눈 그래프입니다.교육이나 공지 뒤 사용이 늘었는지 볼 때

그림의 실행 추이 가로축 날짜가 모두 "오전 12:00"으로 보이는 것은 연습 환경의 표시 문제입니다. 실제 화면에서는 날짜별로 표시됩니다.

화면 아래 **상위 사용자 (Top 10)**에는 사용자, 실행 수, 에러 수, 에러율, 평균 응답 시간이 나옵니다. 교육 효과가 큰 직원이나 도움이 필요한 직원을 찾을 때 봅니다.
