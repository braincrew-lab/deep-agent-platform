Brain Parser 지원 파일 형식과 한도

이 페이지는 Brain Parser가 받는 파일 확장자 20가지와 용량·쪽수 한도, 받지 않는 형식을 바꿔 넣는 방법을 정리합니다.

이 페이지에서 할 수 있는 일

  • 받는 확장자 전체와 형식별 읽는 방식을 확인합니다.
  • 파일 크기, 쪽수, 처리 시간의 기본 한도를 압니다.
  • 받지 않는 형식을 어떻게 바꿔 넣을지 정합니다.

지원하는 확장자 전체​

Brain Parser는 다음 20가지 확장자를 받습니다. 확장자의 대소문자는 가리지 않습니다(예: PDF와 pdf 모두 받음).

분류확장자읽는 방식주로 쓰는 문서
PDFpdf영역마다 PDF 글자 또는 문자 인식 모델보고서, 계약서, 규정, 스캔 문서
이미지png, jpg, jpeg, tiff, tif, bmp, webp문자 인식 모델영수증 사진, 스캔한 서류, 화면 캡처
워드docx, doc파일 구조 읽기(doc는 docx로 바꾼 뒤 읽기)계약서 초안, 회의록, 제안서
파워포인트pptx, ppt파일 구조 읽기(ppt는 문서 해석 라이브러리가 바꾼 뒤 읽기)보고 발표 자료, 교육 자료
엑셀xlsx, xls시트를 표로 읽기(xls는 xlsx로 바꾼 뒤 읽기)판매 실적, 견적서, 예산표
한글hwp, hwpx자체 한글 해석기공문, 사내 규정, 기안문
웹 문서html, htm자체 해석기저장한 웹 페이지, 사내 공지
마크다운md제목 구조를 살려 읽기메모, 위키 문서
메일msg자체 해석기(첨부 문서 포함)아웃룩에서 저장한 메일

doc, ppt, xls는 서버의 오피스 변환 도구로 새 형식으로 바꾼 뒤 읽습니다. 변환에 실패한 xls는 서식 없이 값만 읽을 수 있습니다.

받지 않는 형식과 바꾸는 방법​

목록에 없는 확장자를 보내면 "지원하지 않는 형식" 오류와 함께 받는 확장자 목록이 돌아옵니다.

가진 파일바꾸는 방법
txt(텍스트), csv(쉼표로 나눈 표)Brain Parser 자체는 받지 않습니다. Deep Docurator에서는 이 두 형식을 Deep Docurator가 직접 읽으므로 그대로 넣으면 됩니다. 사내 시스템에서 직접 보낼 때는 내용을 md나 xlsx로 저장합니다.
gifpng로 다시 저장합니다.
xlsm, xlsb엑셀에서 xlsx로 다시 저장합니다.
zip(여러 문서 묶음)압축을 풀어 문서를 한 개씩 보냅니다.
문서 보안(DRM)이 걸린 파일보안을 해제한 파일을 보냅니다. 걸린 상태로는 암호화 문서 오류가 나고, PDF는 손상된 문서 오류로 나올 수도 있습니다.

용량과 쪽수 한도​

다음 값은 기본값이며, 운영 담당자가 서버 설정에서 바꿀 수 있습니다. 실제 한도는 운영 담당자에게 확인하세요.

항목기본값넘으면
파일 한 개 크기150MB파일이 너무 크다는 오류(파일을 받지 않음)
PDF 쪽수5,000쪽쪽수 한도를 넘었다는 오류. PDF에만 적용됩니다.
문서 한 개 처리 시간PDF는 기본 300초에 쪽마다 10초를 더한 값(최대 4시간), 그 밖의 형식은 최대 4시간처리 시간 초과 오류
결과 보관 기간30일결과를 다시 받을 수 없다는 오류. 다시 처리해야 합니다.
메일 첨부첨부 50개, 첨부 안의 첨부는 두 단계까지, 첨부 한 개 100MB넘는 첨부는 읽지 않습니다. 20KB보다 작은 첨부 그림도 건너뜁니다.

한글 문서는 압축을 푼 내부 데이터가 100MB를 넘거나 표 하나의 칸이 25만 개를 넘으면 손상된 문서로 처리합니다.

Deep Docurator와 Deep Connector는 자체 업로드 한도를 따로 둡니다. 예를 들어 Deep Docurator 입력 노드의 기본 한도는 500MB이지만, Brain Parser 쪽 한도가 150MB이면 그보다 큰 파일은 파싱 단계에서 실패합니다.

형식을 고르는 요령​

상황추천
같은 문서가 한글과 PDF로 모두 있음한글 원본을 넣으면 표와 수식이 원본 구조 그대로 나옵니다. PDF로 바꾸면 글꼴이나 표 정렬이 깨질 수 있습니다.
엑셀 자료xlsx 원본을 넣습니다. 시트마다 표로 나오고 숫자 서식이 유지됩니다.
종이 서류기울지 않게, 글자가 선명하게 스캔한 png나 PDF를 넣습니다.
발표 자료pptx를 넣으면 슬라이드마다 구분선으로 나뉘어 나옵니다.
