Brain Parser 성능 지표 (벤치마크 기준)

이 페이지의 수치는 모두 Brain Parser 제품 저장소에 결과가 남아 있는 벤치마크에서 가져왔습니다. 결과 기록이 없는 항목은 "정보없음"으로 적었습니다. 수치는 측정한 문서와 조건에서의 결과이며, 다른 문서나 다른 운영 환경에서도 같은 결과가 나온다는 뜻은 아닙니다.

이 페이지에서 할 수 있는 일

  • 측정에 쓴 벤치마크, 데이터셋, 지표 정의를 확인합니다.
  • Brain Parser와 비교 대상의 점수를 봅니다.
  • 결과를 해석할 때의 한계를 압니다.

벤치마크 개요​

항목내용
벤치마크 이름Brain Parser 파싱 성능 비교(25쪽 평가 세트)
데이터셋실제 업무 문서 25쪽. PDF 15쪽 + 원본 형식(한글·엑셀·파워포인트) 10쪽. 세부 구성은 정보없음
정답PDF 15쪽은 사람이 원문을 보고 작성. 엑셀·파워포인트는 원본 칸과 슬라이드에 맞춰 작성. 한글 일부는 Brain Parser 결과를 사람이 고쳐 작성
입력 방식PDF 15쪽은 모든 엔진에 같은 PDF를 넣음. 원본 형식 10쪽은 Brain Parser에 원본 파일을, 다른 엔진에는 원본을 PDF로 바꾼 파일을 넣음
비교 대상시각 언어 모델 2종(Qwen3-VL-4B, Qianfan-OCR), PDF 글자 추출 도구 2종(PyMuPDF, pypdfium2)
측정 하드웨어정보없음
Brain Parser 버전과 모델 설정정보없음
비교 대상 버전과 설정정보없음(시각 언어 모델 두 종은 설정을 따로 조정하지 않았다고만 기록됨)

지표 정의​

점수는 0부터 1 사이 값이며, 쪽마다 계산한 뒤 25쪽을 평균합니다.

지표정의좋은 방향
텍스트 정확도서식 기호를 지운 정답 글과 결과 글의 글자 단위 편집 거리를 두 글 중 긴 쪽의 글자 수로 나눈 값을 1에서 뺀 값높을수록 좋음
구조 보존표 개수, 표의 행·열 수, 제목 단계별 개수, 목록 항목 수를 각각 1 − (정답과 결과의 개수 차이 ÷ 둘 중 큰 개수)로 계산해 평균한 값. 정답에 있는 요소만 비교하며, 정답에 구조가 하나도 없는 쪽은 1높을수록 좋음
누락률정답의 글 덩어리(다섯 글자 이상인 줄이나 표 칸) 가운데 결과에서 찾지 못한 비율낮을수록 좋음
환각률결과의 글 덩어리 가운데 정답에 없는 비율낮을수록 좋음
종합 점수텍스트 정확도 40% + 구조 보존 30% + (1 − 누락률) 15% + (1 − 환각률) 15%높을수록 좋음

글 덩어리를 "찾았다"고 보는 기준은 대소문자를 무시하고 한쪽이 다른 쪽에 포함되거나, 열 글자가 넘는 덩어리의 글자 가운데 다른 쪽 덩어리에도 들어 있는 글자의 비율(순서는 보지 않음)이 70%를 넘는 경우입니다.

결과를 읽을 때의 한계​

  • 25쪽 소규모 평가이며 통계적 신뢰구간은 계산하지 않았습니다.
  • 원본 형식 10쪽은 Brain Parser만 원본 파일을 받았습니다. 원본을 직접 읽을 수 있다는 점이 점수에 반영된 결과입니다.
  • 한글 정답 일부는 Brain Parser 결과를 고쳐 만들었으므로 그 쪽은 Brain Parser에 유리할 수 있습니다.
  • 다른 오픈소스 변환 도구(Marker, MinerU 등)는 실행 환경 문제로 비교하지 못했습니다.
  • 시각 언어 모델은 조밀한 표에서 같은 칸을 반복해 쓰는 경우가 있었고, 두 모델 모두 설정을 따로 조정하지 않았습니다.
  • 측정 하드웨어와 측정 당시 Brain Parser 버전이 기록되지 않아, 지금 버전의 점수와 같다고 볼 수 없습니다.

측정 기록이 없는 항목​

항목상태
처리 속도(쪽당 시간, 초당 처리 쪽수)정보없음 — 이 페이지의 기준 보고서에 결과가 없음
공개 벤치마크(OmniDocBench) 점수정보없음 — 이 페이지의 기준 보고서에 결과가 없음
한국어 문자 인식 벤치마크(CC-OCR 한국어, MDPBench 한국어) 점수정보없음 — 이 페이지의 기준 보고서에 결과가 없음
동시 처리량(여러 요청을 한꺼번에 보낼 때)정보없음

처리 속도가 필요하면 운영 환경에서 실제 문서로 따로 측정하세요.
