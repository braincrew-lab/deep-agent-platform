Brain Parser 반복 업무

긴 문서의 검토 범위 정하기​

첫 실습을 마쳤다면 여러 페이지 문서의 검토 순서를 정합니다. 이 절차는 사람이 누락과 읽는 순서를 확인하는 방법이며 자동 검사 기능이 아닙니다. 원본과 결과를 모두 볼 수 있는 상태에서 시작하세요.

다음 업무에 필요한 범위를 먼저 고릅니다. 운영 안내문이라면 적용 대상, 신청 절차, 비용 표, 예외 조건을 각각 적어 두세요. 첫 페이지와 마지막 페이지만 보고 중간 내용까지 확인했다고 판단하지 않습니다.

위치를 잃지 않고 대조하기​

  1. 원본의 큰 제목을 순서대로 적습니다. 목차가 있다면 실제 본문 제목과 일치하는지도 확인합니다.
  2. 각 제목 아래에서 첫 문장과 마지막 문장을 고릅니다. 원본 페이지 번호는 위치를 다시 찾기 위한 보조 정보로 기록합니다.
  3. 결과에서 같은 제목이나 문장을 찾아 순서를 비교합니다. 결과의 페이지 번호만으로 대응 위치를 정하지 마세요.
  4. 표와 목록이 다음 페이지로 이어지면 경계 양쪽을 함께 확인합니다. 항목이 끊기거나 반복되는지 살펴봅니다.
  5. 중요한 수치와 조건은 해당 범위 전체를 대조합니다. 표본만 본 범위는 전체 확인 범위와 구분합니다.
원본 위치대조 대상기록 예시
신청 절차 절목록 전체모든 항목 확인
비용 표가 이어지는 부분이전 페이지 마지막 행과 다음 페이지 첫 행다음 페이지 첫 행의 단위 재확인
마지막 절예외 조건 문장결과에서 문장을 찾지 못함

이 표는 가상의 기록 예시입니다. 제품이 자동으로 생성하는 표가 아닙니다.

차이가 있는 부분 다시 검토하기​

원본에서도 글자가 잘렸거나 내용이 비어 있다면 더 읽기 쉬운 원본을 확보할 수 있는지 확인하세요. 원본은 정상인데 결과가 다르면 위치, 기대한 문장이나 값, 실제 차이를 적습니다.

재처리를 제공받은 경우 해당 제품의 절차를 따릅니다. 새 결과에서는 문제 부분을 먼저 대조한 뒤 앞뒤 문단과 관련 표도 확인하세요. 같은 파일 이름만 보고 이전 결과를 다시 읽지 않도록 처리 시점도 구분해 두는 것을 권합니다.

검토 인계하기​

다음 담당자가 필요한 위치를 찾도록 문서 이름, 원본 위치, 확인한 범위와 미확인 범위를 남깁니다. 원본에 민감한 내용이 있으면 조직에서 허용한 전달 방법을 사용하고 불필요한 본문 전체를 복사하지 마세요.

누락이 업무 판단에 영향을 준다면 해당 내용을 사용하기 전에 추가 확인을 요청합니다. 새 결과를 실제로 대조하기 전에는 재처리만으로 해결됐다고 기록하지 않습니다. 활용 사례에서 표 검토를 연습하고, 문제 해결에서 증상별 조치를 찾으세요.
