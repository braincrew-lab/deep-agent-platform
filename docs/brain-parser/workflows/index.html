Brain Parser 반복 업무

첫 실습을 마쳤다면 여러 쪽짜리 문서나 여러 파일을 같은 기준으로 읽고 검토하는 순서를 정합니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 매주 받는 자료를 Brain Parser로 읽어 다음 업무에 넘기는 흐름을 예로 듭니다.

이 페이지에서 할 수 있는 일

  • 문서를 넣기 전에 형식과 크기를 정리합니다.
  • 긴 문서의 결과를 위치를 잃지 않고 대조합니다.
  • 여러 파일을 같은 플로우로 반복 처리합니다.
  • 검토 결과를 다음 담당자에게 넘깁니다.

넣기 전에 정리하기​

확인할 것이렇게 합니다
형식지원 파일 형식의 20가지 확장자인지 봅니다. txt와 csv는 Deep Docurator에서는 그대로 넣고, 사내 시스템에서 직접 보낼 때는 md나 xlsx로 바꿉니다.
원본 형식이 따로 있는지한글·엑셀 원본이 있으면 PDF보다 원본을 넣습니다. 표와 수식이 원본 구조대로 나옵니다.
크기와 쪽수기본 한도는 파일 150MB, PDF 5,000쪽입니다. 수백 쪽짜리는 필요한 장만 따로 저장하면 검토가 쉽습니다.
문서 보안보안이 걸린 파일은 해제한 뒤 넣습니다.
스캔 품질기울거나 흐린 스캔은 다시 스캔합니다. 글자가 흐리면 문자 인식 결과도 흐려집니다.

긴 문서의 검토 범위 정하기​

여러 쪽짜리 문서는 모든 문장을 같은 깊이로 보기 어렵습니다. 다음 업무에 꼭 필요한 범위(예: 요금 표, 신청 절차, 예외 조건)를 먼저 고르고, 그 범위를 다음 순서로 대조합니다.

  1. 원본의 큰 제목을 순서대로 적습니다. 목차가 있으면 실제 본문 제목과 맞는지도 봅니다.
  2. 결과에서 같은 제목을 찾아 순서를 비교합니다. 결과의 절 제목 블록이 원본의 장·절과 같은 단계로 나왔는지 봅니다.
  3. 쪽을 넘어 이어지는 표는 앞 쪽 마지막 행과 다음 쪽 첫 행을 함께 봅니다. 행이 끊기거나 두 번 나오지 않았는지 확인합니다.
  4. 금액, 날짜, 비율, 조건 문장은 해당 범위 전체를 대조합니다. 일부만 본 범위는 따로 표시합니다.
  5. 그림 설명은 원본 그림과 한 번 비교합니다. 설명은 그림 설명 모델이 쓴 글이므로 숫자가 중요하면 원본 그림에서 직접 확인합니다.
원본 위치대조 대상기록 예시
3장 요금 표표 전체모든 행 확인
4~5쪽에 걸친 표4쪽 마지막 행과 5쪽 첫 행5쪽 첫 행 단위 재확인 필요
마지막 장예외 조건 문장결과에서 문장을 찾지 못함

결과의 쪽 번호는 원본과 일대일로 맞지 않을 수 있습니다. 엑셀은 시트, 파워포인트는 슬라이드 단위로 세고, 한글 문서는 쪽 정보 설정에 따라 다릅니다. 쪽 번호보다 제목과 문장으로 위치를 찾습니다.

여러 파일을 같은 기준으로 처리하기​

Deep Docurator에서는 파싱 플로우 하나를 만들어 두고 입력 노드의 파일을 바꿔 가며 실행합니다.

  1. 시작하기에서 만든 플로우를 엽니다.
  2. 입력 노드의 옵션 & 미리보기 탭에서 다음 파일을 넣습니다. 앞의 파일을 대신합니다.
  3. ▶ 버튼으로 실행하고 파싱 노드의 블록 수와 쪽 수를 먼저 봅니다. 원본 쪽수보다 크게 적으면 결과를 열어 빠진 쪽을 찾습니다.
  4. 결과를 대조한 뒤 다음 파일로 넘어갑니다.

매주 같은 종류의 자료(예: 주간 판매 데이터, 회의록)를 읽는다면 파싱 다음에 청킹이나 필드 추출 노드를 붙인 플로우를 프리셋으로 저장해 두면 편합니다. 방법은 Deep Docurator 프리셋과 템플릿 플로우에 있습니다.

다시 처리할 때​

  • 원본이 흐리거나 잘렸다면 더 선명한 원본을 먼저 구합니다.
  • 원본 형식(한글, 엑셀)이 따로 있으면 그것으로 다시 넣어 결과를 비교합니다.
  • 다시 처리한 결과에서는 문제였던 부분을 먼저 보고, 앞뒤 문단과 관련 표도 함께 봅니다.
  • 다시 처리했다는 사실만으로 해결됐다고 적지 않습니다. 새 결과를 대조한 뒤 기록합니다.

검토 결과 넘기기​

다음 담당자가 위치를 찾을 수 있게 다음을 남깁니다.

남길 것예시
문서 이름과 형식서비스이용계약서_샘플.pdf
확인한 범위제1조~제7조 본문, 제3조 금액
확인하지 못한 범위서명란(스캔 화질 낮음)
다른 점없음, 또는 "제4조 가용률이 99.5%가 아니라 995%로 나옴"

원본에 민감한 내용이 있으면 조직이 허용한 방법으로만 넘기고, 본문 전체를 대화에 붙이지 않습니다.
