Brain Parser 결과 형식 읽기

Brain Parser의 결과는 마크다운, JSON, HTML 세 가지 형식으로 받습니다. 이 페이지는 형식마다 무엇이 들어 있는지, 블록 종류가 결과에서 어떻게 보이는지 정리합니다.

이 페이지에서 할 수 있는 일

  • 세 가지 결과 형식의 차이와 쓰임새를 압니다.
  • 블록 종류가 결과에서 어떻게 표시되는지 압니다.
  • JSON 결과의 쪽 번호와 위치 정보를 읽습니다.

결과 형식 세 가지​

형식담기는 내용이런 때 사용하세요
마크다운제목은 샵 기호(#), 표는 마크다운 표, 수식은 LaTeX로 적은 문서 전체 글사람이 읽거나 요약·번역 같은 다음 작업에 그대로 넘길 때
JSON문서 전체 글(일반 글과 마크다운 두 가지), 파일 이름, 전체 쪽수, 쪽마다의 블록 목록블록 종류, 쪽 번호, 위치를 프로그램에서 쓸 때
HTML제목, 문단, 표를 HTML 태그로 적은 결과. 위험한 태그는 지운 뒤 돌려줍니다.웹 화면에 바로 보여 줄 때

Deep Docurator와 Deep Connector는 JSON 결과를 받아 블록 단위로 화면에 보여 줍니다. 사내 시스템에서 직접 받을 때는 요청할 때 형식을 고릅니다.

블록 종류​

Brain Parser는 문서의 요소를 다음 12가지 블록으로 나눕니다. 이 밖에 영역을 하나도 찾지 못한 쪽은 JSON 결과에 빈 블록 하나로 남습니다.

블록뜻마크다운에서 보이는 모양
제목문서 제목샵 기호 한 개(#)로 시작하는 줄
절 제목장·절·조항 제목샵 기호 두 개 이상으로 시작하는 줄
본문일반 문단그대로
목록 항목글머리표나 번호가 붙은 항목줄 앞에 하이픈
표표마크다운 표. 합친 칸이 있으면 HTML 표
그림사진, 도형, 일러스트그림 자리 표시(그림 설명이 켜져 있으면 설명 글이 앞에 붙음)
차트막대·선·원 그래프차트 자리 표시(설명 글이 앞에 붙음)
수식수식달러 기호 두 개로 감싼 LaTeX
캡션표·그림 설명 문구기울임 글씨
머리말페이지 위쪽 반복 문구화면에 보이지 않는 주석
꼬리말페이지 아래쪽 반복 문구, 쪽 번호화면에 보이지 않는 주석
각주각주·미주각주 번호와 내용

여러 쪽으로 된 문서의 마크다운 결과에서는 쪽과 쪽 사이에 가로줄(---)이 들어갑니다. 파워포인트는 슬라이드마다, 엑셀은 시트마다 나뉩니다.

JSON 결과의 구성​

항목내용
문서 전체 글서식 없는 글과 마크다운 글 두 가지
파일 이름보낸 파일의 이름
전체 쪽수문서의 쪽수(엑셀은 시트 수, 파워포인트는 슬라이드 수)
쪽 목록쪽마다 쪽 번호와 블록 목록. 쪽 번호는 0부터 셉니다(첫 쪽이 0).
블록블록 종류, 글, 마크다운, 위치, 신뢰도 점수
빠진 쪽, 경고읽지 못한 쪽이나 주의할 점이 있을 때만 붙습니다

블록의 위치는 쪽 크기를 1로 본 비율 값(왼쪽, 위, 오른쪽, 아래)입니다. 위치와 신뢰도 점수는 PDF와 이미지에서 나오고, 오피스·한글 문서처럼 파일 구조를 읽는 형식에서는 비어 있을 수 있습니다. 그림과 차트 블록에는 그림 데이터가 함께 들어 있습니다. 여러 쪽에 걸친 블록에는 끝나는 쪽 정보가 붙습니다.

표 칸 검출을 켜고 보내면 표 블록에 칸마다 위치, 글, 행·열 번호, 합친 행·열 수가 더 붙습니다.

예시: 계약서 스캔본의 JSON 결과​

시작하기에서 읽은 계약서 스캔본의 JSON 결과는 전체 쪽수 1, 첫 쪽(쪽 번호 0)에 블록 14개였습니다. 첫 블록은 절 제목 "제1조 (목적)", 두 번째 블록은 본문 "본 계약은 주식회사 브레인크루…"였고, 블록마다 위치와 신뢰도 점수가 붙어 있었습니다.
