Brain Parser 시작하기

첫 실습의 목표와 준비물​

제목, 본문, 간단한 표가 있는 짧은 문서 한 개를 변환하고 세 부분을 원본과 대조합니다. 아래는 가상 연습 내용입니다. 문서 작성 도구에서 한 페이지에 담고 이용 중인 제품이 받는 형식으로 저장하세요.

제목은 “회의실 이용 안내”로 적습니다. 본문은 “회의실은 오전 9시부터 오후 6시까지 이용합니다. 사용 후에는 의자를 정리하고 조명을 꺼 주세요.”로 적습니다.

회의실정원이용 시간
가온6명09:00–18:00
나래10명09:00–18:00

이 수치는 연습용이며 실제 조직의 기준이 아닙니다. 원본을 열어 제목과 표가 잘리지 않았는지 확인합니다.

제공받은 화면에서 결과 열기​

  1. Brain Parser를 제공받은 제품의 안내에서 문서 변환 위치와 결과 확인 위치를 찾습니다. 모르면 관리자에게 두 위치를 먼저 확인합니다.
  2. 화면의 허용 형식과 용량을 확인한 뒤 방금 저장한 파일을 전달합니다. 파일 이름과 내용을 대조해 다른 문서를 고르지 않았는지 확인하세요.
  3. 해당 제품이 안내하는 처리 절차를 진행하고 결과를 엽니다. 완료 여부도 해당 제품의 안내를 따릅니다.
  4. 결과와 원본을 함께 준비합니다. 다음 대조 순서는 특정 메뉴가 아니라 사용자가 수행할 검토 방법입니다.

Deep Docurator를 이용한다면 별도의 화면 사용 안내를 참고할 수 있습니다. 그 안내를 모든 제공 환경에 동일하게 적용하지 마세요.

제목에서 표까지 대조하기​

  1. 결과에서 “회의실 이용 안내”를 찾습니다. 다른 제목으로 바뀌거나 본문 중간에 끼어 있지 않은지 확인합니다.
  2. 본문을 끝까지 읽습니다. 이용 시간과 사용 후 행동이 모두 남아 있는지 원문 두 문장과 비교합니다.
  3. 표의 “회의실”, “정원”, “이용 시간”을 확인합니다. 각 열의 의미가 구분되는지 살펴보세요.
  4. “가온”과 “6명”, “나래”와 “10명”이 각각 연결되는지 대조합니다. 숫자만 찾아 끝내지 않습니다.
  5. 두 회의실의 시간 범위가 09:00–18:00인지 확인합니다. 구분 기호가 달라도 시작과 종료 시간이 분명한지 읽어 봅니다.

첫 검토를 마치는 기준​

제목, 두 문장, 두 데이터 행이 모두 원본과 맞으면 이번 연습의 검토를 마칩니다. 표 모양이 달라도 항목과 값의 관계가 유지되는지가 핵심입니다. 이번 확인이 모든 문서의 정확성을 보장하지는 않습니다.

차이는 “원본 표의 나래 정원은 10명, 결과는 1명”처럼 위치와 함께 기록합니다. 원본에도 같은 오류가 있는지 확인하고 결과에서만 다르면 문제 해결을 따르세요. 다음으로 주요 기능과 검토 대상에서 복잡한 문단과 표를 살펴봅니다.
