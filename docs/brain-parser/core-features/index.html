Brain Parser 주요 기능

이 페이지는 Brain Parser가 문서의 각 요소(본문, 표, 수식, 그림, 머리말과 꼬리말)를 어떻게 읽는지, 형식마다 무엇이 다른지 설명합니다. 결과가 기대와 다를 때 어느 단계에서 생긴 차이인지 짐작하는 데 도움이 됩니다.

이 페이지에서 할 수 있는 일

  • PDF를 영역마다 다르게 읽는 방식을 압니다.
  • 표, 수식, 그림이 결과에 어떻게 나오는지 압니다.
  • 한글 문서와 메일 파일을 읽을 때의 특징을 압니다.

PDF를 영역마다 읽기​

PDF 한 페이지에는 제목, 본문, 표, 그림이 섞여 있습니다. Brain Parser는 먼저 레이아웃 모델로 페이지의 영역을 찾고, 영역마다 어떤 방법으로 읽을지 정합니다.

영역읽는 방법
PDF 안의 글자가 온전한 본문·제목PDF에 들어 있는 글자를 그대로 씁니다. 모델이 읽는 것보다 빠르고 오탈자가 생기지 않습니다.
글자가 깨졌거나 비어 있는 영역영역을 이미지로 잘라 문자 인식 모델이 읽습니다. 깨짐은 페이지 전체가 아니라 영역마다 판단합니다.
선으로 칸이 그려진 표그려진 선으로 행과 열을 정하고, 칸마다 PDF의 글자를 채웁니다.
그 밖의 표표 영역을 잘라 문자 인식 모델이 칸 구조(합친 칸 포함)째 읽습니다.
그림, 차트그림 설명 모델이 그림을 글로 설명하고 그림 안의 글자도 옮깁니다. 페이지 위·아래 반복 영역에 있는 글자 없는 로고나 아이콘은 설명하지 않습니다.
아무것도 그려지지 않은 영역모델에 보내지 않습니다.

PDF에 보이지 않게 숨겨 둔 글자가 많은 영역은 PDF 글자를 믿지 않고 문자 인식 모델로 읽습니다. 문자 인식 결과가 한국어가 아닌 다른 글자로 나왔는데 그 자리의 PDF 글자가 한국어이면 PDF 글자로 바꿉니다.

스캔 PDF와 이미지(png, jpg, jpeg, tiff, tif, bmp, webp)는 PDF 안에 글자가 없으므로 모든 영역을 문자 인식 모델이 읽습니다.

표​

표는 결과에서 다음과 같이 나옵니다.

표 모양마크다운 결과JSON·HTML 결과
칸을 합치지 않은 표파이프(세로줄)로 나눈 마크다운 표표 블록
칸을 합친 표합친 칸 정보를 지키려고 HTML 표 그대로 둡니다표 블록(합친 칸 포함)
엑셀 시트시트마다 시트 이름 제목과 표표 블록

엑셀 표의 숫자는 엑셀 화면에 보이는 서식(천 단위 쉼표, 소수 자리)대로 옮깁니다. 숨긴 행과 열은 넣지 않습니다. 날짜 칸은 시각까지 붙어 나올 수 있으니(예: 2026-01-01 00:00:00) 날짜만 쓸 때는 다음 작업에서 정리합니다.

표 칸 검출을 켜고 보내면 표 블록마다 칸의 위치, 행·열 번호, 합친 칸 수가 함께 붙습니다. 자세한 내용은 결과 형식 읽기에 있습니다.

수식​

문서수식을 읽는 방식
한글(hwp, hwpx)한글 수식 편집기로 만든 수식을 LaTeX 수식으로 바꿉니다.
PDF, 이미지수식 영역을 잘라 문자 인식 모델이 LaTeX 수식으로 읽습니다.

마크다운 결과에서 수식은 달러 기호 두 개로 감싼 LaTeX로 나옵니다.

한글 문서​

한글 문서(hwp, hwpx)는 자체 해석기로 읽습니다. 문서를 이미지로 바꾸지 않으므로 표 칸과 글자를 원본 그대로 가져옵니다.

한글 문서의 표 읽기

번호메뉴기능이런 때 사용하세요
1입력 노드읽을 한글 파일(예: 출장비_정산_기준_2026.hwpx)이 들어 있습니다.어떤 파일을 읽었는지 확인할 때
2표 블록한글 표가 직급, 일비, 숙박비 상한 세 열 그대로 나옵니다.금액이 같은 행에 붙어 있는지 대조할 때
  • 각주와 미주, 머리말과 꼬리말도 읽습니다.
  • 표 다음의 문단과 그림은 원본과 같은 순서로 이어집니다.
  • 옛 한글 3.0 형식 파일도 자동으로 알아보고 읽지만, 일부 문서는 쪽 나눔이 정확하지 않을 수 있습니다.
  • 확장자가 hwp인데 실제로는 hwpx 형식인 파일(또는 그 반대)은 자동으로 바로잡아 읽습니다.

그림과 차트 설명​

그림 설명 모델이 켜져 있으면 PDF의 그림과 차트, 그리고 워드·파워포인트·엑셀·마크다운·한글·웹 문서에 들어 있는 그림을 글로 설명합니다. 같은 그림은 한 번만 읽고, 설명은 그림 자리 바로 앞에 들어갑니다. 그림 자체는 JSON 결과에 이미지 데이터로 함께 남습니다.

그림 설명은 운영 담당자가 켜고 끕니다. 꺼져 있으면 그림 자리만 표시됩니다. 설정은 운영 설정에 있습니다.

머리말과 꼬리말​

머리말과 꼬리말은 기본으로 결과에 남고, 마크다운에서는 화면에 보이지 않는 주석으로 표시됩니다. 운영 담당자가 머리말·꼬리말 빼기를 켜면 결과에서 아예 빠집니다.

메일 파일​

메일 파일(msg)은 보낸 사람, 받는 사람, 제목, 본문을 읽고, 첨부 문서도 지원 형식이면 함께 읽습니다. 첨부 안의 첨부는 두 단계까지, 첨부는 최대 50개까지 읽습니다. 100MB가 넘는 첨부와 20KB보다 작은 첨부 그림(서명 로고 등)은 건너뜁니다. 텍스트 파일(txt)은 메일 첨부일 때만 읽습니다.

보안 문서와 손상된 문서​

  • 문서 보안(DRM)이 걸린 파일은 읽지 않고 암호화 문서라는 오류를 돌려줍니다. 보안이 걸린 PDF는 손상된 문서 오류로 나올 수도 있습니다. 보안을 푼 파일을 넣습니다.
  • 확장자와 실제 내용이 다른 파일(예: 이름만 pdf인 이미지)은 손상된 문서로 거부합니다.
