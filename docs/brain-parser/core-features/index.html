Brain Parser 주요 기능과 검토 대상

결과를 읽을 때의 기준​

문서 변환 결과에는 문단과 표 등의 내용이 담깁니다. 실제 표시 방식은 기능을 제공하는 제품에 따라 다릅니다. 이 페이지는 화면의 메뉴 목록을 대신 만들어 안내하지 않고 결과에서 무엇을 검토할지 설명합니다.

원본과 결과를 함께 열고 중요한 내용을 고르세요. 모두 같은 깊이로 검토하기 어렵다면 의사결정에 쓰이는 금액, 날짜, 조건과 결론을 우선 확인하는 것을 권합니다. 이는 검토 방법에 대한 권장 사항입니다.

제목과 문단​

제목을 찾은 뒤 본문 첫 문장과 마지막 문장을 함께 대조하세요. 제목 글자만 맞더라도 다른 절의 본문이 연결되면 내용을 잘못 해석할 수 있습니다.

목록에서는 첫 항목과 마지막 항목 사이에 빠진 내용이 없는지 확인합니다. 두 단으로 배치된 원본은 왼쪽 문장 중간에 오른쪽 문장이 끼지 않았는지 연속해서 읽어 보세요. 줄바꿈이 달라도 뜻이 유지되는지 판단합니다.

표의 행과 열​

숫자는 열 제목, 행의 항목, 단위와 함께 확인합니다. 다음 순서로 한 행씩 대조하는 것을 권합니다.

순서볼 내용주의할 부분
열 제목각 열의 의미비슷한 숫자가 있는 열끼리 바뀌지 않았는지 확인합니다
항목과 값한 행에 속하는 이름과 수치값이 옆 행으로 이동했는지 확인합니다
합쳐진 셀여러 열이나 행에 걸친 제목빈칸이 원래 빈칸인지 합쳐진 셀의 일부인지 구분합니다
표 아래 설명단위와 예외 조건표 밖 설명도 함께 읽습니다

긴 셀은 여러 줄을 끝까지 읽습니다. 표 안에 작은 표가 있다면 안쪽 내용과 바깥 행을 구분하세요. 모양 차이를 곧바로 오류로 확정하지 말고 어떤 항목의 의미가 달라졌는지 기록합니다.

페이지와 내용의 이어짐​

결과의 페이지 구분이 원본과 일대일로 대응한다고 가정하지 않습니다. 빈 내용이 생략될 수 있으므로 페이지 개수만으로 성공과 실패를 판단하지 마세요.

제목이나 문장처럼 실제 내용을 기준으로 위치를 찾습니다. 페이지를 넘어 이어지는 표는 이전 페이지 마지막 행과 다음 페이지 첫 행을 같이 비교합니다. 긴 문서에 적용하는 절차는 반복 업무에 있습니다.

다음 업무에 넘길 내용​

“검토 완료”라고만 남기기보다 “표의 항목·금액·단위 대조 완료, 마지막 주석 확인 필요”처럼 확인한 범위와 미확인 범위를 구분하세요. 이는 사용자가 별도로 남기는 메모이며 자동 보고서 기능이 아닙니다.

숫자 표로 연습하려면 활용 사례, 결과가 비거나 내용이 빠졌다면 문제 해결을 참고하세요.
