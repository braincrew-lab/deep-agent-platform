Brain Parser 버전별 변경 사항

이 매뉴얼은 Brain Parser 1.18.2를 기준으로 씁니다. 아래는 1.14.0부터 1.18.2까지 사용자가 결과에서 느낄 수 있는 변경을 버전별로 정리한 것입니다. 내부 정리나 시험 코드 변경은 넣지 않았습니다. 이용 중인 서버의 버전은 운영 담당자에게 확인합니다.

이 페이지에서 할 수 있는 일

  • 지금 버전에서 달라진 결과의 이유를 찾습니다.
  • 업그레이드 전후로 다시 확인할 문서 유형을 정합니다.

1.18.2​

  • 1.18.1에서 추가된 작은 그림 설명 건너뛰기가 기본으로 꺼졌습니다. 작은 그림도 모두 설명하며, 건너뛰려면 운영 담당자가 작은 그림 설명 건너뛰기 값을 정합니다.

1.18.1​

  • dots_mocr 프로필에서 PDF 표를 문자 인식 모델에 맡길 때 칸 구조를 담은 HTML 표로만 받습니다.
  • 쪽 면적에 비해 작고 PDF 글자가 없는 그림의 설명을 건너뛰는 설정이 추가됐습니다(1.18.2에서 기본 꺼짐으로 바뀜).
  • PDF 글자가 깨졌는지를 페이지 전체가 아니라 영역마다 판단합니다. 한 영역만 깨진 페이지에서 나머지 영역은 PDF 글자를 그대로 씁니다.

1.18.0​

  • PDF를 영역마다 읽습니다. 영역마다 PDF 글자를 믿을 수 있는지 먼저 판단하고, 믿을 수 있는 영역은 PDF 글자를, 아닌 영역만 모델로 읽습니다. 짧은 제목, 글머리표, 배경 그림이 있는 영역도 PDF 글자를 버리지 않습니다. 보이지 않게 숨겨 둔 글자가 많은 영역은 모델로 읽습니다.
  • 아무것도 그려지지 않은 영역은 모델에 보내지 않습니다.
  • PDF가 아닌 형식(워드, 파워포인트, 엑셀, 마크다운, 한글, 웹 문서)의 그림을 그림 설명 모델 한 번 호출로 읽습니다. 그림 속 글자는 설명에 함께 담기며, 설명과 글자를 따로 받는 것은 deepseek 프로필입니다.
  • 문자 인식 결과가 한국어가 아닌 글자로 나왔는데 그 자리의 PDF 글자가 한국어이면 PDF 글자로 바꿉니다.
  • 페이지 위·아래의 반복 문구 영역에 PDF 글자가 없고 페이지에 글이 보이면 그 영역을 모델로 읽지 않습니다.
  • 설정 이름이 바뀌었습니다. 그림 설명 관련 설정은 INFOGRAPHIC으로 시작하던 이름이 VLM으로 시작하는 이름이 되었고, SCAN_REGION_VLM은 VLM_TEXT_REGIONS가 되었습니다. 옛 이름도 경고와 함께 계속 읽습니다.

1.17.0, 1.17.2, 1.17.3, 1.17.4​

  • 문자 인식 프로필에 dots_mocr를 추가했습니다(1.17.0).
  • 문서 속 그림 글자 읽기를 켜면 PDF 그림과 문서에 든 그림의 글자도 문자 인식 모델로 읽습니다(1.17.2).
  • PNG로 표시됐지만 실제로는 모델이 읽을 수 없는 형식(WMF, EMF 같은 메타파일)인 그림을 미리 알아보고 경고로 알립니다(1.17.3).
  • 문자 인식 모델 서버가 요청을 거절하면 부가 항목을 빼고 한 번 더 요청합니다(1.17.4).

1.16.0​

  • 실패한 작업의 상태 조회에 실패 이유와 오류 코드가 함께 나옵니다.
  • 문자 인식 모델 서버 주소가 채팅 완료 경로로 끝나면 그 주소를 그대로 씁니다.

1.14.0 ~ 1.15.0​

  • 디지털 PDF의 표를 그려진 선으로 행과 열을 정해 읽습니다. 선으로 구조를 알 수 없는 표는 전처럼 모델이 읽습니다.
  • 한글 문서(hwp, hwpx)에서 표 뒤의 문단과 그림이 원본 순서대로 이어지고, 글상자 안 그림과 수식이 제자리에 남습니다.
  • 파워포인트에서 파일로 연결만 된 그림은 그림 자리 표시를 남깁니다.
