Brain Parser 소개

사용 목적​

Brain Parser는 PDF, 이미지, 오피스 문서 등 여러 형식의 파일을 마크다운, JSON, HTML 같은 정해진 형식으로 바꿔 주는 문서 변환 서비스입니다. 별도의 화면 없이 API 호출, 명령줄 도구, 파이썬 라이브러리를 통해 사용하도록 만들어져 있어서, 다른 시스템이나 파이프라인에 문서 변환 기능을 붙이고 싶을 때 활용합니다.

호출 위치​

Brain Parser는 웹 화면이 없는 API 기반 서비스이므로, 안내받은 API 주소로 요청을 보내거나 명령줄 도구, 파이썬 SDK를 통해 호출합니다. 문서를 변환해 달라고 요청하는 주소는 POST 방식의 /v1/parse이고, 처리 상태와 결과를 조회하는 주소는 각각 GET 방식의 /v1/jobs/{작업 아이디}/status와 /v1/jobs/{작업 아이디}/result입니다. 서비스가 살아있는지 확인하고 싶을 때는 GET 방식의 /health 주소를 사용합니다.

단계​

  1. 변환하고 싶은 파일과 함께 원하는 결과 형식을 지정해 /v1/parse 주소로 요청을 보냅니다. 결과 형식은 마크다운, JSON, HTML 중에서 고를 수 있고, 표가 있는 문서라면 표 셀 인식 옵션을 함께 켤 수 있습니다. 모든 요청에는 발급받은 API 키가 필요하며, X-API-Key 헤더에 값을 넣거나 Authorization 헤더에 Bearer 와 공백 뒤에 발급받은 API 키를 넣어 인증합니다. 예상 결과: 요청이 접수되면 이후 상태를 조회할 때 사용할 작업 아이디가 응답으로 돌아옵니다.
  2. 받은 작업 아이디로 /v1/jobs/{작업 아이디}/status 주소에 상태를 조회합니다. 예상 결과: 작업이 아직 처리 중이면 진행 중 상태가, 끝났으면 완료 상태가 돌아옵니다.
  3. 상태가 완료로 바뀌면 /v1/jobs/{작업 아이디}/result 주소에서 최종 결과를 받아옵니다. 예상 결과: 요청했던 형식에 맞춘 변환 결과와 함께 문서 페이지 수, 원본 파일 이름 같은 부가 정보가 함께 돌아옵니다.

결과 확인​

상태 조회에서 완료로 표시된 작업의 결과 조회 응답에 변환된 텍스트나 마크다운이 비어 있지 않게 담겨 있으면 호출이 정상적으로 끝난 것입니다.

문제 해결​

  • 요청이 거부된다면 인증 헤더에 넣은 API 키 값이 정확한지, 헤더 이름을 X-API-Key 또는 Authorization 중 하나로 올바르게 사용했는지 다시 확인합니다.
  • 상태 조회 결과가 계속 처리 중에 머물러 있다면 문서 용량이나 페이지 수가 많아 처리 시간이 길어졌을 수 있으므로 잠시 뒤 다시 조회합니다.
  • 서비스 자체가 응답하지 않는 것 같다면 먼저 /health 주소로 서비스 상태를 확인한 뒤, 문제가 계속되면 관리자에게 문의합니다.
