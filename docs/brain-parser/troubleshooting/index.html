Brain Parser 문제 해결

먼저 구분할 것​

파일을 전달하지 못한 상태, 처리가 끝나지 않은 상태, 결과는 있지만 내용이 다른 상태를 구분하세요. 각각 확인할 위치가 다릅니다. 아래는 사용자 검토 방법이며 증상만으로 원인을 확정하는 진단 기능이 아닙니다.

입력 화면과 처리 상태는 Brain Parser를 제공받은 제품에서 확인합니다. 위치를 모르면 제품 이름과 수행하려는 작업을 서비스 관리자에게 알려 확인하세요. 독립된 공통 버튼을 찾아야 하는 것은 아닙니다.

파일이나 결과를 열 수 없어요​

원본 파일이 열리는지 확인합니다. 정상이라면 실제 화면의 허용 형식과 용량을 확인하고 선택한 파일과 비교하세요. 파일 이름의 확장자만 바꾸는 것으로 내용까지 변환했다고 판단하지 않습니다.

전달한 파일의 결과를 열 수 없다면 해당 제품의 처리 상태와 안내를 확인합니다. 진행 중인지 오류가 표시됐는지 모르는 상태에서 같은 파일을 반복 등록하지 마세요. 결과 위치를 확인해도 접근하지 못하면 제품 이름, 수행 단계, 안내 문구를 전달합니다.

결과가 비거나 일부 내용이 없어요​

관찰확인조치와 재확인
전체가 비어 있음원본 내용과 선택한 파일정상 완료로 안내됐는데도 비면 원본의 짧은 제목과 함께 문의합니다
특정 문단만 없음원본에 그 부분이 보이는지원본 위치와 빠진 내용을 기록해 검토를 요청합니다
페이지 수가 다름실제 본문이 빠졌는지개수 대신 제목·문장·표를 찾아 대조합니다
표 셀이 비어 있음원본 빈칸 또는 합쳐진 셀인지앞뒤 값과 열 제목을 함께 비교합니다

빈 페이지가 생략될 수 있으므로 개수 차이 자체를 누락의 증거로 삼지 않습니다. 개수가 같다는 이유로 내용 확인을 건너뛰지도 마세요.

글자나 표의 의미가 달라졌어요​

문장이 섞여 보이면 원본의 읽는 순서를 확인하고 결과의 어느 문장이 끼어들었는지 기록합니다. 숫자가 다르면 행의 항목, 열 제목, 단위도 함께 적으세요.

원본 글자가 흐리거나 잘렸다면 더 선명한 원본을 확보할 수 있는지 확인합니다. 이 조치가 해결을 보장하지는 않습니다. 새 결과를 받은 뒤 문제 부분을 다시 대조해야 합니다.

도움을 요청할 때​

문서 이름, 원본 페이지나 제목, 기대한 내용, 실제 차이, 이용 제품과 처리 시점을 정리하세요. “비용 표의 안내 책자 금액이 원본 18,000원과 다르게 보임”처럼 대상을 특정합니다. 민감한 원문 전체를 공개 대화에 붙이지 말고 조직의 전달 기준을 따르세요.

중요한 값이 확인되지 않았다면 그 값을 근거로 업무를 확정하지 않습니다. 새 결과는 시작하기에서 다시 대조하고 긴 문서는 반복 업무의 검토 범위를 함께 확인하세요.
