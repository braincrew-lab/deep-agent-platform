Brain Parser 문제 해결

결과가 나오지 않거나 원본과 다를 때 먼저 확인할 내용을 증상별로 정리합니다. Deep Docurator나 Deep Connector에서 쓰는 경우 화면의 오류 문구를, 사내 시스템에서 직접 쓰는 경우 오류 코드를 함께 봅니다.

이 페이지에서 할 수 있는 일

  • 파일이 거부되는 이유를 찾습니다.
  • 처리가 실패하거나 끝나지 않을 때 확인할 곳을 압니다.
  • 결과가 비거나 원본과 다를 때 원인을 좁힙니다.
  • 도움을 요청할 때 전달할 내용을 정리합니다.

먼저 구분할 것​

상태확인할 곳
파일이 들어가지 않음형식, 크기, 문서 보안
처리가 실패하거나 끝나지 않음오류 문구 또는 오류 코드, 쪽수
결과는 있지만 내용이 다름원본 품질, 형식, 설정

파일이 거부돼요​

오류원인조치
지원하지 않는 형식(UNSUPPORTED_FORMAT)20가지 확장자에 없는 파일입니다. 확장자가 없는 파일도 같습니다.지원 파일 형식을 보고 바꿔 저장합니다. txt와 csv는 Deep Docurator에서만 그대로 넣을 수 있습니다.
파일이 너무 큼(FILE_TOO_LARGE)파일 크기 한도(기본 150MB)를 넘었습니다.필요한 장만 따로 저장하거나 이미지 해상도를 낮춥니다.
쪽수 초과(PAGE_LIMIT_EXCEEDED)PDF 쪽수 한도(기본 5,000쪽)를 넘었습니다.PDF를 나눠서 넣습니다.
암호화 문서(ENCRYPTED_DOCUMENT)문서 보안(DRM)이 걸린 파일입니다.보안을 해제한 파일을 넣습니다.
손상된 문서(CORRUPTED_DOCUMENT)파일이 깨졌거나, 문서 보안이 걸린 PDF이거나, 확장자와 실제 내용이 다릅니다(예: 이름만 바꾼 파일).원래 프로그램에서 열리는지 보고, 그 프로그램에서 올바른 형식으로 다시 저장합니다. 확장자만 바꾸면 안 됩니다.

처리가 실패하거나 끝나지 않아요​

증상확인조치
PDF와 이미지만 실패하고 워드·한글은 됨문자 인식 모델 서버 연결운영 담당자에게 문자 인식 모델 서버 상태를 확인해 달라고 요청합니다. 오류 코드는 OCR_ERROR입니다.
처리 시간 초과(DOCUMENT_TIMEOUT, JOB_TIMEOUT)쪽수, 스캔 쪽 비율문서를 나눠서 넣습니다. 기본 한도는 PDF가 300초에 쪽마다 10초를 더한 값(최대 4시간), 그 밖의 형식은 최대 4시간입니다.
대기열이 가득 참(QUEUE_FULL)동시에 보낸 문서 수1분쯤 뒤 다시 보냅니다.
서버가 잠시 받을 수 없음(503 오류)서버 재시작, 저장소 상태잠시 뒤 다시 보냅니다. 반복되면 운영 담당자에게 알립니다.
결과를 다시 받을 수 없음(RESULT_UNAVAILABLE)처리한 지 오래됨결과 보관 기간(기본 30일)이 지났습니다. 다시 처리합니다.

같은 파일을 여러 번 연달아 보내지 마세요. 진행 중인지 실패했는지 먼저 확인합니다.

결과가 비거나 일부가 없어요​

관찰확인조치
스캔 문서 결과가 거의 비어 있음스캔이 흐리거나 기울었는지다시 스캔합니다. 운영 담당자에게 페이지 방향 바로잡기 설정을 물어봅니다.
그림 자리만 있고 설명이 없음그림 설명이 켜져 있는지운영 담당자에게 그림 설명 설정을 확인해 달라고 요청합니다.
머리말·꼬리말이 사라짐머리말·꼬리말 빼기 설정필요하면 운영 담당자에게 설정을 바꿔 달라고 요청합니다.
한자로만 된 문장이 빠짐한자만 있는 줄 버리기 설정한자 문장이 중요한 문서라면 운영 담당자에게 알립니다.
쪽 수가 원본과 다름실제 본문이 빠졌는지쪽 수 대신 제목과 문장으로 찾습니다. 엑셀은 시트, 파워포인트는 슬라이드 단위로 셉니다.
JSON 결과에 빠진 쪽, 경고 항목이 있음해당 쪽 번호그 쪽을 원본과 대조하고, 필요하면 그 쪽만 따로 저장해 다시 넣습니다.

글자나 표의 뜻이 달라졌어요​

관찰확인조치
숫자 자리나 소수점이 다름원본 해상도더 선명한 원본이나 원본 형식(엑셀, 한글) 파일로 다시 넣습니다.
표 값이 옆 칸으로 밀림합친 칸이 있는 표인지합친 칸 표는 마크다운 결과에서 HTML 표로 나옵니다. JSON 결과의 표 블록이나 원본으로 대조합니다.
엑셀 날짜에 시각이 붙음날짜 칸정상 동작입니다. 다음 작업에서 날짜만 남깁니다.
두 단 문서의 문장이 섞임원본의 읽는 순서섞인 위치를 적어 운영 담당자에게 전달합니다.
PDF 결과에서 단어가 줄 끝에서 끊김원본의 줄바꿈 위치뜻이 같으면 넘어가고, 검색에 쓰는 핵심 단어라면 원본 형식(워드, 한글)으로 다시 넣어 봅니다.
그림 설명의 숫자가 원본과 다름그림 속 숫자그림 설명은 모델이 쓴 글입니다. 숫자는 원본 그림에서 직접 확인합니다.

도움을 요청할 때​

다음을 정리해 운영 담당자에게 전달합니다.

전달할 것예시
이용한 곳Deep Docurator "계약서 스캔본 읽기" 플로우
문서 이름과 형식, 크기계약서_스캔본.png, 100 KB
원본 위치제3조 둘째 문장
기대한 내용과 실제 결과원본 "연 12%", 결과 "연 1.2%"
오류 문구나 코드화면 문구 그대로, 또는 OCR_ERROR

민감한 원문 전체를 대화에 붙이지 말고 조직의 전달 기준을 따릅니다. 중요한 값이 확인되지 않았다면 그 값을 근거로 업무를 확정하지 않습니다.
