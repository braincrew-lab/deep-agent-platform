Deep Connector 문제 해결

업로드 버튼을 누를 수 없을 때​

파일 선택, 컬렉션 선택, 처리 파이프라인, 파일 확인 상태를 차례로 봅니다. 업로드 대화상자에서 현재 컬렉션 이름이 맞는지 확인하고, 선택한 파일의 내용 확인과 기존 문서 여부 확인이 끝났는지 기다리세요. 확인 실패가 표시되면 해당 파일의 안내를 읽고 다시 선택합니다.

표시되는 상황확인과 조치다시 확인할 것
같은 내용의 문서가 이미 있음안내된 기존 문서를 먼저 찾고, 중복 파일을 선택 목록에서 제거기존 문서의 상태와 내용
파이프라인 목록 불러오기 실패대화상자를 다시 열어 목록 조회가 회복되는지 확인실제 선택 가능한 항목이 표시되는지
사용 가능한 파이프라인 없음담당자에게 사용할 처리 구성을 요청안내받은 구성이 목록에 나타나는지
지원 형식 또는 용량 안내화면의 허용 형식과 파일당 용량을 확인하고 원본을 지원 형식으로 다시 준비새 파일이 선택 목록에 추가되는지
할당량 초과저장공간 또는 업로드 횟수 중 어떤 한도인지 확인하고 담당자와 조정차단 안내 해제와 업로드 가능 여부

이름만 바꾸어 같은 파일을 재등록하면 내용 중복은 해결되지 않습니다. 불필요한 문서 삭제가 필요한 경우에도 다른 사람이 사용하는 자료인지 먼저 확인하세요.

문서가 처리 실패로 표시될 때​

컬렉션의 문서 탭에서 대상 파일과 실패 상태를 확인합니다. 실패 배지의 오류 상세 보기를 열어 파일 형식, 처리 설정, 서비스 연결 중 무엇에 대한 안내인지 읽습니다. 저장된 상세 정보가 없다는 표시도 있을 수 있습니다.

원인을 해소한 뒤 재실행이 제공되면 한 번 실행하고 문서 상태가 다시 진행되는지 확인합니다. 재실행 항목이 없으면 처리 파이프라인 정보와 권한을 담당자에게 확인하세요. 문서를 지우고 다시 올리는 조치를 첫 단계로 삼지 않습니다. 처리중 상태가 오래 유지될 때에는 같은 파일을 반복 등록하지 말고 시작 시각과 현재 상태를 기록해 확인을 요청합니다.

검색 결과가 없거나 관련 없는 문서가 나올 때​

  1. 실험 → 검색에서 현재 선택한 컬렉션 이름을 확인합니다. 문서를 올린 컬렉션과 같아야 합니다.
  2. 해당 컬렉션의 문서 탭으로 돌아가 파일이 완료 상태인지 봅니다. 청크 탭에서도 찾으려는 문장이 존재하는지 확인합니다.
  3. 자유 필터에서 Key-Value 입력 행의 휴지통 버튼을 눌러 조건을 지웁니다. 별도의 메타데이터 필터 영역에서도 선택한 필드를 제거한 뒤 같은 질문을 다시 검색합니다. 위치와 전체 순서는 반복 업무의 특정 문서로 검색 범위 좁히기를 참고하세요.
  4. 질문에 대상이 빠졌다면 “취소 규칙” 대신 “회의실 취소 규칙”처럼 구체화합니다. 검색 방식을 비교할 때에는 질문을 고정합니다.
  5. 문장이 청크에 있는데도 찾지 못하면 컬렉션 이름, 검색어, 방식, 필터 유무와 기대 문장을 담당자에게 전달합니다.

검색 결과에 다른 업무의 규칙이 나오면 파일명과 본문을 함께 읽으세요. 점수가 높다는 이유로 그대로 업무에 적용하지 않습니다. 정확한 조건이 중요한 경우에는 원본까지 대조합니다.

메뉴나 편집 항목이 보이지 않을 때​

문서는 컬렉션을 연 뒤 문서 탭에서 확인합니다. 독립된 문서 메뉴를 찾느라 멈출 필요는 없습니다. 검색은 실험 안에 있습니다. 실험 사용 안내가 뜨면 내용을 확인하고 이용 여부를 결정합니다.

컬렉션은 열리지만 업로드나 교체를 할 수 없다면 조회와 수정 권한의 차이를 확인하세요. 접근 요청 기능이 제공되는 환경에서는 요청 상태도 확인할 수 있습니다. 그렇지 않으면 컬렉션 담당자에게 필요한 작업과 대상 컬렉션을 알려 주세요.

문의할 때에는 발생 시각, 파일 형식과 용량, 현재 상태, 수행한 단계를 전달합니다. 비밀번호나 인증 정보는 포함하지 않습니다. 해결 후에는 시작하기의 처리 완료와 검색 결과 확인을 다시 수행하세요.
