Deep Connector 문제 해결

이 페이지는 Deep Connector를 쓰다 막혔을 때 화면에 나온 문구를 기준으로 원인을 좁히는 방법을 정리합니다. 해결되지 않으면 맨 아래 "문의할 때 알려 줄 것"을 적어 담당자에게 알려 주세요.

이 페이지에서 할 수 있는 일

  • 업로드가 막히거나 파일이 빠질 때 무엇부터 볼지 확인합니다.
  • 처리 실패한 문서의 오류 내용을 열어 보고 다시 처리합니다.
  • 올린 문서가 검색되지 않을 때 처리 상태, 컬렉션, 검색 조건 순으로 점검합니다.
  • 권한, 할당량, 실험 메뉴에서 보이는 안내 문구의 뜻을 알고 다음 행동을 정합니다.

업로드가 안 될 때​

문서 업로드 버튼은 컬렉션의 업로드 권한이 있고, 파일을 고른 뒤 내용 확인과 중복 확인이 끝나고, 파이프라인을 골랐고, 사용량 한도가 남아 있을 때 눌립니다.

화면 문구나 증상뜻할 일
문서 탭에 문서 업로드 버튼이 없음이 컬렉션에서 업로드 권한(Level2 이상)이 없습니다.컬렉션 담당자에게 Level2: 조회/업로드 이상을 요청합니다. 권한·공유·접근 요청 참고
제외 사유 "지원하지 않는 형식"18가지 지원 확장자가 아닌 파일입니다..ppt는 .pptx로, .txt는 .md로, .csv는 .xlsx로 저장해 올립니다
제외 사유 "200 MB 초과"파일 하나가 200 MB를 넘습니다.파일을 나누거나 이미지 해상도를 낮춥니다
제외 사유 "컬렉션에 이미 있음"이름이 달라도 내용이 같은 파일이 이미 있습니다. 옆에 기존 문서 이름과 상태가 나옵니다.그대로 두거나, 개정본이라면 기존 문서의 새 버전 업로드로 교체합니다
선택한 파일의 중복 확인이 끝날 때까지 기다려 주세요파일 내용을 확인하는 중입니다.파일 행의 상태가 "확인됨"이 될 때까지 기다립니다
사용 가능한 파이프라인이 없습니다업로드할 때 고를 처리 방식이 등록되어 있지 않습니다.관리자에게 파이프라인 등록을 요청합니다
할당량 제한으로 업로드가 차단되었습니다내 저장공간이나 이번 달 업로드 건수가 한도에 닿았습니다.아래 "업로드 한도에 걸렸을 때"를 봅니다

업로드 한도에 걸렸을 때​

업로드 차단 화면

번호항목화면에서 볼 것
1차단 안내"할당량 제한으로 업로드가 차단되었습니다"가 화면 위에 나옵니다. 파일 확인은 끝났어도 올릴 수 없습니다.
2사용량사이드바 아래 저장공간과 월간 업로드 막대입니다. 빨간 막대가 한도에 닿은 항목입니다. 이 예에서는 이번 달 업로드 77건이 한도 70건을 넘었습니다.
3문서 업로드눌러도 업로드되지 않습니다.
  1. 저장공간이 찼다면 쓰지 않는 문서나 연습용 컬렉션을 지웁니다.
  2. 월간 업로드가 찼다면 다음 달까지 기다리거나 관리자에게 한도 조정을 요청합니다. 관리자는 사용자와 팀스페이스 두 화면에서 모두 한도를 확인해야 합니다(관리자: 사용자와 팀스페이스 참고).
  3. 한도가 늘어나면 업로드 화면을 새로 고치고 파일을 다시 고릅니다.

처리에 실패했을 때​

문서 목록에서 처리 실패한 문서는 이름 옆에 빨간 표시가 붙고 청크 수가 0입니다.

처리 실패한 문서

번호항목화면에서 볼 것
1문서 이름실패한 문서입니다. 청크 수가 0입니다.
2실패 표시누르면 오류 상세 창이 열립니다.
3재시도같은 파일로 처리를 다시 시작합니다.

오류 상세 창

번호항목화면에서 볼 것
1파일 이름실패한 파일입니다.
2오류 내용오류 코드와 메시지입니다. 이 예는 "Unsupported format: .xls — convert to .xlsx and retry"입니다.
3확인창을 닫습니다.

  1. 오류 내용을 읽고 원인을 정합니다.

    오류 내용에 보이는 말원인할 일
    Unsupported format처리 엔진이 그 형식을 읽지 못합니다.메시지가 권하는 형식(예: .xlsx)으로 저장해 다시 올리고, 실패한 문서는 지웁니다
    password, 암호암호가 걸린 파일입니다.암호를 풀고 다시 올립니다
    timeout, 시간 초과처리가 오래 걸려 중단됐습니다.재시도를 누릅니다. 계속되면 파일을 나눕니다

  2. 일시적인 오류로 보이면 재시도를 누릅니다. "문서 다시 적재를 시작했습니다"가 나오면 다시 처리 중입니다.

  3. "파이프라인 정보가 없어 재실행할 수 없습니다"가 나오면 문서를 지우고 다시 올립니다.

  4. 같은 파일이 계속 실패하면 파일 이름과 오류 내용을 담당자에게 알립니다. 관리자는 적재 현황에서 실패 사유별 통계를 볼 수 있습니다.

올린 문서가 검색되지 않을 때​

  1. 문서 목록에서 상태를 봅니다. 처리 대기중이거나 처리중인 문서는 검색에 나오지 않습니다.
  2. 처리가 끝났다면 청크 수가 0이 아닌지 봅니다. 이미지에 글자가 거의 없으면 청크가 적게 만들어집니다.
  3. 청크 탭이나 문서 상세에서 찾는 문장이 실제로 청크에 들어 있는지 확인합니다.
  4. 실험 > 검색의 컬렉션 선택이 문서를 올린 컬렉션인지 봅니다.
  5. 메타데이터 필터와 자유 필터에 남은 조건을 지우고 다시 검색합니다. 두 조건은 함께 적용됩니다.
  6. 검색 방식을 바꿔 봅니다. 문장으로 물어 안 나오면 문서에 쓰인 낱말로 키워드 검색을, 정확한 숫자나 코드는 문자열 검색을 씁니다.

새 버전 업로드나 다시 적재 뒤 결과가 잠깐 사라질 때​

새 버전 업로드나 다시 적재를 하면 문서가 다시 처리되고, 끝날 때까지 검색에 나오지 않습니다. 에이전트가 쓰는 컬렉션이라면 그동안 에이전트도 그 문서를 근거로 쓰지 못합니다. 상태가 완료로 돌아올 때까지 기다리세요. 직접 고친 청크 내용은 새 처리 결과로 바뀝니다. 같은 파일로 새 버전을 올리면 "현재 파일과 동일한 내용입니다. 변경 없이 유지됩니다."가 나오고 아무것도 바뀌지 않습니다.

권한과 접근 문구​

화면 문구뜻할 일
이 컬렉션의 문서를 볼 수 있는 권한이 없습니다접근 수준이 제한이고 아직 권한을 받지 않았습니다.접근 요청을 눌러 요청 등급과 사유를 적어 보냅니다
제한 · 승인 대기 중보낸 접근 요청이 아직 처리되지 않았습니다.접근 요청 화면에서 상태를 확인합니다
접근 요청 기능을 사용할 수 없습니다이 환경에서 접근 요청 기능이 꺼져 있습니다.컬렉션 담당자에게 직접 공유를 부탁합니다
계정이 없는 사용자는 조회만 줄 수 있습니다공유하려는 사람이 아직 회사 계정 목록에 없어 Level2 이상을 줄 수 없습니다.Level1로 저장하거나, 그 사람이 한 번 로그인한 뒤 다시 시도합니다
설정 탭이나 공유/권한 탭이 보이지 않음컬렉션 수정이나 공유 권한이 없습니다.컬렉션 소유자에게 변경을 부탁합니다

검색과 실험 메뉴의 안내 문구​

화면 문구뜻할 일
실험 공간 안내실험 메뉴를 처음 열 때 나오는 확인 화면입니다.세 항목을 읽고 모두 확인한 뒤 확인하고 시작하기를 누릅니다
이 컬렉션에 연결된 사전이 없습니다사전 확장을 쓸 수 없는 컬렉션입니다.사전 없이 검색합니다. 사전이 필요하면 컬렉션 설정에서 연결합니다
의미 검색에는 적용되지 않습니다시맨틱 검색에서는 사전 확장이 꺼집니다.사전 효과를 보려면 키워드 검색이나 하이브리드 검색을 고릅니다
이 컬렉션에는 추출된 메타데이터 스키마가 없습니다메타데이터 필터로 고를 항목이 없습니다.필터 없이 검색하거나 자유 필터를 씁니다
아직 없습니다(답변 생성이 꺼져 있거나 LLM이 구성되지 않았을 수 있습니다).RAG 진단에서 답변을 만들지 못했습니다.컬렉션 설정의 LLM 검색 보강에 커넥션을 연결하고 AI 답변 생성 사용을 켭니다
컬렉션 정보는 저장됐지만 검색 분석기 설정 저장에 실패했습니다.넣은 LLM 커넥션을 이 컬렉션에서 쓸 수 없습니다.내 팀스페이스용 커넥션 ID를 담당자에게 받아 다시 넣습니다
MCP 도구 테스트 결과의 ValidationErrorsearch_documents에 검색 범위(path나 document_ids)가 없습니다.고급 파라미터의 path나 document_ids에 값을 넣습니다

접근 제한·오류 화면​

화면 문구뜻해결
접근 제한관리자만 쓰는 화면(예: AI 대시보드, 관리자 메뉴 주소)을 일반 계정으로 열었습니다.필요한 경우 Deep Connector 관리자에게 요청합니다
404 요청하신 페이지를 찾을 수 없습니다주소가 바뀌었거나, 이 배포에서 꺼진 기능입니다.대시보드로 돌아가기나 사이드바 메뉴로 다시 들어갑니다
원본 링크가 열리지 않음로그인 없이 여는 원본 링크의 유효시간(기본 8시간)이 지났습니다.검색 결과나 문서 상세에서 링크를 새로 받습니다(관리자: 시스템 참고)

문의할 때 알려 줄 것​

  • 발생 일시와 사용한 메뉴(예: 실험 > 검색)
  • 컬렉션 이름, 문서 이름, 문서 상태
  • 검색어와 검색 방식, 기대한 문장
  • 화면에 나온 안내 문구나 오류 상세 내용 그대로

비밀번호, MCP 토큰, 고객 개인정보는 문의 내용에 넣지 마세요.
