Deep Connector 관리자: 시스템

관리자 사이드바 시스템 묶음은 Deep Connector 전체에 걸리는 운영 화면입니다. 저장공간, 감사 로그, 브랜드 설정, 시스템 설정 네 메뉴가 있습니다. 이 페이지는 AI혁신팀 강혁신 팀장(Deep Connector 관리자)이 각 화면에서 무엇을 확인하고 바꾸는지 설명합니다.

이 페이지에서 할 수 있는 일

  • 팀스페이스와 사용자별 저장 용량을 확인합니다.
  • 누가 언제 무엇을 했는지 감사 로그에서 찾습니다.
  • 제품명, 회사명, 색상 같은 화면 브랜드를 바꿉니다.
  • 로그인 없이 원본을 여는 문서 링크의 유효시간을 정합니다.

시스템 메뉴 구성​

시스템 묶음

번호메뉴기능이런 때 사용하세요
1저장공간·감사 로그저장 용량 현황과 작업 기록 화면입니다.용량을 점검하거나 작업 이력을 추적할 때
2브랜드 설정·시스템 설정화면 브랜드와 배포 전체 설정 화면입니다.회사 로고·이름을 바꾸거나 링크 유효시간을 정할 때

저장공간​

시스템 > 저장공간은 문서가 차지하는 용량을 팀스페이스별, 사용자별로 보여 줍니다.

저장공간

번호메뉴기능이런 때 사용하세요
1총 사용량모든 문서 원본이 차지하는 용량입니다.저장소 증설 시기를 가늠할 때
2팀스페이스별팀스페이스마다 쓴 용량과 한도, 사용률 막대입니다.한도에 가까운 부서를 찾을 때
3저장공간 상위 사용자용량을 많이 쓰는 사용자 순서로 이메일, 사용량, 한도, 사용률을 보여 줍니다.대용량 파일을 많이 올린 사용자를 찾을 때

한도를 바꾸는 곳은 이 화면이 아니라 사용자와 팀스페이스입니다.

이럴 때 쓰세요: 김그루 사원이 "AI혁신팀 업로드가 막혔다"고 알려 오면, 강혁신 팀장은 먼저 저장공간에서 AI혁신팀 막대가 찼는지 보고, 찼다면 팀스페이스 상세에서 한도를 올립니다.

감사 로그​

시스템 > 감사 로그는 Deep Connector에서 일어난 조회·변경 작업을 시간순으로 기록합니다.

감사 로그

번호메뉴기능이런 때 사용하세요
1전체 카테고리기록 종류로 목록을 좁힙니다.컬렉션 변경이나 LLM 호출 기록만 볼 때
2이메일로 검색행위자 이메일로 좁힙니다.특정 사용자의 작업을 추적할 때
3기록 표시간, 행위자(관리자 여부 표시), 활동, 결과(성공·실패와 상태 코드), 소요시간입니다. 아래 이전·다음으로 쪽을 넘깁니다.실패한 작업이 언제 있었는지 찾을 때

감사 로그는 읽기 전용입니다. 기록을 지우거나 고칠 수 없습니다.

이럴 때 쓰세요: "어제 오후에 사내 규정 컬렉션 설정이 바뀌었는데 누가 바꿨는지 모르겠다"는 문의가 오면, 카테고리를 좁히고 시간대를 따라 내려가며 변경 기록과 행위자를 확인합니다.

브랜드 설정​

시스템 > 브랜드 설정은 사용자 화면에 보이는 제품명, 회사명, 로고, 색상을 바꾸는 화면입니다. 바꾼 내용은 먼저 초안으로 저장되고, 게시를 눌러야 모든 사용자에게 적용됩니다.

브랜드 설정

번호메뉴기능이런 때 사용하세요
1초안 초기화·초안 저장·게시초안을 게시된 값으로 되돌리기, 초안만 저장하기, 초안을 모든 사용자에게 적용하기입니다. 제목 옆 배지가 게시 상태를 보여 줍니다.바꾼 브랜드를 검토 후 한 번에 적용할 때
2브랜드 정보제품명, 회사명, 서비스 설명입니다. 로그인 화면과 사이드바 로고 옆에 보입니다.사내 서비스 이름으로 바꿀 때
3실시간 미리보기저장하기 전에 바꾼 모습을 밝은 화면·어두운 화면, 데스크톱·모바일로 미리 봅니다.색상 대비가 괜찮은지 볼 때
설정 묶음항목뜻기본값
브랜드 정보제품명, 회사명, 서비스 설명화면에 표시할 이름과 소개 문구빌드 기본값(DeepConnector)
브랜드 에셋기본 로고, 다크 모드 로고, 파비콘PNG 또는 SVG, 2 MiB까지빌드 기본값 사용
색상과 모서리primary, primary-foreground, background, card, foreground, muted-foreground, border, accent, 모서리 반경버튼, 배경, 카드, 글자, 테두리 색과 모서리 둥글기빌드 기본값

이 시연 환경은 에셋 저장소가 꺼져 있어 로고 업로드 대신 "에셋 저장소가 비활성화되어 이미지 업로드를 사용할 수 없습니다."가 보입니다. 이때도 글자와 색상은 바꿀 수 있습니다.

이럴 때 쓰세요: 브레인크루가 사내 서비스 이름을 "브레인크루 지식창고"로 정했다면, 제품명을 바꾸고 미리보기로 확인한 뒤 초안 저장, 팀장 검토 후 게시를 누릅니다.

시스템 설정​

시스템 > 시스템 설정은 문서 처리와 무관한 배포 전체 설정입니다. 지금은 문서 링크의 유효시간이 있습니다.

시스템 설정

번호메뉴기능이런 때 사용하세요
1링크 유효시간로그인 없이 문서 원본을 여는 링크를 몇 초 동안 쓸 수 있는지 정합니다. 아래에 사람이 읽기 쉬운 값(예: 8시간)이 함께 보입니다.외부에 전달한 링크를 짧게 끊고 싶을 때
2자세히설정 설명을 펼칩니다.이 값이 어디에 쓰이는지 볼 때
3저장바꾼 값을 저장합니다. 새로 발급하는 링크부터 적용됩니다.값을 바꿨을 때
항목뜻기본값범위
링크 유효시간검색 결과, 팝업 뷰어, 다운로드 주소가 주는 원본 링크를 여러 번 열 수 있는 시간28800초(8시간)60초~604800초(7일)

이럴 때 쓰세요: 보안 점검에서 "원본 링크가 하루 종일 열린다"는 지적을 받았다면 링크 유효시간을 3600초(1시간)로 줄입니다. 이미 발급된 링크는 원래 시간까지 열리므로 바꾼 뒤 새 링크로 다시 공유합니다.
