Deep Connector 문서 올리기

이 페이지는 컬렉션에 문서를 올리는 방법을 자세히 설명합니다. 지원하는 확장자 18가지와 형식별 처리 방식, 파이프라인 선택, 파일별·공통 메타데이터, 중복 확인, 업로드만 하기 옵션을 다룹니다. 첫 업로드를 따라 해 보려면 시작하기를 먼저 보세요.

이 페이지에서 할 수 있는 일

  • 올릴 수 있는 파일 형식과 크기 한도를 확인합니다.
  • 파일마다 다른 메타데이터를 붙이거나, 모든 파일에 같은 메타데이터를 붙입니다.
  • 같은 내용의 문서를 두 번 올리지 않도록 중복 확인 결과를 읽습니다.
  • 처리 방식을 정하기 전에 파일만 먼저 올려 둡니다.

지원 형식과 처리 방식​

업로드 화면 가운데에는 받을 수 있는 확장자가 묶음별로 나옵니다. 묶음 오른쪽 배지는 그 형식을 읽는 처리 엔진입니다.

묶음확장자처리 엔진처리 내용
PDF / Images.pdf, .png, .jpg, .jpeg, .webp, .tiff, .tif, .bmpVLM쪽 이미지를 읽어 글자와 표를 뽑습니다. 스캔본과 사진 속 글자도 읽습니다.
Office / Web.doc, .docx, .pptx, .md, .html, .htmDocling제목, 문단, 표 구조를 살려 읽습니다. 슬라이드는 장마다 읽습니다.
Spreadsheet.xlsx, .xlsData-LAB시트와 표를 읽습니다.
HWP / HWPX.hwp, .hwpxHWP Parser한글 문서의 문단과 표를 읽습니다.
  • 파일 하나는 최대 200 MB입니다.
  • 목록에 없는 형식(.ppt, .txt, .csv 등)이나 200 MB를 넘는 파일, 컬렉션에 같은 내용이 이미 있는 파일은 업로드에서 제외됩니다. 목록 위 "전체 N개 중 N개 업로드, 제외 N개" 안내에 제외 건수가 나오고, 제외된 항목 필터를 누르면 파일마다 "지원하지 않는 형식", "200 MB 초과", "컬렉션에 이미 있음" 같은 사유가 보입니다. .ppt는 .pptx로, .txt는 .md로, .csv는 .xlsx로 저장해 올리세요.
  • 업로드 화면에서 받는 형식이라도 처리 엔진 구성에 따라 처리가 실패할 수 있습니다. 이 매뉴얼의 시연 환경에서는 .xls 파일이 "Unsupported format: .xls — convert to .xlsx and retry"로 실패했습니다. 이럴 때는 .xlsx로 저장해 다시 올립니다. 문제 해결을 참고하세요.
  • 암호가 걸린 파일은 처리되지 않습니다. 암호를 풀고 올리세요.

파일을 고른 뒤의 화면​

파일을 고르면 왼쪽에 파일 목록이 생기고, 파일마다 내용 확인과 중복 확인이 진행됩니다.

파일을 고른 뒤의 업로드 화면

번호메뉴기능이런 때 사용하세요
1확인 결과"확인이 끝났습니다. 업로드할 수 있습니다."가 나오면 올릴 준비가 된 것입니다. 같은 내용의 문서가 컬렉션에 이미 있으면 여기서 알려 줍니다.같은 문서를 두 번 올리지 않는지 볼 때
2폴더 묶음폴더째 올리면 폴더별로 묶여 보입니다. 앞의 체크 상자로 폴더 단위로 넣고 뺍니다. 파일만 고르면 "(폴더 없음)"으로 묶입니다.폴더 안 일부 파일만 올릴 때
3파일 행파일 이름, 용량, 상태("확인됨")입니다. 왼쪽 화살표로 그 파일의 메타데이터를 펼칩니다.파일마다 다른 정보를 붙일 때
4파일별 메타데이터그 파일에만 붙는 정보입니다. 처음에는 파일 이름(source)과 시각(timestamp)이 채워져 있습니다.문서번호, 시행일 같은 정보를 적을 때
5필드 추가메타데이터 항목을 하나 더 만듭니다."시행일: 2026-01-01"을 붙일 때
6파일에서 가져오기JSON 파일에서 메타데이터를 불러옵니다(1 MB까지). 가져올 때 기존 값 비우기를 체크하면 기존 값을 지우고 채웁니다.메타데이터를 미리 정리해 둔 파일이 있을 때
7파일 제거이 파일을 업로드 목록에서 뺍니다.잘못 고른 파일을 뺄 때
8파이프라인처리 방식입니다. 컬렉션 기본값에 "(기본)"이 붙어 미리 골라져 있습니다.다른 처리 방식으로 결과를 비교할 때
9공통 메타데이터이번에 올리는 모든 파일에 붙는 정보입니다. 파일에서 따로 고친 값이 우선합니다.여러 파일에 "분류: 사내규정"을 함께 붙일 때
10문서 업로드 (4)고른 파일을 올리고 처리를 시작합니다.확인 결과와 설정을 확인했을 때

메타데이터 편집 영역에서 JSON으로 전환을 누르면 항목별 입력 대신 JSON 형식으로 직접 적을 수 있고, JSON 미리보기로 저장될 모양을 확인할 수 있습니다. 붙인 메타데이터는 검색 화면의 메타데이터 필터와 자유 필터에서 검색 범위를 좁히는 데 씁니다.

따라 해 보기: 공통 메타데이터 붙이기​

  1. 업로드 화면에서 파일을 고릅니다.
  2. 오른쪽 공통 메타데이터를 펼치고 필드 추가를 누릅니다.
  3. 왼쪽 칸(Key)에 "분류", 오른쪽 칸(Value)에 "사내규정"을 적습니다.
  4. 문서 업로드를 누릅니다. 처리가 끝나면 문서 상세의 청크 메타데이터에 "분류"가 보입니다.

업로드만 하기​

업로드만 하기를 체크하면 파일만 저장하고 처리는 하지 않습니다. 쓸 파이프라인을 담당자와 정하는 중이거나, 근무 시간이 끝난 뒤 처리를 몰아서 하려 할 때 씁니다. 저장해 둔 문서는 문서 목록에서 다시 적재로 처리를 시작합니다. 처리하기 전까지는 검색과 에이전트 답변에 쓰이지 않습니다.

업로드 뒤 처리 흐름​

상태뜻검색 가능 여부
처리 대기중업로드 대기열에 들어가 차례를 기다립니다.안 됨
처리중파이프라인이 문서를 읽고 나누는 중입니다.안 됨
완료청크가 만들어져 검색할 수 있습니다.됨
처리 실패, 업로드 실패처리 중 오류가 났습니다. 문서 이름 옆에 빨간 표시가 붙습니다.안 됨

업로드한 직후 다른 화면으로 이동하면 "업로드가 진행 중입니다. 이동하면 업로드가 취소될 수 있습니다." 경고가 나옵니다. 큰 파일은 업로드가 끝날 때까지 화면을 그대로 두세요.

사용량 한도​

업로드 건수와 저장공간에는 사용자별, 팀스페이스별 한도가 있습니다. 사이드바 아래 사용량 막대에서 남은 양을 봅니다. 한도에 닿으면 업로드 화면 위에 "할당량 제한으로 업로드가 차단되었습니다"가 나오고 문서 업로드 버튼이 동작하지 않습니다. 대처 방법은 문제 해결에 있습니다.
