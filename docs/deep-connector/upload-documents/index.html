Deep Connector 문서 올리기

이 페이지는 컬렉션에 문서를 올리는 방법을 자세히 설명합니다. 지원하는 확장자 18가지와 형식별 처리 방식, 파이프라인 선택, 파일별·공통 메타데이터, 중복 확인, 업로드만 하기 옵션, 업로드 대기열, 관리자가 서버 저장소의 폴더를 통째로 들여오는 방법을 다룹니다. 첫 업로드를 따라 해 보려면 시작하기를, 형식이 다른 파일 12개를 한꺼번에 올려 보려면 실습 1을 보세요.

이 페이지에서 할 수 있는 일

  • 올릴 수 있는 파일 형식과 크기 한도를 확인합니다.
  • 파일마다 다른 메타데이터를 붙이거나, 모든 파일에 같은 메타데이터를 붙입니다.
  • 같은 내용의 문서를 두 번 올리지 않도록 중복 확인 결과를 읽습니다.
  • 처리 방식을 정하기 전에 파일만 먼저 올려 두고, 나중에 한꺼번에 처리합니다.
  • 올라가지 못한 파일과 그 이유를 업로드 대기열에서 찾습니다.
  • (관리자) 서버 저장소의 폴더를 컬렉션으로 반입합니다.

지원 형식과 처리 방식​

업로드 화면 가운데에는 받을 수 있는 확장자가 묶음별로 나옵니다. 묶음 오른쪽 배지는 그 형식을 읽는 처리 엔진입니다.

묶음확장자처리 엔진처리 내용
PDF / Images.pdf, .png, .jpg, .jpeg, .webp, .tiff, .tif, .bmpVLM쪽 이미지를 읽어 글자와 표를 뽑습니다. 스캔본과 사진 속 글자도 읽습니다.
Office / Web.doc, .docx, .pptx, .md, .html, .htmDocling제목, 문단, 표 구조를 살려 읽습니다. 슬라이드는 장마다 읽습니다.
Spreadsheet.xlsx, .xlsData-LAB시트와 표를 읽습니다.
HWP / HWPX.hwp, .hwpxHWP Parser한글 문서의 문단과 표를 읽습니다.
  • 파일 하나는 최대 200 MB입니다.
  • 목록에 없는 형식(.txt, .csv, .ppt 등)은 컬렉션에 들어가지 않습니다. 업로드 화면 설정에 따라 두 가지로 보입니다.
    • 파일을 고를 때 바로 "지원하지 않는 형식"으로 제외됩니다. 목록 위 "전체 N개 중 N개 업로드, 제외 N개" 안내에 제외 건수가 나오고, 제외된 항목 필터를 누르면 파일마다 사유가 보입니다.
    • 이 매뉴얼의 시연 환경처럼 업로드 화면이 .txt와 .csv도 받도록 설정되어 있으면, 파일 행이 "확인됨"으로 보이고 업로드까지 진행됩니다. 그러나 서버가 받지 않아 문서 목록에는 나타나지 않고, "최근 업로드 실패 N건" 알림과 함께 아래 "업로드 대기열" 절에서 설명하는 대기열 창에 "unsupported file type (mime=text/plain)" 같은 사유가 남습니다.
  • .ppt는 .pptx로, .txt는 .md나 .html로, .csv는 .xlsx로 저장해 올리세요.
  • 200 MB를 넘는 파일은 "200 MB 초과", 컬렉션에 같은 내용이 이미 있는 파일은 "컬렉션에 이미 있음: 기존 문서 이름(상태)", 이번에 함께 고른 파일끼리 내용이 같으면 "같은 내용: 다른 파일 이름"으로 제외됩니다. .DS_Store, Thumbs.db처럼 운영체제가 만든 파일과 숨김 폴더는 "시스템 파일"로 제외됩니다.
  • 업로드 화면에서 받는 형식이라도 처리 엔진 구성에 따라 처리가 실패할 수 있습니다. 이 매뉴얼의 시연 환경에서는 .xls 파일이 "Unsupported format: .xls — convert to .xlsx and retry"로 실패했습니다. 이럴 때는 .xlsx로 저장해 다시 올립니다. 문제 해결을 참고하세요.
  • 암호가 걸린 파일은 처리되지 않습니다. 암호를 풀고 올리세요.

파일을 고른 뒤의 화면​

파일을 고르면 왼쪽에 파일 목록이 생기고, 파일마다 내용 확인과 중복 확인이 진행됩니다.

파일을 고른 뒤의 업로드 화면

번호메뉴기능이런 때 사용하세요
1확인 결과"확인이 끝났습니다. 업로드할 수 있습니다."가 나오면 올릴 준비가 된 것입니다. 같은 내용의 문서가 컬렉션에 이미 있으면 여기서 알려 줍니다.같은 문서를 두 번 올리지 않는지 볼 때
2폴더 묶음폴더째 올리면 폴더별로 묶여 보입니다. 앞의 체크 상자로 폴더 단위로 넣고 뺍니다. 파일만 고르면 "(폴더 없음)"으로 묶입니다.폴더 안 일부 파일만 올릴 때
3파일 행파일 이름, 용량, 상태("확인됨")입니다. 왼쪽 화살표로 그 파일의 메타데이터를 펼칩니다.파일마다 다른 정보를 붙일 때
4파일 제거이 파일을 업로드 목록에서 뺍니다.잘못 고른 파일을 뺄 때

파일별 메타데이터

번호메뉴기능이런 때 사용하세요
1파일별 메타데이터그 파일에만 붙는 정보입니다. 처음에는 파일 이름(source)과 시각(timestamp)이 채워져 있습니다.문서번호, 시행일 같은 정보를 적을 때
2필드 추가메타데이터 항목을 하나 더 만듭니다."시행일: 2026-01-01"을 붙일 때
3파일에서 가져오기JSON 파일에서 메타데이터를 불러옵니다(1 MB까지). 가져올 때 기존 값 비우기를 체크하면 기존 값을 지우고 채웁니다.메타데이터를 미리 정리해 둔 파일이 있을 때

업로드 설정과 실행

번호메뉴기능이런 때 사용하세요
1파이프라인처리 방식입니다. 컬렉션 기본값에 "(기본)"이 붙어 미리 골라져 있습니다.다른 처리 방식으로 결과를 비교할 때
2공통 메타데이터이번에 올리는 모든 파일에 붙는 정보입니다. 파일에서 따로 고친 값이 우선합니다.여러 파일에 "분류: 사내규정"을 함께 붙일 때
3문서 업로드 (4)고른 파일을 올리고 처리를 시작합니다.확인 결과와 설정을 확인했을 때

메타데이터 편집 영역에서 JSON으로 전환을 누르면 항목별 입력 대신 JSON 형식으로 직접 적을 수 있고, JSON 미리보기로 저장될 모양을 확인할 수 있습니다. 붙인 메타데이터는 검색 화면의 메타데이터 필터와 자유 필터에서 검색 범위를 좁히는 데 씁니다.

따라 해 보기: 공통 메타데이터 붙이기​

  1. 업로드 화면에서 파일을 고릅니다.
  2. 오른쪽 공통 메타데이터를 펼치고 필드 추가를 누릅니다.
  3. 왼쪽 칸(Key)에 "분류", 오른쪽 칸(Value)에 "사내규정"을 적습니다.
  4. 문서 업로드를 누릅니다. 처리가 끝나면 문서 상세의 청크 메타데이터에 "분류"가 보입니다.

이럴 때 쓰세요: 김그루 사원은 인사팀에서 받은 복리후생 안내 파일 여섯 개(PDF, 한글 문서, 포스터 이미지 등)를 한 번에 고르고, 공통 메타데이터에 "관리부서: 인사팀"을 붙여 올립니다. 나중에 검색 화면에서 관리부서로 걸러 볼 수 있습니다.

업로드만 하기​

업로드만 하기를 체크하면 파일만 저장하고 처리는 하지 않습니다. 쓸 파이프라인을 담당자와 정하는 중이거나, 근무 시간이 끝난 뒤 처리를 몰아서 하려 할 때 씁니다. 저장해 둔 문서는 청크 수가 0이고 처리 전 상태로 남습니다. 문서 목록 위 미처리 N건 적재를 누르면 처리하지 않은 문서를 모두 처리하고, 처리에 실패한 문서도 함께 다시 처리합니다. 몇 개만 처리하려면 행 왼쪽 체크로 고른 뒤 위에 나타나는 적재 시작을 누릅니다. 처리하기 전까지는 검색과 에이전트 답변에 쓰이지 않습니다.

업로드 대기열​

문서 업로드를 누르면 문서 목록으로 돌아가고, 화면 오른쪽 아래에 문서 업로드 대기열 창이 생깁니다. 파일 전송이 진행되는 동안 "업로드 중 N건", "대기 중"이 보이고, 서버가 받지 않은 파일은 업로드 실패 (N건) 아래에 파일 이름과 사유가 남습니다.

업로드 대기열

번호메뉴기능이런 때 사용하세요
1문서 수실제로 목록에 들어온 문서 수입니다. 고른 파일 수(이 예에서는 12개)보다 적으면 대기열을 봅니다.올린 파일이 모두 들어왔는지 볼 때
2업로드 실패 (N건)서버가 받지 않은 파일 묶음입니다. 펼치기·접기로 창을 열고 닫고, 실패 목록 지우기로 기록을 비웁니다.업로드 직후 "최근 업로드 실패 N건" 알림이 나왔을 때
3실패한 파일과 사유파일 이름과 서버가 돌려준 사유입니다. "unsupported file type"은 처리할 수 없는 형식이라는 뜻입니다.어떤 형식으로 바꿔 올릴지 정할 때
4처리 실패 표시목록에는 들어왔지만 처리 단계에서 실패한 문서입니다. 누르면 오류 상세가 열립니다.처리 엔진이 읽지 못한 파일을 찾을 때

대기열은 "업로드" 실패만 모읍니다. 목록에 들어온 뒤 처리 단계에서 실패한 문서는 문서 행의 경고 표시로 확인합니다(문제 해결).

이럴 때 쓰세요: 김그루 사원이 팀 공유 폴더의 파일 12개를 한꺼번에 올렸는데 목록에는 10개만 보입니다. 대기열을 펼쳐 회의록 .txt와 설문 .csv가 "unsupported file type"으로 빠진 것을 확인하고, 회의록은 .md로, 설문은 .xlsx로 저장해 다시 올립니다.

서버 저장소에서 반입하기(관리자)​

관리자는 문서 업로드 화면에서 내 컴퓨터 옆 서버 저장소 탭을 쓸 수 있습니다. 서버에 연결된 공유 폴더(NAS)의 파일을 내 PC로 내려받지 않고 바로 컬렉션에 들여옵니다. 서버 설정에 반입할 저장소가 등록된 경우에만 탭이 보입니다.

서버 저장소 반입

번호메뉴기능이런 때 사용하세요
1서버 저장소서버 공유 폴더에서 반입하는 탭입니다.부서 공유 폴더의 문서를 한꺼번에 옮길 때
2저장소·저장 방식반입할 저장소(종류 배지 NAS와 서버 경로, 그림에서는 경로를 가렸습니다)와 저장 방식입니다. 복사는 원천 파일을 문서 저장소로 복사해 등록합니다. 서버 구성에 따라 복사하지 않고 원천 파일을 그대로 가리키는 참조를 고를 수 있습니다.원본을 공유 폴더에 그대로 두고 관리할지 정할 때
3폴더·파일 체크폴더를 체크하면 안의 파일이 모두 들어갑니다. 화살표로 펼쳐 일부 파일만 고를 수도 있습니다. 고르면 "전체 5개 중 5개 반입 (1.6 KB), 제외 0개"처럼 반입할 파일 수를 세고 "반입할 수 있습니다."가 나옵니다.필요한 하위 폴더만 들여올 때
4반입 시작 (N)반입을 시작합니다. 괄호 안은 반입할 파일 수입니다.수와 제외 사유를 확인했을 때
설정 항목뜻기본값
저장소반입할 서버 저장소등록된 첫 저장소
저장 방식복사 또는 참조복사(참조를 지원하지 않는 구성에서는 복사만)
같은 이름의 .json 파일을 메타데이터로 붙이기a.pdf 옆의 a.pdf.json이나 a.json을 그 파일의 메타데이터로 붙입니다.꺼짐
자동 메타데이터파일마다 source(파일명), folder, path가 붙습니다.항상 붙음
파이프라인, 공통 메타데이터, 업로드만 하기내 컴퓨터 탭과 같습니다.내 컴퓨터 탭과 같음

반입하는 파일에도 같은 18가지 확장자 규칙이 적용됩니다. 지원하지 않는 파일은 트리에 "미지원" 배지가 붙고, 반입 요약의 "지원하지 않는 형식 N개"와 제외된 파일 목록에 모입니다. 같은 내용의 문서가 이미 있으면 건너뜁니다. 한 번에 반입할 수 있는 파일 수에는 상한이 있어, 넘으면 "파일이 너무 많습니다. 하위 폴더로 나누어 반입하세요."가 나옵니다.

반입 시작을 누르면 문서 탭으로 돌아가고 위쪽에 원천 반입 진행 카드가 나옵니다. 카드에는 상태(진행 중, 완료 등), "N/M개 처리", 완료·건너뜀·실패 건수와 취소 버튼이 있습니다. 끝나면 "반입이 끝났습니다. 완료 N건, 건너뜀 N건, 실패 N건" 알림이 나오고 문서가 목록에 생깁니다.

반입이 끝난 문서 목록

번호메뉴기능이런 때 사용하세요

2반입된 문서공유 폴더의 파일 이름 그대로 들어옵니다. 청크 메타데이터의 path에서 원래 폴더 위치를 볼 수 있습니다.원본이 공유 폴더의 어디에 있는지 찾을 때

이럴 때 쓰세요: 강혁신 팀장은 팀 공유 폴더에 쌓인 팀위키 노트(.md 5개)를 "브레인크루 팀위키" 컬렉션으로 옮기려 합니다. 직원들에게 파일을 내려받아 다시 올리게 하지 않고, 서버 저장소 탭에서 브레인크루-팀위키 폴더를 체크해 한 번에 반입합니다.

업로드 뒤 처리 흐름​

상태뜻검색 가능 여부
처리 대기중업로드 대기열에 들어가 차례를 기다립니다.안 됨
처리중파이프라인이 문서를 읽고 나누는 중입니다.안 됨
완료청크가 만들어져 검색할 수 있습니다.됨
처리 실패, 업로드 실패처리 중 오류가 났습니다. 문서 이름 옆에 빨간 표시가 붙습니다.안 됨

업로드한 직후 다른 화면으로 이동하면 "업로드가 진행 중입니다. 이동하면 업로드가 취소될 수 있습니다." 경고가 나옵니다. 큰 파일은 업로드가 끝날 때까지 화면을 그대로 두세요.

사용량 한도​

업로드 건수와 저장공간에는 사용자별, 팀스페이스별 한도가 있습니다. 사이드바 아래 사용량 막대에서 남은 양을 봅니다. 한도에 닿으면 업로드 화면 위에 "할당량 제한으로 업로드가 차단되었습니다"가 나오고 문서 업로드 버튼이 동작하지 않습니다. 대처 방법은 문제 해결에 있습니다.
