Deep Connector 권한·공유·접근 요청

컬렉션에는 누가 보고, 누가 올리고, 누가 지울 수 있는지가 따로 정해집니다. 이 페이지는 컬렉션 담당자가 접근 수준과 공유 등급을 정하는 방법, 다른 직원이 접근을 요청하는 흐름, 팀이 컬렉션을 함께 소유하는 워크스페이스를 설명합니다.

이 페이지에서 할 수 있는 일

  • 접근 수준 세 가지(공개, 제한, 비공개)의 차이를 알고 컬렉션에 맞게 고릅니다.
  • 동료에게 Level1~3 등급으로 컬렉션을 공유합니다.
  • 제한 컬렉션에 접근을 요청하고 결과를 확인합니다.
  • 팀 워크스페이스를 만들고 멤버를 추가합니다.

권한을 정하는 세 가지​

구분정하는 것어디서
접근 수준컬렉션이 누구에게 보이는지공유/권한 탭, 컬렉션 메뉴의 접근 수준 변경
공유 등급공유받은 사람이 무엇을 할 수 있는지공유/권한 탭의 공유 멤버
워크스페이스컬렉션을 누가 함께 소유하고 승인 책임을 지는지사이드바 워크스페이스
접근 수준뜻이런 컬렉션에
공개승인된 모든 사용자가 바로 조회·검색할 수 있습니다.전 직원이 보는 사내 규정, 복리후생 안내
제한목록에는 보이지만 접근 승인을 받아야 문서를 볼 수 있습니다.영업 제안서처럼 필요한 사람만 요청해서 보는 자료
비공개소유자와 공유받은 멤버만 접근합니다. 새 컬렉션은 비공개로 만들어집니다.검토 중인 개정안, 개인 연습용 컬렉션
공유 등급할 수 있는 일
Level1: 조회컬렉션 조회, 문서 조회와 검색
Level2: 조회/업로드Level1 + 문서 업로드와 수정
Level3: 조회/업로드/삭제Level2 + 문서 삭제

공유/권한 탭​

컬렉션을 열고 공유/권한 탭을 누릅니다. 컬렉션을 공유할 권한이 있는 사람에게만 보입니다.

공유/권한 탭

번호메뉴기능이런 때 사용하세요
1접근 수준공개, 제한, 비공개 중에서 고릅니다. 고르는 즉시 바뀝니다.검토가 끝난 컬렉션을 전 직원에게 열 때
2공유 상태컬렉션 공유를 켜거나 끕니다. 끄면 공유 멤버에게 더는 보이지 않습니다.공유를 잠시 멈출 때
3MCP 토큰이 컬렉션에 접근할 수 있는 내 MCP 토큰 수입니다. 설정에서 관리로 토큰 화면에 갑니다.외부 도구가 이 컬렉션을 읽을 수 있는지 볼 때
4등급 안내Level1~3이 각각 무엇을 허용하는지 적혀 있습니다.동료에게 줄 등급을 고를 때
5팀 선택팀을 고르면 아래에 구성원이 나옵니다.공유할 사람이 속한 팀을 찾을 때
6구성원 목록누르면 오른쪽 선택된 사용자 목록에 들어갑니다.공유할 사람을 고를 때
7등급선택한 사용자에게 줄 등급입니다.조회만 줄지 업로드까지 줄지 정할 때
8빼기선택한 사용자를 목록에서 뺍니다.잘못 고른 사람을 뺄 때
9저장공유 설정을 저장합니다. 누르기 전에는 반영되지 않습니다.공유 대상과 등급을 다 골랐을 때

아래쪽 워크스페이스 공유에서는 다른 워크스페이스에 이 컬렉션의 접근 권한만 줄 수 있습니다. 소유권과 저장 용량은 옮겨지지 않습니다. 등급은 Viewer(조회·검색·RAG 실행), Editor(Viewer + 문서 업로드·수정), Manager(Editor + 공유·권한 관리·삭제)입니다.

따라 해 보기​

  1. "규정 Q&A" 컬렉션의 공유/권한 탭을 엽니다.
  2. 팀 선택에서 "경영지원팀"을 고르고 구성원 "윤지원"을 누릅니다.
  3. 오른쪽 등급을 Level1: 조회로 둡니다.
  4. 저장을 누릅니다. "공유 설정 저장 완료"가 나오면 끝입니다.

이 시연 환경에서 회사 계정 목록에 없는 사용자에게 Level2 이상을 주면 "계정이 없는 사용자는 조회만 줄 수 있습니다."가 나오고 저장되지 않습니다. 이때는 Level1로 저장하거나, 해당 사용자가 한 번 로그인한 뒤 다시 시도하세요.

접근 요청​

접근 수준이 제한인 컬렉션은 목록에 보이지만 문서를 열 수 없습니다. 영업팀 이영업 사원이 김그루의 "규정 Q&A" 컬렉션을 열면 다음 화면이 나옵니다.

권한이 없는 컬렉션

번호메뉴기능이런 때 사용하세요
1권한 안내"이 컬렉션의 문서를 볼 수 있는 권한이 없습니다."왜 문서가 보이지 않는지 알 때
2접근 요청접근 요청 창을 엽니다.컬렉션을 볼 필요가 있을 때

접근 요청 창

번호메뉴기능이런 때 사용하세요
1요청 등급받고 싶은 등급입니다.조회만 필요하면 Level1을 고를 때
2요청 사유왜 필요한지 적습니다. 승인하는 사람이 읽습니다.업무상 이유를 밝힐 때
3취소보내지 않고 닫습니다.요청할 필요가 없어졌을 때
4요청 보내기요청을 보냅니다.내용을 다 적었을 때

보낸 요청은 사이드바 접근 요청에서 확인합니다.

내 접근 요청

번호메뉴기능이런 때 사용하세요
1요청 목록 머리글컬렉션, 요청 등급, 부여 등급, 상태, 처리자, 처리일, 신청일 열입니다.요청이 승인됐는지, 어떤 등급을 받았는지 볼 때
2요청 행보낸 요청입니다.요청 내용을 확인할 때
3상태대기 중, 승인됨, 거부됨, 철회됨 중 하나입니다.처리 결과를 볼 때

요청은 Deep Connector 관리자가 관리자 메뉴의 컬렉션 권한 화면에서 승인하거나 거부합니다. 승인되면 다음에 컬렉션을 열 때 문서가 보입니다. 거부되면 거부 사유가 함께 표시됩니다.

워크스페이스​

워크스페이스는 컬렉션과 승인 책임을 팀 단위로 묶는 공간입니다. 개인 컬렉션은 "내 컬렉션"에 속하고, 팀 워크스페이스를 만들면 팀원이 함께 소유하고 관리합니다.

새 팀 워크스페이스 창

번호메뉴기능이런 때 사용하세요
1이름워크스페이스 이름입니다."AI혁신팀 지식관리"처럼 팀과 용도를 드러낼 때
2설명이 워크스페이스가 관리하는 지식의 범위입니다.다른 팀이 용도를 알 수 있게 할 때
3워크스페이스 만들기만듭니다. 만든 사람이 Owner가 됩니다.입력을 마쳤을 때

워크스페이스를 열면 컬렉션, 멤버, 설정 탭이 있습니다.

워크스페이스 멤버 탭

번호메뉴기능이런 때 사용하세요
1워크스페이스 요약소유한 컬렉션 수, 멤버 수, 사용 용량입니다.워크스페이스 현황을 볼 때
2컬렉션이 워크스페이스가 소유한 컬렉션과 폴더입니다.팀 컬렉션을 정리할 때
3멤버멤버를 추가하고 역할을 정합니다.팀원을 넣을 때
4설정저장 용량 한도, 소유권 이전, 워크스페이스 삭제가 있습니다. Owner만 바꿀 수 있습니다.담당자가 바뀌어 소유권을 넘길 때
5사용자 ID추가할 사람의 이메일이나 사용자 ID를 적습니다.팀원을 찾을 때
6역할Admin이나 Member 중에서 고릅니다.승인 권한까지 줄지 정할 때
7추가멤버로 넣습니다.입력을 마쳤을 때
8멤버 역할멤버마다 역할(Owner, Admin, Member)이 표시됩니다. 멤버 행의 제거로 멤버를 빼면 이 워크스페이스로 얻은 컬렉션 권한이 바로 사라집니다.누가 승인 권한을 가졌는지 볼 때
역할할 수 있는 일
Owner소유권 이전, 삭제, 용량 정책, Admin 지정
Admin멤버 관리, 권한·에이전트·MCP 승인
Member허용된 자원 사용, 권한 요청 제출
