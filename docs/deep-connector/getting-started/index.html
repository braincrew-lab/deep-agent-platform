Deep Connector 시작하기

이 페이지는 김그루 사원이 처음 Deep Connector에 로그인해 "규정 Q&A" 컬렉션을 만들고, 사내 규정 파일 네 개를 올려 처리 결과를 확인한 뒤 첫 검색까지 해 보는 과정을 화면 순서대로 안내합니다. 따라 하는 데 20분 정도 걸립니다.

이 페이지에서 할 수 있는 일

  • 이메일과 비밀번호로 로그인합니다.
  • 새 컬렉션을 만들고 기본 파이프라인을 정합니다.
  • 서로 다른 형식의 파일 네 개를 한 번에 올리고 처리 상태를 확인합니다.
  • 실험 메뉴의 검색에서 방금 올린 문서의 내용을 찾습니다.
  • 업무를 마친 뒤 로그아웃합니다.

준비물​

파일확장자내용
출장비-지급-규정.pdf.pdf국내 일비, 숙박비 상한, 해외 출장, 정산 기한
재택근무-운영-지침.docx.docx대상, 신청 마감, 코어타임, 보안
연차-사용-안내.md.md연차 발생, 반차와 반반차, 신청 기한
경비-처리-기준.hwp.hwp법인카드 증빙, 식대 한도, 승인권자 표

모두 매뉴얼 시연용 가상 자료입니다. 내 업무 파일로 따라 해도 됩니다.

1. 로그인​

Deep Connector 주소로 접속하면 로그인 화면이 열립니다. 회사에서 받은 이메일과 비밀번호를 씁니다.

로그인 화면

번호메뉴기능이런 때 사용하세요
1이메일회사 이메일 주소를 입력합니다.처음 접속하거나 로그아웃한 뒤 다시 들어올 때
2비밀번호비밀번호를 입력합니다. 입력한 글자는 가려집니다.이메일 다음 칸에 본인 비밀번호를 적을 때
3비밀번호 찾기비밀번호 재설정 화면으로 갑니다.비밀번호가 기억나지 않을 때
4로그인입력한 계정으로 들어갑니다. Enter를 눌러도 됩니다.두 칸을 모두 채웠을 때

계정이 없거나 비밀번호를 잊었을 때는 같은 로그인 화면에서 처리합니다. 이 화면은 Deep Connector가 아니라 회사 계정 화면이라 다른 제품과 같은 계정을 씁니다.

하고 싶은 일누를 곳화면에서 할 일그다음
새 계정 신청아래 "계정이 없으신가요?" 옆 회원가입이메일과 사용할 비밀번호를 적습니다. 관리자에게 초대 코드를 받았다면 **초대 코드 (선택)**에 넣습니다."회원가입이 완료되었습니다. 승인 후 이용 가능합니다."가 나옵니다. 관리자가 승인해야 로그인할 수 있습니다.
비밀번호 다시 정하기비밀번호 찾기"가입하신 이메일을 입력하시면 비밀번호 재설정 링크를 보내드립니다." 안내에 따라 회사 이메일을 적습니다."이메일을 확인해주세요"가 나오면 메일의 링크로 새 비밀번호를 정합니다. 메일이 오지 않으면 다른 이메일로 재시도를 누릅니다.

로그인하면 컬렉션 화면이 열립니다. 화면 각 부분은 메뉴 안내에서 설명합니다.

2. 새 컬렉션 만들기​

컬렉션 화면 오른쪽 위 새 컬렉션을 누르면 아래 화면이 열립니다.

새 컬렉션 화면

번호메뉴기능이런 때 사용하세요
1컬렉션 이름컬렉션 이름입니다. 같은 이름은 쓸 수 없고 "/"는 넣을 수 없습니다."규정 Q&A"처럼 쓰임새가 드러나는 이름을 붙일 때
2설명어떤 문서를 왜 모았는지 적습니다. 선택 사항이지만 에이전트가 컬렉션을 고를 때 참고하므로 채우기를 권합니다.다른 사람이 컬렉션 용도를 알 수 있게 할 때
3위치(폴더)컬렉션을 넣을 폴더입니다. 고르지 않으면 "분류 없음"에 만들어집니다.부서 폴더에 바로 넣을 때
4기본 파이프라인업로드할 때 파이프라인을 따로 고르지 않으면 이 처리 방식을 씁니다.컬렉션의 문서를 늘 같은 방식으로 처리할 때

새 컬렉션 화면 아래쪽

번호메뉴기능이런 때 사용하세요
1고급 설정펼치면 컬렉션 메타데이터를 적을 수 있습니다.부서명, 관리 담당 같은 정보를 붙일 때
2취소만들지 않고 컬렉션 화면으로 돌아갑니다.기존 컬렉션을 쓰기로 했을 때
3새 컬렉션 만들기컬렉션을 만들고 그 컬렉션의 문서 탭으로 이동합니다.입력을 마쳤을 때

따라 해 보기​

  1. 컬렉션 이름에 "규정 Q&A"를 적습니다.
  2. 설명에 "출장비, 재택근무, 연차, 경비 처리 등 직원 문의가 많은 사내 규정 모음"을 적습니다.
  3. 기본 파이프라인에서 "기본 파이프라인"을 고릅니다.
  4. 새 컬렉션 만들기를 누릅니다. "컬렉션이 성공적으로 생성되었습니다" 알림이 나오고 빈 문서 탭이 열립니다.

새 컬렉션은 접근 수준 비공개로 만들어집니다. 다른 사람과 함께 쓰려면 권한·공유·접근 요청을 참고하세요.

3. 문서 올리기​

문서 탭 오른쪽 위 문서 업로드를 누르면 업로드 화면이 열립니다.

문서 업로드 화면

번호메뉴기능이런 때 사용하세요
1내 컴퓨터내 PC의 파일을 올리는 탭입니다.메일로 받은 규정 파일을 올릴 때
2파일 추가파일 선택 창을 엽니다. 여러 개를 한 번에 고를 수 있고, 가운데 영역에 끌어다 놓아도 됩니다.파일 몇 개를 올릴 때
3폴더 추가폴더를 통째로 골라 안의 파일을 모두 올립니다.부서 공유 폴더를 한 번에 옮길 때
4공통 메타데이터이번에 올리는 모든 파일에 같은 정보를 붙입니다.여러 파일에 "분류: 사내규정"을 함께 붙일 때

지원 형식과 업로드 설정

번호메뉴기능이런 때 사용하세요
1지원 형식올릴 수 있는 확장자를 묶음별로 보여 줍니다.받은 파일을 올릴 수 있는지 확인할 때
2크기 한도파일 하나당 200 MB까지입니다.스캔 PDF처럼 큰 파일을 올리기 전에
3대상 컬렉션파일이 들어갈 컬렉션입니다.엉뚱한 컬렉션에 올리지 않는지 확인할 때
4파이프라인처리 방식을 고릅니다. 컬렉션 기본값에는 "(기본)"이 붙습니다.다른 처리 방식으로 결과를 비교할 때

업로드 실행 버튼

번호메뉴기능이런 때 사용하세요
1업로드만 하기파일만 저장하고 처리는 나중에 문서 목록에서 시작합니다.파이프라인을 정하기 전에 파일부터 모아 둘 때
2취소올리지 않고 문서 목록으로 돌아갑니다.다른 컬렉션에 올려야 할 때
3문서 업로드파일을 올리고 처리를 시작합니다. 파일을 고르면 버튼에 건수가 붙습니다.파일과 설정을 확인했을 때

따라 해 보기​

  1. 파일 추가를 누르고 준비한 파일 네 개를 한 번에 고릅니다.
  2. 목록 위에 "확인이 끝났습니다. 업로드할 수 있습니다."가 나올 때까지 기다립니다. 이 사이에 파일 내용이 컬렉션의 기존 문서와 같은지 검사합니다.
  3. 파이프라인이 "기본 파이프라인 (기본)"인지 확인합니다.
  4. **문서 업로드 (4)**를 누릅니다. 문서 목록으로 돌아가고 "4개 파일을 업로드 대기열에 넣었습니다." 알림이 나옵니다.

파일별 메타데이터와 형식별 처리 방식은 문서 올리기에서 자세히 설명합니다.

4. 처리 상태 확인​

업로드가 끝나도 바로 검색되지 않습니다. 문서를 읽고 청크로 나누는 처리(적재)가 끝나야 검색과 에이전트 답변에 쓰입니다.

처리 중인 문서 목록

번호메뉴기능이런 때 사용하세요
1문서 수이 컬렉션의 문서 수입니다.올린 파일 수가 맞는지 볼 때
2필터상태, 업로드 날짜, 확장자로 목록을 좁힙니다.처리 실패한 문서만 볼 때
3문서명 검색파일 이름으로 목록을 좁힙니다.문서가 많은 컬렉션에서 파일 하나를 찾을 때
4문서 업로드업로드 화면을 다시 엽니다.파일을 더 올릴 때

처리 중 표시

번호메뉴기능이런 때 사용하세요
1문서 이름누르면 문서 상세가 열립니다.처리 결과를 원본과 대조할 때
2문서 미리보기오른쪽에 문서 요약 창을 엽니다.문서 상세로 가지 않고 내용을 볼 때
3청크 수처리로 만들어진 청크 수입니다. 처리 중에는 0입니다.처리가 끝났는지 볼 때

처리가 끝난 문서 목록

번호메뉴기능이런 때 사용하세요
1청크 탭처리로 만들어진 청크 목록입니다. 옆 숫자가 이 컬렉션의 청크 수입니다.문장이 청크에 들어갔는지 볼 때
2접근 수준과 저장소 표시왼쪽은 이 컬렉션의 접근 수준(공개, 제한, 비공개), 오른쪽은 검색용 데이터를 보관하는 저장소 종류입니다.내 문서가 다른 사람에게 보이는지 확인하거나 담당자가 저장소 종류를 물을 때
3문서 이름과 형식 아이콘파일 형식 아이콘과 이름입니다.원하는 문서인지 확인할 때

청크 수와 페이지 수

번호메뉴기능이런 때 사용하세요
1문서 미리보기문서 요약 창을 엽니다.내용을 빠르게 볼 때
2청크 수이 예에서는 문서마다 1~2개입니다.0이면 처리 결과가 비었는지 의심할 때
3페이지 수PDF처럼 쪽 구분이 있는 문서의 쪽수입니다.일부 쪽만 처리되지 않았는지 볼 때

문서 행 작업 버튼

번호메뉴기능이런 때 사용하세요
1다시 적재지금 파일로 처리를 다시 합니다.처리 결과가 이상할 때
2삭제문서를 컬렉션에서 지웁니다.잘못 올린 파일을 지울 때

처리 시간은 분량과 서버 상황에 따라 다릅니다. 짧은 규정 파일 네 개는 보통 1~2분이면 끝납니다. 화면이 그대로면 브라우저를 새로 고칩니다. 처리에 실패한 문서는 빨간 경고 표시가 붙습니다. 대처 방법은 문제 해결에 있습니다.

5. 첫 검색​

처리가 끝나면 사이드바 실험 > 검색에서 내용을 찾아볼 수 있습니다. 처음 들어가면 실험 공간 안내가 나옵니다. 세 항목을 읽고 체크한 뒤 확인하고 시작하기를 누르세요. 안내 내용은 실험: 검색에 있습니다.

검색 화면

번호메뉴기능이런 때 사용하세요
1컬렉션 선택검색할 컬렉션을 고릅니다.내가 만든 컬렉션에서만 찾을 때
2검색 방식시맨틱, 키워드, 하이브리드, 문자열 검색 중에서 고릅니다.문장으로 물을지, 낱말로 찾을지 정할 때
3결과 제한결과를 몇 개까지 볼지 고릅니다.결과를 넓게 보고 싶을 때
4사전 확장연결된 용어 사전으로 검색어를 동의어까지 넓힙니다."법카"로 "법인카드"까지 찾을 때

검색 필터와 고급 옵션

번호메뉴기능이런 때 사용하세요
1메타데이터 필터문서에 붙은 메타데이터로 결과를 좁힙니다.특정 분류의 문서만 볼 때
2자유 필터조건을 직접 적습니다.파일 하나만 대상으로 검색할 때
3고급 옵션이번 검색에만 쓸 세부 설정을 엽니다.리랭커를 끄고 결과를 비교할 때

검색 결과

번호메뉴기능이런 때 사용하세요
1검색어 입력란찾을 내용을 적고 Enter를 누릅니다.질문을 그대로 적을 때
2검색검색을 실행합니다.검색어를 다 적었을 때
3실제 적용된 설정방금 검색에 쓰인 분석기, 검색 방식, 리랭커 사용 여부입니다.고른 방식대로 검색됐는지 확인할 때
4원본 다운로드그 결과가 나온 원본 파일을 내려받습니다.검색된 문장을 원문과 대조할 때

결과 카드에는 순위, 문서 이름, 청크 번호, 쪽, 신뢰도, 본문이 보입니다. 답이 어느 문서에 있는지 볼 때 씁니다.

따라 해 보기​

  1. 컬렉션 선택에서 "규정 Q&A"를 고릅니다.

  2. 검색 방식은 시맨틱 검색 그대로 둡니다.

  3. 검색어 입력란에 아래 질문을 적고 Enter를 누릅니다.

    프롬프트: 서울로 출장 가면 숙박비는 하룻밤에 얼마까지 나와요?

  4. 첫 결과가 "출장비-지급-규정.pdf"이고 본문에 "1박 상한은 서울·수도권 120,000원"이 있는지 확인합니다. 결과 카드를 눌러 본문을 끝까지 읽어 보세요.
