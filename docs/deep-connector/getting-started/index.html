Deep Connector 시작하기

사용 목적​

이 문서는 Deep Connector를 처음 사용하는 팀원이 첫 컬렉션을 만들고 문서를 업로드해 검색까지 해보는 과정을 안내합니다. 컬렉션을 만들 때 선택하는 벡터 데이터베이스와 접근 범위, 업로드 가능한 문서 형식과 용량 제한, 업로드 후 처리 상태를 확인하는 방법을 순서대로 설명합니다.

화면 위치​

사이드바의 컬렉션 메뉴를 누르면 컬렉션 목록 화면이 나타나고, 화면 상단이나 목록 안의 새 컬렉션 버튼을 누르면 새 컬렉션 만들기 대화상자가 열립니다. 컬렉션을 만든 뒤에는 해당 컬렉션 화면으로 들어가 문서 업로드 버튼을 눌러 파일을 추가할 수 있습니다.

단계​

  1. 사이드바에서 컬렉션 메뉴를 누르고 새 컬렉션 버튼을 눌러 새 컬렉션 만들기 대화상자를 엽니다. 예상 결과: 컬렉션 이름, 설명, 벡터 데이터베이스를 입력하는 대화상자가 열립니다.
  2. 컬렉션 이름과 설명을 입력하고, 벡터 데이터베이스 항목에서 PostgreSQL, Qdrant, Oracle 23ai, GraphDB, Elasticsearch 중 하나를 선택합니다. 조직에서 별도로 안내한 값이 없다면 기본으로 제공되는 값을 선택해도 됩니다. 이어서 컬렉션의 접근 범위를 공개, 제한, 비공개 중에서 고릅니다. 예상 결과: 컬렉션 이름, 설명, 벡터 데이터베이스 항목을 입력할 수 있습니다.
  3. 생성 버튼을 눌러 컬렉션을 만듭니다. 예상 결과: 컬렉션 목록에 새로 만든 컬렉션이 나타나고, 클릭하면 빈 컬렉션 화면으로 이동합니다.
  4. 컬렉션 화면에서 문서 업로드 버튼을 누르고, 드래그 앤 드롭 또는 클릭하여 파일을 선택합니다. 지원 형식은 PDF, DOCX, PPT, PPTX, XLS, XLSX, TXT, MD, CSV, HWP, HWPX와 JPG, PNG, BMP, TIFF, HEIC 같은 이미지이며, 업로드 대화상자에는 파일당 최대 용량이 함께 표시됩니다. 예상 결과: 선택한 파일이 업로드 대기열에 추가되고 처리가 자동으로 시작됩니다.
  5. 문서 목록에서 방금 올린 문서의 처리 상태를 확인합니다. 상태는 처리 대기중, 처리중, 완료, 처리 실패 중 하나로 표시됩니다. 예상 결과: 잠시 후 상태가 완료로 바뀌면 해당 문서를 검색과 청크 보기에 사용할 수 있습니다.

결과 확인​

새 컬렉션이 목록에 나타나고, 업로드한 문서의 처리 상태가 완료로 바뀌면 시작하기 과정이 정상적으로 끝난 것입니다. 완료된 문서는 검색 화면에서 바로 검색 결과에 나타나야 합니다.

문제 해결​

  • 컬렉션 생성 실패 문구가 뜨면 컬렉션 이름이 비어 있지 않은지, 이미 같은 이름의 컬렉션이 있지 않은지 확인한 뒤 다시 시도합니다.
  • 문서 처리 상태가 계속 처리중에 머물러 있거나 처리 실패로 바뀌면, 문서 목록에서 오류 상세 보기를 눌러 원인을 확인하고 재실행 버튼으로 다시 처리를 시도합니다.
  • 업로드 화면에서 저장공간 할당량을 초과했습니다 라는 문구가 나타나면, 불필요한 파일을 정리하거나 관리자에게 저장공간 한도 증가를 요청합니다.
  • 지원하지 않는 형식의 파일을 올리면 업로드가 거부되므로, 안내된 지원 형식 목록을 다시 확인한 뒤 변환된 파일로 다시 시도합니다.
