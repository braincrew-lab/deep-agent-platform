첫 목표와 준비물​

이 과정의 목표는 회의실 이용 안내 한 편을 등록하고, 취소 시점을 설명하는 문장을 검색 결과에서 찾는 것입니다. 실제 고객 사례가 아닌 연습입니다. 문서 작성 도구에서 제목을 회의실 이용 안내로 정하고, 본문에 “예약은 이용 전날까지 신청합니다. 취소는 이용 시작 두 시간 전까지 신청합니다.”를 넣어 한 페이지 PDF로 준비하세요.

업로드 가능한 계정과 사용할 처리 파이프라인을 확인합니다. 이미 제공받은 컬렉션이 있다면 새로 만들 필요 없이 그 컬렉션을 사용해도 됩니다. 연습 자료를 넣어도 되는 곳인지 먼저 확인하세요.

1. 자료를 담을 컬렉션 선택하기​

  1. 왼쪽 컬렉션 메뉴를 엽니다. 제공받은 컬렉션이 있으면 이름을 눌러 들어갑니다.
  2. 새로 만드는 경우 새 컬렉션을 누르고 이름에 회의실 안내 연습, 설명에 예약과 취소 규칙 검색 연습을 입력합니다.
  3. 위치와 벡터 데이터베이스를 확인합니다. 벡터 데이터베이스는 문서를 검색용으로 보관하는 방식입니다. 화면에 제공되는 선택지 중 조직에서 안내한 값을 사용하세요. 사용할 수 있는 항목이 없거나 가용 여부를 확인하지 못했다는 안내가 있으면 담당자에게 확인합니다.
  4. 생성한 뒤 목록에서 해당 컬렉션을 엽니다. 문서 탭의 컬렉션 이름이 의도한 대상인지 확인합니다.

같은 이름 오류가 나타나면 기존 컬렉션을 확인하거나 연습 목적을 구분할 수 있는 이름으로 바꿉니다. 첫 실습에서는 추가 메타데이터를 입력하지 않아도 됩니다.

2. 파일과 처리 파이프라인 지정하기​

  1. 컬렉션의 문서 탭에서 문서 업로드를 누릅니다.
  2. 현재 컬렉션 이름을 확인하고 준비한 PDF를 파일 선택 영역에 끌어 놓거나 클릭해 선택합니다. 파일명과 용량이 목록에 나타나는지 봅니다.
  3. 파일 내용 확인과 기존 문서 여부 확인이 끝날 때까지 기다립니다. 같은 내용의 문서가 이미 있다는 안내가 있으면 중복 등록을 시도하기 전에 기존 문서를 확인합니다.
  4. 파이프라인 선택에서 담당자가 안내한 구성을 선택합니다. 목록을 불러오지 못했거나 사용 가능한 파이프라인이 없으면 여기서 중단하고 문제 해결을 확인합니다.
  5. 문서 업로드 버튼을 눌러 전송합니다. 파일을 선택한 것만으로 전송이 끝난 것은 아닙니다. 전송 중에는 화면 이동 안내를 주의해서 읽습니다.

3. 문서 처리 결과 확인하기​

문서 목록에서 해당 파일을 찾습니다. 처리 대기중이나 처리중이면 결과 확인을 기다리고, 처리 실패이면 실패 표시에서 오류 내용을 확인합니다. 완료로 바뀌면 청크 탭에서 연습 문서의 내용이 만들어졌는지 확인하세요. 완료 표시만 보고 원하는 문장이 보존되었다고 판단하지 않습니다.

4. 같은 컬렉션에서 검색하기​

  1. 왼쪽 실험 메뉴를 펼치고 검색을 엽니다. 사용 안내가 표시되면 읽고 동의 여부를 결정한 뒤 진행합니다.
  2. 검색 화면의 컬렉션 선택에서 방금 등록한 컬렉션을 명시적으로 고릅니다. 다른 컬렉션이 자동 선택되어 있을 수 있습니다.
  3. 검색 방식은 우선 현재 선택값을 유지하고, 검색어에 회의실 취소는 언제까지 가능한가요?를 입력한 뒤 검색 버튼을 누릅니다.
  4. 결과를 펼쳐 파일명과 본문을 읽습니다. “이용 시작 두 시간 전까지”라는 근거가 있는지 확인하고, 원본 다운로드가 제공되면 원본 문장과 대조합니다.

성공 기준은 의도한 컬렉션에서 연습 문서의 취소 규칙을 찾고 그 조건을 읽을 수 있는 것입니다. 결과 순위나 점수의 특정 값은 성공 조건이 아닙니다. 결과가 없다면 컬렉션, 문서 완료 상태, 검색어 순으로 확인하세요. 이후에는 주요 기능에서 검색 설정의 역할을 살펴보세요.
