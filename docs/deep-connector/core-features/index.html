메뉴를 업무 순서로 이해하기​

컬렉션에서 자료를 정리하고, 그 안의 문서 탭에서 처리 상태를 확인한 뒤, 실험의 검색에서 자료를 찾아봅니다. 문서명 검색은 목록에서 파일을 찾는 용도이고, 실험의 검색은 문서 내용을 찾는 용도입니다. 무엇을 찾고 있는지에 따라 진입 위치를 구분하세요.

위치언제 쓰나요?입력하거나 선택할 것확인할 결과
컬렉션 목록주제별 자료 공간을 선택하거나 생성할 때컬렉션 이름, 새로 만들 때 설명·위치·보관 방식대상 컬렉션과 그 문서 목록
컬렉션 안의 문서 탭원본 등록과 처리 상태 확인파일, 처리 파이프라인, 문서명 또는 상태 필터파일명과 대기·처리·완료·실패 상태
컬렉션 안의 청크 탭검색에 쓰이는 조각의 내용을 확인할 때대상 문서의 청크조각 내용과 원본을 식별할 정보
문서 상세내용과 현재 파일을 대조하거나 개정할 때문서 선택, 권한이 있으면 교체 파일과 변경 사유문서 내용, 원본, 버전 정보
실험 → 검색질문에 맞는 근거를 찾아볼 때컬렉션, 검색어, 검색 방식관련 청크 내용과 출처·점수
컬렉션 안의 공유다른 이용자의 접근을 관리할 때대상 이용자와 권한 수준저장한 공유 대상과 권한

업로드나 공유 설정이 보이지 않으면 현재 컬렉션의 권한을 확인하세요. 조회 가능한 컬렉션이라고 해서 등록·수정·공유 작업까지 허용되는 것은 아닙니다.

검색 방식과 결과 읽기​

검색 화면에서는 시맨틱, 키워드, 하이브리드 방식을 선택할 수 있습니다. 시맨틱 검색은 의미가 비슷한 내용을 찾는 데, 키워드 검색은 특정 용어를 중심으로 찾는 데 사용합니다. 하이브리드는 두 관점을 함께 사용하는 방식입니다. 실제 검색 결과는 문서 처리 결과와 컬렉션의 검색 구성에 영향을 받습니다. 어느 방식이 항상 더 정확하다고 가정하지 마세요.

처음에는 컬렉션과 검색어만 확정한 뒤 실행하세요. 특정 문서로 좁히려면 자유 필터를 펼치고 Key-Value 입력 방식에서 소스 로드로 실제 값을 확인합니다. Add Filter로 행을 추가해 Key에는 source, Value에는 확인한 값을 입력한 뒤 검색합니다. 소스 로드는 값을 보여줄 뿐 검색 범위를 자동으로 바꾸지 않습니다.

메타데이터 필터는 자유 필터와 별도로 선택한 조건입니다. 조건을 해제해 비교할 때에는 자유 필터의 행을 휴지통 버튼으로 지우고 메타데이터 필터에서도 선택한 필드를 제거해야 합니다. 두 영역의 조건이 함께 적용되므로 한쪽만 비워서는 제한 없는 검색으로 돌아오지 않을 수 있습니다. 구체적인 추가·검색·제거 순서는 반복 업무의 특정 문서로 검색 범위 좁히기를 따르세요.

결과 카드에서는 문서명과 본문을 먼저 읽고, 제공되는 페이지 정보와 메타데이터를 보조적으로 확인합니다. 점수는 검색 결과를 비교하는 정보이며 문장이 사실이라는 보증은 아닙니다. 예약 가능 시간과 취소 가능 시간이 서로 다르다면 질문에 맞는 문장을 선택해야 합니다.

검색에 실제 적용된 조건 확인하기​

검색 응답의 effective 정보가 제공되는 환경에서는 요청한 조건과 실제로 적용된 조건을 함께 확인할 수 있습니다. 검색 방식이 바뀌었는지, 리랭크가 적용되었는지, 검증이나 분석 과정에서 추가 안내가 남았는지를 이 정보로 구분합니다.

리랭크를 적용한 검색은 후보를 더 넓게 조회한 뒤 최종 결과를 다시 정렬할 수 있습니다. 리랭크가 적용되지 않은 경우에는 effective.rerank.applied가 거짓으로 표시됩니다. 처리 중 오류가 발생하면 첫 검색 결과의 순서를 유지하고 안내 노트를 남길 수 있으므로, 결과가 표시되었다는 사실만으로 리랭크가 완료되었다고 판단하지 마세요.

하이브리드 검색에서는 실제 적용된 방식과 전략에 따라 fusion의 세부 값 일부만 표시될 수 있습니다. 요청 화면의 입력값과 결과의 effective를 비교하면 서버 기본값 적용이나 검색 방식 변경 여부를 확인할 수 있습니다.

문서와 청크를 따로 확인하는 이유​

문서 탭은 파일이 처리되었는지 확인하는 출발점입니다. 청크 탭에서는 문서의 일부가 어떻게 나뉘었는지 확인합니다. 검색 결과가 짧거나 필요한 조건을 빠뜨렸다면 원본 문서와 청크를 비교해 내용 자체가 누락되었는지, 검색이 다른 조각을 찾았는지 구분하세요.

개정본은 문서 상세의 새 버전 업로드로 교체할 수 있습니다. 교체하면 다시 처리되며, 직접 수정한 구성 단위의 내용은 새 처리 결과로 바뀔 수 있습니다. 실제 교체 전 확인사항과 재검색 순서는 반복 업무에 있습니다.

공유 설정을 확인할 때​

공유 화면에서는 대상 이용자를 선택하고 권한을 지정한 뒤 변경사항을 저장합니다. 조회 목적의 사람에게 편집 권한까지 필요한지 먼저 판단하세요. 저장 후 대상과 권한이 맞는지 다시 읽고, 실제 이용자가 해당 컬렉션을 열 수 있는지도 별도로 확인합니다. 저장 성공 알림만으로 상대방의 사용 가능 여부를 확인한 것으로 간주하지 않습니다.

실제 자료로 연습하려면 활용 사례, 메뉴가 보이지 않거나 작업이 막히면 문제 해결을 참고하세요.
