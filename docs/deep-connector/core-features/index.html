Deep Connector 메뉴 안내

이 페이지는 Deep Connector 화면의 공통 메뉴를 한눈에 정리합니다. 왼쪽 사이드바, 위쪽 막대, 전역 검색, 개인 설정을 차례로 설명하고, 각 메뉴의 자세한 사용법이 있는 페이지로 안내합니다.

이 페이지에서 할 수 있는 일

  • 사이드바의 메뉴가 각각 무엇을 하는지 익힙니다.
  • 저장공간과 월간 업로드 사용량을 읽습니다.
  • 전역 검색으로 컬렉션과 문서를 이름으로 찾아 이동합니다.
  • 화면 언어와 테마를 바꿉니다.

화면 구성​

사이드바 위쪽 메뉴

번호메뉴기능이런 때 사용하세요
1사이드바 접기왼쪽 사이드바를 접거나 펼칩니다.노트북 화면에서 문서 미리보기를 넓게 볼 때
2워크스페이스팀이 함께 소유하는 공간과 멤버를 관리합니다.팀 컬렉션의 소유와 승인 책임을 정할 때
3컬렉션폴더와 컬렉션 목록 화면입니다. 로그인하면 이 화면이 먼저 열립니다.문서를 올리거나 컬렉션을 열 때
4실험누르면 검색, RAG 진단, RAG 평가, MCP 도구 테스트가 펼쳐집니다.문서가 질문에 맞게 검색되는지 점검할 때

사이드바 아래쪽 메뉴

번호메뉴기능이런 때 사용하세요
1접근 요청내가 보낸 접근 요청과 처리 결과를 봅니다.제한 컬렉션의 열람을 요청하고 결과를 기다릴 때
2MCP 토큰외부 프로그램이 Deep Connector를 검색할 때 쓰는 토큰을 관리합니다.다른 AI 도구에 컬렉션을 연결할 때
3사용량내가 쓴 저장공간과 이번 달 업로드 건수, 팀스페이스 사용량입니다. 막대가 차면 업로드가 막힙니다.큰 파일을 여러 건 올리기 전에 남은 양을 볼 때
4내 계정누르면 설정과 로그아웃 메뉴가 열립니다.언어를 바꾸거나 로그아웃할 때

위쪽 막대

번호메뉴기능이런 때 사용하세요
1검색...메뉴, 컬렉션, 문서를 이름으로 찾는 전역 검색 창을 엽니다. ⌘K(Windows는 Ctrl+K)로도 열립니다.이름 일부만 기억나는 문서를 열 때
2테마 전환밝은 화면과 어두운 화면을 바꿉니다.오래 문서를 검토해 눈이 피로할 때

관리자 계정에는 사이드바 아래쪽에 관리자 묶음(대시보드, 적재 현황, 사용자와 팀스페이스, 검색과 AI, 시스템)이 더 보이고, 컬렉션 목록에 숨김 컬렉션을 보는 버튼이 생깁니다. 관리자에게는 접근 요청 메뉴가 보이지 않습니다. 자세한 내용은 관리자 메뉴에 있습니다.

메뉴별 안내 페이지​

사이드바 메뉴와 각 화면의 탭을 이 매뉴얼의 페이지에 대응시킨 지도입니다. 매뉴얼 왼쪽 목차도 같은 순서입니다.

사이드바 묶음메뉴화면과 탭자세한 설명
메뉴워크스페이스워크스페이스 목록, 워크스페이스 화면의 컬렉션·멤버·설정 탭워크스페이스
메뉴컬렉션폴더 트리와 컬렉션 목록, 새 컬렉션, 컬렉션의 설정 탭컬렉션과 폴더
메뉴컬렉션컬렉션의 문서 탭과 문서 업로드 화면문서 올리기
메뉴컬렉션문서 미리보기, 청크 탭, 문서 상세와 변경 이력문서와 청크 확인
메뉴실험 > 검색실험 공간 안내, 검색 방식, 고급 옵션, 필터, AI 답변, 최근 검색실험: 검색
메뉴실험 > RAG 진단질의 재작성·검색·답변 단계별 결과실험: RAG 진단
메뉴실험 > RAG 평가평가 데이터셋, 실행, 실행 이력과 채점실험: RAG 평가
메뉴실험 > MCP 도구 테스트도구 17개 실행과 결과실험: MCP 도구 테스트
권한컬렉션의 공유/권한 탭, 접근 요청접근 수준, 공유 멤버, 워크스페이스 공유, 내 접근 요청권한·공유·접근 요청
권한MCP 토큰설정의 MCP 토큰 탭, 새 토큰 생성, 외부 문서 API 확인MCP 토큰과 외부 연동
내 계정설정, 로그아웃설정의 일반 탭(언어, 테마)이 페이지의 개인 설정
관리자대시보드, 적재 현황사용량 요약, 적재 현황의 문서·배치·설정 탭, AI 대시보드관리자: 대시보드와 적재 현황
관리자사용자와 팀스페이스사용자, 팀스페이스관리자: 사용자와 팀스페이스
관리자검색과 AI용어 사전(전사 용어사전), 메타데이터 관리, 컬렉션 태그, LLM 커넥션, MCP 도구, 도구 평가관리자: 검색과 AI
관리자시스템저장공간, 감사 로그, 브랜드 설정, 시스템 설정관리자: 시스템

Deep Agent Builder 에이전트에 컬렉션을 연결하는 방법은 에이전트에서 지식 쓰기에 있습니다.

전역 검색​

위쪽 **검색...**을 누르거나 ⌘K를 누르면 전역 검색 창이 열립니다. 메뉴, 컬렉션, 문서 이름으로 찾아 바로 이동합니다.

전역 검색 창

번호메뉴기능이런 때 사용하세요
1검색어 입력란찾을 이름 일부를 적습니다."출장"처럼 파일 이름의 일부만 기억날 때
2결과 목록이름이 맞는 메뉴, 컬렉션, 문서가 묶음별로 나옵니다. 문서 오른쪽에는 들어 있는 컬렉션 이름이 보입니다.같은 이름의 문서가 여러 컬렉션에 있을 때 구별할 때
3시맨틱 검색맨 아래 항목을 누르면 같은 검색어로 실험 > 검색이 열립니다.이름이 아니라 내용으로 찾고 싶을 때

전역 검색은 이름을 찾는 기능입니다. 문서 속 문장을 찾을 때는 실험 > 검색을 쓰세요.

이럴 때 쓰세요: 회의 중 "출장비 규정 파일 좀 띄워 줘"라는 요청을 받은 김그루 사원은 ⌘K를 누르고 "출장"을 적어 문서를 바로 엽니다. 어느 컬렉션에 있는지 몰라도 됩니다.

개인 설정​

사이드바 아래 내 계정을 누르고 설정을 고르면 설정 화면이 열립니다.

설정 화면

번호메뉴기능이런 때 사용하세요
1일반언어와 테마를 고르는 탭입니다.화면 표시를 바꿀 때
2MCP 토큰사이드바의 MCP 토큰과 같은 화면입니다.외부 도구 연결용 토큰을 관리할 때
3언어한국어와 영어 중에서 고릅니다.화면이 다른 언어로 보일 때
4테마라이트와 다크 중에서 고릅니다.화면 밝기를 고정할 때

위쪽 막대의 테마 전환 버튼으로도 밝은 화면과 어두운 화면을 바로 바꿀 수 있습니다.

설정뜻기본값
언어화면 언어한국어
테마밝은 화면(라이트) 또는 어두운 화면(다크)라이트

이럴 때 쓰세요: 해외 법인 동료에게 화면을 보여 주며 설명해야 할 때 김그루 사원은 언어를 잠시 영어로 바꾸고, 설명이 끝나면 다시 한국어로 돌립니다.
