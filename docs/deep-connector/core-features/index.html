Deep Connector 메뉴 안내

이 페이지는 Deep Connector 화면의 공통 메뉴를 한눈에 정리합니다. 왼쪽 사이드바, 위쪽 막대, 전역 검색, 개인 설정을 차례로 설명하고, 각 메뉴의 자세한 사용법이 있는 페이지로 안내합니다.

이 페이지에서 할 수 있는 일

  • 사이드바의 메뉴가 각각 무엇을 하는지 익힙니다.
  • 저장공간과 월간 업로드 사용량을 읽습니다.
  • 전역 검색으로 컬렉션과 문서를 이름으로 찾아 이동합니다.
  • 화면 언어와 테마를 바꿉니다.

화면 구성​

Deep Connector 화면 구성

번호메뉴기능이런 때 사용하세요
1사이드바 접기왼쪽 사이드바를 접거나 펼칩니다.노트북 화면에서 문서 미리보기를 넓게 볼 때
2워크스페이스팀이 함께 소유하는 공간과 멤버를 관리합니다.팀 컬렉션의 소유와 승인 책임을 정할 때
3컬렉션폴더와 컬렉션 목록 화면입니다. 로그인하면 이 화면이 먼저 열립니다.문서를 올리거나 컬렉션을 열 때
4실험누르면 검색, RAG 진단, RAG 평가, MCP 도구 테스트가 펼쳐집니다.문서가 질문에 맞게 검색되는지 점검할 때
5접근 요청내가 보낸 접근 요청과 처리 결과를 봅니다.제한 컬렉션의 열람을 요청하고 결과를 기다릴 때
6MCP 토큰외부 프로그램이 Deep Connector를 검색할 때 쓰는 토큰을 관리합니다.다른 AI 도구에 컬렉션을 연결할 때
7사용량내가 쓴 저장공간과 이번 달 업로드 건수, 팀스페이스 사용량입니다. 막대가 차면 업로드가 막힙니다.큰 파일을 여러 건 올리기 전에 남은 양을 볼 때
8검색...메뉴, 컬렉션, 문서를 이름으로 찾는 전역 검색 창을 엽니다. ⌘K(Windows는 Ctrl+K)로도 열립니다.이름 일부만 기억나는 문서를 열 때
9테마 전환밝은 화면과 어두운 화면을 바꿉니다.오래 문서를 검토해 눈이 피로할 때
10내 계정누르면 설정과 로그아웃 메뉴가 열립니다.언어를 바꾸거나 로그아웃할 때

관리자 계정에는 사이드바 아래쪽에 관리자 묶음(대시보드, 적재 현황, 사용자와 팀스페이스, 검색과 AI, 시스템)이 더 보입니다. 관리자는 접근 요청 메뉴 대신 관리자 메뉴에서 요청을 처리합니다. 자세한 내용은 관리자 메뉴에 있습니다.

메뉴별 안내 페이지​

메뉴하는 일자세한 설명
컬렉션 목록과 폴더컬렉션을 만들고 폴더로 정리합니다.컬렉션과 폴더
컬렉션의 문서 탭문서를 올리고 처리 상태를 봅니다.문서 올리기, 문서와 청크 확인
컬렉션의 청크 탭과 문서 상세문서가 어떻게 나뉘었는지 원본과 대조합니다.문서와 청크 확인
컬렉션의 설정 탭기본 파이프라인, 검색 분석기, 사전, LLM 검색 보강을 정합니다.컬렉션과 폴더
컬렉션의 공유/권한 탭, 워크스페이스, 접근 요청누가 무엇을 할 수 있는지 정합니다.권한·공유·접근 요청
실험 > 검색, RAG 진단, RAG 평가검색 품질과 답변 근거를 점검합니다.검색과 RAG 점검
실험 > MCP 도구 테스트, MCP 토큰외부 도구와 에이전트가 쓰는 검색 도구를 시험하고 연결합니다.외부 연동

전역 검색​

위쪽 **검색...**을 누르거나 ⌘K를 누르면 전역 검색 창이 열립니다. 메뉴, 컬렉션, 문서 이름으로 찾아 바로 이동합니다.

전역 검색 창

번호메뉴기능이런 때 사용하세요
1검색어 입력란찾을 이름 일부를 적습니다."출장"처럼 파일 이름의 일부만 기억날 때
2결과 목록이름이 맞는 메뉴, 컬렉션, 문서가 묶음별로 나옵니다. 문서 오른쪽에는 들어 있는 컬렉션 이름이 보입니다.같은 이름의 문서가 여러 컬렉션에 있을 때 구별할 때
3시맨틱 검색맨 아래 항목을 누르면 같은 검색어로 실험 > 검색이 열립니다.이름이 아니라 내용으로 찾고 싶을 때

전역 검색은 이름을 찾는 기능입니다. 문서 속 문장을 찾을 때는 실험 > 검색을 쓰세요.

개인 설정​

사이드바 아래 내 계정을 누르고 설정을 고르면 설정 화면이 열립니다.

설정 화면

번호메뉴기능이런 때 사용하세요
1일반언어와 테마를 고르는 탭입니다.화면 표시를 바꿀 때
2MCP 토큰사이드바의 MCP 토큰과 같은 화면입니다.외부 도구 연결용 토큰을 관리할 때
3언어한국어와 영어 중에서 고릅니다.화면이 다른 언어로 보일 때
4테마라이트와 다크 중에서 고릅니다.화면 밝기를 고정할 때
5테마 전환위쪽 버튼으로도 바로 바꿀 수 있습니다.잠깐 어두운 화면으로 볼 때
