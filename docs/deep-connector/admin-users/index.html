Deep Connector 관리자: 사용자와 팀스페이스

관리자 사이드바 사용자와 팀스페이스 묶음은 누가 얼마나 올리고 저장할 수 있는지 정하는 화면입니다. 사용자와 팀스페이스 두 메뉴가 있고, 사용하는 인증 방식에 따라 컬렉션 권한 메뉴가 더 보일 수 있습니다. 이 페이지는 AI혁신팀 강혁신 팀장(Deep Connector 관리자)이 사용자와 부서의 한도를 조정하는 순서를 설명합니다.

이 페이지에서 할 수 있는 일

  • 사용자별 저장공간과 월간 업로드 사용량을 확인하고 한도를 바꿉니다.
  • 여러 사용자의 한도를 한꺼번에 바꿉니다.
  • 팀스페이스(부서) 단위 한도와 구성원을 확인합니다.

메뉴 구성​

사용자와 팀스페이스 묶음

번호메뉴기능이런 때 사용하세요
1사용자사용자별 사용량과 할당량을 봅니다.한 사람의 업로드 한도를 바꿀 때
2팀스페이스팀스페이스(부서)별 사용량과 할당량을 봅니다.부서 전체 한도를 바꿀 때

컬렉션 권한(컬렉션별 접근 권한과 접근 요청 승인을 한 화면에서 처리)은 회사 계정 연동 방식이 지원할 때만 이 묶음에 나타납니다. 이 매뉴얼의 시연 환경에서는 보이지 않습니다.

사용자​

사용자와 팀스페이스 > 사용자에서 사용자별 사용량을 보고 한도를 바꿉니다.

사용자 목록

번호메뉴기능이런 때 사용하세요
1일괄 할당량 설정여러 사용자의 한도를 한꺼번에 바꿉니다.부서 전체의 월간 업로드 한도를 올릴 때
2이메일로 검색사용자를 찾습니다.문의한 사용자를 찾을 때
3저장공간쓴 용량과 한도입니다.용량이 찬 사용자를 찾을 때
4월간 업로드이번 달 업로드 건수와 한도입니다.업로드가 막힌 사용자를 찾을 때

행 오른쪽 상세를 누르면 그 사용자의 상세 화면과 할당량 설정이 열립니다. 한 사람의 한도를 바꿀 때 씁니다.

사용자 상세와 할당량 설정

번호메뉴기능이런 때 사용하세요
1기본 정보이메일, 이름, 마지막 로그인, 상태입니다.계정이 활성인지 볼 때
2저장공간 할당량이 사용자가 쓸 수 있는 저장 용량입니다.큰 파일을 많이 올리는 담당자의 한도를 늘릴 때
3업로드 크기 제한파일 하나의 최대 크기입니다.대용량 스캔본을 올려야 할 때
4현재 사용량저장공간과 월간 업로드 사용량, 아래에 사용 이력이 이어집니다.한도를 얼마나 늘릴지 정할 때

할당량 설정

번호메뉴기능이런 때 사용하세요
1월간 업로드 제한한 달에 올릴 수 있는 파일 수입니다. 제한 없음을 체크하면 한도를 없앱니다.도입 초기에 문서를 대량으로 올릴 때
2동시 업로드 제한한 번에 처리할 수 있는 업로드 수입니다.처리 대기가 길어질 때
3저장바꾼 한도를 저장합니다.변경을 마쳤을 때
할당량 항목뜻이 시연 환경의 기본값
저장공간 할당량사용자가 올린 원본 파일의 합계 용량 상한1 GB
월간 업로드 제한한 달 동안 올릴 수 있는 파일 수30건
업로드 크기 제한파일 하나의 최대 크기배포 설정의 파일 최대 크기를 따름
동시 업로드 제한한 사용자가 동시에 처리할 수 있는 업로드 수배포 설정을 따름

이럴 때 쓰세요: 이 매뉴얼을 만들 때 김그루 사원이 사례 자료를 한꺼번에 올리다 월간 업로드 30건 한도에 닿았습니다. 강혁신 팀장은 사용자 상세에서 월간 업로드 제한을 200건으로 올리고 저장을 눌러 바로 풀었습니다.

팀스페이스​

사용자와 팀스페이스 > 팀스페이스는 회사 계정의 팀(부서) 단위로 저장공간과 월간 업로드 한도를 관리합니다. 사용자 한도와 팀스페이스 한도 중 하나라도 닿으면 업로드가 막힙니다.

팀스페이스 목록

번호메뉴기능이런 때 사용하세요
1일괄 할당량 설정여러 팀스페이스의 한도를 한꺼번에 바꿉니다.전 부서 한도를 같은 값으로 맞출 때
2검색팀스페이스 이름으로 좁힙니다.부서가 많을 때
3팀스페이스 행이름과 저장공간 사용량·한도입니다.용량을 많이 쓰는 부서를 찾을 때
4상세팀스페이스 상세 화면을 엽니다.한 부서의 한도를 바꾸거나 구성원을 볼 때

팀스페이스 상세

번호메뉴기능이런 때 사용하세요
1저장공간 할당량이 팀스페이스가 함께 쓰는 저장 용량 상한입니다. 단위를 고르고 숫자를 적습니다.부서 자료가 늘어 용량을 늘릴 때
2월간 업로드 제한이 팀스페이스 구성원이 한 달 동안 함께 올릴 수 있는 파일 수입니다. 제한 없음을 체크하면 한도를 없앱니다.부서 전체 업로드가 막혔을 때
3저장바꾼 한도를 저장합니다.변경을 마쳤을 때
4멤버이 팀스페이스에 속한 사용자와 각자의 저장공간·월간 업로드 사용량입니다. 위쪽에 남은 용량이 함께 보입니다.누가 용량을 많이 쓰는지 볼 때

이럴 때 쓰세요: AI혁신팀이 새 프로젝트 자료 300건을 이번 달에 올리기로 했다면, 김그루 사원 개인 한도만 올려서는 부족합니다. 강혁신 팀장은 AI혁신팀 팀스페이스 상세에서 월간 업로드 제한을 300건으로 올립니다.
