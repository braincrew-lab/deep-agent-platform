Deep Connector 실습 6: Builder 에이전트에 연결해 쓰기

마지막 실습은 실습 5에서 만든 토큰으로 Deep Agent Builder에 "AI혁신팀 업무 자료" 도구를 등록하고, 김그루 사원의 "주간 업무 보고서 도우미" 에이전트에 붙여 팀 자료를 근거로 보고서 일부를 쓰게 합니다. 에이전트가 Deep Connector를 어떻게 검색했는지 실행 기록으로 확인하는 것까지가 목표입니다. 연결 흐름 전체는 에이전트에서 지식 쓰기, Builder 쪽 도구 등록 화면의 모든 항목은 Deep Agent Builder 매뉴얼의 도구 등록에 있습니다.

이 페이지에서 할 수 있는 일

  • Deep Agent Builder에 Connect MCP Server 도구를 등록하고 연결 테스트를 합니다.
  • 에이전트 도구함에 도구를 넣고, 지침에 언제 이 도구를 쓸지 적습니다.
  • 에이전트에게 묻고, 실행 기록에서 Deep Connector 검색이 일어났는지와 근거 문서를 확인합니다.

목표​

항목내용
만들 것Builder 도구 "AI혁신팀 업무 자료"(Connect MCP Server), 이 도구를 쓰는 "주간 업무 보고서 도우미"
결과물회의록 결정 사항을 근거 문서 이름과 함께 정리한 "다음 주 계획" 초안
걸리는 시간15분
난이도★★★★☆

준비물​

준비물내용
토큰 값실습 5에서 옮겨 둔 토큰 값
에이전트Deep Agent Builder에 있는 내 에이전트 하나. 이 매뉴얼은 "주간 업무 보고서 도우미"(한 주 업무 메모로 팀장 보고용 주간 보고서 초안을 쓰는 에이전트)를 썼습니다.
권한Builder에서 도구를 만들 수 있는 계정

1단계. Builder에 도구 등록하기​

Deep Agent Builder 사이드바 에셋설정을 누르고 도구 탭의 도구 추가에서 Connect MCP Server를 고릅니다.

Connect MCP Server 등록

번호메뉴입력하거나 고를 값
1도구 이름ai_team_docs(영문 소문자로 시작, 소문자·숫자·밑줄만. 만든 뒤 바꿀 수 없습니다)
2설명AI혁신팀의 주간 회의록, 분기 보고서 초안, 추진 현황, 판매 데이터, 계약서, 시장 조사 메모를 검색해 근거 문서와 함께 돌려줍니다.
3Token실습 5의 토큰 값. 앞에 인증 방식 이름을 붙이지 않고 값만 넣습니다.
4연결 결과연결 테스트를 누르면 "연결 성공(292ms)"처럼 나옵니다.
5생성연결 성공을 확인했으면 누릅니다.
설정 항목이 실습의 값기본값
표시 이름AI혁신팀 업무 자료비우면 도구 이름
URL미리 채워진 값 그대로회사가 정해 둔 Deep Connector MCP 주소
Token실습 5의 토큰없음(필수)
  1. 도구 이름, 표시 이름, 설명을 위 표대로 적습니다. 설명은 에이전트가 이 도구를 언제 쓸지 판단하는 근거이므로 어떤 자료가 들어 있는지 구체적으로 적습니다.
  2. URL은 미리 채워진 값을 그대로 둡니다. Builder는 회사 내부 주소로 Deep Connector에 붙으므로, Deep Connector 토큰 창의 요청 URL과 달라도 괜찮습니다.
  3. Token에 토큰 값을 붙여 넣습니다.
  4. 연결 테스트를 눌러 "연결 성공"을 확인하고 생성을 누릅니다. "도구가 생성되었습니다"가 나옵니다.

2단계. 에이전트 도구함에 넣기​

사이드바에서 "주간 업무 보고서 도우미"를 열고, 대화 화면 사이드바의 에이전트 설정을 누릅니다. 편집 화면 도구함 오른쪽 도구(+)를 누르면 "도구 추가" 창이 열립니다.

도구 추가 창

번호메뉴입력하거나 고를 값
1AI혁신팀 업무 자료1단계에서 만든 도구(MCP)입니다. 누르면 오른쪽에 설명이 나옵니다.
2도구 추가누르면 창이 닫히고 도구함에 들어갑니다.
  1. 도구함 오른쪽 도구(+)를 누릅니다.
  2. 목록에서 "AI혁신팀 업무 자료"를 누르고 오른쪽 설명을 확인합니다.
  3. 도구 추가를 누릅니다. 도구함에 "AI혁신팀 업무 자료"가 보이면 됩니다.

3단계. 지침에 도구 쓰는 때를 적고 저장하기​

도구만 넣으면 에이전트가 언제 검색해야 할지 모를 수 있습니다. 지침 끝에 한 문장을 더합니다.

지침과 도구함

번호메뉴입력하거나 고를 값
1지침기존 지침 끝에 "지난 회의의 결정 사항, 보고서 수치, 계약 조건처럼 팀 자료에 있는 내용은 AI혁신팀 업무 자료 도구로 먼저 검색하고, 쓴 내용 뒤에 근거 문서 이름을 괄호로 적습니다."를 더합니다.
2도구함"AI혁신팀 업무 자료"가 들어 있는지 봅니다. 톱니바퀴로 도구 설정을, 휴지통으로 연결 해제를 합니다.
3저장누르면 "저장되었습니다"가 나옵니다.

4단계. 묻고 실행 기록 확인하기​

편집 화면을 닫고 대화 화면에서 이 에이전트와 새 대화를 연 뒤 아래 질문을 보냅니다.

프롬프트: 11월 10일 주간 회의에서 정한 결정 사항과 액션 아이템을 팀 자료에서 찾아서, 이번 주 주간 업무 보고의 '다음 주 계획' 부분 초안을 써 줘.

에이전트 답변과 실행 기록

번호메뉴확인할 것
1ai_team_docs__glob_paths에이전트가 먼저 검색할 컬렉션 경로를 찾았습니다(0.3초). 이름 앞부분은 1단계의 도구 이름입니다.
2ai_team_docs__search_documents컬렉션에서 질문으로 검색했습니다(22.2초). 누르면 출력에 찾은 청크가 보입니다.
3답변"다음 주 계획 (회의록_AI업무혁신_20261110.html):"으로 시작해 결정 사항과 액션 아이템을 정리하고, 메모에 없는 일정은 "[확인 필요: …]"로 남겼습니다.

이 실습에서 받은 답변입니다.

다음 주 계획 (회의록_AI업무혁신_20261110.html): 판매 리포트 에이전트에 지역별 목표 대비 실적 표 추가 예정. 설문 분석 에이전트 마케팅팀과 공동 기획, 커뮤니티 공유 예정. 복리후생 규정 최신본 지식 컬렉션 '사내 규정'에 반영 예정. 부서별 LLM 토큰 한도 기준안 작성 및 관리자 리포트 관리 기능 검토. [확인 필요: 각 항목별 담당자 진행상황, 일정 세부 조정] (근거: 회의록_AI업무혁신_20261110.html)

결과​

  • 실습 1에서 올린 회의록이 실습 5의 토큰과 1단계의 도구를 거쳐 Builder 에이전트의 답변 근거가 되었습니다.
  • 실행 기록에서 Deep Connector 검색이 일어났는지, 어떤 문서를 근거로 삼았는지 확인할 수 있습니다.

흔한 실수​

증상원인해결
"Token must be at least 51 characters"토큰 일부만 붙여 넣었습니다.생성 완료 창에서 복사한 값을 그대로 붙여 넣습니다. 창을 이미 닫았다면 토큰을 새로 만듭니다.
연결 테스트 실패URL을 바꿨거나 토큰이 만료·삭제됐습니다.URL을 미리 채워진 값으로 되돌리고, Deep Connector 토큰 목록에서 상태를 봅니다.
답변에 실행 기록이 없음도구함에 넣고 저장하지 않았거나, 지침에 검색하라는 말이 없습니다.3단계를 다시 하고 새 대화에서 묻습니다.
"접근 권한이 없다"는 취지로 답함토큰의 접근 컬렉션에 그 컬렉션이 없습니다.Deep Connector MCP 토큰에서 접근 컬렉션 수정으로 컬렉션을 더합니다.
엉뚱한 문서를 근거로 듦비슷한 내용이 여러 문서에 있습니다.Deep Connector MCP 도구 테스트에서 같은 질문으로 search_documents를 실행해 순위를 보고, 겹치는 문서를 정리합니다.

응용 과제​

  1. "크루 커넥트 계약의 월 이용료와 지연 이자 조건을 표로 정리해 줘"를 물어 계약서 PDF가 근거로 나오는지 봅니다.
  2. Deep Connector에서 회의록 .html을 새 버전으로 교체한 뒤 같은 질문을 다시 해, 에이전트 답변이 새 내용으로 바뀌는지 확인합니다(반복 업무).
  3. 실습 4의 데이터셋 질문 6개를 이 에이전트에게 물어, RAG 평가의 답과 에이전트의 답이 어떻게 다른지 비교합니다.
