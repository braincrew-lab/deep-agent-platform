Deep Connector 검색과 RAG 점검

사이드바 실험 메뉴는 문서가 질문에 맞게 검색되는지, 에이전트가 어떤 근거로 답할지를 미리 확인하는 화면입니다. 이 페이지는 검색, RAG 진단, RAG 평가를 설명합니다. MCP 도구 테스트는 외부 연동에 있습니다.

이 페이지에서 할 수 있는 일

  • 네 가지 검색 방식의 차이를 알고 질문에 맞게 고릅니다.
  • 고급 옵션으로 리랭커와 하이브리드 전략을 바꿔 결과를 비교합니다.
  • RAG 진단으로 질문 재작성, 검색, 답변 생성까지 단계별로 확인합니다.
  • RAG 평가로 자주 묻는 질문 묶음을 한꺼번에 점검합니다.

실험 공간 안내​

실험 메뉴를 처음 열면 안내 화면이 나옵니다. 세 항목을 하나씩 확인해야 들어갈 수 있습니다.

실험 공간 안내

번호메뉴기능이런 때 사용하세요
1확인 항목세 항목을 차례로 눌러 확인합니다. 내용은 아래 표와 같습니다.실험 공간을 처음 열 때
2확인하고 시작하기세 항목을 모두 확인하면 누를 수 있습니다.내용을 읽고 동의했을 때
확인 항목내용이런 때 확인하세요
확인 항목 1이 공간은 문서 검색 서비스가 아니라 검색기 성능을 실험하고 평가하는 도구라는 내용입니다.일상 업무 질문은 에이전트에게 한다는 점을 확인할 때
확인 항목 2진단과 평가를 실행하면 데이터셋 항목 수만큼 검색과 LLM 호출이 생긴다는 내용입니다.질문이 많은 평가를 돌리기 전에 호출량을 가늠할 때
확인 항목 3내가 만든 평가 데이터셋과 실행 결과는 검색된 문서 원문을 포함해 모든 사용자에게 공개된다는 내용입니다.평가 질문에 개인정보를 넣지 않도록 확인할 때

검색​

실험 > 검색은 컬렉션을 골라 질문이나 낱말로 청크를 찾는 화면입니다. 화면 구성은 시작하기의 첫 검색에서 번호와 함께 설명했습니다.

검색 방식 고르기​

검색 방식

번호메뉴기능이런 때 사용하세요
1검색 방식 목록검색 방식을 누르면 열리는 네 가지 방식입니다. 아래 표에서 고릅니다.질문 성격에 맞는 방식을 고를 때
검색 방식이렇게 찾습니다이런 때 고르세요
시맨틱 검색뜻이 비슷한 문장을 찾습니다. 실제 적용된 설정에는 "벡터 검색"으로 표시됩니다."서울 출장 가면 숙박비 얼마 나와요?"처럼 문장으로 물을 때
키워드 검색검색어 낱말이 들어간 청크를 찾습니다. 한국어 분석기로 낱말을 나눕니다. 실제 적용된 설정에는 "BM25 키워드"로 표시됩니다."숙박비 상한"처럼 문서에 쓰인 용어로 찾을 때
하이브리드 검색두 방식을 함께 써서 순위를 합칩니다.어느 쪽이 나을지 모를 때
문자열 검색입력한 문구를 문서 본문에서 대소문자 구분 없이 그대로 찾습니다."E103"처럼 정확한 코드나 숫자가 들어 있는지 볼 때

키워드 검색 결과

번호메뉴기능이런 때 사용하세요
1검색 방식키워드 검색을 고른 상태입니다.–
2검색어"숙박비 상한"처럼 문서에 쓰인 낱말을 적습니다.규정 용어를 알고 있을 때
3실제 적용된 설정분석기(KIWI), 검색 방식(BM25 키워드), 리랭커 사용 여부, 사전 적용 여부가 보입니다.고른 방식대로 검색됐는지 확인할 때
4결과 카드숙박비 조항 청크가 첫 결과로 나왔습니다.근거 문장을 읽을 때

같은 질문도 방식에 따라 순위가 달라집니다. 점수가 높다고 정답은 아니므로 결과 카드를 펼쳐 본문까지 읽으세요. 키워드 검색에서 "법카"처럼 줄임말로 찾아야 한다면 컬렉션에 용어 사전을 연결하고 사전 확장을 켭니다. 사전 확장은 시맨틱 검색에는 적용되지 않습니다.

고급 옵션​

검색 화면 왼쪽 아래 고급 옵션을 누르면 이번 검색에만 쓸 세부 설정이 열립니다. 컬렉션 설정은 바뀌지 않습니다.

고급 옵션

번호메뉴기능이런 때 사용하세요
1분석기이 컬렉션에 설정된 분석기입니다. 여기서는 바꿀 수 없습니다.키워드 검색이 어떤 분석기로 되는지 볼 때
2하이브리드 전략하이브리드 검색에서 두 결과를 합치는 방식(RRF, SRRF, DBSF, Weighted)입니다. Weighted를 고르면 시맨틱 가중치를 정합니다.하이브리드 결과 순위가 어색할 때
3RRF KRRF 전략에서 순위를 합칠 때 쓰는 값입니다. 고른 전략에 따라 SRRF β나 시맨틱 가중치로 바뀝니다.하이브리드 결과를 미세하게 조정할 때
4리랭커후보를 넓게 찾은 뒤 질문과의 관련도로 다시 순위를 매깁니다. 사용으로 바꾸면 리랭크 후보 수와 최종 결과 수를 정합니다.관련 없는 청크가 위에 올라올 때

창 맨 위 안내대로 이 설정은 이번 검색에만 적용되며 컬렉션 설정을 변경하지 않습니다.

필터로 범위 좁히기​

  • 메타데이터 필터: 필드 추가로 문서 메타데이터 항목을 고르고 값을 정합니다. 컬렉션에 추출된 메타데이터가 없으면 "이 컬렉션에는 추출된 메타데이터 스키마가 없습니다."가 나옵니다.
  • 자유 필터: Key-Value나 JSON으로 조건을 직접 적습니다. 소스 로드를 누르면 컬렉션의 실제 문서 이름(source) 값이 나옵니다. 예를 들어 Key에 source, Value에 "출장비-지급-규정.pdf"를 적으면 그 파일 안에서만 찾습니다.

두 필터의 조건은 함께 적용됩니다. 비교 검색을 하기 전에 남은 조건이 없는지 확인하세요.

RAG 진단​

실험 > RAG 진단은 질문 하나로 질문 재작성, 검색, 답변에 쓸 청크 고르기, 답변 생성까지 단계별로 보여 주는 화면입니다. 에이전트가 이 컬렉션으로 어떻게 답할지 미리 볼 수 있습니다. 답변 생성은 컬렉션 설정에 LLM 커넥션이 연결되어 있어야 동작합니다(컬렉션과 폴더 참고).

RAG 진단 화면

번호메뉴기능이런 때 사용하세요
1컬렉션진단할 컬렉션을 고릅니다. 고르면 그 컬렉션의 검색 설정이 아래 검색 파라미터에 채워집니다.점검할 컬렉션을 정할 때
2질의질문을 적습니다.직원이 자주 묻는 질문을 넣어 볼 때
3max_context_chunks답변에 넘길 청크 수입니다.근거를 더 넓게 줄 때
4질의 재작성·답변 생성왼쪽은 검색 전에 질문을 검색하기 좋은 문장으로 바꾸고, 오른쪽은 검색 결과로 답변을 만듭니다.재작성 효과를 비교하거나 답변 문장까지 볼 때

실행과 검색 파라미터

번호메뉴기능이런 때 사용하세요
1실행진단을 실행합니다. 실행 중에는 중지로 바뀝니다.조건을 다 정했을 때
2검색 파라미터아래 검색 설정을 펼치거나 접습니다.검색 설정을 바꿔 볼 때

검색 파라미터

번호메뉴기능이런 때 사용하세요
1검색 방식semantic(의미), keyword, hybrid 중에서 고릅니다.방식별 답변을 비교할 때
2결과 수·점수 컷가져올 결과 수와, 이 점수보다 낮은 결과를 뺄 기준입니다.관련 없는 결과를 걸러 낼 때
3리랭킹결과 순서를 다시 매길지 정합니다.순위가 어색할 때

진단 결과

번호메뉴기능이런 때 사용하세요
1답변만들어진 답변입니다. 문장 끝 [1] 같은 번호가 근거 청크입니다.답이 문서와 맞는지 볼 때
2재작성·소요시간·토큰재작성된 질문, 단계별 걸린 시간, 입력·출력 토큰 수입니다.느린 단계를 찾을 때
3근거 문서답변에 쓰인 청크의 문서 이름입니다. 아래로 최종 프롬프트, 선택된 컨텍스트 청크, 검색 결과가 이어집니다.어떤 문서가 답에 쓰였는지 볼 때

이 예에서는 "연차는 며칠 전까지 신청해야 하나요?"에 "사용일 3영업일 전까지 그룹웨어 근태 메뉴에서 신청"이라고 답하고 근거로 "연차-사용-안내.md"를 들었습니다. 커넥션이 연결되지 않은 컬렉션에서는 검색 결과까지만 나오고, 답변과 최종 프롬프트에는 "아직 없습니다(답변 생성이 꺼져 있거나 LLM이 구성되지 않았을 수 있습니다)."가 표시됩니다.

RAG 평가​

실험 > RAG 평가는 질문과 기대 답을 모은 데이터셋(CSV)을 컬렉션에 한꺼번에 돌려 결과를 Excel·CSV로 받는 화면입니다. 규정이 바뀔 때마다 같은 질문 묶음으로 점검하면 품질이 떨어졌는지 바로 알 수 있습니다.

RAG 평가 화면

번호메뉴기능이런 때 사용하세요
1새로 만들기새 평가 데이터셋을 만듭니다. 이름과 설명을 적습니다.자주 묻는 질문 묶음을 만들 때
2데이터셋 목록만든 데이터셋이 쌓입니다. 다른 사람의 데이터셋은 내 데이터셋으로 복사로 가져옵니다.지난 데이터셋을 고를 때
3데이터셋 내용데이터셋을 고르면 항목과 CSV 업로드가 나옵니다. 템플릿 받기로 CSV 양식을 받습니다.질문 목록을 올릴 때

평가 실행 설정

번호메뉴기능이런 때 사용하세요
1실행 대상 컬렉션평가를 돌릴 컬렉션입니다.개정 전·후 컬렉션을 같은 질문으로 비교할 때
2검색 파라미터누르면 아래 설정을 펼치거나 접습니다. 옆에 지금 고른 검색 방식이 요약으로 보입니다.평가 조건을 확인할 때
3검색 방식·결과 수·점수 컷·리랭킹검색 방식, 결과 수, 점수 컷, 리랭킹을 정합니다.조건별로 결과를 비교할 때
4실행평가를 실행합니다. 데이터셋을 고르기 전에는 누를 수 없습니다.데이터셋과 컬렉션을 정했을 때

실행 이력

번호메뉴기능이런 때 사용하세요
1실행 이력지난 실행이 쌓입니다. 상태, 성공·실패 건수, 점수를 보고 결과를 xlsx·csv로 내려받습니다.지난달 결과와 비교할 때

데이터셋 CSV는 question 열이 필수이고, expected_answer(기대 답), expected_source(기대 근거 문서) 같은 열을 함께 적을 수 있습니다. 예시는 다음과 같습니다.

questionexpected_answerexpected_source
국내 당일 출장 일비는 얼마인가요?15,000원(일비의 50%)출장비-지급-규정.pdf
재택근무는 언제까지 신청해야 하나요?전주 금요일 18시까지재택근무-운영-지침.docx
업무 식대는 1인 얼마까지 인정되나요?25,000원경비-처리-기준.hwp

실험 공간 안내대로 데이터셋과 결과는 모든 사용자에게 공개됩니다. 실제 고객 문의나 개인정보를 넣지 마세요.
