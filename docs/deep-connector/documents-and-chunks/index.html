Deep Connector 문서와 청크 확인

문서를 올리고 처리가 끝났다고 해서 원하는 문장이 제대로 나뉘었다는 뜻은 아닙니다. 이 페이지는 문서 미리보기, 청크 탭, 문서 상세, 변경 이력에서 처리 결과를 원본과 대조하는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 문서 목록을 상태·확장자·파이프라인으로 좁힙니다.
  • 문서 목록에서 바로 문서 요약과 첫 쪽을 봅니다.
  • 컬렉션의 모든 청크를 훑고 너무 짧거나 긴 청크를 찾습니다.
  • 문서 상세에서 원본과 청크를 나란히 보고, 필요하면 청크 본문을 고칩니다.
  • 변경 이력으로 누가 언제 문서를 교체하거나 다시 처리했는지 확인합니다.

문서 목록 좁히기​

컬렉션의 문서 탭 위쪽 도구로 문서가 많을 때 목록을 좁힙니다.

문서 목록 필터

번호메뉴기능이런 때 사용하세요
1필터·문서명 검색필터를 누르면 상태(처리 중, 완료, 실패 등), 등록(등록 시점), 확장자, 파이프라인으로 좁히는 메뉴가 열립니다. 옆 칸은 문서 이름으로 찾습니다.실패한 문서나 PDF만 볼 때
2쪽당 개수한 쪽에 보일 문서 수(기본 20개)를 고릅니다.문서를 한 화면에서 많이 훑을 때

문서 행 오른쪽 버튼은 상태에 따라 바뀝니다. 처리가 끝난 문서는 다시 적재와 삭제, 처리에 실패한 문서는 재시도와 삭제, 처리 중인 문서는 중지와 삭제입니다. 행 왼쪽 체크로 여러 문서를 고르면 위에 "N개 선택됨"과 함께 다시 적재, 다운로드(원본을 ZIP 하나로 받기), 삭제가 나타나고, 처리 전 문서나 실패한 문서가 섞여 있으면 적재 시작, 재시도도 나옵니다. 업로드만 하고 처리하지 않은 문서와 실패한 문서가 있으면 목록 위에 미처리 N건 적재가 생겨 한 번에 처리할 수 있습니다.

이럴 때 쓰세요: 고객지원 답변 근거 컬렉션 목록에 "실패 1"이 보이면, 김그루 사원은 필터 > 상태에서 실패를 골라 그 문서만 남기고 오류 상세를 확인합니다.

문서 미리보기​

문서 목록에서 문서 이름 옆 돋보기(문서 미리보기)를 누르면 오른쪽에 요약 창이 열립니다.

문서 미리보기 창

번호메뉴기능이런 때 사용하세요
1선택한 문서미리보기 중인 문서 행이 강조됩니다.어느 문서를 보고 있는지 확인할 때
2문서 상세 열기·미리보기 닫기왼쪽(↗)은 문서 상세 화면으로 가고, 오른쪽(×)은 요약 창을 닫습니다.원본과 청크를 나란히 보거나 목록을 넓게 볼 때
3첫 쪽 미리보기원본 첫 쪽 모습입니다.올린 파일이 맞는지 눈으로 확인할 때
4문서 요약페이지 수, 청크 수, 청크 기준 문자 수, 평균 청크 길이, 용량, 파일 버전, 상태, 등록·수정 일시입니다. 아래로 내리면 더 보입니다.개정본의 버전과 처리 상태를 한눈에 볼 때

청크 탭​

컬렉션의 청크 탭은 컬렉션 안 모든 청크를 보여 줍니다. 검색 결과와 에이전트 근거가 청크 단위로 나오므로, 원하는 문장이 어느 청크에 들어갔는지 여기서 확인합니다.

컬렉션의 청크 탭

번호메뉴기능이런 때 사용하세요
1청크 수이 컬렉션의 청크 총수입니다.문서를 올린 뒤 청크가 늘었는지 볼 때
2전체 선택지금 화면의 청크를 모두 고릅니다. 고르면 위에 다운로드(출처·쪽이 적힌 문서 파일 하나로 받기)와 삭제가 나타납니다. 청크 본문 수정은 문서 상세에서 하나씩 합니다.청크 여러 개를 한 파일로 모아 검토할 때
3미리보기청크 앞부분입니다. 누르면 문서 상세에서 그 청크가 열립니다.규정 조항이 통째로 들어갔는지 볼 때

청크 목록의 열

번호메뉴기능이런 때 사용하세요
1청크 미리보기청크 전문을 바로 봅니다.잘린 문장이 없는지 빠르게 볼 때
2문자청크 글자 수입니다. 눌러 정렬합니다.너무 짧거나 긴 청크를 찾을 때
3파싱된 날짜청크가 만들어진 일시입니다.개정본 처리 뒤 새로 생긴 청크를 구별할 때
4문서명청크가 나온 문서입니다.같은 내용이 어느 문서에서 나왔는지 볼 때

표가 있는 문서는 청크 본문에 표가 표 형식 그대로 들어갑니다. 예를 들어 경비-처리-기준.hwp의 "비용 항목별 승인권자" 표는 한 청크 안에 행과 열이 그대로 보존됩니다.

이럴 때 쓰세요: 김그루 사원은 출장비 규정을 올린 뒤 청크 탭에서 문자 열로 정렬해 100자도 안 되는 청크가 있는지 봅니다. 조항 제목만 따로 떨어진 청크가 많으면 기본 파이프라인을 조항 단위 청킹으로 바꾸고 다시 적재합니다. 형식별로 청크를 직접 열어 보는 손동작은 실습 2에 있습니다.

문서 상세​

문서 이름을 누르면 문서 상세가 열립니다. 왼쪽은 원본 미리보기, 오른쪽 위는 청크 목록, 오른쪽 아래는 고른 청크의 본문과 정보입니다.

문서 상세 화면

번호메뉴기능이런 때 사용하세요
1문서 목록으로컬렉션의 문서 탭으로 돌아갑니다.다른 문서를 볼 때
2처리 상태이 문서의 처리 상태(예: 완료)입니다.검색에 쓰일 수 있는 상태인지 볼 때
3개요제목, 설명, 태그, 상태, 형식, 글자 수, 처리에 쓴 파이프라인을 보여 줍니다. 제목·설명·태그는 고칠 수 있습니다.어떤 파이프라인으로 처리됐는지 확인할 때
4변경 이력업로드, 교체, 다시 처리 기록이 쌓입니다.누가 언제 문서를 바꿨는지 확인할 때

문서 상세의 작업 버튼

번호메뉴기능이런 때 사용하세요
1다시 적재이 문서만 다시 처리합니다.문서 하나의 결과만 다시 만들 때
2새 버전 업로드같은 문서를 새 파일로 바꿉니다. 이전 파일은 버전으로 남습니다.개정본으로 교체할 때(반복 업무 참고)
3새 창으로 보기원본을 새 창에서 엽니다.원본을 크게 띄워 놓고 대조할 때
4원본 다운로드원본 파일을 내려받습니다.원본을 다른 사람에게 전달할 때

원본 보기와 목록 도구

번호메뉴기능이런 때 사용하세요
1쪽 이동·확대쪽 번호를 바꾸고 축소·확대·화면 맞춤을 합니다.표가 있는 쪽을 크게 볼 때
2구성 단위Chunk(청크)와 Element(문단·표 같은 원본 요소) 중에서 목록 단위를 고릅니다.원본 요소가 청크로 어떻게 묶였는지 볼 때
3본문에서 검색이 문서 안에서 낱말을 찾습니다."120,000원"이 어느 청크에 있는지 찾을 때
4쪽 범위오른쪽 목록을 현재 쪽 것만 볼지 전체 쪽을 볼지 고릅니다.쪽이 많은 문서에서 한 쪽만 볼 때

청크 목록과 본문

번호메뉴기능이런 때 사용하세요
1청크 목록번호, 앞부분, 쪽이 보입니다. 누르면 아래에 본문이 열리고 왼쪽 원본에서 해당 위치가 표시됩니다.원본과 청크를 한 줄씩 대조할 때
2편집고른 청크 본문을 직접 고칩니다. 고치면 그 청크를 다시 임베딩합니다.처리 중 깨진 글자를 바로잡을 때

청크 본문 아래에는 청크 기본 정보와 메타데이터가 있습니다. 쪽 번호, 글자 위치, 제목 경로, 업로드 때 붙인 메타데이터(예: 분류, source)가 보입니다. 다시 적재하거나 새 버전을 올리면 직접 고친 청크 내용은 새 처리 결과로 바뀝니다.

이럴 때 쓰세요: 에이전트가 숙박비 상한을 틀리게 답했다면, 근거로 든 청크를 문서 상세에서 열어 원본 쪽과 나란히 봅니다. 표가 깨져 금액이 다른 칸에 붙었다면 청크 편집으로 바로잡습니다.

변경 이력​

문서 상세 위쪽 변경 이력 버튼을 누르면 문서와 구성 단위의 변경 기록이 열립니다.

변경 이력

번호메뉴기능이런 때 사용하세요
1보기 범위전체, 문서, 구성 단위 중에서 고릅니다.청크를 고친 기록만 볼 때
2파싱 완료처리 완료 기록입니다. 만들어진 구성 단위 수가 함께 보입니다.교체 뒤 처리가 끝났는지 확인할 때
3파일 교체새 버전 업로드 기록입니다. 한 사람, 일시, 새 파일 이름과 변경 사유가 남고 rev 번호가 하나 올라갑니다.개정 반영 이력을 확인할 때
4문서 등록문서를 처음 올린 기록입니다.문서가 언제 들어왔는지 볼 때

기록의 변경 내용 보기로 바뀐 내용을 비교하고, 이 내용으로 되돌리기로 청크 내용을 이전 상태로 돌릴 수 있습니다.

이럴 때 쓰세요: "지난주에 누가 취업규칙 파일을 바꿨나요?"라는 질문을 받으면 변경 이력에서 파일 교체 기록과 작업자, 시각을 확인합니다.
