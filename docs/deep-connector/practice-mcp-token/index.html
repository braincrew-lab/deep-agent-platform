Deep Connector 실습 5: MCP 토큰을 만들고 도구로 시험하기

Deep Agent Builder 에이전트나 다른 AI 도구가 컬렉션을 검색하려면 MCP 토큰이 있어야 합니다. 이 실습은 "AI혁신팀 업무 자료" 컬렉션 하나만 읽을 수 있는 토큰을 만들고, 에이전트가 쓸 검색 도구(search_documents)를 MCP 도구 테스트에서 같은 조건으로 실행해 이 컬렉션이 제대로 검색되는지 미리 확인합니다. 토큰 화면 전체 설명은 MCP 토큰과 외부 연동, 도구 17개의 설명은 실험: MCP 도구 테스트에 있습니다.

이 페이지에서 할 수 있는 일

  • 유효기간, 권한, 접근 컬렉션을 좁혀 MCP 토큰을 만듭니다.
  • 토큰 생성 완료 창에서 요청 URL과 토큰 값을 옮겨 둡니다.
  • MCP 도구 테스트에서 검색 범위(path)를 정해 search_documents를 실행합니다.

목표​

항목내용
만들 것"AI혁신팀 업무 자료"만 읽는 읽기 전용 토큰(유효기간 90일)
결과물요청 URL과 토큰 값, search_documents 실행 성공 결과
걸리는 시간10분
난이도★★★☆☆

준비물​

준비물내용
컬렉션실습 1의 "AI혁신팀 업무 자료"
메모할 곳토큰 값을 잠시 붙여 둘 곳. 사내 비밀번호 관리 도구를 권합니다. 메신저나 메일로 보내지 않습니다.

1단계. 새 토큰 만들기​

사이드바 MCP 토큰을 누르고 새 토큰 생성을 누릅니다.

새 토큰 생성 창

번호메뉴입력하거나 고를 값
1유효기간 (일)90
2권한 설정읽기 전용("데이터 조회 및 검색만 가능")
3컬렉션 이름 검색AI혁신팀
4컬렉션 체크AI혁신팀 업무 자료
설정 항목이 실습의 값기본값과 범위
유효기간 (일)90창을 처음 열면 365, 한 번 닫았다 다시 열면 30. 1~365 사이로 적습니다.
권한 설정읽기 전용읽기 전용. 읽기 / 쓰기는 문서 추가·삭제까지 허락합니다.
접근 컬렉션AI혁신팀 업무 자료 1개없음(1개 이상 골라야 만들 수 있음)
사용자당 활성 토큰–최대 10개
  1. **유효기간 (일)**에 90을 적습니다. 칸에 미리 들어 있는 숫자는 창을 연 횟수에 따라 365나 30이므로 꼭 확인하고 고칩니다.
  2. 권한 설정은 읽기 전용 그대로 둡니다. 에이전트가 검색만 하면 되므로 쓰기 권한을 주지 않습니다.
  3. 컬렉션 이름 검색 칸에 "AI혁신팀"을 적어 목록을 좁히고 "AI혁신팀 업무 자료"를 체크합니다.
  4. 창 아래 생성을 누릅니다.

고른 컬렉션이 모두 지워지면 토큰도 자동으로 폐기됩니다. 활성 토큰이 이미 10개면 "MCP 토큰은 사용자당 최대 10개까지 발급할 수 있습니다."가 나오므로, 쓰지 않는 토큰을 먼저 지웁니다.

2단계. 요청 URL과 토큰 옮겨 두기​

생성을 누르면 "토큰 생성 완료" 창이 열립니다. 이 창을 닫으면 토큰 값을 다시 볼 수 없습니다.

토큰 생성 완료 창

번호메뉴확인할 것
1요청 URL외부 도구에 적을 MCP 서버 주소입니다.
2토큰 값요청 URL 아래 두 번째 칸의 토큰 값입니다. 다른 사람에게 보이지 않게 합니다(그림에서는 가렸습니다).
3복사토큰 값 칸 오른쪽 위 복사로 토큰 값을 복사합니다.
4닫기토큰 값을 옮겨 둔 뒤 누릅니다.
  1. 요청 URL의 복사를 눌러 메모할 곳에 붙여 둡니다.
  2. 두 번째 칸(토큰 값)의 복사를 눌러 메모할 곳에 붙여 둡니다.
  3. 아래 **전체 URL (URL + Token)**은 주소 하나로 연결하는 도구에 씁니다. 이 실습에서는 쓰지 않습니다. 클라이언트 연결 설정은 Cursor, Dify 같은 도구의 설정 예시를 보여 줍니다.
  4. 닫기를 누릅니다. 토큰 목록에 접근 컬렉션 "AI혁신팀 업무 자료", 권한 READ, 만료일(발급일 + 90일)이 적힌 새 토큰이 생깁니다.

3단계. MCP 도구 테스트로 검색해 보기​

에이전트가 쓸 검색 도구를 같은 조건으로 먼저 실행해 봅니다. 사이드바 실험 > MCP 도구 테스트를 열고 왼쪽 읽기 도구 목록에서 search_documents를 누릅니다.

search_documents 파라미터

번호메뉴입력하거나 고를 값
1고급 파라미터눌러 펼칩니다. 옆 숫자 10은 선택 파라미터 수입니다.
2path/AI혁신팀 업무 자료
3실행값을 다 넣었으면 누릅니다.
  1. 맨 위 query 칸에 "다음 주간 회의는 언제야?"를 적습니다.
  2. 고급 파라미터를 펼치고 path 칸에 "/AI혁신팀 업무 자료"를 적습니다. 컬렉션 이름 앞에 "/"를 붙이고, 폴더 안에 있는 컬렉션이면 "/폴더 이름/컬렉션 이름"으로 적습니다. 경로를 모르면 glob_paths 도구로 먼저 찾습니다.
  3. 실행을 누릅니다.

search_documents 실행 결과

번호메뉴확인할 것
1실행 결과 요약"성공", 도구 이름 search_documents, 걸린 시간입니다.
2보기·Raw JSON읽기 쉬운 화면과 원문 사이를 바꿉니다.
3결과 청크"[회의록] 2026년 4분기 AI 업무 혁신 주간 회의" 청크입니다. 아래로 내리면 "다음 회의: 2026-11-17(화) 14:00"이 보입니다.

MCP 도구 테스트는 토큰이 아니라 로그인한 내 권한으로 실행됩니다. 에이전트가 볼 결과와 같으려면 path를 토큰의 접근 컬렉션과 같게 맞춥니다.

결과​

  • "AI혁신팀 업무 자료"만 읽는 읽기 전용 토큰이 만들어졌고, 요청 URL과 토큰 값을 옮겨 두었습니다.
  • search_documents가 이 컬렉션에서 회의록 청크를 찾아 왔습니다. 실습 6의 에이전트도 같은 도구로 같은 청크를 찾습니다.

흔한 실수​

증상원인해결
토큰 값을 옮기기 전에 창을 닫음토큰 값은 생성 완료 창에서만 보입니다.그 토큰을 지우고 새로 만듭니다.
만료일이 30일 뒤로 찍힘창을 한 번 닫았다 열어 유효기간 기본값이 30으로 바뀌었습니다.만들기 전에 유효기간 (일) 칸을 확인합니다.
"Search scope API request failed (HTTP 404): Collection path not found"path의 컬렉션 이름이 틀렸거나, 폴더 안의 컬렉션인데 폴더 이름을 빼먹었습니다.glob_paths를 실행해 정확한 경로를 복사합니다.
ValidationErrorsearch_documents에 검색 범위(path나 document_ids)가 없습니다.고급 파라미터의 path를 채웁니다.

응용 과제​

  1. glob_paths를 파라미터 없이 실행해 내가 볼 수 있는 컬렉션 경로 목록을 받고, "AI혁신팀 업무 자료"의 path를 복사해 써 봅니다.
  2. read_document에 실습 2에서 본 계약서 PDF의 문서 ID를 넣어 실행하고, 에이전트가 문서 전체를 읽을 때 어떻게 보이는지 봅니다.
  3. 토큰 목록에서 접근 컬렉션 수정으로 "사내 규정"을 더해 보고, 다시 빼서 원래대로 돌립니다.
