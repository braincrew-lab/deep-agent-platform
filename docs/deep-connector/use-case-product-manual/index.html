Deep Connector 사례: 제품 매뉴얼 검색

브레인크루 기술지원 담당은 회의 녹음기 "브레인노트 S2" 문의를 받을 때마다 사용설명서 PDF, 빠른 시작 웹 페이지, 펌웨어 안내, 버튼 그림, 제품 소개 슬라이드를 번갈아 열어 봅니다. 이 사례에서는 다섯 가지 형식의 자료를 한 컬렉션에 모아, 증상이나 궁금한 점을 입력하면 해당 설명과 출처가 바로 나오게 합니다.

이 페이지에서 할 수 있는 일

  • 웹 문서(.html, .htm), 이미지(.png), 슬라이드(.pptx), PDF를 한 컬렉션에 올립니다.
  • 그림 속 글자까지 검색되는지 확인합니다.
  • 문장 질문과 낱말 검색의 결과를 비교하고, 증상 질문에 답변을 받습니다.

목표​

항목내용
누가기술지원 담당, 영업 담당
무엇을브레인노트 S2 자료 다섯 건을 "제품 매뉴얼" 컬렉션에 올려 검색합니다
끝났다고 볼 기준"공장 초기화 방법"을 물었을 때 설명서와 버튼 안내 그림이 함께 나오는 것
걸리는 시간20분 정도

준비물​

파일확장자내용
브레인노트-S2-사용설명서.pdf.pdf구성품, 배터리(완충 2시간, 연속 녹음 12시간), 상태 표시등 색 의미, 초기화(전원+녹음 10초), 보증 1년
브레인노트-S2-빠른시작.html.html충전, 앱 설치, 블루투스 연결, 녹음 시작까지 다섯 단계
브레인노트-S2-펌웨어-업데이트.htm.htm최신 버전 2.4.1, 배터리 50% 이상, 실패하면 빨간색 빠른 깜박임
브레인노트-S2-버튼-안내.png.png버튼 네 개의 이름과 기능을 적은 안내 그림
브레인노트-S2-제품소개.pptx.pptx한 줄 소개, 주요 사양, 가격(189,000원)과 법인 할인

모두 매뉴얼 시연용 가상 자료입니다.

단계​

1. 컬렉션 만들고 자료 올리기​

  1. 새 컬렉션에서 이름 "제품 매뉴얼", 설명 "브레인노트 S2 회의 녹음기 설명서·빠른 시작·펌웨어 안내·버튼 그림·제품 소개"로 만들고 기본 파이프라인을 고릅니다.
  2. 문서 업로드에서 다섯 파일을 한 번에 올립니다. 업로드 화면의 지원 형식 표에서 .html, .htm, .pptx는 Office / Web, .png와 .pdf는 PDF / Images 묶음으로 처리됩니다.

제품 매뉴얼 컬렉션의 문서 목록

번호항목화면에서 볼 것
1문서 이름형식 아이콘으로 PDF, 슬라이드, 웹 문서, 그림을 구별합니다. 슬라이드는 쪽 수 칸에 장 수(4)가 보입니다.
2청크 수그림 파일도 글자를 읽어 청크가 1개 만들어졌습니다.
3청크 탭그림에서 읽은 글자가 맞는지 청크 본문으로 확인합니다.

2. 문장으로 묻기​

실험 > 검색에서 "제품 매뉴얼"을 고르고 시맨틱 검색으로 묻습니다.

프롬프트: 녹음기를 공장 초기화하려면 어떻게 하나요?

시맨틱 검색 결과

번호항목화면에서 볼 것
1컬렉션"제품 매뉴얼"을 고른 상태입니다.
2검색 방식시맨틱 검색입니다.
3질문고객이 말한 그대로 적었습니다.
4첫 결과사용설명서 PDF의 "4. 초기화" 청크(신뢰도 80%)입니다. 2위에는 버튼 안내 그림의 "초기화: ①+② 동시에 10초"가 나옵니다.

3. 낱말로 찾기​

증상에 정해진 용어가 있으면 키워드 검색이 더 빠릅니다.

키워드 검색 결과

번호항목화면에서 볼 것
1컬렉션"제품 매뉴얼"입니다.
2검색 방식키워드 검색입니다. 적용된 설정에 "BM25 키워드"가 보입니다.
3검색어"펌웨어 업데이트 실패"
4결과펌웨어 안내(.htm) 청크가 신뢰도 100%로 나오고, 본문의 검색어 낱말이 노란색으로 표시됩니다.

4. 답변 받기​

컬렉션에 LLM 커넥션을 연결한 뒤 RAG 진단에서 증상을 묻습니다.

프롬프트: 상태 표시등이 빨간색으로 빠르게 깜박이면 무슨 뜻이고 어떻게 해야 하나요?

제품 매뉴얼 답변

번호항목화면에서 볼 것
1컬렉션"제품 매뉴얼"입니다.
2질의증상 질문입니다.
3답변"펌웨어 업데이트에 실패한 상태입니다. 이 경우 본체를 충전기에 연결한 채 앱에서 다시 업데이트를 시도하면 됩니다"라고 답하고, 근거로 "브레인노트-S2-펌웨어-업데이트.htm"을 들었습니다.

결과물 예시​

고객 문의찾은 답근거
공장 초기화 방법전원 버튼과 녹음 버튼을 동시에 10초. 저장된 녹음이 모두 지워짐사용설명서 PDF, 버튼 안내 그림
빨간 표시등이 빠르게 깜박임펌웨어 업데이트 실패. 충전기 연결 후 앱에서 다시 시도펌웨어 업데이트 안내
법인 구매 할인10대 이상 15% 할인제품 소개 슬라이드

응용 팁​

  • 그림 파일은 글자가 또렷해야 잘 읽힙니다. 사진으로 찍은 설명서는 반듯하게 잘라 올리세요.
  • 같은 내용이 설명서와 웹 페이지에 모두 있으면 둘 다 결과에 나옵니다. 버전이 다른 자료가 섞이지 않도록 옛 설명서는 새 버전 업로드로 교체합니다.
  • 제품이 여러 개면 제품마다 컬렉션을 나누거나, 파일별 메타데이터에 "제품명"을 붙여 검색 필터로 좁힙니다.
