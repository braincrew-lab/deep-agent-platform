연습: 비슷한 규칙 중 정확한 조건 찾기​

다음은 제품 사용법을 익히기 위한 가상 연습입니다. 특정 조직의 실제 규정이나 도입 성과가 아닙니다. 목표는 문서가 검색되는지만 확인하는 것이 아니라 예약과 취소의 서로 다른 조건을 구분해 읽는 것입니다.

문서 작성 도구로 아래 내용을 담은 PDF 두 개를 준비하세요. 실제 업무 자료와 섞이지 않는 연습용 컬렉션과 사용 가능한 처리 파이프라인을 사용합니다.

문서 제목넣을 내용
회의실 이용 안내예약은 이용 전날까지 신청합니다. 취소는 이용 시작 두 시간 전까지 신청합니다. 이용 후에는 책상을 정리합니다.
장비 대여 안내장비는 대여 전날까지 신청합니다. 취소는 수령 전날까지 신청합니다. 반납 시 구성품을 확인합니다.

두 문서는 신청과 취소라는 단어를 공유하지만 적용 대상과 시점이 다릅니다. 이 차이 때문에 검색어에 대상이 들어 있는지, 결과가 어느 문서에서 왔는지 확인하는 연습에 적합합니다.

수행 순서​

  1. 시작하기의 등록 절차로 두 파일을 같은 연습용 컬렉션에 넣습니다. 각각의 처리 완료 상태와 청크 내용을 확인합니다.
  2. 실험 → 검색으로 이동하고 연습용 컬렉션을 선택합니다. 첫 질문은 “회의실 취소는 언제까지 가능한가요?”로 입력합니다.
  3. 결과를 펼쳐 문서명이 회의실 이용 안내인지, “이용 시작 두 시간 전까지”라는 조건이 포함되어 있는지 확인합니다.
  4. 질문을 “장비 취소는 언제까지 가능한가요?”로 바꾸어 실행합니다. 장비 대여 안내의 “수령 전날까지”라는 조건을 찾습니다.
  5. 마지막으로 “취소는 언제까지 가능한가요?”처럼 대상을 뺀 질문을 실행합니다. 결과가 두 업무를 구분할 충분한 정보를 제공하는지 비교합니다.

결과가 기대와 다르다고 즉시 실패한 업로드로 보지 마세요. 문서가 정상 처리되었는지 확인한 후, 질문의 대상과 검색 범위가 충분히 명확한지 살펴봅니다. 검색 방식을 비교하려면 질문은 고정하고 반복 업무의 절차를 따릅니다.

결과를 판단하는 기준​

점검 질문통과로 볼 수 있는 관찰
다른 업무의 규칙을 가져오지 않았나요?문서명과 적용 대상이 질문에 맞음
숫자만 있고 기준 시점은 빠지지 않았나요?두 시간뿐 아니라 이용 시작 전이라는 조건도 읽을 수 있음
예약과 취소를 혼동하지 않았나요?결과 본문이 질문의 행위를 설명함
원문과 일치하나요?원본에 적은 문장과 검색된 근거를 대조할 수 있음

질문별 결과 순위나 청크 수는 미리 정하지 않습니다. 분할 구성과 검색 방식에 따라 달라질 수 있습니다. 중요한 것은 업무에 필요한 근거를 식별하고 조건을 보존해 읽을 수 있느냐입니다.

실제 업무로 확장하기​

사내 지침이나 제품 안내를 점검할 때에도 대표 질문과 기대 근거를 먼저 정하세요. 개정 날짜가 다른 문서를 함께 사용하는 경우에는 현재 적용할 버전을 확인해야 합니다. 이 연습만으로 전체 문서의 검색 품질을 보장할 수 없으므로, 표가 있는 문서와 긴 문서도 별도로 확인합니다.

찾아야 할 문장이 검색되지 않으면 문제 해결에서 처리 누락과 검색 조건 문제를 나누어 확인하세요.
