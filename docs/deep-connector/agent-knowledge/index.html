Deep Connector 에이전트에서 지식 쓰기

Deep Connector의 컬렉션은 Deep Agent Builder 에이전트가 근거로 쓰는 지식이 됩니다. 에이전트는 질문을 받으면 연결된 컬렉션을 검색하고 문서를 읽은 뒤, 찾은 문장으로 답하고 근거 문서를 밝힙니다. 이 페이지는 김그루 사원이 "사내 규정 Q&A 비서" 에이전트에 Deep Connector 컬렉션을 연결하고 질문하는 순서를 설명합니다.

이 페이지에서 할 수 있는 일

  • 컬렉션이 에이전트의 지식이 되기까지의 단계를 이해합니다.
  • Deep Connector에서 연결용 MCP 토큰을 만들고, Deep Agent Builder에 도구로 등록합니다.
  • 에이전트의 도구 실행 기록에서 어떤 컬렉션을 검색했는지 확인합니다.
  • 에이전트가 근거를 못 찾을 때 Deep Connector 쪽에서 점검할 곳을 압니다.

연결 흐름​

단계어디서할 일결과
1. 컬렉션 준비Deep Connector 컬렉션문서를 올리고 처리 완료와 검색을 확인합니다.질문에 맞는 청크가 검색됨
2. 토큰 발급Deep Connector MCP 토큰읽기 전용 권한으로, 에이전트가 쓸 컬렉션만 골라 토큰을 만듭니다.요청 URL과 토큰 값
3. 도구 등록Deep Agent Builder 에셋설정 > 도구도구 추가에서 Connect MCP Server를 고르고 요청 URL과 토큰을 넣습니다.Deep Connector 검색 도구 묶음이 도구 목록에 생김
4. 에이전트 연결Deep Agent Builder 에이전트 설정도구함에 3단계의 도구를 추가하고 저장합니다.에이전트가 질문마다 컬렉션을 검색함
5. 질문과 확인Deep Agent Builder 대화질문하고 도구 실행 기록과 근거 문서를 봅니다.근거 문서 이름이 붙은 답변

다섯 단계를 새 컬렉션으로 처음부터 직접 해 보려면 실습 5와 실습 6을 따라 합니다. 2단계는 MCP 토큰과 외부 연동의 토큰 만들기, 3단계는 Deep Agent Builder 매뉴얼의 MCP와 에이전트의 MCP화에서 자세히 설명합니다. 토큰의 접근 컬렉션을 바꾸면 에이전트가 검색할 수 있는 범위도 함께 바뀝니다. 예를 들어 시작하기에서 만든 "규정 Q&A"도 에이전트가 검색하게 하려면 Deep Connector MCP 토큰의 접근 컬렉션 수정에서 체크하면 됩니다.

에이전트 설정 확인​

Deep Agent Builder에서 에이전트를 열고 에이전트 설정을 누르면 연결된 도구를 볼 수 있습니다.

에이전트 설정

번호메뉴기능이런 때 사용하세요
1지침에이전트가 답하는 방식입니다. 이 예에서는 질문을 받으면 deep_connector_kb 도구로 사내 규정 컬렉션을 검색하고, 근거 문서 이름을 함께 밝히도록 적었습니다.출처를 꼭 밝히게 할 때
2도구함의 연결 도구Deep Connector 연결 도구(deep_connector_kb)입니다. 톱니바퀴로 설정을, 휴지통으로 연결 해제를 합니다.Deep Connector 연결이 되어 있는지 볼 때
3+ 도구도구함에 도구를 추가합니다.등록해 둔 Deep Connector 연결 도구를 에이전트에 넣을 때
4+ 지식(지식함)Deep Agent Builder 자체 지식 연결 칸입니다. Deep Connector 컬렉션은 도구함으로 연결하므로 이 칸이 비어 있어도 됩니다.–

도구를 더하거나 지침을 고친 뒤에는 오른쪽 위 저장을 눌러야 반영됩니다.

지침에 "Deep Connector에서 찾은 문서만 근거로 답하고, 근거 문서 이름을 함께 적는다. 찾지 못하면 모른다고 답한다."처럼 적어 두면 출처가 빠진 답을 줄일 수 있습니다.

질문하고 근거 확인하기​

에이전트 답변과 도구 실행 기록

번호메뉴기능이런 때 사용하세요
1에이전트 이름지금 대화 중인 에이전트입니다.맞는 에이전트에게 묻는지 확인할 때
2search_documents 실행 기록에이전트가 Deep Connector에서 질문으로 검색한 기록입니다. 위쪽에는 glob_paths(경로 찾기), list_collections(컬렉션 목록)처럼 검색 범위를 정하려고 실행한 도구도 보입니다.어떤 컬렉션을 뒤졌는지 볼 때
3출력펼치면 도구가 돌려준 결과(찾은 청크와 문서 이름)를 볼 수 있습니다.어떤 문장을 근거로 삼았는지 볼 때
4답변과 근거 문서답과 근거 문서 이름입니다.원문과 대조할 문서를 정할 때

왼쪽 사이드바의 에이전트 설정을 누르면 에이전트의 지침과 도구를 보는 화면이 열립니다. 연결 도구를 확인하거나 바꿀 때 씁니다.

이 예의 질문은 "서울로 출장 가면 숙박비는 1박에 얼마까지 나오나요? 근거 문서 이름도 알려 주세요."였습니다. 시연 환경에서 이 에이전트는 미리 준비된 "사내 규정" 컬렉션(규정 Q&A와는 다른 컬렉션)에 연결되어 있어, 그 컬렉션의 "브레인크루_출장비_규정" 문서를 근거로 답했습니다. 도구 이름 앞의 deep_connector_kb는 3단계에서 등록한 도구 이름입니다.

이럴 때 쓰세요: 신입 사원 정신입 님이 "연차는 며칠 전에 신청해요?"라고 물을 때마다 규정을 찾아 주던 김그루 사원은, Builder의 "사내 규정 Q&A 비서"에 Deep Connector 컬렉션을 연결해 두고 비서의 답변 아래 도구 실행 기록에서 근거 문서 이름을 함께 보여 주도록 안내합니다.

근거를 못 찾을 때​

증상Deep Connector에서 볼 곳할 일
도구 실행 기록이 없음–에이전트 설정의 도구함에 연결 도구가 있는지, 지침이 검색을 하라고 되어 있는지 봅니다
검색은 했는데 엉뚱한 문서를 근거로 듦실험 > MCP 도구 테스트(MCP 도구 테스트)같은 질문으로 search_documents를 실행해 결과 순위를 봅니다. 설명이 비슷한 컬렉션이 섞여 있으면 토큰의 접근 컬렉션을 줄입니다
최신 개정 내용이 반영되지 않음문서 상세 버전, 문서 상태새 버전 처리가 완료됐는지, 옛 문서가 같은 컬렉션에 남아 있지 않은지 봅니다
"접근 권한이 없다"는 취지로 답함MCP 토큰의 접근 컬렉션토큰에 그 컬렉션이 들어 있는지, 토큰이 만료되지 않았는지 봅니다
