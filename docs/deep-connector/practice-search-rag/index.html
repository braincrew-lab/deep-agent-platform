Deep Connector 실습 3: 검색 방식과 AI 답변 시험하기

이 실습은 "AI혁신팀 업무 자료" 컬렉션에 LLM 커넥션을 연결해 AI 답변을 켜고, 회의록에 있는 결정 사항을 문장으로 물어 답과 근거를 받아 봅니다. 이어서 같은 컬렉션을 키워드 검색으로 찾아 두 방식의 결과가 어떻게 다른지 비교합니다. 검색 화면의 모든 설정은 실험: 검색, 컬렉션 설정은 컬렉션과 폴더에 있습니다.

이 페이지에서 할 수 있는 일

  • 컬렉션 설정에 LLM 커넥션을 넣고 질의 재작성과 AI 답변 생성을 켭니다.
  • 검색 화면에서 AI 답변을 켜고 문장으로 물어 답변과 근거 청크를 함께 봅니다.
  • 키워드 검색으로 문서에 쓰인 낱말을 찾고, 실제 적용된 설정을 읽습니다.
  • 문자열 검색이 결과를 내지 않을 때의 이유를 압니다.

1단계. 컬렉션에 LLM 커넥션 연결하기​

컬렉션을 열고 설정 탭을 누른 뒤 맨 아래 LLM 검색 보강까지 내립니다.

LLM 검색 보강 설정

번호메뉴입력하거나 고를 값
1커넥션 ID관리자에게 받은 커넥션 ID를 붙여 넣습니다(그림에서는 가렸습니다).
2질의 재작성 사용체크합니다. 짧거나 구어체인 질문을 검색하기 좋은 문장으로 바꿉니다.
3AI 답변 생성 사용체크합니다. 검색한 청크로 답변 문장을 만듭니다.
4저장값을 바꾸면 화면 아래에 나타납니다.
설정 항목이 실습의 값기본값
커넥션 ID내 팀스페이스용 커넥션없음
질의 재작성 사용켬꺼짐
AI 답변 생성 사용켬꺼짐
답변에 사용할 최대 청크 수55(1~20)
  1. 커넥션 ID 칸에 커넥션 ID를 붙여 넣습니다. 칸이 비어 있는 동안에는 "연결된 커넥션이 없습니다. 커넥션 ID를 입력하면 재작성/답변 옵션을 켤 수 있습니다."가 나옵니다.
  2. 질의 재작성 사용과 AI 답변 생성 사용을 체크합니다.
  3. 저장을 누릅니다. "컬렉션이 성공적으로 수정되었습니다"가 나오면 끝입니다.

질문은 그대로 LLM에 전송됩니다. 질문에 개인정보를 넣지 마세요.

2단계. 문장으로 묻고 AI 답변 받기​

사이드바 실험 > 검색을 엽니다. 처음이면 실험 공간 안내의 세 항목을 확인하고 확인하고 시작하기를 누릅니다.

AI 답변과 근거

번호메뉴입력하거나 고를 값
1컬렉션 선택AI혁신팀 업무 자료
2AI 답변눌러 켭니다. 켜지면 버튼 테두리가 초록색으로 바뀝니다.
3검색어 입력란11월 10일 회의에서 정한 결정 사항이 뭐야?
4AI 답변결정 사항 세 줄이 나오고, 끝의 작은 숫자 1이 근거로 쓴 첫 번째 검색 결과입니다.
  1. 컬렉션 선택에서 "AI혁신팀 업무 자료"를 고릅니다. 검색 방식은 시맨틱 검색, 결과 제한은 5개 그대로 둡니다.
  2. AI 답변을 눌러 켭니다.
  3. 검색어를 적고 Enter를 누릅니다. "질의 재작성 중"이 잠깐 보인 뒤 답변이 나옵니다. 이 매뉴얼에서는 30초 정도 걸렸습니다.
  4. 답변 아래 검색 결과의 첫 카드가 "회의록_AI업무혁신_20261110.html"이고 신뢰도가 높은지(이 예에서는 89%) 봅니다.
  5. 검색에 쓰인 질의 보기를 눌러 재작성된 질문을 확인합니다.

이 실습에서 받은 답변입니다.

11월 10일 회의에서 결정된 사항은 다음과 같습니다. 판매 리포트 에이전트에 지역별 목표 대비 실적 표를 추가한다. 설문 분석 에이전트를 마케팅팀과 함께 만들고 커뮤니티에 공유한다. 복리후생 규정 최신본을 지식 컬렉션 '사내 규정'에 올린다.

검색어 아래 띠에는 실제로 적용된 설정이 나옵니다. 이 예에서는 분석기 KIWI, 검색 방식 벡터 검색, 리랭커 사용, 사전 미적용이었습니다. 시맨틱 검색에는 용어 사전이 적용되지 않습니다.

3단계. 키워드 검색으로 계약서 조항 찾기​

이번에는 문서에 쓰인 낱말로 찾습니다. AI 답변을 다시 눌러 끄고 진행합니다.

키워드 검색 결과

번호메뉴입력하거나 고를 값
1검색 방식키워드 검색
2검색어 입력란지연 이자
3실제 적용된 설정검색 방식이 "BM25 키워드"로 바뀐 것을 확인합니다.
4검색 결과"2개의 결과를 찾았습니다." 서비스이용계약서_샘플.pdf와 계약서_스캔본.png의 제3조 청크입니다.
  1. 검색 방식을 키워드 검색으로 바꿉니다.
  2. "지연 이자"를 적고 Enter를 누릅니다.
  3. 두 결과가 같은 조항을 PDF와 스캔 이미지에서 각각 찾은 것인지 봅니다. 스캔 이미지의 글자도 검색됩니다.
검색 방식이 실습의 검색어결과이럴 때 고르세요
시맨틱 검색11월 10일 회의에서 정한 결정 사항이 뭐야?회의록이 첫 결과(신뢰도 89%), 나머지 4개는 관련 낮음문장으로 물을 때
키워드 검색지연 이자계약서 PDF와 스캔본 2개만문서에 쓰인 용어를 알 때
문자열 검색990만 원결과 없음정확한 코드·숫자가 원본 요소에 있는지 볼 때

문자열 검색은 문서의 원본 요소(문단·표)에서 글자를 그대로 찾습니다. 이 실습의 "기본 파이프라인"은 원본 요소를 따로 남기지 않아(문서 상세의 "Element · 0") 문자열 검색으로는 아무것도 나오지 않습니다. 이럴 때는 키워드 검색이나 문서 상세의 본문에서 검색을 씁니다.

결과​

  • 컬렉션에 LLM 커넥션이 연결되어 검색 화면과 RAG 진단에서 답변을 만들 수 있습니다.
  • 회의 결정 사항은 시맨틱 검색과 AI 답변으로, 계약서의 특정 조항은 키워드 검색으로 찾았습니다.

흔한 실수​

증상원인해결
설정 탭에 LLM 검색 보강이 없음컬렉션 소유자가 아닙니다. 분석기·사전·LLM 구역은 소유자에게만 보입니다.컬렉션 소유자에게 설정을 부탁합니다.
"컬렉션 정보는 저장됐지만 검색 분석기 설정 저장에 실패했습니다."다른 팀스페이스의 커넥션 ID입니다.컬렉션 소유자가 속한 팀스페이스용 커넥션 ID를 받습니다.
AI 답변이 눌리지 않음고른 컬렉션에 커넥션이 연결되지 않았습니다.1단계를 먼저 합니다.
키워드 검색 결과가 0개문서에 쓰이지 않은 낱말로 찾았습니다.문서의 표현("지연 이자", "가용률")으로 바꾸거나 시맨틱 검색을 씁니다.

응용 과제​

  1. 같은 질문을 AI 답변을 켠 채 하이브리드 검색으로 바꿔 실행하고 답변이 달라지는지 봅니다.
  2. 사이드바 실험 > RAG 진단에서 같은 질문을 넣고 실행해, 재작성된 질문, 단계별 소요 시간, 최종 프롬프트를 확인합니다(실험: RAG 진단).
  3. "3분기에 목표에 못 미친 지역은?"을 물어 근거 문서가 보고서 초안 .docx와 .doc 두 개로 나오는지 보고, 실습 1에서 하나를 지우지 않았다면 결과가 어떻게 겹치는지 확인합니다.
