Deep Connector 컬렉션과 폴더

컬렉션은 문서를 묶는 보관함이자 검색 범위이고, 폴더는 컬렉션을 정리하는 분류입니다. 이 페이지는 컬렉션 목록을 읽는 법, 폴더로 정리하는 법, 컬렉션 설정 탭에서 기본 파이프라인과 검색 방식, AI 답변을 정하는 법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 컬렉션 목록의 열과 버튼이 무엇을 뜻하는지 압니다.
  • 폴더를 만들고 컬렉션을 폴더로 옮깁니다.
  • 컬렉션 이름, 설명, 태그, 기본 파이프라인을 고칩니다.
  • 검색 분석기, 사용자 사전, LLM 검색 보강을 설정합니다.

컬렉션 목록​

사이드바 컬렉션을 누르면 왼쪽에 폴더 트리, 오른쪽에 컬렉션 목록이 나옵니다. 내가 볼 수 있는 컬렉션만 보입니다.

컬렉션 목록과 폴더

번호메뉴기능이런 때 사용하세요
1새 폴더최상위에 새 폴더를 만듭니다.부서별로 컬렉션을 나눌 때
2전체폴더와 관계없이 내가 볼 수 있는 컬렉션을 모두 보여 줍니다. 옆 숫자는 컬렉션 수입니다.어느 폴더에 있는지 모르는 컬렉션을 찾을 때
3폴더누르면 그 폴더의 컬렉션만 보입니다. 왼쪽 화살표로 펼치면 안의 컬렉션이 보입니다.경영지원 폴더의 컬렉션만 볼 때
4태그컬렉션에 붙은 태그로 목록을 좁힙니다."사내규정" 태그가 붙은 컬렉션만 볼 때

컬렉션 목록의 열

번호메뉴기능이런 때 사용하세요
1컬렉션 이름 검색이름 일부로 목록을 좁힙니다.컬렉션이 많을 때
2새 컬렉션새 컬렉션 만들기 화면을 엽니다.새 주제의 문서를 모을 때
3컬렉션 이름이름과 설명입니다. 왼쪽 아이콘은 저장소와 접근 수준을 나타냅니다. 누르면 문서 탭이 열립니다.컬렉션 안의 문서를 볼 때
4태그컬렉션에 붙은 태그입니다. 여러 개면 첫 태그와 남은 개수(예: +1)가 보입니다. 처리 중이거나 실패한 문서가 있으면 오른쪽 처리 상태 열에 건수가 표시되고, 누르면 그 문서만 걸러서 보여 줍니다.컬렉션 용도를 구별하거나 실패한 문서를 바로 찾을 때

행 작업 버튼

번호메뉴기능이런 때 사용하세요
1행 작업 버튼컬렉션 행 오른쪽 끝의 버튼 묶음입니다. 왼쪽부터 아래 네 버튼입니다.컬렉션을 공유·편집·삭제하거나 폴더를 옮길 때
버튼기능이런 때 사용하세요
공유컬렉션의 공유/권한 탭으로 갑니다.동료에게 조회 권한을 줄 때
편집컬렉션 설정 탭으로 갑니다.설명이나 기본 파이프라인을 고칠 때
삭제컬렉션을 지웁니다. 안의 문서와 청크도 함께 사라집니다.연습용 컬렉션을 정리할 때
컬렉션 메뉴폴더로 이동, 접근 수준 변경이 있습니다.컬렉션을 다른 폴더로 옮기거나 공개 범위를 바꿀 때

이름, 문서, 청크 열 머리글을 누르면 그 기준으로 정렬합니다. 관리자에게는 목록 위에 숨김 컬렉션을 함께 보는 버튼이 더 있습니다(아래 "숨김 컬렉션(관리자)").

이럴 때 쓰세요: 컬렉션이 스무 개를 넘으면 김그루 사원은 왼쪽 태그 필터에서 "사내규정"을 골라 규정 관련 컬렉션만 남기고, 처리 상태 열의 "실패" 건수를 눌러 처리에 실패한 문서부터 확인합니다. 에이전트가 근거로 쓰는 운영 컬렉션은 삭제하거나 이름을 바꾸기 전에 담당자와 상의하세요.

새 컬렉션 만들기​

목록 위 새 컬렉션을 누르면 새 컬렉션 화면이 열립니다. 이름, 설명, 위치(폴더), 기본 파이프라인을 채우는 방법은 시작하기에 있습니다. 화면 아래 고급 설정을 펼치면 컬렉션 메타데이터를 미리 넣을 수 있습니다.

새 컬렉션 고급 설정

번호메뉴기능이런 때 사용하세요
1고급 설정메타데이터 입력 구역을 펼치거나 접습니다.컬렉션에 관리 정보를 붙일 때
2필드 추가메타데이터 항목을 하나 추가합니다. 새 항목은 문자열로 저장되고, 숫자·불리언·배열·객체는 타입을 직접 고릅니다."관리부서: 경영지원팀"을 붙일 때
3JSON으로 편집메타데이터를 JSON으로 한꺼번에 적습니다.다른 컬렉션의 메타데이터를 그대로 옮길 때
새 컬렉션 항목뜻기본값
컬렉션 이름목록과 검색에 보일 이름비어 있음(필수)
설명컬렉션 용도. 에이전트가 컬렉션을 고를 때 참고비어 있음
위치(폴더)컬렉션을 둘 폴더분류 없음(맨 위)
기본 파이프라인업로드 때 따로 고르지 않으면 쓰는 처리 방식. 문서를 나누는 방식(청킹)과 표·이미지 처리는 파이프라인이 정합니다.지정 안 함(관리자가 정한 전역 기본 파이프라인을 씀)
메타데이터컬렉션에 붙이는 관리 정보없음
접근 수준누가 볼 수 있는지비공개(만든 뒤 공유/권한 탭에서 바꿈)

문서를 숫자로 바꾸는 임베딩 모델과 벡터 저장소는 배포 전체 설정이라 화면에서 고르지 않습니다. 컬렉션 화면 오른쪽 위 배지(예: qdrant)에서 어느 저장소에 들어 있는지 볼 수 있습니다.

이럴 때 쓰세요: 김그루 사원이 사내 규정 조항을 한 조씩 나눠 검색되게 하고 싶다면, 새 컬렉션을 만들 때 기본 파이프라인으로 "사내 규정 조항 청킹"을 고릅니다. 파이프라인은 Deep Docurator에서 만든 플로우입니다.

폴더 만들기와 정리​

폴더 트리 위 새 폴더를 누르면 아래 창이 열립니다.

새 폴더 창

번호메뉴기능이런 때 사용하세요
1폴더 이름트리에 보일 이름입니다."경영지원"처럼 부서나 용도가 드러나는 이름을 붙일 때
2폴더 설명폴더 용도입니다. 선택 사항입니다.다른 사람이 폴더 용도를 알 수 있게 할 때
3취소만들지 않고 닫습니다.같은 용도의 폴더가 이미 있을 때
4만들기폴더를 만듭니다.이름을 다 적었을 때

폴더에 마우스를 올리면 오른쪽에 폴더 메뉴 버튼이 나옵니다.

폴더 메뉴

번호메뉴기능이런 때 사용하세요
1폴더 메뉴마우스를 올린 폴더의 메뉴입니다. 아래 네 항목이 있습니다.폴더를 나누거나 이름·위치를 바꾸거나 지울 때
메뉴 항목기능이런 때 사용하세요
하위 폴더 만들기이 폴더 안에 폴더를 만듭니다. 폴더는 3단계까지 만들 수 있습니다.경영지원 아래를 "규정"과 "안내"로 나눌 때
이름 변경폴더 이름과 설명을 바꿉니다.조직 개편으로 부서 이름이 바뀌었을 때
이동폴더를 다른 폴더 아래로 옮깁니다.폴더 구조를 다시 정리할 때
삭제폴더를 지웁니다. 하위 폴더도 함께 지워지고, 안의 컬렉션은 "분류 없음"으로 옮겨집니다. 컬렉션은 지워지지 않습니다.쓰지 않는 폴더를 정리할 때

메뉴는 마우스를 올린 폴더(그림에서는 경영지원) 오른쪽에 열립니다. 어느 폴더의 메뉴인지 확인하고 고르세요.

이럴 때 쓰세요: 경영지원팀 자료가 규정과 안내문으로 늘어나면, 경영지원 폴더 메뉴의 하위 폴더 만들기로 "규정"과 "안내"를 만들고 컬렉션을 옮깁니다.

따라 해 보기: 컬렉션을 폴더로 옮기기​

  1. 새 폴더로 "경영지원" 폴더를 만듭니다.
  2. 컬렉션 목록에서 "규정 Q&A" 행 오른쪽 컬렉션 메뉴를 누르고 폴더로 이동을 고릅니다.
  3. 이동할 위치에서 "경영지원"을 고르고 이동을 누릅니다.
  4. 폴더 트리에서 경영지원 옆 숫자가 1로 바뀌었는지 확인합니다.

숨김 컬렉션(관리자)​

숨김 컬렉션은 관리자만 목록에서 볼 수 있는 컬렉션입니다. 일반 사용자에게는 접근 수준이나 공유 여부와 관계없이 컬렉션 목록에 나타나지 않습니다. 관리자가 준비 중인 자료를 정리하거나, 운영에서 잠시 빼 둘 컬렉션을 감출 때 씁니다. 관리자 계정에서만 아래 숨김 체크와 숨김 컬렉션 보기 버튼이 보입니다.

숨김 컬렉션 만들기

번호메뉴기능이런 때 사용하세요
1컬렉션 이름숨길 컬렉션의 이름입니다.–
2숨김"관리자만 볼 수 있습니다." 체크하면 숨김 컬렉션으로 만들어집니다. 이미 있는 컬렉션은 설정 탭의 기본 정보에 있는 같은 체크로 바꿉니다.경영 회의 전까지 보고 초안을 감춰 둘 때
3새 컬렉션 만들기컬렉션을 만듭니다.–

숨김 컬렉션 보기

번호메뉴기능이런 때 사용하세요
1숨김 컬렉션 보기·숨김 컬렉션 가리기눈 모양 버튼입니다. 누르면 숨김 컬렉션을 목록에 함께 보여 주고, 다시 누르면 감춥니다. 처음에는 감춘 상태입니다.숨긴 컬렉션을 찾아 고칠 때
2숨김 컬렉션 행이름 왼쪽 아이콘에 마우스를 올리면 "숨김 컬렉션, 관리자만 볼 수 있습니다."가 나옵니다.숨김 상태인지 확인할 때
설정 항목뜻기본값
숨김관리자만 목록에서 볼 수 있게 함꺼짐
숨김 컬렉션 보기관리자 목록에 숨김 컬렉션을 함께 보여 줌꺼짐(감춘 상태)

이럴 때 쓰세요: 강혁신 팀장은 다음 주 경영 회의 자료를 미리 정리하려고 "임원 보고 준비 자료" 컬렉션을 숨김으로 만듭니다. 회의가 끝나면 설정 탭에서 숨김을 풀고 접근 수준을 정해 직원들에게 엽니다.

컬렉션 설정 탭​

컬렉션을 열고 설정 탭을 누르면 컬렉션의 기본 정보와 검색 방식을 정하는 화면이 나옵니다. 탭은 컬렉션을 고칠 권한이 있는 사람에게 보이고, 그중 아래 "검색 분석기와 사전"과 "LLM 검색 보강" 구역은 컬렉션 소유자에게만 보입니다. 값을 바꾸면 아래에 "변경 사항은 저장을 눌러야 적용됩니다."와 저장 버튼이 나타납니다.

컬렉션 설정 탭(기본 정보)

번호메뉴기능이런 때 사용하세요
1설정 탭컬렉션 설정 화면입니다.컬렉션 정보를 고칠 때
2컬렉션 이름이름을 바꿉니다.용도가 바뀌어 이름을 정리할 때
3설명설명을 바꿉니다. 에이전트가 컬렉션을 고를 때 참고합니다.어떤 질문에 쓰는 컬렉션인지 적어 둘 때
4태그태그를 적고 Enter를 누르면 추가됩니다. 최대 20개입니다.목록에서 태그로 좁혀 볼 수 있게 할 때

컬렉션 설정 탭(메타데이터와 파이프라인)

번호메뉴기능이런 때 사용하세요
1JSON으로 편집컬렉션 메타데이터를 JSON 형식으로 직접 고칩니다.메타데이터를 한꺼번에 붙여 넣을 때
2필드 추가메타데이터 항목을 하나 추가합니다. 새 항목은 문자열로 저장됩니다."관리부서: 경영지원팀"을 붙일 때
3기본 파이프라인업로드 때 따로 고르지 않으면 쓰는 처리 방식입니다.컬렉션 문서를 같은 방식으로 처리하게 할 때
4저장바꾼 내용을 저장합니다.변경을 마쳤을 때

검색 분석기와 사전​

설정 탭 가운데에는 키워드 검색에 쓰는 한국어 분석기와 사전이 있습니다.

컬렉션 설정 탭(검색 분석기)

번호메뉴기능이런 때 사용하세요
1현재 분석기지금 쓰이는 분석기 이름(예: KIWI)입니다.분석기 설정이 적용됐는지 볼 때
2분석기자동 (저장소 권장값), Simple, Kiwi, Nori 중에서 고릅니다.담당자가 분석기 변경을 안내했을 때
3실패 정책분석기를 쓸 수 없을 때 기본 분석기로 대체할지 오류로 처리할지 정합니다.분석기를 바꾼 뒤 동작을 정할 때

컬렉션 설정 탭(사전)

번호메뉴기능이런 때 사용하세요
1사용자 사전분석기가 한 낱말로 봐야 하는 용어를 적습니다. 최대 500개, 용어당 100자입니다."법인카드"가 "법인"과 "카드"로 쪼개져 검색이 어긋날 때
2추가적은 용어를 사용자 사전에 넣습니다.용어를 다 적었을 때
3연결된 사전관리자가 만든 용어 사전을 이 컬렉션에 연결합니다. 최대 8개이며 먼저 나열된 사전이 우선합니다."법카"로 "법인카드"까지 찾게 할 때

분석기를 바꾼 뒤에는 "분석기 변경을 기존 문서에 반영하려면 재색인이 권장됩니다."라는 안내가 나옵니다. 기존 문서에도 적용하려면 반복 업무의 다시 적재를 하세요. 용어 사전을 만드는 방법은 관리자: 검색과 AI에 있습니다.

LLM 검색 보강​

설정 탭 맨 아래에서는 검색 전에 질문을 다듬거나, 검색 결과로 답변 문장을 만드는 기능을 켭니다.

컬렉션 설정 탭(LLM 커넥션)

번호메뉴기능이런 때 사용하세요
1개인정보 안내"청크는 저장 시점에 가명화되어 전송됩니다. 다만 사용자가 입력한 질의는 그대로 전송됩니다."질문에 개인정보를 넣지 않도록 확인할 때
2커넥션 ID관리자가 만든 LLM 커넥션의 ID를 적습니다. 컬렉션 소유자가 속한 팀스페이스의 커넥션만 쓸 수 있습니다.담당자에게 받은 커넥션 ID를 넣을 때
3연결 해제커넥션 연결을 지웁니다.AI 답변 기능을 끌 때
4조직으로 커넥션 찾기조직 ID로 쓸 수 있는 커넥션 목록을 조회합니다. 관리자 권한이 필요할 수 있습니다.ID를 모를 때

컬렉션 설정 탭(LLM 검색 보강 옵션)

번호메뉴기능이런 때 사용하세요
1질의 재작성 사용검색 전에 질문을 검색하기 좋은 문장으로 바꿉니다.짧거나 구어체인 질문이 잘 검색되지 않을 때
2AI 답변 생성 사용검색 결과로 답변 문장까지 만듭니다.Deep Connector 안에서 답변 초안을 보고 싶을 때
3답변에 사용할 최대 청크 수 (1~20)답변을 만들 때 참고할 청크 수입니다.답이 짧거나 근거가 부족할 때 늘릴 때

커넥션을 연결하지 않으면 재작성과 답변 옵션을 켤 수 없습니다. 값을 바꾸면 화면 아래에 저장 버튼이 나타나므로 눌러서 저장합니다. 다른 팀스페이스의 커넥션 ID를 넣고 저장하면 "컬렉션 정보는 저장됐지만 검색 분석기 설정 저장에 실패했습니다."가 나옵니다. 이때는 담당자에게 내 팀스페이스용 커넥션 ID를 받으세요. 커넥션 ID는 그림처럼 화면 공유나 캡처에서 가려 두는 것이 좋습니다.
