Deep Connector 실험: RAG 평가

사이드바 실험 > RAG 평가는 질문과 기대 답을 모은 데이터셋(CSV)을 컬렉션에 한꺼번에 돌려 결과를 Excel·CSV로 받는 화면입니다. 규정이 바뀔 때마다 같은 질문 묶음으로 점검하면 품질이 떨어졌는지 바로 알 수 있습니다.

이 페이지에서 할 수 있는 일

  • 평가 데이터셋을 만들고 질문 CSV를 올립니다.
  • 데이터셋을 컬렉션에 돌려 채점하고 결과를 내려받습니다.
  • 지난 실행 결과와 비교합니다.

화면 구성​

RAG 평가 화면

번호메뉴기능이런 때 사용하세요
1새로 만들기새 평가 데이터셋을 만듭니다. 이름과 설명을 적습니다.자주 묻는 질문 묶음을 만들 때
2데이터셋 목록만든 데이터셋이 쌓입니다. 다른 사람의 데이터셋은 내 데이터셋으로 복사로 가져옵니다.지난 데이터셋을 고를 때
3데이터셋 내용데이터셋을 고르면 CSV 형식 안내, 항목, CSV 업로드가 나옵니다. 템플릿 받기로 CSV 양식을 받습니다. 목록의 복사·삭제 버튼으로 데이터셋을 복사하거나 지웁니다.질문 목록을 올릴 때

데이터셋을 고르고 CSV 파일을 고르면 읽은 내용이 미리 보입니다. 확인한 뒤 올립니다.

데이터셋 CSV 올리기

번호메뉴기능이런 때 사용하세요
1CSV 파일올릴 CSV 파일을 고릅니다. 한 데이터셋에 최대 2,000행, 파일 5 MiB까지입니다. 엑셀에서는 CSV UTF-8로 저장합니다.질문 목록을 준비했을 때
2읽은 결과읽은 행 수와, 기존 항목이 교체되는지 알려 줍니다. 아래 표에서 질문, 기대 답, 근거 문서를 미리 봅니다.열 이름이 맞게 읽혔는지 확인할 때
3업로드·전량 교체항목을 저장합니다. 이미 항목이 있는 데이터셋이면 전량 교체로 바뀌고, 기존 항목이 모두 새 파일 내용으로 바뀝니다.미리보기를 확인했을 때

평가 실행 설정

번호메뉴기능이런 때 사용하세요
1실행 대상 컬렉션평가를 돌릴 컬렉션입니다.개정 전·후 컬렉션을 같은 질문으로 비교할 때
2검색 파라미터누르면 아래 설정을 펼치거나 접습니다. 옆에 지금 고른 검색 방식이 요약으로 보입니다.평가 조건을 확인할 때
3검색 방식·결과 수·점수 컷·리랭킹검색 방식, 결과 수, 점수 컷, 리랭킹을 정합니다.조건별로 결과를 비교할 때
4실행평가를 실행합니다. 데이터셋을 고르기 전에는 누를 수 없습니다.데이터셋과 컬렉션을 정했을 때

실행 이력

번호메뉴기능이런 때 사용하세요
1실행 이력지난 실행이 쌓입니다. 상태, 성공·실패 건수, 점수를 보고 결과를 xlsx·csv로 내려받습니다.지난달 결과와 비교할 때

실행이 끝나면 실행 이력에서 채점하고 결과를 내려받습니다.

실행 이력과 채점

번호메뉴기능이런 때 사용하세요
1점수채점 결과입니다. 그림은 검색만 채점으로 기대 근거 문서가 상위 5개 안에 모두 들어온 결과(hit@5 100%)입니다.근거 문서가 검색되는지 한눈에 볼 때
2채점·검색만 채점채점은 검색 점수와 LLM 판정을 함께 매기고, 검색만 채점은 LLM 판정 없이 hit@k·MRR·어휘 점수만 매깁니다. 검색만 매긴 실행에는 판정을 더하는 채점만 남습니다.LLM 커넥션 없이 검색 품질만 볼 때
3xlsx·csv질문별 답변, 근거, 소요시간을 파일로 받습니다.결과를 팀에 공유할 때
4복사해서 실행데이터셋을 내 것으로 복사하고 같은 조건으로 실행 폼을 채웁니다.다른 사람의 평가를 내 컬렉션에 다시 돌릴 때

데이터셋 CSV는 question 열이 필수이고, expected_answer(기대 답), expected_source(기대 근거 문서) 같은 열을 함께 적을 수 있습니다. 근거 문장으로 적중을 재려면 expected_chunk, 근거가 여럿이면 expected_chunks와 evidence_mode(all 또는 any, 기본 all)를 씁니다. 화면의 템플릿 받기로 전체 양식을 받습니다. 예시는 다음과 같습니다(첫 줄은 이 매뉴얼에서 제품 매뉴얼 컬렉션에 실제로 돌린 "제품 매뉴얼 자주 묻는 질문" 데이터셋의 항목입니다).

questionexpected_answerexpected_source
처음 쓰기 전에 몇 시간 충전해야 하나요?USB-C 케이블로 2시간브레인노트-S2-빠른시작.html
국내 당일 출장 일비는 얼마인가요?15,000원(일비의 50%)출장비-지급-규정.pdf
재택근무는 언제까지 신청해야 하나요?전주 금요일 18시까지재택근무-운영-지침.docx
업무 식대는 1인 얼마까지 인정되나요?25,000원경비-처리-기준.hwp

실험 공간 안내대로 데이터셋과 결과는 모든 사용자에게 공개됩니다. 실제 고객 문의나 개인정보를 넣지 마세요.

설정 항목과 기본값​

항목뜻기본값
실행 대상 컬렉션평가를 돌릴 컬렉션직접 고름
검색 방식semantic(의미), keyword, hybrid컬렉션 검색 설정, 없으면 semantic
결과 수질문마다 가져올 청크 수컬렉션 검색 설정, 없으면 5
점수 컷이보다 낮은 점수의 결과를 뺌0
리랭킹결과 순서를 다시 매길지꺼짐
데이터셋 크기한 데이터셋의 행 수와 파일 크기최대 2,000행, 5 MiB
evidence_mode근거가 여럿일 때 적중 기준all(모두 찾아야 적중)

이럴 때 쓰세요: 고객센터에서 녹음기 사용법 문의가 늘자 김그루 사원은 자주 묻는 질문 5개로 "제품 매뉴얼 자주 묻는 질문" 데이터셋을 만들어 제품 매뉴얼 컬렉션에 돌렸고, 검색만 채점에서 hit@5 100%를 확인했습니다. 사내 규정은 매월 첫 주에 "규정 Q&A 월간 점검" 데이터셋을 같은 방법으로 돌립니다. 지난달보다 점수가 떨어진 질문이 있으면 그 질문을 RAG 진단에 넣어 원인을 봅니다.
