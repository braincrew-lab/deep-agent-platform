Deep Connector 실습 1: 컬렉션 만들고 여러 형식 문서 올리기

이 실습은 김그루 사원이 주간 업무 보고에 자주 꺼내 보는 팀 자료를 "AI혁신팀 업무 자료" 컬렉션 하나에 모으는 과정입니다. 형식이 다른 파일 12개를 한 번에 올리고, 어떤 파일이 들어가고 어떤 파일이 빠지는지, 빠진 파일은 어디서 이유를 보는지 확인합니다. 화면 각 부분의 자세한 설명은 컬렉션과 폴더와 문서 올리기에 있으므로, 이 페이지는 손동작과 결과에 집중합니다.

이 페이지에서 할 수 있는 일

  • 새 컬렉션을 만들고 기본 파이프라인을 정합니다.
  • 서로 다른 형식의 파일 12개를 한 번에 고르고 확인 결과를 읽습니다.
  • 업로드 대기열에서 올라가지 못한 파일과 그 이유를 찾습니다.
  • 처리가 끝난 문서 목록에서 청크 수와 처리 실패 표시를 읽습니다.

목표​

항목내용
만들 것컬렉션 "AI혁신팀 업무 자료"
결과물처리가 끝난 문서 9개(청크 36개), 처리 실패 1개, 올라가지 못한 파일 2개
걸리는 시간10분(처리 대기 2분 포함)
난이도★☆☆☆☆

준비물​

실습 묶음 안내의 "연습 파일 만들기"에 있는 파일 12개를 한 폴더에 둡니다.

파일형식이 실습에서 확인할 것
회의록_AI업무혁신_20261110.html웹 문서로 저장한 회의록이 처리되는지
회의록_AI업무혁신_20261110.txt지원하지 않는 형식이 어떻게 빠지는지
3분기_영업실적_보고서_초안.docx, .doc새 형식과 옛 형식 워드가 모두 처리되는지
AI업무혁신_추진현황.pptx슬라이드가 쪽 단위로 읽히는지
브레인크루_판매데이터_2026.xlsx, .xls엑셀 표가 처리되는지, 옛 형식 엑셀은 어떻게 되는지
서비스이용계약서_샘플.pdfPDF 조항이 처리되는지
계약서_스캔본.png이미지 속 글자가 읽히는지
제품소개서_사진.jpg사진 속 글자가 읽히는지
시장조사_메모.md짧은 메모가 처리되는지
고객만족도_설문_2026Q4.csv지원하지 않는 형식이 어떻게 빠지는지

Deep Connector가 받는 확장자는 .pdf, .png, .jpg, .jpeg, .webp, .tiff, .tif, .bmp, .doc, .docx, .pptx, .md, .html, .htm, .xlsx, .xls, .hwp, .hwpx의 18가지입니다. .txt, .csv, .ppt는 받지 않습니다.

1단계. 새 컬렉션 만들기​

사이드바 컬렉션을 누르고 오른쪽 위 새 컬렉션을 누릅니다.

새 컬렉션 화면

번호메뉴입력하거나 고를 값
1컬렉션 이름AI혁신팀 업무 자료
2설명주간 회의록, 분기 보고서 초안, 추진 현황, 판매 데이터, 계약서 등 AI혁신팀 주간 업무 보고에 쓰는 자료 모음 (가상 자료)
3기본 파이프라인기본 파이프라인
4새 컬렉션 만들기입력을 마치면 누릅니다.
설정 항목이 실습의 값기본값
위치(폴더)분류 없음분류 없음
기본 파이프라인기본 파이프라인지정 안 함(관리자가 정한 전역 기본 파이프라인을 씀)
고급 설정(메타데이터)비워 둠없음
접근 수준비공개비공개
  1. 컬렉션 이름과 설명을 위 표대로 적습니다. 설명은 나중에 에이전트가 이 컬렉션을 고를 때 읽는 문장이므로 어떤 자료가 들어 있는지 구체적으로 적습니다.
  2. 기본 파이프라인을 눌러 "기본 파이프라인"을 고릅니다.
  3. 새 컬렉션 만들기를 누릅니다. "컬렉션이 성공적으로 생성되었습니다"가 나오고 빈 문서 탭이 열립니다.

2단계. 파일 12개를 한 번에 고르기​

문서 탭 오른쪽 위 문서 업로드를 누르고 파일 추가로 준비한 파일 12개를 한 번에 고릅니다. 가운데 영역에 끌어다 놓아도 됩니다.

파일을 고른 뒤의 업로드 화면

번호메뉴확인할 것
1확인 결과"전체 12개 중 12개 업로드 (519.9 KB), 제외 0개" 아래에 "확인이 끝났습니다. 업로드할 수 있습니다."가 나옵니다.
2고객만족도_설문_2026Q4.csv 행상태가 "확인됨"입니다.
3회의록_AI업무혁신_20261110.txt 행상태가 "확인됨"입니다.
4문서 업로드 (12)고른 파일 수가 버튼에 붙습니다.

여기서 "확인됨"은 같은 내용의 문서가 컬렉션에 이미 있는지까지 확인했다는 뜻이고, 처리할 수 있는 형식이라는 뜻은 아닙니다. 이 매뉴얼의 시연 환경은 업로드 화면이 .txt와 .csv도 받도록 설정되어 있어 두 파일이 "확인됨"으로 보입니다. 화면 설정에 따라서는 같은 파일이 처음부터 "지원하지 않는 형식"으로 제외되고 제외된 항목 필터에 모입니다. 어느 쪽이든 두 파일은 컬렉션에 들어가지 않습니다(3단계).

  1. 목록 위에 "확인이 끝났습니다. 업로드할 수 있습니다."가 나올 때까지 기다립니다.
  2. 오른쪽 파이프라인이 "기본 파이프라인 (기본)"인지 봅니다. 1단계에서 정한 컬렉션 기본값입니다.
  3. 업로드만 하기는 체크하지 않습니다.
  4. **문서 업로드 (12)**를 누릅니다.

3단계. 업로드 대기열에서 빠진 파일 확인하기​

업로드를 누르면 문서 목록으로 돌아가고 "12개 파일을 업로드 대기열에 넣었습니다."가 나옵니다. 몇 초 뒤 "최근 업로드 실패 2건 — 파일별 실패 사유는 업로드 대기열에서 확인할 수 있습니다."가 이어서 나옵니다.

업로드 대기열의 실패 사유

번호메뉴확인할 것
1문서 수12개 중 10개만 목록에 들어왔습니다("총 10개").
2업로드 실패 (2건)화면 오른쪽 아래 문서 업로드 대기열 창입니다. 접혀 있으면 펼치기를 누릅니다. 실패 목록 지우기로 기록을 비웁니다.
3실패한 파일과 사유.txt는 "unsupported file type (mime=text/plain)", .csv는 "unsupported file type (mime=text/csv)"입니다. 서버가 처리할 수 없는 형식이라 받지 않았다는 뜻입니다.
4처리 실패 표시목록에는 들어왔지만 처리에 실패한 문서입니다. 4단계에서 봅니다.

.txt와 .csv가 문서 목록에 보이지 않는 이유가 이것입니다. 내용이 필요하면 형식을 바꿔 다시 올립니다.

올리지 못한 형식바꿔 올릴 형식방법
.txt.md 또는 .html메모장에서 다른 이름으로 저장하며 확장자를 .md로 바꿉니다. 이 실습의 회의록은 .html이 이미 올라갔으므로 다시 올리지 않습니다.
.csv.xlsx엑셀에서 열고 "Excel 통합 문서"로 저장합니다.
.ppt.pptx파워포인트에서 "PowerPoint 프레젠테이션"으로 저장합니다.

4단계. 처리 결과 확인하기​

1~2분 기다린 뒤 문서 목록을 새로 고칩니다.

처리가 끝난 문서 목록

번호메뉴확인할 것
1문서 수총 10개입니다. 탭의 "문서 9"는 처리가 끝나 검색에 쓰이는 문서 수입니다.
2미처리 1건 적재업로드만 하고 처리하지 않은 문서와 처리에 실패한 문서를 한꺼번에 다시 처리합니다. 마우스를 올리면 몇 건씩인지 나옵니다.
3처리 실패 표시브레인크루_판매데이터_2026.xls 옆 경고 표시입니다. 누르면 "적재 실패 — 오류 상세" 창이 열리고 "Unsupported format: .xls — convert to .xlsx and retry"가 보입니다. 행 오른쪽 버튼은 재시도로 바뀌어 있습니다.
4처리된 문서같은 데이터의 .xlsx는 청크 21개로 처리됐습니다.

이 실습에서 확인한 형식별 결과입니다.

파일청크페이지결과

제품소개서_사진.jpg2–완료. 사진 속 글자를 읽었습니다.

  1. 청크 수가 0보다 크고 경고 표시가 없으면 처리가 끝난 것입니다.
  2. .xls 행의 경고 표시를 눌러 오류 내용을 읽고 확인으로 닫습니다.
  3. .xlsx가 이미 처리됐으므로 .xls 행은 휴지통(삭제)으로 지웁니다. 같은 데이터가 두 번 들어가면 검색 결과에 같은 내용이 겹쳐 나옵니다. .doc와 .docx도 같은 내용이지만, 이 매뉴얼은 겹친 결과가 어떻게 보이는지 실습 3에서 확인하려고 둘 다 남겨 둡니다.

결과​

  • 컬렉션 "AI혁신팀 업무 자료"에 문서 9개, 청크 36개가 들어갔습니다.
  • .txt와 .csv는 업로드 대기열에서 "unsupported file type"으로 빠졌고, .xls는 목록에 들어왔지만 처리에 실패했습니다.

흔한 실수​

증상원인해결
올린 .txt 파일이 문서 목록에 없음Deep Connector가 처리하지 않는 형식입니다. 업로드 화면에서 "확인됨"으로 보였어도 서버가 받지 않습니다.업로드 대기열의 실패 사유를 확인하고 .md나 .html로 바꿔 올립니다.
문서 업로드 버튼이 눌리지 않음파일 확인이 아직 끝나지 않았거나 사용량 한도에 닿았습니다."확인이 끝났습니다"가 나올 때까지 기다립니다. 한도는 문제 해결을 봅니다.
업로드 직후 다른 메뉴로 가자 경고가 나옴파일 전송이 끝나지 않았습니다.큰 파일은 대기열의 업로드 중 건수가 0이 될 때까지 화면을 그대로 둡니다.
같은 표가 검색 결과에 두 번 나옴.xls와 .xlsx, .doc와 .docx처럼 같은 내용을 두 형식으로 올렸습니다.한 형식만 남기고 지웁니다.

응용 과제​

  1. 회의록 .txt를 .md로 바꿔 올려 보고, 이미 있는 .html 회의록과 내용이 같을 때 확인 결과가 어떻게 나오는지 봅니다.
  2. 고객만족도 설문 .csv를 .xlsx로 저장해 올리고 청크 수를 확인합니다.
  3. 업로드만 하기를 체크하고 파일 하나를 올린 뒤, 문서 목록의 미처리 1건 적재로 처리를 시작해 봅니다.
