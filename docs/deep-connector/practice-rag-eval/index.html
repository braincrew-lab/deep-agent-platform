Deep Connector 실습 4: RAG 평가로 한꺼번에 점검하기

검색 화면에서 질문을 하나씩 넣어 보는 것만으로는 컬렉션이 자주 묻는 질문에 모두 잘 답하는지 알기 어렵습니다. 이 실습은 "AI혁신팀 업무 자료" 컬렉션에서 자주 찾는 사실 6개를 CSV 파일 하나로 묶어 평가 데이터셋을 만들고, 한 번에 실행해 채점한 뒤 결과 파일을 내려받습니다. RAG 평가 화면의 모든 버튼과 CSV 열 설명은 실험: RAG 평가에 있습니다.

이 페이지에서 할 수 있는 일

  • 평가 데이터셋을 만들고 질문 CSV를 올립니다.
  • 데이터셋을 컬렉션에 실행하고 채점합니다.
  • 점수를 읽고 결과를 xlsx나 csv로 받습니다.

목표​

항목내용
만들 것데이터셋 "AI혁신팀 업무 자료 점검"(6문항)
결과물실행 1건(성공 6, 실패 0), 점수 "정답 100% · hit@5 100%", 결과 파일
걸리는 시간준비 10분, 실행과 채점 1분
난이도★★★☆☆

준비물​

파일내용형식
AI혁신팀_업무자료_점검질문question(질문), expected_answer(기대 답), expected_source(기대 근거 문서) 세 열과 질문 6행.csv

데이터셋으로 올릴 수 있는 형식은 .csv 하나입니다. 엑셀에서 작성했다면 "CSV UTF-8(쉼표로 분리)"로 저장합니다. 첫 줄의 열 이름은 영문으로 적습니다. 한 데이터셋은 2,000행, 파일 5 MiB까지입니다.

expected_source에는 문서 목록에 보이는 파일 이름을 확장자까지 그대로 적습니다. 질문을 만들기 어려우면 실습 2에서 본 청크의 예상 질문(hypothetical_questions)을 참고합니다.

1단계. 데이터셋 만들기​

사이드바 실험 > RAG 평가를 열고 왼쪽 새로 만들기를 누릅니다.

새 데이터셋 창

번호메뉴입력하거나 고를 값
1이름AI혁신팀 업무 자료 점검
2설명 (선택)회의록·보고서·계약서·시장 메모에서 자주 찾는 사실 6문항 (가상 자료)
3만들기입력을 마치면 누릅니다.
  1. 이름과 설명을 적고 만들기를 누릅니다.
  2. 왼쪽 데이터셋 목록에 "AI혁신팀 업무 자료 점검 — 0개 항목"이 생기고, 가운데에 CSV 형식 안내와 "항목이 없습니다. CSV를 올려 주세요."가 나옵니다.

2단계. 질문 CSV 올리기​

가운데 CSV 파일 칸에서 준비한 파일을 고르면 읽은 내용이 미리 보입니다.

CSV 미리보기

번호메뉴확인할 것
1CSV 파일고른 파일 이름이 보입니다.
2읽은 결과"6개 행을 읽었습니다." 행 수가 파일과 같은지 봅니다.
3expected_source 열기대 근거 문서 이름이 제 열에 들어갔는지 봅니다. 한글이 깨졌다면 CSV UTF-8로 다시 저장합니다.
4업로드미리보기를 확인했으면 누릅니다. 이미 항목이 있는 데이터셋이면 전량 교체로 바뀝니다.
  1. CSV 파일 칸을 눌러 파일을 고릅니다.
  2. 미리보기 표에서 질문, 기대 답, 기대 근거 문서가 각자 열에 들어갔는지 봅니다. 쓰지 않은 열(expected_chunk, evidence_mode, note)은 "—"로 보입니다.
  3. 업로드를 누릅니다. "6개 항목으로 교체했습니다."가 나오고 목록의 항목 수가 6으로 바뀝니다.

3단계. 컬렉션에 실행하기​

화면 아래 실행 구역에서 컬렉션을 고르고 실행합니다.

평가 실행

번호메뉴입력하거나 고를 값
1실행 대상 컬렉션AI혁신팀 업무 자료
2검색 파라미터펼쳐서 검색 방식과 결과 수를 확인합니다. 이 실습은 그대로 둡니다.
36건 실행데이터셋 항목 수가 버튼에 붙습니다.
설정 항목이 실습의 값기본값
검색 방식semantic (의미)semantic (의미)
결과 수55
점수 컷00
리랭킹꺼짐꺼짐
  1. 실행 대상 컬렉션에서 "AI혁신팀 업무 자료"를 고릅니다.
  2. 6건 실행을 누릅니다.
  3. 아래 실행 이력에 새 행이 생기고 상태가 "성공", 성공/실패가 "6/0"이 될 때까지 기다립니다. 이 매뉴얼에서는 13.8초 걸렸습니다.

4단계. 채점하고 결과 내려받기​

실행이 끝난 행의 점수 칸에는 채점과 검색만 채점 버튼이 있습니다.

버튼하는 일필요한 것
채점기대 근거 문서가 검색 상위 5개 안에 있는지(hit@5)와, 만들어진 답이 기대 답과 맞는지(LLM 판정)를 함께 매깁니다.컬렉션에 연결된 LLM 커넥션(실습 3)
검색만 채점검색 점수(hit@k, MRR, 어휘 점수)만 매깁니다.없음

채점 결과

번호메뉴확인할 것
1상태성공입니다. 옆에 성공/실패 6/0과 걸린 시간 13.8초가 있습니다.
2점수"정답 100% · hit@5 100%"입니다. 6문항 모두 기대 근거 문서가 상위 5개 안에 들었고, 답도 기대 답과 맞았습니다.
3xlsx·csv질문별 답변, 근거, 걸린 시간을 파일로 받습니다.
  1. 새 행의 채점을 누릅니다. 몇 초 뒤 점수 칸이 바뀝니다.
  2. xlsx를 눌러 결과를 받고, 질문별로 근거 문서와 답을 확인합니다.
  3. 점수가 떨어진 질문이 있으면 그 질문을 RAG 진단에 넣어 어느 단계에서 어긋났는지 봅니다.

결과​

  • 데이터셋 "AI혁신팀 업무 자료 점검"(6문항)이 만들어졌고, 첫 실행에서 정답 100%, hit@5 100%가 나왔습니다.
  • 다음에 문서를 바꾸거나 파이프라인을 바꾸면 같은 데이터셋을 다시 실행해 점수를 비교합니다.

흔한 실수​

증상원인해결
미리보기의 한글이 깨짐CSV가 UTF-8이 아닙니다.엑셀에서 "CSV UTF-8(쉼표로 분리)"로 다시 저장합니다.
실행 버튼이 눌리지 않고 "먼저 데이터셋을 고르세요."왼쪽 목록에서 데이터셋을 고르지 않았습니다.데이터셋 이름을 누른 뒤 실행합니다.
"항목이 없습니다. CSV를 먼저 올리세요."파일만 고르고 업로드를 누르지 않았습니다.2단계의 업로드를 누릅니다.
hit@5가 낮음expected_source의 파일 이름이 문서 목록과 다르거나, 같은 내용이 다른 문서에도 있습니다.파일 이름을 확장자까지 맞추고, 겹치는 문서(.doc와 .docx 등)를 정리합니다.
채점을 눌러도 정답 점수가 없음컬렉션에 LLM 커넥션이 없습니다.검색만 채점을 쓰거나 실습 3의 1단계를 합니다.

데이터셋과 실행 결과는 실험 공간의 다른 사용자에게도 공개됩니다. 실제 고객 문의나 개인정보를 질문에 넣지 마세요.

응용 과제​

  1. 검색 파라미터에서 검색 방식을 keyword로 바꿔 한 번 더 실행하고, 두 실행의 점수를 비교합니다.
  2. 데이터셋에 "제품소개서 사진에 나온 주요 기능은 무엇인가요?"를 추가한 CSV로 전량 교체하고 다시 실행해, 사진에서 읽은 글자도 근거로 잡히는지 봅니다.
  3. 동료의 데이터셋 옆 복사 버튼으로 내 데이터셋을 만들고 내 컬렉션에 실행해 봅니다.
