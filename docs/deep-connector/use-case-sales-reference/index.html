Deep Connector 사례: 영업 제안서 레퍼런스 찾기

브레인크루 영업팀은 새 제안서를 쓸 때마다 "비슷한 업종에 무엇을 제안했지?", "그때 일정과 비용은?", "표준 단가는?"을 찾느라 지난 파일을 하나씩 엽니다. 이 사례에서는 지난 제안서와 구축 사례, 단가표를 한 컬렉션에 모으고, 과제나 업종으로 검색해 새 제안서의 근거를 빠르게 모읍니다.

이 페이지에서 할 수 있는 일

  • 슬라이드(.pptx), 문서(.docx, .doc), PDF, 엑셀(.xlsx)을 한 컬렉션에 올립니다.
  • 하이브리드 검색으로 비슷한 지난 제안을 찾습니다.
  • 찾은 제안서의 일정과 비용을 답변으로 정리하고, 컬렉션을 제한 공개로 운영합니다.

목표​

항목내용
누가영업 담당(검색), 김그루 사원(컬렉션 담당)
무엇을지난 제안서 세 건, 구축 사례 요약, 표준 단가표를 "영업 제안서 레퍼런스" 컬렉션에 올립니다
끝났다고 볼 기준"문서 검색 구축 비용과 기간"을 검색했을 때 누리제약 제안서의 일정과 구축비가 나오는 것
걸리는 시간30분 정도

준비물​

파일확장자내용
제안서-가온물류-업무자동화.pptx.pptx배차 입력 자동화 제안. 하루 3시간을 20분으로, 오기입 90% 감소, 구축비 4,800만원
제안서-누리제약-사내문서검색.docx.docx품질 문서 1,200건 검색 구축 제안. 파일럿 4주, 확산 6주, 구축비 6,500만원, 연 구독료 1,800만원
제안서-다솜유통-고객센터-2025.doc.doc예전 형식 Word 문서. 상담 시간 6분 → 4분 목표, 구축비 3,900만원
구축사례-요약-2026.pdf.pdf다솜유통 고객센터, 가온물류, 한결회계법인 세 사례의 성과 수치
표준-견적-단가표.xlsx.xlsx컬렉션 구축 300만원, 문서 처리 1,000건당 80만원, 에이전트 구축 1,200만원 등

고객사 이름과 수치는 모두 매뉴얼 시연용 가상 자료입니다.

단계​

1. 컬렉션 만들고 자료 올리기​

  1. 새 컬렉션에서 이름 "영업 제안서 레퍼런스", 설명 "지난 제안서·구축 사례·표준 단가표"로 만듭니다. 설명은 에이전트가 이 컬렉션을 고를 때 참고하므로 구체적으로 적습니다.
  2. 문서 업로드에서 다섯 파일을 올립니다. 업종이나 연도로 좁혀 찾고 싶다면 파일 행을 펼쳐 파일별 메타데이터에 "업종: 제약", "연도: 2026"처럼 붙입니다.

영업 제안서 레퍼런스 컬렉션의 문서 목록

번호항목화면에서 볼 것
1문서 이름슬라이드, PDF, 예전 형식 Word(.doc), 엑셀, Word(.docx)가 모두 올라왔는지 봅니다.
2청크 수다섯 파일 모두 청크가 만들어졌습니다.
3청크 탭단가표 행이 청크에 표 그대로 들어갔는지 봅니다.

2. 비슷한 제안 찾기​

실험 > 검색에서 "영업 제안서 레퍼런스"를 고르고 하이브리드 검색으로 과제를 적습니다. 제안서는 고유 명사와 숫자가 많아 문장 검색과 낱말 검색을 함께 쓰는 하이브리드가 잘 맞습니다.

하이브리드 검색 결과

번호항목화면에서 볼 것
1컬렉션"영업 제안서 레퍼런스"입니다.
2검색 방식하이브리드 검색입니다.
3검색어"문서 검색 구축 비용과 기간"
4첫 결과누리제약 제안서 청크가 첫 결과입니다. 아래로 같은 제안서의 다른 청크와 다솜유통 제안서(.doc)가 이어집니다.

3. 제안 근거 정리하기​

RAG 진단에서 정리를 부탁하면 근거 문서 이름이 붙은 요약을 받을 수 있습니다.

프롬프트: 제약사에 사내 문서 검색을 제안할 때 참고할 지난 제안의 일정과 비용, 표준 단가를 정리해 줘.

영업 제안서 레퍼런스 답변

번호항목화면에서 볼 것
1컬렉션"영업 제안서 레퍼런스"입니다.
2질의새 제안의 상황을 적었습니다.
3답변누리제약 사내 문서 검색 제안을 "일정: 파일럿 4주(품질팀 30명), 확산 6주 / 구축비: 6,500만원 / 연 구독료: 1,800만원"으로 정리하고, 근거 문서 "제안서-누리제약-사내문서검색.docx"가 나옵니다.

이 예의 답변에는 표준 단가가 빠졌습니다. 질문 하나에 여러 가지를 함께 물으면 일부만 답할 수 있으므로, 단가는 "표준 견적 단가표에서 문서 처리 단가는?"처럼 따로 묻거나 max_context_chunks를 늘려 다시 실행합니다.

4. 영업팀에 열기​

제안서에는 고객사 정보가 들어 있으므로 공유/권한 탭에서 접근 수준을 제한으로 두고, 영업팀 구성원에게 Level1: 조회를 줍니다. 다른 부서 직원은 필요할 때 접근 요청으로 사유를 적어 요청합니다(권한·공유·접근 요청 참고).

결과물 예시​

새 제안서 "제약사 사내 문서 검색" 초안에 넣을 레퍼런스 표입니다.

항목내용근거
유사 레퍼런스누리제약 품질 문서 검색(파일럿 4주, 확산 6주)제안서-누리제약-사내문서검색.docx
비용 기준구축비 6,500만원, 연 구독료 1,800만원같은 문서
성과 사례고객센터 상담 시간 6분 → 4분구축사례-요약-2026.pdf
단가문서 처리 1,000건당 80만원표준-견적-단가표.xlsx

응용 팁​

  • 수주 결과나 고객 반응을 파일별 메타데이터("결과: 수주")로 붙여 두면 성공한 제안만 골라 찾을 수 있습니다.
  • 단가표가 바뀌면 새 버전 업로드로 교체해, 옛 단가가 답에 섞이지 않게 합니다.
  • 오래된 .doc 파일은 그대로 올려도 되지만, 표가 깨져 보이면 .docx로 저장해 다시 올립니다.
