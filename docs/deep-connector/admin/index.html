Deep Connector 관리자 메뉴

Deep Connector 관리자로 로그인하면 사이드바 아래쪽에 관리자 묶음이 보입니다. 이 페이지는 AI혁신팀 강혁신 팀장(Deep Connector 관리자)이 자주 쓰는 화면, 곧 대시보드, 적재 현황, 사용자 할당량, 용어 사전, LLM 커넥션을 설명합니다. 일반 사용자에게는 이 메뉴가 보이지 않습니다.

이 페이지에서 할 수 있는 일

  • 관리자 메뉴 구성을 알고 원하는 화면으로 이동합니다.
  • 대시보드와 적재 현황에서 문서 처리 상황을 봅니다.
  • 사용자와 팀스페이스의 저장공간·업로드 한도를 조정합니다.
  • 용어 사전을 만들고 CSV로 용어를 한꺼번에 넣습니다.

관리자 메뉴 구성​

묶음메뉴하는 일
–대시보드전체 문서 수, 저장공간, 할당량 경고, 최근 14일 사용량 추이
–적재 현황문서 처리 성공·실패 통계와 문서별 처리 기록
사용자와 팀스페이스사용자사용자별 사용량과 할당량
팀스페이스팀스페이스(부서)별 사용량과 할당량
컬렉션 권한컬렉션별 접근 권한과 접근 요청 승인(사용하는 인증 방식에 따라 보이지 않을 수 있음)
검색과 AI용어 사전동의어·별칭 사전 관리
메타데이터 관리, 컬렉션 태그문서 메타데이터 항목과 컬렉션 태그 관리
LLM 커넥션질의 재작성·AI 답변에 쓸 언어 모델 연결
MCP 도구, 도구 평가에이전트에 제공하는 검색 도구 설명과 품질 점검
시스템저장공간, 감사 로그, 브랜드 설정, 시스템 설정저장 용량 모니터링, 작업 기록, 화면 로고·색, 원본 링크 유효시간 같은 설정

대시보드​

관리자 대시보드

번호메뉴기능이런 때 사용하세요
1전체 문서모든 컬렉션의 문서 수입니다.도입 초기 문서가 얼마나 들어왔는지 볼 때
2전체 저장공간문서가 차지하는 저장 용량입니다.용량 증설 시기를 가늠할 때
3할당량 경고한도에 가까워졌거나 넘은 사용자 수입니다.업로드가 막힌 사용자를 찾을 때
4사용량 추이최근 14일 동안 날마다 업로드·삭제 건수와 늘어난 용량입니다.대량 업로드가 있었던 날을 확인할 때

사이드바 아래쪽 관리자 묶음(대시보드, 적재 현황, 사용자와 팀스페이스, 검색과 AI, 시스템)에서 다른 관리 화면으로 갑니다.

적재 현황​

모든 컬렉션의 문서 처리 기록을 한 화면에서 봅니다. 실패한 문서를 찾아 원인을 확인하는 데 씁니다.

적재 현황

번호메뉴기능이런 때 사용하세요
1문서·배치·설정문서별 기록, 업로드 묶음(배치)별 기록, 처리 설정 탭입니다.한 번에 올린 묶음 단위로 볼 때
2기간1시간부터 30일, 직접 지정, 기간 무관 중에서 고릅니다.어제 밤 처리분만 볼 때
3처리 요약적재 실패, 적재 중(그중 멈춤), 완료, 전체 건수와 비율입니다.실패율이 오르지 않았는지 볼 때
4새로고침최신 상태로 다시 불러옵니다.처리 중인 문서를 지켜볼 때

시각별 추이와 문서 목록

번호메뉴기능이런 때 사용하세요
1시각별 추이처리 시작 시각별 건수입니다. 아래 탭에서 실패 사유별, 컬렉션별 실패 상위 10을 봅니다.실패가 몰린 시간이나 컬렉션을 찾을 때
2문서 목록파일명, 컬렉션, 상태, 요청·시작·완료 시각, 시도 횟수입니다. 필터와 파일명 검색으로 좁힙니다.특정 파일의 처리 과정을 추적할 때
3CSV 내보내기목록을 CSV 파일로 내려받습니다.월간 처리 실적을 보고할 때

사용자와 할당량​

사용자와 팀스페이스 > 사용자에서 사용자별 사용량을 보고 한도를 바꿉니다.

사용자 목록

번호메뉴기능이런 때 사용하세요
1일괄 할당량 설정여러 사용자의 한도를 한꺼번에 바꿉니다.부서 전체의 월간 업로드 한도를 올릴 때
2이메일로 검색사용자를 찾습니다.문의한 사용자를 찾을 때
3저장공간쓴 용량과 한도입니다.용량이 찬 사용자를 찾을 때
4월간 업로드이번 달 업로드 건수와 한도입니다.업로드가 막힌 사용자를 찾을 때

행 오른쪽 상세를 누르면 그 사용자의 상세 화면과 할당량 설정이 열립니다. 한 사람의 한도를 바꿀 때 씁니다.

사용자 상세와 할당량 설정

번호메뉴기능이런 때 사용하세요
1기본 정보이메일, 이름, 마지막 로그인, 상태입니다.계정이 활성인지 볼 때
2저장공간 할당량이 사용자가 쓸 수 있는 저장 용량입니다.큰 파일을 많이 올리는 담당자의 한도를 늘릴 때
3업로드 크기 제한파일 하나의 최대 크기입니다.대용량 스캔본을 올려야 할 때
4현재 사용량저장공간과 월간 업로드 사용량, 아래에 사용 이력이 이어집니다.한도를 얼마나 늘릴지 정할 때

할당량 설정

번호메뉴기능이런 때 사용하세요
1월간 업로드 제한한 달에 올릴 수 있는 파일 수입니다. 제한 없음을 체크하면 한도를 없앱니다.도입 초기에 문서를 대량으로 올릴 때
2동시 업로드 제한한 번에 처리할 수 있는 업로드 수입니다.처리 대기가 길어질 때
3저장바꾼 한도를 저장합니다.변경을 마쳤을 때

사용자 한도와 별개로 팀스페이스 화면에도 팀 단위 저장공간과 월간 업로드 한도가 있습니다. 둘 중 하나라도 닿으면 업로드가 막히므로, 업로드가 막혔다는 문의를 받으면 두 화면을 모두 확인하세요. 이 매뉴얼을 만들 때 김그루 사원의 월간 업로드가 30건 한도에 닿아 업로드가 막혔고, 사용자 한도를 200건, AI혁신팀 팀스페이스 한도를 300건으로 올려 풀었습니다.

용어 사전​

검색과 AI > 용어 사전에서 동의어·별칭 사전을 만들고, 컬렉션 설정의 연결된 사전에서 컬렉션에 연결합니다. 연결하면 키워드 검색에서 "법카"로 "법인카드"까지 찾습니다.

용어 사전 상세

번호메뉴기능이런 때 사용하세요
1파일 선택용어를 정리한 CSV나 엑셀 파일을 고릅니다(20 MiB까지).용어를 한꺼번에 넣을 때
2양식 내려받기·양식 예시 보기파일 양식을 받거나 예시를 봅니다. CSV는 canonical(대표어), code, description(설명), aliases(별칭, "\"로 구분) 열을 씁니다.처음 파일을 만들 때
3적재 방식병합은 표제어가 같은 항목은 갱신하고, 파일에 없는 기존 항목은 그대로 둡니다. 교체를 고르면 파일 내용으로 바꿉니다.기존 사전에 용어를 더할 때
4업로드파일을 적재합니다.파일을 고른 뒤

용어 사전 항목

번호메뉴기능이런 때 사용하세요
1항목 검색·항목 추가왼쪽은 대표어, 코드, 별칭, 설명으로 항목을 찾고, 오른쪽은 항목을 하나씩 직접 추가합니다.특정 용어가 있는지 보거나 용어 한두 개를 더할 때
2항목 목록대표어, 코드, 별칭, 설명과 수정·삭제 버튼입니다.잘못 들어간 별칭을 고칠 때

업로드가 끝나면 업로드 버튼 아래에 추가, 갱신, 삭제 건수가 적재 결과로 나옵니다. 파일이 제대로 들어갔는지 여기서 확인합니다.

이 예에서는 다음 CSV로 "브레인크루 사내 용어" 사전에 네 항목을 넣었습니다.

canonicalcodedescriptionaliases
법인카드EXP-CARD회사 명의로 발급한 업무용 신용카드회사카드|법카
재택근무WFH회사 밖에서 근무하는 제도원격근무|리모트근무|재택
반반차HALF-HALF2시간 단위 휴가반반휴가
숙박비LODGING출장 중 숙박에 드는 비용호텔비|숙소비

LLM 커넥션​

검색과 AI > LLM 커넥션에서 질의 재작성과 AI 답변에 쓸 언어 모델 연결을 팀스페이스별로 만듭니다. 만든 커넥션의 ID를 컬렉션 담당자에게 알려 주면, 담당자가 컬렉션 설정의 LLM 검색 보강에 넣어 씁니다(컬렉션과 폴더 참고). 컬렉션은 소유자가 속한 팀스페이스의 커넥션만 쓸 수 있으므로, 부서마다 커넥션을 하나씩 만들어 두는 것이 좋습니다. 커넥션 화면에는 API 키 같은 비밀값이 들어가므로 화면을 캡처해 공유하지 마세요.
