Deep Connector 워크스페이스

사이드바 메뉴 맨 위 워크스페이스는 컬렉션과 승인 책임을 팀 단위로 묶는 공간입니다. 컬렉션은 개인("내 컬렉션") 또는 워크스페이스 하나만 소유하고, 다른 워크스페이스에는 필요한 권한만 줍니다. 이 페이지는 AI혁신팀 김그루 사원이 팀 워크스페이스 "AI혁신팀 지식관리"를 만들고 멤버를 넣고 설정하는 순서로 설명합니다.

이 페이지에서 할 수 있는 일

  • 내가 속한 팀 워크스페이스 목록을 봅니다.
  • 팀 워크스페이스를 만들고 폴더로 정리합니다.
  • 멤버를 추가하고 역할을 정합니다.
  • 저장 용량 한도, 소유권 이전, 워크스페이스 삭제를 합니다.

워크스페이스 목록​

워크스페이스 목록

번호메뉴기능이런 때 사용하세요
1워크스페이스 만들기새 팀 워크스페이스 창을 엽니다.팀이 함께 관리할 지식 공간이 필요할 때
2워크스페이스 카드이름, 설명, 내 역할(Owner 등), 컬렉션 수, 멤버 수, 사용 용량입니다. 누르면 워크스페이스 화면이 열립니다.팀 워크스페이스로 들어갈 때

워크스페이스 기능이 꺼진 배포에서는 사이드바에 워크스페이스 메뉴가 보이지 않습니다.

워크스페이스 만들기​

새 팀 워크스페이스 창

번호메뉴기능이런 때 사용하세요
1이름워크스페이스 이름입니다."AI혁신팀 지식관리"처럼 팀과 용도를 드러낼 때
2설명이 워크스페이스가 관리하는 지식의 범위입니다.다른 팀이 용도를 알 수 있게 할 때
3워크스페이스 만들기만듭니다. 만든 사람이 Owner가 됩니다.입력을 마쳤을 때

워크스페이스를 열면 컬렉션, 멤버, 설정 탭이 있습니다.

워크스페이스 화면

번호메뉴기능이런 때 사용하세요
1워크스페이스 요약소유한 컬렉션 수, 멤버 수, 사용 용량입니다.워크스페이스 현황을 볼 때
2컬렉션이 워크스페이스가 소유한 컬렉션과 폴더입니다.팀 컬렉션을 정리할 때
3멤버멤버를 추가하고 역할을 정합니다.팀원을 넣을 때
4설정저장 용량 한도, 소유권 이전, 워크스페이스 삭제가 있습니다. Owner만 바꿀 수 있습니다.담당자가 바뀌어 소유권을 넘길 때

컬렉션 탭​

워크스페이스 컬렉션 탭

번호메뉴기능이런 때 사용하세요
1용량 한도 표시사용 용량 아래에 한도가 보입니다. 따로 정하지 않으면 "조직 기본값 상속"입니다.팀 용량 한도가 정해졌는지 볼 때
2폴더 추가워크스페이스 안에 폴더를 만듭니다. 워크스페이스 → 폴더(최대 3단계) → 컬렉션 구조입니다.팀 컬렉션을 주제별로 나눌 때
3폴더만든 폴더입니다. 이 워크스페이스가 소유한 컬렉션이 폴더 아래에 보입니다.팀 컬렉션을 찾을 때

멤버 탭​

워크스페이스 멤버 탭

번호메뉴기능이런 때 사용하세요
1사용자 ID추가할 사람의 이메일이나 사용자 ID를 적습니다.팀원을 찾을 때
2역할Admin이나 Member 중에서 고릅니다.승인 권한까지 줄지 정할 때
3추가멤버로 넣습니다.입력을 마쳤을 때
4멤버 목록멤버마다 역할(Owner, Admin, Member)이 표시됩니다. 멤버 행의 제거로 멤버를 빼면 이 워크스페이스로 얻은 컬렉션 권한이 바로 사라집니다.누가 승인 권한을 가졌는지 볼 때
역할할 수 있는 일
Owner소유권 이전, 삭제, 용량 정책, Admin 지정
Admin멤버 관리, 권한·에이전트·MCP 승인
Member허용된 자원 사용, 권한 요청 제출

설정 탭​

워크스페이스 설정 탭

번호메뉴기능이런 때 사용하세요
1저장 용량 한도 (바이트)·저장워크스페이스가 쓸 수 있는 저장 용량을 바이트로 적고 저장합니다. 비워 두면 소속 조직(팀스페이스)의 기본값을 따릅니다. Owner만 바꿀 수 있습니다.팀 자료가 늘어 한도를 따로 정할 때
2소유권 이전새 Owner의 사용자 ID를 적고 이전을 누릅니다. 기존 Owner는 Admin으로 남습니다.담당자가 다른 부서로 옮길 때
3삭제워크스페이스를 지웁니다. 소유한 컬렉션이 남아 있으면 지울 수 없으니 먼저 다른 워크스페이스로 옮깁니다.프로젝트가 끝나 공간을 정리할 때
설정뜻기본값
저장 용량 한도워크스페이스 전체가 쓸 수 있는 용량비워 둠(조직 기본값 상속)
새 멤버 역할멤버 탭에서 추가할 때의 역할Member
만든 사람의 역할워크스페이스를 만든 사람Owner

이럴 때 쓰세요: AI혁신팀 김그루 사원은 팀이 함께 쓰는 "사내 규정"·"제품 소개" 컬렉션을 개인 소유로 두면 휴가나 이동 때 관리가 끊긴다는 것을 알게 됐습니다. "AI혁신팀 지식관리" 워크스페이스를 만들고 강혁신 팀장을 Admin으로 넣어, 팀장이 권한 승인을 대신할 수 있게 했습니다. 팀장이 다른 부서로 옮기면 설정 탭의 소유권 이전으로 넘깁니다.
