Deep Connector 실습 묶음 안내

이 묶음은 컬렉션을 하나 새로 만들어 문서를 올리는 것부터, 청크 확인, 검색과 AI 답변, RAG 평가, MCP 토큰 발급, Deep Agent Builder 에이전트 연결까지 여섯 가지 실습을 한 흐름으로 잇습니다. 앞 실습에서 만든 컬렉션과 토큰을 다음 실습이 그대로 이어 씁니다. 실습마다 목표, 준비물, 단계별 화면과 번호 표, 설정값 표, 실제 결과, 흔한 실수, 응용 과제가 있습니다. 예시 인물은 브레인크루 AI혁신팀 김그루 사원이고, 회의록과 보고서, 계약서의 회사와 금액은 모두 연습용 가상 자료입니다.

이 페이지에서 할 수 있는 일

  • 실습 여섯 가지가 무엇을 만들고 무엇을 익히는지 한눈에 봅니다.
  • 실습끼리 무엇을 이어 쓰는지 확인하고 순서를 정합니다.
  • 실습에 쓰는 파일 12개를 직접 준비하는 방법을 봅니다.
  • 실습과 시작하기, 활용사례의 차이를 압니다.

모든 실습에 공통인 손동작​

하고 싶은 일방법
컬렉션 열기사이드바 컬렉션에서 컬렉션 이름을 누릅니다. 문서 탭이 먼저 열립니다.
실험 메뉴 열기사이드바 실험을 눌러 펼치고 검색, RAG 진단, RAG 평가, MCP 도구 테스트 중에서 고릅니다. 처음이면 실험 공간 안내의 세 항목을 확인합니다.
바꾼 설정 저장화면 아래에 나타나는 저장을 누릅니다. "컬렉션이 성공적으로 수정되었습니다"가 나오면 저장된 것입니다.
처리 상태 보기문서 목록의 청크 수가 0보다 크면 처리가 끝난 것입니다. 빨간 경고 표시는 처리 실패입니다.
화면 공유 전 가리기이메일, 토큰, 커넥션 ID가 보이는 칸은 캡처나 화면 공유 전에 가립니다.

실습과 다른 페이지의 차이​

구분시작하기실습 묶음활용사례
