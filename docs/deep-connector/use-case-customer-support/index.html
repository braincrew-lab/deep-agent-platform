Deep Connector 사례: 고객 문의 답변 근거 찾기

브레인크루 고객센터 상담원은 "앱에 E103 오류가 떠요", "단순 변심인데 반품 배송비는요?" 같은 문의에 FAQ, 처리 기준표, 스캔한 안내문을 뒤져 답합니다. 이 사례에서는 텍스트 문서와 엑셀, 사진·스캔 이미지를 한 컬렉션에 모아, 상담원이 문의 내용을 그대로 넣으면 답변 근거가 나오게 합니다. 처리에 실패한 파일을 바로잡는 과정도 함께 봅니다.

이 페이지에서 할 수 있는 일

  • Markdown(.md), 엑셀(.xls, .xlsx), 사진(.jpg, .jpeg), 스캔 이미지(.tiff)를 한 컬렉션에 올립니다.
  • 처리에 실패한 파일의 오류를 읽고 형식을 바꿔 다시 올립니다.
  • 문의 문장으로 검색해 FAQ와 스캔 안내문을 함께 근거로 받습니다.

목표​

항목내용
누가고객센터 상담원(검색), 상담 리더(문서 관리)
무엇을FAQ, 처리 기준표, 오류 화면, 반품 안내문, 보증서를 "고객지원 답변 근거" 컬렉션에 올립니다
끝났다고 볼 기준"단순 변심 반품 배송비"를 물었을 때 6,000원과 14일 기준이 근거와 함께 나오는 것
걸리는 시간25분 정도

준비물​

파일확장자내용
자주-묻는-질문.md.md배송, 교환·반품(14일, 왕복 배송비 6,000원), 오류 코드 E101·E103·E205, A/S
문의-유형별-처리-기준.xls.xls문의 유형마다 1차 응대, 처리 기한, 에스컬레이션 대상(예전 엑셀 형식)
오류-화면-E103.jpg.jpg앱 오류 화면을 찍은 그림(마이크 연결 오류)
반품-접수-안내문-스캔.jpeg.jpeg반품 접수 순서를 적은 안내문 스캔
품질-보증서-스캔.tiff.tiff보증 기간 1년과 무상 수리 제외 항목이 적힌 보증서 스캔

모두 매뉴얼 시연용 가상 자료입니다. 실제 상담 기록이나 고객 개인정보가 담긴 파일은 올리지 마세요.

단계​

1. 컬렉션 만들고 자료 올리기​

  1. 새 컬렉션에서 이름 "고객지원 답변 근거", 설명 "FAQ·문의 유형별 처리 기준·오류 화면·반품 안내문·보증서"로 만듭니다.
  2. 문서 업로드에서 다섯 파일을 올립니다. 스캔 이미지는 크기가 커서(.tiff 약 2.7 MB) 다른 파일보다 처리가 조금 더 걸립니다.

2. 처리 실패한 파일 바로잡기​

이 매뉴얼의 시연 환경에서는 .xls 파일이 처리에 실패했습니다. 문서 목록에서 실패 표시를 보고 원인을 확인합니다.

처리 실패한 문서

번호항목화면에서 볼 것
1문서 이름청크 수가 0인 .xls 파일입니다.
2실패 표시누르면 오류 상세 창이 열립니다.
3재시도같은 파일로 처리를 다시 시작합니다.

오류 상세에는 "Unsupported format: .xls — convert to .xlsx and retry"가 나옵니다. 엑셀에서 파일을 열어 .xlsx로 다른 이름으로 저장한 뒤 같은 컬렉션에 다시 올립니다. 위 그림은 .xlsx를 다시 올린 뒤의 목록이라 맨 위에 처리가 끝난 .xlsx가 보입니다. 실패한 .xls 문서는 정리가 끝나면 지웁니다.

고객지원 답변 근거 컬렉션의 문서 목록

번호항목화면에서 볼 것
1문서 이름다시 올린 "문의-유형별-처리-기준.xlsx"가 맨 위에 있습니다.
2청크 수스캔 이미지와 사진도 글자를 읽어 청크가 만들어졌습니다. 아직 지우지 않은 실패한 .xls만 0입니다.
3청크 탭스캔본에서 읽은 글자가 원문과 같은지 봅니다.

3. 문의 문장으로 찾기​

실험 > 검색에서 하이브리드 검색으로 고객이 한 말을 그대로 넣습니다.

프롬프트: 단순 변심으로 반품하면 배송비는 누가 내나요?

하이브리드 검색 결과

번호항목화면에서 볼 것
1컬렉션"고객지원 답변 근거"입니다.
2검색 방식하이브리드 검색입니다. 적용된 설정에 RRF 전략이 보입니다.
3질문고객 문의 그대로입니다.
4결과FAQ(.md)가 신뢰도 93%, 반품 안내문 스캔(.jpeg)이 81%, 처리 기준표(.xlsx)가 3위로 나옵니다.

4. 답변 초안 받기​

RAG 진단에서 오류 문의에 대한 응대 순서를 묻습니다.

프롬프트: 고객이 앱에 E103 오류가 뜬다고 합니다. 1차 응대와 다음 조치를 알려 주세요.

고객지원 답변

번호항목화면에서 볼 것
1컬렉션"고객지원 답변 근거"입니다.
2질의상담원이 받은 문의입니다.
3답변"앱 오류 코드 E103(마이크 연결 오류) 발생 시 1차 응대는 기기 재부팅 안내입니다. 기기를 다시 켠 뒤 문제가 계속되면 A/S 접수를 권장합니다"라고 답하고, 근거로 "자주-묻는-질문.md"와 "문의-유형별-처리-기준.xlsx"를 들었습니다.

결과물 예시​

상담원이 고객에게 보낼 답변 초안입니다.

문의답변 초안근거
단순 변심 반품 배송비받은 날부터 14일 안에 신청할 수 있고, 단순 변심이면 왕복 배송비 6,000원을 고객님이 부담하십니다.자주-묻는-질문.md, 반품-접수-안내문-스캔.jpeg
앱 E103 오류기기를 다시 켠 뒤 시도해 주세요. 계속되면 A/S 접수를 도와드리겠습니다.자주-묻는-질문.md, 문의-유형별-처리-기준.xlsx
보증 기간구입일로부터 1년이며, 침수·낙하·임의 분해는 무상 수리에서 제외됩니다.품질-보증서-스캔.tiff

응용 팁​

  • 고객이 보낸 오류 화면 사진과 같은 화면을 컬렉션에 미리 올려 두면, 오류 문구만 입력해도 대응 문서가 함께 나옵니다.
  • 상담원 에이전트를 만들 때 지침에 "근거 문서에 없는 보상이나 예외는 약속하지 않는다"를 넣습니다.
  • 처리 기준표는 자주 바뀌므로 바뀔 때마다 새 버전 업로드로 교체하고, 변경 사유에 바뀐 유형을 적어 둡니다.
