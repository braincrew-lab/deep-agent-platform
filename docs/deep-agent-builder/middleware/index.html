미들웨어와 개인정보 보호

미들웨어는 에이전트가 질문을 받고 답을 내보내는 흐름 중간에 끼워 두는 처리 규칙입니다. 이 페이지는 에이전트 편집 화면의 미들웨어 칸에서 미들웨어를 붙이고 빼는 방법, 기본 제공 미들웨어 11종의 쓰임새, 그리고 가장 많이 쓰는 개인정보 보호 미들웨어의 설정 항목을 화면 순서대로 설명합니다. 사례로는 브레인크루 AI혁신팀 김그루 사원이 계약서 검토 도우미에 계약서 초안과 담당자 연락처를 붙여 넣었을 때 전화번호와 이메일이 어떻게 가려지는지 보여 드립니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면의 미들웨어 칸에서 미들웨어를 추가하고, 설정을 열고, 뺍니다.
  • 미들웨어 추가 창에서 기본 제공 미들웨어 11종의 설명을 읽고 업무에 맞는 것을 고릅니다.
  • 개인정보 보호 미들웨어에서 보호할 개인정보 19종, 처리 방식(가리기·마스킹·해시·차단), 적용 지점(사용자 입력·모델 응답·도구 결과)을 정합니다.
  • 고급 옵션의 카테고리별 처리 방식, 탐지 엄격도, 탐지 제외 값, 도구 호출 인자 검사, AI 추가 탐지 종류, AI 탐지 제한 시간(초), 감사 로그 기록이 무엇을 바꾸는지 알고 필요한 것만 바꿉니다.
  • 계약서 검토 도우미로 전화번호는 끝 네 자리만 남기고 이메일은 통째로 가리는 설정을 직접 시험합니다.

미들웨어를 언제 붙일지 설계 단계에서 정하는 방법은 첫 에이전트 설계하기에서 다룹니다. 대화로 에이전트를 만들면 만드는 도중에 미들웨어 추천 단계가 나오는데, 그 흐름은 에이전트 만들기를 참고하세요.

미들웨어가 하는 일​

미들웨어는 에이전트에 새 기능을 더하기보다 이미 있는 흐름에 규칙을 겁니다. 입력을 모델에 넘기기 전에 고치거나, 실패한 호출을 다시 시도하거나, 위험한 도구를 실행하기 전에 사람 확인을 받는 식입니다.

구성맡는 일브레인크루 예
도구외부 시스템을 조회하거나 작업을 실행합니다시장 조사 리서처의 웹 검색 도구
스킬업무 절차와 기준을 알려 줍니다회사 디자인 가이드 스킬
지식답변 근거가 되는 문서를 찾아 줍니다사내 규정 Q&A 비서의 사내 규정 문서
미들웨어실행 흐름 중간에 처리 규칙을 적용합니다계약서에 적힌 담당자 전화번호를 모델에 넘기기 전에 가림

미들웨어를 붙였다고 에이전트가 새로운 외부 시스템에 접근하지는 않습니다. 외부 호출은 도구가 맡습니다. 도구와 스킬은 도구와 스킬 구성에서 설명합니다.

미들웨어와 별개로, 회사가 정한 보안 정책(가드레일)이 대화를 막을 때도 있습니다. 이때는 정책이 정한 안내 문구가 답변 말풍선에 그대로 표시됩니다. 미들웨어 설정으로는 이 정책을 끄거나 바꿀 수 없습니다. 자세한 내용은 파일 첨부 정책과 가드레일을 참고하세요.

에이전트 편집 화면의 미들웨어 칸​

미들웨어는 에이전트마다 따로 붙입니다. 사이드바에서 에이전트를 고르고 에이전트 설정을 누르면 에이전트 편집 화면이 열립니다. 가운데 편집 영역의 폼 보기 아래쪽에 도구함, 지식함과 나란히 미들웨어 칸이 있습니다. 세 칸 모두 제목을 누르면 접히거나 펼쳐지므로, 지침을 넓게 보며 고칠 때 아래 칸을 잠시 접어 두면 편합니다. 그림은 개인정보 보호를 붙인 계약서 검토 도우미의 에이전트 편집 화면이며, 번호별 기능은 아래 표와 같습니다.

에이전트 편집 화면의 미들웨어 칸

번호메뉴기능이런 때 사용하세요
1+ 미들웨어미들웨어 추가 창을 엽니다.계약서 검토 도우미처럼 연락처가 섞인 문서를 다루는 에이전트에 개인정보 보호를 붙일 때
2연결된 미들웨어이 에이전트에 붙은 미들웨어 이름입니다. 아무것도 없으면 "추가된 미들웨어가 없습니다"가 보입니다.동료가 만든 에이전트를 넘겨받아 어떤 처리가 걸려 있는지 확인할 때
3미들웨어 설정(톱니바퀴)"미들웨어 설정: 개인정보 보호"처럼 그 미들웨어의 설정 창을 엽니다.가릴 항목이나 처리 방식을 바꿀 때
4삭제(휴지통)이 에이전트에서 미들웨어를 뺍니다. 빼면 "미들웨어가 에이전트에서 제거되었습니다" 알림이 뜹니다.더는 그 처리가 필요 없을 때

미들웨어를 붙이거나 빼거나 설정을 저장하면 곧바로 대화와 테스트 탭에 적용됩니다. 이름·설명·지침과 달리 헤더의 저장을 누르지 않아도 됩니다. 헤더의 버전 안내에도 "도구, 모델, 오프너 등 고급 설정은 변경하는 즉시 저장됩니다"라고 적혀 있습니다. 다만 이 변경은 현재 버전의 저장본에는 아직 기록되지 않아, 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보입니다. 헤더 저장을 누르면 현재 버전에 기록되며, 워크스페이스 등록을 요청하기 전에는 꼭 눌러 둡니다. 되돌릴 지점이 필요하면 바꾸기 전에 새 버전으로 저장을 해 둡니다. 버전은 에이전트 수정에서 설명합니다.

미들웨어 이름 옆에 노란 방패 표시가 보이면 그 미들웨어를 쓸 권한이 없다는 뜻입니다. 표시에 마우스를 올리면 "사용 권한이 없습니다. 관리자에게 문의하세요."가 나옵니다. 권한 문구는 시크릿과 권한에 모아 두었습니다.

대화 화면에서도 붙은 미들웨어를 확인할 수 있습니다. 입력란 아래 왼쪽의 미들웨어 버튼을 누르면 연결된 미들웨어 이름이 나오고, 없으면 "추가된 미들웨어가 없습니다"가 보입니다. 여기서는 보기만 하고 바꿀 수는 없습니다.

대화 화면에서 연결된 미들웨어 확인

번호메뉴기능이런 때 사용하세요
1미들웨어 버튼이 에이전트에 붙은 미들웨어 목록을 펼칩니다.대화를 시작하기 전에 개인정보 보호가 걸려 있는지 확인할 때
2연결된 미들웨어 목록붙은 미들웨어 이름이 나옵니다. 없으면 "추가된 미들웨어가 없습니다"가 보입니다.에이전트 편집 화면을 열지 않고 빠르게 확인할 때

미들웨어 추가 창​

+ 미들웨어를 누르면 미들웨어 추가 창이 열립니다. 왼쪽은 목록, 오른쪽은 상세 정보입니다. 이미 이 에이전트에 붙은 미들웨어는 목록에 나오지 않습니다. 위쪽 미들웨어 검색... 칸에 이름이나 설명의 일부를 적으면 목록이 좁혀집니다. 목록의 각 항목에는 이름 옆에 유형 표시(기본 제공 미들웨어는 "built-in")와 한 줄 설명이 나옵니다. 목록에서 하나를 누르면 오른쪽에 이름, 유형, 전체 설명이 나오고, 창 아래 미들웨어 추가를 누르면 이 에이전트에 붙으며 "미들웨어가 에이전트에 추가되었습니다" 알림이 뜹니다. 쓸 권한이 없는 항목은 흐리게 보이고 방패 표시가 붙습니다. 붙이지 않고 나가려면 오른쪽 위 닫기(X)를 누릅니다. 그림은 개인정보 보호를 이미 붙인 계약서 검토 도우미에서 "도구"로 검색하고 도구 재시도를 고른 모습입니다.

미들웨어 추가 창

번호메뉴기능이런 때 사용하세요
1미들웨어 검색...이름과 설명으로 목록을 좁힙니다. 맞는 것이 없으면 "검색 결과가 없습니다"가 보입니다."재시도"처럼 이름 일부만 기억날 때
2목록 항목이름, 유형 표시(built-in), 한 줄 설명이 나옵니다. 쓸 권한이 없는 항목은 흐리게 보이고 방패 표시가 붙습니다.설명을 훑어보고 업무에 맞는 것을 고를 때
3상세 정보목록에서 하나를 누르면 오른쪽에 이름, 유형, 그 아래 전체 설명이 나옵니다. 고르기 전에는 "미들웨어를 선택하면 상세 정보를 볼 수 있습니다"가 보입니다.목록 설명이 잘려 끝까지 읽어야 할 때
4미들웨어 추가고른 미들웨어를 이 에이전트에 붙입니다. 붙이면 "미들웨어가 에이전트에 추가되었습니다" 알림이 뜨고 에이전트 편집 화면의 미들웨어 칸에 이름이 생깁니다.설명을 읽고 붙이기로 정했을 때

기본 제공 미들웨어​

기본 제공 미들웨어는 다음 11종입니다. 설명은 화면 문구를 줄인 것입니다. 기본값은 설정 창을 처음 열었을 때의 값입니다.

미들웨어화면 설명 요약주요 설정과 기본값이런 때 사용하세요
개인정보 보호대화, 모델 응답, 도구 호출과 결과에 섞인 개인정보를 찾아 정해진 방식으로 처리합니다. 모델은 원문 대신 자리표시자만 봅니다.보호할 항목, 처리 방식 가리기, 적용 지점 셋 모두 켜짐계약서·견적서처럼 담당자 연락처가 적힌 문서를 붙여 넣을 때
인텐트 재질의요청이 모호하면 작업을 시작하기 전에 먼저 되묻습니다. 요청이 구체적이면 아무것도 하지 않습니다.연속으로 되물을 최대 턴 수 1"보고서 써 줘"처럼 대상과 형식이 빠진 요청이 자주 들어올 때
자가 개선 반복답변을 한 뒤 목표를 이뤘는지 스스로 판단하고 필요하면 한두 번 더 다듬습니다.최대 턴 수 2교육 자료 초안처럼 한 번 더 점검하면 품질이 좋아지는 작업
도구 재시도외부 API나 사내 시스템 도구가 잠깐 실패하면 자동으로 다시 호출합니다.최대 재시도 3회, 첫 대기 1초웹 검색 도구가 가끔 응답하지 않을 때
도구 호출 제한도구를 너무 많이 부르지 않도록 제한합니다.한 번 실행에 20회, 한 대화 전체에 100회유료 API 도구를 같은 질문에 반복 호출할 우려가 있을 때
모델 재시도모델 호출이 네트워크 문제나 일시 오류로 실패하면 다시 시도합니다.최대 재시도 3회사용자가 몰리는 시간에 응답이 가끔 끊길 때
모델 대체 실행주 모델이 실패하면 미리 정한 다른 모델로 바꿔 실행합니다.먼저 쓸 모델, 예비 모델 목록등록된 모델이 둘 이상이고 작업을 끊김 없이 마쳐야 할 때
모델 호출 제한모델을 너무 많이 부르지 않도록 한도를 둡니다.한 번 실행에 10회, 한 대화 전체에 50회작업이 끝나지 않고 계속 도는 상황을 막을 때
도구 자동 선택도구가 많을 때 질문에 맞는 도구 몇 개만 골라 모델에 보여 줍니다.한 번에 보여 줄 도구 수 5도구를 여러 개 붙인 에이전트가 엉뚱한 도구를 고를 때
사람 승인중요하거나 위험한 도구를 실행하기 전에 멈추고 사람의 승인·수정·거절을 받습니다.승인이 필요한 도구와 규칙메일 발송처럼 되돌리기 어려운 작업을 맡길 때

마스킹이 적용된 계약서 검토 대화

번호메뉴기능이런 때 사용하세요
1김그루 휴대전화내 질문 말풍선에서도 *-**-5678로 바뀌어 보입니다. 끝 네 자리만 남습니다.전화번호가 마스킹되는지 확인할 때
2이메일[마스킹:이메일]로 바뀌었습니다. 이메일은 남길 숫자가 없어 통째로 가려집니다.이메일이 모델에 넘어가지 않았는지 확인할 때
3한빛데이터 담당자 휴대전화*-**-6789로 바뀌었습니다.두 담당자를 끝자리로 구분할 수 있는지 볼 때
4대표번호탐지 제외 값에 넣은 02-1234-5678은 그대로 남았습니다.공개 번호가 답변에 필요한 그대로 나오는지 확인할 때

말풍선 아래에는 불리한 조항을 조항 번호, 문제점, 수정 제안 열로 정리한 검토 표가 이어집니다. 이 예에서는 제2조(자동 연장), 제3조(서비스 수준), 제4조(일방 구독료 조정), 제5조(비밀유지 기간), 제6조(손해배상 한도 1개월), 제7조(결과물 권리 을 귀속), 제8조(해지 사유), 제9조(을 관할 법원)가 나왔습니다.

결과를 이렇게 확인하세요​

  • 내 질문 말풍선과 답변 모두에서 휴대전화 두 개가 끝 네 자리만 남았는지 봅니다. 모델은 원래 번호를 보지 못하므로 답변에도 원래 번호가 나올 수 없습니다. 답변에서는 별표가 굵은 글씨 표시로 처리되어 "*--5678"처럼 짧게 보일 수 있지만, 원래 번호가 드러난 것은 아닙니다.
  • 이메일이 [마스킹:이메일]로 표시되는지 봅니다.
  • 대표번호 02-1234-5678이 그대로 남았는지 봅니다. 가려졌다면 1단계 7번에서 탐지 제외 값에 적은 값과 하이픈 위치까지 똑같은지, 1단계 8번에서 저장을 눌렀는지 확인합니다.
  • 검토 표의 조항 번호를 원문과 대조합니다. 조항 해석은 에이전트의 제안이므로 최종 판단은 계약 담당자가 합니다. 이 예에서는 답변 끝에 "최종 판단은 법무 담당 부서 검토를 받아야 합니다."가 붙었습니다.

팁: 시험에는 010-1234-5678처럼 누가 봐도 가상인 값만 씁니다. 실제 직원이나 거래처 연락처로 설정을 시험하지 않습니다.

설정을 바꿀 때 확인할 것​

  • 처음 붙인 설정에는 보험증권번호, 전화번호, 이메일, 사업자등록번호, 법인등록번호, 이름, 주소, 생년월일, 건강보험증번호, 차량번호, IP 주소, MAC 주소, URL이 빠져 있습니다. 브레인크루 계약서나 견적서처럼 업무에 들어오는 문서를 떠올려 필요한 것을 선택합니다.
  • 설정은 저장하는 즉시 이 에이전트의 다음 대화부터 적용됩니다. 이미 끝난 대화의 내용은 바뀌지 않습니다.
  • 바꾼 뒤에는 가상 자료를 새 대화에서 보내 결과를 확인합니다. 같은 대화에서 이어 물으면 앞 대화의 내용이 섞여 비교하기 어렵습니다.
  • 개인정보 보호를 붙이면 이 에이전트의 사용자 메모리는 쌓이지 않습니다.
  • 계약서 검토 전 과정은 사례: 계약서 검토 도우미에서 이어서 다룹니다.
