Deep Agent Builder 주요 기능

사용 목적​

이 문서는 에이전트를 만든 이후 자주 사용하게 되는 기능들, 즉 에이전트 수정, 대화 공유, 사용자 메모리, 스킬 업로드, 내보내기와 가져오기, 백그라운드 실행, 스레드 관리 방법을 안내합니다.

화면 위치​

에이전트 대화 화면 상단에서 에이전트 수정 화면으로 들어갈 수 있습니다. 수정 화면에는 저장, 에이전트 복제, 에이전트 삭제, 에이전트 내보내기 버튼과 함께 사용자 메모리 탭, 컨텍스트 압축 설정 카드가 있습니다. 대화 화면 안에서는 공유 버튼으로 대화를 공유할 수 있고, 에셋 화면에서는 스킬을 zip 파일로 업로드할 수 있습니다. 백그라운드 작업 화면에서는 실행 중이거나 완료된 작업 목록과 스레드를 확인할 수 있습니다.

단계​

  1. 에이전트 수정: 대화 화면에서 수정 메뉴로 들어가 필요한 내용을 바꾼 뒤 저장을 누릅니다. 더 이상 필요 없는 에이전트는 에이전트 삭제로, 비슷한 에이전트를 새로 만들고 싶다면 에이전트 복제로 처리합니다. 다른 워크스페이스로 옮기고 싶다면 에이전트 내보내기로 zip 파일을 받고, 나중에 가져오기 기능으로 동일한 zip 파일을 불러올 수 있습니다.
  2. 사용자 메모리 설정: 수정 화면의 사용자 메모리 탭에서 에이전트가 기억할 내용을 적습니다. 이 입력란은 최대 2000자까지 입력할 수 있으므로, 핵심 정보 위주로 간결하게 작성하는 것이 좋습니다.
  3. 대화 공유: 공유하고 싶은 대화에서 공유 버튼을 누르고 공유 링크 생성을 선택합니다. 만들어진 링크로 접속하면 공유된 대화가 읽기 전용으로 표시됩니다.
  4. 스킬 업로드: 에셋 화면에서 스킬 추가를 선택하고 문서 또는 일반 유형 중 하나를 고릅니다. 업로드할 수 있는 파일은 zip 형식만 가능하며, 스킬 설명은 최대 200자까지 입력할 수 있습니다.
  5. 백그라운드 실행과 스레드 관리: 오래 걸리는 작업은 백그라운드 작업 화면에서 확인할 수 있습니다. 대화 목록에서는 스레드를 검색하거나 자주 보는 스레드를 고정할 수 있고, 필요 없는 스레드는 삭제할 수 있습니다.

결과 확인​

수정 내용을 저장하면 대화 화면에 바뀐 설정이 바로 반영됩니다. 사용자 메모리는 2000자를 넘기면 더 이상 입력되지 않으므로, 입력이 멈추면 글자 수 제한에 도달한 것입니다. 공유 링크는 누른 즉시 생성되며 별도 승인 절차 없이 바로 사용할 수 있습니다. 스킬 업로드는 zip 파일이 아니거나 설명이 200자를 넘으면 업로드가 진행되지 않습니다.

문제 해결​

스킬 업로드가 계속 실패한다면 파일 형식이 zip인지, 설명 글자 수가 200자를 넘지 않는지 다시 확인합니다. 사용자 메모리가 저장되지 않는다면 2000자 제한을 넘겼을 가능성이 높으므로 내용을 줄여봅니다. 공유한 링크에 상대방이 접속하지 못한다면 링크를 다시 생성해 재전달합니다. 백그라운드 작업이 오래 끝나지 않으면 작업 화면에서 상태를 확인하고, 필요하면 관리자에게 문의합니다. 기본적인 로그인과 생성 절차는 Deep Agent Builder 시작하기 문서를 참고하세요.
