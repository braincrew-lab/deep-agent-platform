메뉴 안내

이 페이지는 Deep Agent Builder에 로그인했을 때 보이는 메뉴를 사이드바 위쪽부터 아래쪽, 대화 화면, 에이전트 편집 화면, 에셋 화면, 환경설정 순서로 한 번씩 소개합니다. 메뉴 이름과 위치를 먼저 익혀 두면 이후 페이지의 설명을 따라가기 쉽습니다. 각 메뉴를 자세히 다루는 페이지는 절마다 링크로 이어집니다.

이 페이지에서 할 수 있는 일

  • 사이드바 위쪽 메뉴와 더 보기 메뉴로 어떤 화면에 갈 수 있는지 확인합니다.
  • 에이전트 목록의 탭, 폴더, 에이전트별 메뉴의 위치를 익힙니다.
  • 사이드바 아래쪽 메뉴와 프로필 메뉴에서 무엇을 확인하고 바꿀 수 있는지 봅니다.
  • 대화 화면과 에이전트 편집 화면의 버튼, 에셋 화면의 탭, 환경설정 항목을 구별합니다.

전체 화면 구성​

로그인하면 왼쪽에 사이드바가 있고 오른쪽에 작업 영역이 열립니다. 별도의 상단 메뉴 바는 없으며, 메뉴는 모두 사이드바에 모여 있습니다. 처음에는 작업 영역에 새 에이전트를 만드는 홈 화면이 열립니다. 홈 화면 각 부분의 이름은 시작하기에서 설명합니다.

사이드바는 두 가지 모습으로 바뀝니다. 평소에는 메뉴와 에이전트 목록이 보이고, 에이전트를 하나 열면 그 에이전트 전용 메뉴와 채팅 목록이 보입니다. 아래쪽 메뉴와 사용자 이름은 어느 모습에서나 그대로 남습니다.

사이드바 위쪽: 주요 메뉴와 목록 도구​

사이드바 위쪽에는 화면을 옮기는 주요 메뉴와, 에이전트 목록을 다루는 탭과 도구가 있습니다. 맨 위에는 홈 화면으로 가는 로고와 사이드바를 좁게 접는 사이드바 축소가 있고, 그 아래에 주요 메뉴 새 에이전트, 에이전트 템플릿, 더 보기가 이어집니다. 새 에이전트는 생성 권한이 없으면 누를 수 없습니다.

탭과 목록 도구는 아이콘으로만 표시되며, 마우스를 올리면 이름이 나타납니다. 목록 탭은 내가 만든 에이전트를 보여 주는 내 에이전트와, 워크스페이스에 게시된 에이전트 가운데 내가 대화한 에이전트를 워크스페이스 폴더별로 보여 주는 워크스페이스 에이전트 두 개입니다. 목록 도구는 이름으로 에이전트를 찾는 에이전트 검색, 숨겨 둔 에이전트를 함께 보여 주는 숨겨진 에이전트 보기(다시 누르면 숨겨진 에이전트 숨기기), 에이전트와 폴더의 이름·폴더·설명·숨김 여부를 한 창에서 고치고 변경사항 적용으로 반영하는 에이전트 관리, 새 폴더를 만드는 폴더 생성 네 개입니다.

템플릿은 에이전트 만들기, 워크스페이스 에이전트는 즐겨찾기·워크스페이스·다운로드에서 이어서 설명합니다.

더 보기 메뉴​

더 보기를 누르면 사이드바 오른쪽에 작은 메뉴가 열립니다. 메뉴에는 도구, 모델, 미들웨어, 스킬을 찾아보고 설치하는 유틸리티, 백그라운드 작업과 예약 실행의 상태를 보는 작업, 데이터셋으로 답변을 점검하는 평가, 내 에이전트 전체에 요청을 나눠 주는 대화 화면을 여는 SUPER AI 에이전트 네 항목이 있습니다. 진행 중인 백그라운드 작업이 있으면 더 보기 옆에 개수가 표시됩니다.

유틸리티는 도구와 스킬 구성, 작업은 스케줄링과 백그라운드 모드와 모니터링과 실행 상태 확인, 평가는 에이전트 평가 개요, SUPER AI 에이전트는 핵심 개념 이해하기에서 설명합니다.

에이전트 목록과 에이전트 메뉴​

목록은 폴더 단위로 묶여 있고, 폴더를 정하지 않은 에이전트는 미분류에 들어갑니다. 에이전트 이름 아래에는 설명 앞부분이 보이며, 이름을 누르면 그 에이전트의 대화 화면이 열립니다. 에이전트 이름에 마우스를 올리면 오른쪽 끝에 에이전트 옵션 버튼이 나타나고, 누르면 이름 변경, 복제, 폴더로 이동, 삭제 네 항목이 있는 메뉴가 열립니다. 삭제는 확인 창을 거칩니다. 폴더 이름에 마우스를 올리면 폴더 수정, 폴더 삭제, 에이전트 관리를 쓸 수 있고, 폴더 이름을 누르면 폴더가 접히거나 펼쳐집니다.

복제한 에이전트는 이름만 바꾸고 끝내지 말고 지침과 연결된 지식함, 스킬을 다시 확인하세요. 수정 방법은 에이전트 수정에 있습니다.

사이드바 아래쪽 메뉴​

사이드바 맨 아래에는 즐겨찾기, 에셋설정, 라운지, 환경설정 네 메뉴와 사용자 이름이 고정되어 있습니다. 목록을 아래로 내려도 이 영역은 그대로 남습니다.

즐겨찾기는 즐겨찾기한 내 에이전트와 워크스페이스 에이전트를 개인, 워크스페이스 표시와 함께 한 목록으로 보여 주는 창을 엽니다. 에셋설정은 도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드를 관리하는 에셋 화면을, 라운지는 사내 게시판을, 환경설정은 컬러 테마, 서체, 글자 크기, 표시 언어, 푸시 알림을 바꾸는 설정 화면을 엽니다. 맨 아래 사용자 이름 자리에는 내 이름과 이메일이 보이고, 누르면 프로필과 로그아웃 메뉴가 열립니다.

즐겨찾기는 즐겨찾기·워크스페이스·다운로드, 라운지는 커뮤니티에서 다룹니다.

프로필 메뉴와 프로필 화면​

사용자 이름을 누르면 위쪽으로 작은 메뉴가 열리고, 맨 위에 이름과 이메일, 그 아래에 프로필과 로그아웃이 있습니다. 프로필을 누르면 프로필 화면이 열립니다. 이 화면은 계정 정보(이메일, 레벨, 닉네임, 사용자 ID), 워크스페이스(기본 워크스페이스), 개인 정보(이름, 연락처, 회사/기관, 부서, 직책), 보안(비밀번호 변경), 활동(가입일, 마지막 로그인) 다섯 영역으로 나뉩니다. 닉네임은 오른쪽 연필 버튼으로 바꾸고, 기본 워크스페이스는 이 화면에서 바꿀 수 없으며, 비밀번호는 보안의 변경을 눌러 바꿉니다.

에이전트 대화 화면​

목록에서 에이전트를 누르면 사이드바가 그 에이전트 전용 메뉴로 바뀌고, 작업 영역에 대화 화면이 열립니다. 사이드바에는 원래 메뉴로 돌아가는 뒤로, 지난 채팅과 섞이지 않게 새 채팅을 여는 이 에이전트와 새 대화, 에이전트 편집 화면을 여는 에이전트 설정, 채팅을 검색어로 찾는 **채팅 검색...**과 채팅 목록이 있습니다. 에이전트 설정은 워크스페이스 에이전트에서는 보이지 않습니다. 채팅에 마우스를 올리면 나타나는 버튼으로 이름 변경, 고정, 삭제를 할 수 있습니다.

화면 위쪽에는 에이전트 이름과 설명, 오른쪽에는 모델 이름과 이 채팅의 입력·출력 토큰 수, 에이전트 즐겨찾기가 있습니다. 모델 이름과 사용량을 누르면 스레드 토큰 요약 창이 열립니다.

에이전트에 챗 오프너가 설정되어 있으면 첫 화면 입력란 근처에 예시 질문 칩이 보이고, 누르면 그 질문으로 대화를 시작합니다. 문서작성 에이전트라면 화면 오른쪽에 문서 캔버스가 함께 열립니다. 챗 오프너는 챗 오프너, 캔버스는 캔버스로 문서·PPT·표 만들기에서 다룹니다.

메시지 입력란 아래 버튼​

메시지 입력란 아래에는 버튼이 한 줄로 놓여 있습니다. 입력란 아래 왼쪽의 도구, 서브에이전트, 미들웨어, 스킬은 이 에이전트에 연결된 도구, 서브에이전트, 미들웨어, 스킬을 보여 줍니다. 스킬에서 스킬을 고르면 그 스킬을 써서 답해 달라는 문장이 입력란에 채워집니다.

입력란 아래 오른쪽의 아티팩트는 이 대화에서 에이전트가 만든 결과물을 모아 미리 보고 내보내는 창을 엽니다. 파일 업로드는 메시지에 파일을 한 번에 최대 10개까지 첨부합니다. 백그라운드 모드는 켜 두고 보내면 요청을 백그라운드 작업으로 실행하며, 버튼 이름 뒤에 (ON)/(OFF) 상태가 보입니다. 전송은 메시지를 보내며, 입력란과 첨부가 모두 비어 있거나 파일을 처리하는 중에는 누를 수 없습니다.

입력란에 "/"를 입력하면 사이드바의 에셋설정을 눌러 여는 에셋 화면의 커맨드 탭에 저장해 둔 커스텀 커맨드(예: /weekly_report)를 골라 쓸 수 있습니다. 관리자가 기본 커맨드를 등록해 두었다면 함께 보입니다. 채팅 관리는 대화 화면과 채팅 목록, 첨부는 첨부파일 지원, 커맨드는 커맨드와 재사용, 백그라운드 모드는 스케줄링과 백그라운드 모드에서 다룹니다.

에이전트 편집 화면​

사이드바의 에이전트 설정을 누르면 에이전트 편집 화면이 열립니다. 위쪽 헤더에는 이름, 설명과 관리 버튼이, 가운데 편집 영역에는 폼 또는 비주얼로 보는 에이전트 구성 칸이, 오른쪽에는 수정·시험·실행 설정 탭이 있습니다.

헤더​

헤더에는 눌러서 바로 고치는 이름과 설명, 그리고 워크스페이스 등록, 코드 스니펫, 버전 안내, 에이전트 복제, 에이전트 삭제, 지금 버전 표시, 저장, 저장 옵션 더 보기가 있습니다. 워크스페이스 등록은 팀이 함께 쓰도록 등록을 요청하는 창을, 코드 스니펫은 다른 시스템에서 이 에이전트를 부르는 예시 코드를, 버전 안내는 저장과 버전이 어떻게 동작하는지 설명하는 창을 엽니다. 버전 표시를 누르면 다른 버전으로 전환하고, 저장 옵션 더 보기에서는 새 버전으로 저장과 에이전트 내보내기를 고릅니다. 삭제 권한이 없으면 에이전트 삭제가 흐리게 보이고 마우스를 올리면 "삭제 권한이 없습니다. 관리자에게 문의하세요."가 나옵니다. 워크스페이스 등록으로 커뮤니티에 배포되었거나 배포 요청이 심사 중인 에이전트는 확인 창에서 삭제를 눌러도 지워지지 않고 "커뮤니티에 배포되었거나 배포 요청 중인 에이전트는 삭제할 수 없습니다. 커뮤니티 관리에서 배포를 먼저 정리한 뒤 다시 시도해 주세요."가 나옵니다.

이름, 설명, 지침은 헤더의 저장을 눌러야 현재 버전에 저장되며, 저장하기 전의 지침은 대화와 테스트 탭에 쓰이지 않습니다. 도구, 모델, 오프너, 스킬, 지식, 미들웨어, 서브에이전트, 설정 탭의 에이전트 모드와 Webhook 활성화, 그리고 Fix 에이전트가 적용한 변경은 바꾸는 즉시 대화와 테스트에 반영됩니다. 다만 이런 변경도 현재 버전에 기록하려면 저장 옆에 "저장되지 않은 변경이 있습니다"가 보일 때 저장을 누릅니다. 워크스페이스 등록은 저장된 버전으로 하므로 등록을 요청하기 전에 저장합니다. 자세한 내용은 에이전트 수정, 워크스페이스 등록은 커뮤니티, 코드 스니펫은 코드 스니펫과 외부 API, 내보내기는 에이전트 가져오기와 내보내기에 있습니다.

구성 칸과 오른쪽 탭​

가운데 편집 영역 위쪽의 폼 / 비주얼로 구성을 입력 칸으로 볼지, 에이전트와 도구·지식·서브에이전트를 잇는 그림으로 볼지 고릅니다. 폼 보기에는 역할과 답변 기준을 적는 지침(에디터 확장으로 넓게 펼침), 일을 나눠 맡길 에이전트를 잇는 서브에이전트, 모델과 세부 값을 정하는 모델, 도구 버튼으로 도구를 붙이는 도구함, 지식 버튼으로 지식을 고르는 지식함, 미들웨어 버튼으로 처리 규칙을 붙이는 미들웨어 칸이 있습니다. 오른쪽 탭은 Fix 에이전트, 테스트, 오프너, 파일, 스킬, 스케줄, 설정 일곱 개이며, 탭마다 하는 일은 아래 표에 정리했습니다.

에셋 화면​

사이드바 아래쪽의 에셋설정을 누르면 에셋 화면이 열립니다. 부제는 "도구, 모델, 미들웨어, 스킬을 관리합니다"이며, 에이전트에 연결할 재료를 종류별 탭으로 나눠 관리합니다. 탭은 내가 등록한 도구를 보는 도구, 쓸 수 있는 모델을 보는 모델, 스킬을 보고 스킬 업로드로 올리는 스킬, 대화에서 기억한 어투·언어·선호도를 설정하고 확인하는 메모리, 도구가 쓸 비밀 값을 보관하는 시크릿, 외부 시스템에서 에이전트를 부를 때 쓰는 키를 만드는 API 키, "/"로 부르는 커맨드를 저장하는 커맨드 일곱 개입니다. 새 도구는 도구 추가를 눌러 HTTP 요청 Server, MCP Remote, Zapier MCP Server, Dify MCP Server, n8n MCP Server, Connect MCP Server 가운데 하나를 골라 등록합니다.

탭별 사용법은 도구와 스킬 구성, 스킬 만들기와 업로드, MCP와 에이전트의 MCP화, 모델 구성, 세부 설정과 메모리, 시크릿과 권한, 커맨드와 재사용에 있습니다.

에이전트 템플릿 화면​

사이드바 위쪽의 에이전트 템플릿을 누르면 워크스페이스에 게시된 에이전트를 템플릿으로 보여 주는 화면이 열립니다. 첫 탭에는 내 기본 워크스페이스 이름이 붙어 있고(기본 워크스페이스 이름이 없으면 전체로 보입니다) 기본 워크스페이스의 템플릿을 보여 줍니다. 워크스페이스 탭은 고른 워크스페이스의 템플릿을 보여 주고, **템플릿 검색...**으로 이름을 찾습니다. 템플릿 카드를 누르면 상세 창이 열리고, 템플릿으로 제작을 누르면 그 구성을 복사한 내 에이전트가 만들어집니다. 같은 화면의 커뮤니티 에이전트 관리는 내가 배포한 에이전트와 배포 요청을 관리하는 화면을 엽니다.

라운지 화면​

사이드바 아래쪽의 라운지를 누르면 사내 게시판이 열립니다. 부제는 "라운지에서 공지사항이나 질문, 활용 팁 등 Deep Agent Builder와 관련된 다양한 이야기를 확인해 보세요."입니다. 게시판은 유즈케이스, 사용 가이드, FAQ, 문의 및 오류, 기능 개선 제안, 커뮤니티, 공지사항 일곱 개이며, 처음에는 유즈케이스가 열립니다. 게시글 목록에는 날짜, 제목, 작성자, 추천, 조회, 댓글 수가 보이고, **게시글 검색...**은 모든 게시판의 게시글을 찾습니다.

새 글은 글쓰기로 씁니다. 글을 쓸 권한이 없으면 공지사항, 사용 가이드, 유즈케이스, FAQ에서는 글쓰기가 자물쇠 표시와 함께 눌리지 않는 상태로 보이고, 마우스를 올리면 "이 게시판에 글을 작성할 권한이 없습니다"가 나타납니다. 문의 및 오류, 기능 개선 제안, 커뮤니티에서는 권한이 없으면 글쓰기가 보이지 않습니다.

환경설정​

사이드바 아래쪽의 환경설정을 누르면 설정 화면이 열립니다. 이 화면에서는 화면을 보는 방식과 알림만 바꿉니다. 외관에서는 화면 강조 색인 컬러 테마(Default, Blue, Green, Rose, Orange, Red), 서체(Pretendard, Noto Sans KR, 시스템 기본, Noto Serif KR), 글자 크기(작게, 보통, 크게, 아주 크게)를 고릅니다. 언어 및 지역의 표시 언어는 한국어 또는 영어로, 알림의 푸시 알림은 에이전트 업데이트 알림을 켜고 끕니다. 정보에서는 지금 쓰는 Deep Agent Builder의 버전을 확인합니다.

따라 해 보기​

김그루 사원이 판매 실적 분석을 맡기면서 메뉴를 한 바퀴 돌아보는 순서입니다. 첨부할 파일은 브레인크루_2026_판매실적.xlsx입니다.

  1. 사이드바 내 에이전트 목록에서 판매 데이터 분석가를 누릅니다.

  2. 사이드바가 이 에이전트 메뉴로 바뀌면 이 에이전트와 새 대화를 누릅니다.

  3. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_2026_판매실적.xlsx를 첨부합니다. 새 대화에서는 첨부한 파일이 입력란 위에 파일 이름으로 남아 있다가 전송을 누를 때 올라갑니다.

  4. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다. "업로드 중...", "파일 처리 중..."이 차례로 보인 뒤 파일 처리가 끝나면 질문이 전달됩니다.

    프롬프트: 첨부한 엑셀의 판매내역 시트로 2026년 1월부터 10월까지 지역별 매출 합계를 표로 정리하고, 목표 시트와 비교해 지역별 달성률을 알려 주세요.

  5. 답변이 끝나면 입력란 아래 오른쪽의 아티팩트를 눌러 결과 표를 열어 봅니다.

  6. 다음 달에도 쓸 예정이면 화면 오른쪽 위의 에이전트 즐겨찾기를 눌러 둡니다. 이후에는 사이드바 아래쪽 즐겨찾기에서 바로 열 수 있습니다.

팁: 사이드바 위쪽 메뉴가 뒤로, 이 에이전트와 새 대화, 에이전트 설정, 채팅 검색... 네 개로 바뀌어 있으면 에이전트 대화 화면에 들어와 있는 상태입니다. 워크스페이스 에이전트에서는 에이전트 설정이 빠져 세 개만 보입니다. 뒤로를 누르면 원래 메뉴로 돌아옵니다.
