Deep Agent Builder 주요 기능

새 에이전트 화면의 두 가지 출발점​

목적 입력란은 어떤 도우미가 필요한지 설명하고 제작 대화를 시작하는 곳입니다. 역할, 입력 자료, 원하는 결과, 하지 말아야 할 추측을 함께 적으면 요구를 검토하기 쉽습니다. 전송 가능한 설명은 5자 이상 2000자 이하이며 생성 권한이 필요합니다. 제작 완료 뒤에는 바로 이용하기로 이동합니다.

에이전트 직접 만들기는 이름과 설명을 입력하는 별도 대화상자를 엽니다. 생성 후에는 수정 화면으로 이동하므로 지침과 구성을 직접 살펴야 합니다. 두 경로를 섞지 않도록 첫 실습은 시작하기의 순서를 따라가세요.

수정 화면에서 보는 항목​

에이전트 대화 화면 상단의 수정 버튼을 누르면 수정 화면으로 이동합니다. 아래 표는 첫 도우미를 다듬는 데 필요한 항목을 정리한 것입니다.

항목과 위치사용 시점입력과 결과 확인
이름·설명, 수정 화면 상단목록에서 역할을 구별하기 어려울 때알아보기 쉬운 이름과 용도를 입력하고 저장 후 다시 확인합니다.
지침, 수정 화면의 편집 영역출력 형식이나 빠진 정보 처리 방법을 바꿀 때역할·기준을 문장으로 적고 저장합니다. 대화로 실제 동작도 확인합니다.
저장, 수정 화면 상단편집 내용을 확정할 때변경한 내용이 있어야 활성화됩니다. 저장 중에는 기다리고 완료 후 설정을 다시 확인합니다.
에이전트 복제, 상단 복사 아이콘기존 구성을 바탕으로 다른 용도를 시험할 때저장된 에이전트에서 복제합니다. 새 에이전트의 수정 화면으로 이동하면 이름부터 구별합니다.
에이전트 내보내기, 저장 옆 메뉴구성 파일을 보관할 때권한이 있는 경우 내려받습니다. 성공 안내와 내려받은 압축 파일을 확인합니다.
뒤로가기 화살표, 수정 화면 상단에이전트와 실제 대화할 때저장을 먼저 마치고 대화 화면에서 시험 질문을 보냅니다.

저장이 비활성화된 상태는 변경 사항이 없거나 저장 중인 상태일 수 있습니다. 저장 버튼의 상태만으로 권한 문제라고 단정하지 마세요.

지침과 개별 요청을 나누어 쓰기​

지침에는 여러 대화에서 반복할 기준을 적습니다. “제공된 사실만 사용한다”, “누락된 장소는 먼저 질문한다”처럼 역할에 필요한 원칙이 여기에 해당합니다. 반면 이번 모임의 시간과 장소처럼 매번 달라지는 자료는 대화에서 줍니다.

지침 수정은 앞으로 어떤 답변을 원하는지 설정하는 과정입니다. 저장 성공은 답변의 정확성까지 보증하지 않으므로, 바꾼 기준이 필요한 질문을 보내 결과를 확인하세요. 변경 전후를 비교하는 절차는 반복 업무에 있습니다.

재사용 전에 확인할 것​

복제한 에이전트는 이름만 확인하지 말고 지침과 사용할 구성을 다시 읽습니다. 내보낸 파일을 내려받았다는 사실만으로 다른 환경에서 바로 실행할 준비가 끝난 것은 아닙니다. 모델이나 연결 자원의 준비 여부는 사용하려는 환경에서 확인해야 합니다.

처음에는 필요하지 않은 공유·연동 기능까지 한꺼번에 설정하기보다 도우미의 기본 응답부터 검토하세요. 활용 사례는 정보가 빠졌을 때의 응답까지 비교하는 방법을 안내합니다. 생성·저장에 문제가 있으면 문제 해결을 확인합니다.
