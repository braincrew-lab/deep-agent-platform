메뉴 안내

이 페이지는 Deep Agent Builder에 로그인했을 때 보이는 메뉴를 사이드바 위쪽부터 아래쪽, 대화 화면, 에이전트 편집 화면, 에셋 화면, 환경설정 순서로 한 번씩 소개합니다. 메뉴 이름과 위치를 먼저 익혀 두면 이후 페이지의 설명을 따라가기 쉽습니다. 각 메뉴를 자세히 다루는 페이지는 절마다 링크로 이어집니다.

이 페이지에서 할 수 있는 일

  • 사이드바 위쪽 메뉴와 더 보기 메뉴로 어떤 화면에 갈 수 있는지 확인합니다.
  • 에이전트 목록의 탭, 폴더, 에이전트별 메뉴의 위치를 익힙니다.
  • 사이드바 아래쪽 메뉴와 프로필 메뉴에서 무엇을 확인하고 바꿀 수 있는지 봅니다.
  • 대화 화면과 에이전트 편집 화면의 버튼, 에셋 화면의 탭, 환경설정 항목을 구별합니다.

전체 화면 구성​

로그인하면 왼쪽에 사이드바가 있고 오른쪽에 작업 영역이 열립니다. 별도의 상단 메뉴 바는 없으며, 메뉴는 모두 사이드바에 모여 있습니다. 처음에는 작업 영역에 새 에이전트를 만드는 홈 화면이 열립니다. 홈 화면 각 부분의 이름은 시작하기에서 설명합니다.

사이드바는 두 가지 모습으로 바뀝니다. 평소에는 메뉴와 에이전트 목록이 보이고, 에이전트를 하나 열면 그 에이전트 전용 메뉴와 채팅 목록이 보입니다. 아래쪽 메뉴와 사용자 이름은 어느 모습에서나 그대로 남습니다.

사이드바 위쪽: 주요 메뉴와 목록 도구​

사이드바 위쪽에는 화면을 옮기는 주요 메뉴와, 에이전트 목록을 다루는 탭과 도구가 있습니다. 맨 위의 로고를 누르면 어느 화면에서든 홈 화면으로 돌아오고, 로고 오른쪽의 사이드바 축소를 누르면 사이드바가 아이콘만 남은 좁은 막대로 접힙니다. 접힌 상태에서 다시 누르면 사이드바 확장으로 펼쳐지므로, 캔버스나 긴 표를 넓은 화면으로 볼 때 씁니다. 그 아래에 주요 메뉴 새 에이전트, 에이전트 템플릿, 더 보기가 이어집니다. 새 에이전트는 생성 권한이 없으면 누를 수 없습니다. 더 보기는 바로 아래 절에서 따로 설명합니다.

탭과 목록 도구는 아이콘으로만 표시되며, 마우스를 올리면 이름이 나타납니다. 목록 탭은 내가 만든 에이전트를 보여 주는 내 에이전트와, 워크스페이스에 게시된 에이전트 가운데 내가 대화한 에이전트를 워크스페이스 폴더별로 보여 주는 워크스페이스 에이전트 두 개입니다.

사이드바 위쪽 메뉴와 목록 탭

번호메뉴기능이런 때 사용하세요
1새 에이전트만들고 싶은 에이전트를 설명해 대화로 만드는 홈 화면을 엽니다. 생성 권한이 없으면 누를 수 없습니다.회의록 요약 도우미를 새로 만들 때
2에이전트 템플릿워크스페이스에 게시된 에이전트를 템플릿으로 보여 주는 화면을 엽니다.동료가 만든 에이전트 구성을 본떠 시작할 때
3내 에이전트내가 만든 에이전트 목록을 보여 줍니다.내가 만든 주간 업무 보고서 도우미를 열 때
4워크스페이스 에이전트워크스페이스에 게시된 에이전트 중 내가 대화한 에이전트를 워크스페이스 폴더별로 보여 줍니다. 아직 대화한 적이 없으면 "아직 대화한 워크스페이스 에이전트가 없습니다."가 보입니다.지난주에 써 본 동료의 게시 에이전트로 다시 들어갈 때

탭 오른쪽에는 목록 도구 아이콘 네 개가 있습니다. 이름으로 에이전트를 찾는 에이전트 검색, 숨겨 둔 에이전트를 함께 보여 주는 숨겨진 에이전트 보기(다시 누르면 숨겨진 에이전트 숨기기), 에이전트와 폴더의 이름·폴더·설명·숨김 여부를 한 창에서 고치고 변경사항 적용으로 반영하는 에이전트 관리, 새 폴더를 만드는 폴더 생성입니다.

사이드바 목록 도구

번호메뉴기능이런 때 사용하세요
1에이전트 검색목록 위에 검색란을 열어 이름으로 에이전트를 찾습니다.에이전트가 많아져 "분석"이 들어간 에이전트만 골라 볼 때
2숨겨진 에이전트 보기목록에서 숨겨 둔 에이전트를 함께 보여 줍니다. 다시 누르면(숨겨진 에이전트 숨기기) 감춥니다.시험용으로 만들었다가 숨겨 둔 에이전트를 다시 꺼낼 때
3에이전트 관리에이전트와 폴더를 한 창에서 정리합니다. 폴더 이름과 색상, 에이전트 이름·폴더·설명, 사이드바에서 숨기기를 바꾸고 변경사항 적용을 누르면 반영됩니다.분기 초에 쓰지 않는 에이전트를 숨기고 폴더를 다시 나눌 때
4폴더 생성목록에 새 폴더를 만듭니다.보고서용, 분석용 에이전트를 폴더로 나눌 때

템플릿은 에이전트 만들기, 워크스페이스 에이전트는 즐겨찾기·워크스페이스·다운로드에서 이어서 설명합니다.

더 보기 메뉴​

더 보기를 누르면 사이드바 오른쪽에 작은 메뉴가 열립니다. 메뉴 항목은 네 개입니다. 유틸리티에서는 도구, 모델, 미들웨어, 스킬을 찾아보고 설치하고, 작업에서는 백그라운드 작업과 예약 실행의 상태를 봅니다. 평가에서는 데이터셋으로 답변을 점검하고, SUPER AI 에이전트는 내 에이전트 전체에 요청을 나눠 주는 대화 화면을 엽니다. 진행 중인 백그라운드 작업이 있으면 더 보기 옆에 개수가 표시됩니다.

더 보기 메뉴

번호메뉴기능이런 때 사용하세요
1유틸리티사용 가능한 도구, 모델, 미들웨어, 스킬을 찾아보고 설치하는 화면을 엽니다. 전체와 워크스페이스 탭이 있습니다.동료나 관리자가 등록한 도구를 내 에셋에 추가할 때
2작업백그라운드 작업 화면을 엽니다. 작업 기록 탭에서 백그라운드로 실행한 작업의 상태를, 스케줄 작업 탭에서 예약 실행을 확인합니다.백그라운드 모드로 맡긴 분석이 끝났는지 확인할 때
3평가평가 화면을 엽니다. 데이터셋, 평가 실행, 평가기, 대시보드 탭이 있습니다.주간 업무 보고서 도우미의 답변을 정해 둔 질문 묶음으로 점검할 때
4SUPER AI 에이전트내 에이전트 전체에 요청을 자동으로 나눠 주는 SUPER AI 에이전트의 대화 화면을 엽니다. 처음 누르면 내 계정에 하나가 만들어집니다.어떤 에이전트에게 물어야 할지 모를 때

유틸리티는 도구와 스킬 구성, 작업은 스케줄링과 백그라운드 모드와 모니터링과 실행 상태 확인, 평가는 에이전트 평가 개요, SUPER AI 에이전트는 핵심 개념 이해하기에서 설명합니다.

에이전트 목록과 에이전트 메뉴​

목록은 폴더 단위로 묶여 있고, 폴더를 정하지 않은 에이전트는 미분류에 들어갑니다. 폴더 이름 옆 괄호에는 들어 있는 에이전트 수가 보입니다. 에이전트 이름 아래에는 설명 앞부분이 보이며, 이름을 누르면 그 에이전트의 대화 화면이 열립니다. 에이전트 이름에 마우스를 올리면 오른쪽 끝에 에이전트 옵션 버튼이 나타나고, 누르면 이름 변경, 복제, 폴더로 이동, 삭제 네 항목이 있는 메뉴가 열립니다. 삭제는 확인 창을 거칩니다. 폴더 이름에 마우스를 올리면 폴더 수정, 폴더 삭제, 에이전트 관리를 쓸 수 있고, 폴더 이름을 누르면 폴더가 접히거나 펼쳐집니다.

에이전트 목록

번호메뉴기능이런 때 사용하세요
1폴더(미분류)폴더를 접거나 펼칩니다. 폴더에 마우스를 올리면 폴더 수정, 폴더 삭제, 에이전트 관리 메뉴를 쓸 수 있습니다.지금 쓰는 폴더만 펼쳐 두고 싶을 때
2에이전트 이름누르면 그 에이전트의 대화 화면이 열립니다.주간 업무 보고서 도우미에게 이번 주 보고서를 맡길 때
3에이전트 옵션이 에이전트의 메뉴를 엽니다.이름을 바꾸거나 복제·이동·삭제할 때

에이전트 옵션을 누르면 아래와 같은 메뉴가 열립니다.

에이전트 옵션 메뉴

번호메뉴기능이런 때 사용하세요
1이름 변경목록에 보이는 이름을 바꿉니다."주간 업무 보고서 도우미"를 "주간 업무 보고서 도우미(AI혁신팀용)"처럼 용도가 드러나게 바꿀 때
2복제같은 구성으로 새 에이전트를 하나 더 만듭니다.지침만 바꿔 두 가지 보고서 형식을 비교할 때
3폴더로 이동에이전트를 다른 폴더로 옮깁니다.새로 만든 에이전트를 "데이터 분석" 폴더에 넣을 때
4삭제에이전트를 지웁니다. 확인 창을 거칩니다.시험이 끝나 더 쓰지 않을 에이전트를 정리할 때

이럴 때 쓰세요: 영업팀 동료가 주간 업무 보고서 도우미를 써 보고 싶은데 영업팀 보고 양식이 다르다고 하면, 김그루 사원은 원본을 복제한 뒤 이름 변경으로 "(영업팀용)"을 붙이고 폴더로 이동으로 보고서용 폴더에 함께 넣어 둡니다. 원본은 AI혁신팀 양식 그대로 두고 사본의 지침만 영업팀 양식에 맞춰 고치므로, 한쪽을 고치다 다른 팀 보고서가 흐트러지지 않습니다.

복제한 에이전트는 이름만 바꾸고 끝내지 말고 지침과 연결된 지식함, 스킬을 다시 확인하세요. 수정 방법은 에이전트 수정에 있습니다.

사이드바 아래쪽 메뉴​

사이드바 맨 아래에는 즐겨찾기, 에셋설정, 라운지, 환경설정 네 메뉴와 사용자 이름이 고정되어 있습니다. 목록을 아래로 내려도 이 영역은 그대로 남습니다.

즐겨찾기는 즐겨찾기한 내 에이전트와 워크스페이스 에이전트를 개인, 워크스페이스 표시와 함께 한 목록으로 보여 주는 창을 엽니다. 에셋설정은 도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드를 관리하는 에셋 화면을, 라운지는 사내 게시판을, 환경설정은 컬러 테마, 서체, 글자 크기, 표시 언어, 푸시 알림을 바꾸는 설정 화면을 엽니다. 맨 아래 사용자 이름 자리에는 내 이름과 이메일이 보이고, 누르면 프로필과 로그아웃 메뉴가 열립니다.

사이드바 아래쪽

번호메뉴기능이런 때 사용하세요
1즐겨찾기즐겨찾기 창을 엽니다. 즐겨찾기한 내 에이전트와 워크스페이스 에이전트가 한 목록에 개인, 워크스페이스 표시와 함께 모입니다.매주 쓰는 주간 업무 보고서 도우미를 목록에서 찾지 않고 바로 열 때
2에셋설정도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드를 관리하는 에셋 화면을 엽니다.에이전트에 붙일 도구나 스킬을 등록할 때
3라운지공지사항, 사용 가이드, 활용 사례, 질문을 모아 둔 사내 게시판을 엽니다.동료가 올린 에이전트 활용 사례를 찾아볼 때
4환경설정컬러 테마, 서체, 글자 크기, 표시 언어, 푸시 알림을 바꾸고 버전 정보를 보는 설정 화면을 엽니다.화면 글씨가 작아 읽기 불편할 때

맨 아래 사용자 이름은 프로필을 열거나 로그아웃할 때 누릅니다. 이어지는 절에서 설명합니다.

즐겨찾기는 즐겨찾기·워크스페이스·다운로드, 라운지는 커뮤니티에서 다룹니다.

프로필 메뉴와 프로필 화면​

에이전트 대화 화면​

목록에서 에이전트를 누르면 사이드바가 그 에이전트 전용 메뉴로 바뀌고, 작업 영역에 대화 화면이 열립니다. 사이드바에는 원래 메뉴로 돌아가는 뒤로, 지난 채팅과 섞이지 않게 새 채팅을 여는 이 에이전트와 새 대화, 에이전트 편집 화면을 여는 에이전트 설정, 채팅을 검색어로 찾는 **채팅 검색...**과 채팅 목록이 있습니다. 에이전트 설정은 워크스페이스 에이전트에서는 보이지 않습니다. 채팅에 마우스를 올리면 나타나는 버튼으로 이름 변경, 고정, 삭제를 할 수 있습니다.

화면 위쪽에는 에이전트 이름과 설명, 오른쪽에는 모델 이름과 이 채팅의 입력·출력 토큰 수, 에이전트 즐겨찾기, 앱 연동이 있습니다. 모델 이름과 사용량을 누르면 스레드 토큰 요약 창이 열려 입력, 출력, 합계 토큰과 턴별 상세를 보여 줍니다.

헤더​

헤더 왼쪽의 이름과 설명은 눌러서 바로 고칩니다. 비어 있으면 "에이전트 이름...", "에이전트 설명..."이 흐리게 보입니다. 오른쪽에는 워크스페이스 등록, 코드 스니펫, 버전 안내, 에이전트 복제, 에이전트 삭제, 지금 버전 표시, 저장, 저장 옵션 더 보기가 있습니다. 워크스페이스 등록은 팀이 함께 쓰도록 등록을 요청하는 창을, 코드 스니펫은 다른 시스템에서 이 에이전트를 부르는 예시 코드를, 버전 안내는 저장과 버전이 어떻게 동작하는지 설명하는 창을 엽니다. 버전 표시를 누르면 다른 버전으로 전환하고, 저장 옵션 더 보기에서는 새 버전으로 저장과 에이전트 내보내기를 고릅니다. 삭제 권한이 없으면 에이전트 삭제가 흐리게 보이고 마우스를 올리면 "삭제 권한이 없습니다. 관리자에게 문의하세요."가 나옵니다. 워크스페이스 등록으로 커뮤니티에 배포되었거나 배포 요청이 심사 중인 에이전트는 확인 창에서 삭제를 눌러도 지워지지 않고 "커뮤니티에 배포되었거나 배포 요청 중인 에이전트는 삭제할 수 없습니다. 커뮤니티 관리에서 배포를 먼저 정리한 뒤 다시 시도해 주세요."가 나옵니다.

에이전트 편집 화면 헤더의 저장과 버전

번호메뉴기능이런 때 사용하세요
1에이전트 삭제에이전트를 지웁니다. 삭제 권한이 없으면 누를 수 없고, 커뮤니티에 배포되었거나 배포 요청 중인 에이전트는 배포를 먼저 정리해야 지울 수 있습니다.더 쓰지 않는 에이전트를 정리할 때
2버전 표시현재 버전:V1처럼 지금 버전을 보여 주고, 눌러서 다른 버전으로 전환합니다.지난 버전으로 되돌려 비교할 때
3저장바꾼 이름, 설명, 지침과, 바로 반영된 다른 변경을 현재 버전에 저장합니다.지침을 고친 뒤 확정할 때
4저장 옵션 더 보기새 버전으로 저장과 에이전트 내보내기를 고릅니다.큰 변경을 새 버전으로 남기거나 ZIP 파일로 내보낼 때

이름, 설명, 지침은 헤더의 저장을 눌러야 현재 버전에 저장되며, 저장하기 전의 지침은 대화와 테스트 탭에 쓰이지 않습니다. 도구, 모델, 오프너, 스킬, 지식, 미들웨어, 서브에이전트, 설정 탭의 에이전트 모드와 Webhook 활성화, 그리고 Fix 에이전트가 적용한 변경은 바꾸는 즉시 대화와 테스트에 반영됩니다. 다만 이런 변경도 현재 버전에 기록하려면 저장 옆에 "저장되지 않은 변경이 있습니다"가 보일 때 저장을 누릅니다. 워크스페이스 등록은 저장된 버전으로 하므로 등록을 요청하기 전에 저장합니다. 자세한 내용은 에이전트 수정, 워크스페이스 등록은 커뮤니티, 코드 스니펫은 코드 스니펫과 외부 API, 내보내기는 에이전트 가져오기와 내보내기에 있습니다.

따라 해 보기​

김그루 사원이 판매 실적 분석을 맡기면서 메뉴를 한 바퀴 돌아보는 순서입니다. 첨부할 파일은 브레인크루_2026_판매실적.xlsx입니다.

  1. 사이드바 내 에이전트 목록에서 판매 데이터 분석가를 누릅니다.

  2. 사이드바가 이 에이전트 메뉴로 바뀌면 이 에이전트와 새 대화를 누릅니다.

  3. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_2026_판매실적.xlsx를 첨부합니다. 새 대화에서는 첨부한 파일이 입력란 위에 파일 이름으로 남아 있다가 전송을 누를 때 올라갑니다.

  4. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다. "업로드 중...", "파일 처리 중..."이 차례로 보인 뒤 파일 처리가 끝나면 질문이 전달됩니다.

    프롬프트: 첨부한 엑셀의 판매내역 시트로 2026년 1월부터 10월까지 지역별 매출 합계를 표로 정리하고, 목표 시트와 비교해 지역별 달성률을 알려 주세요.

  5. 답변이 끝나면 입력란 아래 오른쪽의 아티팩트를 눌러 결과 표를 열어 봅니다.

  6. 다음 달에도 쓸 예정이면 화면 오른쪽 위의 에이전트 즐겨찾기를 눌러 둡니다. 이후에는 사이드바 아래쪽 즐겨찾기에서 바로 열 수 있습니다.

팁: 사이드바 위쪽 메뉴가 뒤로, 이 에이전트와 새 대화, 에이전트 설정, 채팅 검색... 네 개로 바뀌어 있으면 에이전트 대화 화면에 들어와 있는 상태입니다. 워크스페이스 에이전트에서는 에이전트 설정이 빠져 세 개만 보입니다. 뒤로를 누르면 원래 메뉴로 돌아옵니다.
