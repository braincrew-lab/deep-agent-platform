데이터 분석

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 판매 데이터 분석가에게 브레인크루_2026_판매실적.xlsx 파일을 맡겨 지역별 매출 순위, 제품별 월 추이 차트, 이상치 목록을 받고, 결과를 엑셀 파일로 내려받는 과정을 화면 순서대로 안내합니다. 아래 따라 해 보기의 단계는 모두 김그루 사원이 직접 하는 순서입니다. 에이전트가 낸 숫자를 원본과 대조해 검증하는 방법과, 에이전트가 질문을 잘못 읽었을 때 바로잡는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 엑셀이나 CSV 파일을 첨부해 질문하고, 에이전트가 실행한 분석 코드와 결과를 직접 확인합니다.
  • 결과 표와 차트를 읽고, 데이터 표를 Excel이나 CSV 파일로 내려받습니다.
  • 여러 분석 결과를 시트 3개짜리 엑셀 파일 하나로 받아 아티팩트 창에서 미리 봅니다.
  • 원본 데이터 200행 전체를 화면에서 넘겨 보고 Word, PPTX, HTML, Excel, CSV 형식으로 내보냅니다.
  • 시트가 두 개인 엑셀 파일에서 목표 시트까지 읽혀 지역별 목표 대비 달성률을 받습니다.
  • 보고에 쓰기 전에 에이전트가 낸 숫자를 원본 파일과 대조해 검증합니다.
  • 달성률이 가장 낮은 지역의 연말 전망을 받아, 남은 두 달에 필요한 매출을 짚습니다.

분석 전에 준비할 것​

판매 데이터 분석가는 별도 도구를 연결하지 않아도 됩니다. 데이터 분석과 데이터 시각화 기능은 모든 에이전트에 기본으로 들어 있어서, 파일을 첨부하고 질문하면 에이전트가 직접 분석 코드를 작성해 실행하고 결과를 표와 차트로 보여 줍니다.

이 페이지의 예시 파일은 브레인크루_2026_판매실적.xlsx(가상 데이터)입니다. 시트가 두 개 있습니다.

  • 판매내역 시트: 2026년 1~10월 판매 기록 200행입니다. 열은 월, 지역, 제품, 판매수량, 단가(원), 매출(원), 담당팀 일곱 개입니다. 월 열에는 2026-01처럼 연도와 월이 함께 적혀 있습니다. 지역은 서울, 경기, 부산, 대구, 광주 5곳, 제품은 AI 회의록 솔루션, 문서 자동화 패키지, 데이터 분석 구독, 교육 컨설팅 4종입니다.
  • 목표 시트: 지역별 연간 목표 매출(원) 5행입니다.

파일을 준비할 때는 아래를 확인합니다.

  • 첫 행에 열 이름이 있는 엑셀 또는 CSV 파일을 준비합니다. 데이터 분석에 쓸 수 있는 형식은 .xlsx, .xls, .xlsb, .xlsm, .csv입니다.
  • 파일 하나는 50MB를 넘을 수 없습니다. 더 큰 파일은 시트나 기간을 나눠 올립니다.
  • 고객 이름, 연락처처럼 개인을 알아볼 수 있는 열은 지우고 집계에 필요한 열만 남깁니다.
  • 질문에는 무엇을 기준으로 계산할지 적습니다. 예를 들어 달성률을 연간 목표로 나눌지, 경과 기간(10개월)만큼 나눈 목표로 나눌지 밝힙니다.
  • 질문에 계산에 쓸 열 이름을 그대로 적습니다. 이 페이지의 예시에서도 에이전트가 파일에 없는 "일자", "매출액" 열을 찾다가 계산을 멈춘 적이 있습니다. "월 열", "매출(원) 열"처럼 실제 열 이름을 적으면 이런 일이 줄어듭니다.

판매 데이터 분석가가 아직 없다면 에이전트 만들기의 직접 만들기로 만들고, 지침에 아래 내용을 넣습니다. 이 페이지의 화면은 이 지침으로 만든 에이전트에서 찍었습니다.

프롬프트: 너는 브레인크루 영업기획 데이터를 분석하는 판매 데이터 분석가다. 첨부한 엑셀·CSV 파일의 숫자는 반드시 코드로 계산한다. 금액은 원 단위에 천 단위 쉼표를 붙이고, 비율은 소수 첫째 자리까지 %로 쓴다. 결과는 표로 먼저 보여 주고, 계산 기준(합계·평균, 기간, 사용한 시트)을 답변 끝에 한 줄로 적는다. 파일에 없는 숫자는 만들지 않는다.

파일 첨부와 첫 질문​

에이전트 대화 화면에서 엑셀 파일을 첨부하고 질문을 보냅니다. 에이전트는 분석 코드를 실행한 뒤 결과 표를 답변에 붙입니다. 답변 위에는 분석 코드를 실행한 데이터 분석 기록이, 그 아래에는 결과를 담은 데이터 표 카드가 생깁니다. 카드의 내보내기로 Excel로 내보내기 또는 CSV로 내보내기를 고르면 표를 내려받을 수 있고, 클릭하여 확인하기를 누르면 아티팩트 창에서 표를 크게 엽니다. 입력란 아래 오른쪽의 아티팩트 버튼에는 이 대화에서 모인 표와 파일 개수가 숫자로 붙습니다.

파일 첨부와 첫 질문

번호메뉴기능이런 때 사용하세요
1첨부 파일내 질문과 함께 보낸 파일 이름과 형식(XLSX)을 보여 줍니다.어느 파일로 분석했는지 나중에 채팅을 다시 열어 확인할 때
2질문내가 보낸 질문입니다.같은 분석을 다음 달 파일로 다시 맡기려고 질문 문장을 복사할 때
3데이터 분석에이전트가 분석 코드를 실행한 기록입니다. 오른쪽에 실행 시간이 보이고, 누르면 펼쳐집니다.합계를 어떤 열로 냈는지 확인할 때

데이터 표 카드

번호메뉴기능이런 때 사용하세요
1데이터 표에이전트가 계산한 결과를 표 카드로 보여 줍니다.답변 본문보다 먼저 결과 숫자를 훑어볼 때
2내보내기데이터 표를 Excel로 내보내기 또는 CSV로 내보내기로 내려받습니다.결과 표를 내 PC에서 엑셀로 열어 보고 싶을 때
3클릭하여 확인하기데이터 표를 아티팩트 창에서 크게 엽니다.표가 길어 카드 안에서 다 보이지 않을 때
4아티팩트이 대화에서 만들어진 표와 파일 목록 창을 엽니다. 숫자 배지는 모인 개수입니다.앞서 만든 결과 표와 엑셀 파일을 한곳에서 다시 볼 때

따라 해 보기​

  1. 김그루 사원은 사이드바 내 에이전트에서 판매 데이터 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드(클립 아이콘)를 눌러 브레인크루_2026_판매실적.xlsx를 고릅니다.

  3. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 판매실적 파일의 판매내역 시트에서 지역별 매출(원) 합계를 큰 순서로 표로 보여 주세요. 순위, 지역, 매출 합계, 전체 대비 비중(%)을 열로 넣고, 맨 아래에 전체 합계 행을 붙여 주세요.

  4. 답변 위쪽에 데이터 분석 기록과 데이터 표 카드가 나타나면 분석이 실행된 것입니다.

실행한 코드와 결과 확인​

에이전트가 계산한 숫자의 출처는 데이터 분석 기록에 남습니다. 기록을 펼치면 실행한 코드가 그대로 있어, 답변에 적힌 숫자가 어떤 시트와 열에서 나왔는지 따라가 볼 수 있습니다. 코드가 표를 만들면 그 결과가 바로 아래 데이터 표 카드로 나오고, 코드가 글이나 숫자를 출력하면 출력 (데이터 분석) 기록이 따로 생깁니다.

실행 코드와 결과

번호메뉴기능이런 때 사용하세요
1데이터 분석코드 실행 기록의 제목 줄입니다. 누르면 펼치거나 접습니다.분석 과정을 펼쳐 보거나, 다 본 뒤 접어 화면을 정리할 때
2실행 코드에이전트가 작성해 실행한 분석 코드입니다. 판매내역 시트를 읽어 지역별로 매출(원)을 더하고(groupby), 전체 대비 비중을 계산한 과정이 보입니다.어느 시트와 어느 열로 계산했는지, 빠진 조건은 없는지 확인할 때
3데이터 표위 코드가 만든 결과 표입니다. 지역 5곳의 매출 합계와 전체 합계가 나옵니다.답변 본문의 표와 코드 결과가 같은지 대조할 때

따라 해 보기​

  1. 답변 위쪽의 데이터 분석을 눌러 펼칩니다.
  2. 코드에서 판매내역 시트의 매출(원) 열을 지역별로 더했는지 확인합니다. 판매수량이나 단가(원)를 더했다면 질문과 다른 계산입니다.
  3. 바로 아래 데이터 표의 숫자와 답변 본문 표의 숫자가 같은지 비교합니다.

팁: 한 질문에 데이터 분석 기록이 여러 개 생길 수 있습니다. 에이전트가 파일 구조를 먼저 확인하고, 계산을 나눠 실행하기 때문입니다. 마지막 기록의 결과가 답변 표와 맞는지 보면 됩니다.

결과 표 읽기​

데이터 분석이 끝나면 에이전트가 결과 표를 답변 본문에 다시 정리하고, 지침대로 계산 기준을 한 줄로 덧붙입니다.

지역별 매출 순위 답변

번호영역기능이런 때 사용하세요
1파일 요약읽은 파일의 행 수(200), 분석 기간(2026-01 ~ 2026-10), 지역 수(5), 제품 수(4)를 한 줄로 적습니다.파일이 빠짐없이 읽혔는지 먼저 확인할 때
2매출 열지역별 매출 합계입니다. 1위 서울 1,307,210,000원(34.9%), 2위 경기 976,570,000원(26.1%), 3위 부산 632,860,000원(16.9%), 4위 대구 469,840,000원(12.5%), 5위 광주 362,240,000원(9.7%)입니다.영업회의 자료에 지역별 실적 순위를 넣을 때
3전체 합계다섯 지역을 더한 매출 3,748,720,000원입니다. 비중 열에는 100.0%가 붙습니다.같은 파일로 만든 다른 보고서의 총매출과 맞춰 볼 때

따라 해 보기​

  1. 순위 표에서 매출 합계와 비중 열을 읽습니다. 1위 서울 1,307,210,000원(34.9%), 2위 경기 976,570,000원(26.1%), 3위 부산 632,860,000원(16.9%), 4위 대구 469,840,000원(12.5%), 5위 광주 362,240,000원(9.7%)이어야 합니다.
  2. 전체 합계 행이 3,748,720,000원인지 봅니다.
  3. 파일 요약 줄에서 행 수 200, 기간 2026-01 ~ 2026-10, 지역 5, 제품 4인지 확인합니다.

결과를 이렇게 확인하세요​

  • 표 머리에 단위가 붙었는지 봅니다. 매출은 원, 비중은 %로 적혀 있어야 보고서로 옮길 때 단위를 다시 확인하지 않아도 됩니다.
  • 비중 다섯 개를 그대로 더하면 100.1%가 됩니다. 각 비중을 소수 첫째 자리로 반올림했기 때문이며, 전체 합계 행의 100.0%는 반올림 전 값으로 계산한 것입니다.
  • 데이터 표 카드 맨 왼쪽의 0, 1, 2 같은 숫자는 계산 과정의 행 번호이며 순위가 아닙니다. 순위는 순위 열에서 읽습니다.
  • 파일 요약 줄의 행 수(200)는 원본 판매내역 시트의 행 수와 같아야 합니다. 같은 질문을 다시 보냈을 때 행 수나 기간이 원본과 다르게 적힌 답변이 나온 적이 있으므로, 요약 줄이 이상하면 이 페이지 뒤쪽의 전체 데이터 보기와 내보내기에서 표 크기(200 x 7)로 다시 확인합니다.

차트 만들기​

표만으로 흐름이 잘 보이지 않으면 차트를 요청합니다. 에이전트가 차트 그리기 코드를 실행해 그림을 답변에 넣고, 같은 숫자를 표로도 정리해 줍니다. 답변 위에는 차트를 그린 데이터 시각화 기록과 그 결과인 출력 (데이터 시각화) 기록이 남고, 누르면 펼쳐집니다.

제품별 월 추이 차트

번호메뉴기능이런 때 사용하세요
1데이터 시각화차트를 그린 코드 실행 기록입니다. 누르면 펼쳐집니다.차트에 어떤 열을 썼는지 확인할 때
2출력 (데이터 시각화)차트 실행 결과 기록입니다. 제목 끝에 만들어진 그림 수(1 figure)가 붙습니다.그림이 몇 장 만들어졌는지 확인할 때

  • 연말 예상 매출은 1~10월 합계에 월평균 × 2를 더한 값이어야 합니다. 광주는 362,240,000 + 36,224,000 × 2 = 434,688,000원입니다.
  • 예상 달성률은 앞에서 받은 경과 목표(10/12) 대비 달성률과 같아야 합니다. 월평균을 그대로 이어 가는 가정이라 두 계산이 같은 값이 됩니다(광주 77.62%).
  • 남은 두 달 필요 배수가 가장 큰 지역부터 광주 2.73배, 부산 2.51배, 대구 2.45배, 서울 2.27배, 경기 2.17배인지 봅니다. 다섯 지역 모두 월평균의 2배 이상이 필요하므로, 지금 속도로는 연간 목표를 채우기 어렵다고 읽을 수 있습니다. 답변은 "최근 월평균 대비 2배 이상 수준"이라고만 적고 달성 가능성은 판단하지 않았으므로, 보고서의 결론 문장은 직접 씁니다.
  • 원인을 짚으려면 이어서 광주의 제품별 매출 비중을 물어봅니다. 예시 파일로 계산하면 광주는 교육 컨설팅 31.9%, 데이터 분석 구독 30.3%, 문서 자동화 패키지 19.0%, AI 회의록 솔루션 18.8%로 전체 비중과 비슷해서, 특정 제품 문제라기보다 지역 전체 규모의 문제로 읽힙니다. 원인은 영업3팀 의견을 받아 씁니다.

분석 결과를 문서로 이어 가기​

분석이 끝난 숫자를 보고용 PPT나 문서로 옮길 때는 문서작성 에이전트를 씁니다. 판매 데이터 분석가에게 받은 엑셀 파일을 제안서 PPT 작성기 같은 문서작성 에이전트에 올려 요청하면, 결과물이 대화 화면 오른쪽 캔버스에 열립니다. 만드는 순서는 캔버스로 문서·PPT·표 만들기와 PPT·문서 만들기에 있고, 같은 파일로 처음부터 끝까지 진행한 예시는 사례: 엑셀 판매 데이터 분석에 있습니다.
