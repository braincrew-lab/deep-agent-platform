데이터 분석

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 판매 데이터 분석가에게 브레인크루_2026_판매실적.xlsx 파일을 맡겨 지역별 매출 순위, 제품별 월 추이 차트, 이상치 목록을 받고, 결과를 엑셀 파일로 내려받는 과정을 화면 순서대로 안내합니다. 아래 따라 해 보기의 단계는 모두 김그루 사원이 직접 하는 순서입니다. 에이전트가 낸 숫자를 원본과 대조해 검증하는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 엑셀이나 CSV 파일을 첨부해 질문하고, 에이전트가 실행한 분석 코드와 출력을 직접 확인합니다.
  • 결과 표와 차트를 읽고, 데이터 표를 Excel이나 CSV 파일로 내려받습니다.
  • 여러 분석 결과를 시트 3개짜리 엑셀 파일 하나로 받아 아티팩트 창에서 미리 봅니다.
  • 원본 데이터 200행 전체를 화면에서 넘겨 보고 Word(.doc), PowerPoint(.pptx), HTML(.html), Excel(.xlsx), CSV(.csv) 파일로 내보냅니다.
  • 시트가 두 개인 엑셀 파일에서 목표 시트까지 읽혀 지역별 목표 대비 달성률을 받습니다.
  • 보고에 쓰기 전에 에이전트가 낸 숫자를 원본 파일과 대조해 검증합니다.
  • 달성률이 가장 낮은 지역의 연말 전망을 받아, 남은 두 달에 필요한 매출을 짚습니다.

분석 전에 준비할 것​

판매 데이터 분석가는 별도 도구를 연결하지 않아도 됩니다. 데이터 분석과 데이터 시각화 기능은 모든 에이전트에 기본으로 들어 있어서, 파일을 첨부하고 질문하면 에이전트가 직접 분석 코드를 작성해 실행하고 결과를 표와 차트로 보여 줍니다.

이 페이지의 예시 파일은 브레인크루_2026_판매실적.xlsx(가상 데이터)입니다. 시트가 두 개 있습니다.

  • 판매내역 시트: 2026년 1~10월 판매 기록 200행입니다. 열은 월, 지역, 제품, 판매수량, 단가(원), 매출(원), 담당팀 일곱 개입니다. 지역은 서울, 경기, 부산, 대구, 광주 5곳, 제품은 AI 회의록 솔루션, 문서 자동화 패키지, 데이터 분석 구독, 교육 컨설팅 4종입니다.
  • 목표 시트: 지역별 연간 목표 매출(원)입니다.

파일을 준비할 때는 아래를 확인합니다.

  • 첫 행에 열 이름이 있는 엑셀 또는 CSV 파일을 준비합니다. 데이터 분석에 쓸 수 있는 형식은 .xlsx, .xls, .xlsb, .xlsm, .csv입니다.
  • 파일 하나는 50MB를 넘을 수 없습니다. 더 큰 파일은 시트나 기간을 나눠 올립니다.
  • 고객 이름, 연락처처럼 개인을 알아볼 수 있는 열은 지우고 집계에 필요한 열만 남깁니다.
  • 질문에는 무엇을 기준으로 계산할지 적습니다. 예를 들어 달성률을 연간 목표로 나눌지, 경과 기간(10개월)만큼 나눈 목표로 나눌지 밝힙니다.

판매 데이터 분석가가 아직 없다면 에이전트 만들기의 직접 만들기로 만들고, 지침에 아래 내용을 넣습니다.

프롬프트: 너는 브레인크루 영업기획 데이터를 분석하는 판매 데이터 분석가다. 첨부한 엑셀·CSV 파일의 숫자는 반드시 코드로 계산한다. 금액은 원 단위에 천 단위 쉼표를 붙이고, 비율은 소수 첫째 자리까지 %로 쓴다. 결과는 표로 먼저 보여 주고, 계산 기준(합계·평균, 기간, 사용한 시트)을 답변 끝에 한 줄로 적는다. 파일에 없는 숫자는 만들지 않는다.

파일 첨부와 첫 질문​

에이전트 대화 화면에서 엑셀 파일을 첨부하고 질문을 보냅니다. 에이전트는 먼저 파일을 읽어 데이터 구조를 확인하고, 분석 코드를 실행한 뒤 결과 표를 답변에 붙입니다. 답변 위에는 분석 코드를 실행한 데이터 분석 기록이, 답변에는 결과를 담은 데이터 표 카드가 생깁니다. 카드의 내보내기로 Excel로 내보내기 또는 CSV로 내보내기를 고르면 표를 내려받을 수 있고, 클릭하여 확인하기를 누르면 아티팩트 창에서 표를 크게 엽니다. 입력란 아래 오른쪽의 아티팩트 버튼에는 이 대화에서 모인 표와 파일 개수가 숫자로 붙습니다.

따라 해 보기​

  1. 김그루 사원은 사이드바 내 에이전트에서 판매 데이터 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드(클립 아이콘)를 눌러 브레인크루_2026_판매실적.xlsx를 고릅니다.

  3. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 판매실적 파일의 판매내역 시트에서 지역별 매출(원) 합계를 큰 순서로 표로 보여 주세요. 순위, 지역, 매출 합계, 전체 대비 비중(%)을 열로 넣고, 맨 아래에 전체 합계 행을 붙여 주세요.

  4. 답변 위쪽에 데이터 분석 기록과 데이터 표 카드가 나타나면 분석이 실행된 것입니다.

실행한 코드와 출력 확인​

에이전트가 계산한 숫자의 출처는 데이터 분석 기록에 남습니다. 기록을 펼치면 실행한 코드와 그 코드가 낸 출력이 그대로 있어, 답변에 적힌 숫자가 어디서 나왔는지 따라가 볼 수 있습니다.

따라 해 보기​

  1. 답변 위쪽의 데이터 분석을 눌러 펼칩니다.
  2. 코드에서 판매내역 시트의 매출(원) 열을 지역별로 더했는지 확인합니다. 판매수량이나 단가(원)를 더했다면 질문과 다른 계산입니다.
  3. 출력 (데이터 분석) 아래 숫자와 답변 본문 표의 숫자가 같은지 비교합니다.

팁: 한 질문에 데이터 분석 기록이 여러 개 생길 수 있습니다. 에이전트가 파일 구조를 먼저 확인하고, 계산을 나눠 실행하기 때문입니다. 마지막 기록의 출력이 답변 표와 맞는지 보면 됩니다.

결과 표 읽기​

데이터 분석이 끝나면 에이전트가 데이터 구조와 결과 표를 답변 본문에 정리합니다. 표를 보기 전에 데이터 구조 요약에서 파일이 빠짐없이 읽혔는지 확인합니다.

따라 해 보기​

  1. 데이터 구조 요약에서 행 수가 200행, 기간이 2026-01~2026-10인지 확인합니다.
  2. 순위 표에서 매출 합계와 비중 열을 읽습니다. 1위 서울 1,307,210,000원(34.9%), 2위 경기 976,570,000원(26.1%), 3위 부산 632,860,000원(16.9%), 4위 대구 469,840,000원(12.5%), 5위 광주 362,240,000원(9.7%)이어야 합니다.
  3. 비중을 모두 더하면 100%에 가까운지, 전체 합계가 3,748,720,000원인지 봅니다. 비중은 소수 첫째 자리로 반올림한 값이라, 더한 값이 반올림 때문에 이 예시의 100.1%처럼 100%와 조금 달라질 수 있습니다.

결과를 이렇게 확인하세요​

  • 데이터 구조 요약이 "200행 × 7열", 기간 2026-01 ~ 2026-10, 지역 5곳, 결측값 없음인지 봅니다. 하나라도 다르면 파일 일부가 읽히지 않은 것입니다.
  • 표 머리에 단위가 붙었는지 봅니다. 매출은 원, 비중은 %로 적혀 있어야 보고서로 옮길 때 단위를 다시 확인하지 않아도 됩니다.
  • 데이터 표 카드 맨 왼쪽의 0, 1, 2 같은 숫자는 계산 과정의 행 번호이며 순위가 아닐 수 있습니다. 순위는 순위 열에서 읽습니다.

차트 만들기​

표만으로 흐름이 잘 보이지 않으면 차트를 요청합니다. 에이전트가 차트 그리기 코드를 실행해 그림을 답변에 넣고, 같은 숫자를 표로도 정리해 줍니다. 답변 위에는 차트를 그린 데이터 시각화 기록과 그 결과인 출력 (데이터 시각화) 기록이 남고, 누르면 펼쳐집니다.

따라 해 보기​

  1. 같은 대화에서 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 제품별 월별 매출(원) 합계를 표로 만들고, 추이를 선 차트로 그려 주세요. 월 전체 매출이 다른 달보다 뚜렷하게 많은 달이 있으면, 나머지 달 평균과 비교해 몇 % 많은지 함께 적어 주세요.

  2. 차트가 나타나면 범례에서 제품 색을 확인하고, 매출이 튀는 달을 찾습니다.

  3. 월별 표에서 3월과 9월 숫자가 차트의 꼭짓점과 같은지 봅니다. 네 제품 모두 3월과 9월에 솟아오르고, 월 전체 매출은 3월 459,270,000원, 9월 448,760,000원으로 나머지 8개월 평균 355,086,250원보다 각각 29.3%, 26.4% 많아야 합니다. 교육 컨설팅은 3월 159,600,000원, 9월 149,100,000원입니다.

팁: 차트의 점 하나하나는 아래 월별 표의 숫자와 같아야 합니다. 보고서에는 차트와 함께 표 숫자를 적어 두면 읽는 사람이 다시 확인할 수 있습니다.

이상치 찾기​

원본에 입력 실수나 특이한 판매가 섞여 있으면 평균과 추이가 흔들립니다. 판정 기준을 정해 이상치를 찾아 달라고 하면, 에이전트가 기준값과 해당 행을 표로 보여 줍니다.

따라 해 보기​

  1. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 판매내역 시트의 매출(원)에서 이상치를 찾아 주세요. 사분위수 범위(IQR) 1.5배 기준으로 판정하고, 판정 기준값과 해당 행을 표로 보여 주세요.

  2. 판정 기준 표에서 상한과 하한을 확인합니다. 매출(원)의 1사분위수는 10,382,500원, 3사분위수는 25,242,500원, 사분위수 범위(IQR)는 14,860,000원입니다. 하한은 1사분위수에서 IQR의 1.5배를 뺀 -11,907,500원으로 0보다 작아서 하한 아래에 있는 행은 없고, 상한은 3사분위수에 IQR의 1.5배를 더한 47,532,500원입니다.

  3. 이상치 목록의 월, 지역, 제품으로 원본 파일을 걸러 같은 행이 있는지 확인합니다. 200행 중 2행이 상한을 넘었고, 둘 다 서울의 교육 컨설팅입니다(2026-03 58,800,000원, 2026-09 52,500,000원).

팁: 이상치는 틀린 값이라는 뜻이 아닙니다. 이 예시의 2행은 단가가 가장 높은 교육 컨설팅(2,100,000원)이 매출이 가장 큰 서울에서 성수기에 많이 팔린 결과로, 실제 영업 결과일 수 있습니다. 지우거나 고치기 전에 담당팀(영업1팀)에 값이 맞는지 확인하세요. 사분위수 계산 방식에 따라 기준값이 조금 달라질 수 있으니 코드도 함께 봅니다.

결과 파일 내려받기​

여러 번에 나눠 받은 분석 결과는 엑셀 파일 하나로 모아 달라고 요청합니다. 에이전트가 시트를 나눠 파일을 만들고, 답변에 다운로드 링크를 붙입니다.

따라 해 보기​

  1. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 지금까지 만든 지역별 매출 순위, 제품별 월별 추이, 이상치 목록을 시트 3개짜리 엑셀 파일로 만들어 내려받을 수 있게 해 주세요.

  2. 시트 구성 표에서 시트 3개와 행 수를 확인합니다. 지역별 순위는 5행(전체 합계 행을 넣었다면 6행), 제품별 월별 추이는 제품 4행 또는 월 10행, 이상치 목록은 2행이어야 합니다.

  3. 다운로드 링크를 눌러 파일을 저장합니다.

파일 이름과 시트 이름은 요청할 때마다 조금씩 달라질 수 있습니다. 이때도 시트 수와 행 수가 맞는지만 확인하면 됩니다. 에이전트가 만든 파일은 일정 기간이 지나면 내려받을 수 없게 되므로, 필요한 파일은 바로 저장해 둡니다.

아티팩트 창​

입력란 아래 오른쪽의 아티팩트를 누르면 이 대화에서 만들어진 데이터 표와 파일이 한 창에 모입니다. 엑셀 파일은 내려받기 전에 여기서 시트별로 미리 봅니다. 왼쪽 목록에서 항목을 고르면 오른쪽에 내용이 보입니다. 미리보기와 코드로 보기 방식을 바꾸고, 파일은 다운로드로 받거나 인쇄로 출력합니다. 더보기를 누르면 파일 이름, 형식, 크기를 담은 문서 속성이 보입니다. 엑셀 파일은 아래쪽 시트 탭으로 시트를 바꿔 봅니다.

따라 해 보기​

  1. 입력란 아래 오른쪽의 아티팩트를 누릅니다.
  2. 왼쪽 목록에서 판매실적_분석_요약.xlsx를 누릅니다.
  3. 아래쪽 시트 탭을 눌러 세 시트를 차례로 확인합니다.
  4. 지역별 순위 시트의 숫자가 앞의 답변 표(서울 1,307,210,000원부터 광주 362,240,000원까지)와 같은지 봅니다.

전체 데이터 보기와 내보내기​

데이터 표 카드는 처음에 일부 행만 보여 줍니다. 아티팩트 창에서 전체 데이터 보기로 바꾸면 전체 데이터를 다시 불러와 페이지 단위로 넘겨 볼 수 있고, 원하는 형식으로 내보낼 수도 있습니다. 전체 행·열 수(이 예시는 200 × 7)가 함께 표시되고, 처음·이전·다음·마지막 페이지 버튼으로 넘깁니다. 간단하게 보기를 누르면 일부 행만 보는 화면으로 돌아갑니다. 내보내기를 누르면 Word로 내보내기, PPTX로 내보내기, HTML 다운로드, Excel로 내보내기, CSV로 내보내기 중에서 고를 수 있습니다.

따라 해 보기​

  1. 아티팩트 창 왼쪽 목록에서 원본 행을 담은 데이터 표를 누릅니다.
  2. 전체 데이터 보기를 누르고 표 크기가 200 × 7인지 확인합니다.
  3. 왼쪽 아래 내보내기를 누르고 Excel로 내보내기를 고릅니다.

팁: 시간이 지나 원본 데이터가 남아 있지 않으면 "원본 데이터가 더 이상 남아 있지 않아 불러올 수 없습니다. 에이전트에게 표를 다시 만들어 달라고 요청해 주세요."가 표시됩니다. 같은 대화에서 표를 다시 만들어 달라고 요청하세요. 아티팩트 내보내기는 PDF 형식을 지원하지 않습니다.

엑셀 파일 첨부와 두 번째 시트 읽기​

엑셀 파일에 시트가 여러 개 있으면 질문에 시트 이름을 적어 함께 쓰도록 요청합니다. 여기서는 새 대화에서 같은 파일을 다시 올려 목표 시트의 연간 목표와 판매내역을 비교합니다. 첨부할 수 있는 형식과 업로드 상태 표시는 첨부파일 지원에, 용량과 차단 규칙은 파일 첨부 정책과 가드레일에 있습니다.

엑셀 파일을 보내면 에이전트가 먼저 데이터 테이블 미리보기로 시트 내용을 읽은 뒤 분석을 실행합니다.

따라 해 보기​

  1. 사이드바의 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드를 눌러 브레인크루_2026_판매실적.xlsx를 고릅니다.

  3. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 파일의 판매내역 시트와 목표 시트를 함께 써서 지역별 목표 대비 달성률을 계산해 주세요. 1~10월 매출 합계를 연간 목표 매출로 나눈 달성률과, 연간 목표를 10/12로 줄인 경과 목표 대비 달성률을 둘 다 표로 보여 주세요.

  4. 결과 표에서 지역별 달성률을 확인합니다. 연간 목표 기준으로는 경기 69.8%, 서울 68.8%, 대구 67.1%, 부산 66.6%, 광주 64.7%, 전체 68.0%이고, 경과 목표(10/12) 기준으로는 경기 83.7%, 서울 82.6%, 대구 80.5%, 부산 79.9%, 광주 77.6%입니다. 답변 위에 에이전트가 엑셀 파일을 읽은 데이터 테이블 미리보기 기록이 있으면 펼쳐 판매내역과 목표 두 시트를 모두 읽었는지 봅니다.

팁: 매출 1위는 서울이지만 달성률 1위는 경기입니다. 순위는 무엇을 기준으로 냈는지에 따라 달라지므로, 보고서에는 기준(매출 합계인지 달성률인지, 연간 목표인지 경과 목표인지)을 꼭 함께 적습니다.

결과 표의 열 이름이 질문과 정확히 일치하지 않을 수 있습니다. 열 이름이 애매하면 같은 대화에서 아래처럼 다시 물어 확인하세요.

프롬프트: 이 표의 달성률 열은 어떤 목표 값으로 나눈 것인가요?

한 단계 더: 연말 달성 전망 받아 보기​

달성률을 받은 뒤에는 "올해 목표를 채울 수 있는가"를 묻게 됩니다. 같은 대화에서 지금까지의 월평균으로 11~12월을 채웠을 때의 연말 전망과, 목표를 채우려면 남은 두 달에 얼마가 필요한지 물어봅니다.

프롬프트: 110월 월평균 매출이 1112월에도 이어진다고 가정해 지역별 연말 예상 매출과 연간 목표 대비 예상 달성률을 표로 보여 주세요. 연간 목표를 채우려면 남은 두 달 동안 월마다 얼마가 필요한지, 그 금액이 지금 월평균의 몇 배인지도 함께 적어 주세요. 금액은 원, 비율은 %, 배수는 배로 단위를 붙여 주세요.

결과를 이렇게 확인하세요​

  • 연말 예상 매출은 1~10월 합계에 월평균 × 2를 더한 값이어야 합니다. 광주는 362,240,000 + 36,224,000 × 2 = 434,688,000원입니다.
  • 예상 달성률은 앞에서 받은 경과 목표(10/12) 기준 달성률과 같아야 합니다. 월평균을 그대로 이어 가는 가정이라 두 계산이 같은 값이 됩니다(광주 77.6%).
  • 남은 두 달 필요 배수가 가장 큰 지역부터 광주 2.73배, 부산 2.51배, 대구 2.45배, 서울 2.27배, 경기 2.17배인지 봅니다.
  • 에이전트는 원인을 단정하지 않고 가정으로만 적어야 합니다. 광주의 제품별 매출 비중(교육 컨설팅 31.9%, 데이터 분석 구독 30.3%, 문서 자동화 패키지 19.0%, AI 회의록 솔루션 18.8%)은 전체 비중과 비슷해서, 특정 제품 문제라기보다 지역 전체 규모의 문제로 읽힙니다. 원인은 영업3팀 의견을 받아 씁니다.

분석 결과를 문서로 이어 가기​

분석이 끝난 숫자를 보고용 PPT나 문서로 옮길 때는 문서작성 에이전트를 씁니다. 판매 데이터 분석가에게 받은 엑셀 파일을 제안서 PPT 작성기 같은 문서작성 에이전트에 올려 요청하면, 결과물이 대화 화면 오른쪽 캔버스에 열립니다. 만드는 순서는 캔버스로 문서·PPT·표 만들기와 PPT·문서 만들기에 있고, 같은 파일로 처음부터 끝까지 진행한 예시는 사례: 엑셀 판매 데이터 분석에 있습니다.
