사례: 회의록 요약과 액션 아이템

이 페이지는 김그루 사원이 회의록 요약 도우미로 AI혁신팀 11월 10일 주간회의 회의록을 정리하는 과정을 따라 합니다. 회의록 파일을 올리고 챗 오프너를 눌러, 요약과 결정사항, 담당과 기한이 붙은 액션 아이템 표를 받습니다.

이 페이지에서 할 수 있는 일

  • 회의록 요약 도우미의 지침과 챗 오프너 4개가 준비되어 있는지 에이전트 편집 화면에서 확인합니다.
  • 회의록 파일을 올리고 챗 오프너를 눌러 요약, 결정사항, 액션 아이템 표를 받습니다.
  • 같은 대화에서 액션 아이템을 담당자별로 다시 묶습니다.
  • 회의록 원문과 대조해 담당과 기한이 맞는지 확인합니다.

목표​

항목내용
입력브레인크루 AI혁신팀 주간회의 회의록(2026년 11월 10일, 안건 4개)
받는 결과회의 개요, 세 줄 요약, 결정사항, 액션 아이템 표(할 일, 담당, 기한, 관련 안건), 다음 회의 일시
반복 방법대화 첫 화면의 챗 오프너를 눌러 같은 요청을 매주 보냄

준비물​

준비할 것내용
예시 파일브레인크루_AI혁신팀_주간회의록_1110.txt (가상 자료)
파일 내용일시, 장소, 참석자 5명, 안건 4개(사내 에이전트 도입 현황, 교육 과정 개편, 고객 제안서 템플릿, 기타), 결정 3건
같은 방법으로 올릴 수 있는 형식.txt, .md, .markdown, .html, .htm(10MB 이하), .docx, .pdf, .hwp, .hwpx, .jpg, .jpeg, .png, .gif, .webp(20MB 이하), .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt(50MB 이하). 한 번에 최대 10개
에이전트회의록 요약 도우미(일반 에이전트, 모델 GPT-4.1)
따로 연결할 도구없습니다.

회의록 파일이 없으면 회의 메모를 입력창에 그대로 붙여 넣어도 됩니다. 참석자 개인 연락처나 고객 이름이 들어 있으면 지우고 올립니다.

에이전트 준비​

회의록 요약 도우미는 에이전트 직접 만들기로 이름과 설명을 넣어 만들고, 에이전트 편집 화면에서 지침과 챗 오프너를 넣은 에이전트입니다. 처음 만드는 방법은 에이전트 만들기의 직접 만들기 순서를, 챗 오프너를 넣는 방법은 챗 오프너를 따릅니다. 이 페이지에서는 아래 값으로 이미 만들어 둔 에이전트를 씁니다.

항목넣은 값
에이전트 이름회의록 요약 도우미
에이전트 설명회의록을 받아 요약, 결정사항, 액션 아이템 표(담당, 기한)로 정리합니다.
지침아래 프롬프트
챗 오프너 4개첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요. / 액션 아이템을 담당자별로 다시 묶어 주세요. / 기한이 다음 회의 전인 액션 아이템만 골라 주세요. / 참석자에게 보낼 회의 결과 공유 메일 초안을 써 주세요.

프롬프트: 당신은 브레인크루 AI혁신팀의 회의록 요약 도우미입니다. 사용자가 올리거나 붙여 넣은 회의록을 다음 순서로 정리합니다. 1) 회의 개요: 일시, 장소, 참석자 2) 세 줄 요약 3) 결정사항: 안건 번호를 붙여 개조식으로 4) 액션 아이템 표: 할 일, 담당, 기한, 관련 안건 열 5) 다음 회의 일시. 회의록에 담당이나 기한이 적혀 있지 않으면 지어내지 말고 "확인 필요"로 적습니다. 회의록에 없는 내용은 덧붙이지 않습니다. 참석자 이름은 직함과 함께 회의록에 적힌 그대로 씁니다.

지침과 챗 오프너 확인하기​

대화를 시작하기 전에 에이전트 편집 화면에서 지침과 챗 오프너가 들어 있는지 봅니다.

지침과 챗 오프너 확인

번호메뉴기능이런 때 사용하세요
1에이전트 설정에이전트 대화 화면 사이드바의 메뉴입니다. 누르면 에이전트 편집 화면이 열립니다.지침이나 챗 오프너를 확인하거나 고칠 때
2지침에이전트가 늘 따를 정리 순서와 규칙입니다. 칸 아래에 글자 수(272자)가 보입니다.정리 순서와 "확인 필요" 규칙이 들어 있는지 볼 때
3오프너 탭챗 오프너 목록을 보여 주는 탭입니다.대화 첫 화면에 보일 예시 질문을 확인할 때
4개수 표시"4/12"처럼 등록한 개수와 최대 개수를 보여 줍니다.예시 질문을 더 넣을 수 있는지 볼 때

개수 표시 아래에는 등록한 챗 오프너 4개가 넣은 순서대로 번호와 함께 보입니다. 매주 쓰는 요청이 들어 있는지 이 목록에서 봅니다.

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 누르고, 사이드바의 에이전트 설정을 누릅니다.
  2. 가운데 지침 칸에 위 프롬프트가 들어 있는지 봅니다. 없으면 붙여 넣고 화면 위쪽 헤더의 저장을 누릅니다.
  3. 오른쪽 오프너 탭을 눌러 챗 오프너 4개와 "4/12"가 보이는지 봅니다. 없으면 챗 오프너의 따라 해 보기대로 네 문장을 넣습니다.

팁: 지침은 헤더의 저장을 눌러야 대화와 테스트 탭에 쓰이지만, 챗 오프너는 추가하는 즉시 새 대화 화면에 보입니다. 자세한 차이는 에이전트 수정과 챗 오프너에 있습니다.

단계별 실행​

1단계. 회의록 올리고 챗 오프너 누르기​

새 대화를 열고 회의록 파일을 첨부한 뒤, 첫 번째 챗 오프너로 요약을 요청합니다.

챗 오프너로 대화 시작

번호메뉴기능이런 때 사용하세요
1이 에이전트와 새 대화회의록 요약 도우미와 새 대화를 엽니다.새 회의록을 정리할 때
2챗 오프너등록한 예시 질문 4개가 칩으로 보입니다. 누르면 바로 보내지지 않고 입력창에 문장이 채워집니다.매주 같은 요청을 빠르게 넣을 때
3첨부 파일올린 회의록 파일입니다. 파일 이름 옆에 형식(TXT)이 보입니다.이번 주 회의록을 올렸는지 확인할 때
4전송입력창의 요청과 파일을 보냅니다.오프너 문장을 확인한 뒤 보낼 때

따라 해 보기​

  1. 사이드바에서 회의록 요약 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 눌러 브레인크루_AI혁신팀_주간회의록_1110.txt를 고릅니다.

  3. 첫 번째 챗 오프너를 누릅니다. 입력창에 아래 문장이 들어갑니다.

    프롬프트: 첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요.

  4. 전송을 누릅니다.

2단계. 담당자별로 다시 묶기​

챗 오프너는 대화 첫 화면에만 보입니다. 같은 대화에서 이어 요청할 때는 입력창에 직접 적습니다.

따라 해 보기​

  1. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다.

    프롬프트: 액션 아이템을 담당자별로 다시 묶어 주세요. 담당이 "확인 필요"인 항목은 맨 아래에 따로 모아 주세요.

  2. 담당자별 목록을 봅니다. 김그루 사원이 보냈을 때는 박지원 팀장(이번 회의록에서 별도 할 일 없음), 김그루 사원 2건(데이터 분석 실무 교안 개정안 작성 11/24, 디자인 가이드 스킬 초안 검토 기한 확인 필요), 이서준 선임 1건, 최하늘 책임 1건, 정다은 대리 1건으로 묶였고, 커뮤니티 실습 다음 차수 반영은 맨 아래 "담당자 확인 필요"로 따로 모였습니다.

결과물 예시​

첫 요청에 대한 답변에서 회의 개요, 세 줄 요약, 결정사항, 액션 아이템 표, 다음 회의 일시가 지침 순서대로 나왔는지 봅니다. 답변이 길어 두 화면으로 나눠 봅니다. 먼저 답변 윗부분입니다.

회의 개요, 세 줄 요약, 결정사항

번호메뉴기능이런 때 사용하세요
1회의 개요일시 2026년 11월 10일(화) 10:00~11:00, 장소 본사 7층 회의실 B / 온라인 병행, 참석자 5명입니다.회의록 머리말에 옮길 때
2세 줄 요약경영지원팀 확대, 교안 개정과 커뮤니티 실습, 제안서 템플릿과 디자인 가이드 스킬을 세 줄로 줄였습니다.회의에 빠진 사람에게 먼저 보낼 때
3결정사항안건 1~3의 결정과 4번 기타 안건의 고객명 확인 절차 안내가 6줄로 정리되었습니다.결정이 빠짐없이 들어갔는지 볼 때

답변을 아래로 내리면 액션 아이템 표와 다음 회의 일시가 이어집니다.

액션 아이템 표와 다음 회의 일시

번호메뉴기능이런 때 사용하세요
1담당 열액션 아이템 표에서 할 일을 맡은 사람입니다. 회의록에 담당이 없으면 "확인 필요"입니다.담당자에게 할 일을 알릴 때
2기한 열할 일의 마감일입니다. 회의록에 기한이 없으면 "확인 필요"입니다.기한을 일정표에 옮기거나 지어낸 날짜가 없는지 볼 때
3다음 회의 일시2026년 11월 17일(화) 10:00입니다.일정표에 다음 회의를 넣을 때

액션 아이템 표에는 담당과 기한 외에 할 일과 관련 안건 열도 있습니다.

결과 확인 포인트

예시 회의록에 적힌 결정은 아래 3건입니다. 답변의 결정사항에 이 내용이 모두 들어 있는지 봅니다.

안건결정사항
1. 사내 에이전트 도입 현황경영지원팀 확대는 12월 1일 시작, 파일 크기 점검은 이서준 선임이 11월 20일까지 완료
2. 교육 과정 개편데이터 분석 실무 교안 개정안은 김그루 사원이 11월 24일까지 작성, 커뮤니티 실습은 다음 차수부터 반영
3. 고객 제안서 템플릿정다은 대리가 디자인 가이드 스킬 초안을 11월 17일까지 등록, 김그루 사원이 검토

김그루 사원이 받은 액션 아이템 표는 아래 6줄입니다. 회의록에 담당과 기한이 모두 적힌 3줄은 그대로 채워졌고, 나머지는 빠진 칸이 "확인 필요"로 남았습니다.

할 일담당기한관련 안건
경영지원팀 엑셀 파일 크기 점검이서준 선임11/201
데이터 분석 실무 교안 개정안 작성김그루 사원11/242
디자인 가이드 스킬 초안 등록정다은 대리11/173
디자인 가이드 스킬 초안 검토김그루 사원확인 필요3
커뮤니티 실습 다음 차수 반영확인 필요확인 필요2
커뮤니티 게시 전 고객명 포함 확인 절차 안내최하늘 책임확인 필요4
  • 담당이나 기한이 회의록에 없는데 날짜나 이름이 채워져 있으면 지어낸 값입니다. 해당 칸을 "확인 필요"로 고쳐 달라고 요청합니다.
  • 경영지원팀 확대(12월 1일 시작)는 결정사항에는 들어갔지만 액션 아이템 표에는 줄이 없었습니다. 회의록에 담당이 정해져 있지 않기 때문입니다. 표에도 넣고 싶다면 "경영지원팀 확대 시작도 담당 확인 필요로 표에 넣어 주세요"처럼 이어서 요청합니다.
  • 기한의 요일을 달력과 맞춰 봅니다. 2026년 11월 17일과 24일은 화요일, 11월 20일은 금요일입니다.

응용 팁​

  • 회의 결과를 메일로 돌리려면 네 번째 챗 오프너("참석자에게 보낼 회의 결과 공유 메일 초안을 써 주세요.")를 새 대화에서 쓰거나, 같은 대화에서 그대로 입력합니다. 메일 문체를 정해 두고 싶다면 사례: 이메일 초안 작성의 이메일 초안 도우미에 요약을 넘깁니다.
  • 회의록을 매주 같은 요청으로 정리한다면 첫 번째 챗 오프너 문장을 커맨드로도 저장해 둡니다. 저장한 커맨드는 대화 중에도 입력창에서 / 를 입력해 부를 수 있습니다. 방법은 커맨드와 재사용에 있습니다.
  • 회의록에 고객 이름이나 연락처가 자주 섞인다면 개인정보 보호 미들웨어를 연결합니다. 방법은 미들웨어와 개인정보 보호에 있습니다.
