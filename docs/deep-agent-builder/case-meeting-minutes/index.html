사례: 회의록 요약과 액션 아이템

이 페이지는 김그루 사원이 회의록 요약 도우미를 직접 만들어, AI혁신팀 11월 10일 주간회의 회의록을 요약과 결정사항, 담당과 기한이 붙은 액션 아이템 표로 받는 과정을 따라 합니다. 자주 하는 첫 질문은 챗 오프너로 등록해 대화 첫 화면에서 눌러 쓰게 합니다.

이 페이지에서 할 수 있는 일

  • 에이전트 직접 만들기로 회의록 요약 도우미를 만들고 정리 순서를 지침에 적습니다.
  • 오프너 탭에 자주 쓰는 첫 질문 4개를 챗 오프너로 등록합니다.
  • 회의록 파일을 올리고 챗 오프너를 눌러 요약, 결정사항, 액션 아이템 표를 받습니다.
  • 회의록 원문과 대조해 담당과 기한이 맞는지 확인합니다.

목표​

항목내용
입력브레인크루 AI혁신팀 주간회의 회의록(2026년 11월 10일, 안건 4개)
받는 결과회의 개요, 세 줄 요약, 결정사항, 액션 아이템 표(할 일, 담당, 기한), 다음 회의
반복 방법대화 첫 화면의 챗 오프너를 눌러 같은 요청을 매주 보냄

준비물​

준비할 것내용
예시 파일브레인크루_AI혁신팀_주간회의록_1110.txt (가상 자료)
파일 내용일시, 장소, 참석자 5명, 안건 4개(사내 에이전트 도입 현황, 교육 과정 개편, 고객 제안서 템플릿, 기타), 결정 3건
같은 방법으로 올릴 수 있는 형식.txt, .md, .markdown, .html, .htm(10MB 이하), .docx, .pdf, .hwp, .hwpx, .jpg, .jpeg, .png, .gif, .webp(20MB 이하), .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt(50MB 이하). 한 번에 최대 10개
에이전트 모드일반 에이전트
따로 연결할 도구없습니다.

회의록 파일이 없으면 회의 메모를 입력창에 그대로 붙여 넣어도 됩니다. 참석자 개인 연락처나 고객 이름이 들어 있으면 지우고 올립니다.

에이전트 만들기​

회의록 요약 도우미는 에이전트 직접 만들기로 만듭니다. 이름과 설명만 넣어 빈 에이전트를 만든 뒤, 에이전트 편집 화면에서 지침을 직접 적습니다. 정리 순서와 규칙이 이미 정해져 있을 때는 이 방법이 빠릅니다.

1단계. 이름과 설명 넣기​

새 에이전트 만들기 창에 에이전트 이름과 한 줄 설명을 넣어 빈 에이전트를 만듭니다.

따라 해 보기​

  1. 사이드바의 새 에이전트를 누르고, 화면 아래쪽의 에이전트 직접 만들기를 누릅니다.
  2. 에이전트 이름에 "회의록 요약 도우미"를 입력합니다.
  3. **에이전트 설명 (선택)**에 "회의록을 받아 요약, 결정사항, 액션 아이템 표(담당, 기한)로 정리합니다."를 입력합니다.
  4. 확인을 누릅니다.

2단계. 지침 적고 저장하기​

에이전트 편집 화면 가운데의 지침 칸에 정리 순서와 규칙을 적고, 화면 위쪽 헤더의 저장으로 저장합니다. 지침은 헤더의 저장을 눌러야 대화와 테스트 탭에 쓰입니다.

따라 해 보기​

  1. 지침 칸에 아래 문장을 붙여 넣습니다.

    프롬프트: 당신은 브레인크루 AI혁신팀의 회의록 요약 도우미입니다. 사용자가 올리거나 붙여 넣은 회의록을 다음 순서로 정리합니다. 1) 회의 개요: 일시, 장소, 참석자 2) 세 줄 요약 3) 결정사항: 안건 번호를 붙여 개조식으로 4) 액션 아이템 표: 할 일, 담당, 기한, 관련 안건 열 5) 다음 회의 일시. 회의록에 담당이나 기한이 적혀 있지 않으면 지어내지 말고 "확인 필요"로 적습니다. 회의록에 없는 내용은 덧붙이지 않습니다. 참석자 이름은 직함과 함께 회의록에 적힌 그대로 씁니다.

  2. 화면 위쪽 헤더의 저장을 누릅니다.

팁: 지침을 바꾸고 헤더의 저장을 누른 뒤에는 오른쪽 테스트 탭에서 같은 회의록으로 한 번 시험해 보고 대화에 씁니다. 테스트 탭은 저장된 지침으로 실행됩니다.

3단계. 챗 오프너 등록하기​

챗 오프너는 대화 첫 화면에 버튼처럼 보이는 예시 질문입니다. 누르면 입력창에 그 문장이 들어가므로, 매주 같은 요청을 다시 쓰지 않아도 됩니다.

따라 해 보기​

  1. 에이전트 편집 화면 오른쪽의 오프너 탭을 누릅니다.
  2. 탭 위쪽의 추가를 눌러 Chat Opener 추가 창을 열고, 아래 문장 하나를 넣은 뒤 창의 추가를 누릅니다. 네 문장을 모두 넣을 때까지 반복합니다.
    • 첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요.
    • 액션 아이템을 담당자별로 다시 묶어 주세요.
    • 기한이 다음 회의 전인 액션 아이템만 골라 주세요.
    • 참석자에게 보낼 회의 결과 공유 메일 초안을 써 주세요.
  3. 문장을 넣을 때마다 "Chat Opener가 추가되었습니다" 알림이 뜨고, 개수 표시가 "4/12"가 되는지 확인합니다.

오프너는 Chat Opener 추가 창의 추가를 누르는 즉시 반영되어 새 대화 화면에 바로 보입니다. 2단계에서 누른 헤더의 저장은 이름, 설명, 지침을 저장하는 버튼이므로, 오프너를 대화에서 쓰려고 따로 누를 필요는 없습니다. 다만 오프너를 바꾸면 헤더의 저장 옆에 "저장되지 않은 변경이 있습니다"가 나타납니다. 오프너가 아직 현재 버전에 기록되지 않았다는 뜻이므로, 이 에이전트를 워크스페이스에 등록하기 전에는 헤더의 저장을 한 번 눌러 둡니다.

단계별 실행​

1단계. 회의록 올리고 챗 오프너 누르기​

새 대화를 열고 회의록 파일을 첨부한 뒤, 첫 번째 챗 오프너로 요약을 요청합니다.

따라 해 보기​

  1. 사이드바에서 회의록 요약 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 눌러 브레인크루_AI혁신팀_주간회의록_1110.txt를 고릅니다.

  3. 첫 번째 챗 오프너를 누릅니다. 입력창에 아래 문장이 들어갑니다.

    프롬프트: 첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요.

  4. 전송을 누릅니다.

2단계. 담당자별로 다시 묶기​

같은 대화에서 두 번째 챗 오프너를 쓰려면 새 대화를 열지 않고 입력창에 직접 적습니다. 챗 오프너는 대화 첫 화면에만 보입니다.

따라 해 보기​

  1. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다.

    프롬프트: 액션 아이템을 담당자별로 다시 묶어 주세요. 담당이 "확인 필요"인 항목은 맨 아래에 따로 모아 주세요.

  2. 김그루 사원 담당 항목이 두 개(교안 개정안 작성, 디자인 가이드 스킬 초안 검토)인지 봅니다.

결과물 예시​

첫 요청에 대한 답변에서 회의 개요(2026년 11월 10일(화) 10:00~11:00, 본사 7층 회의실 B / 온라인 병행, 참석자 5명), 세 줄 요약, 결정사항, 액션 아이템 표, 다음 회의(11월 17일(화) 10:00)가 지침 순서대로 나왔는지 봅니다.

결과 확인 포인트

예시 회의록으로 기대하는 결정사항은 아래 3건입니다.

안건결정사항
1. 사내 에이전트 도입 현황경영지원팀 확대는 12월 1일 시작, 파일 크기 점검은 이서준 선임이 11월 20일까지 완료
2. 교육 과정 개편데이터 분석 실무 교안 개정안은 김그루 사원이 11월 24일까지 작성, 커뮤니티 실습은 다음 차수부터 반영
3. 고객 제안서 템플릿정다은 대리가 디자인 가이드 스킬 초안을 11월 17일까지 등록, 김그루 사원이 검토

기대하는 액션 아이템 표입니다. 회의록에 담당과 기한이 모두 적힌 항목은 3건이고, 나머지는 한 칸 이상이 "확인 필요"여야 합니다.

할 일담당기한
업로드 파일 크기(50MB 초과 파일) 점검이서준 선임11월 20일(금)
데이터 분석 실무 교안 개정안 작성김그루 사원11월 24일(화)
디자인 가이드 스킬 초안 등록정다은 대리11월 17일(화)
디자인 가이드 스킬 초안 검토김그루 사원확인 필요
경영지원팀 확대 시작확인 필요12월 1일(화) 시작
에이전트 만들기 실습에 커뮤니티 공유 실습 반영확인 필요다음 차수부터
커뮤니티 게시 전 고객명 확인 절차 안내최하늘 책임확인 필요
  • 담당이나 기한이 회의록에 없는데 날짜나 이름이 채워져 있으면 지어낸 값입니다. 해당 칸을 "확인 필요"로 고쳐 달라고 요청합니다.
  • 경영지원팀 확대는 박지원 팀장이 제안했지만 담당자로 정한 기록은 없습니다. 박지원 팀장이 담당으로 들어가 있으면 회의 참석자에게 확인합니다.
  • 기한의 요일을 달력과 맞춰 봅니다. 2026년 11월 17일과 24일은 화요일, 11월 20일은 금요일입니다.

응용 팁​

  • 회의 결과를 메일로 돌리려면 네 번째 챗 오프너("참석자에게 보낼 회의 결과 공유 메일 초안을 써 주세요.")를 새 대화에서 쓰거나, 같은 대화에서 그대로 입력합니다. 메일 문체를 정해 두고 싶다면 사례: 이메일 초안 작성의 이메일 초안 도우미에 요약을 넘깁니다.
  • 회의록을 매주 같은 요청으로 정리한다면 첫 번째 챗 오프너 문장을 커맨드로도 저장해 둡니다. 예를 들어 커맨드에 action_items, 설명에 액션아이템을 넣어 저장하면 대화 중에도 입력창에서 /action_items로 부를 수 있습니다. 방법은 커맨드와 재사용에 있습니다.
  • 회의록에 고객 이름이나 연락처가 자주 섞인다면 개인정보 보호 미들웨어를 연결합니다. 방법은 미들웨어와 개인정보 보호에 있습니다.
