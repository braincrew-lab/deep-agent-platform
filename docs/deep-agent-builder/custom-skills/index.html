스킬 만들기와 업로드

스킬은 에이전트가 일하는 순서와 기준을 적어 둔 업무 매뉴얼 파일입니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 팀 공통 "브레인크루 보고서 작성 규칙"을 스킬로 올리고, 에이전트에 연결해 대화에서 쓰고, 팀원과 나누거나 ZIP으로 내보내는 과정을 화면 순서대로 설명합니다.

이 페이지에서 할 수 있는 일

  • 스킬 파일(SKILL.md)의 구성과 이름 규칙을 알고 직접 만듭니다.
  • 에셋 화면 스킬 탭의 스킬 업로드로 .md 파일 또는 .zip 파일을 올립니다.
  • ZIP 안에 넣을 수 있는 확장자를 확인하고, 거부 안내를 읽고 고칩니다.
  • 에이전트 편집 화면의 스킬 탭에서 문서 작성 스킬을 ZIP으로 올리고, 스킬을 켜고 끕니다.
  • 대화 화면 입력란 아래 왼쪽의 스킬 버튼으로 스킬을 골라 답을 받고, 실행 기록에서 스킬을 읽었는지 확인합니다.
  • 배포 관리로 스킬을 워크스페이스에 배포하고, ZIP 내보내기로 스킬을 내려받습니다.

스킬 파일의 구성​

스킬은 폴더 하나이고, 그 안의 SKILL.md가 진입 파일입니다. SKILL.md 맨 앞에는 세 개의 하이픈(---) 줄로 감싼 머리말이 있고, 머리말에 name(스킬 이름)과 description(스킬 설명)을 적습니다. 머리말 아래에는 에이전트가 따를 규칙을 평범한 글로 씁니다.

김그루 사원이 만든 SKILL.md의 내용은 다음과 같습니다.

부분적은 내용
namebraincrew-report-rules
description브레인크루 보고서 작성 규칙. 주간 보고, 시장 조사 리포트, 회의 결과 보고를 쓸 때 사용한다.
규칙 1첫 줄에 결론을 한 문장으로 쓴다(두괄식).
규칙 2요약은 번호를 붙인 3줄 이내로 쓴다.
규칙 3금액은 만원 단위로 쓰고 천 단위에 쉼표를 넣는다.
규칙 4표는 5열 이하로 만들고 마지막 열에 출처를 적는다. 자료에 없는 값은 "자료에 없음"으로 적는다.
규칙 5마지막에 "다음 행동" 절을 두고 담당과 기한을 적는다.

스킬 이름은 다음 규칙을 지켜야 합니다.

  • 영문 소문자로 시작하고, 소문자 영문, 숫자, 밑줄(_), 하이픈(-)만 씁니다.
  • 최대 64자입니다.
  • anthropic, claude라는 단어는 넣을 수 없습니다.

참고 자료가 필요하면 SKILL.md 옆에 references 같은 하위 폴더를 두고 파일을 넣은 뒤 폴더째 ZIP으로 묶습니다. 폴더 깊이는 10단계까지입니다.

스킬 탭​

사이드바의 에셋설정을 눌러 여는 에셋 화면에서 스킬 탭을 엽니다. 왼쪽은 내 스킬 목록, 오른쪽은 대화로 스킬을 만들고 고치는 AI 스킬 어시스턴트입니다.

스킬 탭의 위쪽 버튼

번호메뉴기능이런 때 사용하세요
1스킬 탭에셋 화면에서 스킬을 모아 관리하는 탭입니다.내 스킬을 확인하거나 새로 올릴 때
2배포 관리스킬 배포 관리 창을 열어 내 스킬을 워크스페이스에 배포하거나 해제합니다.만든 스킬을 팀원과 나눌 때
3스킬 업로드.md 파일 또는 .zip 파일로 스킬을 올리는 창을 엽니다.미리 만들어 둔 SKILL.md나 스킬 ZIP이 있을 때
4스킬 생성화면에서 스킬 이름과 SKILL.md 내용을 직접 적고 편집과 미리보기를 오가며 쓴 뒤 스킬 저장으로 만듭니다.파일 없이 바로 스킬을 쓰고 싶을 때

같은 화면의 스킬 목록과 어시스턴트는 다음과 같습니다.

스킬 목록과 AI 스킬 어시스턴트

번호메뉴기능이런 때 사용하세요
1스킬 검색...목록에서 스킬을 찾습니다.스킬이 많아 찾기 어려울 때
2선택여러 스킬을 골라 한꺼번에 지웁니다. 바로 왼쪽에 **스킬 목록 (개수)**로 등록된 스킬 수가 보입니다.쓰지 않는 스킬을 정리할 때
3스킬 카드스킬 이름, 설명, 파일 개수가 보입니다. 카드를 누르면 스킬 파일 창이 열립니다.스킬 내용을 보거나 고칠 때
4AI 스킬 어시스턴트 입력란"스킬 생성이나 편집을 요청하세요..." 칸에 요청을 적으면 대화로 스킬을 만들거나 고칩니다.규칙을 말로 설명해 스킬로 만들고 싶을 때

스킬 카드에는 수정과 스킬 삭제 버튼도 있습니다. 스킬 삭제를 누르면 카드 안에 확인과 취소가 나타나고, 확인을 눌러야 지워집니다. 등록된 스킬이 없으면 목록에 "등록된 스킬이 없습니다"가 보입니다. 에이전트가 쓰고 있는 스킬은 지울 수 없고, 먼저 에이전트에서 연결을 해제해야 합니다.

스킬 업로드 창​

스킬 업로드를 누르면 스킬 업로드 창이 열립니다. 안내 문구는 "SKILL.md 필수 포함 (.md 파일 또는 .zip 파일 1개)"입니다.

SKILL.md를 고르고 스킬 이름과 설명을 적은 스킬 업로드 창

번호메뉴기능이런 때 사용하세요
1파일 선택 영역"클릭하거나 파일을 드래그하세요"라고 적힌 곳입니다. 눌러서 고르거나 파일을 끌어다 놓습니다. 고른 파일 이름과 크기는 바로 아래에 보이고, 오른쪽 버튼으로 목록에서 뺄 수 있습니다.올릴 SKILL.md나 ZIP 파일을 고를 때
2스킬 이름.md 파일로 올릴 때 스킬 이름을 적습니다. 64자까지 쓸 수 있습니다.이름 규칙에 맞는 이름을 정할 때
3스킬 설명다른 사용자와 공유할 때 보이는 설명입니다(선택, 200자까지).스킬 카드에 보일 설명을 정할 때
4업로드스킬을 올립니다. 끝나면 "스킬이 업로드되었습니다" 알림이 뜹니다.입력을 마쳤을 때

이름 아래 동일한 이름의 내 스킬을 덮어쓰기를 체크하면 같은 이름의 내 스킬이 올린 내용으로 바뀝니다. 되돌릴 수 없으니 이미 올린 스킬을 새 내용으로 바꿀 때만 체크합니다.

ZIP으로 올리면 이름은 ZIP 안 SKILL.md의 name 값으로 정해집니다. 스킬 설명을 비워 두면 스킬 카드에는 SKILL.md 머리말의 description이 보입니다. 스킬 종류(일반 또는 문서 작성)는 이 창에 없고, 올린 뒤 스킬 파일 창에서 바꿉니다.

올릴 수 있는 파일은 다음과 같습니다.

올리는 방식규칙
.md 파일SKILL.md가 반드시 있어야 합니다. 없으면 "SKILL.md 파일이 반드시 포함되어야 합니다."가 보입니다. .md가 아닌 파일은 "(개수)개 파일이 거부되었습니다 (.md 또는 .zip만 허용)" 알림과 함께 빠집니다.
.zip 파일한 번에 1개만, .md 파일과 섞지 않고 올립니다. ZIP 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다. ZIP 파일 크기는 최대 50MB입니다.
ZIP 안의 파일확장자가 md, txt, json, yaml, yml, csv, py, sh, js, ts, html, xml, toml, docx, pptx, xlsx, pdf, png, jpg, jpeg, gif인 파일만 넣을 수 있습니다. svg를 포함한 다른 확장자가 하나라도 있으면 ZIP 전체가 거부됩니다.

같은 이름의 내 스킬이 이미 있으면 스킬 이름 아래에 "같은 이름의 내 스킬이 있습니다. 덮어쓰려면 「동일한 이름의 내 스킬을 덮어쓰기」를 체크해 주세요."가 보이고 업로드를 누를 수 없습니다. 체크하고 올리면 기존 스킬이 바뀌며 되돌릴 수 없고, 그 스킬을 쓰는 에이전트에도 영향이 갑니다.

ZIP이 거부될 때​

ZIP을 고르면 창이 먼저 안의 파일을 살핍니다. 허용되지 않은 파일이 있으면 업로드 전에 빨간 안내가 나오고, 문제가 남아 있는 동안 업로드를 누를 수 없습니다.

허용되지 않은 확장자 안내와 비활성 업로드 버튼

번호메뉴기능이런 때 사용하세요
1거부 안내"허용되지 않은 확장자의 파일이 포함되어 있어 업로드할 수 없습니다:" 뒤에 문제 파일의 ZIP 안 경로(예: braincrew-doc-style/assets/braincrew-logo.svg)가 나오고, 이어서 "허용 확장자:"와 허용 확장자 전체가 나옵니다.어떤 파일을 고쳐야 하는지 확인할 때
2업로드(비활성)문제가 남아 있는 동안 누를 수 없습니다.고친 ZIP을 다시 고를 때까지

로고가 svg라면 png로 바꿔 넣고 ZIP을 다시 만든 뒤 다시 고릅니다. 그 밖에 "ZIP 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다.", "SKILL.md 맨 앞에 --- 줄로 감싼 머리말(frontmatter)이 있어야 합니다.", 이름 규칙 위반 안내가 나오면 안내대로 SKILL.md를 고칩니다.

따라 해 보기: 보고서 작성 규칙 스킬 올리기​

  1. 메모장 같은 편집기로 SKILL.md를 만들고, 위 "스킬 파일의 구성" 표대로 머리말(name, description)과 규칙 5개를 적어 UTF-8로 저장합니다.
  2. 사이드바의 에셋설정을 눌러 여는 에셋 화면의 스킬 탭에서 스킬 업로드를 누릅니다.
  3. 파일 선택 영역에 SKILL.md를 끌어다 놓습니다.
  4. 스킬 이름에 braincrew-report-rules를 입력합니다.
  5. 스킬 설명에 "브레인크루 보고서 작성 규칙"을 적고 업로드를 누릅니다.
  6. "스킬이 업로드되었습니다" 알림이 뜨고 목록에 braincrew-report-rules 카드가 생겼는지 확인합니다.

스킬 파일 창과 ZIP 내보내기​

스킬 카드를 누르면 스킬 이름이 제목인 창이 열립니다. 제목 아래에 "스킬의 파일을 둘러보고, 텍스트 파일을 수정하고, 파일을 추가하거나 삭제합니다."라는 안내가 보입니다.

스킬 종류, 파일 추가, ZIP 내보내기, 파일 내용 편집

번호메뉴기능이런 때 사용하세요
1스킬 종류일반 또는 문서 작성으로 바꿉니다.문서작성 에이전트용 스킬로 쓰려 할 때
2파일 추가왼쪽 스킬 파일 목록 아래 칸에 새 파일 경로(예: references/notes.md)를 적고 누르면 텍스트 파일이 생깁니다. 목록의 파일을 누르면 내용이 열립니다.참고 파일을 더 넣을 때
3ZIP 내보내기스킬 폴더 전체를 스킬 이름의 ZIP 파일(예: braincrew-report-rules.zip)로 내려받습니다.스킬을 보관하거나 다른 환경에 다시 올릴 때
4파일 내용편집 탭에서 텍스트 파일 내용을 바로 고치고, 미리보기 탭에서 확인합니다. 다 고치면 아래 저장을 누릅니다.규칙 문장을 조금 고칠 때

창 제목에는 스킬 이름이 보입니다. ZIP 내보내기 옆의 파일 삭제로 고른 파일을 지웁니다. SKILL.md는 진입 파일이라 지울 수 없고, SKILL.md를 고르면 "SKILL.md는 진입 파일이라 삭제할 수 없습니다."가 보입니다. 화면에서 고칠 수 있는 파일은 UTF-8 텍스트이고 파일 하나에 256KB까지입니다.

docx, pptx, xlsx, pdf, png, jpg, jpeg, gif 파일은 화면에서 열어 고칠 수 없고 ZIP 업로드로만 넣습니다. 다른 사용자가 배포한 스킬을 설치해 쓰는 경우에는 "다른 사용자가 배포한 스킬입니다 · 열람만 가능" 안내가 보이고 내용을 고칠 수 없습니다.

스킬 배포 관리​

배포 관리를 누르면 스킬 배포 관리 창이 열립니다. 안내 문구는 "내 스킬을 워크스페이스에 배포하고, 배포한 스킬을 재배포하거나 해제합니다."입니다.

미배포 상태의 braincrew-report-rules와 배포 버튼

번호메뉴기능이런 때 사용하세요
1스킬 이름 검색...스킬 이름으로 목록을 거릅니다.배포할 스킬을 찾을 때
2상태미배포, 심사 중, 배포됨, 배포됨 · 수정 사항 있음, 거부됨 중 하나가 보입니다. 옆 배포 버전과 최근 배포일 열에는 배포된 버전과 마지막 배포 날짜가 보이고, 배포 전에는 —로 보입니다.팀원에게 반영됐는지 확인할 때
3배포스킬을 워크스페이스에 배포합니다. 배포된 스킬은 같은 자리에서 재배포 또는 배포 해제를 고릅니다.스킬을 팀에 나눌 때
4하단 안내내 계정의 승인 방식이 보입니다. 김그루 사원 계정에는 "자동 승인 권한이 있어 배포 · 재배포가 즉시 반영되고, 설치한 사용자에게 자동 업데이트됩니다."가 보입니다.배포가 바로 반영되는지 확인할 때

자동 승인 권한이 없는 계정은 관리자가 승인한 뒤에 배포가 반영됩니다. 배포 후 내용을 고치면 상태가 배포됨 · 수정 사항 있음으로 바뀝니다. 재배포해야 팀원에게 반영됩니다. 고객 정보나 내부 수치가 든 스킬은 배포하지 마세요. 배포된 스킬은 다른 사용자가 유틸리티에서 스킬 설치로 받아 씁니다.

에이전트에 스킬 연결하기​

스킬은 에이전트 편집 화면 오른쪽 스킬 탭에서 켭니다. 위쪽에 "스킬 선택"과 "에이전트에서 사용할 스킬을 선택하세요" 안내가 있고, 아래에 문서 작성 스킬과 일반 스킬 하위 탭이 있습니다.

문서 작성 스킬 하위 탭, ZIP 업로드, 스킬 스위치

번호메뉴기능이런 때 사용하세요
1스킬 탭편집 화면 오른쪽에서 이 에이전트가 쓸 스킬을 고르는 탭입니다.에이전트에 스킬을 연결할 때
2문서 작성 스킬·일반 스킬스킬 종류별 목록을 바꿔 봅니다. 처음에는 문서 작성 스킬이 열립니다.보고서 규칙처럼 일반 스킬을 켤 때는 일반 스킬로 바꿀 때
3ZIP 업로드문서 작성 스킬을 ZIP으로 바로 올립니다. 문서 작성 스킬 탭에만 있습니다.편집 화면을 떠나지 않고 스킬을 올릴 때
4스킬 스위치켜면 이 에이전트가 그 스킬을 쓸 수 있습니다.스킬을 켜거나 끌 때

스위치를 바꾸면 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보입니다. 저장을 눌러 "저장되었습니다" 알림을 확인합니다. 문서 작성 스킬이 하나도 없으면 목록에 "문서 작성 스킬이 없습니다. ZIP으로 업로드하세요."가 보입니다.

문서 작성 스킬 ZIP 업로드​

문서 작성 스킬 탭의 ZIP 업로드를 누르면 스킬 업로드 창이 열립니다. 안내는 "SKILL.md를 포함한 ZIP 파일을 업로드하세요."입니다.

braincrew-doc-style.zip을 고르고 설명을 적은 스킬 업로드 창

번호메뉴기능이런 때 사용하세요
1ZIP 파일ZIP 파일 선택을 눌러 ZIP을 고릅니다. 고르면 파일 이름이 보입니다.올릴 스킬 ZIP을 고를 때
2스킬 종류처음 값은 문서 작성이고, 일반으로 바꿀 수 있습니다.스킬 종류를 정할 때
3설명다른 사용자와 공유할 때 보이는 설명입니다(선택, 200자까지).스킬 목록에 보일 설명을 적을 때
4업로드스킬을 올립니다. "스킬이 업로드되었습니다" 알림이 뜨고 목록에 스킬이 나타납니다.입력을 마쳤을 때

고친 ZIP을 다시 올릴 때는 동일한 이름의 스킬을 덮어쓰기를 체크해 같은 이름의 스킬을 새 내용으로 바꿉니다.

ZIP 안 확장자와 50MB 한도는 에셋 화면의 스킬 업로드와 같습니다. 문서작성 에이전트와 캔버스는 PPT·문서 만들기와 캔버스로 문서·PPT·표 만들기에서 설명합니다.

대화에서 스킬 쓰기​

스킬을 켠 에이전트의 대화 화면에서 입력란 아래 왼쪽의 스킬 버튼을 누르면 이 에이전트에서 쓸 수 있는 스킬 목록이 열립니다. 스킬을 고르면 "braincrew-report-rules 스킬을 사용하여 답변해 주세요."처럼 스킬 이름이 든 메시지가 바로 전송됩니다.

스킬 메시지, 스킬 불러오기 기록, 규칙을 따른 답변

번호메뉴기능이런 때 사용하세요
1스킬 버튼입력란 아래 왼쪽, 도구·서브에이전트·미들웨어 버튼 옆에 있습니다. 누르면 이 에이전트의 스킬 목록이 열립니다.특정 스킬로 답을 받고 싶을 때
2스킬 메시지스킬을 고르면 "스킬 이름 스킬을 사용하여 답변해 주세요." 메시지가 사용자 말풍선으로 남습니다.어떤 스킬을 요청했는지 확인할 때
3스킬 불러오기 기록에이전트가 스킬 파일을 읽은 실행 기록입니다. 바로 위에는 스킬 목록 기록이 함께 보입니다.스킬을 실제로 읽었는지 확인할 때
4답변스킬 규칙을 따른 답변입니다. 첫 줄이 결론 한 문장(규칙 1)으로 시작합니다.규칙대로 썼는지 확인할 때

김그루 사원이 받은 답변은 첫 줄에 결론 한 문장("11/2~11/6 한 주간, 영업본부 파일럿 대응·사내 교육·에이전트 배포 등 실질적 성과가 있었습니다.")을 두고, 요약 3줄, 마지막 열이 출처인 5열 표, 이슈, "다음 행동: 경영지원팀 확대 준비·교안 개정(담당: 김그루, 기한: 자료에 없음)" 순서로 쓰였습니다. 메모에 기한이 없는 값은 "자료에 없음"으로 적혔고, 메모에 금액이 없어 규칙 3은 쓰이지 않았습니다.

따라 해 보기: 스킬을 켜고 주간 보고 받기​

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 에이전트 설정을 누릅니다.

  2. 오른쪽 스킬 탭에서 일반 스킬을 누르고 braincrew-report-rules 스위치를 켠 뒤 헤더 저장을 누릅니다.

  3. 이 에이전트와 새 대화를 누르고 입력란 아래 오른쪽의 파일 업로드로 김그루_주간업무메모_1106.md를 붙인 뒤 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 메모로 이번 주 업무 보고서를 써 주세요.

  4. 답이 끝나면 입력란 아래 왼쪽의 스킬 버튼을 누르고 braincrew-report-rules를 골라, 같은 대화에서 스킬을 쓴 답을 한 번 더 받습니다.

  5. 실행 기록에 스킬 불러오기 줄이 있는지, 답변이 규칙 1부터 5까지를 따랐는지 확인합니다.

팁: 같은 규칙을 지침과 스킬에 둘 다 적어 두면 한쪽만 고쳤을 때 어긋납니다. 여러 에이전트가 함께 쓰는 기준은 스킬에 두고, 지침에는 "braincrew-report-rules 스킬의 규칙을 따릅니다"처럼 스킬 이름만 적으세요.

정리​

  • 스킬은 SKILL.md가 든 폴더이며, 에셋 화면의 스킬 탭에서 .md 파일 또는 .zip 파일(최대 50MB)로 올립니다.
  • ZIP 안에는 md, txt, json, yaml, yml, csv, py, sh, js, ts, html, xml, toml, docx, pptx, xlsx, pdf, png, jpg, jpeg, gif 확장자만 넣을 수 있습니다.
  • 에이전트 편집 화면 스킬 탭에서 켜고 저장하면, 대화의 스킬 버튼으로 골라 쓸 수 있습니다.
  • 배포 관리로 팀에 나누고, ZIP 내보내기로 보관합니다.
