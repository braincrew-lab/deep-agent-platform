첨부파일 지원

질문에 파일을 붙이면 에이전트가 그 파일을 읽고 답합니다. 회의록을 올려 요약을 받거나, 판매 실적 엑셀을 올려 분석을 맡기거나, 계약서 초안을 올려 검토 포인트를 받을 수 있습니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 회의록 요약 도우미에 회의록 두 개를 올려 비교 요약을 받는 과정을 예로 들어, 파일을 붙이는 방법과 업로드 상태, 붙일 수 있는 형식과 크기, 에이전트에 늘 붙여 두는 파일을 설명합니다.

이 페이지에서 할 수 있는 일

  • 입력란 아래 오른쪽의 파일 업로드 버튼이나 끌어다 놓기로 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm 파일을 붙입니다.
  • 형식별 크기 한도와 한 번에 10개라는 개수 한도를 알고, 한도를 넘었을 때 나오는 안내를 읽고 다시 붙입니다.
  • 업로드 중..., 파일 처리 중... 표시를 보고 파일이 준비된 뒤에 질문을 보냅니다.
  • 보낸 질문의 첨부파일을 눌러 문서 보기 창에서 원본을 다시 봅니다.
  • 에이전트 편집 화면의 파일 탭에 자료를 올려 두고 모든 채팅에서 쓰게 합니다.

파일이 거부되는 경우의 전체 규칙은 파일 첨부 정책과 가드레일에 모아 두었습니다.

파일을 붙이는 곳​

에이전트 대화 화면의 입력창에서 파일을 붙입니다. 입력란 아래 오른쪽의 파일 업로드를 누르면 내 PC에서 파일을 고르는 창이 열리고, 한 번에 여러 파일을 고를 수 있습니다. 고른 파일은 입력란 위에 이름과 종류(TXT, DOCX, PDF 같은 표시)가 적힌 파일 칩으로 붙고, 이미지는 이름 대신 작은 사진으로 보입니다. 잘못 붙인 파일은 칩 오른쪽의 X 버튼으로 뺍니다. 질문을 적고 전송을 누르면 질문과 파일이 함께 보내지며, 업로드와 처리가 끝나야 전송을 누를 수 있습니다. 그림은 회의록 요약 도우미와 새 대화를 열고 파일 두 개를 붙인 화면입니다.

파일을 붙이는 곳

번호메뉴기능이런 때 사용하세요
1파일 업로드내 PC에서 파일을 고르는 창을 엽니다. 한 번에 여러 파일을 고를 수 있습니다. 파일을 올리는 동안에는 누를 수 없습니다.회의록 파일을 올릴 때
2파일 칩붙인 파일의 이름과 종류입니다. 이미지는 이름 대신 작은 사진으로 보입니다.올바른 파일을 골랐는지 이름으로 확인할 때
3제거(X) 버튼이 파일을 첨부에서 뺍니다. Word 파일은 파일 제거, PDF는 PDF 제거처럼 종류에 따라 이름이 붙어 있습니다.다른 주의 회의록을 잘못 붙였을 때
4전송입력란에 적은 질문과 첨부파일을 함께 보냅니다. 업로드와 처리가 끝나야 누를 수 있습니다.파일 준비가 끝나고 "두 회의록의 결정 사항을 비교해 주세요"처럼 파일로 무엇을 할지 적었을 때

파일 탐색기에서 파일을 끌어 입력창 위에 놓아도 붙습니다. 끌고 들어오면 입력창 테두리가 바뀌고 "여기에 파일을 놓으세요"가 표시됩니다.

붙일 수 있는 파일 형식과 크기​

채팅에서 붙일 수 있는 형식과 파일 한 개의 크기 한도는 다음과 같습니다. 이 목록에 없는 형식은 고르는 즉시 "지원하지 않는 파일 형식입니다"라는 알림과 함께 빠집니다.

종류확장자파일 한 개 한도브레인크루 업무 예
PDF.pdf20MB3분기 AI 활용 현황 보고서, 출장비 규정
이미지.jpg, .jpeg, .png, .gif, .webp20MB영수증 사진, 화면 캡처
마크다운·텍스트.md, .markdown, .txt10MB주간회의록, 주간 업무 메모
엑셀·표.xlsx, .xls, .xlsb, .xlsm, .csv50MB판매 실적, 교육 만족도 설문 결과
Word.docx20MB계약서 초안, 회의록
PowerPoint.pptx, .ppt50MB분기 발표자료
한글.hwp, .hwpx20MB사내 공문
웹 문서.html, .htm10MB사내 규정 웹 페이지 저장본

알아 둘 점은 다음과 같습니다.

  • 옛 Word 형식(.doc)은 받지 않습니다. Word에서 .docx로 다시 저장해 붙입니다.
  • .tiff, .bmp 이미지는 받지 않습니다. .png나 .jpg로 바꿔 붙입니다.
  • 한글 파일은 HWP 5.x 이상과 .hwpx를 받습니다. 옛 HWP 3.0 문서는 한글에서 다시 저장해 붙입니다.
  • 크기 한도를 넘는 파일은 붙지 않고 "보고서-3분기-AI활용현황-원본스캔.pdf: PDF 파일 크기가 제한(20MB)을 초과합니다. 현재 크기: 27.35 MB"처럼 파일 이름, 종류, 한도, 현재 크기가 알림에 나옵니다.
  • 어느 형식이든 파일 한 개의 업로드 제한은 50MB입니다.

한 번에 붙이는 파일 수​

메시지 한 번에 붙일 수 있는 파일은 10개까지입니다. 한도를 넘게 고르면 남은 자리만큼만 붙고 빠진 개수가 알림에 나옵니다. 예를 들어 이미 1개가 붙어 있는데 11개를 더 고르면 9개만 붙고 "2개 파일이 제한으로 인해 추가되지 않았습니다."가 나옵니다. 이미 10개가 붙어 있는데 더 고르면 "최대 10개 파일만 업로드할 수 있습니다."가 나옵니다.

팁: 파일이 10개를 넘으면 한 질문에 몰아넣지 말고, 같은 채팅에서 질문을 나눠 차례로 올리세요. 큰 엑셀은 필요한 시트만 따로 저장해 50MB 아래로 줄입니다.

업로드 상태​

파일을 고르면 입력창 위에 파일 칩이 생깁니다. 파일은 올라간 뒤 에이전트가 읽을 수 있는 형태로 바뀌는 처리 단계를 거치며, 그동안 칩 옆에 진행 상태가 표시됩니다. 언제 올라가는지는 채팅 상태에 따라 다릅니다.

  • 이미 대화가 있는 채팅: 파일을 고르는 즉시 올라가고 처리가 시작됩니다. 질문을 적는 동안 처리가 함께 진행됩니다.
  • 이 에이전트와 새 대화로 연 빈 채팅: 고른 파일은 칩으로만 붙어 있다가, 전송을 누르면 채팅이 만들어지면서 올라갑니다. 질문은 처리가 끝난 뒤 에이전트에게 전달됩니다.

업로드 중

번호표시뜻이런 때 사용하세요
1파일 칩올리고 있는 파일입니다.올바른 파일을 골랐는지 확인할 때
2업로드 중...파일을 올리는 중입니다. 이 표시가 끝나면 **파일 처리 중...**으로 바뀝니다. 올리는 동안에는 파일 업로드도 누를 수 없습니다.큰 파일을 올린 뒤 끝날 때까지 기다릴 때
3전송업로드나 처리가 끝나지 않으면 흐리게 보이고 누를 수 없습니다.상태 표시가 사라졌는지 확인할 때

파일 처리 중

번호표시뜻이런 때 사용하세요
1파일 처리 중...에이전트가 읽을 수 있도록 문서를 바꾸는 중입니다. 쪽 수가 많은 문서는 시간이 더 걸립니다.수십 쪽짜리 보고서를 올린 뒤 기다릴 때

처리가 끝나면 칩만 남습니다. 이 상태에서 질문을 적고 전송을 누릅니다. 업로드나 처리가 끝나지 않은 동안에는 전송을 누를 수 없습니다. 처리가 아주 오래 걸려 화면이 기다리는 한도를 넘으면 "문서를 처리하고 있어요. 잠시 후 다시 시도해 주세요."가 나오고 질문은 보내지지 않습니다. 칩은 그대로 남아 상태를 계속 확인하므로, 표시가 사라진 뒤 다시 보냅니다. 붙인 파일이 모두 거부되면 "첨부한 파일을 모두 올리지 못해 전송하지 않았습니다. 파일을 확인한 뒤 다시 보내 주세요."가 파일별 사유와 함께 나오고, 적어 둔 질문은 입력란에 그대로 남습니다.

처리에 실패한 파일​

처리에 실패한 파일은 칩 테두리가 빨갛게 바뀌고 칩 아래에 이유가 표시됩니다. 실패한 파일이 남아 있으면 "문서 처리에 실패한 파일이 있어 전송하지 않았어요. 실패한 파일을 삭제한 뒤 다시 보내 주세요."가 나오므로, 칩의 X 버튼으로 그 파일을 뺀 뒤 다시 보냅니다.

칩 아래 표시할 일
"문서의 크기, 쪽 수 또는 추출할 내용이 처리 한도를 초과했습니다. 파일을 나누어 다시 올려 주세요."문서를 장이나 시트 단위로 나눠 올립니다.
"암호로 보호된 문서는 읽을 수 없습니다. 암호를 해제한 파일을 올려 주세요."원본 프로그램에서 암호를 풀고 다시 저장합니다.
"이 파일 형식은 문서 읽기를 지원하지 않습니다. 지원되는 형식으로 변환해 올려 주세요.".pdf나 .docx처럼 위 표의 형식으로 바꿔 올립니다.
"문서 처리 시간이 초과되었습니다. 문서를 나누어 다시 시도해 주세요."문서를 나눠 다시 올립니다.
"문서 내용을 변환하지 못했습니다. 원본 프로그램에서 다시 저장하거나 PDF로 변환해 올려 주세요."원본 프로그램에서 다시 저장하거나 PDF로 바꿉니다.
"문서를 처리하지 못했습니다. 다시 시도하고 문제가 계속되면 관리자에게 문의해 주세요."다시 올려 보고, 계속되면 관리자에게 문의합니다.

보낸 첨부파일 다시 보기​

보낸 질문 말풍선에는 첨부파일 칩이 함께 남습니다. 칩을 누르면 파일 이름이 제목인 문서 보기 창이 열려 원본을 다시 볼 수 있습니다. 창 위쪽 도구모음으로 축소, 확대, 원래 비율로, 너비 맞춤, 왼쪽으로 돌리기, 다운로드, 인쇄를 하고, 크게 보기로 창을 넓힙니다. 창 네 모서리를 끌어 크기를 바꿀 수 있어, 그림처럼 창을 줄여 뒤의 답변과 함께 볼 수도 있습니다. 닫기 버튼이나 Esc 키로 창을 닫습니다.

첨부파일 다시 보기

번호메뉴기능이런 때 사용하세요
1첨부파일 칩이 질문과 함께 보낸 파일입니다. 누르면 문서 보기 창이 열립니다.답변을 읽다가 원본 회의록을 다시 확인할 때
2크게 보기창을 크게 펼칩니다.작은 글씨의 표를 읽을 때
3닫기창을 닫습니다. Esc 키로도 닫힙니다.확인을 마치고 대화로 돌아갈 때
4도구모음축소, 확대, 원래 비율로, 너비 맞춤, 왼쪽으로 돌리기 버튼입니다. 오른쪽 끝의 다운로드, 인쇄로 원본을 내려받거나 인쇄합니다.원본을 크게 보거나 내려받아 보관할 때

알아 둘 점은 다음과 같습니다.

  • 채팅에 붙인 파일은 그 채팅 안에서만 쓰입니다. 새 채팅을 열면 앞 채팅에 올린 파일은 보이지 않으므로, 같은 일의 자료는 한 채팅에 이어서 올립니다.
  • 채팅에 붙인 파일은 올린 지 7일이 지나면 만료됩니다. 만료된 칩에는 만료됨이 붙고 "업로드가 만료되어 파일을 더 이상 열 수 없습니다. 다시 업로드해 주세요."가 안내됩니다. 그 파일이 다시 필요하면 새로 올립니다.
  • 옛 엑셀 형식(.xls)은 에이전트가 읽을 수는 있지만 문서 보기 창에는 그려지지 않습니다. 내려받아 확인하거나 .xlsx로 저장해 올립니다.

따라 해 보기​

김그루 사원이 두 팀의 회의록을 한 번에 올려 비교 요약을 받는 순서입니다.

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 누르고 브레인크루_AI혁신팀_주간회의록_1110.txt와 회의록-영업본부-11월2주.docx를 함께 고릅니다.

  3. 입력란 위에 두 파일의 칩이 붙었는지 확인합니다. 새 채팅이므로 파일은 아직 올라가지 않은 상태입니다.

  4. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다. 입력창에 업로드 중..., **파일 처리 중...**이 차례로 표시된 뒤 질문이 전달됩니다.

    프롬프트: 첨부한 두 회의록에서 결정 사항과 액션 아이템(담당·기한)을 팀별로 정리하고, 두 팀이 함께 챙겨야 할 일을 따로 뽑아 주세요.

  5. 답변에서 팀별 결정 사항과 액션 아이템 표, 두 팀이 함께 챙겨야 할 일을 확인합니다. 김그루 사원이 받은 답변은 AI혁신팀, 영업본부, "두 팀이 함께 챙겨야 할 일" 세 부분으로 나뉘었고, 공통 할 일로 "제안서 템플릿 정비(11월 말)"를 뽑았습니다. 회의록에 담당이나 기한이 없는 항목은 "확인 필요"로 표시됐습니다.

  6. 질문 말풍선의 회의록 칩을 눌러 문서 보기 창을 열고, 답변에 적힌 담당자와 기한이 원본과 같은지 대조합니다.

에이전트에 늘 붙여 두는 파일​

채팅마다 같은 자료를 다시 올리기 번거롭다면 에이전트 편집 화면 오른쪽의 파일 탭에 올려 둡니다. 이 탭에 올린 파일은 채팅이 바뀌어도 에이전트가 계속 쓸 수 있습니다. 회의록 요약 도우미라면 회의록 표준양식처럼 매번 참고할 자료가 알맞습니다. 탭의 "파일을 드래그하거나 클릭하여 업로드" 영역에 파일을 끌어 놓거나 영역을 눌러 고르면 올라가고, 아래 목록에 파일 개수(N개 파일)와 파일마다 크기, 올린 날짜, 처리 상태(문서 처리중, 완료, 파일 처리 실패)가 보입니다. 파일 이름을 누르면 문서 보기 창으로 열립니다. 파일 하나는 그 파일 오른쪽의 삭제 버튼으로 지우고, 전부 지우려면 모두 지우기를 누른 뒤 모든 파일 삭제 확인 창에서 모두 삭제를 누릅니다. 지운 파일은 되돌릴 수 없습니다.

에이전트 파일 탭

번호메뉴기능이런 때 사용하세요
1파일 탭이 에이전트에 늘 붙여 두는 파일을 관리합니다.모든 채팅에서 같은 양식을 참고하게 할 때
2업로드 영역"파일을 드래그하거나 클릭하여 업로드" 영역에 파일을 끌어 놓거나, 영역을 눌러 고릅니다. 영역 안에 지원 형식 안내가 보입니다.회의록 표준양식을 올릴 때
3파일 목록올린 파일과 개수(N개 파일), 크기, 올린 날짜, 처리 상태(문서 처리중, 완료, 파일 처리 실패)입니다. 파일 이름을 누르면 문서 보기 창으로 열립니다.올린 양식이 처리됐는지 확인할 때
4모두 지우기올린 파일을 모두 지웁니다. 모든 파일 삭제 확인 창에서 모두 삭제를 눌러야 지워지며, 되돌릴 수 없습니다. 파일 하나만 지울 때는 그 파일 오른쪽의 삭제 버튼을 씁니다.자료를 새로 정리할 때

파일 탭은 채팅과 같은 형식과 크기 한도를 따르며, 에이전트 하나에 50개까지 올릴 수 있습니다. 업로드 영역의 "지원 형식" 안내에는 .markdown, .ppt, .html, .htm이 빠져 있지만 이 형식도 고를 수 있고, .doc처럼 목록에 없는 형식은 "지원하지 않는 파일 형식입니다"와 함께 빠집니다. 에이전트 편집 화면은 에이전트 수정에서 설명합니다.

에이전트를 만들 때 붙이는 파일​

새 에이전트 화면에서 만들고 싶은 에이전트를 설명할 때도 참고 자료를 붙일 수 있습니다. 이때는 채팅과 받는 형식이 조금 다릅니다.

  • 받는 확장자: .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm
  • 엑셀·표 파일(.xlsx, .xls, .xlsb, .xlsm, .csv)은 붙일 수 없습니다. 표 자료는 에이전트를 만든 뒤 채팅이나 파일 탭에 올립니다.
  • 한 번에 10개까지, 붙인 파일 크기의 합은 50MB까지입니다.
  • 만드는 도중 도우미의 확인 질문에 답할 때는 이미지만 붙일 수 있습니다. 다른 파일을 붙이면 "이미지 첨부만 지원합니다."가 나옵니다.

자세한 화면은 에이전트 만들기에 있습니다.

자주 보는 안내 문구​

화면 안내뜻할 일
"지원하지 않는 파일 형식입니다"위 표에 없는 확장자입니다.받는 형식으로 다시 저장해 붙입니다.
"PDF 파일 크기가 제한(20MB)을 초과합니다. 현재 크기: …"종류별 크기 한도를 넘었습니다.필요한 쪽만 나눠 저장합니다.
"파일 크기가 업로드 제한(50MB)을 초과합니다."파일 한 개의 업로드 제한을 넘었습니다.파일을 나누거나 줄입니다.
"빈 파일은 업로드할 수 없습니다."내용이 없는 파일입니다.입력창에 남은 칩을 X 버튼으로 빼고, 원본을 다시 저장해 붙입니다.
"파일 확장자와 실제 파일 형식이 일치하지 않습니다."확장자만 바꾼 파일처럼 이름과 내용이 다릅니다.원본 프로그램에서 해당 형식으로 다시 저장합니다.
"암호나 권한 보호(DRM)가 걸린 문서는 업로드할 수 없습니다. 보호를 해제한 뒤 다시 올려 주세요."암호나 DRM이 걸린 문서입니다.보호를 해제한 사본을 올립니다.
"최대 10개 파일만 업로드할 수 있습니다."이미 10개가 붙어 있는데 더 골랐습니다.나머지는 다음 질문에 붙입니다.
"2개 파일이 제한으로 인해 추가되지 않았습니다."10개 한도를 넘은 만큼 빠졌습니다.빠진 파일은 다음 질문에 붙입니다.
"문서를 처리하고 있어요. 잠시 후 다시 시도해 주세요."처리가 오래 걸려 화면이 기다리는 한도를 넘었습니다. 질문은 보내지지 않았습니다.칩의 처리 표시가 사라진 뒤 다시 보냅니다.
"첨부한 파일을 모두 올리지 못해 전송하지 않았습니다. 파일을 확인한 뒤 다시 보내 주세요."붙인 파일이 모두 거부됐습니다.함께 나온 파일별 사유를 보고 고쳐 다시 붙입니다.
만료됨올린 지 7일이 지나 파일을 열 수 없습니다.필요하면 다시 올립니다.

정리​

  • 채팅에는 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm을 붙일 수 있습니다.
  • 크기 한도는 PDF·이미지·Word·한글 20MB, 마크다운·텍스트·웹 문서 10MB, 엑셀·표·PowerPoint 50MB입니다. 메시지 한 번에 10개까지입니다.
  • **업로드 중...**과 **파일 처리 중...**이 사라진 뒤 보냅니다.
  • 모든 채팅에서 쓸 자료는 에이전트 편집 화면 파일 탭에 올립니다(에이전트당 50개).
