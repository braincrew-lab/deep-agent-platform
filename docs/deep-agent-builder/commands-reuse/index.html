커맨드와 재사용

매주 같은 형식으로 보내는 요청은 커맨드로 저장해 두고, 대화 입력창에서 / 를 입력해 불러 쓸 수 있습니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 주간 업무 보고서 도우미에게 보내는 주간보고 요청과 회의록 요약 도우미에게 보내는 액션 아이템 요청을 커맨드로 만들어 쓰는 과정을 화면 순서대로 안내합니다. 입력란 아래 왼쪽의 도구, 서브에이전트, 미들웨어, 스킬 버튼으로 에이전트 구성을 확인하고 스킬을 바로 부르는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 사이드바의 에셋설정을 눌러 여는 에셋 화면의 커맨드 탭에서 기본 커맨드와 내가 만든 커스텀 커맨드를 찾고, 더 쓰지 않는 커맨드를 지웁니다.
  • 커맨드 이름, 설명, 프롬프트를 채워 새 커맨드를 저장합니다. 이름은 영문 소문자로 시작해야 하고, 프롬프트는 2000자까지 쓸 수 있습니다.
  • 에이전트 대화 입력창에서 / 를 입력해 저장한 커맨드를 고르고, 프롬프트를 바로 보냅니다.
  • 기본으로 들어 있는 기본 커맨드(예: /preview_sandbox_data)도 / 목록에서 같은 방법으로 골라 씁니다.
  • 입력란 아래 왼쪽의 도구, 서브에이전트, 미들웨어, 스킬 버튼으로 이 에이전트에 연결된 구성을 확인하고, 스킬을 골라 바로 요청합니다.
  • 커맨드와 복제·내보내기(에이전트 구성 전체를 옮겨 쓰는 방법)가 어떻게 다른지 알아봅니다.

커맨드 탭​

사이드바 아래쪽 에셋설정을 눌러 여는 에셋 화면에서 커맨드 탭을 고릅니다. 위쪽은 기본 커맨드, 아래쪽은 내가 만든 커스텀 커맨드 자리입니다. 그림은 기본 커맨드 세 개 아래에 커스텀 커맨드 두 개를 만들어 둔 상태입니다.

검색란에 글자를 넣으면 커맨드 이름과 설명에 그 글자가 들어 있는 것만 남습니다. 커스텀 커맨드 카드에는 커맨드 이름(예: /weekly_report), 설명, 프롬프트 앞부분이 보이고, 카드의 삭제(휴지통)를 누르면 확인 창 없이 바로 지워집니다. 새 커맨드는 커맨드 추가로 만듭니다.

커맨드 탭

번호메뉴기능이런 때 사용하세요
1커맨드 탭기본 커맨드와 커스텀 커맨드를 관리하는 화면을 엽니다.지난주에 만든 주간보고 커맨드의 프롬프트를 다시 확인할 때
2검색란커맨드 이름과 설명에 들어 있는 글자로 목록을 걸러 봅니다.커맨드가 많아져 설명에 "회의"가 들어간 것만 보고 싶을 때
3기본 커맨드기본으로 제공되는 커맨드입니다. "기본 제공되는 커맨드로 수정할 수 없습니다." 안내가 보이고, 카드에 기본 표시가 붙습니다.기본 커맨드와 내가 만든 커맨드를 구분할 때
4커맨드 추가새 커맨드를 입력하는 칸을 엽니다.매주 반복하는 보고 요청을 새로 저장할 때

커스텀 커맨드 카드

번호메뉴기능이런 때 사용하세요
1커맨드 이름입력창에서 / 뒤에 입력할 이름(/weekly_report)입니다. 아래 줄에 설명(주간보고)이 보입니다.입력창에서 부를 이름을 확인할 때
2프롬프트 앞부분커맨드를 고르면 전송될 문장의 앞부분입니다.어떤 문장이 전송되는지 보내기 전에 확인할 때
3삭제(휴지통)커맨드를 지웁니다. 확인 창 없이 바로 지워지고 "커맨드가 삭제되었습니다" 알림이 뜹니다.보고 양식이 바뀌어 옛 커맨드를 정리할 때

커맨드 카드에는 수정 버튼이 없습니다. 프롬프트를 고치려면 기존 커맨드를 지운 뒤 같은 이름으로 다시 추가합니다.

기본 커맨드​

커맨드 탭 위쪽 기본 커맨드 자리에는 기본으로 제공되는 커맨드가 있고, 입력창의 / 목록에도 함께 보입니다. 카드에는 기본 표시가 붙고, 고칠 수도 지울 수도 없습니다. 고르는 방법은 내가 만든 커맨드와 같습니다.

커맨드설명
/list_agent_files업로드된 지식 파일 목록 조회
/markdown_image_format본문의 이미지를 마크다운 형식으로 출력
/preview_sandbox_dataExcel, CSV 파일 미리보기

대화 답변을 파일로 받는 일은 커맨드로 하지 않습니다. 일반 에이전트가 답변을 아티팩트로 만들었다면 답변의 아티팩트 카드나 입력란 아래 오른쪽의 아티팩트 버튼을 눌러 아티팩트 창을 열고, 그 창의 내보내기로 받습니다. 아티팩트 창은 저절로 열리지 않습니다. 문서작성 에이전트라면 캔버스의 내보내기를 씁니다. 그 밖에는 에이전트에게 답변을 파일로 만들어 달라고 요청합니다. 자세한 방법은 PPT·문서 만들기에 있습니다.

커맨드 추가​

커맨드 추가를 누르면 커스텀 커맨드 영역에 입력 칸 세 개가 열립니다. 각 칸 아래에는 입력한 글자 수와 최대 글자 수가 표시됩니다.

  • 커맨드: / 뒤에 붙을 커맨드 이름입니다. 영문 소문자로 시작하고 소문자, 숫자, 밑줄만 쓸 수 있으며 최대 32자입니다. 예: weekly_report, action_items
  • 설명: 입력창 커맨드 목록에 이름과 함께 보일 짧은 설명입니다. 최대 255자이며, 한글 이름(예: 주간보고)은 여기에 적습니다.
  • 프롬프트: 커맨드를 고르면 실제로 전송될 문장입니다. 최대 2000자입니다.

취소를 누르면 입력한 내용을 버리고 칸을 닫습니다. 저장을 누르면 "커맨드가 추가되었습니다" 알림이 뜨고 목록에 카드가 생깁니다.

커맨드 추가

번호메뉴기능이런 때 사용하세요
1커맨드 입력란/ 뒤에 붙을 커맨드 이름을 적습니다. 영문 소문자로 시작하고 소문자, 숫자, 밑줄만 쓸 수 있으며 최대 32자입니다."weekly_report", "action_items"처럼 업무를 알아볼 수 있는 이름을 정할 때
2설명 입력란입력창 커맨드 목록에 이름과 함께 보일 짧은 설명입니다. 최대 255자입니다.영문 이름만으로는 뜻을 알기 어려워 "주간보고"처럼 한글 설명을 붙여 둘 때
3프롬프트 입력란커맨드를 고르면 실제로 전송될 문장입니다. 최대 2000자입니다.보고 항목과 순서, 표 형식을 매주 똑같이 요청하고 싶을 때
4저장커맨드를 저장합니다. 저장되면 "커맨드가 추가되었습니다" 알림이 뜨고 목록에 카드가 생깁니다.프롬프트를 다 쓰고 목록에 올릴 때

이럴 때 쓰세요: 김그루 사원은 커맨드를 저장하기 전에 같은 요청을 주간 업무 보고서 도우미에게 두세 번 직접 보내 보고, 원하는 형식이 나온 문장만 프롬프트 칸에 옮깁니다. 팀장이 보고 양식에 리스크 항목을 더해 달라고 하면 기존 커맨드를 지우고, 항목을 고친 프롬프트로 같은 이름의 커맨드를 다시 저장합니다. 설명 칸에는 주간보고(팀장 양식)처럼 어떤 양식인지까지 적어 두면 비슷한 커맨드가 늘어나도 헷갈리지 않습니다.

저장 왼쪽의 취소를 누르면 입력한 내용을 버리고 칸을 닫습니다.

프롬프트를 비워 두면 "프롬프트를 입력해 주세요", 2000자를 넘기면 "프롬프트는 2000자 이하여야 합니다" 알림이 뜨고 저장되지 않습니다.

커맨드 이름에 한글을 넣었을 때​

커맨드 이름에는 한글을 쓸 수 없습니다. 커맨드 칸에 "주간보고"처럼 한글을 입력하면 칸이 빨간 테두리로 바뀌고 아래에 "소문자, 숫자, 밑줄만 사용 가능 (최대 32자)"가 나타나며, 저장을 누를 수 없습니다. 한글 이름은 설명 칸에 적고, 커맨드 이름은 weekly_report, action_items처럼 영문으로 정하세요.

커맨드 이름 규칙 안내

번호메뉴기능이런 때 사용하세요
1커맨드 입력란규칙에 맞지 않는 이름이면 테두리가 빨갛게 바뀌고 아래에 규칙이 표시됩니다."주간보고"로 만들려다 안내 문구가 떠서 이름을 "weekly_report"로 바꿀 때
2저장이름이 규칙에 맞을 때까지 누를 수 없습니다.이름을 고친 뒤 저장이 다시 눌리는지 확인할 때

따라 해 보기​

AI혁신팀 김그루 사원은 금요일마다 주간 업무 보고서 도우미에게 한 주 메모로 보고서 초안을 받습니다. 매번 같은 요청을 다시 쓰지 않도록 커맨드로 저장합니다.

  1. 사이드바 아래쪽 에셋설정을 눌러 여는 에셋 화면에서 커맨드 탭을 고릅니다.

  2. 커맨드 추가를 누릅니다.

  3. 커맨드 칸에 "weekly_report"를 입력합니다.

  4. 설명 칸에 "주간보고"를 입력합니다.

  5. 프롬프트 칸에 보고 항목을 번호로 적습니다. 예를 들어 아래 문장을 붙여 넣습니다.

    프롬프트: 이 대화에 올린 주간 업무 메모로 주간 업무 보고서 초안을 작성해 주세요. 형식은 매주 같게 맞춥니다. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 개조식으로 쓰고, 메모에 없는 내용은 만들지 말고 [확인 필요]로 표시해 주세요.

  6. 저장을 누르고 목록에 /weekly_report 카드가 생겼는지 확인합니다.

  7. 같은 방법으로 회의록 요약 도우미에 쓸 커맨드를 하나 더 만듭니다. 커맨드는 "action_items", 설명은 "액션아이템", 프롬프트는 아래 문장입니다.

    프롬프트: 이 대화에 올린 회의록에서 결정 사항과 액션 아이템을 뽑아 주세요. 표의 열은 할 일, 담당자, 기한, 근거 문장입니다. 담당자나 기한이 회의록에 없으면 빈칸 대신 "미정"이라고 적고, 회의록에 없는 내용은 만들지 마세요.

팁: 프롬프트에 개인정보(예: 고객 이름, 연락처, 계좌번호)를 적지 마세요. 커맨드는 여러 대화에서 그대로 다시 전송됩니다.

대화 입력창에서 커맨드 부르기​

저장한 커맨드는 에이전트 대화 화면의 메시지 입력창에서 부릅니다. 맨 앞에 / 를 입력하면 입력창 위로 커맨드 목록이 열립니다. 위쪽 기본 커맨드 묶음에 기본 커맨드가, 아래쪽 커스텀 커맨드 묶음에 내가 만든 커맨드가 이름과 설명과 함께 보입니다. / 뒤에 글자를 이어 쓰면 커맨드 이름에 그 글자가 들어간 것만 남습니다. 예를 들어 "/we"까지 입력하면 weekly_report만 남습니다. 띄어쓰기를 하면 목록이 닫힙니다. 커맨드를 누르거나, 위·아래 화살표로 고르고 Enter를 누르면 프롬프트가 바로 전송됩니다.

커맨드 목록

번호메뉴기능이런 때 사용하세요
1메시지 입력창맨 앞에 / 를 입력하면 커맨드 목록이 열립니다. / 뒤에 글자를 이어 쓰면 커맨드 이름에 그 글자가 들어간 것만 남습니다. 띄어쓰기를 하면 목록이 닫힙니다."/we"까지 입력해 weekly_report만 남겨 고를 때
2커스텀 커맨드내가 만든 커맨드 묶음입니다. 그 위의 기본 커맨드 묶음에는 기본 커맨드가 기본 표시와 함께 보입니다.내가 만든 커맨드만 골라 볼 때
3/weekly_report커맨드 이름과 설명이 보입니다. 누르면 프롬프트가 바로 전송됩니다. 위·아래 화살표로 고르고 Enter를 눌러도 됩니다.금요일 오후에 주간보고 요청을 한 번에 보낼 때
4/action_items다른 커스텀 커맨드입니다.회의록을 올린 뒤 할 일 표를 받을 때

커맨드를 고르면 입력창에 프롬프트가 채워지는 것이 아니라 곧바로 전송됩니다. 덧붙일 말이 있으면 커맨드를 보낸 뒤 다음 메시지로 이어서 적습니다. 목록을 닫으려면 Esc를 누릅니다. 이름과 맞는 커맨드가 없으면 "일치하는 커맨드가 없습니다"가 보입니다. 설명 칸의 한글로는 걸러지지 않으니 / 뒤에는 한글 대신 영문 이름 앞부분을 입력합니다.

입력창의 도구·서브에이전트·미들웨어·스킬 목록​

에이전트 대화 화면의 입력란 아래 왼쪽에는 이 에이전트에 연결된 구성을 보여 주는 목록 버튼 네 개(도구, 서브에이전트, 미들웨어, 스킬)가 있습니다. 도구, 서브에이전트, 미들웨어 목록은 확인용이고, 스킬 목록은 골라서 바로 요청할 수 있습니다. 연결된 도구가 없으면 도구 목록에 "구성된 도구가 없습니다"가, 스킬이 없으면 스킬 목록에 "등록된 스킬이 없습니다"가 보입니다. 그림은 스킬이 연결되지 않은 주간 업무 보고서 도우미에서 스킬을 누른 모습입니다.

커맨드와 에이전트 재사용의 차이​

커맨드는 문장 하나를 저장해 두었다가 어느 에이전트 대화에서든 다시 보내는 기능입니다. 에이전트 구성(예: 지침, 모델, 지식함, 스킬)은 커맨드에 들어가지 않습니다.

  • 같은 요청 문장을 여러 에이전트에 반복해 보낼 때는 커맨드를 씁니다.
  • 대화를 시작할 때 고를 예시 질문을 에이전트마다 보여 주려면 챗 오프너를 씁니다.
  • 지침과 연결 자원까지 그대로 가져와 조금 바꿔 쓰려면 에이전트 편집 화면 머리글의 에이전트 복제를 씁니다. 에이전트 편집 화면은 에이전트 수정에 있습니다.
  • 다른 사람이나 다른 환경으로 구성을 옮기려면 에이전트 가져오기와 내보내기를 참고합니다.
  • 정해진 시각에 같은 요청을 자동으로 보내려면 스케줄링과 백그라운드 모드의 스케줄을 씁니다.

정리​

  • 커맨드 이름은 영문 소문자로 시작하고 소문자·숫자·밑줄만 씁니다. 한글 이름은 설명 칸에 적습니다.
  • 입력창에서 / 를 입력해 커맨드를 고르면 프롬프트가 바로 전송됩니다. 파일이 필요하면 먼저 문장과 함께 보내 둡니다.
  • 커맨드에는 수정 버튼이 없어 지우고 다시 만듭니다. 삭제 버튼을 누르면 확인 창 없이 바로 지워집니다.
