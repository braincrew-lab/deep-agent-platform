Deep Agent Builder 멀티에이전트 개념

멀티에이전트는 부모 에이전트가 업무 일부를 서브에이전트에 맡기고 그 결과를 이어서 사용하는 방식입니다. 이 페이지에서는 두 에이전트의 연결 조건, 실행 전에 다시 확인하는 권한, 결과가 전달되는 범위를 구분합니다. 실제 연결 절차는 서브에이전트 할당하기를 먼저 확인하세요.

부모 에이전트와 서브에이전트는 어떻게 다른가요?​

부모 에이전트는 사용자의 요청과 전체 실행 흐름을 관리합니다. 서브에이전트는 부모가 맡긴 작업을 처리합니다. 연결했다고 해서 두 에이전트가 같은 자원과 권한을 자동으로 공유하는 것은 아닙니다.

서브에이전트 연결은 부모 에이전트의 설정에 저장됩니다. 연결할 수 있는 대상은 현재 사용자가 소유한 일반 에이전트이며, 보관된 에이전트나 Super Agent는 대상이 될 수 없습니다. 부모 자신을 다시 연결하거나 서로를 순환해서 연결하면 저장할 수 없습니다.

구성을 확인할 때는 다음 세 가지를 나눠 보세요.

구분확인할 내용
연결부모가 의도한 서브에이전트를 참조하는가
실행현재 사용자가 연결된 에이전트와 자원을 사용할 수 있는가
결과작업 결과가 사용자 화면과 부모 에이전트에 어떻게 보이는가

연결 상태와 실행 가능 여부를 따로 확인하세요​

연결 목록에 대상이 보이는 것은 설정이 저장됐다는 뜻입니다. 실제 실행 가능 여부는 실행을 시작할 때 다시 판단합니다. 따라서 저장이 완료됐다는 이유만으로 다음 실행도 성공한다고 판단하지 마세요.

연결 뒤에는 다음 순서로 확인합니다.

  1. 부모와 대상이 현재 사용자가 소유한 범위에 있는지 확인합니다.
  2. 대상이 보관 상태가 아니며 Super Agent가 아닌지 확인합니다.
  3. 자기 자신을 가리키거나 같은 대상을 중복해서 연결하지 않았는지 확인합니다.
  4. 서로 연결된 에이전트가 다시 상대를 가리키는 순환 구조가 아닌지 확인합니다.
  5. 저장한 뒤 부모의 연결 목록에 의도한 대상만 남았는지 다시 확인합니다.

실행을 시작하면 부모 에이전트와 선택한 대화, 실행 방식에 연결된 자원을 사용할 수 있는지 다시 확인합니다. 이 확인에는 권한이 아직 유효한지, 현재 실행과 다른 실행의 권한을 재사용하지 않았는지, 직접 연결된 서브에이전트와 자원이 실행 대상에 포함되는지가 들어갑니다.

검사에 실패하면 실제 작업을 시작하기 전에 실행이 중단됩니다. 저장 목록이 올바른데 실행되지 않는다면 부모 설정을 반복해서 저장하지 말고, 실행 전 권한 확인에서 다음 원인을 구분하세요.

  • 사용 권한이 없음
  • 권한 확인 시간이 초과됨
  • 권한이 만료됨
  • 이미 사용한 실행 요청을 다시 사용함
  • 현재 실행과 연결 대상이 일치하지 않음

작업 결과는 두 곳에서 다르게 보일 수 있습니다​

서브에이전트가 만든 결과는 사용자 화면에 원본 결과로 표시될 수 있습니다. 반면 부모 에이전트가 다음 작업을 이어 갈 때는 같은 결과 전체가 아니라 결과를 가리키는 짧은 안내가 전달될 수 있습니다.

이 안내에는 결과를 다시 찾는 데 필요한 식별 정보와 결과의 종류, 제목, 분량이 포함될 수 있습니다. 부모 에이전트가 후속 작업에 원문을 반드시 사용해야 할 때만 원문 조회를 수행합니다. 원문을 조회하지 않아도 되는 작업이라면 자동으로 전체 결과가 합쳐진다고 가정하지 마세요.

따라서 다음 두 사실은 별도로 확인해야 합니다.

  1. 사용자 화면에 서브에이전트의 원본 결과가 표시됐는가
  2. 부모 에이전트가 후속 작업에 사용할 결과 안내를 받았는가

원본 결과와 후속 조회 결과가 화면에 중복해서 표시된다면 같은 결과를 두 번 렌더링한 것인지 확인하세요. 화면을 합성해 중복을 숨기지 말고, 어느 결과가 원본이고 어느 결과가 후속 조회인지 구분합니다.

문제가 생겼을 때 어디부터 확인하나요?​

상황먼저 확인할 것다음 판단
연결 저장이 거부됨대상의 소유 범위와 상태, 자기 참조와 순환 연결대상 조건을 바꾼 뒤 다시 저장합니다. 권한 문제를 입력 문제로 보지 않습니다.
저장은 됐지만 실행되지 않음연결된 자원의 사용 권한과 실행 전 확인 결과설정 화면이 아니라 실행 전 권한 결과를 확인합니다.
결과는 보이지만 부모가 이어 쓰지 못함부모가 받은 결과 안내와 원문 조회 필요 여부자동으로 원문이 합쳐졌다고 가정하지 말고 필요한 경우에만 조회합니다.
같은 결과가 두 번 표시됨원본 표시와 후속 조회 결과가 함께 렌더링됐는지두 결과의 표시 경계를 구분해 확인합니다.

구성이 끝났는지 확인하는 기준​

다음 조건을 모두 확인했을 때 멀티에이전트 구성이 완료됐다고 판단합니다.

  • 부모 에이전트의 연결 목록에 의도한 서브에이전트가 저장되어 있습니다.
  • 대상이 현재 사용자가 사용할 수 있는 일반 에이전트이며 보관 상태나 Super Agent가 아닙니다.
  • 자기 참조, 중복 연결, 순환 연결이 없습니다.
  • 부모와 직접 연결된 자원을 현재 실행에서 사용할 수 있습니다.
  • 실행 전 권한 확인에서 연결 대상과 자원이 허용됩니다.
  • 사용자 화면의 원본 결과와 부모 에이전트가 받은 결과 안내를 구분할 수 있습니다.
  • 후속 작업에 원문이 필요할 때만 원문 조회를 사용합니다.
