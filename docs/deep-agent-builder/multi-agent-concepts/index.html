멀티에이전트 개념

멀티에이전트는 에이전트 하나가 모든 일을 혼자 하지 않고, 이미 만들어 둔 다른 에이전트에게 일을 나눠 맡기는 구성입니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 만든 "업무 총괄 비서"를 예로 들어 멀티에이전트가 무엇인지, 화면 어디에서 확인하는지, 언제 쓰면 좋은지 설명합니다.

이 페이지에서 할 수 있는 일

  • 총괄 에이전트와 서브에이전트가 각각 무엇을 맡는지 팀 업무 분담에 빗대어 이해합니다.
  • 일을 나눠 맡기는 세 가지 방법(서브에이전트 직접 연결, 대화로 만들기의 서브에이전트 추천, SUPER AI 에이전트)을 구분합니다.
  • 에이전트 편집 화면, 대화 화면, 에이전트 관리 창에서 서브에이전트 연결을 확인합니다.
  • 내 업무를 에이전트 하나로 처리할지, 여러 에이전트로 나눌지 판단합니다.

팀장과 담당자로 보는 멀티에이전트​

김그루 사원은 매주 금요일 팀장에게 주간 보고를 올립니다. 보고에는 이번 주 회의에서 정한 일, 자신의 업무 내용, 판매 실적 요약이 들어갑니다. 지금까지는 회의록을 요약하고, 업무 메모를 보고서 형식으로 옮기고, 판매 엑셀을 따로 집계해 하나로 합쳤습니다.

이 세 가지 일을 맡는 에이전트는 이미 있습니다. 회의록 요약 도우미, 주간 업무 보고서 도우미, 판매 데이터 분석가입니다. 멀티에이전트는 이 세 에이전트를 담당자로 두고, 팀장 역할을 하는 에이전트 하나가 요청을 받아 일을 나눠 맡긴 뒤 결과를 모아 답하게 하는 구성입니다. 화면에서는 담당 에이전트를 서브에이전트라고 부릅니다. 이 매뉴얼에서는 서브에이전트를 붙인 쪽을 "총괄 에이전트"라고 부릅니다.

팀의 역할멀티에이전트에서의 역할브레인크루 예시 에이전트
팀장총괄 에이전트. 요청을 받아 일을 나누고 결과를 모아 답합니다.업무 총괄 비서
회의 기록 담당서브에이전트. 회의록에서 결정 사항과 담당·기한을 뽑아 요약합니다.회의록 요약 도우미
보고서 담당서브에이전트. 업무 메모를 주간 보고서 형식으로 정리합니다.주간 업무 보고서 도우미
데이터 담당서브에이전트. 판매 엑셀을 집계하고 표와 차트로 정리합니다.판매 데이터 분석가

서브에이전트도 따로 보면 평범한 에이전트입니다. 회의록 요약 도우미는 업무 총괄 비서에 붙어 있어도 사이드바에서 열어 혼자 대화할 수 있습니다. 서브에이전트로 붙인다고 해서 원래 에이전트가 복사되거나 바뀌지 않습니다. 반대로 담당 에이전트의 지침을 고치면 그 에이전트를 쓰는 모든 총괄 에이전트의 결과가 함께 바뀝니다.

직접 연결하는 방법은 서브에이전트 할당하기, 실행 중 화면은 멀티에이전트 실행 흐름에서 설명합니다.

에이전트 편집 화면에서 서브에이전트 확인하기​

서브에이전트는 총괄 에이전트의 에이전트 편집 화면에서 붙이고 확인합니다. 사이드바에서 에이전트를 연 뒤 에이전트 설정을 누르면 에이전트 편집 화면이 열립니다. 가운데 편집 영역의 폼 보기에서 지침 바로 아래, 모델 위에 서브에이전트 칸이 있습니다. 이 칸에는 연결된 서브에이전트 이름이 두 개까지 모두 보이고, 세 개부터는 앞의 두 이름 뒤에 "+1"처럼 나머지 개수가 붙습니다. 하나도 없으면 "서브에이전트가 없습니다"로 표시됩니다. 칸 오른쪽의 톱니바퀴 버튼(서브에이전트 관리)을 누르면 서브에이전트를 추가하거나 빼는 창이 열립니다. 편집 영역 위쪽의 비주얼을 누르면 같은 구성이 총괄 에이전트 상자와 서브 에이전트 상자를 선으로 이은 그림으로 바뀌므로, 담당 구성을 한눈에 보거나 팀장에게 구조를 설명할 때 씁니다.

그림은 서브에이전트 세 개를 붙인 업무 총괄 비서의 에이전트 편집 화면입니다.

에이전트 편집 화면의 서브에이전트 칸

번호메뉴기능이런 때 사용하세요
1폼가운데 편집 영역을 입력 양식으로 보여 줍니다. 서브에이전트 칸은 지침 바로 아래, 모델 위에 있습니다.서브에이전트 이름을 글자로 확인할 때
2비주얼같은 설정을 연결 그림으로 보여 줍니다. 총괄 에이전트와 서브 에이전트 상자가 선으로 이어집니다.담당 구성을 한눈에 보거나 팀장에게 구조를 설명할 때
3서브에이전트 칸연결된 서브에이전트 이름입니다. 두 개까지는 이름을 모두 보여 주고, 세 개부터는 앞의 두 이름 뒤에 "+1"처럼 나머지 개수를 붙입니다. 그림은 "회의록 요약 도우미, 주간 업무 보고서 도우미 +1"입니다. 하나도 없으면 "서브에이전트가 없습니다"로 표시됩니다.지금 누구에게 일을 나눠 맡기고 있는지 확인할 때
4서브에이전트 관리톱니바퀴 버튼입니다. 서브에이전트를 추가하거나 빼는 창을 엽니다.담당 에이전트를 새로 붙이거나 뺄 때

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 업무 총괄 비서를 누릅니다.
  2. 사이드바 위쪽의 에이전트 설정을 누릅니다.
  3. 폼 보기에서 지침 아래 서브에이전트 칸의 이름을 읽습니다.
  4. 비주얼을 눌러 같은 구성이 그림으로 어떻게 보이는지 확인한 뒤 폼으로 돌아옵니다.

대화 화면에서 서브에이전트 확인하기​

대화 화면의 입력란 아래 왼쪽에는 도구, 서브에이전트, 미들웨어, 스킬 버튼이 아이콘으로 있습니다. 사람 모양 아이콘의 서브에이전트 버튼을 누르면 위쪽에 "서브에이전트"라는 이름표가 뜨고, 아래로 이 에이전트에 붙어 있는 서브에이전트 이름이 펼쳐집니다. 워크스페이스 에이전트를 붙였다면 이름 옆에 워크스페이스 표시가, 지금 실행할 수 없는 에이전트라면 실행 불가 표시가 붙습니다. 여기서는 목록을 보기만 하고, 추가나 삭제는 에이전트 편집 화면에서 합니다.

SUPER AI 에이전트​

SUPER AI 에이전트는 담당을 미리 정해 두지 않아도, 요청을 읽고 내가 쓸 수 있는 에이전트 가운데 알맞은 에이전트를 골라 일을 맡기는 에이전트입니다. 모든 에이전트에 일을 자동으로 나눠 주는 창구라고 생각하면 됩니다. 사이드바 위쪽 더 보기 메뉴에서 엽니다. 에이전트 대화 화면 안에서는 사이드바 위쪽이 뒤로, 이 에이전트와 새 대화, 에이전트 설정으로 바뀌므로, 뒤로를 눌러 처음 사이드바로 돌아온 뒤 엽니다.

더 보기 메뉴의 SUPER AI 에이전트

번호메뉴기능이런 때 사용하세요
1더 보기사이드바 위쪽 새 에이전트, 에이전트 템플릿 아래에 있습니다. 누르면 오른쪽에 유틸리티, 작업, 평가, SUPER AI 에이전트가 펼쳐집니다.자주 쓰지 않는 메뉴를 찾을 때
2SUPER AI 에이전트SUPER AI 에이전트 대화 화면을 엽니다. 처음 누르면 내 계정에 SUPER AI 에이전트가 만들어진 뒤 열립니다. 화면 위쪽에는 "SUPER AI Agent"라는 이름과 "Auto-routing meta agent for all your agents"라는 설명이 보입니다.어느 에이전트에 맡겨야 할지 모르는 요청을 보낼 때

SUPER AI 에이전트는 인사나 간단한 질문에는 직접 답하고, 요청이 어떤 에이전트의 이름, 설명, 도구, 자료와 맞으면 그 에이전트에게 맡깁니다. 맡긴 기록은 대화 화면에 에이전트에 위임 상자로 남고, 답변 첫머리에 "회의록 요약 도우미에게 맡겨 아래와 같이 정리했습니다."처럼 어느 에이전트에게 맡겼는지 밝힙니다. 맡길 만한 에이전트가 없으면 그 업무용 에이전트를 만들 수 있다고 안내합니다.

SUPER AI 에이전트는 일반 에이전트 목록에 나오지 않고, 다른 에이전트의 서브에이전트로 붙일 수도 없습니다. 만드는 데 실패하면 "SUPER AI 에이전트 생성에 실패했습니다" 알림이 나옵니다.

따라 해 보기​

  1. 사이드바 위쪽의 더 보기를 누릅니다.
  2. SUPER AI 에이전트를 누릅니다.
  3. 입력란 아래 오른쪽의 파일 업로드(클립)로 "브레인크루_AI혁신팀_주간회의록_1110.txt"를 올립니다.
  4. 입력창에 다음과 같이 보내고, 어느 에이전트에 맡겼는지 답변 첫머리를 읽습니다.

프롬프트: 첨부한 회의록에서 결정 사항과 담당자, 기한을 표로 정리해 주세요.

팁: 같은 업무를 매주 반복한다면 SUPER AI 에이전트보다 서브에이전트를 직접 붙인 총괄 에이전트가 더 안정적입니다. 맡길 담당과 순서를 지침에 적어 둘 수 있기 때문입니다.

나눠 맡기면 좋은 업무​

에이전트 하나에 지침을 계속 덧붙이면 지침이 길어지고, 어느 규칙 때문에 답이 달라졌는지 찾기 어려워집니다. 다음과 같은 업무라면 담당 에이전트를 나누는 편이 관리하기 쉽습니다.

  • 단계마다 필요한 자료나 도구가 다른 업무. 주간 보고에서 회의 요약에는 회의록 텍스트가, 실적 집계에는 판매 엑셀과 코드 실행이 필요합니다.
  • 이미 잘 쓰고 있는 에이전트가 있는 업무. 회의록 요약 도우미와 판매 데이터 분석가가 따로 검증되어 있다면 새로 만들지 않고 붙여 씁니다.
  • 맡은 부분마다 고칠 사람이 다른 업무. 보고서 형식은 김그루 사원이, 분석 기준은 영업1팀 최하늘 책임이 각자의 에이전트에서 고칩니다.

반대로 질문 하나에 답 하나로 끝나는 업무(회의록 한 건 요약, 이메일 한 통 작성)는 에이전트 하나로 충분합니다. 담당이 늘수록 응답 시간과 토큰 사용량도 늘어납니다.

에이전트 관리 창에서 확인하기​

사이드바 에이전트 목록 위의 에이전트 관리 창에서도 서브에이전트를 볼 수 있습니다. 왼쪽 패널에서 에이전트를 고르면 에이전트 설정 영역의 서브에이전트 항목에 연결된 에이전트 이름과 설명이 나오고, 이름을 누르면 그 에이전트 항목이 선택됩니다. 연결이 없으면 "서브에이전트 없음"으로 표시됩니다. 이 창에서는 연결을 보기만 하고, 추가나 삭제는 에이전트 편집 화면에서 합니다.

용어 정리​

용어뜻
서브에이전트다른 에이전트에 붙어 일을 나눠 받는 에이전트입니다. 비주얼 보기에서는 "서브 에이전트", 대화 기록에서는 "하위 에이전트"로 표기되는 곳도 있습니다.
총괄 에이전트서브에이전트를 붙인 쪽 에이전트입니다. 화면에 따로 표기되는 이름은 없고, 이 매뉴얼에서 설명을 위해 쓰는 말입니다.
서브에이전트 관리에이전트 편집 화면에서 서브에이전트를 추가하거나 빼는 창입니다.
SUPER AI 에이전트담당을 미리 정하지 않고 요청에 맞는 에이전트를 골라 맡기는 에이전트입니다.

정리​

  • 총괄 에이전트는 팀장, 서브에이전트는 담당자입니다. 총괄 에이전트의 지침에 누구에게 무엇을 맡길지 적어 둡니다.
  • 서브에이전트는 원래 있던 에이전트를 그대로 붙여 씁니다. 붙이기 전에 그 에이전트가 혼자서도 제대로 동작하는지 먼저 확인하세요.
  • 담당을 정하지 않고 맡기고 싶다면 SUPER AI 에이전트를 씁니다.
