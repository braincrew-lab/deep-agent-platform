커뮤니티

Deep Agent Builder에는 동료와 함께 쓰는 공간이 두 가지 있습니다. 하나는 공지사항, 질문, 활용 팁을 글로 나누는 라운지이고, 다른 하나는 내가 만든 에이전트를 사내에 공유해 동료가 바로 대화할 수 있게 하는 워크스페이스 등록과 커뮤니티 에이전트 관리입니다. 이 페이지는 두 공간을 화면 순서대로 설명하고, 브레인크루 AI혁신팀 김그루 사원이 회의록 요약 도우미를 사내에 공유한 뒤 라운지 커뮤니티 게시판에 소개 글을 쓰는 사례로 마무리합니다.

이 페이지에서 할 수 있는 일

  • 라운지의 일곱 게시판이 각각 어떤 글을 위한 곳인지, 누가 글을 쓸 수 있는지 알아봅니다.
  • 게시글 목록을 정렬하고 검색해 필요한 글을 찾습니다.
  • 글쓰기 화면에서 제목과 본문을 쓰고, 이미지와 파일을 붙이고, 임시저장된 글을 복원합니다.
  • 처음 글을 쓸 때 나오는 닉네임 설정 창에서 라운지에 표시될 닉네임을 정합니다.
  • 게시글에 추천을 누르고, 댓글과 답글을 남깁니다.
  • 에이전트 편집 화면의 워크스페이스 등록으로 내 에이전트를 사내에 공유하고, 커뮤니티 에이전트 관리에서 배포 요청·재배포·비공개·삭제를 관리합니다.
  • 공유한 에이전트가 동료에게 어디에 보이는지, 얼마나 쓰이는지 확인합니다.

라운지 화면​

사이드바 아래쪽 라운지를 누르면 라운지 화면이 열립니다. 제목은 "라운지", 부제는 "라운지에서 공지사항이나 질문, 활용 팁 등 Deep Agent Builder와 관련된 다양한 이야기를 확인해 보세요."입니다. 처음 열면 유즈케이스 게시판이 카드 형태로 보입니다.

라운지 첫 화면

번호메뉴기능이런 때 사용하세요
1라운지라운지 화면을 엽니다.공지나 다른 사람의 활용 사례를 보러 갈 때

화면 맨 위의 제목 "라운지"와 부제는 지금 라운지 화면에 있다는 것을 알려 줍니다. 제목과 부제 오른쪽에는 게시글 검색... 칸이 있습니다. 그 아래 왼쪽에는 게시판 목록이 유즈케이스, 사용 가이드, FAQ, 문의 및 오류, 기능 개선 제안, 커뮤니티, 공지사항 순서로 놓여 있고, 누르면 오른쪽 내용이 그 게시판으로 바뀝니다. 게시글 목록 위쪽에는 정렬 목록과 글쓰기 버튼이 있습니다.

게시글 검색... 칸은 지금 보고 있는 게시판만이 아니라 모든 게시판의 글을 한꺼번에 찾습니다. 낱말을 입력하면 잠시 뒤 칸 아래에 결과 목록이 펼쳐지고, 줄마다 글이 있는 게시판 이름과 제목이 보입니다. 제목이나 본문에 그 낱말이 들어간 글이 나오며, 제목에 들어간 글이 위쪽에 놓입니다. 결과를 누르면 그 게시판으로 옮겨 가 해당 글이 바로 열립니다. 맞는 글이 없으면 "검색 결과가 없습니다"가 보이고, Esc를 누르면 결과 목록이 닫힙니다.

정렬 목록에서는 최신순, 과거순, 추천순, 조회수순 중 하나를 고릅니다. 최신순은 최근에 쓴 글부터, 과거순은 오래된 글부터, 추천순은 추천을 많이 받은 글부터, 조회수순은 많이 읽힌 글부터 보여 줍니다. 어느 순서를 고르든 상단 고정 글은 맨 위에 남습니다. 정렬을 바꾸면 첫 페이지로 돌아가고, 다른 게시판으로 옮기면 다시 최신순으로 바뀝니다.

글쓰기​

게시판에서 글쓰기를 누르면 글쓰기 화면이 열립니다. 맨 위에 글이 올라갈 게시판 이름이 보이고, 그 아래 "게시글 제목을 입력하세요" 칸에 제목을 최대 200자까지 적습니다. 칸 오른쪽 아래에 "54/200"처럼 지금 글자 수가 보입니다. 본문 위 편집 도구 줄에는 되돌리기·다시 실행, 제목 크기(H1~H4), 굵게·기울임·밑줄·취소선·인라인 코드, 글자 색과 크기, 목록, 인용, 구분선, 표, 링크, YouTube 버튼과 함께, 첨부 권한이 있을 때 이미지(Image)와 파일 업로드(File Upload) 버튼이 있습니다. 다 쓰면 게시를 누르고, 그만두려면 취소를 누릅니다. 제목이나 본문이 비어 있으면 "제목과 내용을 모두 입력해 주세요"가 나옵니다.

그림은 커뮤니티 게시판의 글쓰기 화면입니다. 위쪽(제목과 설정)과 아래쪽(편집 도구와 버튼)을 나눠 보여 줍니다.

임시저장 복원​

글을 쓰는 동안 내용이 브라우저에 임시저장됩니다. 쓰다가 창을 닫았다가 같은 게시판에서 다시 글쓰기를 누르면 "임시저장 복원" 창이 열리고 "이전에 작성 중이던 임시저장이 있습니다. 복원하시겠습니까?"라고 묻습니다. 복원을 누르면 이어서 쓸 수 있고, 삭제를 누르면 빈 화면에서 새로 시작합니다.

닉네임 설정​

라운지에서는 실명 대신 닉네임이 표시됩니다. 닉네임을 정하지 않은 채 커뮤니티, 문의 및 오류, 기능 개선 제안 게시판에서 게시를 누르면 닉네임 설정 창이 먼저 열립니다. 창 위에는 "커뮤니티에서 사용할 닉네임을 설정하세요. 실명 대신 닉네임이 표시됩니다."라는 안내가 있습니다. 닉네임은 2자 이상 50자 이하이며 영문, 숫자, 한글, 하이픈(-), 언더스코어(_)만 쓸 수 있고, 규칙에 맞지 않으면 "올바르지 않은 닉네임 형식입니다"가 나옵니다. 입력하는 동안 "사용 가능 여부 확인 중..." 뒤에 "사용 가능한 닉네임입니다" 또는 "이미 사용 중인 닉네임입니다"가 나오니, 사용 가능한 닉네임을 정하고 저장을 누르면 "닉네임이 저장되었습니다" 알림과 함께 글이 이어서 게시됩니다. 취소를 누르면 창이 닫히고 글은 아직 올라가지 않습니다. 닉네임을 이미 정해 두었다면 창 없이 바로 게시되고 "게시글이 작성되었습니다" 알림이 뜹니다. 관리자 계정으로 쓴 글은 닉네임 대신 "관리자"로 표시됩니다.

게시글 읽기와 댓글​

목록에서 글을 누르면 상세 화면이 열립니다. 제목 오른쪽의 추천 버튼(엄지 모양)을 누르면 그 글에 추천이 더해지고 버튼 옆 숫자가 하나 늘어납니다. 추천한 글은 버튼이 강조색으로 바뀌며, 다시 누르면 추천이 취소됩니다. 추천 수는 목록의 추천 열과 추천순 정렬에 쓰입니다. 댓글과 그 답글에도 같은 엄지 버튼이 있어, 도움이 된 댓글에 추천을 더하거나 취소할 수 있습니다. 추천 권한이 없는 사용자에게는 추천 버튼이 보이지 않습니다.

에이전트를 사내에 공유하기​

내가 만든 에이전트는 처음에는 나만 씁니다. 동료도 쓰게 하려면 워크스페이스에 등록합니다. 등록한 에이전트는 동료가 대화만 할 수 있고, 설정은 원본을 가진 내가 바꿉니다. 워크스페이스 설정에 따라 등록 요청이 바로 게시되기도 하고, 관리자 심사를 거쳐 게시되기도 합니다.

공유는 두 곳에서 시작할 수 있습니다.

  • 에이전트 편집 화면 헤더의 워크스페이스 등록: 지금 고치고 있는 에이전트를 바로 등록할 때
  • 에이전트 템플릿 화면의 커뮤니티 에이전트 관리 > 배포 요청: 내 에이전트 여러 개를 한곳에서 골라 요청하고 배포 상태를 관리할 때

등록하기 전에 에이전트를 저장해 둡니다. 저장된 버전이 없으면 "등록할 수 있는 저장된 버전이 없습니다. 에이전트를 먼저 저장하세요.", 저장하지 않은 변경이 있으면 "저장되지 않은 변경이 있습니다. 에이전트를 먼저 저장한 뒤 등록하세요."가 나오고 요청할 수 없습니다.

워크스페이스 등록 창​

에이전트 편집 화면 헤더의 워크스페이스 등록 아이콘을 누르면 "워크스페이스에 에이전트 등록" 창이 열립니다. 설명은 "에이전트를 등록할 워크스페이스를 선택하세요. 워크스페이스별로 확인하고 각각 요청합니다."입니다.

워크스페이스에 에이전트 등록 창

번호메뉴기능이런 때 사용하세요
1워크스페이스 등록에이전트 편집 화면 헤더의 아이콘입니다. 마우스를 올리면 "이 에이전트를 워크스페이스에 등록합니다"가 보입니다. 권한이 없으면 "이 에이전트를 등록할 권한이 없습니다."가 나옵니다.이 에이전트를 동료와 나누려 할 때
2워크스페이스 목록등록할 수 있는 워크스페이스입니다. 이름 옆에 내 역할(예를 들어 "멤버")이 보이고, 체크 상자로 등록할 곳을 고릅니다. 이름을 누르면 오른쪽에 그 워크스페이스의 안내가 나옵니다. 그림은 AI혁신팀을 고른 모습입니다.공유할 공간을 고를 때
3상태 표시워크스페이스마다 미등록, 심사 대기, 게시됨, 반려됨 중 하나가 붙습니다.이미 게시했는지, 심사 중인지 확인할 때
4심사 안내고른 워크스페이스에 "등록 요청이 바로 게시됩니다." 또는 "관리자 심사 후 게시됩니다."가 나옵니다. 아래 게시 현황에는 "이 워크스페이스에는 아직 게시되지 않았습니다."처럼 지금 게시 상태가 보입니다.바로 게시되는지, 심사를 기다려야 하는지 알고 싶을 때

창 아래쪽에서 버전을 고르고 요청을 보냅니다.

등록할 버전과 등록 요청

번호메뉴기능이런 때 사용하세요
1등록할 버전등록할 저장 버전을 고릅니다. 지금 쓰는 버전에는 "(사용 중)"이 붙습니다.검토가 끝난 버전만 공유할 때
2N개 등록 요청고른 워크스페이스 수만큼 등록을 요청합니다. 예를 들어 하나를 골랐으면 "1개 등록 요청"입니다.고르기를 마쳤을 때

요청을 보내면 워크스페이스마다 결과가 표시됩니다. 바로 게시되는 워크스페이스는 "게시되었습니다", 심사가 필요한 워크스페이스는 "심사를 요청했습니다", 문제가 있으면 "실패했습니다"가 보이고, 목록 아래에 "성공 1개, 실패 0개, 건너뜀 0개"처럼 합계가 나옵니다. 김그루 사원이 고른 AI혁신팀 워크스페이스는 "관리자 심사 후 게시됩니다."로 안내된 곳이라 결과가 "심사를 요청했습니다"로 나왔습니다.

워크스페이스 등록 결과

번호메뉴기능이런 때 사용하세요
1결과 표시워크스페이스 이름 아래에 "심사를 요청했습니다" 또는 "게시되었습니다"가 나옵니다. 심사 대기 중이면 "대기 중인 요청이 있습니다. 먼저 대기 중인 요청을 취소하세요."도 함께 보이고, 같은 워크스페이스에 다시 요청할 수 없습니다.요청이 제대로 들어갔는지 확인할 때
2상태 표시결과에 맞춰 심사 대기 또는 게시됨으로 바뀝니다.다음에 창을 열었을 때 상태를 확인할 때
3요청 취소오른쪽 대기 중인 요청에 어떤 버전 기준으로 언제 요청했는지("내 에이전트 v1 기준으로 요청됨")가 보이고, 그 아래 버튼으로 요청을 거둡니다.요청을 거두고 고친 버전으로 다시 요청할 때
4결과 합계"성공 1개, 실패 0개, 건너뜀 0개"처럼 이번 요청의 결과를 셉니다.여러 워크스페이스에 한꺼번에 요청했을 때

심사가 필요한 워크스페이스에서는 관리자가 승인해야 동료에게 보입니다. 관리자가 승인하면 상태가 게시됨으로 바뀌고, 반려하면 반려됨으로 바뀝니다.

커뮤니티 에이전트 관리​

사이드바 위쪽 에이전트 템플릿을 누르고 오른쪽 위 커뮤니티 에이전트 관리를 누르면 관리 화면이 열립니다. 설명은 "내 에이전트를 사내에 배포하고 배포된 에이전트를 관리할 수 있습니다."입니다. 탭은 배포 에이전트 관리, 배포 요청, 내 요청 세 개이고, 오른쪽 위 닫기(X)로 에이전트 템플릿 화면에 돌아갑니다.

배포 요청 탭​

배포 요청 탭에는 배포할 수 있는 내 에이전트가 나옵니다. 줄마다 버튼이 하나씩 있는데, 바로 게시되는 워크스페이스에서는 자동 등록과 "등록 시 즉시 반영됩니다", 심사가 필요한 워크스페이스에서는 배포 요청과 "관리자 승인 후 반영됩니다"가 보입니다. 이 워크스페이스가 등록을 막아 두었으면 "이 워크스페이스는 등록이 비활성화되어 있습니다"가 보입니다.

그림은 김그루 사원의 배포 요청 탭입니다. 이미 심사를 요청한 이메일 초안 도우미 줄에는 심사중 표시와 요청 취소가 보이고, 번호는 회의록 요약 도우미 줄에 붙였습니다.

배포 요청 탭

번호메뉴기능이런 때 사용하세요
1배포 요청 탭배포할 수 있는 내 에이전트 목록을 엽니다. 옆의 배포 에이전트 관리, 내 요청 탭으로 오갈 수 있습니다.해야 할 일에 맞는 탭으로 갈 때
2에이전트 검색...이름으로 내 에이전트를 찾습니다.내 에이전트가 많을 때
3에이전트 이름에이전트 이름이고, 아래에 설명이 보입니다. 심사 중인 요청이 있으면 이름 옆에 상태 표시가, 오른쪽에 요청 취소가 보입니다.배포할 에이전트가 맞는지 설명까지 확인할 때
4배포 요청 또는 자동 등록요청 양식을 엽니다. 버튼 아래에는 "관리자 승인 후 반영됩니다" 또는 "등록 시 즉시 반영됩니다"가 보여 공개까지 시간이 걸리는지 알 수 있습니다.이 에이전트를 사내에 공개하려 할 때

버튼을 누르면 "커뮤니티 에이전트 배포 요청" 창이 열립니다. 창 제목 아래에는 이 워크스페이스에 맞춰 "관리자 승인 후 반영됩니다" 또는 "등록 시 즉시 반영됩니다"가 보이고, 그 아래에 다음 항목이 위에서부터 차례로 나옵니다.

  • 에이전트 이름과 설명: 서브에이전트가 붙은 에이전트는 이름 옆에 "서브에이전트 2개"처럼 개수가 붙습니다.
  • 배포 버전: 배포할 저장 버전을 고르는 칸입니다. 버전은 v1, v2처럼 보이고, 지금 쓰는 버전에는 "(사용 중)"이 붙습니다. 버전을 저장할 때 설명을 적어 두었다면 칸 아래에 그 설명이 보입니다.
  • 이 버전에 포함된 구성: 함께 배포되는 도구, 지식, 서브에이전트, 스킬, 미들웨어, 파일이 "도구 1개"처럼 묶음마다 개수와 이름으로 나옵니다. 비어 있는 묶음에는 "포함된 도구가 없습니다"처럼 표시됩니다. 파일이 있으면 "파일은 버전과 관계없이 현재 업로드된 파일이 배포됩니다"라는 안내가 붙고, 쓸 수 없는 항목이 섞여 있으면 "사용할 수 없는 리소스가 포함되어 있습니다"가 나옵니다. 아직 배포되지 않은 서브에이전트 줄에는 먼저 배포 요청 버튼이 붙습니다.

  • 맨 아래 취소와 요청 버튼: 요청 버튼은 심사가 필요한 워크스페이스에서는 배포 요청, 바로 게시되는 워크스페이스에서는 자동 등록입니다. 취소는 요청하지 않고 창을 닫습니다.

서브에이전트 줄의 먼저 배포 요청을 누르면 같은 창이 그 서브에이전트의 요청 양식으로 바뀌고, 위쪽에 뒤로가 생깁니다. 서브에이전트 요청을 마치거나 뒤로를 누르면 원래 에이전트의 양식으로 돌아옵니다.

그림은 회의록 요약 도우미 줄의 배포 요청을 눌러 연 창입니다. 이 에이전트는 도구, 지식, 서브에이전트, 스킬, 미들웨어가 모두 0개라 묶음마다 "포함된 … 없습니다"가 보이고, 파일에는 업로드해 둔 회의록 양식 파일 1개와 "파일은 버전과 관계없이 현재 업로드된 파일이 배포됩니다" 안내가 보입니다.

사례: 회의록 요약 도우미를 공유하고 소개 글 쓰기​

김그루 사원은 AI혁신팀 주간회의 때마다 쓰던 회의록 요약 도우미를 팀 전체가 쓰게 하려고 합니다. 11월 10일 회의에서 "커뮤니티 공유 실습"을 교육에 넣자는 의견도 나왔으니, 직접 공유하고 라운지에 소개 글을 남겨 보기로 했습니다.

준비물은 다음과 같습니다.

  • 에이전트: 회의록 요약 도우미(일반 에이전트, 저장된 버전이 하나 이상 있는 상태). 만드는 방법은 사례: 회의록 요약과 액션 아이템을 참고하세요.
  • 자료: 가상 자료 "브레인크루_AI혁신팀_주간회의록_1110.txt"(소개 글에 첨부)
  • 권한: 워크스페이스 등록 권한, 라운지 커뮤니티 게시판 글쓰기 권한

1단계: 워크스페이스에 등록하기​

  1. 사이드바에서 회의록 요약 도우미를 누르고 에이전트 설정을 누릅니다.
  2. 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 먼저 누릅니다.
  3. 헤더의 워크스페이스 등록 아이콘을 누릅니다.
  4. 워크스페이스 목록에서 AI혁신팀을 체크하고, 오른쪽 안내를 읽습니다. AI혁신팀은 "관리자 심사 후 게시됩니다."로 안내됩니다.
  5. 등록할 버전이 "v1 (사용 중)"인지 확인하고 1개 등록 요청을 누릅니다.
  6. AI혁신팀 아래에 "심사를 요청했습니다"가 나오고 상태가 심사 대기로 바뀝니다. 오른쪽 "대기 중인 요청"에 "내 에이전트 v1 기준으로 요청됨"과 요청 취소가 보이고, 아래에 "성공 1개, 실패 0개, 건너뜀 0개"가 나옵니다. 관리자가 승인하면 AI혁신팀 동료에게 공유됩니다. 바로 게시되는 워크스페이스였다면 "게시되었습니다"가 나오고 곧바로 공유됩니다.

2단계: 라운지 커뮤니티 게시판에 소개 글 쓰기​

  1. 사이드바 라운지를 누르고 게시판 목록에서 커뮤니티를 누릅니다.

  2. 글쓰기를 누릅니다.

  3. 제목에 다음을 적습니다.

    프롬프트: [공유] 회의록 요약 도우미 — 회의록을 붙여 넣으면 결정 사항과 담당·기한을 표로 정리해 줍니다

  4. 본문에 다음 내용을 적습니다.

    프롬프트: 안녕하세요, AI혁신팀 김그루입니다. 주간회의 회의록을 정리할 때 쓰던 회의록 요약 도우미를 워크스페이스에 공유했습니다. 에이전트 템플릿 화면에서 회의록 요약 도우미 카드를 누르고 대화하기를 누르면 바로 쓸 수 있습니다. 회의록 텍스트를 붙여 넣거나 첨부하면 결정 사항, 담당자, 기한을 표로 정리하고 다음 회의 안건을 제안합니다. 첨부한 파일은 가상 회의록 예시입니다. 써 보시고 개선할 점은 댓글로 알려 주세요.

  5. 편집 도구의 파일 업로드(File Upload)를 눌러 "브레인크루_AI혁신팀_주간회의록_1110.txt"를 붙입니다.

  6. 게시를 누릅니다. "게시글이 작성되었습니다" 알림이 뜨고 올린 글의 상세 화면이 열립니다. 닉네임을 정하지 않았다면 그 전에 닉네임 설정 창이 열리니, "그루_AI혁신팀"처럼 규칙에 맞는 닉네임을 정하고 저장합니다.

회의록 요약 도우미 소개 글

번호메뉴기능이런 때 사용하세요
1제목"[공유] 회의록 요약 도우미 — …"로 올라간 제목입니다.목록에서 소개 글을 찾을 때
2작성자정한 닉네임이 보입니다. 실명은 보이지 않습니다. 그림은 관리자 권한이 있는 계정으로 올린 글이라 "관리자"로 보입니다.닉네임이 제대로 저장됐는지 볼 때
3첨부 파일첨부한 회의록 예시 파일입니다. 소개 문장 끝에 파일 이름 링크로 보입니다.동료가 예시 파일을 내려받아 바로 시험할 때
4댓글 입력동료가 의견을 남기는 칸입니다.개선 의견을 모을 때

결과를 이렇게 확인하세요​

  • 에이전트 템플릿 화면에 회의록 요약 도우미 카드가 보이는지 확인합니다. 심사가 필요한 워크스페이스라면 승인된 뒤에 보입니다.
  • 커뮤니티 에이전트 관리 > 배포 에이전트 관리 탭에 회의록 요약 도우미가 배포 버전과 함께 보이는지 확인합니다.
  • 라운지 커뮤니티 게시판 목록 맨 위에 소개 글이 보이는지, 작성자가 닉네임(관리자 계정이면 "관리자")으로 보이는지 확인합니다.
  • 며칠 뒤 카드 상세의 사용량에서 실행 횟수와 사용자 수를 확인합니다.

팁: 소개 글이나 첨부 파일에 고객사 이름, 실제 연락처, 시크릿 값이 들어가지 않았는지 게시 전에 한 번 더 확인합니다. 개인정보가 섞일 수 있는 에이전트라면 공유 전에 미들웨어와 개인정보 보호의 개인정보 보호를 붙여 둡니다.
