에이전트 평가 개요

에이전트의 지침을 고친 뒤에는 답변이 정말 나아졌는지 같은 질문, 같은 기준으로 확인해야 합니다. 평가 화면은 미리 정해 둔 질문 묶음을 에이전트에게 똑같이 보내고, 정해 둔 기준(평가기)으로 답변을 채점해 결과를 모아 보여 줍니다. 이 페이지는 평가 화면의 네 탭이 하는 일과, 브레인크루 AI혁신팀 김그루 사원이 "이메일 초안 도우미"를 점검할 때 탭을 쓰는 순서를 설명합니다.

이 페이지에서 할 수 있는 일

  • 사이드바에서 평가 화면을 열고 데이터셋, 평가 실행, 평가기, 대시보드 탭이 각각 무엇을 다루는지 구분합니다.
  • 평가에 쓰는 말(데이터셋, 문항, 참조 답변, 평가기, 채점 모델, 정답률)의 뜻을 익힙니다.
  • 업무 메일 요청 10개로 이메일 초안 도우미를 점검하는 전체 순서를 미리 봅니다.

평가 메뉴 열기​

평가 화면은 사이드바 위쪽 더 보기를 누르면 나오는 메뉴에서 엽니다. 같은 메뉴에 유틸리티, 작업, SUPER AI 에이전트도 함께 있습니다.

더 보기 메뉴의 평가

번호메뉴기능이런 때 사용하세요
1더 보기사이드바의 추가 메뉴를 펼칩니다.평가, 작업처럼 자주 쓰지 않는 화면으로 갈 때
2평가평가 화면을 엽니다.이메일 초안 도우미의 지침을 고친 뒤 결과를 점검하러 갈 때

평가 화면을 볼 권한이 없으면 탭 대신 권한이 없다는 안내 화면이 나옵니다. 이때는 관리자에게 평가 화면을 쓸 수 있게 권한을 요청합니다.

평가 화면의 네 탭​

평가 화면 위쪽에는 화면 제목 "평가"와 "평가 데이터셋, 실행, 평가기를 관리합니다."라는 설명이 있고, 그 아래에 탭 네 개가 있습니다. 처음 열면 데이터셋 탭이 보입니다.

평가 화면

번호메뉴기능이런 때 사용하세요
1데이터셋평가에 쓸 질문과 참조 답변 묶음을 만들고 관리합니다. 그림에는 "이메일 초안 기본 10문항"이 하나 있습니다.메일 요청 10개를 한 번 정리해 두고 지침을 고칠 때마다 같은 질문으로 점검할 때
2평가 실행에이전트를 고르고 평가 시작으로 데이터셋을 실행합니다. 실행 목록과 실행 결과도 이 탭에서 봅니다.이메일 초안 도우미에게 10문항을 한 번에 풀게 할 때
3평가기답변을 채점하는 기준을 봅니다. 기본 평가기와 직접 만든 사용자 평가기가 나뉘어 있습니다.요청한 내용이 빠짐없이 들어갔는지(완전성) 볼지, 어조가 업무에 맞는지(전문성) 볼지 정할 때
4대시보드에이전트별 평가 결과를 모아 봅니다. 평가한 적이 없으면 "표시할 평가 데이터가 없습니다."라고 나옵니다.지침을 몇 번 고치는 동안 점수가 어떻게 바뀌었는지 볼 때

이럴 때 쓰세요: 영업팀에서 "이메일 초안 도우미가 회신 기한을 자꾸 빠뜨린다"는 말을 들으면, 김그루 사원은 바로 지침을 고치지 않고 평가 실행 탭에서 지금 지침 그대로 한 번 돌려 기준 점수부터 남깁니다. 지침을 고친 뒤 같은 데이터셋과 평가기로 다시 돌리고, 대시보드에서 점수가 올랐는지 확인한 다음에야 고친 버전을 동료들에게 알립니다.

네 탭이 다루는 일은 다음과 같습니다.

  • 데이터셋: 평가에 쓸 질문과 참조 답변 묶음을 만들고 관리합니다. 자세한 화면은 평가 데이터셋 만들기에 있습니다.
  • 평가 실행: 에이전트를 고르고 평가 시작으로 데이터셋을 실행합니다. 실행 목록과 실행 결과도 이 탭에서 봅니다. 자세한 화면은 평가 실행에 있습니다.
  • 평가기: 답변을 채점하는 기준을 봅니다. 기본 평가기와 직접 만든 사용자 평가기가 나뉘어 있습니다. 자세한 화면은 평가기 구성에 있습니다.
  • 대시보드: 에이전트별 평가 결과를 모아 봅니다. 평가한 적이 없으면 "표시할 평가 데이터가 없습니다."라고 나옵니다. 자세한 화면은 에이전트 평가 요약에 있습니다.

평가에 쓰는 말​

평가 화면에는 처음 보는 말이 몇 개 나옵니다. 아래 표는 화면 표기와 그 뜻, 이메일 초안 도우미 점검에서의 예입니다.

화면 표기뜻이메일 초안 점검에서의 예
데이터셋평가에 쓰는 질문 묶음입니다. 이름과 설명을 붙여 저장합니다."이메일 초안 기본 10문항"
문항데이터셋 안의 질문 하나입니다. 질문과 참조 답변이 한 쌍입니다."영업1팀 최하늘 책임에게 AI 회의록 솔루션 데모 일정이 11월 18일(수) 오후 2시로 확정됐다고 알리는 메일을 써 줘. 장소는 본사 3층 회의실 B야."
참조 답변에이전트 답변과 비교할 기대 답변입니다. 메일처럼 정답 문장이 하나로 정해지지 않으면 꼭 들어가야 할 내용을 번호로 적습니다."① 데모 일정 확정 안내 ② 일시 11월 18일(수) 오후 2시 ③ 장소 본사 3층 회의실 B ④ 최하늘 책임에 맞는 존칭과 정중한 맺음말"
평가기답변을 채점하는 기준과 채점 프롬프트입니다. 통과/실패로 채점하는 것과 점수로 채점하는 것이 있습니다.완전성 (Completeness): 참조 답변의 주요 내용이 모두 들어갔는지
채점 모델평가기 프롬프트를 받아 실제로 채점하는 모델입니다. 평가를 시작할 때 고르고, 고르지 않으면 사용자 기본값을 씁니다.내 모델 목록 가운데 API 키가 등록되어 "사용 가능"으로 표시된 모델
평가 실행데이터셋, 평가기, 채점 모델을 묶어 에이전트를 한 번 평가한 기록입니다. "#번호 · 에이전트 이름"으로 구분합니다."#1 · 이메일 초안 도우미"
전체 정답률통과한 문항 수를 전체 문항 수로 나눈 값입니다. 오류나 시간 초과로 끝난 문항도 오답으로 셉니다.첫 실행의 "90.0% (9/10)"

따라 해 보기​

김그루 사원이 이메일 초안 도우미를 처음 점검합니다. 처음 한 번은 아래 순서로 준비하고, 다음부터는 5~7단계만 반복합니다.

  1. 사이드바 위쪽 더 보기를 누르고 평가를 고릅니다.
  2. 데이터셋 탭에서 메일 요청 10개를 담은 데이터셋 "이메일 초안 기본 10문항"을 CSV 파일로 만듭니다. 방법은 평가 데이터셋 만들기에 있습니다.
  3. 데이터셋을 열어 문항마다 질문과 참조 답변이 맞게 들어갔는지 확인하고 필요하면 고칩니다. 방법은 평가 문항 설계에 있습니다.
  4. 평가기 탭에서 평가기마다 무엇을 보는지 확인하고 이번 점검에 쓸 평가기를 정합니다. 요청에 나온 날짜, 장소, 기한이 메일에 빠짐없이 들어갔는지가 중요하므로 **완전성 (Completeness)**을 씁니다. 방법은 평가기 구성에 있습니다.
  5. 평가 실행 탭에서 이메일 초안 도우미를 고르고 평가 시작을 누릅니다. 열린 창에서 데이터셋과 평가기를 고르고 실행 시작을 누릅니다. 방법은 평가 실행에 있습니다.
  6. 실행이 끝나면 실패한 문항의 채점 사유를 읽습니다. 방법은 평가 결과 읽기와 비교에 있습니다.
  7. 지침을 고친 뒤 같은 데이터셋과 평가기로 다시 실행해 전후를 비교합니다. 방법은 회귀 평가와 개선에 있습니다.

팁: 데이터셋은 한 번 만들어 두고 계속 씁니다. 지침을 고칠 때마다 질문까지 바꾸면 이전 결과와 비교할 수 없습니다.
