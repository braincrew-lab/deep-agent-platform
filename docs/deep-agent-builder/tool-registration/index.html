Deep Agent Builder 도구 등록 화면

에셋 화면 도구 탭의 도구 추가는 외부 서비스와 사내 시스템을 에이전트가 부를 수 있는 도구로 등록하는 곳입니다. 이 페이지는 도구 추가 메뉴에 나올 수 있는 여섯 종류(Dify MCP Server, n8n MCP Server, Connect MCP Server, HTTP 요청 Server, MCP Remote, Zapier MCP Server)의 입력 항목과 기본값, 등록 뒤 상세 화면에서 할 일을 정리합니다. 도구를 에이전트에 붙이고 시험하는 손동작은 실습 3: 도구와 스킬 붙이기, 도구 테스트와 기본값 설정 창은 도구와 스킬 구성에 있습니다.

이 페이지에서 할 수 있는 일

  • 내 계정의 도구 추가 메뉴에 어떤 종류가 보이는지, 왜 계정마다 다른지 압니다.
  • 종류별 새 도구 추가 창의 입력 항목과 규칙을 확인합니다.
  • 토큰을 직접 넣지 않고 환경변수(시크릿)로 연결합니다.
  • 등록한 도구를 상세 화면에서 테스트하고 기본값을 정합니다.

도구 추가 메뉴​

사이드바 에셋설정을 누르고 도구 탭 오른쪽 위 도구 추가를 누르면 등록할 종류를 고르는 메뉴가 열립니다.

도구 추가 메뉴

번호메뉴기능이런 때 사용하세요
1도구 추가등록할 도구 종류 메뉴를 엽니다. 내 권한으로 만들 수 있는 종류가 하나도 없으면 흐리게 보입니다.새 도구를 등록할 때
2Dify MCP Server"Dify 워크플로우를 MCP로 연결"합니다.Dify에서 만든 워크플로우를 도구로 쓸 때
3n8n MCP Server"n8n 워크플로우를 MCP로 연결"합니다.n8n 자동화 흐름을 에이전트가 실행하게 할 때
4Connect MCP Server"Connect MCP 서버 연결" — Deep Connector가 발급한 MCP 토큰으로 사내 지식 컬렉션을 연결합니다.사내 규정·제품 자료를 근거로 답하게 할 때

메뉴 항목은 권한에 따라 달라집니다. 그림은 일반 직원인 김그루 사원의 메뉴입니다.

종류메뉴에 보이는 조건하는 일
Connect MCP Server항상 보입니다.Deep Connector MCP 서버를 주소와 토큰으로 연결합니다.
Dify MCP Server도구 생성 권한과 Dify 도구 생성 권한이 있을 때Dify 워크플로우의 MCP 주소를 연결합니다.
n8n MCP Server도구 생성 권한과 n8n 도구 생성 권한이 있을 때n8n 워크플로우의 MCP 주소를 인증 토큰과 함께 연결합니다.
HTTP 요청 Server관리자 화면 접근 권한과 HTTP 도구 생성 권한이 있을 때REST API를 직접 호출하는 도구를 만듭니다.
MCP Remote관리자 화면 접근 권한과 MCP Remote 생성 권한이 있을 때원격 MCP HTTP 서버를 주소·헤더로 연결합니다.
Zapier MCP Server관리자 화면 접근 권한과 Zapier 도구 생성 권한이 있을 때Zapier의 Connect URL을 연결합니다.

메뉴에 필요한 종류가 없으면 워크스페이스 관리자에게 권한을 요청하거나, 관리자가 등록해 워크스페이스에 올린 도구를 유틸리티에서 설치합니다.

이럴 때 쓰세요: 김그루 사원은 영업팀이 n8n에 만들어 둔 "주간 판매 집계 후 팀 메신저 발송" 흐름을 주간 보고 에이전트에서 부르고 싶습니다. 메뉴에 n8n MCP Server가 보이면 직접 등록하고, 보이지 않으면 관리자에게 권한을 요청합니다.

모든 종류에 공통인 항목​

어떤 종류를 고르든 새 도구 추가 창("새 도구 설정을 생성합니다. 도구 유형에 따라 필요한 필드를 입력하세요.") 위쪽에 고른 종류가 표시되고, 다음 항목이 먼저 나옵니다.

항목필수규칙과 기본값예시
도구 이름필수영문 소문자로 시작, 소문자·숫자·밑줄(_)만. 만든 뒤 바꿀 수 없습니다.braincrew_sales_docs
표시 이름선택목록·상세에 보일 이름. 한글·공백 가능, 비우면 도구 이름이 보입니다.영업 자료 검색
설명Dify·n8n은 필수, Connect MCP는 선택에이전트가 이 도구를 언제 쓸지 판단하는 근거입니다. 무엇을 찾거나 실행하는지 구체적으로 적습니다.브레인크루 영업 자료 컬렉션에서 고객 제안에 쓸 근거 문서를 찾습니다.
연결 테스트—입력한 주소와 인증으로 연결해 성공·실패와 걸린 시간을 보여 줍니다. 제한 시간은 10초입니다.—
생성—도구를 등록합니다. 등록한 도구는 도구 탭 목록에 "사용자 등록" 표시와 함께 나타납니다.—

Connect MCP Server​

Connect MCP Server 등록 창

번호메뉴기능이런 때 사용하세요
1도구 이름도구의 고유 이름입니다. 만든 뒤 바꿀 수 없습니다.용도가 드러나는 영문 이름을 정할 때
2URLConnect MCP 서버 주소입니다. 회사가 정해 둔 주소가 미리 채워져 있습니다(그림에서는 흐리게 가렸습니다).다른 Connect 서버를 쓸 때만 바꿉니다
3TokenDeep Connector에서 발급한 MCP 토큰 값입니다. 토큰 값만 넣고 인증 방식 이름을 앞에 붙이지 않습니다. 51자보다 짧으면 "Token must be at least 51 characters"가 나옵니다.Deep Connector에서 토큰을 발급받은 뒤
4연결 테스트주소와 토큰으로 연결해 봅니다.생성 전에 토큰이 맞는지 확인할 때

토큰은 Deep Connector의 MCP 토큰 화면에서 컬렉션과 권한(읽기 등)을 골라 발급합니다. 토큰에 포함된 컬렉션만 검색되므로, 에이전트가 찾아야 할 컬렉션이 토큰에 들어 있는지 확인합니다. 등록한 도구의 서브 도구(search_documents, read_document, list_collections 등 17개)는 도구 상세와 에이전트의 도구 설정 창에서 볼 수 있습니다.

이럴 때 쓰세요: 사내 규정 Q&A 비서처럼 근거 문서를 인용해야 하는 에이전트를 만들 때, 김그루 사원은 Deep Connector에서 '사내 규정' 컬렉션 읽기 토큰을 발급받아 Connect MCP Server로 등록하고 에이전트 도구함에 붙입니다.

n8n MCP Server​

n8n MCP Server 등록 창

번호메뉴기능이런 때 사용하세요
1URLn8n MCP 서버 주소입니다. 화면의 예시처럼 n8n 서버 주소 뒤에 /mcp/ 경로가 붙은 형식입니다.n8n 워크플로우의 MCP 트리거 주소를 받았을 때
2환경변수로 추가 / 직접 입력인증 토큰을 넣는 방식을 바꿉니다. 처음에는 토큰을 직접 넣는 칸이고, 환경변수로 추가를 누르면 환경변수 이름 칸으로 바뀌며 버튼 이름이 직접 입력이 됩니다(그림은 바꾼 뒤 모습).토큰을 화면에 남기지 않고 시크릿으로 관리할 때
3인증 토큰직접 입력이면 토큰 값(예시 "n8n-auth-token-..."), 환경변수면 시크릿 이름(기본 예시 N8N_MCP_API_KEY)을 적습니다. "서버에서 자동으로 값을 불러옵니다."개인 시크릿에 같은 이름으로 토큰을 저장해 둔 뒤
4생성도구를 등록합니다.연결 테스트가 성공한 뒤

환경변수 방식을 쓰려면 에셋 화면 시크릿 탭에 같은 이름의 시크릿을 먼저 등록합니다. 등록하지 않으면 도구 상세의 필수 환경변수에 "미등록"이 보이고, 그 자리의 등록으로 바로 만들 수 있습니다. 시크릿은 시크릿과 권한에서 설명합니다.

Dify MCP Server​

Dify MCP Server 창은 공통 항목 아래 URL 하나만 받습니다. URL은 반드시 /mcp로 끝나야 하며(Dify 앱의 MCP 서버 주소 끝부분), 그렇지 않으면 "URL은 /mcp로 끝나야 합니다" 안내가 나오고 만들 수 없습니다. 별도 인증 칸이 없으므로 Dify에서 받은 MCP 주소를 다른 사람과 공유하지 않습니다. 설명은 필수입니다.

관리자 권한이 필요한 종류​

아래 세 종류는 관리자 화면 접근 권한이 있는 계정의 메뉴에만 보입니다. 이 환경의 일반 직원 계정에는 보이지 않아 화면 그림은 싣지 않았고, 입력 항목은 화면 문구 기준으로 정리했습니다.

종류입력 항목기본값과 규칙
HTTP 요청 Server엔드포인트 URL, HTTP 메서드, 파라미터(이름, 타입, 위치, 모드, 설명, 기본값), 인증, 테스트 파라미터 값메서드 기본값 GET(GET, POST, PUT, DELETE, PATCH). 파라미터 위치는 Query, Header, Body(Body는 POST·PUT·PATCH만). 모드는 선택적, 필수, 고정값이며 고정값은 직접 입력하거나 환경변수(시크릿)를 고릅니다. 인증 기본값은 인증 없음(그 밖에 토큰 인증, API 키 — 키 이름·키 값·위치 Query/Header, 커스텀 헤더).
MCP RemoteURL, 헤더(JSON), 환경 변수(key: value), JSON 가져오기헤더 기본값은 빈 JSON. JSON 가져오기는 다른 프로그램의 mcpServers 설정 JSON을 붙여 넣어 채우며, 서버는 한 번에 하나만 가져옵니다.
Zapier MCP ServerURLZapier의 Connect URL을 넣습니다. URL에 토큰이 들어 있으니 다른 사람과 공유하지 않습니다.

이럴 때 쓰세요: 경영지원팀이 사내 예약 시스템 API로 회의실 예약을 조회하게 하고 싶다면, 관리자가 HTTP 요청 Server로 GET 도구를 만들고 API 키를 시크릿 참조로 연결한 뒤 워크스페이스에 등록합니다. 직원은 유틸리티에서 설치해 씁니다.

등록한 뒤 상세 화면에서 할 일​

도구 탭 목록에서 도구를 누르면 오른쪽에 상세가 열립니다. 위쪽 버튼으로 다음을 합니다.

버튼하는 일자세한 설명
테스트"도구 테스트" 창에서 서브 도구를 골라 직접 호출합니다. 타임아웃 기본 10초(1~60초), MCP 도구의 Arguments 기본값은 빈 JSON입니다.도구와 스킬 구성
기본값 설정이 도구를 쓰는 내 에이전트 전체에 적용할 파라미터 기본값을 정합니다. 처음에는 모두 "기본값 해제 (상속)"입니다.도구와 스킬 구성
수정HTTP 도구는 전체 설정을, 그 밖의 도구는 표시 이름과 설명을 고칩니다.—
삭제도구를 지웁니다. 에이전트가 쓰는 중이면 "그래도 제거" 확인이 한 번 더 나옵니다.—

도구에 새 버전이 나오면 상세 위쪽에 동기화가 보입니다. 누르면 서브 도구 목록과 파라미터가 최신으로 바뀝니다.
