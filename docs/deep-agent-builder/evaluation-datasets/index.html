평가 데이터셋 만들기

평가 데이터셋은 에이전트에게 똑같이 물어볼 질문과, 그 질문의 기대 답변(참조 답변)을 묶어 둔 것입니다. 이 페이지는 이메일 초안 도우미 점검용 데이터셋 "이메일 초안 기본 10문항"을 CSV 파일로 만드는 과정을 화면 순서대로 설명합니다. 만든 데이터셋 안의 문항을 하나씩 다듬는 방법은 평가 문항 설계에서 이어서 설명합니다.

이 페이지에서 할 수 있는 일

  • 데이터셋 목록에서 데이터셋을 찾고, 새로 만들거나 엽니다.
  • 작성 가이드로 질문과 참조 답변을 적는 규칙을 확인합니다.
  • question, answer 열이 있는 CSV 파일을 올려 미리보기로 확인한 뒤 데이터셋을 만듭니다.
  • CSV가 거절됐을 때 안내를 보고 파일을 고치거나 파일 없이 만들기로 빈 데이터셋을 만듭니다.
  • 데이터셋의 평가 설정을 정하고, 필요 없어진 데이터셋을 지웁니다.

데이터셋 목록​

평가 화면을 열면 데이터셋 탭이 먼저 보입니다. 내가 볼 수 있는 데이터셋이 이름, 설명, 문항 수, 생성일과 함께 나열됩니다. 데이터셋이 하나도 없으면 "사용 가능한 데이터셋이 없습니다."와 데이터셋 만들기 버튼이 대신 보입니다. 목록은 한 쪽에 20개씩 나오고, 그보다 많으면 아래쪽에 총 개수와 쪽 이동 버튼이 생깁니다.

목록 위에는 "데이터셋 이름 또는 설명 검색" 칸과 데이터 새로고침(둥근 화살표), 작성 가이드, 데이터셋 생성 버튼이 있습니다. 데이터 새로고침은 다른 탭에서 방금 만든 데이터셋이 아직 보이지 않을 때 목록을 다시 불러옵니다. 데이터셋 행을 누르면 그 데이터셋의 문항 화면이 열립니다.

데이터셋 목록

번호메뉴기능이런 때 사용하세요
1검색란"데이터셋 이름 또는 설명 검색" 자리에 낱말을 넣으면 이름이나 설명에 그 낱말이 든 데이터셋만 남습니다.데이터셋이 늘어나 "이메일"이 들어간 것만 보고 싶을 때
2작성 가이드질문, 답변, 근거를 어떻게 적어야 하는지 정리한 안내 창을 엽니다.CSV를 처음 만들기 전에 작성 규칙을 확인할 때
3데이터셋 생성새 데이터셋을 만드는 창을 엽니다.이메일 초안 점검용 질문 묶음을 새로 만들 때
4데이터셋 행누르면 그 데이터셋의 문항 화면이 열립니다. 문항 열은 들어 있는 문항 수입니다."이메일 초안 기본 10문항"에 10문항이 모두 들어갔는지 확인할 때

작성 가이드​

작성 가이드를 누르면 오른쪽에 "평가 데이터셋 작성 가이드" 창이 열립니다. 질문과 답변을 일정한 규칙으로 적어야 실행끼리 점수를 비교할 수 있으므로, 데이터셋을 처음 만들 때 한 번은 읽어 둡니다.

작성 가이드

번호메뉴기능이런 때 사용하세요
1한 장 요약열마다 작성 방법과 영향받는 지표를 표로 보여 줍니다. 아래로 내리면 근거 적는 법, 답할 수 없는 문항, 재질의 열, "근거 미확정"이 나오는 이유, 올리기 전 체크리스트가 이어집니다.질문과 답변을 어떻게 적어야 하는지 헷갈릴 때
2닫기안내 창을 닫습니다.다 읽고 목록으로 돌아갈 때

작성 가이드의 근거문서, 청크, 답변가능 열은 지식(Deep Connector 컬렉션)을 찾아 답하는 에이전트를 평가할 때 쓰는 열입니다. 이메일 초안 도우미처럼 문서를 찾지 않는 에이전트는 질문과 답변 두 열만 있으면 됩니다. 이 두 열에 해당하는 규칙은 다음과 같습니다.

  • 질문은 실제 사용자가 에이전트에게 말하는 말투로 쓰고, 답이 하나로 정해지게 합니다. 메일 요청이라면 받는 사람, 날짜, 장소, 기한처럼 메일에 들어가야 할 사실을 질문 안에 적어 둡니다.
  • 답변에는 확인할 수 있는 사실을 간결하게 적습니다. 답이 길면 핵심 내용을 ①, ②처럼 번호로 나눕니다. 메일 전문을 적지 말고 꼭 들어가야 할 내용만 적습니다.

데이터셋 생성 창​

데이터셋 생성을 누르면 창이 열립니다. 이름은 꼭 입력해야 하고, 시작 방법(CSV 파일, 질문만, 컬렉션 문서에서, 싫어요에서)에 따라 아래쪽 입력 칸이 바뀝니다. 창이 길어서 위쪽과 아래쪽을 나눠 보여 줍니다. 그림은 CSV 파일을 고른 직후의 모습입니다.

데이터셋 생성 창 위쪽

번호메뉴기능이런 때 사용하세요
1이름데이터셋 이름을 255자 이내로 입력합니다. 꼭 입력해야 합니다."이메일 초안 기본 10문항"처럼 대상과 문항 수가 드러나게 이름 붙일 때
2설명데이터셋의 용도를 적습니다. 목록의 설명 열에 나옵니다.어느 에이전트를 무슨 목적으로 점검하는지 남길 때
3CSV 파일질문, 참조 답변(과 근거) 열이 있는 파일을 올려 만듭니다. 파일을 올리지 않으면 빈 데이터셋이 됩니다. 처음 열면 이 방법이 골라져 있습니다.메일 요청과 기대 내용을 표로 미리 정리해 두었을 때
4파일CSV 파일을 끌어 놓거나 눌러서 고릅니다. 최대 5MB입니다. 고른 뒤에는 파일 이름과 크기가 보이고, 오른쪽 X 버튼(선택한 파일 제거)으로 뺄 수 있습니다.정리한 질문 CSV를 올릴 때

이럴 때 쓰세요: 김그루 사원은 데이터셋에 넣을 질문을 머릿속으로 지어내지 않고, 지난 한 달 동안 영업팀 동료들이 이메일 초안 도우미에게 실제로 보낸 요청 가운데 자주 나오는 유형을 골라 CSV로 옮깁니다. 실제 거래처 이름과 담당자 연락처는 가나다물산, 라마바유통 같은 가상 값으로 바꿔 적고, 설명 칸에는 어느 기간의 요청을 바탕으로 했는지 남겨 둡니다. 이 데이터셋은 지침을 고칠 때마다 그대로 다시 쓰므로 처음 만들 때 공을 들이는 편이 낫습니다.

나머지 시작 방법은 다음과 같습니다.

  • 질문만: 질문만 붙여 넣거나 질문 열 하나짜리 CSV를 올립니다. 만든 뒤 에이전트로 참조 답변과 근거 초안을 채웁니다. 질문 목록은 있는데 참조 답변은 아직 없을 때 씁니다.
  • 컬렉션 문서에서: 질문이 없을 때 에이전트가 읽을 수 있는 문서에서 질문, 답변, 근거 초안을 만듭니다.
  • 싫어요에서: 포털에서 싫어요를 받은 실제 질문으로 만듭니다. 민감 실행 조회 권한이 있어야 합니다.

창을 아래로 내리면 미리보기와 버튼이 나옵니다.

데이터셋 생성 창 아래쪽

번호메뉴기능이런 때 사용하세요
1미리보기올린 파일의 앞 다섯 행을 표로 보여 줍니다. 나머지 행 수는 표 아래에 "그 외 5행이 더 있습니다."처럼 나옵니다.열이 제대로 나뉘었는지, 한글이 깨지지 않았는지 확인할 때
2취소만들지 않고 창을 닫습니다.파일을 잘못 골라 처음부터 다시 할 때
3생성데이터셋을 만듭니다. 이름이 비어 있으면 누를 수 없습니다.미리보기까지 확인을 마쳤을 때

질문만, 컬렉션 문서에서, 싫어요에서로 만들면 빈 데이터셋이 만들어진 뒤 곧바로 데이터셋 화면이 열리고 초안 만들기 창이 이어집니다. 이 세 방법은 에이전트의 지식 도구로 참조 답변과 근거를 찾기 때문에 지식이 연결된 에이전트에서 씁니다. CSV 파일로 만든 데이터셋은 목록에 그대로 추가됩니다.

CSV 파일 규칙​

항목규칙
확장자.csv
크기최대 5MB
행 수첫 줄(열 이름)을 빼고 최대 1,000행
꼭 있어야 하는 열question, answer (대소문자는 가리지 않습니다)
글자 인코딩UTF-8, 또는 엑셀에서 기본으로 저장되는 한글 인코딩(CP949)
선택 열doc_type, evidence_doc_1, evidence_chunk_1_1, evidence_chunk_1_2, evidence_doc_2, evidence_chunk_2_1, evidence_desc_3, note, answerable, expected_reask, expected_missing, clarification_reply처럼 근거와 재질의 평가 열을 더 둘 수 있습니다. evidence_doc, evidence_chunk, evidence_desc 열의 숫자는 근거 문서 번호(와 그 문서 안의 청크 순번)이므로, 근거 문서가 더 있으면 번호를 늘려 evidence_doc_3, evidence_chunk_3_1로 적습니다. expected_reask, expected_missing, clarification_reply는 재질의 평가 열입니다.

규칙에 맞지 않는 파일을 고르면 파일 칸 아래에 빨간 안내 상자가 뜨고 파일은 선택되지 않습니다.

경우안내 상자 첫 줄
.csv가 아닌 파일"CSV 파일만 지원됩니다."
5MB를 넘는 파일"파일이 최대 업로드 크기를 초과했습니다."
question, answer 열이 없는 파일"CSV 헤더에 question, answer 열이 있어야 합니다."
1,000행을 넘는 파일"CSV는 최대 1000행까지 업로드할 수 있습니다."

열 이름을 "질문", "답변"처럼 한글로 적은 파일도 question, answer 열이 없다고 거절됩니다. 첫 줄의 열 이름은 영문 question, answer로 적습니다. 그림은 열 이름을 한글로 적은 CSV를 골랐다가 거절된 모습입니다.

CSV가 거절된 데이터셋 생성 창

번호메뉴기능이런 때 사용하세요
1파일거절된 CSV가 빠지고 빈 칸으로 돌아왔습니다. 눌러서 다른 파일을 고릅니다.열 이름을 고친 CSV를 다시 올릴 때
2거절 사유거절된 이유입니다. 그 아래에 "이 파일은 사용할 수 없습니다. 다른 파일을 선택하거나, 파일 없이 빈 데이터셋을 만들 수 있습니다."가 이어집니다.무엇을 고쳐야 하는지 확인할 때
3파일 없이 만들기안내 상자를 닫고 파일 없이 만들 준비를 합니다. 이어서 생성을 누르면 빈 데이터셋이 만들어집니다.데이터셋 이름부터 만들어 두고 문항은 화면에서 직접 넣을 때

안내 상자가 떠 있는 동안에는 생성을 누를 수 없습니다. 거절된 파일이 모르는 사이에 빈 데이터셋으로 바뀌지 않도록, 다른 파일을 고르거나 파일 없이 만들기를 눌러야 다시 누를 수 있습니다.

따라 해 보기​

김그루 사원이 이메일 초안 도우미 점검용으로 업무 메일 요청 10개를 CSV로 올립니다.

  1. 엑셀이나 메모장에서 아래처럼 question, answer 두 열로 메일 요청을 정리하고 CSV로 저장합니다. 파일 이름은 "브레인크루_이메일초안_평가데이터셋.csv"로 합니다. 아래 표는 10행 가운데 앞의 세 행입니다.

    questionanswer
    영업1팀 최하늘 책임에게 AI 회의록 솔루션 데모 일정이 11월 18일(수) 오후 2시로 확정됐다고 알리는 메일을 써 줘. 장소는 본사 3층 회의실 B야.① 데모 일정 확정 안내 ② 일시 11월 18일(수) 오후 2시 ③ 장소 본사 3층 회의실 B ④ 최하늘 책임에 맞는 존칭과 정중한 맺음말
    한빛데이터 담당자에게 데이터 분석 구독 계약서 초안을 보내면서 검토 의견을 11월 20일(금)까지 회신해 달라고 요청하는 메일을 써 줘.① 데이터 분석 구독 계약서 초안 송부(첨부) 안내 ② 검토 의견 회신 요청 ③ 회신 기한 11월 20일(금) ④ 정중한 요청 어조
    고객사에 연말 휴무를 안내하는 메일을 써 줘. 12월 31일부터 1월 3일까지 쉬고, 1월 4일(월)부터 정상 업무를 해. 휴무 중 급한 문의는 영업1팀 최하늘 책임에게 하면 돼.① 휴무 기간 12월 31일~1월 3일 ② 업무 재개일 1월 4일(월) ③ 휴무 중 긴급 문의처 영업1팀 최하늘 책임 ④ 연말 인사

    나머지 일곱 행은 이메일 초안 도우미가 평소 자주 받는 메일 요청으로 직접 채웁니다. 위 세 행처럼 question에는 받는 사람, 용건, 날짜·장소·기한 같은 구체적인 값을 넣은 요청 문장을 적고, answer에는 메일에 꼭 들어가야 할 내용을 ①~④처럼 번호를 붙여 적습니다. 첫 줄의 열 이름을 빼고 모두 10행이 되어야 합니다.

  2. 평가 화면의 데이터셋 탭에서 데이터셋 생성을 누릅니다.

  3. 이름에 "이메일 초안 기본 10문항", 설명에 "이메일 초안 도우미 정기 점검용 업무 메일 요청"을 입력합니다.

  4. 시작 방법은 CSV 파일 그대로 두고, 파일 칸을 눌러 1단계의 CSV를 고릅니다.

  5. 미리보기에서 question, answer 열이 나뉘어 보이는지, 표 아래 "그 외 5행이 더 있습니다."로 모두 10행인지 확인합니다.

  6. 생성을 누릅니다. "데이터셋을 만들었습니다." 안내가 뜨고, 목록에 "이메일 초안 기본 10문항"이 문항 10으로 나타납니다.

팁: 질문이나 답변 안에 쉼표가 들어가면 그 칸 전체를 큰따옴표로 감싸야 열이 밀리지 않습니다. 엑셀에서 CSV로 저장하면 자동으로 감싸 줍니다. 미리보기에서 열이 밀려 보이면 생성하지 말고 파일을 다시 저장해 올립니다.

데이터셋 평가 설정​

데이터셋 행을 누르면 데이터셋 화면이 열립니다. 문항 표 위에 평가 설정 줄이 있고, 누르면 이 데이터셋으로 채점할 때 함께 쓰는 설정이 펼쳐집니다. 설정 대부분은 지식을 찾아 답하는 에이전트의 근거 지표에 쓰입니다.

데이터셋 평가 설정

번호메뉴기능이런 때 사용하세요
1평가 설정설정을 펼치거나 접습니다. 접혀 있을 때도 옆에 지금 설정(예를 들어 "없음 · 자동")이 보입니다.이 데이터셋의 채점 기준을 확인할 때
2주 지표실행을 서로 비교할 때 기준이 되는 지표를 고릅니다. 기본값은 정하지 않음이고, 화면 안내대로 실행 전에 정해 둡니다.전체 정답 비율을 기준으로 지침 수정 전후를 비교하기로 정했을 때(전체 정답)
3도구 호출 단가 (USD)통합 비용 계산에 쓰는 도구 호출 1회 단가입니다. 비우면 0.001입니다.도구 호출 비용까지 넣어 실행 비용을 비교할 때
4설정 저장바꾼 설정을 저장합니다. 바꾼 내용이 없으면 "변경한 내용이 없습니다."가 보이고 누를 수 없습니다. 진행 중인 평가 실행이 있으면 바꿀 수 없습니다.주 지표를 정한 뒤 저장할 때

이럴 때 쓰세요: 김그루 사원은 팀장에게 "지침을 고친 뒤 메일 품질이 나아졌다"고 보고하기 전에, 무엇을 기준으로 나아졌다고 말할지부터 주 지표로 정해 둡니다. 이메일 초안 도우미는 전체 정답을 고르고 설정 저장을 누른 뒤 첫 실행을 돌리므로, 이후 실행을 모두 같은 기준으로 견줄 수 있습니다. 주간 보고에는 이 지표의 수정 전후 값만 옮겨 적으면 됩니다.

윗줄의 나머지 설정은 지식을 찾아 답하는 에이전트의 근거 지표에 쓰입니다.

  • 문서 버전: 없음 또는 기간별 버전을 고릅니다. 없음이면 근거 추출과 원인 분석에서 문서 버전을 구분하지 않습니다. 같은 문서의 여러 판이 지식에 함께 들어 있을 때 기간별 버전을 고릅니다.
  • 버전 표시 패턴: 질문과 근거설명에서 버전 표기를 찾는 규칙입니다. 기간별 버전일 때만 쓰며, 비우면 연·월 날짜(예를 들어 2024.03, 2024-03)를 찾습니다.
  • 언어: 근거 추출에 쓰는 언어를 자동, 한국어, 영어 중에서 고릅니다. 자동이면 질문에 한글이 있을 때 한국어를 씁니다.
  • 과제 성공 판정 평가기: 모든 실행의 과제 성공을 한 평가기로 판정하게 고정합니다. 기본값은 실행마다 고른 평가기이고, 통과/실패형 평가기만 고를 수 있습니다.

이메일 초안 도우미처럼 지식을 찾지 않는 에이전트는 위 네 가지를 그대로 두고, 지침 수정 전후를 무엇으로 비교할지 주 지표(예를 들어 전체 정답)만 실행 전에 정해 둡니다.

데이터셋 삭제​

데이터셋 화면 오른쪽 위 삭제를 누르면 "데이터셋 삭제" 확인 창이 열립니다. 창에는 "이 작업은 되돌릴 수 없습니다. 이 데이터셋의 모든 문항이 영구적으로 삭제됩니다."라고 나오고, 삭제를 눌러야 지워집니다. 지침을 고칠 때마다 비교하는 데이터셋은 지우지 말고 이름이나 설명으로 구분해 둡니다.

정리하면 다음과 같습니다.

  • CSV 첫 줄에는 영문 question, answer 열이 있어야 하고, 파일은 5MB, 1,000행까지 올릴 수 있습니다.
  • 생성 전에 미리보기로 열과 행 수를 확인합니다.
  • 파일이 거절되면 고쳐서 다시 올리거나 파일 없이 만들기로 빈 데이터셋을 만든 뒤 문항을 직접 넣습니다.
