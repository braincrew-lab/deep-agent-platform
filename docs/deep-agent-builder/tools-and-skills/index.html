도구와 스킬 구성

에이전트가 일을 하려면 실제로 손을 움직이는 도구와, 어떤 순서와 기준으로 일할지 적어 둔 스킬이 필요합니다. 이 페이지는 에셋 화면에서 도구를 등록·시험·관리하고, 유틸리티에서 제공 도구를 찾아 설치한 뒤, 에이전트 편집 화면의 도구함에 붙이는 과정을 브레인크루 AI혁신팀 김그루 사원의 예시로 설명합니다. 예시 화면의 도구는 김그루가 등록해 둔 사내 문서 검색 MCP 도구 deep_connector_kb입니다.

이 페이지에서 할 수 있는 일

  • 도구, 스킬, 지식의 차이를 업무 예시로 구분합니다.
  • 에셋 화면의 탭 구성(도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드)을 알고 필요한 탭으로 이동합니다.
  • 도구 추가 메뉴로 MCP 서버 도구를 등록하고, 도구 이름 규칙을 지킵니다.
  • 테스트 실행으로 도구를 미리 호출해 보고, 기본값 설정에서 시크릿 키를 참조하게 합니다.
  • 쓰지 않는 도구를 선택 모드로 여러 개 골라 한 번에 지웁니다.
  • 유틸리티에서 제공 도구를 설치하고, 에이전트 도구함에 붙인 뒤 도구 설정에서 에이전트별 값을 바꿉니다.

도구, 스킬, 지식은 무엇이 다른가​

구분하는 일브레인크루 예시
도구실제 동작을 합니다. 예를 들어 외부 시스템을 호출하거나 사내 문서를 검색합니다.사내 문서를 검색하는 deep_connector_kb 도구
스킬어떤 순서와 기준으로 일할지 적은 업무 매뉴얼입니다. 에이전트가 필요할 때 불러와 읽습니다."브레인크루 보고서 작성 규칙" 스킬
지식답변 근거가 되는 사내 문서 묶음입니다. Deep Connector 컬렉션을 연결합니다.사내 규정 Q&A 도우미의 "브레인크루 사내 규정"

도구만 있으면 자료는 모으지만 보고서 형식이 들쭉날쭉할 수 있고, 스킬만 있으면 기준은 알지만 새 자료를 가져오지 못합니다. 시장 조사처럼 자료를 모아 정해진 형식으로 정리하는 업무는 두 가지를 함께 붙입니다. 지식 연결은 지식으로 근거 있는 답변 받기에서 설명합니다.

에셋 화면과 도구 탭​

사이드바 아래쪽 에셋설정을 누르면 에셋 화면이 열립니다. 화면 설명은 "도구, 모델, 미들웨어, 스킬을 관리합니다"입니다. 위쪽 탭 줄에는 도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드 탭이 있고, 처음에는 도구 탭이 열립니다.

도구 탭에서는 **도구 검색...**으로 이름을 찾고, 유형 필터(전체와 내가 가진 도구 유형, 예: MCP)로 목록을 거릅니다. 목록의 도구를 고르면 오른쪽 도구 상세에 설명, 세부 도구 목록(MCP 도구일 때), 필수 환경변수와 테스트, 기본값 설정, 수정, 삭제 아이콘 버튼이 보입니다. 새 도구는 도구 추가로 등록하고, 여러 도구를 한꺼번에 지울 때는 선택을 누릅니다.

에셋 화면의 도구 탭: 메뉴와 목록 거르기

번호메뉴기능이런 때 사용하세요
1에셋설정사이드바 아래쪽에서 에셋 화면을 엽니다.도구, 모델, 스킬을 한곳에서 관리할 때
2탭 줄도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드 탭으로 바꿉니다.관리할 자원 종류를 고를 때
3도구 검색...도구 이름으로 목록을 좁힙니다.등록된 도구가 많을 때
4유형 필터전체 또는 도구 유형(예: MCP)별로 목록을 거릅니다. 처음에는 전체가 선택되어 있습니다.한 유형만 골라 볼 때

같은 화면에서 목록과 상세를 다루는 버튼은 다음과 같습니다.

에셋 화면의 도구 탭: 도구 목록과 도구 상세

번호메뉴기능이런 때 사용하세요
1선택여러 도구를 골라 한 번에 지우는 선택 모드로 바꿉니다.쓰지 않는 시험용 도구를 정리할 때
2도구 추가새 도구를 등록하는 메뉴를 엽니다.사내 API나 MCP 서버를 도구로 쓰고 싶을 때
3도구 목록의 도구내가 쓸 수 있는 도구입니다. 도구 이름 아래에 출처(예: 사용자 등록)와 유형(예: MCP), 설명이 함께 보입니다. 누르면 오른쪽에 도구 상세가 열립니다.내가 만든 도구와 제공 도구를 구분할 때
4도구 상세 버튼고른 도구의 오른쪽 위 테스트, 기본값 설정, 수정, 삭제 아이콘입니다. 아래에는 설명, 세부 도구, 필수 환경변수가 보이고, 도구를 고르지 않으면 "선택된 도구가 없습니다"가 보입니다.에이전트에 붙이기 전에 도구를 시험하거나 고칠 때

도구 상세 아래 필수 환경변수에는 도구가 쓰는 키 이름과 등록됨 또는 미등록 상태가 보입니다. 미등록이면 그 키가 아직 시크릿에 없다는 뜻이므로 시크릿에 먼저 등록합니다. 시크릿은 시크릿과 권한에서 설명합니다.

도구 추가 메뉴​

도구 추가를 누르면 등록할 도구 종류를 고르는 메뉴가 열립니다. 이 환경의 메뉴에는 Dify MCP Server, n8n MCP Server, Connect MCP Server 세 가지가 있고, 항목마다 한 줄 설명이 붙어 있습니다. 회사 설정에 따라 HTTP 요청 도구나 MCP Remote 같은 항목이 더 보일 수 있습니다.

도구 추가 메뉴

번호메뉴기능이런 때 사용하세요
1Dify MCP ServerDify 워크플로우를 MCP로 연결합니다. URL은 /mcp로 끝나야 합니다.Dify에서 만든 워크플로우를 도구로 쓸 때
2n8n MCP Servern8n 워크플로우를 MCP로 연결합니다. URL과 인증 토큰을 넣으며, 토큰은 환경변수로 추가로 시크릿에 넣을 수 있습니다.n8n 자동화를 에이전트에서 부를 때
3Connect MCP ServerConnect MCP 서버를 URL과 Token으로 연결합니다. Token에는 받은 토큰 값만 넣고 앞에 인증 방식 이름을 붙이지 않습니다.Connect MCP 서버 주소와 토큰을 받았을 때

어떤 종류든 새 도구 추가 창("새 도구 설정을 생성합니다. 도구 유형에 따라 필요한 필드를 입력하세요.")에서 도구 이름과 설명을 먼저 넣습니다.

  • 도구 이름은 영문 소문자로 시작하고 소문자, 숫자, 밑줄(_)만 쓸 수 있습니다. 만든 뒤에는 바꿀 수 없으니 신중히 정합니다. 예: braincrew_sales_lookup
  • 표시 이름은 목록과 상세에 보일 이름으로, 한글과 공백을 쓸 수 있습니다. 비우면 도구 이름이 그대로 보입니다.
  • 설명은 에이전트가 이 도구를 언제 쓸지 판단하는 근거가 되므로 하는 일을 구체적으로 적습니다.

토큰이 들어가는 칸은 비밀번호처럼 다룹니다. 창 아래 연결 테스트로 연결을 확인한 뒤 생성을 누르고, 그만두려면 취소를 누릅니다. MCP 도구를 등록하고 에이전트를 MCP 서버로 공개하는 방법은 MCP와 에이전트의 MCP화에서 더 자세히 설명합니다. 종류별 입력 항목과 기본값, 관리자 권한이 필요한 종류(HTTP 요청 Server, MCP Remote, Zapier MCP Server)는 도구 등록 화면에 모아 두었습니다.

도구 테스트​

에이전트에 붙이기 전에 도구 상세의 테스트를 눌러 도구를 직접 불러 볼 수 있습니다. "도구 테스트 - 도구 이름" 창이 열립니다. MCP 도구는 Arguments (JSON) 아래 **세부 도구 (sub-tool)**에서 부를 하위 도구를 고르고, 그 아래 칸에 값을 넣은 뒤 테스트 실행을 누릅니다. 실행이 끝나면 버튼 아래에 성공 또는 실패와 걸린 시간, 응답 본문(실패하면 오류 내용)이 보입니다. 응답이 느린 사내 API라면 **타임아웃 (초)**을 늘립니다. 1초부터 60초까지 넣을 수 있고 기본값은 10초입니다.

도구 테스트 창

번호메뉴기능이런 때 사용하세요
1타임아웃 (초)요청 제한 시간입니다. 1초부터 60초까지 넣을 수 있고 기본값은 10초입니다.응답이 느린 사내 API를 시험할 때 시간을 늘립니다
2세부 도구 (sub-tool)Arguments (JSON) 아래에서 부를 하위 도구를 고릅니다. 고르면 그 아래에 하위 도구 설명과 파라미터 칸(예: path, pattern)이 나옵니다. 파라미터가 없는 하위 도구는 "이 도구는 파라미터가 없습니다"가 보입니다.검색어나 조회 조건을 직접 넣어 볼 때
3자동채우기AI 자동채우기에서 고른 모델이 파라미터 예시 값을 채웁니다. 쓸 수 있는 모델이 없으면 "사용 가능한 모델이 없습니다. 개인 또는 워크스페이스 시크릿에 모델 API 키를 등록해 주세요"가 보입니다.파라미터가 많아 예시 값을 직접 만들기 번거로울 때
4테스트 실행입력한 값으로 도구를 호출합니다. 끝나면 버튼 아래에 성공 또는 실패, 걸린 시간, 응답 본문이 보입니다.값을 다 넣었을 때

테스트가 실패로 끝나고 "오류: fetch failed"처럼 연결 오류가 보이면, 이 창에서 도구 서버에 닿지 못했다는 뜻입니다. 도구 주소와 키를 확인하고, 그래도 같으면 에이전트 대화에서 도구가 실제로 불리는지 먼저 확인한 뒤 관리자에게 문의합니다. AI 자동채우기를 쓰려면 모델 API 키가 개인 또는 워크스페이스 시크릿에 등록되어 있어야 합니다.

기본값 설정​

도구 상세의 기본값 설정을 누르면 "기본값 설정 · 도구 이름" 창이 열립니다. 이 도구를 쓰는 내 에이전트 전체에 적용할 파라미터 기본값을 정합니다. 에이전트에 따로 정한 값이 우선하며, 저장한 뒤 시작한 실행부터 반영됩니다.

기본값 설정 창

번호메뉴기능이런 때 사용하세요
1공통 설정여러 하위 도구가 함께 쓰는 파라미터를 한 번에 정합니다. 수정한 공통 설정만 저장되고, 개별 설정이 있으면 개별 설정이 우선합니다. 파라미터마다 적용 대상 하위 도구가 함께 보입니다.MCP 도구의 하위 도구들이 같은 값을 쓸 때
2하위 도구별 설정하위 도구마다 기본값을 따로 정합니다.하위 도구 하나만 다른 값을 써야 할 때
3설정 방식파라미터마다 기본값 해제 (상속), 직접 입력, 빈 값 (null), 시크릿 키 참조 중에서 고릅니다. 파라미터 형식에 따라 고를 수 있는 항목이 다릅니다.값을 화면에 직접 적지 않고 시크릿에서 가져오게 할 때
4시크릿 키시크릿 키 참조를 고르면 옆에 나타납니다. "시크릿 키를 선택하세요"를 눌러 저장된 시크릿 키 이름을 고릅니다. 값은 보이지 않습니다.API 키처럼 노출되면 안 되는 값을 쓸 때

처음에는 모든 파라미터가 기본값 해제 (상속)("기본값을 저장하지 않습니다")입니다. API 키 같은 값은 직접 입력 대신 시크릿 키 참조를 고르고 시크릿 키를 고릅니다. 필요한 키가 목록에 없으면 창 왼쪽 아래 시크릿 등록으로 새로 만듭니다. 설정을 마치면 창 아래 저장을 누르고, 그만두려면 취소를 누릅니다. 이렇게 연결해 두면 화면과 에이전트 설정 어디에도 실제 값이 남지 않습니다.

여러 도구 한 번에 지우기​

도구 목록 위 선택을 누르면 선택 모드로 바뀝니다. 지울 도구를 체크하거나 전체 선택으로 지금 보이는 도구를 모두 고르면 "1개 선택됨"처럼 고른 개수가 보입니다. 선택 항목 삭제를 누르면 "선택 항목 삭제" 확인 창에 "1개 항목을 삭제합니다. 이 작업은 되돌릴 수 없습니다."가 나오고, 삭제를 눌러야 지워집니다. 지우지 않고 돌아가려면 취소를 누릅니다.

도구 여러 개 선택

번호메뉴기능이런 때 사용하세요
1취소선택 모드를 끝냅니다.지우지 않고 돌아갈 때
2전체 선택지금 보이는 도구를 모두 고릅니다.검색으로 좁힌 시험용 도구를 한꺼번에 고를 때
3선택된 개수"1개 선택됨"처럼 고른 도구 수입니다.지우기 전에 개수를 확인할 때
4선택 항목 삭제확인 창을 거쳐 고른 도구를 지웁니다. 되돌릴 수 없습니다.고르기를 마쳤을 때

에이전트가 쓰는 도구를 지우면 그 에이전트가 오동작할 수 있습니다. 먼저 에이전트의 도구함에서 빼는 편이 안전합니다.

유틸리티에서 제공 도구 설치하기​

직접 등록하지 않아도 회사가 제공하는 도구, 모델, 스킬을 유틸리티에서 찾아 설치할 수 있습니다. 사이드바 위쪽 더 보기를 누르고 유틸리티를 고릅니다. 화면 설명은 "사용 가능한 도구, 모델, 미들웨어를 찾아보고 추가하세요"입니다.

위쪽 탭에서 회사 전체 항목(예: 브레인크루)과 워크스페이스 항목을 나눠 봅니다. 워크스페이스 탭에서는 워크스페이스 선택 칸(예: AI혁신팀)과 전체 항목 수(예: "총 75개")가 보입니다. 그 아래 도구, 모델, 스킬 탭으로 종류를 고르고, **검색...**으로 이름을 찾고, 유형: 필터에서 전체, 설치됨, 미설치 또는 분야(커머스, 커뮤니케이션, 이미지, 지식, 법률, 생산성, 리서치, 안전)로 거릅니다. 항목 카드에는 이름, 설명, 분야, 버전과 설치됨 또는 미설치 상태가 보입니다. 조회 권한이 없는 탭에서는 "접근 권한이 없습니다"가 보입니다.

유틸리티 화면: 볼 범위와 종류 고르기

번호메뉴기능이런 때 사용하세요
1회사, 워크스페이스 탭회사 전체 항목과 워크스페이스에 등록된 항목을 나눠 봅니다.팀이 쓸 수 있는 항목을 볼 때
2워크스페이스 선택항목을 볼 워크스페이스를 고릅니다. 옆에 전체 항목 수가 보입니다.내가 속한 다른 팀의 항목을 볼 때
3도구, 모델, 스킬 탭항목 종류를 바꿉니다.도구만 찾을 때

같은 화면 아래쪽에서 항목을 찾고 거릅니다. 아래는 **검색...**에 "search"를 넣은 모습입니다.

유틸리티 화면: 검색과 항목 카드

번호메뉴기능이런 때 사용하세요
1검색...이름과 설명으로 항목을 찾습니다."search"처럼 이름 일부로 찾을 때
2유형: 필터전체, 설치됨, 미설치와 분야별로 거릅니다.아직 설치하지 않은 리서치 도구만 볼 때
3항목 카드이름, 설명, 분야, 버전과 설치 상태가 보입니다. 누르면 상세 창이 열립니다.도구가 하는 일을 확인할 때

카드를 누르면 상세 창에 도구 설명과 기본 정보(유형, 버전, 등록자, 등록일), 아래에 닫기와 설치 버튼이 보입니다. 설치를 누르면 내 에셋에 추가되고, 설치한 도구는 에셋 화면의 도구 탭과 에이전트의 도구 추가 창에 나타납니다. 설치 권한이 없으면 설치 버튼이 흐리게 보이고, 버튼에 마우스를 올리면 "설치 권한이 없습니다. 관리자에게 문의하세요."가 보입니다. 이때는 워크스페이스 관리자에게 설치를 요청합니다.

팁: 웹 검색 도구(예: 카드 이름에 SEARCH가 들어간 리서치 도구)는 대부분 외부 서비스 키가 있어야 동작합니다. 회사에 키가 등록되어 있지 않으면 설치해도 실행되지 않으므로, 관리자에게 먼저 확인합니다.

워크스페이스에 내 도구를 등록 요청하는 등록 요청 관리와 관리자의 일괄 배포(Danger Zone)는 유틸리티에서 설명합니다.

에이전트 도구함에 도구 붙이기​

도구는 에이전트 편집 화면 가운데 편집 영역의 폼 보기 아래쪽 도구함에서 붙입니다. 도구함 제목을 누르면 칸을 접거나 펼치므로, 지침 칸을 넓게 볼 때 접어 둡니다. 붙은 도구가 없으면 "추가된 도구가 없습니다"가 보입니다. + 도구를 누르면 도구 추가 창이 열리고, 왼쪽 목록에서 도구를 고른 뒤 오른쪽 도구 추가를 누르면 이 에이전트에 붙습니다.

아래는 deep_connector_kb 도구가 붙은 시장 조사 리서처의 에이전트 편집 화면입니다.

에이전트 편집 화면의 도구함

번호메뉴기능이런 때 사용하세요
1+ 도구도구 추가 창을 엽니다. 왼쪽 목록에서 도구를 고르고 오른쪽 도구 추가를 누릅니다.에셋에 있는 도구를 이 에이전트에 붙일 때
2연결된 도구이 에이전트가 쓰는 도구입니다. 칸이 좁으면 이름이 줄여서 보입니다. 없으면 "추가된 도구가 없습니다"가 보입니다.어떤 도구가 붙어 있는지 확인할 때
3도구 설정(톱니바퀴)"도구 설정: 도구 이름" 창을 엽니다.이 에이전트에서만 다른 값을 쓰게 할 때
4삭제(휴지통)이 에이전트에서 도구를 뺍니다. 에셋 화면의 도구는 지워지지 않습니다.더는 쓰지 않는 도구를 뺄 때

도구를 붙이거나 빼면 바로 반영되어 대화와 테스트 탭에서 곧바로 쓰입니다. 붙이면 도구 이름과 함께 "도구가 추가되었습니다" 알림이, 빼면 "도구가 제거되었습니다" 알림이 뜹니다. 이때 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 눌러 현재 버전에도 기록해 둡니다. 워크스페이스 등록은 저장된 버전을 쓰기 때문입니다. 도구 추가 창에는 지식이 나오지 않습니다. 지식은 바로 옆 지식함에서 붙입니다.

도구 이름이 줄여 보이면 칸 사이 경계를 끌어 도구함을 넓힙니다. 도구를 빼려면 이름 옆 삭제(휴지통)를 누릅니다. 에셋 화면의 도구는 지워지지 않습니다.

도구 설정 창​

도구함에서 도구 이름 옆 도구 설정(톱니바퀴)을 누르면 "도구 설정: 도구 이름" 창이 열립니다. 이 창에서 정한 값은 이 에이전트에만 적용되고, 에셋 화면의 기본값 설정보다 우선합니다.

  • 위쪽에 도구 설명과 연결된 서버가 보이고, MCP 도구라면 서브 도구 목록과 하위 도구 개수가 보입니다.
  • 왼쪽 목록에서 하위 도구를 고르면 오른쪽에 그 하위 도구의 설명과 파라미터 카드가 나옵니다. 카드마다 형식, 기본값 유무(예: 기본값 없음), 필수 여부(예: 선택)와 기본값 칸, **기본값 해제 (상속)**이 있습니다.
  • 고급 설정을 펼치면 **기본 설정(전역 기본값)**과 에이전트 재정의가 보입니다. 재정의 값은 폼 또는 JSON으로 넣습니다. 재정의 값은 기본 설정과 병합되고, 비워 두면 기본값을 쓰며, 기본값과 같은 값은 저장되지 않습니다.
  • 다 바꾼 뒤 저장을 누릅니다. 바꾸지 않고 닫으려면 취소를 누릅니다.

도구 설정 창

번호메뉴기능이런 때 사용하세요
1서브 도구MCP 도구의 하위 도구 목록입니다. 하나를 고르면 오른쪽에 그 하위 도구의 파라미터가 나옵니다.MCP 서버의 특정 하위 도구 값만 바꿀 때
2파라미터 카드파라미터마다 형식, 기본값 유무, 필수 여부와 기본값 칸이 보입니다. **기본값 해제 (상속)**을 누르면 값을 비웁니다.이 에이전트에서 검색 범위나 결과 수를 바꾸고 싶을 때
3고급 설정펼치면 **기본 설정(전역 기본값)**과 에이전트 재정의를 나란히 보고, 재정의 값을 폼 또는 JSON으로 넣습니다. 폼에 칸이 없으면 "설정 가능한 파라미터가 없습니다. JSON 모드에서 사용자 정의 재정의를 추가하세요."가 보입니다.어떤 값이 실제로 적용되는지 확인하거나 폼에 없는 값을 넣을 때
4저장에이전트별 도구 설정을 저장합니다.값을 다 바꿨을 때

따라 해 보기: 시장 조사 리서처의 도구 확인하기​

  1. 사이드바의 에셋설정을 눌러 에셋 화면의 도구 탭을 열고, 쓸 도구(예: deep_connector_kb)를 눌러 필수 환경변수가 등록됨인지 확인합니다.
  2. 도구 상세의 테스트를 누르고 **세부 도구 (sub-tool)**를 고른 뒤 테스트 실행을 눌러 결과를 봅니다.
  3. 사이드바에서 시장 조사 리서처를 누르고 에이전트 설정을 누릅니다.
  4. 도구함에 도구가 없으면 + 도구를 누르고, 도구를 고른 뒤 도구 추가를 누릅니다. 헤더에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 누릅니다.
  5. 도구 이름 옆 톱니바퀴를 눌러 도구 설정 창에서 하위 도구별 값을 확인하고, 바꾼 것이 없으면 취소를 누릅니다.

팁: 결과가 예상과 다르면 먼저 대화의 실행 기록에 도구 줄이 있는지 봅니다. 줄이 없다면 도구함에 붙었는지, 지침에 그 도구를 언제 쓰는지 적혀 있는지 확인합니다. 시장 조사 전체 흐름은 사례: 시장 조사 리포트에 있습니다.

스킬 한눈에 보기​

스킬은 에셋 화면의 스킬 탭에서 올리거나 만들고, 에이전트 편집 화면 오른쪽 스킬 탭에서 켭니다. 스킬은 문서 작성 스킬과 일반 스킬 두 종류로 나뉘며, 켠 스킬은 대화 화면 입력란 아래 왼쪽의 스킬 버튼으로 골라 바로 쓸 수 있습니다. 대화 중 에이전트가 스킬을 읽으면 실행 기록에 스킬 불러오기 줄이 나옵니다.

스킬 파일 형식, 업로드 규칙, 배포와 ZIP 내보내기는 스킬 만들기와 업로드에서 자세히 설명합니다.

바꾼 뒤 확인할 것​

  • 실행 기록에 붙인 도구나 스킬의 줄이 나오는가
  • 도구 결과의 값이 테스트 실행 결과와 같은 형식인가
  • 키가 필요한 도구는 시크릿에 등록되어 있고 기본값 설정에서 시크릿 키 참조로 연결되었는가
  • 지운 도구를 쓰던 에이전트가 남아 있지 않은가
