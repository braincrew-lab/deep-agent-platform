도구와 스킬 구성

에이전트가 일을 하려면 실제로 손을 움직이는 도구와, 어떤 순서와 기준으로 일할지 적어 둔 스킬이 필요합니다. 이 페이지는 에셋 화면에서 도구를 등록·시험·관리하고, 유틸리티에서 제공 도구를 설치한 뒤, 에이전트 편집 화면의 도구함에 붙이는 과정을 브레인크루 AI혁신팀 김그루 사원의 시장 조사 리서처 예시로 설명합니다.

이 페이지에서 할 수 있는 일

  • 도구, 스킬, 지식의 차이를 업무 예시로 구분합니다.
  • 에셋 화면의 탭 구성(도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드)을 알고 필요한 탭으로 이동합니다.
  • 도구 추가 메뉴로 HTTP 도구와 MCP 서버 도구를 등록하고, 도구 이름 규칙을 지킵니다.
  • 테스트 실행으로 도구를 미리 호출해 보고, 기본값 설정에서 시크릿 키를 참조하게 합니다.
  • 쓰지 않는 도구를 선택 모드로 여러 개 골라 한 번에 지웁니다.
  • 유틸리티에서 제공 도구를 설치하고, 에이전트 도구함에 붙인 뒤 도구 설정에서 에이전트별 값을 바꿉니다.

도구, 스킬, 지식은 무엇이 다른가​

구분하는 일브레인크루 예시
도구실제 동작을 합니다. 예를 들어 외부 시스템을 호출하거나 파일을 읽습니다.시장 조사 리서처가 쓰는 웹 검색 도구
스킬어떤 순서와 기준으로 일할지 적은 업무 매뉴얼입니다. 에이전트가 필요할 때 불러와 읽습니다."브레인크루 보고서 작성 규칙" 스킬
지식답변 근거가 되는 사내 문서 묶음입니다. Deep Connector 컬렉션을 연결합니다.사내 규정 Q&A 도우미의 "브레인크루 사내 규정"

도구만 있으면 자료는 모으지만 보고서 형식이 들쭉날쭉할 수 있고, 스킬만 있으면 기준은 알지만 새 자료를 가져오지 못합니다. 시장 조사처럼 자료를 모아 정해진 형식으로 정리하는 업무는 두 가지를 함께 붙입니다. 지식 연결은 지식으로 근거 있는 답변 받기에서 설명합니다.

에셋 화면과 도구 탭​

사이드바 아래쪽 에셋설정을 누르면 에셋 화면이 열립니다. 화면 설명은 "도구, 모델, 미들웨어, 스킬을 관리합니다"입니다. 위쪽 탭 줄에는 도구, 모델, 스킬, 메모리, 시크릿, API 키, 커맨드 탭이 있고, 처음에는 도구 탭이 열립니다.

도구 탭에서는 **도구 검색...**으로 이름을 찾고, 유형 필터(처음에는 전체)로 목록을 거릅니다. 목록의 도구를 고르면 오른쪽 도구 상세에 설명, 파라미터, 필수 환경변수와 테스트, 기본값 설정, 수정, 삭제 버튼이 보입니다. 새 도구는 도구 추가로 등록하고, 여러 도구를 한꺼번에 지울 때는 선택을 누릅니다.

도구 상세의 필수 환경변수 옆에 미등록이 보이면, 그 도구가 쓰는 키가 아직 시크릿에 없다는 뜻입니다. 옆의 등록을 누르면 시크릿 입력 창이 열립니다. 시크릿은 시크릿과 권한에서 설명합니다.

도구 추가 메뉴​

도구 추가를 누르면 등록할 도구 종류를 고르는 메뉴가 열립니다. 메뉴에는 HTTP 요청 Server, MCP Remote, Zapier MCP Server, Dify MCP Server, n8n MCP Server, Connect MCP Server 여섯 가지가 있습니다.

어떤 종류든 새 도구 추가 창에서 도구 이름과 설명을 먼저 넣습니다.

  • 도구 이름은 영문 소문자로 시작하고 소문자, 숫자, 밑줄(_)만 쓸 수 있습니다. 만든 뒤에는 바꿀 수 없으니 신중히 정합니다. 예: braincrew_sales_lookup
  • 표시 이름은 목록과 상세에 보일 이름으로, 한글과 공백을 쓸 수 있습니다. 비우면 도구 이름이 그대로 보입니다.
  • 설명은 에이전트가 이 도구를 언제 쓸지 판단하는 근거가 되므로 하는 일을 구체적으로 적습니다.

URL에 키가 들어가는 도구(예: Zapier의 Connect URL)는 비밀번호처럼 다룹니다. MCP 서버 도구는 창 아래 연결 테스트로 연결을 확인한 뒤 생성합니다. MCP 도구를 등록하고 에이전트를 MCP 서버로 공개하는 방법은 MCP와 에이전트의 MCP화에서 더 자세히 설명합니다.

도구 테스트​

에이전트에 붙이기 전에 도구 상세의 테스트를 눌러 도구를 직접 불러 볼 수 있습니다. "도구 테스트 - 도구 이름" 창이 열립니다. 파라미터에 값을 넣거나(필수 값에는 필수 표시가 붙습니다) AI 자동채우기로 예시 값을 채운 뒤 테스트 실행을 누르면, 실행 결과에 성공 또는 실패, 응답 시간, 응답 본문이 보입니다. 응답이 느린 사내 API라면 **타임아웃 (초)**을 늘립니다. 1초부터 60초까지 넣을 수 있고 기본값은 10초입니다.

MCP 도구 가운데 아직 하위 도구 정보가 없는 것은 "이 MCP 도구는 아직 서브 도구 정보가 없습니다. 먼저 서브 도구를 조회하세요." 안내와 함께 서브 도구 조회 버튼이 보입니다. 누르면 서버가 제공하는 하위 도구 목록을 가져옵니다. AI 자동채우기의 모델 목록이 비어 있으면 모델 API 키가 시크릿에 등록되어 있는지 확인하세요.

기본값 설정​

도구 상세의 기본값 설정은 이 도구를 쓰는 내 에이전트 전체에 적용할 파라미터 기본값을 정합니다. 에이전트에 따로 정한 값이 있으면 그 값이 우선하며, 저장한 뒤 시작한 실행부터 반영됩니다.

기본값 설정 창에서는 파라미터마다 설정 방식을 직접 입력, 기본값 해제 (상속), 빈 값 (null), 시크릿 키 참조 중에서 고르고 저장을 누릅니다. 하위 도구가 있는 MCP 도구는 여러 하위 도구에 함께 쓸 값을 공통 설정에서, 하위 도구마다 다른 값을 하위 도구별 설정에서 정합니다. API 키 같은 값은 직접 입력 대신 시크릿 키 참조를 고르고 시크릿 키에서 저장된 키를 고릅니다(없으면 시크릿 등록으로 새로 만듭니다). 이렇게 연결해 두면 화면과 에이전트 설정 어디에도 실제 값이 남지 않습니다.

여러 도구 한 번에 지우기​

도구 목록 위 선택을 누르면 선택 모드로 바뀝니다. 지울 도구를 체크하거나 전체 선택으로 지금 보이는 도구를 모두 고르면 "3개 선택됨"처럼 고른 개수가 보입니다. 선택 항목 삭제를 누르면 "선택 항목 삭제" 확인 창이 열리며, 지운 도구는 되돌릴 수 없습니다. 지우지 않고 돌아가려면 취소를 누릅니다.

고른 도구 중 에이전트가 쓰는 것이 있으면 확인 창에 사용 중인 에이전트 이름과 함께 경고가 나오고, 무시하고 삭제를 고를 수 있습니다. 이때 그 도구를 쓰던 에이전트는 오동작할 수 있으므로, 먼저 에이전트의 도구함에서 빼는 편이 안전합니다.

유틸리티에서 제공 도구 설치하기​

직접 등록하지 않아도 회사가 제공하는 도구, 모델, 미들웨어, 스킬을 유틸리티에서 골라 설치할 수 있습니다. 사이드바 위쪽 더 보기를 누르고 유틸리티를 고릅니다. 화면 설명은 "사용 가능한 도구, 모델, 미들웨어를 찾아보고 추가하세요"입니다.

전체 탭과 워크스페이스 탭으로 전체 제공 항목과 내 워크스페이스에 등록된 항목을 나눠 보고, 유형: 필터에서 도구, 모델, 미들웨어, 스킬 중 하나로 거르며, **검색...**으로 이름을 찾습니다. 항목 카드에는 이름, 설명, 유형과 설치됨 또는 미설치 상태가 보입니다. 설치를 누르면 내 에셋에 추가되며, 스킬은 스킬 설치로 표시됩니다.

설치 권한이 없으면 "설치 권한이 없습니다. 관리자에게 문의하세요."가 보입니다. 설치한 도구는 에셋 화면의 도구 탭과 에이전트의 도구 추가 창에 나타납니다.

에이전트 도구함에 도구 붙이기​

도구는 에이전트 편집 화면 가운데 편집 영역의 폼 보기 아래쪽 도구함에서 붙입니다. 도구함 제목을 누르면 칸을 접거나 펼칩니다. 붙은 도구가 없으면 "추가된 도구가 없습니다"가 보입니다. + 도구를 누르면 도구 추가 창이 열리고, 왼쪽 목록에서 도구를 고른 뒤 오른쪽 도구 추가를 누르면 이 에이전트에 붙습니다.

도구를 붙이거나 빼면 바로 반영되어 대화와 테스트 탭에서 곧바로 쓰입니다. 붙이면 도구 이름과 함께 "도구가 추가되었습니다" 알림이, 빼면 "도구가 제거되었습니다" 알림이 뜹니다. 이때 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 눌러 현재 버전에도 기록해 둡니다. 워크스페이스 등록은 저장된 버전을 쓰기 때문입니다. 도구 추가 창에는 지식이 나오지 않습니다. 지식은 바로 옆 지식함에서 붙입니다.

붙은 도구 이름 옆 노란 방패는 그 도구를 쓸 권한이 없다는 표시입니다. 도구를 빼려면 이름 옆 삭제(휴지통)를 누릅니다. 에셋 화면의 도구는 지워지지 않습니다.

도구 설정 창​

도구함에서 도구 이름 옆 도구 설정(톱니바퀴)을 누르면 "도구 설정: 도구 이름" 창이 열립니다. 이 창에서 정한 값은 이 에이전트에만 적용되고, 에셋 화면의 기본값 설정보다 우선합니다.

  • 파라미터 (개수) 목록에서 값마다 어디에서 온 값인지(이 에이전트, 도구 기본값, 공통 설정, 기본값 없음)를 확인하고 값을 바꿉니다.
  • 폼에 없는 값을 넣어야 하면 폼을 JSON으로 바꿔 재정의 값을 직접 적습니다.
  • MCP 도구라면 서브 도구에서 하위 도구를 골라 하위 도구별 파라미터를 봅니다.
  • 고급 설정을 펼치면 전역 기본값과 에이전트 재정의 값을 나란히 볼 수 있습니다. 기본값과 같은 값은 저장되지 않습니다.
  • 다 바꾼 뒤 저장을 누르면 "도구 설정이 저장되었습니다" 알림이 뜹니다.

따라 해 보기: 시장 조사 리서처에 웹 검색 도구 붙이기​

카탈로그에 웹 검색 도구가 있으면 아래 순서로 시장 조사 리서처에 붙입니다. 웹 검색 도구가 없는 환경이면 3단계까지만 확인하고, 첨부한 시장 메모만으로 조사하도록 쓰면 됩니다.

  1. 사이드바 더 보기 > 유틸리티에서 **유형:**을 도구로 바꾸고 **검색...**에 "검색"을 입력합니다.

  2. 웹 검색 도구 카드가 미설치이면 설치를 누릅니다. 이미 설치됨이면 다음 단계로 넘어갑니다.

  3. 사이드바의 에셋설정을 눌러 여는 에셋 화면의 도구 탭에서 방금 설치한 도구를 고르고, 필수 환경변수가 미등록이면 등록으로 키를 시크릿에 넣습니다.

  4. 도구 상세의 테스트를 누르고 AI 자동채우기로 파라미터를 채운 뒤 테스트 실행을 누릅니다. 실행 결과가 성공인지 봅니다.

  5. 사이드바에서 시장 조사 리서처를 누르고 에이전트 설정을 누릅니다.

  6. 도구함의 + 도구를 누르고, 웹 검색 도구를 고른 뒤 도구 추가를 누릅니다.

  7. 이 에이전트와 새 대화에서 아래 프롬프트를 보내고, 답변 위 실행 기록에 웹 검색 도구 줄이 나오는지 확인합니다.

    프롬프트: 국내 업무용 AI 에이전트 도구 시장의 최근 동향을 웹에서 찾아 세 줄로 요약하고, 각 줄 끝에 참고한 출처를 적어 주세요.

팁: 결과가 예상과 다르면 먼저 실행 기록에 도구 줄이 있는지 봅니다. 줄이 없다면 도구함에 붙었는지, 지침에 "자료를 찾을 때는 웹 검색 도구를 먼저 쓴다"는 문장이 있는지 확인합니다. 시장 조사 전체 흐름은 사례: 시장 조사 리포트에 있습니다.

스킬 한눈에 보기​

스킬은 에셋 화면의 스킬 탭에서 올리거나 만들고, 에이전트 편집 화면 오른쪽 스킬 탭에서 켭니다. 스킬은 문서 작성 스킬과 일반 스킬 두 종류로 나뉘며, 켠 스킬은 대화 화면 입력란 아래 왼쪽의 스킬 버튼으로 골라 바로 쓸 수 있습니다. 대화 중 에이전트가 스킬을 읽으면 실행 기록에 스킬 불러오기 줄이 나옵니다.

스킬 파일 형식, 업로드 규칙, 배포와 ZIP 내보내기는 스킬 만들기와 업로드에서 자세히 설명합니다.

바꾼 뒤 확인할 것​

  • 실행 기록에 붙인 도구나 스킬의 줄이 나오는가
  • 도구 결과의 값이 테스트 실행 결과와 같은 형식인가
  • 키가 필요한 도구는 시크릿에 등록되어 있고 기본값 설정에서 시크릿 키 참조로 연결되었는가
  • 지운 도구를 쓰던 에이전트가 남아 있지 않은가
