Deep Agent Builder 실습 묶음 안내

이 묶음은 에이전트를 처음 만드는 것부터 도구·스킬 연결, 캔버스 산출물, 멀티에이전트, 평가까지 여섯 가지 실습을 난이도 순으로 담았습니다. 실습마다 목표, 준비물, 단계별 화면과 번호 표, 설정값 표, 실제 실행 결과, 흔한 실수와 해결, 응용 과제가 있습니다. 예시 인물은 브레인크루 AI혁신팀 김그루 사원이고, 고객사와 금액, 문의 내용은 모두 연습용 가상 자료입니다.

이 페이지에서 할 수 있는 일

  • 실습 여섯 가지가 무엇을 만들고 무엇을 새로 익히는지 한눈에 봅니다.
  • 실습끼리 어떤 에이전트를 이어 쓰는지 확인하고 순서를 정합니다.
  • 실습에 쓰는 파일을 직접 준비하는 방법을 봅니다.
  • 실습과 활용 사례 페이지의 차이를 압니다.

실습 한눈에 보기​

실습만드는 것새로 익히는 것예시 파일난이도
실습 1: 대화로 첫 에이전트 만들기고객 문의 답장 도우미제작 요청, 확인 질문, 추천 승인, 첫 질문md★☆☆☆☆
실습 2: 직접 만들고 다듬기주간 일정 정리 도우미에이전트 직접 만들기, 지침 쓰기, 모델 설정, 챗 오프너, 테스트 탭txt★★☆☆☆
실습 3: 도구와 스킬 붙이기고객 문의 답장 도우미(보강)도구함·도구 설정, 스킬 ZIP 업로드, 스킬 켜기, 대화에서 스킬 부르기zip★★☆☆☆
실습 4: 캔버스로 PPT·Word·표 받기분기 보고 자료 도우미문서작성 에이전트 모드, 캔버스 조작, 문서 요소 선택, 형식별 내보내기pptx, docx, xlsx★★★☆☆
실습 5: 멀티에이전트 만들기총괄 에이전트와 담당 에이전트서브에이전트 관리, 비주얼 보기, 위임 지침, 위임 표시 읽기xlsx, txt★★★★☆
실습 6: 평가하고 고쳐서 다시 비교하기고객 문의 평가 데이터셋과 평가기데이터셋 CSV, 사용자 평가기, 평가 실행, 결과 읽기, 수정 후 재평가csv★★★★☆

처음이라면 실습 1부터 차례로 하세요. 실습 3과 6은 실습 1에서 만든 고객 문의 답장 도우미를 이어 씁니다. 실습 3의 사내 지식 검색은 Deep Connector에서 발급한 토큰으로 등록한 도구가 있어야 하며, 등록 방법은 도구 등록 화면에 있습니다.

실습끼리 이어지는 흐름​

순서실습이어 쓰는 것
1실습 1새로 만든 고객 문의 답장 도우미
2실습 2별도의 새 에이전트(주간 일정 정리 도우미). 지침을 손으로 쓰는 법을 익힙니다.
3실습 3실습 1의 에이전트에 도구 확인과 스킬 추가
4실습 4새 문서작성 에이전트. 실습 2의 지침 쓰는 법을 씁니다.
5실습 5담당 에이전트(판매 데이터 분석가 등)와 새 총괄 에이전트
6실습 6실습 1·3의 에이전트를 데이터셋으로 채점하고, 고친 뒤 다시 채점

실습과 활용 사례의 차이​

구분실습활용 사례
목적메뉴를 직접 눌러 손에 익힙니다. 설정값과 기본값을 함께 봅니다.업무 하나를 끝까지 처리한 결과물을 봅니다.
시작점새 에이전트를 만들거나 앞 실습의 에이전트를 이어 씁니다.사례에 맞게 만들어 둔 에이전트로 바로 시작합니다.
다루는 범위만들기, 지침, 모델, 도구, 스킬, 캔버스, 서브에이전트, 평가업무별 프롬프트와 결과 확인

모든 실습에 공통인 손동작​

하고 싶은 일방법
에이전트 편집 화면 열기사이드바에서 에이전트를 누르고 위쪽 에이전트 설정
바꾼 내용 저장헤더 저장. "저장되지 않은 변경이 있습니다"가 사라지면 저장된 것입니다.
저장 전에 시험오른쪽 탭 줄의 테스트. 새로 시험하려면 새 대화
파일 붙이기입력란 아래 파일 업로드(클립)
실행 기록 보기답변 위 도구·스킬·서브에이전트 호출 줄을 눌러 펼치기
결과 복사답변 아래 복사

연습 파일 만들기​

실습직접 만들 때의 내용
1, 3응대 원칙(결론 → 근거 → 다음 안내), 가격·계약·일정 확정 금지 표시, 문의 유형 네 가지와 담당, 마무리 문장을 적은 1쪽 응대 기준(md 또는 docx)
2일시, 참석자, 결정 사항, 담당자별 액션 아이템과 기한이 있는 주간 회의록(txt 또는 html)
3SKILL.md 한 개를 폴더에 넣어 압축한 ZIP. SKILL.md 맨 위에 name과 description, 그 아래 규칙
4분기 추진 현황 슬라이드(pptx) 또는 보고서 초안(docx), 월별·지역별 판매 표(xlsx)
5판매 표(xlsx)와 회의록(txt)
6question, answer 두 열에 고객 문의와 모범 답변 기준을 8~10행 적은 csv

실제 고객 정보나 영업 비밀이 들어 있는 문서로 연습하지 마세요.

이럴 때 쓰세요: 김그루 사원은 신규 입사자 교육 둘째 날에 이 묶음을 순서대로 진행합니다. 오전에 실습 13으로 에이전트 하나를 만들어 다듬고, 오후에 실습 46으로 산출물과 평가까지 해 보면, 교육생이 다음 날부터 자기 업무 에이전트를 혼자 만들 수 있습니다.
