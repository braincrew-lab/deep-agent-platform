에이전트 평가

에이전트 평가는 같은 질문과 기준으로 여러 실행 결과를 비교하는 작업입니다. 먼저 평가용 질문과 기대 답변을 준비한 뒤 판정 기준을 정하고, 실행이 끝나면 개별 결과와 전체 집계를 함께 확인합니다.

평가에 필요한 자원​

평가 화면에서 다음 자원을 순서대로 확인합니다.

자원확인할 내용
Dataset평가할 질문과 기대 답변의 모음
CaseDataset 안의 개별 질문과 기대 답변
Evaluator에이전트 답변을 판정할 기준
RunDataset과 Evaluator를 사용한 한 번의 실행
ResultCase별 판정 결과
Dashboard여러 실행을 묶어 보는 집계

Dataset과 Evaluator는 개인용 또는 workspace용으로 관리할 수 있습니다. workspace에 보이는 자원이라도 실행 권한이 항상 같은 것은 아니므로, 실행 화면에서 선택할 수 있는지 확인합니다.

Dataset과 Case 준비하기​

평가할 질문은 실제로 확인하려는 업무 입력을 대표해야 합니다. 기대 답변에는 비교 기준이 될 내용을 적습니다. 평가 결과만으로 업무 적합성이나 배포 승인을 확정하지는 않습니다.

Dataset을 새로 만들 때는 다음 순서로 진행합니다.

  1. Dataset 만들기 화면에서 이름을 입력합니다. 설명은 필요할 때만 추가합니다.
  2. Case를 직접 입력하거나 제공된 CSV 양식으로 준비합니다. CSV를 사용할 때는 question과 answer 열을 포함합니다.
  3. 파일을 올린 뒤 항목 수와 질문·기대 답변이 의도한 순서로 들어갔는지 확인합니다.
  4. 저장한 Dataset의 상세 화면을 다시 열어 Case 목록을 확인합니다.

CSV 파일은 최대 5 MB, 최대 1,000행까지 가져올 수 있습니다. question은 50,000자, answer는 100,000자까지 입력할 수 있습니다. 파일이 거부되면 열 이름, 행 수, 파일 크기와 문자 인코딩을 확인한 뒤 다시 저장합니다.

Dataset을 삭제하면 목록에서 더 이상 사용할 수 없게 됩니다. Case 삭제는 개별 항목을 영구적으로 제거하므로, 삭제 전에 대상과 항목 수를 확인합니다.

Evaluator 선택하기​

Evaluator는 에이전트 답변을 어떤 기준으로 비교할지 정합니다.

  • binary는 통과와 실패처럼 두 상태로 판정할 때 선택합니다.
  • score는 점수 범위로 결과를 비교할 때 선택합니다.
  • rubric은 여러 기준을 나눠 답변을 검토할 때 선택합니다.

새 Evaluator를 만들거나 기존 Evaluator를 수정할 때는 판정 유형과 적용 범위를 함께 확인합니다. score를 선택했다면 최소 점수가 최대 점수보다 작은지 확인합니다. 미리 제공되는 Evaluator를 복사해 사용할 때는 복사본의 범위와 이름을 다시 확인합니다.

평가 실행하기​

평가를 실행하기 전에 Dataset과 Evaluator가 같은 목적을 대상으로 하는지 확인합니다. 준비가 끝나면 실행 화면에서 Dataset과 Evaluator를 선택하고 실행을 시작합니다.

실행 중에는 화면에 표시된 진행 상태를 확인합니다. 실행이 끝난 뒤에는 성공 여부만 보지 말고 처리된 Case 수와 결과 목록을 함께 확인합니다. 실행 중인 항목이 있으면 결과 전체를 최종 평가로 해석하지 않습니다.

동시에 실행할 수 있는 평가 수에는 사용자별 제한이 있습니다. 기본값은 2개입니다. 제한에 걸리면 실행 중인 평가가 끝난 뒤 다시 시도합니다. workspace Dataset을 볼 수 있어도 해당 Dataset으로 평가를 시작할 권한이 없을 수 있으므로, 실행 제어가 보이지 않으면 workspace 관리자에게 권한을 요청합니다.

취소와 오류가 발생했을 때​

평가를 취소한 뒤에도 이미 처리 중인 Case가 잠시 결과에 포함될 수 있습니다. 취소를 실행했다면 화면을 새로 확인해 최종 상태와 남은 결과를 함께 봅니다.

다음 증상이 나타나면 해당 조치를 시도합니다.

화면에서 보이는 증상확인할 사항과 다음 조치
입력을 저장할 수 없음필수 값, 열 이름, 파일 크기와 행 수를 확인한 뒤 다시 저장합니다.
평가를 시작할 수 없음선택한 Dataset과 Evaluator의 범위, 실행 권한과 현재 상태를 확인합니다.
대상이 목록에 보이지 않음현재 workspace와 필터를 확인합니다. 계속 보이지 않으면 관리자에게 접근 권한을 요청합니다.
이미 끝난 평가를 다시 취소하려 함최종 상태와 결과를 먼저 확인합니다. 끝난 실행에는 취소를 다시 시도하지 않습니다.
실행 제한 안내가 표시됨현재 실행 중인 평가가 끝난 뒤 다시 시도합니다.
일부 결과만 표시됨실행 상태와 처리된 Case 수를 확인합니다. 전체 결과로 해석하지 않습니다.

같은 문제가 반복되면 Dataset, Evaluator, 실행 상태와 화면에 표시된 안내를 함께 기록해 관리자에게 문의합니다.

결과와 Dashboard 확인하기​

Results에서는 Case별 판정 결과를 확인하고, 결과 export에서는 전체 결과를 내려받아 보관할 수 있습니다. Dashboard를 볼 때는 집계 대상이 현재 보고 있는 에이전트 범위와 같은지 먼저 확인합니다.

결과를 해석할 때는 다음 정보를 함께 기록합니다.

  1. 어떤 Dataset과 Case를 사용했는지
  2. 어떤 Evaluator 유형과 범위를 적용했는지
  3. 실행이 끝났는지, 일부 Case가 남아 있는지
  4. 개별 Result와 Dashboard 집계가 같은 범위를 가리키는지

일부 Case만 처리된 실행이나 제한 시간 안에 끝나지 않은 실행은 전체 평가를 대표하지 않습니다. 결과가 좋아도 Dataset, 지침, 모델 또는 연결 도구가 달랐다면 차이가 생긴 원인을 따로 기록합니다.

권장 실행 순서​

  1. 평가 목적에 맞는 Dataset과 Case를 준비합니다.
  2. CSV를 사용했다면 열 이름, 파일 크기, 행 수와 문자 인코딩을 확인합니다.
  3. Evaluator의 유형과 적용 범위를 확인합니다.
  4. Dataset과 Evaluator를 선택해 평가를 실행합니다.
  5. 실행 상태와 처리된 Case 수를 확인합니다.
  6. 개별 Results와 전체 결과 export를 확인합니다.
  7. Dashboard의 집계 범위를 개별 결과의 범위와 비교합니다.
  8. 취소 또는 오류가 있었다면 최종 상태와 남은 Case를 다시 확인합니다.

평가 결과는 설정을 비교하는 자료로 사용할 수 있지만, 결과 조회만으로 품질 보증이 끝나는 것은 아닙니다.
