에이전트 평가 요약

평가를 여러 번 돌리고 나면 어떤 실행이 어떤 점수였고, 지침을 고치는 동안 점수가 어떻게 바뀌어 왔는지 한눈에 봐야 할 때가 있습니다. 이 페이지는 평가 실행 탭의 실행 목록과 대시보드 탭으로 이메일 초안 도우미의 평가 이력을 요약해 보는 방법을 설명합니다. 데이터셋, 평가기, 실행 하나하나의 자세한 설명은 앞 장에 있습니다.

이 페이지에서 할 수 있는 일

  • 실행 목록에서 실행마다 상태, 데이터셋, 정답률, 오류 건수를 훑어보고 볼 실행을 고릅니다.
  • 대시보드에서 에이전트를 골라 총 실행 횟수, 평균 점수, 데이터셋별 성적, 점수 추이, 평가기별 성능을 확인합니다.
  • 팀에 보고할 실행을 고르기 전에 오류가 섞인 실행을 걸러 냅니다.

평가 실행 목록​

평가 화면의 평가 실행 탭에서 오른쪽 위 에이전트로 에이전트를 고르면 그 에이전트의 실행이 최신순으로 나옵니다. 그림은 이메일 초안 도우미를 고른 모습으로, "이메일 초안 기본 10문항" 데이터셋으로 돌린 #1부터 #4까지 네 실행이 보입니다.

평가 실행 목록

번호메뉴기능이런 때 사용하세요
1에이전트실행 목록을 볼 에이전트를 고릅니다.다른 에이전트의 실행을 볼 때
2평가 시작고른 에이전트로 새 평가를 시작하는 창을 엽니다.지침을 고친 뒤 다시 평가할 때
3데이터 새로고침실행 목록을 다시 불러옵니다.방금 끝난 실행이 목록에 반영됐는지 볼 때

실행마다 첫 줄에 "#4 · 이메일 초안 도우미"처럼 실행 번호와 에이전트 이름, 오른쪽에 상태(대기 중, 실행 중, 완료, 오류, 취소됨, 시간 초과)가 보입니다. 아래 줄 왼쪽에는 "11-12 03:21 · 이메일 초안 기본 10문항"처럼 시작 시각과 데이터셋 이름, 오른쪽에는 "100.0% (50/50)"처럼 정답률이 나옵니다. 목록에서 실행을 누르면 오른쪽에 그 실행의 상세가 열립니다.

오류가 섞인 실행은 목록에서 바로 가려낼 수 있습니다. 아래 그림은 #2를 고른 모습입니다. #2는 문항 5개가 서버 연결 오류로 끝나 정답률이 50.0% (5/10)로 나왔고, 환경 문제로 무효 처리된 실행입니다.

오류가 섞인 실행

번호메뉴기능이런 때 사용하세요
1실행 항목무효로 처리된 실행은 번호 앞에 빨간 점이 붙고, 오류가 있으면 정답률 아래에 "오류 5건 포함"처럼 빨간 글씨가 붙습니다.팀에 보고할 실행을 고르기 전에 오류가 섞인 실행을 걸러 낼 때
2오류 건수실행 상세의 전체 정답률 아래에도 같은 오류 건수가 나옵니다. 오류로 끝난 문항은 오답으로 셉니다.낮은 점수가 답변 품질 탓인지 실행 오류 탓인지 가를 때
3실행 유효성실행이 환경 문제 없이 끝났는지를 정상, 주의, 무효 (환경) 가운데 하나로 보여 줍니다. 그림의 #2는 **무효 (환경)**입니다.점수를 믿어도 되는 실행인지 볼 때

실행이 많으면 목록 아래쪽 쪽 이동 버튼으로 넘깁니다. 실행 상세를 읽는 방법은 평가 결과 읽기와 비교에 있습니다.

대시보드​

대시보드 탭은 평가 이력을 모아 보여 줍니다. 에이전트의 기본값은 전체이고, 에이전트를 고르면 그 에이전트의 실행만 집계합니다. 선택한 범위에 평가가 하나도 없으면 "표시할 평가 데이터가 없습니다."가 나옵니다. 기간을 고르는 칸은 따로 없습니다. 그림은 이메일 초안 도우미를 고른 모습입니다.

대시보드 위쪽

번호메뉴기능이런 때 사용하세요
1에이전트집계할 에이전트를 고릅니다. 전체를 고르면 내 모든 에이전트의 실행이 함께 나옵니다.이메일 초안 도우미 하나만 볼 때
2데이터 새로고침카드, 표, 차트를 모두 다시 불러옵니다.방금 끝난 실행을 반영할 때
3총 실행 횟수고른 범위의 실행 수입니다. 그림에서는 4입니다.지금까지 몇 번 점검했는지 셀 때
4평균 점수고른 범위 실행의 평균 점수입니다. 그림에서는 97%로, 무효 (환경)인 #2의 50.0%는 평균에 들어가지 않았습니다.대략적인 수준을 가늠할 때

데이터셋이 여러 개면 평균 점수 아래에 "데이터셋 2개의 평균입니다. 데이터셋별 결과는 아래에서 확인하세요."가 붙습니다. 평균 점수는 여러 데이터셋과 평가기의 결과를 섞어 계산하므로, 데이터셋별 결과는 바로 아래 데이터셋별 성적에서 봅니다.

데이터셋별 성적

번호메뉴기능이런 때 사용하세요
1집계 기준무엇을 셌는지 알려 줍니다. 그림에서는 "최근 실행 4개 기준 · 완료된 실행만 · 무효·근거 추출 실행 1개 제외"입니다.표의 숫자에 어떤 실행이 들어갔는지 확인할 때
2최근 정답률데이터셋 카드 안에서 에이전트별 가장 최근 실행의 정답률입니다. 그림에서는 100.0%입니다. 누르면 그 실행이 열립니다.지금 지침의 성적을 볼 때
3평균 (범위) · 횟수집계에 들어간 실행들의 평균 정답률, 최저와 최고, 실행 수입니다. 그림에서는 "96.7% (90%–100%) · 3회"입니다.점수가 실행마다 얼마나 흔들리는지 볼 때
4실행별 정답률실행마다의 정답률을 50%부터 100%까지 축 위에 그립니다. 막대는 최저부터 최고, 세로 선은 평균, 파란 점은 최근 실행입니다. 점을 누르면 그 실행이 열립니다.최근 실행이 지난 실행들보다 나아졌는지 볼 때

데이터셋마다 카드가 하나씩 나오고, 카드 오른쪽 위에 "실행 3개"처럼 집계한 실행 수가 보입니다. 평가기가 다른 실행도 같은 데이터셋이면 한 카드에 모입니다. 그림의 카드에는 완전성으로 채점한 #1, #3과 전문성으로 채점한 #4가 함께 들어 있고, 무효인 #2는 빠졌습니다. 카드 아래에는 "정답률은 오류를 오답으로 셉니다."로 시작하는 읽는 법 안내가 붙습니다. 설정을 바꿔 가며 돌린 실행도 같은 에이전트 줄에 표시됩니다.

아래로 내리면 실행 표와 차트가 이어집니다. 에이전트를 전체로 두면 전체 실행 표에 에이전트 열이 더해집니다.

대시보드 아래쪽

번호메뉴기능이런 때 사용하세요
1실행 ID전체 실행 표의 첫 열로, 실행 번호가 최신순으로 나옵니다. 같은 줄에 점수, 상태, 데이터셋, 평가기, 평균 응답 시간, 날짜가 이어집니다. 줄을 누르면 평가 실행 탭의 그 실행 상세로 갑니다.실행 번호와 날짜를 보고서에 옮길 때
2평균 응답 시간문항별 첫 토큰까지 시간(TTFT)의 평균입니다. 제목에 마우스를 올리면 "TTFT가 기록된 문항은 첫 토큰까지 시간, 없는 문항은 전체 소요 시간으로 평균합니다."가 나옵니다. 그림에서는 4.17s부터 8.68s까지입니다.지침을 고친 뒤 응답이 느려졌는지 볼 때
3점수 추이날짜별 평균 점수와 실행 횟수입니다. 그림에서는 네 실행이 한 날짜에 모여 평균 점수 0.97, 실행 횟수 4로 나옵니다.몇 주에 걸친 점수 흐름을 볼 때
4평가기 성능평가기별 실행 횟수와 평균 점수입니다. 그림에서는 전문성 (Professional) 1회 1.00, 완전성 (Completeness) 3회 0.97입니다.완전성과 전문성 결과를 나눠 볼 때

따라 해 보기​

김그루 사원이 박지원 팀장에게 이메일 초안 도우미의 개선 결과를 한 줄로 보고합니다.

  1. 평가 화면에서 대시보드 탭을 엽니다.
  2. 에이전트에서 "이메일 초안 도우미"를 고릅니다.
  3. 데이터셋별 성적에서 "이메일 초안 기본 10문항"의 최근 정답률(100.0%)과 평균 (범위) · 횟수(96.7% (90%–100%) · 3회)를 확인합니다.
  4. 전체 실행 표에서 지침을 고치기 전 실행 #1(90.0% (9/10))과 고친 뒤 실행 #3(100.0% (10/10))의 평가기가 둘 다 완전성 (Completeness)인지 확인합니다. 같은 평가기로 채점한 실행끼리만 비교합니다.
  5. #3 줄을 눌러 실행 상세로 가서, 정답률 아래에 오류 건수가 없고 실행 유효성이 정상인지 확인합니다. 오류 5건이 섞인 #2는 보고에서 뺍니다.
  6. 두 실행의 번호와 정답률을 "#1 90.0% → #3 100.0%"처럼 보고서에 옮깁니다.

팁: 평균 점수는 여러 데이터셋과 평가기의 결과를 섞어 계산할 수 있습니다. 개선 전후를 보고할 때는 같은 데이터셋, 같은 평가기로 채점한 실행의 정답률을 씁니다.
