모니터링과 실행 상태 확인

에이전트에게 일을 맡긴 뒤에는 지금 어디까지 진행됐는지, 얼마나 많은 토큰을 썼는지, 팀에서 얼마나 쓰이고 있는지를 따로 확인해야 할 때가 있습니다. 이 페이지는 사용자 화면에서 이를 확인하는 네 곳, 곧 백그라운드 작업을 보는 작업 화면, 대화 화면의 토큰 사용량, 평가 실행 상태, 워크스페이스 에이전트의 사용량을 이메일 초안 도우미를 예로 설명합니다.

이 페이지에서 할 수 있는 일

  • 작업 화면에서 백그라운드로 맡긴 작업이 끝났는지 상태, 출처, 기간으로 골라 보고, 진행 중인 작업을 취소하거나 기록을 정리합니다.
  • 대화 화면에서 답변 하나와 대화 전체의 입력·출력 토큰을 확인하고, 토큰 사용량 상세 창에서 답변의 지연 시간, 첫 토큰까지 걸린 시간(TTFT), 부른 도구와 도구별 소요 시간, 문의에 쓸 Run ID를 봅니다.
  • 작업과 평가 실행에 표시되는 상태의 뜻을 구분합니다.
  • 워크스페이스 에이전트의 이번 달, 올해, 누적 실행 수와 사용자 수를 확인합니다.

작업 화면​

사이드바 위쪽 더 보기를 누르고 작업을 고르면 "백그라운드 작업" 화면이 열립니다. 진행 중인 작업이 있으면 작업 메뉴 옆에 그 수가 배지로 붙습니다. 대화 입력창에서 백그라운드 모드를 켜고 보낸 요청과 스케줄로 실행된 요청이 여기에 쌓입니다. 그림은 이메일 초안 도우미에게 백그라운드로 맡긴 메일 초안 두 건 가운데 하나가 진행 중인 모습입니다.

백그라운드 작업 화면

번호메뉴기능이런 때 사용하세요
1정리작업 기록을 지우는 메뉴를 엽니다. 삭제된 에이전트 정리는 이미 지운 에이전트의 작업 기록만, 대화 히스토리 전체 삭제는 완료된 작업 기록을 모두 지웁니다. 둘 다 되돌릴 수 없고, 완료된 작업이 없으면 흐리게 보입니다.오래된 작업 기록을 한꺼번에 정리할 때
2작업 기록백그라운드로 실행한 작업 목록입니다. 화면을 열면 이 탭이 먼저 보입니다.맡겨 둔 작업이 끝났는지 볼 때
3스케줄 작업등록된 스케줄을 카드로 봅니다. 카드마다 실행 주기와 타임존, 맡길 요청 문장, 상태, 다음 실행, 실행 횟수가 나옵니다.예약해 둔 실행이 다음에 언제 도는지 볼 때

작업 기록 위쪽에는 필터 세 묶음이 있습니다.

작업 기록 필터

번호메뉴기능이런 때 사용하세요
1상태 필터(전체, 진행중, 완료됨)작업을 진행 상태로 거릅니다. 진행중 옆에는 진행 중인 작업 수가 붙습니다. 그림에서는 1입니다.아직 끝나지 않은 작업만 골라 볼 때
2출처 필터(전체, 수동, 스케줄)직접 보낸 작업과 스케줄로 실행된 작업을 나눠 봅니다. 스케줄로 실행된 작업은 제목 앞에 스케줄 꼬리표가 붙습니다.직접 맡긴 작업만 따로 볼 때
3기간 필터(전체, 1시간, 오늘, 이번 주, 날짜 선택)작업을 맡긴 시점으로 거릅니다. 날짜 선택은 달력에서 날짜를 고르고, 날짜 초기화로 되돌립니다.어제 맡긴 작업만 찾을 때

필터 아래에는 작업이 한 줄씩 나옵니다.

작업 행

번호메뉴기능이런 때 사용하세요
1작업 행시간, 제목, 상태, 에이전트가 보입니다. 제목은 맡길 때 보낸 요청 문장이고, 에이전트 칸에는 에이전트 식별 번호의 끝 여덟 자리가 보입니다. 행을 누르면 결과 대화가 열립니다.결과를 바로 읽으러 갈 때
2취소진행 중인 작업을 멈춥니다. 대기나 진행중 상태일 때만 보입니다. "작업이 취소되었습니다" 안내가 뜹니다.잘못된 요청을 맡긴 것을 알았을 때
3기록에서 삭제(휴지통)이 작업을 작업 기록에서 지웁니다.확인을 마친 작업을 목록에서 치울 때

그림 맨 위 줄은 방금 맡긴 "영업1팀 최하늘 책임에게 12월 데모 일정 후보 세 개를 묻는 메일 초안을 써 줘." 작업으로 진행중이고 취소가 보입니다. 그 아래 줄들은 이미 완료된 작업입니다. 메일 초안 같은 짧은 작업은 몇 초 안에 끝나므로 취소가 보이는 시간도 짧습니다.

작업이 하나도 없으면 "작업이 없습니다"와 "백그라운드 작업을 시작하면 여기에서 확인할 수 있습니다."가 보입니다. 작업이 많으면 아래쪽 쪽 이동 버튼으로 넘깁니다. 백그라운드 모드로 요청을 맡기는 방법과 스케줄을 만드는 방법은 스케줄링과 백그라운드 모드에 있습니다.

따라 해 보기​

  1. 사이드바에서 "이메일 초안 도우미"를 열고 이 에이전트와 새 대화를 누른 뒤, 입력란 아래 오른쪽의 백그라운드 모드(시계 아이콘)를 누릅니다. 마우스를 올렸을 때 "백그라운드 모드 (ON)"으로 보이면 켜진 것입니다.

  2. 아래 요청을 보냅니다.

    프롬프트: AI혁신팀 팀원에게 다음 주 월요일 오전 10시 주간회의 안건(평가 결과 공유, 교육 자료 개편 일정, 12월 파일럿 준비)을 미리 알리는 메일 초안을 써 줘.

  3. 사이드바 더 보기에서 작업을 누릅니다.

  4. 방금 맡긴 작업이 맨 위 줄에 진행중으로 보이는지 확인합니다. 이미 끝났으면 완료로 보입니다.

  5. 상태가 완료로 바뀌면 행을 눌러 결과 대화를 엽니다.

실행 상태의 뜻​

작업 화면과 평가 화면은 같은 일을 조금 다른 말로 표시합니다.

작업 화면평가 실행뜻
대기대기 중실행이 만들어졌고 처리를 기다리고 있습니다.
진행중실행 중처리하고 있습니다. 상태 아이콘이 돌아갑니다.
중단됨(없음)작업이 대화 안에서 멈춰 다음 입력을 기다리는 상태입니다. 행을 눌러 대화를 열고 이어 갑니다. 진행 중 개수에 세지 않고 취소도 보이지 않습니다.
완료완료끝났습니다.
실패오류오류로 중단되었습니다. 평가 실행은 실행 상세 위쪽에 오류 안내와 원본 오류 보기가 나옵니다.
취소됨취소됨사용자가 멈췄습니다. 평가 실행은 그때까지 채점된 결과가 남습니다.
시간 초과시간 초과정해진 시간 안에 끝나지 않아 중단되었습니다.

평가 실행은 작업 화면에 나오지 않습니다. 평가 진행 상황과 취소는 평가 화면의 평가 실행 탭에서 봅니다. 자세한 내용은 평가 실행에 있습니다.

대화 화면의 토큰 사용량​

에이전트와 대화하면 대화 화면 맨 위 오른쪽에 이 대화에 쓰인 모델 이름이 보이고, 답변이 하나라도 끝나면 그 아래에 이 대화 전체의 입력·출력 토큰 합계가 붙습니다. 답변마다 오른쪽 아래에도 그 답변 하나의 토큰 수가 작은 배지로 붙습니다. 그림은 이메일 초안 도우미에게 아래 두 요청을 차례로 보낸 대화입니다.

프롬프트: 박지원 팀장님께 11월 14일(금) 오전까지 주간 업무 보고서를 제출하겠다고 알리는 짧은 메일 초안을 써 줘.

프롬프트: 조금 더 정중한 말투로 바꿔 줘.

대화 화면의 토큰 사용량

번호메뉴기능이런 때 사용하세요
1모델과 대화 합계첫 줄은 이 대화에 쓰인 모델 이름, 둘째 줄은 대화 전체의 입력 토큰과 출력 토큰 합계입니다. 그림에서는 "OpenAI/GPT-4.1"과 입력 27.9K, 출력 227입니다. 누르면 "스레드 토큰 요약" 창이 열립니다.긴 대화가 토큰을 얼마나 썼는지 볼 때
2답변 토큰 배지이 답변 하나의 입력 토큰과 출력 토큰입니다. 그림의 두 번째 답변은 "14.0K · 137"입니다. 비용 정보가 있으면 함께 보입니다. 마우스를 올리면 Model, Input, Output, Total 네 줄로 모델 이름과 토큰 수가 나오고, 누르면 "토큰 사용량 상세" 창이 열립니다.특정 답변이 유난히 길었는지 볼 때

토큰 사용량 상세​

답변 토큰 배지를 누르면 "토큰 사용량 상세" 창이 열립니다. 창 제목 아래에 이 답변을 만든 모델 이름이 보이고, 위에서부터 토큰, 성능, 도구 사용, 추적 정보 순서로 나옵니다.

  • 토큰: 이 답변의 입력, 출력, 합계 토큰입니다. 1,000 이상은 "12.3K"처럼 줄여 보입니다. 캐시를 쓴 답변이면 아래에 캐시 읽기, 캐시 생성 토큰도 나옵니다.
  • 성능: **지연 시간:**은 이 답변을 만드는 데 걸린 전체 시간이고, **TTFT:**는 질문을 보낸 뒤 답변의 첫 토큰이 나오기까지 걸린 시간입니다. 1초 미만은 "850ms", 1초 이상은 "3.42s"처럼 표시됩니다. TTFT는 0.5초 미만이면 초록, 2초까지는 노랑, 2초를 넘으면 빨강 글씨로 보여 답이 늦게 시작됐는지 한눈에 알 수 있습니다. 시간이 기록되지 않은 답변에는 성능이 나오지 않습니다.
  • 도구 사용: 제목 옆 괄호에 이 답변에서 도구를 부른 횟수가 나오고, 아래에 부른 도구 이름이 하나씩 표시됩니다. 도구마다 걸린 시간과, 도구 실행 시간 전체에서 그 도구가 차지한 비율(%)이 함께 보이므로 어느 도구에서 시간이 많이 걸렸는지 알 수 있습니다. 도구를 부르지 않은 답변에는 도구 사용이 나오지 않습니다.
  • 추적 정보: Run ID(답변 하나의 실행 번호), Thread ID(대화 번호), Trace ID(기록된 경우에만), 생성 시간, 상태입니다. 번호는 전체 값으로 나오고 그 자리에서 복사할 수 있습니다. 관리자에게 문의할 때 쓰는 Run ID는 여기서 복사합니다.

실패한 답변이면 추적 정보 위에 실패 사유 안내가 함께 나옵니다. 아래 그림은 두 번째 답변의 창입니다. 도구를 부르지 않은 답변이라 도구 사용이 없고, 캐시를 쓴 답변이라 캐시 읽기와 캐시 생성이 보입니다.

토큰 사용량 상세

번호메뉴기능이런 때 사용하세요
1토큰이 답변의 입력, 출력, 합계 토큰입니다. 그림에서는 14.0K, 137, 14.2K이고, 아래에 "캐시 읽기: 13.8K (99%)"와 "캐시 생성: 0"이 붙었습니다.답변 하나의 사용량을 정확한 숫자로 볼 때
2성능지연 시간과 TTFT(첫 토큰까지 걸린 시간)입니다. 기록된 값만 나오며, 그림에서는 TTFT 1.59s만 보입니다.답이 늦게 시작된 이유를 가늠할 때
3추적 정보Run ID, Thread ID, Trace ID(기록된 경우에만), 생성 시간, 상태입니다. 그림의 상태는 성공입니다.관리자에게 특정 답변의 처리 기록을 알려 줄 때

스레드 토큰 요약​

대화 화면 오른쪽 위 모델과 대화 합계를 누르면 "스레드 토큰 요약" 창이 열립니다. 이 대화의 Thread ID, 대화 전체의 입력, 출력, 합계 토큰, 총 턴 수(답변 횟수)와 턴당 평균 입력·출력 토큰이 나옵니다. 아래 턴별 상세 표에는 답변마다 순번, Run ID, 모델, 입력·출력 토큰, 상태(성공 또는 실패)가 한 줄씩 나옵니다. 이 표의 Run ID는 앞 여덟 자리만 보이며, 줄을 누르면 그 답변의 토큰 사용량 상세 창이 열립니다.

스레드 토큰 요약

번호메뉴기능이런 때 사용하세요
1Thread ID이 대화의 식별 번호입니다. 오른쪽 복사 단추로 복사합니다.관리자에게 대화를 특정해 알려 줄 때
2입력, 출력, 합계대화 전체의 토큰 합계입니다. 그림에서는 27.9K, 227, 28.2K입니다.대화 하나가 쓴 전체 양을 볼 때
3총 턴 수, 턴당 평균답변 횟수와 답변 한 번에 쓴 평균 입력·출력 토큰입니다. 그림에서는 2와 "14.0K / 114"입니다.대화가 길어질수록 답변당 사용량이 늘었는지 볼 때
4턴별 상세답변마다 Run ID 앞 여덟 자리, 모델, 입력·출력 토큰, 상태가 한 줄씩 나옵니다. 그림에서는 첫 답변 13.9K / 90, 두 번째 답변 14.0K / 137이고 둘 다 성공입니다. 줄을 누르면 그 답변의 토큰 사용량 상세 창이 열립니다.어느 답변에서 사용량이 크게 늘었는지 찾을 때

이럴 때 쓰세요: 한 대화에서 회의록 여러 건을 이어 요약하다가 답이 느려졌다고 느끼면, 김그루 사원은 스레드 토큰 요약을 열어 턴별 상세의 입력 토큰이 턴마다 커지고 있는지 봅니다. 앞 대화를 계속 다시 읽느라 입력이 불어난 것이라면 새 대화로 나눠 이어 가거나, 에이전트 편집 화면 설정 탭의 Context Compaction에서 압축 시작 비율을 낮춥니다.

팁: 사용량이 유난히 큰 답변을 턴별 상세에서 찾으면 그 줄을 눌러 토큰 사용량 상세 창을 열고, 추적 정보의 Run ID 전체 값을 복사해 관리자에게 문의할 때 함께 알려 줍니다. 대화 화면의 다른 기능은 대화 화면과 채팅 목록에 있습니다.

워크스페이스 에이전트 사용량​

워크스페이스에 등록된 에이전트는 팀에서 얼마나 쓰이는지 사용량을 볼 수 있습니다. 사이드바 위쪽 에이전트 템플릿을 누르면 회사 이름 탭(그림에서는 브레인크루)과 워크스페이스 탭이 보입니다. 등록된 에이전트 카드를 누르면 상세 창이 열리고, 창 안의 사용량 표에 이번 달, 올해, 누적 기간별로 실행 횟수("회")와 사용자 수("명")가 나옵니다. 표 아래에는 "2026.11.12 03:45 기준"처럼 집계 시점이 보이고, 집계되지 않은 칸은 "-"로 보입니다. 아직 사용량이 하나도 집계되지 않은 에이전트에는 사용량 표가 보이지 않습니다. 한 번 대화한 워크스페이스 에이전트는 사이드바 워크스페이스 에이전트 탭에도 모이지만, 사용량 표는 에이전트 템플릿의 상세 창에서 봅니다. 그림은 브레인크루 탭에 등록된 주간 업무 보고서 도우미의 상세 창입니다.

4누적지금까지 쌓인 전체 실행 횟수와 사용자 수입니다. 집계하지 못한 칸은 "-"로 보입니다.에이전트를 계속 운영할지 판단할 때

이럴 때 쓰세요: 김그루 사원은 분기 보고에 AI혁신팀이 공유한 에이전트의 활용 실적을 넣을 때, 에이전트 템플릿에서 카드마다 상세 창을 열어 이번 달과 누적의 실행 횟수와 사용자 수를 옮겨 적습니다. 실행은 많은데 사용자가 한두 명뿐이면 팀에 덜 알려진 것이므로 라운지 커뮤니티 게시판에 소개 글을 올리고, 몇 달째 실행이 거의 없는 에이전트는 비공개로 돌릴지 팀과 의논합니다.

워크스페이스 에이전트를 찾아 쓰는 방법은 즐겨찾기·워크스페이스·다운로드에 있습니다.

정리​

  • 백그라운드로 맡긴 대화와 스케줄 실행은 작업 화면, 평가는 평가 실행 탭에서 상태를 봅니다.
  • 대화 화면 오른쪽 위에는 대화 전체 토큰, 답변 아래에는 답변 하나의 토큰이 보이고, 누르면 상세 창이 열립니다.
  • 워크스페이스 에이전트의 이번 달, 올해, 누적 실행 수와 사용자 수는 에이전트 템플릿의 상세 창 사용량에서 봅니다.
