MCP와 에이전트의 MCP화

MCP(Model Context Protocol)는 AI 도구와 에이전트가 서로를 부를 때 쓰는 공통 연결 방식입니다. Deep Agent Builder에서는 MCP를 두 방향으로 씁니다. 바깥의 MCP 서버를 도구로 등록해 에이전트가 쓰게 하는 방향과, 내가 만든 에이전트를 MCP 서버로 열어 MCP 호환 클라이언트에서 부르게 하는 방향입니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원의 사내 규정 Q&A 도우미를 예로 두 방향을 모두 설명합니다.

이 페이지에서 할 수 있는 일

  • MCP가 쓰이는 두 방향을 구분합니다.
  • 에셋 화면 도구 탭의 도구 추가 메뉴에서 MCP Remote, Zapier, Dify, n8n, Connect MCP 서버를 도구로 등록하고 연결 테스트로 확인합니다.
  • 등록한 MCP 도구의 서브 도구 조회로 하위 도구를 가져오고, 에이전트 도구함에 붙입니다.
  • 에이전트 편집 화면 설정 탭에서 MCP 서버 활성화를 켜고 서버 이름과 설명을 정합니다.
  • 연결 JSON을 복사해 MCP 호환 클라이언트에 넣고, 필요 없으면 MCP 서버 비활성화로 닫습니다.

MCP가 쓰이는 두 방향​

방향하는 일설정하는 곳브레인크루 예
MCP 서버를 도구로 쓰기바깥 MCP 서버가 제공하는 기능을 에이전트가 도구처럼 부릅니다.에셋 화면의 도구 탭에서 도구 추가팀이 n8n에 만든 일정 등록 워크플로우를 시장 조사 리서처가 부름
에이전트를 MCP 서버로 열기내 에이전트를 다른 MCP 호환 클라이언트에서 부를 수 있게 엽니다.에이전트 편집 화면 설정 탭의 MCP 서버김그루 사원이 쓰는 MCP 호환 데스크톱 앱에서 사내 규정 Q&A 도우미에게 바로 질문

MCP 서버를 도구로 등록하기​

사이드바의 에셋설정을 눌러 여는 에셋 화면의 도구 탭에서 도구 추가를 누르면 MCP 서버 종류별 항목이 보입니다.

메뉴넣는 값알아 둘 점
MCP RemoteURL, 헤더 (JSON), 환경 변수JSON 가져오기로 MCP 설정 JSON을 붙여 넣으면 값이 채워집니다. 한 번에 서버 하나만 가져올 수 있습니다.
Zapier MCP ServerZapier가 준 Connect URLURL에 키가 들어 있으므로 비밀번호처럼 다룹니다.
Dify MCP ServerDify MCP 서버 URLURL은 /mcp로 끝나야 합니다.
n8n MCP Servern8n MCP 서버 URL, 인증 토큰토큰은 환경변수로 추가(등록해 둔 시크릿에서 값을 불러옴) 또는 직접 입력 중에서 고릅니다.
Connect MCP ServerURL, TokenToken에는 발급받은 토큰 값만 그대로 넣습니다. 앞에 다른 글자를 붙이지 않습니다.

모든 종류에서 도구 이름은 영문 소문자로 시작하고 소문자, 숫자, 밑줄(_)만 쓸 수 있으며 만든 뒤에는 바꿀 수 없습니다.

종류를 고르면 새 도구 추가 창이 열립니다. 도구 이름(예: braincrew_n8n_calendar), 설명, 위 표의 값을 넣고, 창 아래 연결 테스트로 연결을 확인한 뒤 생성을 누릅니다. 연결 테스트는 연결 성공 또는 연결 실패를 보여 주고, 10초가 지나면 시간 초과로 끝납니다. MCP Remote는 JSON 가져오기를 눌러 열리는 MCP 설정 가져오기 창에 다른 MCP 클라이언트용 설정 JSON을 붙여 넣어 값을 채울 수도 있습니다.

서브 도구 조회​

MCP 서버 하나에는 여러 기능(하위 도구)이 들어 있습니다. 등록 직후에는 하위 도구 정보가 비어 있을 수 있으므로, 도구 상세의 테스트를 눌러 하위 도구를 먼저 가져옵니다. 테스트 창에 "이 MCP 도구는 아직 서브 도구 정보가 없습니다. 먼저 서브 도구를 조회하세요."가 보이면 서브 도구 조회를 누릅니다. 끝나면 "서브 도구 조회가 완료되었습니다." 알림이 뜹니다. 이어서 **세부 도구 (sub-tool)**에서 시험할 하위 도구를 고르고, **Arguments (JSON)**에 넘길 값을 넣거나 AI 자동채우기로 채운 뒤 테스트 실행을 누르면 실행 결과가 보입니다.

조회했는데 하위 도구가 없으면 "서브 도구를 조회했지만 등록된 서브 도구가 없습니다."가, 실패하면 "서브 도구 조회에 실패했습니다."가 보입니다. 이때는 URL과 인증 값을 다시 확인합니다. 하위 도구 조회에 성공했다고 실제 호출이 성공한 것은 아니므로, 하나라도 테스트 실행까지 해 봅니다.

등록한 MCP 도구는 일반 도구와 같이 에이전트 편집 화면 도구함의 + 도구로 붙입니다. 붙인 뒤 도구 설정 창의 서브 도구에서 하위 도구별 값을 에이전트마다 다르게 정할 수 있습니다. 자세한 과정은 도구와 스킬 구성에 있습니다.

에이전트를 MCP 서버로 열기​

에이전트 편집 화면 오른쪽 설정 탭에서 Recursion Limit 아래에 MCP 서버 묶음이 있습니다. 안내 문구는 MCP 서버를 활성화하면 MCP 호환 클라이언트(예: Claude Desktop, Cursor)에서 이 에이전트를 사용할 수 있다는 내용입니다.

MCP 서버 활성화 스위치를 켜면 서버 이름과 설명 칸이 나타납니다. 스위치만 켜서는 열리지 않고, 아래 MCP 서버 활성화 버튼을 눌러야 열립니다. 서버 이름은 클라이언트에 보일 이름으로 영문, 숫자, _, -, . 만 쓸 수 있습니다(예: braincrew-policy-qa). 설명에는 이 서버가 무엇을 하는지 적습니다(예: 브레인크루 사내 규정 Q&A). 이미 열려 있으면 버튼이 MCP 설정 업데이트로 바뀝니다. 이 묶음의 설정은 헤더 저장이 아니라 이 버튼으로 반영됩니다.

서버 이름이 비었거나 규칙에 맞지 않으면 버튼을 누를 수 없습니다. 열리면 "MCP 서버가 활성화되었습니다" 알림이 뜹니다.

연결 JSON 복사​

MCP 서버가 열리면 같은 묶음 아래에 연결 JSON이 나타납니다. MCP 호환 클라이언트의 MCP 서버 설정에 이 JSON을 넣으면 클라이언트가 이 에이전트를 부를 수 있습니다. JSON에는 서버 주소와 인증 자리가 들어 있습니다. 복사를 누르면 버튼이 잠시 **복사됨!**으로 바뀌고 "연결 JSON이 클립보드에 복사되었습니다" 알림이 뜹니다.

JSON 안의 API 키 자리는 비어 있는 표시일 뿐이므로, 에셋 화면의 API 키 탭에서 발급한 키로 바꿔 넣어야 합니다. API 키 발급은 코드 스니펫과 외부 API에서 설명합니다. 키를 넣은 JSON은 다른 사람에게 그대로 보내지 마세요.

MCP 서버 닫기​

더 이상 외부 클라이언트에서 쓰지 않으면 MCP 서버 활성화 스위치를 끕니다. 그러면 빨간 MCP 서버 비활성화 버튼이 나타나고, 눌러야 실제로 닫힙니다. 닫히면 "MCP 서버가 비활성화되었습니다" 알림이 뜨고, 기존 연결 JSON으로는 더 이상 부를 수 없습니다.

따라 해 보기: 사내 규정 Q&A 도우미를 MCP 서버로 열기​

  1. 사이드바에서 사내 규정 Q&A 도우미를 누르고 에이전트 설정을 누릅니다.

  2. 오른쪽 설정 탭을 누르고 MCP 서버 묶음으로 스크롤합니다.

  3. MCP 서버 활성화 스위치를 켭니다.

  4. 서버 이름에 braincrew-policy-qa, 설명에 "브레인크루 사내 규정 Q&A"를 입력합니다.

  5. MCP 서버 활성화 버튼을 누르고 알림을 확인합니다.

  6. 연결 JSON의 복사를 눌러 MCP 호환 클라이언트의 MCP 서버 설정에 붙여 넣고, API 키 자리를 내 API 키로 바꿉니다.

  7. 클라이언트에서 아래 프롬프트로 질문해 답이 오는지 확인합니다.

    프롬프트: 브레인크루 출장비 규정 2026년판에서 국내 출장 일비는 하루 얼마인가요?

열기 전에 확인할 것​

  • MCP 서버로 연 에이전트는 키를 가진 사람이면 클라이언트에서 부를 수 있습니다. 키는 필요한 사람에게만 발급하고, 쓰지 않는 키는 API 키 탭에서 지웁니다.
  • 에이전트가 쓰는 지식과 도구가 그대로 쓰이므로, 바깥에 알려도 되는 범위의 에이전트인지 먼저 확인합니다.
  • 서버 이름을 바꾼 뒤에는 MCP 설정 업데이트를 누르고, 클라이언트 쪽 설정도 새 JSON으로 바꿉니다.
  • 클라이언트 쪽 설정 방법은 각 클라이언트 제품의 안내를 따릅니다. 이 매뉴얼에서는 다루지 않습니다.
