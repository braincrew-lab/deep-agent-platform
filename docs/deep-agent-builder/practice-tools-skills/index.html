Deep Agent Builder 실습 3: 도구와 스킬 붙이기

이 실습은 실습 1에서 만든 고객 문의 답장 도우미에 두 가지를 더합니다. 하나는 사내 지식을 찾아 근거를 붙이는 도구, 다른 하나는 답장 형식을 정해 두는 스킬입니다. 브레인크루 AI혁신팀 김그루 사원이 답장 규칙 스킬 ZIP을 올리고, 에이전트에 켜고, 대화에서 도구와 스킬이 실제로 쓰이는지 확인하는 순서로 진행합니다. 도구 등록 화면 전체는 도구 등록 화면, 스킬 파일 구성은 스킬 만들기와 업로드에 있습니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면의 도구함과 미들웨어 칸에서 붙어 있는 도구와 설정 버튼을 찾습니다.
  • 에셋 화면 스킬 탭에서 SKILL.md가 든 ZIP을 올립니다.
  • 에이전트 편집 화면 스킬 탭의 일반 스킬에서 스킬을 켭니다.
  • 대화 화면 입력란의 스킬 버튼으로 스킬을 골라 부르고, 실행 기록에서 도구·스킬 호출을 확인합니다.

목표​

항목내용
바꿀 것고객 문의 답장 도우미에 사내 지식 검색 도구 확인, 답장 규칙 스킬 추가
결과물첫 줄에 문의 유형 표시, 사내 제품 자료를 근거로 인용, 정해진 마무리 문장으로 끝나는 답장
걸리는 시간스킬 올리기 3분, 켜기 1분, 시험 3분
난이도★★☆☆☆

준비물​

파일내용형식
customer_reply_rules.zip폴더 customer_reply_rules 안에 SKILL.md 한 개. 이름(name)은 customer_reply_rules, 설명(description)은 "브레인크루 고객 문의 답장 규칙". 본문은 유형 표시, 세 단락, 확정 금지 표시, 마무리 문장 네 규칙zip

SKILL.md는 맨 위에 name과 description을 적고 그 아래에 규칙을 쓰는 마크다운 파일입니다. 스킬 업로드 창은 .md 파일 여러 개 또는 .zip 파일 1개를 받으며, 어느 쪽이든 SKILL.md가 반드시 들어 있어야 합니다. ZIP 안의 파일 하나는 256KB 이하, 항목은 5,000개 이하, 폴더 깊이는 10단계 이하여야 합니다.

사내 지식 검색 도구 deep_connector_kb는 김그루 사원의 에셋 화면 도구 탭에 이미 등록되어 있습니다(Deep Connector가 발급한 MCP 토큰으로 연결한 도구). 새로 등록하는 방법은 도구 등록 화면에서 설명합니다.

1단계. 붙어 있는 도구와 미들웨어 확인하기​

도구함과 미들웨어 칸

번호메뉴기능이런 때 사용하세요
1+ 도구에셋에 있는 도구를 골라 이 에이전트의 도구함에 붙입니다.다른 도구를 더 붙일 때
2도구 설정(톱니)deep_connector_kb의 "도구 설정" 창을 엽니다. 서브 도구 목록과 각 파라미터의 기본값, 고급 설정(에이전트 재정의)이 있습니다.이 에이전트만 검색 개수 같은 값을 다르게 쓸 때
3미들웨어 설정(톱니)실습 1에서 빌더가 붙인 도구 재시도 미들웨어의 설정 창을 엽니다.재시도 횟수를 바꿀 때
  1. 사이드바에서 고객 문의 답장 도우미를 누르고 에이전트 설정을 누릅니다.
  2. 폼 보기 아래쪽 도구함에 deep_connector_kb가, 미들웨어 칸에 도구 재시도가 있는지 확인합니다. 칸이 좁으면 그림처럼 이름이 "d..."나 "도"로 잘려 보이니, 칸 사이 경계를 끌어 넓히면 전체 이름이 보입니다.
  3. 도구 설정을 눌러 서브 도구가 17개(search_documents, read_document 등) 보이는지 확인하고 취소로 닫습니다.

도구 설정 창의 파라미터는 처음에 모두 "기본값 해제 (상속)"입니다. 비워 두면 도구의 기본값을 쓰고, 고급 설정을 펼쳐 값을 적으면 이 에이전트에서만 그 값을 씁니다. 창 아래 안내대로 "재정의 값은 기본 설정과 병합되며, 기본값과 동일한 값은 저장되지 않습니다."

2단계. 스킬 ZIP 올리기​

스킬 업로드 창

번호메뉴입력하거나 고를 값
1파일customer_reply_rules.zip을 끌어 놓거나 눌러서 고릅니다.
2스킬 이름ZIP을 올리면 SKILL.md의 name(customer_reply_rules)으로 자동으로 채워지고 고칠 수 없습니다.
3스킬 설명고객 문의 답장의 유형 표시, 세 단락 구성, 확정 금지 표시, 마무리 문장 규칙 (200자까지, 선택)
4업로드스킬을 만듭니다. "스킬이 업로드되었습니다" 알림이 뜹니다.
  1. 사이드바 에셋설정을 누르고 스킬 탭을 엽니다.
  2. 위쪽 스킬 업로드를 누르고 표대로 채운 뒤 업로드를 누릅니다. 스킬 종류는 일반 그대로 둡니다. 종류를 바꾸면 3단계에서 일반 스킬 하위 탭에 보이지 않습니다.

.md 파일을 올릴 때는 스킬 이름을 직접 적습니다. 영문 소문자로 시작하고 소문자, 숫자, 밑줄, 하이픈만 쓸 수 있으며 64자까지입니다. 같은 이름의 내 스킬이 이미 있으면 동일한 이름의 내 스킬을 덮어쓰기를 체크해야 바뀝니다. 덮어쓰면 그 스킬을 쓰는 모든 에이전트가 바뀐 내용을 쓰고 되돌릴 수 없습니다.

3단계. 에이전트에 스킬 켜기​

스킬 탭에서 스킬 켜기

번호메뉴입력하거나 고를 값
1스킬오른쪽 탭 줄에서 누릅니다. "에이전트에서 사용할 스킬을 선택하세요"가 보입니다.
2일반 스킬하위 탭을 고릅니다. 업로드한 스킬은 종류가 일반이라 여기 보입니다. 문서 작성 스킬은 문서작성 에이전트가 쓰는 양식 스킬입니다.
3스킬 스위치customer_reply_rules 줄의 스위치를 켭니다. 켜는 즉시 반영됩니다.
  1. 고객 문의 답장 도우미 편집 화면에서 스킬 탭 → 일반 스킬을 엽니다.
  2. customer_reply_rules 스위치를 켭니다.
  3. 헤더에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 눌러 현재 버전에도 기록합니다.

4단계. 사내 지식을 근거로 답하게 하기​

에이전트 화면에서 이 에이전트와 새 대화를 누르고 아래 문의를 보냅니다.

프롬프트: 라마바유통 최은지 대리 문의: 귀사 제품 소개 자료에 나온 회의록 요약 솔루션이 어떤 기능을 제공하는지, 그리고 30명 기준 견적을 받을 수 있는지 알려 주세요. 사내 지식에서 제품 소개 자료를 찾아 근거로 답장 초안을 써 주세요.

도구 호출과 답장

번호항목확인할 것
1deep_connector_kb__search_documents사내 지식 검색 도구가 불렸는지와 걸린 시간(이 실습은 15.6초). 눌러 펼치면 보낸 검색어가 보입니다.
2출력 (deep_connector_kb__search_documents)검색 결과입니다. 펼치면 찾은 문서 조각이 보입니다.
3답장 단락견적·계약 조건·일정을 "[담당자 확인 필요]"로 남겼는지

이 실습의 답장은 "문서(회의록 포함) 업로드 시 자동으로 파싱, 정리 및 요약을 제공"한다는 기능 설명에 "(출처: 크루도큐 사용설명서)"를 붙였고, 30명 기준 견적은 "[담당자 확인 필요]"로 남겼습니다. 사내 지식 검색은 문서를 다시 순위 매기는 단계가 있어 10초 넘게 걸릴 수 있습니다.

5단계. 스킬을 골라 부르기​

에이전트에 켠 스킬은 질문에 맞을 때 에이전트가 스스로 불러 씁니다. 꼭 쓰게 하고 싶으면 입력란 아래 스킬 버튼으로 직접 고릅니다.

스킬 버튼으로 스킬 고르기

번호메뉴입력하거나 고를 값
1스킬입력란 아래 왼쪽 네 번째 버튼입니다. 이 에이전트에 켠 스킬 목록이 열립니다. 일반 스킬뿐 아니라 문서 작성 스킬 하위 탭에서 켜 둔 스킬도 함께 보이므로, 그림처럼 customer_reply_rules 말고 다른 스킬이 보일 수 있습니다.
2customer_reply_rules고르면 "customer_reply_rules 스킬을 사용하여 답변해 주세요." 메시지가 바로 보내집니다.

결과​

스킬을 적용한 답장

번호항목확인할 것
1스킬 불러오기에이전트가 스킬 내용을 읽었다는 실행 기록입니다. 바로 위 스킬 목록은 쓸 수 있는 스킬을 확인한 기록입니다.
2유형 표시첫 줄이 스킬 규칙 1대로 "[제품 기능]"인지
3마무리 문장스킬 규칙 4의 문장 "추가로 궁금하신 점이 있으면 언제든 회신 주세요. 브레인크루 AI혁신팀 드림"으로 끝났는지

같은 문의라도 스킬을 쓰기 전에는 유형 표시와 정해진 마무리 문장이 없었고, 스킬을 쓴 뒤에는 첫 줄 유형 표시, 기능 설명과 견적 안내 단락, 마무리 문장이 규칙대로 나왔습니다. 모델의 답은 실행마다 조금씩 다를 수 있으니, 스킬을 불렀다는 기록만 믿지 말고 규칙 네 가지를 답과 하나씩 대조하세요.

설정값 표​

설정위치이 실습의 값기본값과 의미
도구폼 보기 도구함deep_connector_kb(서브 도구 17개)처음에는 비어 있습니다. 붙인 도구의 서브 도구는 모두 쓸 수 있는 상태로 붙습니다.
도구 파라미터도구 설정 창바꾸지 않음"기본값 해제 (상속)" — 도구 기본값을 씁니다. 고급 설정의 에이전트 재정의가 기본값보다 우선합니다.
미들웨어폼 보기 미들웨어도구 재시도실패한 도구 호출을 최대 3번까지 다시 시도합니다(첫 대기 1초). 값의 뜻은 미들웨어와 개인정보 보호에 있습니다.
스킬스킬 탭 일반 스킬customer_reply_rules 켬업로드만 하면 꺼진 상태입니다. 켜야 이 에이전트가 씁니다.
덮어쓰기스킬 업로드 창끔기본은 끔. 켜면 같은 이름의 내 스킬을 업로드 내용으로 바꿉니다.

이럴 때 쓰세요: 브레인크루 영업팀과 AI혁신팀은 각자 답장 에이전트를 쓰지만 마무리 문장과 확정 금지 규칙은 같아야 합니다. 김그루 사원은 규칙을 스킬 하나로 올려 두고 두 에이전트에 모두 켜 둡니다. 규칙이 바뀌면 스킬만 덮어쓰기로 다시 올리면 두 에이전트가 함께 바뀝니다.

흔한 실수와 해결​

증상원인해결
ZIP을 올렸더니 거부됩니다.SKILL.md가 없거나, 파일 하나가 256KB를 넘거나, 허용하지 않는 파일이 들어 있습니다.압축을 풀어 SKILL.md 위치와 파일 크기를 확인합니다. 거부 이유는 스킬 만들기와 업로드에 정리되어 있습니다.
업로드한 스킬이 스킬 탭에 보이지 않습니다.문서 작성 스킬 하위 탭을 보고 있습니다.일반 스킬을 누릅니다.
입력란 스킬 목록에 스킬이 없습니다.에이전트에서 스킬을 켜지 않았습니다.편집 화면 스킬 탭에서 스위치를 켭니다.
사내 지식 검색이 결과 없이 끝납니다.질문에 문서 이름이나 주제어가 빠졌거나, 도구 토큰의 컬렉션 권한이 없습니다.질문에 "제품 소개 자료"처럼 주제를 적습니다. 그래도 같으면 도구 담당자에게 컬렉션 권한을 확인합니다.
견적 금액을 확정해서 답합니다.사내 자료에 요금 예시가 있어 그대로 인용했습니다.스킬이나 지침에 "자료에 금액이 있어도 확정 견적으로 쓰지 않는다"를 더합니다.

응용 과제​

  1. 스킬 규칙에 "답장 맨 아래에 참고한 문서 이름을 한 줄로 적는다"를 더해 동일한 이름의 내 스킬을 덮어쓰기로 다시 올리고, 답이 바뀌는지 보세요.
  2. 도구 설정의 고급 설정에서 search_documents의 limit 값을 3으로 재정의하고, 답의 근거 수가 달라지는지 비교해 보세요.
  3. 에셋 화면 스킬 탭 오른쪽 AI 스킬 어시스턴트에 "회의록 요약 스킬을 만들어 주세요"라고 요청해, 파일 없이 스킬을 만들어 보세요.
