사례: 주간 업무 보고서 작성

이 페이지는 김그루 사원이 한 주 동안 적어 둔 업무 메모를 주간 업무 보고서 도우미에 올려, "제목, 이번 주 핵심 성과 3줄, 업무별 진행 표, 이슈와 조치, 다음 주 계획, 확인 필요" 양식의 주간 보고서로 받는 과정을 따라 합니다. 매주 같은 요청을 짧게 보내는 커맨드와, 매주 금요일 오후에 보고서 초안을 자동으로 만드는 스케줄까지 설정합니다.

이 페이지에서 할 수 있는 일

  • 대화로 주간 업무 보고서 도우미를 만들고 보고서 양식을 지침에 고정합니다.
  • 업무 메모 파일을 올려 정해진 양식의 주간 보고서를 받습니다.
  • 매주 보내는 요청을 커맨드로 저장하고 입력창에서 / 로 불러 씁니다.
  • 매주 금요일 17시에 보고서 초안을 만드는 스케줄을 등록합니다.

목표​

항목내용
입력김그루 사원의 한 주 업무 메모(11/2~11/6, 요일별 한 줄씩)
받는 결과제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 여섯 부분으로 된 주간 보고서
반복 방법커맨드로 매주 같은 요청 보내기, 금요일 17시 스케줄로 자동 작성

준비물​

준비할 것내용
예시 파일김그루_주간업무메모_1106.md (가상 자료)
파일 내용월~금 업무 5줄, 이슈 1줄, 다음 주 계획 1줄
대화에 같은 방법으로 올릴 수 있는 형식.md, .markdown, .txt, .html, .htm(10MB 이하), .docx, .pdf, .hwp, .hwpx, .jpg, .jpeg, .png, .gif, .webp(20MB 이하), .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt(50MB 이하). 한 번에 최대 10개
스케줄용으로 에이전트 파일 탭에 올릴 수 있는 형식대화 첨부와 같습니다: .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (형식별 크기 한도도 같고, 에이전트당 최대 50개)
에이전트 모드일반 에이전트
따로 연결할 도구없습니다.

메모 형식은 자유입니다. 요일별로 한 줄씩 적고, 숫자(문의 건수, 참석 인원)는 메모에 직접 적어 두면 보고서에 그대로 옮겨집니다.

에이전트 만들기​

주간 업무 보고서 도우미는 새 에이전트 화면에서 빌더와 대화해 만듭니다. 보고서 양식과 지켜야 할 규칙을 처음 요청에 모두 적고, 빌더의 확인 질문에 답한 뒤 도구·미들웨어·스킬·서브에이전트 추천을 승인 또는 수정 요청합니다. 요청 입력부터 바로 이용하기까지의 화면과 순서는 에이전트 만들기의 "대화로 만들기"에서 이 에이전트를 예로 들어 그대로 보여 줍니다.

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 입력창에 아래 문장을 붙여 넣고 전송을 누릅니다.

    프롬프트: 매주 금요일에 내 업무 메모를 받아 주간 업무 보고서를 써 주는 "주간 업무 보고서 도우미"를 만들고 싶어요. 보고서는 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 고정하고, 개조식으로 적어 주세요. 메모에 있는 숫자는 그대로 쓰고, 메모에 없는 숫자나 일정은 지어내지 말고 "확인 필요"로 남겨 주세요. 보고 대상은 AI혁신팀 박지원 팀장입니다.

  3. 확인 질문에 답합니다. 이름을 묻는 질문이 나오면 직접 입력으로 "주간 업무 보고서 도우미"를 적습니다.

  4. 추천 카드를 읽고 승인 또는 수정 요청을 누릅니다. 이 에이전트는 첨부한 메모만 정리하면 되므로 도구가 없어도 됩니다.

  5. 빌더가 완성을 알리면 바로 이용하기를 누릅니다.

팁: 만든 뒤 지침을 고치고 싶으면 사이드바에서 주간 업무 보고서 도우미를 누르고 에이전트 설정을 눌러 에이전트 편집 화면을 엽니다. 가운데 지침 칸을 직접 고친 뒤 헤더의 저장을 누르거나, 오른쪽 Fix 에이전트 탭에 바꿀 내용을 말로 적습니다. 방법은 Fix 에이전트에 있습니다.

단계별 실행​

1단계. 업무 메모로 보고서 받기​

주간 업무 보고서 도우미와 새 대화를 열고 업무 메모 파일을 첨부해 이번 주 보고서를 요청합니다.

업무 메모 첨부와 보고서 요청

번호메뉴기능이런 때 사용하세요
1이 에이전트와 새 대화주간 업무 보고서 도우미와 새 대화를 엽니다.이번 주 보고서를 새로 쓸 때
2파일 업로드업무 메모 파일을 첨부합니다.메모를 파일로 적어 두었을 때
3첨부 파일김그루_주간업무메모_1106.md가 입력창 위에 보입니다.이번 주 메모를 올렸는지 확인할 때
4입력창요청을 적습니다. 다 적은 뒤 입력창 오른쪽 아래의 전송을 누릅니다.파일과 요청을 함께 보낼 때

따라 해 보기​

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 눌러 김그루_주간업무메모_1106.md를 고릅니다. 새 대화에서는 파일이 입력창 위에 파일 이름으로 남아 있다가 전송을 누를 때 올라갑니다.

  3. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다. "업로드 중...", "파일 처리 중..."이 차례로 지나간 뒤 요청이 전달됩니다.

    프롬프트: 첨부한 업무 메모로 11월 2일~11월 6일 주간 업무 보고서를 써 주세요. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표, 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓰고, 이슈에는 원인과 조치를 함께 적어 주세요.

팁: 파일 없이 입력창에 메모를 그대로 붙여 넣어도 됩니다. 이때는 프롬프트 다음 줄에 메모를 이어 붙여 보냅니다.

2단계. 커맨드로 저장하기​

매주 같은 요청을 보낸다면 커맨드로 저장합니다. 커맨드는 사이드바의 에셋설정을 눌러 여는 에셋 화면의 커맨드 탭에서 만들고, 대화 입력창에서 / 를 입력해 고릅니다. 커맨드 이름은 영문 소문자로 시작하고 소문자, 숫자, 밑줄만 쓸 수 있으므로 "주간보고"는 설명 칸에 적습니다.

주간보고 커맨드 만들기

번호메뉴기능이런 때 사용하세요
1에셋설정사이드바 아래쪽 메뉴입니다. 누르면 에셋 화면이 열립니다.커맨드를 만들거나 지울 때
2커맨드 탭기본 커맨드와 커스텀 커맨드 목록을 보여 줍니다. 커스텀 커맨드 오른쪽의 커맨드 추가를 누르면 그림처럼 입력 칸이 열립니다.내가 만든 커맨드를 확인하거나 새로 만들 때
3커맨드입력창에서 / 다음에 칠 이름입니다. 소문자, 숫자, 밑줄만 쓸 수 있고 최대 32자입니다.짧고 기억하기 쉬운 이름을 정할 때
4설명커맨드 목록 팝업에 함께 보이는 짧은 설명입니다.한글 이름("주간보고")으로 알아보게 할 때

프롬프트 입력과 저장

번호메뉴기능이런 때 사용하세요
1프롬프트커맨드를 고르면 보낼 문장입니다. 2000자 이하로 적습니다.매주 보내는 요청을 그대로 넣을 때
2저장커맨드를 저장합니다.입력을 마쳤을 때

따라 해 보기​

  1. 사이드바 아래쪽의 에셋설정을 눌러 에셋 화면을 열고 커맨드 탭을 누릅니다.

  2. 커맨드 추가를 누르고 아래처럼 입력한 뒤 저장을 누릅니다.

    • 커맨드: weekly_report
    • 설명: 주간보고
    • 프롬프트: 아래 문장

    프롬프트: 이 대화에 올린 주간 업무 메모로 주간 업무 보고서 초안을 작성해 주세요. 형식은 매주 같게 맞춥니다. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 개조식으로 쓰고, 메모에 없는 내용은 만들지 말고 [확인 필요]로 표시해 주세요.

  3. "커맨드가 추가되었습니다" 알림과 함께 커스텀 커맨드 목록에 weekly_report가 보이면 끝입니다.

3단계. 대화에서 커맨드 쓰기​

커맨드는 고르는 즉시 저장한 프롬프트만 보내고, 입력창에 붙어 있는 파일은 함께 보내지 않습니다. 그래서 이번 주 업무 메모를 "이번 주 업무 메모입니다."처럼 짧은 문장과 함께 먼저 보내고, 답이 온 뒤에 입력창에 / 를 입력해 저장한 커맨드를 고릅니다. 고르면 저장한 프롬프트가 바로 전송되고, 에이전트는 앞서 이 대화에 올린 메모로 보고서를 씁니다.

입력창에서 커맨드 고르기

번호메뉴기능이런 때 사용하세요
1첨부 파일앞서 짧은 문장과 함께 보낸 이번 주 업무 메모 파일입니다. 커맨드는 입력창에 붙어 있는 파일을 보내지 않으므로, 커맨드를 고르기 전에 파일을 먼저 보내 둡니다.커맨드가 읽을 메모를 대화에 올려 둘 때
2커맨드 목록입력창에 / 를 입력하면 열립니다. 위쪽 기본 커맨드와 아래쪽 커스텀 커맨드가 나뉘어 나옵니다.저장한 커맨드를 찾을 때
3/weekly_report내가 만든 커맨드와 설명 "주간보고"입니다. 누르면 저장한 프롬프트가 바로 전송됩니다.매주 같은 요청을 한 번에 보낼 때

따라 해 보기​

  1. 주간 업무 보고서 도우미와 새 대화를 엽니다.
  2. 입력란 아래 오른쪽의 파일 업로드로 이번 주 업무 메모를 첨부하고, 입력창에 "이번 주 업무 메모입니다."라고 적어 전송을 누릅니다.
  3. 에이전트의 답이 끝나면 입력창에 / 를 입력합니다. 에이전트가 확인 질문을 띄웠다면 먼저 답하고, 그 답변이 끝난 뒤에 / 를 입력합니다.
  4. 목록에서 weekly_report를 누릅니다. 저장한 프롬프트가 바로 전송됩니다.

팁: 커맨드는 모든 에이전트의 입력창에서 쓸 수 있습니다. 다른 에이전트에서 실수로 고르지 않도록 이름을 업무와 연결되게 짓습니다.

4단계. 금요일 스케줄 등록하기​

매주 금요일 17시에 에이전트가 보고서 초안을 미리 만들어 두게 합니다. 스케줄은 실행될 때마다 새 대화를 열어 실행 메시지만 보내고, 파일을 첨부할 수 없습니다. 그래서 업무 메모는 에이전트 편집 화면의 파일 탭에 올려 두고 실행 메시지에서 그 파일을 읽으라고 적습니다.

금요일 스케줄 등록

번호메뉴기능이런 때 사용하세요
1파일 탭에이전트가 늘 참고할 파일을 올리는 곳입니다. 에이전트당 최대 50개까지 올릴 수 있습니다.매주 고쳐 쓰는 업무 메모 파일을 둘 때
2스케줄 탭"에이전트 자동 실행 스케줄을 관리합니다" 화면입니다.정해진 시간에 에이전트를 실행할 때
3스케줄 추가새 스케줄 입력 칸을 엽니다.첫 스케줄을 만들 때
4폼 / 스케줄 표현식분, 시, 일, 월, 요일을 칸에서 고르거나 표현식으로 적습니다.금요일 17시처럼 요일과 시각을 정할 때

미리보기와 실행 메시지

번호메뉴기능이런 때 사용하세요
1미리보기고른 실행 주기를 스케줄 표현식으로 보여 줍니다. 금요일 17시는 "0 17 * * 5"입니다.고른 요일과 시각이 맞는지 확인할 때
2타임존실행 시각의 기준 시간대입니다. 처음에는 내 브라우저의 시간대가 들어 있습니다.해외에서 접속하거나 다른 시간대로 실행할 때
3실행 메시지스케줄이 돌 때 에이전트에게 보낼 메시지입니다. 다 적은 뒤 아래 생성을 누릅니다.무엇을 할지 에이전트에게 알려 줄 때

따라 해 보기​

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 에이전트 설정을 누릅니다.

  2. 오른쪽 패널의 파일 탭을 누르고 김그루_주간업무메모_1106.md를 올립니다. 다음 주부터는 같은 이름의 파일을 지우고 새 메모를 올립니다.

  3. 스케줄 탭을 누르고 스케줄 추가를 누릅니다.

  4. 폼에서 분 0, 시 17, 요일 금요일을 고릅니다. 스케줄 표현식으로 적으려면 "0 17 * * 5"를 입력합니다.

  5. 타임존이 내가 일하는 시간대(서울이면 Asia/Seoul)인지 확인합니다.

  6. 실행 메시지에 아래 문장을 넣고 생성을 누릅니다.

    프롬프트: 파일 탭에 올려 둔 이번 주 업무 메모를 읽고 주간 업무 보고서 초안을 작성해 주세요. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓰고, 메모에 없는 내용은 만들지 말고 [확인 필요]로 표시해 주세요.

  7. "스케줄이 생성되었습니다" 알림이 뜨고 목록의 다음 실행에 이번 주 금요일 오후 5시(예: 11/13/2026, 5:00:00 PM)가 보이는지 확인합니다.

팁: 스케줄이 돌 때마다 이 에이전트의 채팅 목록에 새 대화가 하나씩 생깁니다. 실행 결과는 더 보기 > 작업의 작업 기록에서 출처 스케줄로 걸러 볼 수 있습니다. 등록한 스케줄 전체는 같은 화면의 스케줄 작업 탭에서 켜고 끕니다. 자세한 내용은 스케줄링과 백그라운드 모드에 있습니다.

결과물 예시​

1단계에서 받은 주간 보고서를 아래 기준과 맞춰 봅니다. 제목에 보고 기간(11월 2일~11월 6일)이 들어 있고, 메모 7줄이 여섯 부분에 나뉘어 들어갔는지 확인합니다.

주간 업무 보고서 결과

번호메뉴기능이런 때 사용하세요
1보고서 제목보고 기간(11월 2일~11월 6일)이 들어 있습니다.어느 주 보고서인지 확인할 때
2이번 주 핵심 성과메모에서 고른 대표 성과 세 줄입니다.팀장이 첫 줄만 읽어도 한 주를 알 수 있게 할 때
3업무별 진행 표월요일부터 금요일까지 다섯 가지 업무가 업무, 진행 내용, 수치, 상태 열로 들어 있습니다.팀장에게 보낼 본문을 고를 때

주간 업무 보고서 결과 뒷부분

번호메뉴기능이런 때 사용하세요
1이슈와 조치50MB 넘는 결산 엑셀 업로드 실패와 시트 분리 안내 조치입니다.원인과 조치가 함께 적혔는지 볼 때
2다음 주 계획경영지원팀 확대 준비, 교안 개정 착수입니다.다음 주 일정을 팀장과 맞출 때
3확인 필요메모에 없어 채우지 못한 항목입니다.보내기 전에 직접 채울 내용을 찾을 때

결과 확인 포인트

예시 메모로 기대하는 내용입니다. 문장은 달라도 아래 항목과 숫자가 모두 들어 있으면 됩니다.

부분들어가야 할 내용
이번 주 핵심 성과 3줄메모의 숫자가 있는 성과 가운데 세 가지(예: 문의 7건 응대, 교육 보조 강사 참석 24명, 댓글 5건 답변)
업무별 진행 표월: 영업본부 파일럿 사용자 문의 7건 응대(첨부파일 형식 4건, 권한 2건, 기타 1건)
화: 주간 보고서 에이전트 프롬프트 개선, "지난주 대비" 비교 항목 추가
수: 사내 교육 "에이전트 만들기 실습" 보조 강사(참석 24명)
목: 판매 실적 대시보드용 엑셀 정리, 9월 매출 이상치 3건 확인 요청
금: 커뮤니티에 "회의록 요약 에이전트" 공유 게시글 작성, 댓글 5건 답변(메모 원문 그대로이며, 화면의 메뉴 이름은 라운지입니다)
이슈와 조치50MB 넘는 결산 엑셀 업로드 실패, 시트 분리 안내
다음 주 계획경영지원팀 확대 준비, 교안 개정 착수
확인 필요메모에 없어 채우지 못한 내용(이 예시에서는 프롬프트 개선 업무의 상세 변경 내역)
  • 문의 7건의 내역(4 + 2 + 1)이 메모와 같은지 봅니다.
  • 다음 주 계획에 메모에 없는 날짜나 담당자가 붙어 있으면 지어낸 값입니다. "확인 필요"로 바꾸거나 지웁니다.
  • 메모에 없는 "지난주 대비" 수치가 들어가 있지 않은지 봅니다. 메모에는 지난주 숫자가 없습니다.

응용 팁​

  • 보고서를 Word 파일로 받고 싶다면 에이전트 모드를 문서작성 에이전트로 둔 에이전트를 따로 만들어 보고서 내용을 넘깁니다. 일반 에이전트와 문서작성 에이전트의 차이는 PPT·문서 만들기에 있습니다.
  • 회의록에서 내 담당 업무만 뽑아 메모에 보태려면 사례: 회의록 요약과 액션 아이템의 회의록 요약 도우미에 "김그루 사원 담당 액션 아이템만 골라 주세요"라고 묻습니다.
  • 지난주 보고서를 다시 찾으려면 그 채팅 이름을 "[주간보고] 11월 1주"처럼 바꾸고 고정해 둡니다. 사이드바 **채팅 검색...**에 "주간보고"를 입력하면 모아 볼 수 있습니다. 방법은 대화 화면과 채팅 목록에 있습니다.
