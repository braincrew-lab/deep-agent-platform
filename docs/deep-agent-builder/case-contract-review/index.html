사례: 계약서 검토 도우미

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 "계약서 검토 도우미"를 만들어, 데이터 분석 구독 계약서 초안의 조항별 위험을 표로 받고 수정 문구 제안까지 받는 과정을 화면 순서대로 보여 줍니다. 대화에 연락처 같은 개인정보가 섞여도 모델에 그대로 넘어가지 않도록 개인정보 보호 미들웨어를 붙이는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 대화로 계약서 검토 도우미를 만들고 개인정보 보호 미들웨어를 붙입니다.
  • 계약서 초안(.docx)을 첨부해 조항별 위험 표를 받습니다.
  • 위험 조항마다 수정 문구(레드라인) 제안을 받습니다.
  • 연락처가 마스킹되어 처리되는지 확인합니다.
  • 결과가 원본 조항과 맞는지 확인하는 기준을 익힙니다.

주의: 에이전트의 검토 결과는 초안 검토를 돕는 참고 자료입니다. 계약 체결 전에는 반드시 회사의 법무 담당 부서 검토를 받으세요. 이 페이지의 계약서는 가상 자료입니다.

목표​

  • 계약서 초안 9개 조항을 조항, 현재 문구 요약, 위험 수준, 이유, 확인 질문으로 나눈 위험 표 1개
  • 위험이 큰 조항 5곳(자동연장, 일방 단가조정, 손해배상 상한, 결과물 권리 귀속, 전속 관할)의 수정 문구 제안
  • 법무 담당 부서에 보낼 검토 요청 메모 초안

준비물​

항목내용
예시 파일브레인크루_데이터분석구독_계약서_초안.docx (가상 자료. 브레인크루(갑)와 한빛데이터(을)의 구독 계약 초안, 9개 조항)
대화에 첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (한 번에 최대 10개. 파일 1개당 .md, .markdown, .txt, .html, .htm은 10MB, .pdf, 이미지, .docx, .hwp, .hwpx는 20MB, .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt는 50MB까지)
받지 않는 형식예전 Word 형식(.doc)은 첨부할 수 없습니다. Word에서 .docx나 PDF로 다시 저장해 올립니다.
에이전트 모드일반 에이전트
미들웨어개인정보 보호
권한새 에이전트를 만들 수 있는 권한

암호를 걸었거나 권한 보호(DRM)가 걸린 계약서는 올릴 수 없습니다. 보호를 해제한 사본을 씁니다.

에이전트 만들기​

사이드바의 새 에이전트를 눌러 대화로 에이전트를 만드는 첫 화면을 열고, 입력란에 계약서 검토 도우미가 할 일을 적어 보냅니다.

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 아래 요청을 붙여 넣고 보냅니다.

    프롬프트: 계약서 검토 도우미를 만들어 주세요. 우리 회사(브레인크루)가 갑으로 맺는 서비스 계약서 초안을 첨부하면, 조항마다 갑에게 불리한 점을 찾아 위험 수준(높음, 중간, 낮음), 이유, 상대방에게 물어볼 질문을 표로 정리하고, 위험이 높은 조항은 수정 문구를 제안하는 에이전트입니다. 계약서에 없는 내용은 추측하지 말고, 답변 끝에는 항상 "최종 판단은 법무 담당 부서 검토를 받아야 합니다"라고 적어 주세요. 개인정보는 가려서 처리해 주세요.

  3. 도우미가 미들웨어 추천에서 개인정보 보호를 제안하면 추가하도록 답합니다. 확인 질문에 답한 뒤 전체 제출을 누릅니다.

  4. 완료 카드의 바로 이용하기를 누릅니다.

개인정보 보호 미들웨어 설정​

계약서 원문에는 개인정보가 없어도, 검토하며 상대 담당자 연락처나 메일 주소를 함께 붙여 넣는 일이 많습니다. 개인정보 보호 미들웨어를 붙이면 정해진 항목을 찾아 모델과 도구, 사용자에게 전달되기 전에 처리합니다. 에이전트 만들기 대화에서 이미 추가됐다면 설정만 확인합니다. 미들웨어는 에이전트 편집 화면 가운데 편집 영역의 미들웨어에서 붙이고, 설정은 미들웨어 설정: 개인정보 보호 창 안의 저장으로 저장합니다. 헤더의 저장을 누르지 않아도 대화와 테스트 탭에 바로 적용됩니다.

따라 해 보기​

  1. 사이드바에서 계약서 검토 도우미를 누르고 에이전트 설정을 누릅니다.
  2. 가운데 편집 영역의 미들웨어에 개인정보 보호가 없으면 미들웨어 버튼을 눌러 미들웨어 추가 창에서 개인정보 보호를 고르고 미들웨어 추가를 누릅니다.
  3. 목록의 개인정보 보호를 눌러 미들웨어 설정: 개인정보 보호 창을 엽니다.
  4. 보호 항목에서 연락처(전화번호, 이메일)와 사업자(사업자등록번호, 법인등록번호)가 켜져 있는지 봅니다.
  5. 처리 방식을 마스킹으로 고르고, 적용 지점의 사용자 입력, 모델 응답, 도구 결과를 모두 켠 뒤 창의 저장을 누릅니다. "미들웨어 설정이 저장되었습니다"가 표시되면 끝입니다.

팁: 처리 방식을 차단으로 두면 개인정보가 들어간 요청은 "개인정보 보호 정책으로 실행을 멈췄습니다" 안내와 함께 멈춥니다. 이 설정을 켜면 이 에이전트의 사용자 메모리는 쌓이지 않습니다. 항목별 설명은 미들웨어와 개인정보 보호에 있습니다.

단계별 실행​

1단계: 계약서 첨부와 조항별 위험 표​

계약서 검토 도우미와 새 대화를 열고 계약서 초안을 첨부해 조항별 위험 표를 받습니다.

따라 해 보기

  1. 사이드바에서 계약서 검토 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_데이터분석구독_계약서_초안.docx를 첨부하고, 파일 처리 표시가 끝날 때까지 기다립니다.

  3. 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 계약서 초안을 갑(브레인크루) 입장에서 조항별로 검토해 주세요. 제1조부터 제9조까지 빠짐없이 조항, 현재 문구 요약, 위험 수준(높음/중간/낮음), 이유, 을에게 확인할 질문 열로 표를 만들어 주세요. 특히 자동연장, 단가 조정, 손해배상 한도, 결과물 권리, 관할 법원 조항을 자세히 봐 주세요.

  4. 표의 행이 9개인지, 위험 수준 높음이 위 다섯 조항에 붙었는지 확인합니다.

2단계: 수정 문구(레드라인) 제안​

같은 대화에서 위험 수준이 높은 조항마다 수정 문구를 제안받습니다.

따라 해 보기

  1. 같은 대화에서 아래 프롬프트를 보냅니다.

    프롬프트: 위험 수준이 높음인 조항마다 현재 문구, 수정 제안 문구, 협상 메모를 표로 정리해 주세요. 수정 제안은 계약서 문체로 써 주세요.

  2. 현재 문구 열이 원문과 같은지, 수정 제안이 조항 번호와 맞는지 확인합니다.

3단계: 마스킹 확인과 검토 요청 메모​

연락처를 넣은 요청을 보내 개인정보 보호 미들웨어가 연락처를 마스킹하는지 확인하고, 법무 담당 부서에 보낼 검토 요청 메모를 받습니다.

따라 해 보기

  1. 같은 대화에서 아래 프롬프트를 보냅니다. 연락처는 예시 번호입니다.

    프롬프트: 지금까지 검토한 내용으로 법무 담당 부서에 보낼 검토 요청 메모를 써 주세요. 메모 끝에 한빛데이터 계약 담당자 연락처 010-1234-5678을 적어 주세요.

  2. 답변의 연락처가 *-**-5678처럼 마스킹되어 있는지 확인합니다. 원래 번호가 그대로 보이면 미들웨어 설정의 적용 지점에서 모델 응답이 켜져 있는지 다시 확인합니다.

결과물 예시​

예시 계약서로 받은 위험 표와 수정 제안에서 아래 내용이 맞는지 확인합니다. 원본 값은 계약서에서 직접 확인할 수 있습니다.

조항원본 문구 핵심갑 입장 위험확인 포인트
제2조(계약기간)2027년 1월 1일~12월 31일, 만료 1개월 전까지 서면 해지 통보가 없으면 1년씩 자동 연장높음해지 통보 기한이 2027년 11월 30일(만료 1개월 전)로 계산됐는지, 연장 전 사전 안내 의무를 제안했는지
제3조(서비스 수준)월간 가용률 99.0% 이상 유지하도록 노력, 정기 점검 시간 제외중간"노력한다"가 의무가 아니라는 점과 미달 시 보상이 없다는 점을 짚었는지
제4조(대금 및 지급)월 5,900,000원(부가세 별도), 을이 30일 전 통지로 조정 가능높음연간 70,800,000원(부가세 별도)으로 계산했는지, 조정에 갑의 서면 동의나 상한을 제안했는지
제5조(비밀유지)계약 종료 후 1년간중간기간이 짧다는 점, 데이터 반환·파기 조항이 없다는 점을 짚었는지
제6조(손해배상)배상액은 직전 1개월 구독료 한도높음한도가 5,900,000원으로 연간 대금의 12분의 1이라는 점, 고의·중과실 예외를 제안했는지
제7조(데이터의 귀속)분석 결과물의 권리는 을에게 귀속높음갑의 데이터로 만든 결과물을 갑이 쓰지 못할 위험, 갑 귀속이나 갑의 무상 이용권을 제안했는지
제8조(해지)갑은 을의 중대한 위반 시 14일 시정기간 뒤 해지 가능중간을의 해지 조건이 없다는 점, 가용률 반복 미달도 해지 사유에 넣자는 제안이 있는지
제9조(분쟁해결)을의 본사 소재지 관할 법원 전속 관할높음갑 소재지 법원이나 피고 소재지 법원으로 바꾸는 제안이 있는지
제1조(목적)데이터 분석 구독 서비스 제공과 대가 지급낮음서비스 범위가 별첨으로 정의되지 않았다는 점을 짚었는지

결과를 이렇게 확인하세요​

  • 표의 행이 9개인지 봅니다. 하나라도 빠지면 "제몇조가 빠졌습니다. 다시 표를 만들어 주세요"라고 요청합니다.
  • 금액과 기간 숫자가 원문과 같은지 봅니다. 월 구독료는 5,900,000원, 시정기간은 14일, 비밀유지 기간은 1년입니다.
  • 원문에 없는 조항(예: 지체상금, 하도급 금지)을 원문에 있는 것처럼 적었다면 고쳐 달라고 합니다. 원문에 없는 조항을 "추가 제안"으로 따로 적은 것은 괜찮습니다.
  • 답변 끝에 법무 담당 부서 검토 안내가 있는지 봅니다.

응용 팁​

  • 같은 기준으로 다른 계약서를 볼 때는 1단계 프롬프트를 커맨드로 저장해 둡니다. 커맨드와 재사용을 보세요.
  • 회사의 표준 계약 기준 문서가 지식으로 준비되어 있으면 에이전트 편집 화면의 지식함에 연결해 "회사 기준과 다른 조항"을 따로 묻습니다. 지식으로 근거 있는 답변 받기를 참고하세요.
  • 검토 결과를 Word 문서로 정리하려면 에이전트 모드를 문서작성 에이전트로 바꿔 수정 제안 문서를 받고, 캔버스에서 확인한 뒤 내려받습니다. 캔버스로 문서·PPT·표 만들기를 보세요.
  • 계약서에 사람 이름이나 주소가 많다면 개인정보 보호 설정의 AI 추가 탐지를 검토합니다. 모델을 한 번 더 호출해 응답이 느려질 수 있습니다.
