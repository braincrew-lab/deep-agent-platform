사례: 계약서 검토 도우미

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 "계약서 검토 도우미"를 만들어, 데이터 분석 구독 계약서 초안의 조항별 위험을 표로 받고 수정 문구 제안까지 받는 과정을 화면 순서대로 보여 줍니다. 대화에 연락처 같은 개인정보가 섞여도 모델에 그대로 넘어가지 않도록 개인정보 보호 미들웨어를 붙이는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 대화로 계약서 검토 도우미를 만들고 개인정보 보호 미들웨어를 붙입니다.
  • 계약서 초안(.docx)을 첨부해 조항별 위험 표를 받습니다.
  • 위험 조항마다 수정 문구(레드라인) 제안을 받습니다.
  • 연락처가 마스킹되어 처리되는지 확인합니다.
  • 결과가 원본 조항과 맞는지 확인하는 기준을 익힙니다.

주의: 에이전트의 검토 결과는 초안 검토를 돕는 참고 자료입니다. 계약 체결 전에는 반드시 회사의 법무 담당 부서 검토를 받으세요. 이 페이지의 계약서는 가상 자료입니다.

목표​

  • 계약서 초안 9개 조항을 조항, 현재 문구 요약, 위험 수준, 이유, 확인 질문으로 나눈 위험 표 1개
  • 위험이 높은 조항의 수정 문구 제안(이 예에서는 단가 조정, 손해배상 상한, 결과물 권리 귀속, 전속 관할의 4곳)
  • 법무 담당 부서에 보낼 검토 요청 메모 초안

준비물​

항목내용
예시 파일브레인크루_데이터분석구독_계약서_초안.docx (가상 자료. 브레인크루(갑)와 한빛데이터(을)의 구독 계약 초안, 9개 조항)
대화에 첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (한 번에 최대 10개. 파일 1개당 .md, .markdown, .txt, .html, .htm은 10MB, .pdf, 이미지, .docx, .hwp, .hwpx는 20MB, .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt는 50MB까지)
받지 않는 형식예전 Word 형식(.doc)은 첨부할 수 없습니다. Word에서 .docx나 PDF로 다시 저장해 올립니다.
에이전트 모드일반 에이전트
미들웨어개인정보 보호
권한새 에이전트를 만들 수 있는 권한

암호를 걸었거나 권한 보호(DRM)가 걸린 계약서는 올릴 수 없습니다. 보호를 해제한 사본을 씁니다.

에이전트 만들기​

사이드바의 새 에이전트를 눌러 대화로 에이전트를 만드는 첫 화면을 열고, 입력란에 계약서 검토 도우미가 할 일을 적어 보냅니다. 첫 화면의 입력란과 전송, 확인 질문과 추천 화면은 에이전트 만들기의 "대화로 만들기"에서 그림과 함께 설명합니다. 여기서는 계약서 검토 도우미에 맞춘 요청 문장과 답만 정리합니다.

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 아래 요청을 붙여 넣고 보냅니다.

    프롬프트: 계약서 검토 도우미를 만들어 주세요. 우리 회사(브레인크루)가 갑으로 맺는 서비스 계약서 초안을 첨부하면, 조항마다 갑에게 불리한 점을 찾아 위험 수준(높음, 중간, 낮음), 이유, 상대방에게 물어볼 질문을 표로 정리하고, 위험이 높은 조항은 수정 문구를 제안하는 에이전트입니다. 계약서에 없는 내용은 추측하지 말고, 답변 끝에는 항상 "최종 판단은 법무 담당 부서 검토를 받아야 합니다"라고 적어 주세요. 개인정보는 가려서 처리해 주세요.

  3. 도우미가 확인 질문 3개(검토 범위, 결과 형태, 지켜야 할 조건)를 보여 주면 각 질문에서 답을 고르고 제출을 누른 뒤 전체 제출을 누릅니다. 이 예에서는 "서비스 계약서 초안 전체 조항", "조항별 위험 수준, 이유, 질문을 표로 정리", "개인정보는 반드시 가려서 처리"를 골랐습니다.

  4. 이어서 도구, 미들웨어, 스킬, 도우미 에이전트 추천이 차례로 나옵니다. 추천마다 승인으로 받아들이거나 수정 요청에 원하는 내용을 적어 다시 추천받습니다. 이 예에서는 도구 추천(사내 지식 검색 도구)은 "도구는 추가하지 않아도 됩니다. 첨부한 계약서만 보고 검토하게 해 주세요."로, 미들웨어 추천(도구 재시도, 개인정보 보호)은 "개인정보 보호만 추가해 주세요."로, 도우미 에이전트 추천은 "도우미 에이전트 없이 혼자 검토하게 해 주세요."로 수정 요청한 뒤 승인했습니다. 스킬은 추천이 없어 그대로 승인했습니다.

  5. 행동 지침 작성과 이름·설명 저장이 끝나면 완료 안내에 "에이전트 이름: 계약서 검토 도우미", "동작 방식 설정: 계약서 내 개인정보를 가려서 민감 정보 노출을 방지해요."가 나옵니다. 바로 이용하기를 누릅니다.

개인정보 보호 미들웨어 설정​

계약서 원문에는 개인정보가 없어도, 검토하며 상대 담당자 연락처나 메일 주소를 함께 붙여 넣는 일이 많습니다. 개인정보 보호 미들웨어를 붙이면 정해진 항목을 찾아 모델과 도구, 사용자에게 전달되기 전에 처리합니다. 에이전트 만들기 대화에서 이미 추가됐다면 설정만 확인합니다. 미들웨어는 에이전트 편집 화면 가운데 편집 영역의 미들웨어에서 붙이고, 설정은 미들웨어 설정: 개인정보 보호 창 안의 저장으로 저장합니다. 헤더의 저장을 누르지 않아도 대화와 테스트 탭에 바로 적용됩니다.

에이전트 편집 화면 미들웨어 칸에서 개인정보 보호 옆 톱니바퀴를 누르면 미들웨어 설정: 개인정보 보호 창이 열립니다. 아래 그림은 창을 아래로 내려 사업자 항목부터 저장까지 보이게 한 모습입니다.

개인정보 보호 미들웨어 설정

번호메뉴기능이런 때 사용하세요
1보호 항목찾을 개인정보 종류를 고릅니다. 고유식별정보, 금융정보, 연락처, 사업자, 인적사항, 기술 식별자로 묶여 있으며, 그림은 사업자의 사업자등록번호를 선택한 모습입니다.전화번호, 이메일, 사업자등록번호처럼 계약 업무에 자주 나오는 항목을 켤 때
2처리 방식가리기, 마스킹, 해시, 차단 중에서 고릅니다. 마스킹은 010-1234-5678을 *-**-5678처럼 끝자리만 남깁니다.원래 값의 일부만 보여도 되는 업무일 때
3적용 지점사용자 입력, 모델 응답, 도구 결과 중 어디에 적용할지 고릅니다.첨부 파일에서 읽은 내용까지 보호하고 싶을 때
4저장설정을 저장하고 창을 닫습니다. 따로 알림은 뜨지 않으며, 창이 닫히면 저장된 것입니다.설정을 마쳤을 때

따라 해 보기​

  1. 사이드바에서 계약서 검토 도우미를 누르고 에이전트 설정을 누릅니다.
  2. 가운데 편집 영역의 미들웨어 칸에 개인정보 보호가 없으면 칸 제목 줄의 + 미들웨어를 눌러 미들웨어 추가 창에서 개인정보 보호를 고르고 미들웨어 추가를 누릅니다. 대화로 만들면서 추가했다면 이미 붙어 있습니다.
  3. 개인정보 보호 옆 톱니바퀴(미들웨어 설정)를 눌러 미들웨어 설정: 개인정보 보호 창을 엽니다.
  4. 보호 항목에서 연락처(전화번호, 이메일)와 사업자(사업자등록번호, 법인등록번호)를 선택합니다. 처음 붙였을 때는 이 네 항목이 선택되어 있지 않습니다.
  5. 처리 방식을 마스킹으로 고르고, 적용 지점의 사용자 입력, 모델 응답, 도구 결과가 모두 켜져 있는지 확인한 뒤 창의 저장을 누릅니다. 따로 알림은 뜨지 않고 창이 닫히면 저장된 것입니다. 이 설정은 헤더의 저장을 누르지 않아도 바로 대화에 적용됩니다.

창 위쪽에 "이 리소스의 설정을 수정할 권한이 없습니다."와 "수정 권한이 없어 읽기 전용으로 표시됩니다."가 보이면 설정을 바꿀 권한이 없는 것입니다. 이때는 항목과 저장이 흐리게 보이므로, 바꿀 값을 정리해 관리자에게 권한을 요청합니다.

팁: 처리 방식을 차단으로 두면 개인정보가 들어간 요청은 실행이 멈추고, "개인정보 보호 정책으로 실행을 멈췄습니다" 제목의 알림에 "보호 대상 개인정보가 포함되어 개인정보 보호 정책에 따라 실행을 멈췄습니다. 해당 정보를 빼고 다시 요청해 주세요."가 표시됩니다. 이 설정을 켜면 이 에이전트의 사용자 메모리는 쌓이지 않습니다. 항목별 설명은 미들웨어와 개인정보 보호에 있습니다.

단계별 실행​

1단계: 계약서 첨부와 조항별 위험 표​

계약서 검토 도우미와 새 대화를 열고 계약서 초안을 첨부해 조항별 위험 표를 받습니다.

조항별 위험 표

번호메뉴기능이런 때 사용하세요
1파일 업로드계약서 파일을 골라 첨부합니다.검토할 초안을 올릴 때
2첨부 파일함께 보낸 계약서 파일 이름과 형식(DOCX)입니다.어느 버전 초안으로 검토했는지 나중에 확인할 때
3위험 표 머리글조항, 현재 문구 요약, 위험 수준, 불리한 점/이유, 을에게 확인할 질문 열입니다.검토 회의에서 조항 순서대로 짚을 때

따라 해 보기

  1. 사이드바에서 계약서 검토 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_데이터분석구독_계약서_초안.docx를 첨부합니다. 새 대화에서는 파일이 입력란에 칩으로 붙어 있다가 전송을 누를 때 올라가므로, 기다리지 말고 바로 다음 단계로 넘어갑니다.

  3. 아래 프롬프트를 붙여 넣고 전송을 누릅니다. "업로드 중..."과 "파일 처리 중..." 표시가 지나가고 파일 처리가 끝나면 질문이 전달되어 답변이 시작됩니다.

    프롬프트: 첨부한 계약서 초안을 갑(브레인크루) 입장에서 조항별로 검토해 주세요. 제1조부터 제9조까지 빠짐없이 조항, 현재 문구 요약, 위험 수준(높음/중간/낮음), 이유, 을에게 확인할 질문 열로 표를 만들어 주세요. 특히 자동연장, 단가 조정, 손해배상 한도, 결과물 권리, 관할 법원 조항을 자세히 봐 주세요.

  4. 표의 행이 9개인지, 위험 수준이 붙은 조항이 원문과 맞는지 확인합니다. 이 예에서는 제4조, 제6조, 제7조, 제9조가 높음, 제2조, 제5조, 제8조가 중간, 제1조, 제3조가 낮음으로 나왔고, 표 아래 "중점 검토"에 자동연장, 단가 조정, 손해배상 한도, 결과물 권리, 관할 법원이 따로 정리되었습니다.

2단계: 수정 문구(레드라인) 제안​

같은 대화에서 위험 수준이 높은 조항마다 수정 문구를 제안받습니다.

수정 문구 제안

번호영역기능이런 때 사용하세요
1현재 문구 열계약서 원문 그대로 옮긴 부분입니다.원문과 글자가 같은지 대조할 때
2수정 제안 문구 열갑에게 유리하게 바꾼 문구 제안입니다.을에게 보낼 수정 요청서에 옮길 때
3협상 메모 열수정 이유와 양보할 수 있는 선입니다.협상 우선순위를 정할 때
4안내 문구"최종 판단은 법무 담당 부서 검토를 받아야 합니다" 문장입니다.결과를 다른 사람에게 넘기기 전에

따라 해 보기

결과물 예시​

예시 계약서로 받은 위험 표와 수정 제안에서 아래 내용이 맞는지 확인합니다. 위험 수준은 에이전트 판단 예이며, 실행할 때마다 조금씩 달라질 수 있습니다. 원본 값은 계약서에서 직접 확인할 수 있습니다.

조항원본 문구 핵심갑 입장 위험확인 포인트

제3조(서비스 수준)월간 가용률 99.0% 이상 유지하도록 노력, 정기 점검 시간 제외중간"노력한다"가 의무가 아니라는 점과 미달 시 보상이 없다는 점을 짚었는지

제5조(비밀유지)계약 종료 후 1년간중간기간이 짧다는 점, 데이터 반환·파기 조항이 없다는 점을 짚었는지

제8조(해지)갑은 을의 중대한 위반 시 14일 시정기간 뒤 해지 가능중간을의 해지 조건이 없다는 점, 가용률 반복 미달도 해지 사유에 넣자는 제안이 있는지
제9조(분쟁해결)을의 본사 소재지 관할 법원 전속 관할높음갑 소재지 법원이나 피고 소재지 법원으로 바꾸는 제안이 있는지
제1조(목적)데이터 분석 구독 서비스 제공과 대가 지급낮음서비스 범위가 별첨으로 정의되지 않았다는 점을 짚었는지

이 예의 실제 답변에서는 위 표와 달리 제3조(서비스 수준)를 낮음으로 판단했습니다. 같은 조항이라도 위험 수준은 달라질 수 있으니 이유 열을 함께 읽고 판단합니다.

결과를 이렇게 확인하세요​

  • 표의 행이 9개인지 봅니다. 하나라도 빠지면 "제몇조가 빠졌습니다. 다시 표를 만들어 주세요"라고 요청합니다.
  • 금액과 기간 숫자가 원문과 같은지 봅니다. 월 구독료는 5,900,000원, 시정기간은 14일, 비밀유지 기간은 1년입니다.
  • 원문에 없는 조항(예: 지체상금, 하도급 금지)을 원문에 있는 것처럼 적었다면 고쳐 달라고 합니다. 원문에 없는 조항을 "추가 제안"으로 따로 적은 것은 괜찮습니다.
  • 답변 끝에 법무 담당 부서 검토 안내가 있는지 봅니다.

응용 팁​

  • 같은 기준으로 다른 계약서를 볼 때는 1단계 프롬프트를 커맨드로 저장해 둡니다. 커맨드를 고르면 저장한 프롬프트가 바로 전송되고 입력란에 올려 둔 파일은 함께 가지 않으므로, 먼저 새 계약서를 "검토할 계약서 초안입니다."처럼 짧은 문장과 함께 보내 답을 받은 뒤 커맨드를 고릅니다. 커맨드와 재사용을 보세요.
  • 회사의 표준 계약 기준 문서가 지식으로 준비되어 있으면 에이전트 편집 화면의 지식함에 연결해 "회사 기준과 다른 조항"을 따로 묻습니다. 지식으로 근거 있는 답변 받기를 참고하세요.
  • 검토 결과를 Word 문서로 정리하려면 에이전트 모드를 문서작성 에이전트로 바꿔 수정 제안 문서를 받고, 캔버스에서 확인한 뒤 내려받습니다. 캔버스로 문서·PPT·표 만들기를 보세요.
  • 계약서에 사람 이름이나 주소가 많다면 개인정보 보호 설정의 AI 추가 탐지를 검토합니다. 모델을 한 번 더 호출해 응답이 느려질 수 있습니다.
