PPT·문서 만들기

보고 자료를 PPT로 옮기고 같은 내용을 Word 요약본으로 다시 쓰는 일은 자주 반복되지만 손이 많이 갑니다. Deep Agent Builder에서는 두 가지 방법으로 PPT·Word·Excel 결과물을 받을 수 있습니다. 하나는 문서작성 에이전트가 실제 파일을 만들어 캔버스에 올리는 방법이고, 다른 하나는 일반 에이전트가 답변을 아티팩트로 보여 주고 내보내는 방법입니다. 이 페이지는 두 방법의 차이를 비교하고, 브레인크루 AI혁신팀 김그루 사원이 보고서 초안 도우미에 "3분기 사내 AI 활용 현황 보고서" PDF를 붙여 경영진 보고 PPT와 1쪽 요약 Word를 만드는 과정을 따라 하며, 문서 양식을 스킬로 붙이는 방법까지 설명합니다.

이 페이지에서 할 수 있는 일

  • 캔버스와 아티팩트 중 어떤 방법이 내 업무에 맞는지 고릅니다.
  • 보고서 PDF를 첨부해 PPT를 요청하고, 같은 채팅에서 요약 Word를 이어서 받습니다.
  • 캔버스 내보내기로 원본 .pptx, .docx와 PDF를 내려받습니다.
  • 일반 에이전트의 아티팩트 창에서 미리보기, 코드를 보고 HTML, Word, PPTX, Excel, CSV, Markdown으로 내보냅니다.
  • 에이전트 편집 화면 스킬 탭의 문서 작성 스킬에 ZIP을 올려 회사 양식을 에이전트에 붙입니다.

두 가지 방법 비교​

구분문서작성 에이전트(캔버스)일반 에이전트(아티팩트)
설정에이전트 편집 화면 설정 탭 에이전트 모드를 문서작성 에이전트로별도 설정 없음. 지침에 아티팩트로 답하도록 적거나, 데이터를 표로 분석할 때 생김
만드는 것실제 .pptx, .docx, .xlsx 파일(필요하면 .md, .html도)답변 안의 미리보기(프레젠테이션, 스프레드시트, 문서, 웹페이지, 데이터 표)
보는 곳대화 오른쪽 문서 캔버스입력란 아래 오른쪽의 아티팩트 버튼이나 답변의 아티팩트 카드를 눌러 여는 아티팩트 창(저절로 열리지 않음)
고치는 방법대화로 요청. 문서 요소 선택으로 고칠 곳을 집어 요청대화로 요청
내려받기원본 다운로드, 문서 종류에 따라 PPTX·DOCX·XLSX·PDFHTML, Word(.doc), PPTX, 데이터 표는 Excel·CSV. PDF는 지원하지 않음
이럴 때그대로 보고·제출할 Office 파일이 필요할 때답변을 빠르게 훑어보고 필요한 형식으로 옮길 때

아티팩트 창의 안내에도 PPT를 만들 때는 전용 에이전트를 쓰는 편이 디자인과 완성도가 낫다고 적혀 있습니다. 보고·제출용 PPT와 Word는 문서작성 에이전트로 만드는 것을 권합니다. 캔버스 화면 자체는 캔버스로 문서·PPT·표 만들기에서 자세히 설명합니다.

따라 하기: 3분기 AI 활용 현황 보고 PPT와 요약 Word​

준비물​

항목내용
에이전트보고서 초안 도우미(문서작성 에이전트). 지침은 "당신은 브레인크루 직원의 보고서 작성을 돕는 비서입니다. 요청하면 Word(docx)·PowerPoint(pptx)·Excel(xlsx) 문서를 만들어 제공합니다."입니다. 문서작성 에이전트로 바꾸는 방법은 캔버스로 문서·PPT·표 만들기에 있습니다.
자료보고서-3분기-AI활용현황.pdf(가상 자료). 월간 활성 사용자 412명(2분기 대비 18% 증가), 부서별 사용 현황 표(경영지원본부 86명, 영업본부 131명, 연구개발본부 142명, AI혁신팀 53명), 성과·문제점·4분기 계획이 들어 있습니다.
첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm

1단계: PPT 요청​

PPT 요청

번호메뉴기능이런 때 사용하세요
1이 에이전트와 새 대화이전 채팅과 섞이지 않게 새 채팅을 엽니다.다른 보고서 채팅과 별개로 분기 보고를 시작할 때
2PDF 칩붙인 보고서 PDF입니다. PDF 제거로 뺄 수 있습니다.2분기 보고서를 잘못 붙였을 때
3메시지 입력란장 수, 슬라이드 순서, 숫자를 다루는 규칙을 적습니다.결과물의 모양을 구체적으로 정할 때
4전송요청과 PDF를 보냅니다.요청을 다 적었을 때

  1. 사이드바에서 보고서 초안 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드로 보고서-3분기-AI활용현황.pdf를 붙입니다.

  3. 아래 프롬프트를 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 2026년 3분기 사내 AI 활용 현황 보고서로 경영진 보고용 PPT 5장을 만들어 주세요. 표지, 요약, 부서별 사용 현황, 성과와 문제점, 4분기 계획 순서로 구성하고, 부서별 표의 숫자는 보고서 그대로 넣어 주세요. 표지의 보고 시점은 2026년 11월로 적어 주세요.

  4. 에이전트가 여러 단계를 차례로 실행합니다. 작업 목록 작성, 스킬 목록, 스킬 불러오기, 작업 파일 작성, 스킬 파일 가져오기, 코드 실행, 문서 구조 확인, 문서를 캔버스에 게시, 문서 내보내기 단계가 대화에 한 줄씩 쌓입니다. 1~2분쯤 걸렸습니다.

  5. 답변에는 장마다 들어간 내용 요약과 다운로드 링크가 붙고, 끝에 프레젠테이션 · 캔버스에서 열기 카드가 생깁니다. 카드가 두 개 생길 수도 있는데, 이름이 보고서 제목으로 된 카드가 완성본입니다.

팁: 날짜를 적지 않으면 표지에 엉뚱한 연도가 들어갈 수 있습니다. 표지 날짜, 보고 기간처럼 문서에 들어갈 날짜는 요청에 직접 적습니다. 매번 같은 순서로 받는 자료라면 그 순서를 에이전트 지침이나 문서 작성 스킬에 넣어 둡니다.

2단계: 캔버스에서 PPT 확인​

작성이 끝나면 답변 끝에 프레젠테이션 · 캔버스에서 열기 카드가 생깁니다. 카드를 눌러 캔버스에서 슬라이드를 넘겨 보며 숫자를 원본과 대조합니다.

보고 PPT 확인

번호메뉴기능이런 때 사용하세요
1결과 카드프레젠테이션 · 캔버스에서 열기가 적힌 카드입니다. 누르면 캔버스가 이 PPT로 열립니다.캔버스를 닫았다가 다시 볼 때
2미리보기슬라이드 내용입니다. 슬라이드가 세로로 이어지며, 썸네일과 이전·다음 버튼으로 장을 넘깁니다.장마다 숫자와 문장을 검토할 때
3상태준비됨이면 작성이 끝난 것입니다. **작성 중…**이면 기다립니다.내려받아도 되는지 확인할 때
4내보내기원본 다운로드, PPTX 형식으로 내보내기, PDF 형식으로 내보내기를 고릅니다.완성본을 받을 때

결과를 이렇게 확인하세요

  • 요약 장의 월간 활성 사용자 412명, 2분기 대비 18% 증가, 문서 작성·회의록 정리 비중 61%가 보고서와 같은지 봅니다.
  • 부서별 표의 네 부서 숫자를 더하면 86 + 131 + 142 + 53 = 412명으로 요약 숫자와 맞아야 합니다. 영업본부 증가율 +42%가 가장 높게 표시됐는지도 봅니다.
  • 성과 장에 주간 업무 보고 작성 시간 단축(보고서의 52분 → 31분, 약 40%)과 회의록 정리 요청 1,240건 중 92% 수정 없이 공유가 들어갔는지 봅니다. 따라 해 본 결과에서는 시간 단축이 "40% 단축"으로 줄여 적혔습니다.
  • 4분기 계획 장의 목표 월간 활성 사용자가 480명인지 봅니다.
  • 표지 날짜가 요청한 "2026년 11월"인지 봅니다.
  • 보고서에 없는 숫자가 들어갔다면 그 장을 문서 요소 선택으로 골라 "보고서에 없는 숫자는 빼 주세요"라고 요청합니다.

3단계: 같은 채팅에서 요약 Word 받기​

PPT를 받은 채팅에서 이어서 요청하면 에이전트가 앞에서 읽은 보고서 내용을 이어받아 Word 문서를 만듭니다. 이때는 Word 제목 추가, Word 문단 추가, Word 표 추가, 문서 내보내기 단계가 쌓입니다. 작성이 끝나면 답변 끝에 문서 · 캔버스에서 열기가 적힌 카드가 생기고, 캔버스 위에는 이 채팅에서 만든 PPT와 Word가 탭으로 나란히 놓여 오가며 숫자를 맞춰 볼 수 있습니다. Word 미리보기는 페이지 단위로 보입니다.

프롬프트: 같은 보고서 내용을 경영진 메일에 붙일 1쪽 요약 보고서로 Word 문서를 만들어 주세요. 제목, 핵심 숫자 표, 문제점 2가지, 4분기 요청 사항 순서로 써 주세요. 작성일은 2026년 11월 12일로 적어 주세요.

요약 Word 확인

번호메뉴기능이런 때 사용하세요
1결과 카드문서 · 캔버스에서 열기가 적힌 카드입니다.요약 Word를 열 때
2문서 탭캔버스에 올라온 문서가 탭으로 나란히 있습니다. 그림은 왼쪽 PPT 탭 옆의 Word 탭을 고른 상태입니다.PPT와 요약본을 오가며 숫자를 맞춰 볼 때
3미리보기Word 문서를 페이지 단위로 보여 줍니다.1쪽 안에 들어갔는지 확인할 때
4원본 다운로드내보내기 메뉴의 첫 항목으로, 에이전트가 만든 .docx를 그대로 받습니다. 아래에 DOCX 형식으로 내보내기, PDF 형식으로 내보내기가 이어집니다.메일에 붙일 .docx나 PDF를 받을 때

이럴 때 쓰세요: 김그루 사원은 분기마다 경영진 보고 PPT를 만든 뒤, 보고 회의에 들어오지 못하는 본부 담당자에게 보낼 요약본을 같은 채팅에서 이어 받습니다. PPT 탭과 Word 탭을 오가며 부서별 숫자가 두 문서에서 같은지 먼저 맞추고, 요약본은 PDF로 받아 회의 안내 메일에 붙입니다. 새 채팅을 열면 보고서를 다시 읽혀야 하므로, 같은 자료로 만드는 문서는 한 채팅에 모아 두는 편이 숫자가 어긋날 일이 적습니다.

결과를 이렇게 확인하세요

  • 핵심 숫자 표에 네 부서의 사용자 수, 증가율, 주요 용도가 보고서와 같게 들어갔는지 봅니다.
  • 문제점 2가지가 보고서의 "표가 많은 문서의 요약 품질", "스캔 문서 글자 인식 오류(17건)·부서별 회의록 양식 차이" 내용과 맞는지 봅니다.
  • 4분기 요청 사항에 공통 회의록 양식, 표 중심 문서 프리셋 배포, 스캔 문서 원본 재확인 절차가 들어갔는지 봅니다.
  • "1쪽"으로 요청해도 표와 문단이 길면 여러 쪽이 될 수 있습니다. 따라 해 본 결과는 PDF로 내보냈을 때 3쪽이었습니다. 1쪽 안에 꼭 넣어야 하면 "표는 4행, 문장은 항목당 한 줄로 줄여 1쪽에 맞춰 주세요"처럼 이어서 요청합니다.

4단계: 내려받기​

  1. 캔버스 탭에서 PPT를 고르고 내보내기 > 원본 다운로드로 .pptx를 받습니다.
  2. 요약 Word 탭을 고르고 내보내기 > PDF 형식으로 내보내기로 PDF를 받습니다. 고쳐 쓸 문서가 필요하면 원본 다운로드로 .docx를 받습니다.
  3. 받은 파일은 캔버스 탭에 보이는 이름 그대로 저장됩니다. PDF는 Word 파일 이름에 .pdf가 붙습니다.

내려받지 못하면 "다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."가 나옵니다. 에이전트 조회·실행 권한이 있는지 관리자에게 확인합니다.

일반 에이전트의 아티팩트로 받기​

일반 에이전트도 답변을 아티팩트로 보여 줄 수 있습니다. 아티팩트는 에이전트의 답변 결과를 창에서 바로 확인하고 필요한 파일 형식으로 내보내는 미리보기입니다. 다음 경우에 만들어집니다.

  • 에이전트 지침에 아티팩트로 답하도록 적혀 있을 때. 지침에 설정이 없으면 "아티팩트 만들어줘"라고 요청해도 만들어지지 않을 수 있습니다.
  • 엑셀(.xlsx, .xls, .xlsb, .xlsm)이나 CSV(.csv) 파일의 데이터로 표를 만들거나 분석할 때. 결과 표가 데이터 표로 자동으로 들어옵니다.

아티팩트 창은 저절로 열리지 않습니다. 답변에 생긴 아티팩트 카드("클릭하여 확인하기")를 누르거나, 입력란 아래 오른쪽의 아티팩트 버튼을 눌러 엽니다. 버튼의 숫자는 이 채팅에 모인 항목 수입니다. 예를 들어 김그루 사원이 판매 데이터 분석가에게 판매 실적 엑셀을 올려 지역별 매출 표를 받은 뒤 아티팩트를 누르면 아래와 같이 쓸 수 있습니다.

  • 왼쪽 아티팩트 목록에는 이 채팅에서 만든 아티팩트와 캔버스 문서, 에이전트가 만든 다운로드 파일이 모입니다. 데이터 표에는 "5행 × 5열"처럼 표 크기가 붙습니다.
  • 오른쪽에서 미리보기와 코드를 번갈아 눌러 실제 모양과 원본 내용을 봅니다.
  • 데이터 표는 간단하게 보기와 전체 데이터 보기를 바꿔 가며 봅니다. 전체 데이터 보기를 누르면 전체 행을 다시 불러와 보여 줍니다.
  • 내보내기로 내보낼 형식을 고릅니다. 형식은 아래 "내보내기 형식"에 있습니다.
  • 아티팩트 도움말에는 아티팩트가 언제 만들어지는지, 어떤 형식으로 내보낼 수 있는지 안내되어 있습니다. 닫기를 누르면 대화로 돌아갑니다.

아티팩트 창

번호메뉴기능이런 때 사용하세요
1아티팩트 목록이 채팅에서 만든 아티팩트와 캔버스 문서, 에이전트가 만든 다운로드 파일이 모입니다. 데이터 표에는 "10행 × 4열"처럼 표 크기가 붙습니다.앞에서 만든 표를 다시 고를 때
2미리보기, 코드실제 모양과, 그 모양을 만든 원본 내용을 번갈아 봅니다.표 안 문장을 복사해 메일에 붙일 때
3간단하게 보기, 전체 데이터 보기데이터 표를 간단히 보거나, 전체 행을 다시 불러와 보여 줍니다.미리보기에 잘린 행까지 확인할 때
4내보내기내보낼 형식을 고르는 메뉴를 엽니다.표나 슬라이드를 파일로 받을 때

창 제목 옆 물음표 아티팩트 도움말에는 아티팩트가 언제 만들어지는지, 어떤 형식으로 내보낼 수 있는지 안내되어 있습니다. 오른쪽 위 닫기(X)를 누르면 창을 닫고 대화로 돌아갑니다.

내보내기 형식​

아티팩트메뉴 항목받는 파일
모든 아티팩트HTML 다운로드, Word로 내보내기, PPTX로 내보내기.html, .doc, .pptx
데이터 표위 항목에 더해 Excel로 내보내기, CSV로 내보내기.xlsx, .csv
문서 내보내기 도구로 만든 문서위 항목에 더해 Markdown 내보내기.md
  • HTML 다운로드, Word로 내보내기, PPTX로 내보내기를 고르면 아티팩트 선택 창이 열립니다. 전체 선택이나 체크 상자로 넣을 아티팩트를 고른 뒤 내보냅니다. 여러 개를 고르면 한 파일로 묶입니다.
  • PDF 형식은 지원하지 않습니다. PDF가 필요하면 Word로 받아 PDF로 저장하거나, 문서작성 에이전트의 캔버스를 씁니다.
  • Word로 내보내기로 받는 파일은 예전 Word 형식(.doc)입니다. 대화의 파일 업로드와 에이전트 편집 화면 파일 탭은 Word 파일을 .docx만 받으므로, 받은 .doc 파일은 그대로 다시 올릴 수 없습니다. 다시 올려야 하면 Word에서 .docx로 저장한 뒤 올립니다.
  • 원본 데이터가 더 이상 남아 있지 않으면 "원본 데이터가 더 이상 남아 있지 않아 불러올 수 없습니다. 에이전트에게 표를 다시 만들어 달라고 요청해 주세요."가 나옵니다.

아티팩트 내보내기 메뉴

번호메뉴기능이런 때 사용하세요
1Word로 내보내기고른 아티팩트를 Word 문서(.doc) 하나로 받습니다.표를 보고서 본문에 옮길 때
2PPTX로 내보내기고른 아티팩트를 PowerPoint 파일로 받습니다.표를 발표자료 한 장으로 옮길 때
3Excel로 내보내기데이터 표를 엑셀 파일로 받습니다.표를 내 엑셀에서 더 가공할 때
4CSV로 내보내기데이터 표를 CSV 파일로 받습니다.다른 시스템에 올릴 원본 데이터가 필요할 때

이럴 때 쓰세요: 영업 회의 전에 김그루 사원은 판매 데이터 분석가에게서 받은 지역별 매출 표를 Excel로 내보내기로 받아 지난달 표 옆에 붙이고 증감을 계산합니다. 회의 자료에 표 한 장만 넣으면 될 때는 같은 표를 PPTX로 내보내기로 받아 월간 영업 보고 슬라이드 사이에 끼워 넣습니다. 고객에게 그대로 보낼 정식 문서가 필요하면 아티팩트에서 옮기지 않고 문서작성 에이전트로 다시 만듭니다.

메뉴 가운데 HTML 다운로드는 웹 페이지 파일로 받습니다. PowerPoint나 Word가 없는 사람에게 브라우저로 볼 파일을 보낼 때 씁니다.

따라 해 보기​

  1. 사이드바에서 판매 데이터 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드로 브레인크루_2026_판매실적.xlsx를 붙이고 아래 프롬프트를 보냅니다.

  3. 답변이 끝나면 입력란 아래 오른쪽의 아티팩트를 누릅니다. 목록에서 데이터 표를 고르고 전체 데이터 보기를 누릅니다.

문서 작성 스킬로 양식 붙이기​

회사 보고서 양식, 표지 문구, 숫자 표기 규칙처럼 매번 지켜야 할 내용은 문서 작성 스킬로 만들어 에이전트에 붙입니다. 문서 작성 스킬은 문서작성 에이전트가 문서를 만들 때 쓰는 스킬이며, 에이전트 편집 화면(에이전트 설정) 오른쪽 스킬 탭에서 관리합니다. 스킬 탭에는 제목 스킬 선택과 "에이전트에서 사용할 스킬을 선택하세요"가 보이고, 문서 작성 스킬과 일반 스킬 하위 탭이 있습니다. 문서 작성 스킬 탭에는 ZIP 업로드 버튼과 스킬 목록이 있고, 스킬마다 켜기 스위치가 붙어 있습니다. 아직 없으면 "문서 작성 스킬이 없습니다. ZIP으로 업로드하세요."가 보입니다. 스킬을 만들 권한이 없으면 ZIP 업로드를 누를 수 없습니다.

문서 작성 스킬 탭

번호메뉴기능이런 때 사용하세요
1스킬에이전트 편집 화면 오른쪽 패널의 스킬 탭입니다. 제목 스킬 선택과 "에이전트에서 사용할 스킬을 선택하세요"가 보입니다.에이전트에 스킬을 붙이러 갈 때
2문서 작성 스킬문서 작성용 스킬만 모아 보는 하위 탭입니다. 옆의 일반 스킬 탭에는 일반 스킬이 있습니다.보고서 양식 스킬을 찾을 때
3ZIP 업로드문서 작성 스킬 ZIP을 올리는 스킬 업로드 창을 엽니다. 스킬을 만들 권한이 없으면 누를 수 없습니다.회사 양식을 스킬로 새로 올릴 때
4스킬 목록올린 스킬과 켜기 스위치입니다. 켠 스킬을 이 에이전트가 씁니다. 스위치를 바꾼 뒤에는 머리줄에 "저장되지 않은 변경이 있습니다"가 보이므로 저장을 눌러야 적용됩니다.보고서 양식 스킬을 이 에이전트에 켤 때

이럴 때 쓰세요: AI혁신팀이 사내 보고서 양식을 바꾸면, 김그루 사원은 SKILL.md의 규칙을 고친 ZIP을 같은 이름으로 덮어써 올리고 보고서 초안 도우미에서 스위치가 켜져 있는지 확인합니다. 적용한 뒤에는 지난 분기 보고서 PDF로 PPT를 한 번 다시 받아, 제목 방식과 숫자 표기가 새 양식대로 바뀌었는지 이전 결과와 비교합니다. 양식이 바뀔 때마다 지침을 고치지 않아도 되어, 보고서를 쓰는 동료들이 같은 결과를 받습니다.

ZIP 업로드를 누르면 "SKILL.md를 포함한 ZIP 파일을 업로드하세요."라는 안내와 함께 스킬 업로드 창이 열립니다. ZIP 파일 칸을 눌러 ZIP을 고르면 칸에 파일 이름이 표시됩니다. 스킬 종류는 이 창에서 문서 작성이 먼저 골라져 있습니다. 설명(선택, 200자까지)을 적고, 같은 이름의 스킬을 고쳐 다시 올릴 때는 동일한 이름의 스킬을 덮어쓰기를 체크합니다. 마지막으로 업로드를 누릅니다.

스킬 업로드 창

번호메뉴기능이런 때 사용하세요
1ZIP 파일올릴 ZIP을 고릅니다. 고른 파일 이름이 칸에 표시됩니다.준비한 양식 ZIP을 올릴 때
2설명다른 사용자와 공유할 때 보이는 설명입니다(선택, 200자까지). 스킬 목록에서 이름 아래에도 보입니다.스킬이 무엇을 하는지 적어 둘 때
3동일한 이름의 스킬을 덮어쓰기같은 이름의 스킬이 있으면 올린 내용으로 바꿉니다.양식을 고쳐 다시 올릴 때
4업로드스킬을 올립니다. 올라가면 창이 닫히고 스킬 목록에 새 스킬이 생깁니다.확인을 마쳤을 때

ZIP 파일과 설명 사이의 스킬 종류는 일반과 문서 작성 중 고르는 칸이며, 이 창에서는 문서 작성이 먼저 골라져 있습니다.

ZIP을 만들 때 지킬 점은 다음과 같습니다.

  • ZIP 최상위나 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다. 없으면 "ZIP 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다."가 나옵니다.
  • SKILL.md 맨 앞에 --- 줄로 감싼 머리말이 있고, 그 안에 name 값이 있어야 합니다. name은 소문자로 시작하고 소문자 영문, 숫자, 밑줄, 하이픈만 쓸 수 있으며 64자까지입니다. anthropic, claude는 넣을 수 없습니다.
  • ZIP은 50MB까지이고, ZIP 파일만 올릴 수 있습니다(그 밖의 파일은 "ZIP 파일만 업로드할 수 있습니다").
  • 안에 넣을 수 있는 확장자는 .md, .txt, .json, .yaml, .yml, .csv, .py, .sh, .js, .ts, .html, .xml, .toml, .docx, .pptx, .xlsx, .pdf, .png, .jpg, .jpeg, .gif입니다. 다른 확장자가 하나라도 있으면 "허용되지 않은 확장자의 파일이 포함되어 있어 업로드할 수 없습니다"와 함께 허용 확장자가 안내됩니다.

따라 해 보기​

  1. SKILL.md에 머리말(name: braincrew-report-style, description: 브레인크루 사내 보고서 작성 규칙)과 본문 규칙(두괄식 제목, 슬라이드당 메시지 1개, 숫자는 천 단위 쉼표, 출처는 장 아래에 표기)을 적고, 표지 예시 .pptx 한 개와 함께 braincrew-report-style 폴더째 ZIP으로 묶습니다.
  2. 보고서 초안 도우미 대화 화면 사이드바에서 에이전트 설정을 누르고, 오른쪽 스킬 > 문서 작성 스킬 > ZIP 업로드를 누릅니다.
  3. ZIP 파일 칸에서 ZIP을 고르고, 설명에 "브레인크루 사내 보고서 작성 규칙"을 적은 뒤 업로드를 누릅니다.
  4. 스킬 목록에 생긴 braincrew-report-style의 스위치를 켜고 머리줄의 저장을 누릅니다. "저장되었습니다"가 나오면 적용된 것입니다.
  5. 대화 화면으로 돌아가 1단계 PPT 요청을 다시 보내고, 제목과 숫자 표기가 스킬 규칙대로 바뀌었는지 비교합니다.

팁: 켠 스킬은 스킬 목록 단계에 이름이 나타나지만, 에이전트가 요청에 맞는 기본 문서 스킬만 불러오고 내 스킬은 건너뛸 수도 있습니다. 따라 해 본 결과에서도 그랬습니다. 이럴 때는 "braincrew-report-style 스킬을 불러와 그 규칙대로 방금 PPT를 다시 만들어 주세요."처럼 스킬 이름을 요청에 적으면, 스킬 불러오기 단계에서 그 스킬을 읽고 규칙대로 다시 만듭니다. 늘 쓰게 하려면 에이전트 지침에 "PPT를 만들 때는 braincrew-report-style 스킬을 먼저 불러온다"를 넣어 둡니다.

스킬을 화면에서 직접 쓰거나 에셋 화면의 스킬 탭에서 관리하는 방법은 스킬 만들기와 업로드에서 설명합니다.

정리​

  • 그대로 제출할 PPT·Word·Excel 파일이 필요하면 문서작성 에이전트와 캔버스를, 답변을 빠르게 옮기려면 일반 에이전트의 아티팩트를 씁니다.
  • 요청에 장 수, 순서, 숫자 규칙을 적고, 결과의 숫자는 원본과 한 번 더 대조합니다. 같은 채팅에서 이어 요청하면 PPT에 이어 요약 Word를 받을 수 있습니다.
  • 캔버스는 원본 다운로드와 PDF를, 아티팩트는 HTML·Word·PPTX와 데이터 표의 Excel·CSV를 내보냅니다.
  • 반복되는 양식은 스킬 > 문서 작성 스킬 > ZIP 업로드로 붙입니다.
