PPT·문서 만들기

보고 자료를 PPT로 옮기고 같은 내용을 Word 요약본으로 다시 쓰는 일은 자주 반복되지만 손이 많이 갑니다. Deep Agent Builder에서는 두 가지 방법으로 PPT·Word·Excel 결과물을 받을 수 있습니다. 하나는 문서작성 에이전트가 실제 파일을 만들어 캔버스에 올리는 방법이고, 다른 하나는 일반 에이전트가 답변을 아티팩트로 보여 주고 내보내는 방법입니다. 이 페이지는 두 방법의 차이를 비교하고, 브레인크루 AI혁신팀 김그루 사원이 "3분기 사내 AI 활용 현황 보고서" PDF로 경영진 보고 PPT와 1쪽 요약 Word를 만드는 과정을 따라 하며, 문서 양식을 스킬로 붙이는 방법까지 설명합니다.

이 페이지에서 할 수 있는 일

  • 캔버스와 아티팩트 중 어떤 방법이 내 업무에 맞는지 고릅니다.
  • 보고서 PDF를 첨부해 PPT를 요청하고, 같은 채팅에서 요약 Word를 이어서 받습니다.
  • 캔버스 내보내기로 원본 .pptx, .docx와 PDF를 내려받습니다.
  • 일반 에이전트의 아티팩트 창에서 미리보기, 코드를 보고 HTML, Word, PPTX, Excel, CSV, Markdown으로 내보냅니다.
  • 에이전트 편집 화면 스킬 탭의 문서 작성 스킬에 ZIP을 올려 회사 양식을 에이전트에 붙입니다.

두 가지 방법 비교​

구분문서작성 에이전트(캔버스)일반 에이전트(아티팩트)
설정에이전트 편집 화면 설정 탭 에이전트 모드를 문서작성 에이전트로별도 설정 없음. 지침에 아티팩트로 답하도록 적거나, 데이터를 표로 분석할 때 생김
만드는 것실제 .pptx, .docx, .xlsx 파일(필요하면 .md, .html도)답변 안의 미리보기(프레젠테이션, 스프레드시트, 문서, 웹페이지, 데이터 표)
보는 곳대화 오른쪽 문서 캔버스입력란 아래 오른쪽의 아티팩트 버튼이나 답변의 아티팩트 카드를 눌러 여는 아티팩트 창(저절로 열리지 않음)
고치는 방법대화로 요청. 문서 요소 선택으로 고칠 곳을 집어 요청대화로 요청
내려받기원본 다운로드, 문서 종류에 따라 PPTX·DOCX·XLSX·PDFHTML, Word(.doc), PPTX, 데이터 표는 Excel·CSV. PDF는 지원하지 않음
이럴 때그대로 보고·제출할 Office 파일이 필요할 때답변을 빠르게 훑어보고 필요한 형식으로 옮길 때

아티팩트 창의 안내에도 PPT를 만들 때는 전용 에이전트를 쓰는 편이 디자인과 완성도가 낫다고 적혀 있습니다. 보고·제출용 PPT와 Word는 문서작성 에이전트로 만드는 것을 권합니다. 캔버스 화면 자체는 캔버스로 문서·PPT·표 만들기에서 자세히 설명합니다.

따라 하기: 3분기 AI 활용 현황 보고 PPT와 요약 Word​

준비물​

항목내용
에이전트제안서 PPT 작성기(문서작성 에이전트). 만드는 방법은 캔버스로 문서·PPT·표 만들기의 "문서작성 에이전트로 바꾸기"에 있습니다.
자료보고서-3분기-AI활용현황.pdf(가상 자료). 월간 활성 사용자 412명(2분기 대비 18% 증가), 부서별 사용 현황 표(경영지원본부 86명, 영업본부 131명, 연구개발본부 142명, AI혁신팀 53명), 성과·문제점·4분기 계획이 들어 있습니다.
첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm

1단계: PPT 요청​

  1. 사이드바에서 제안서 PPT 작성기를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드로 보고서-3분기-AI활용현황.pdf를 붙입니다.

  3. 아래 프롬프트를 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 3분기 사내 AI 활용 현황 보고서로 경영진 보고용 PPT 5장을 만들어 주세요. 이번 자료는 고객 제안서가 아니라 내부 보고용이니 표지, 요약, 부서별 사용 현황, 성과와 문제점, 4분기 계획 순서로 구성하고, 부서별 표의 숫자는 보고서 그대로 넣어 주세요.

  4. 에이전트가 여러 단계를 차례로 실행합니다. 예를 들어 PowerPoint 문서 생성, 슬라이드 추가, 문서를 캔버스에 게시 단계가 대화에 한 줄씩 쌓입니다. 몇 분 걸릴 수 있습니다.

팁: 지침에 정해 둔 순서와 다른 문서를 받고 싶을 때는 요청에 "이번 자료는 … 순서로"처럼 순서를 직접 적습니다. 매번 같은 순서로 받는 자료라면 그 순서를 에이전트 지침이나 문서 작성 스킬에 넣어 둡니다.

2단계: 캔버스에서 PPT 확인​

작성이 끝나면 답변 끝에 프레젠테이션 카드가 생깁니다. 카드를 눌러 캔버스에서 슬라이드를 넘겨 보며 숫자를 원본과 대조합니다.

결과를 이렇게 확인하세요

  • 요약 장의 월간 활성 사용자 412명, 2분기 대비 18% 증가, 문서 작성·회의록 정리 비중 61%가 보고서와 같은지 봅니다.
  • 부서별 표의 네 부서 숫자를 더하면 86 + 131 + 142 + 53 = 412명으로 요약 숫자와 맞아야 합니다. 영업본부 증가율 42%가 가장 높게 표시됐는지도 봅니다.
  • 성과 장에 주간 업무 보고 작성 시간 52분 → 31분, 회의록 정리 1,240건 중 92% 수정 없이 공유가 들어갔는지 봅니다.
  • 4분기 계획 장의 목표 월간 활성 사용자가 480명인지 봅니다.
  • 보고서에 없는 숫자가 들어갔다면 그 장을 문서 요소 선택으로 골라 "보고서에 없는 숫자는 빼 주세요"라고 요청합니다.

3단계: 같은 채팅에서 요약 Word 받기​

PPT를 받은 채팅에서 이어서 요청하면 에이전트가 앞에서 읽은 보고서 내용을 이어받아 Word 문서를 만듭니다. 작성이 끝나면 답변 끝에 문서 · 캔버스에서 열기가 적힌 카드가 생기고, 캔버스에는 PPT와 Word가 탭으로 나란히 놓여 오가며 숫자를 맞춰 볼 수 있습니다. Word 미리보기는 페이지 단위로 보이므로 1쪽 안에 들어갔는지도 확인합니다.

프롬프트: 같은 보고서 내용을 경영진 메일에 붙일 1쪽 요약 보고서로 Word 문서를 만들어 주세요. 제목, 핵심 숫자 표, 문제점 2가지, 4분기 요청 사항 순서로 써 주세요.

결과를 이렇게 확인하세요

  • 문제점 2가지가 보고서의 "표가 많은 문서의 요약 품질", "스캔 문서 글자 인식 오류(17건)·부서별 회의록 양식 차이" 내용과 맞는지 봅니다.
  • 4분기 요청 사항에 공통 회의록 양식, 표 중심 문서 프리셋 배포, 스캔 문서 원본 재확인 절차가 들어갔는지 봅니다.

4단계: 내려받기​

  1. 캔버스 탭에서 PPT를 고르고 내보내기 > 원본 다운로드로 .pptx를 받습니다.
  2. 요약 Word 탭을 고르고 내보내기 > PDF 형식으로 내보내기로 PDF를 받습니다. 고쳐 쓸 문서가 필요하면 원본 다운로드로 .docx를 받습니다.
  3. 받은 파일 이름을 "2026년 3분기 AI 활용 현황 보고.pptx"처럼 바꿔 보관합니다.

내려받지 못하면 "다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."가 나옵니다. 에이전트 조회·실행 권한이 있는지 관리자에게 확인합니다.

일반 에이전트의 아티팩트로 받기​

일반 에이전트도 답변을 아티팩트로 보여 줄 수 있습니다. 아티팩트는 에이전트의 답변 결과를 창에서 바로 확인하고 필요한 파일 형식으로 내보내는 미리보기입니다. 다음 경우에 만들어집니다.

  • 에이전트 지침에 아티팩트로 답하도록 적혀 있을 때. 지침에 설정이 없으면 "아티팩트 만들어줘"라고 요청해도 만들어지지 않을 수 있습니다.
  • 엑셀(.xlsx, .xls, .xlsb, .xlsm)이나 CSV(.csv) 파일의 데이터로 표를 만들거나 분석할 때. 결과 표가 데이터 표로 자동으로 들어옵니다.

아티팩트 창은 저절로 열리지 않습니다. 답변에 생긴 아티팩트 카드("클릭하여 확인하기")를 누르거나, 입력란 아래 오른쪽의 아티팩트 버튼을 눌러 엽니다. 버튼의 숫자는 이 채팅에 모인 항목 수입니다. 예를 들어 김그루 사원이 판매 데이터 분석가에게 판매 실적 엑셀을 올려 지역별 매출 표를 받은 뒤 아티팩트를 누르면 아래와 같이 쓸 수 있습니다.

  • 왼쪽 아티팩트 목록에는 이 채팅에서 만든 아티팩트와 캔버스 문서, 에이전트가 만든 다운로드 파일이 모입니다. 데이터 표에는 "5행 × 3열"처럼 표 크기가 붙습니다.
  • 오른쪽에서 미리보기와 코드를 번갈아 눌러 실제 모양과 원본 내용을 봅니다.
  • 데이터 표는 전체 데이터 보기를 누르면 전체 행을 다시 불러와 보여 주고, 간단하게 보기로 돌아갈 수 있습니다.
  • 내보내기로 내보낼 형식을 고릅니다. 형식은 아래 "내보내기 형식"에 있습니다.
  • 아티팩트 도움말에는 아티팩트가 언제 만들어지는지, 어떤 형식으로 내보낼 수 있는지 안내되어 있습니다. 닫기를 누르면 대화로 돌아갑니다.

내보내기 형식​

아티팩트메뉴 항목받는 파일
모든 아티팩트HTML 다운로드, Word로 내보내기, PPTX로 내보내기.html, .doc, .pptx
데이터 표위 항목에 더해 Excel로 내보내기, CSV로 내보내기.xlsx, .csv
문서 내보내기 도구로 만든 문서위 항목에 더해 Markdown 내보내기.md
  • HTML 다운로드, Word로 내보내기, PPTX로 내보내기를 고르면 아티팩트 선택 창이 열립니다. 전체 선택이나 체크 상자로 넣을 아티팩트를 고른 뒤 내보냅니다. 여러 개를 고르면 한 파일로 묶입니다.
  • PDF 형식은 지원하지 않습니다. PDF가 필요하면 Word로 받아 PDF로 저장하거나, 문서작성 에이전트의 캔버스를 씁니다.
  • Word로 내보내기로 받는 파일은 예전 Word 형식(.doc)입니다. 대화의 파일 업로드와 에이전트 편집 화면 파일 탭은 Word 파일을 .docx만 받으므로, 받은 .doc 파일은 그대로 다시 올릴 수 없습니다. 다시 올려야 하면 Word에서 .docx로 저장한 뒤 올립니다.
  • 원본 데이터가 더 이상 남아 있지 않으면 "원본 데이터가 더 이상 남아 있지 않아 불러올 수 없습니다. 에이전트에게 표를 다시 만들어 달라고 요청해 주세요."가 나옵니다.

따라 해 보기​

  1. 사이드바에서 판매 데이터 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드로 브레인크루_2026_판매실적.xlsx를 붙이고 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 판매실적 엑셀의 판매내역 시트로 지역별, 제품별 매출 합계 표를 만들어 주세요.

  3. 답변이 끝나면 입력란 아래 오른쪽의 아티팩트를 누릅니다. 목록에서 데이터 표를 고르고 전체 데이터 보기를 누릅니다.

  4. 내보내기 > Excel로 내보내기로 표를 받습니다.

데이터 분석 전반은 데이터 분석에서 설명합니다.

문서 작성 스킬로 양식 붙이기​

회사 보고서 양식, 표지 문구, 숫자 표기 규칙처럼 매번 지켜야 할 내용은 문서 작성 스킬로 만들어 에이전트에 붙입니다. 문서 작성 스킬은 문서작성 에이전트가 문서를 만들 때 쓰는 스킬이며, 에이전트 편집 화면 오른쪽 스킬 탭에서 관리합니다. 스킬 탭에는 제목 스킬 선택과 "에이전트에서 사용할 스킬을 선택하세요"가 보이고, 문서 작성 스킬과 일반 스킬 하위 탭이 있습니다. 문서 작성 스킬 탭에는 ZIP 업로드 버튼과 스킬 목록이 있고, 스킬마다 켜기 스위치가 붙어 있습니다. 아직 없으면 "문서 작성 스킬이 없습니다. ZIP으로 업로드하세요."가 보입니다. 스킬을 만들 권한이 없으면 ZIP 업로드를 누를 수 없습니다.

ZIP 업로드를 누르면 스킬 업로드 창이 열립니다. ZIP 파일 선택으로 ZIP을 고르면 "ZIP 파일 확인 중..."이 잠깐 표시되며 안에 든 파일을 검사합니다. 설명(선택)을 적고, 스킬 종류는 이 창에서 문서 작성이 먼저 골라져 있습니다. 같은 이름의 스킬을 고쳐 다시 올릴 때는 동일한 이름의 스킬을 덮어쓰기를 체크합니다. 마지막으로 업로드를 누릅니다.

ZIP을 만들 때 지킬 점은 다음과 같습니다.

  • ZIP 최상위나 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다. 없으면 "ZIP 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다."가 나옵니다.
  • SKILL.md 맨 앞에 --- 줄로 감싼 머리말이 있고, 그 안에 name 값이 있어야 합니다. name은 소문자로 시작하고 소문자 영문, 숫자, 밑줄, 하이픈만 쓸 수 있으며 64자까지입니다. anthropic, claude는 넣을 수 없습니다.
  • ZIP은 50MB까지이고, ZIP 파일만 올릴 수 있습니다(그 밖의 파일은 "ZIP 파일만 업로드할 수 있습니다").
  • 안에 넣을 수 있는 확장자는 .md, .txt, .json, .yaml, .yml, .csv, .py, .sh, .js, .ts, .html, .xml, .toml, .docx, .pptx, .xlsx, .pdf, .png, .jpg, .jpeg, .gif입니다. 다른 확장자가 하나라도 있으면 "허용되지 않은 확장자의 파일이 포함되어 있어 업로드할 수 없습니다"와 함께 허용 확장자가 안내됩니다.

따라 해 보기​

  1. SKILL.md에 머리말(name: braincrew-report-style, description: 브레인크루 사내 보고서 작성 규칙)과 본문 규칙(두괄식 제목, 슬라이드당 메시지 1개, 숫자는 천 단위 쉼표, 출처는 장 아래에 표기)을 적고, 표지 예시 .pptx 한 개와 함께 ZIP으로 묶습니다.
  2. 제안서 PPT 작성기 에이전트 편집 화면에서 스킬 > 문서 작성 스킬 > ZIP 업로드를 누릅니다.
  3. ZIP 파일 선택으로 ZIP을 고르고, 설명에 "브레인크루 사내 보고서 작성 규칙"을 적은 뒤 업로드를 누릅니다.
  4. 스킬 목록에 생긴 braincrew-report-style을 켭니다.
  5. 대화 화면으로 돌아가 1단계 PPT 요청을 다시 보내고, 제목과 숫자 표기가 스킬 규칙대로 바뀌었는지 비교합니다.

스킬을 화면에서 직접 쓰거나 에셋 화면의 스킬 탭에서 관리하는 방법은 스킬 만들기와 업로드에서 설명합니다.

정리​

  • 그대로 제출할 PPT·Word·Excel 파일이 필요하면 문서작성 에이전트와 캔버스를, 답변을 빠르게 옮기려면 일반 에이전트의 아티팩트를 씁니다.
  • 요청에 장 수, 순서, 숫자 규칙을 적고, 결과의 숫자는 원본과 한 번 더 대조합니다. 같은 채팅에서 이어 요청하면 PPT에 이어 요약 Word를 받을 수 있습니다.
  • 캔버스는 원본 다운로드와 PDF를, 아티팩트는 HTML·Word·PPTX와 데이터 표의 Excel·CSV를 내보냅니다.
  • 반복되는 양식은 스킬 > 문서 작성 스킬 > ZIP 업로드로 붙입니다.
