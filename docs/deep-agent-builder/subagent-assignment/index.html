Deep Agent Builder 서브에이전트 할당하기

부모 에이전트에 서브에이전트를 연결하면 부모가 사용하는 자원 구성에 위임 대상을 포함할 수 있습니다. 이 페이지에서는 연결 가능한 대상을 고르고 저장 결과와 실행 전 권한을 확인하는 방법을 설명합니다. 실행 중 동적으로 대상을 선택하는 경로는 이 페이지의 범위가 아니며, 연결된 구성을 먼저 점검하려면 멀티에이전트 개념을 확인하세요.

시작하기 전에 확인할 것​

서브에이전트를 연결하려면 부모 에이전트와 대상 에이전트를 같은 호출자 소유 범위에서 확인할 수 있어야 합니다. 대상은 보관되지 않은 일반 에이전트여야 하며 Super Agent는 선택할 수 없습니다. 부모 자신을 다시 연결하거나 이미 연결된 대상을 중복으로 추가하면 저장할 수 없습니다.

부모 에이전트의 편집 권한과 서브에이전트의 실행 권한은 별개입니다. 목록을 읽는 데 필요한 권한이 있어도 연결을 저장하거나 실행할 때 필요한 권한까지 얻는 것은 아닙니다.

서브에이전트를 연결하는 순서​

  1. 부모 에이전트의 편집 화면에서 서브에이전트 목록을 엽니다. 실제 화면의 메뉴 이름이 이 문서와 다르면 현재 UI에서 서브에이전트 목록에 해당하는 영역을 확인합니다.
  2. 대상 목록에서 부모와 같은 호출자 소유 범위에 있는 일반 에이전트를 선택합니다. 보관 상태이거나 Super Agent인 대상은 선택하지 않습니다.
  3. 대상의 소유 범위와 상태를 확인한 뒤 부모의 연결 목록에 추가합니다. 자기 자신을 가리키거나 기존 연결과 중복되는지 함께 확인합니다.
  4. 저장합니다. 연결 API는 선택한 서브에이전트 참조를 부모 에이전트 설정에 반영합니다. 저장 응답이 성공해도 실행 가능 여부가 확정된 것은 아닙니다.
  5. 저장 후 부모 상세 정보의 서브에이전트 목록을 다시 조회해 의도한 대상만 남았는지 확인합니다. 목록이 갱신되지 않으면 화면의 임시 선택 상태를 저장 완료로 보지 않습니다.

저장이 거부될 때 판단하기​

다음 오류는 입력을 조금 바꿔 재시도하기 전에 원인을 구분해야 합니다.

상황먼저 확인할 것다음 판단
대상이 목록에 없음소유 범위, 보관 상태, Super Agent 여부대상 자격이 맞는 다른 에이전트를 선택합니다.
자기 자신을 추가할 수 없음부모와 대상의 식별자가 같은지다른 에이전트를 선택합니다. 자기 참조를 우회하지 않습니다.
순환 참조로 저장이 거부됨연결하려는 대상이 부모를 직접 또는 간접으로 참조하는지cycle을 끊은 뒤 다시 저장합니다.
중복 연결로 저장이 거부됨부모의 현재 연결 목록기존 참조를 유지하고 새 항목을 추가하지 않습니다.
저장 권한이 없음부모 에이전트 편집 권한과 대상 사용 권한권한을 확인한 뒤 재시도합니다. 권한 오류를 대상 없음으로 판단하지 않습니다.

부모의 자산 배열은 부분 추가가 아니라 전체 교체로 처리될 수 있으므로, 저장 요청에 포함할 목록을 현재 설정과 대조하세요. 서브에이전트만 바꾸려는 작업에서 다른 tool, middleware, skill 연결을 실수로 비우지 않도록 저장 범위를 확인해야 합니다.

실행 전에 다시 확인할 것​

실행을 시작하면 Service API가 부모 에이전트와 선택된 thread, 실행 모드에 연결된 자원을 모아 권한을 평가합니다. 이때 허용 결과는 permission snapshot으로 보존됩니다. Runtime은 snapshot을 그대로 신뢰하지 않고 실행 ID와 부모 에이전트의 일치 여부, 만료와 재사용 여부, 직접 연결된 서브에이전트와 자원의 포함 여부, RESOURCE_CAN_USE 권한을 다시 확인합니다.

검사에 실패하면 graph를 구성하거나 호출하기 전에 실행이 중단됩니다. 따라서 저장 목록이 올바른데 실행이 시작되지 않는다면 부모 편집 화면부터 다시 저장하지 말고 실행 전 권한 검사 결과에서 권한 거부, 만료, 재사용, 정책 결정 시간 초과를 구분하세요.

완료 확인​

연결 작업은 다음 조건을 모두 확인했을 때 완료로 판단합니다.

  • 부모의 서브에이전트 목록에 의도한 대상이 저장되어 있습니다.
  • 대상이 호출자 소유 범위에 있고 보관 상태나 Super Agent가 아닙니다.
  • 자기 참조, 중복, 순환 참조가 없습니다.
  • 부모의 다른 자원 연결이 저장 과정에서 바뀌지 않았습니다.
  • 실행 전 권한 검사에서 직접 연결된 서브에이전트와 자원이 허용 목록에 포함됩니다.
  • 실행이 중단됐다면 저장 상태와 실행 전 권한 검사 결과를 분리해 확인했습니다.
