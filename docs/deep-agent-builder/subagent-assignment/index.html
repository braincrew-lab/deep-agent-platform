서브에이전트 할당하기

이 페이지는 에이전트 편집 화면에서 다른 에이전트를 서브에이전트로 붙이는 방법을 화면 순서대로 안내합니다. 예시로 브레인크루 AI혁신팀 김그루 사원이 "업무 총괄 비서"를 만들고 회의록 요약 도우미, 주간 업무 보고서 도우미, 판매 데이터 분석가를 서브에이전트로 붙입니다. 서브에이전트가 무엇인지 먼저 알고 싶다면 멀티에이전트 개념을 읽고 오세요.

이 페이지에서 할 수 있는 일

  • 총괄 에이전트를 만들고, 지침에 어떤 일을 누구에게 맡길지 적어 둡니다.
  • 서브에이전트 관리 창의 내 에이전트 탭과 워크스페이스 에이전트 탭에서 담당 에이전트를 찾아 추가하거나 뺍니다.
  • 폼 보기와 비주얼 보기에서 연결 상태를 확인하고 저장합니다.
  • 대화로 에이전트를 만들 때 나오는 서브에이전트 추천을 승인하거나 수정을 요청합니다.
  • 총괄 에이전트를 워크스페이스에 등록할 때 서브에이전트를 먼저 배포해야 하는 이유를 알아 둡니다.

시작하기 전에​

서브에이전트로 붙일 에이전트가 먼저 있어야 합니다. 이 페이지의 예시에서는 김그루 사원이 미리 만들어 둔 세 에이전트를 씁니다.

담당 에이전트맡는 일만드는 방법
회의록 요약 도우미회의록에서 결정 사항, 담당, 기한을 뽑아 요약합니다.사례: 회의록 요약과 액션 아이템
주간 업무 보고서 도우미업무 메모를 주간 보고서 형식으로 정리합니다.사례: 주간 업무 보고서 작성
판매 데이터 분석가판매 엑셀을 집계하고 표와 차트로 정리합니다.사례: 엑셀 판매 데이터 분석

각 에이전트는 붙이기 전에 혼자서도 제대로 동작하는지 확인해 두세요. 혼자서 엉뚱한 답을 내는 에이전트는 서브에이전트로 붙여도 같은 답을 냅니다.

총괄 에이전트 편집 화면​

서브에이전트는 총괄 역할을 할 에이전트의 에이전트 편집 화면에서 붙입니다. 홈 화면의 에이전트 직접 만들기로 "업무 총괄 비서"를 만들면 에이전트 편집 화면이 열립니다. 가운데 편집 영역은 위쪽의 폼과 비주얼로 두 보기를 바꿔 볼 수 있습니다. 폼 보기에서는 지침 입력란 아래에 서브에이전트 칸이 있고, 그 아래에 모델 칸이 있습니다. 비주얼 보기는 아래 "비주얼 보기에서 확인하기"에서 설명합니다. 아직 서브에이전트가 없으면 이 칸에 "서브에이전트가 없습니다"가 보입니다. 칸 오른쪽의 톱니바퀴 버튼(서브에이전트 관리)을 누르면 담당을 붙이거나 빼는 창이 열립니다. 헤더의 저장은 이름, 설명, 지침을 현재 버전에 저장하는 버튼이며, 저장할 변경이 없으면 흐리게 표시됩니다.

아래 그림은 업무 총괄 비서를 만들고 지침을 적어 저장한 직후의 화면입니다.

총괄 에이전트 편집 화면

번호메뉴기능이런 때 사용하세요
1지침 입력란총괄 에이전트가 따를 지침입니다. 어떤 일을 어느 서브에이전트에게 맡길지 이름을 넣어 적어 둡니다."회의록 정리는 회의록 요약 도우미에게 맡긴다"처럼 분담 규칙을 정할 때
2서브에이전트 칸연결된 서브에이전트 이름이 표시됩니다. 지금은 "서브에이전트가 없습니다"입니다.지금 누구에게 일을 나눠 맡기고 있는지 확인할 때
3서브에이전트 관리톱니바퀴 버튼입니다. 서브에이전트를 추가하거나 빼는 창을 엽니다.담당 에이전트를 새로 붙이거나 뺄 때
4저장이름, 설명, 지침을 현재 버전에 저장합니다. 서브에이전트 추가나 제거처럼 바로 적용된 변경도 이때 현재 버전에 기록됩니다. 저장할 변경이 없으면 흐리게 표시됩니다.지침을 다 쓴 뒤, 또는 "저장되지 않은 변경이 있습니다"가 보일 때

총괄 에이전트의 지침에는 맡길 일, 넘길 자료, 받을 결과, 마지막 답변 형식을 함께 적습니다. 업무 총괄 비서의 지침 입력란에는 다음과 같이 적습니다.

프롬프트: 너는 브레인크루 AI혁신팀의 업무 총괄 비서야. 요청을 받으면 아래 순서로 담당 에이전트에게 일을 나눠 맡기고 결과를 모아 답해.

  1. 회의록 정리(결정 사항, 담당자, 기한)는 "회의록 요약 도우미"에게 맡기고, 첨부한 회의록 파일 이름을 함께 넘긴다.
  2. 판매 실적 집계는 "판매 데이터 분석가"에게 맡기고, 판매 엑셀 파일 이름과 집계 기간을 함께 넘긴다.
  3. 주간 보고서 작성은 "주간 업무 보고서 도우미"에게 맡기고, 업무 메모와 1번, 2번 결과를 함께 넘긴다.
  4. 마지막 답변 맨 위에 이번 주 핵심 3줄을 쓰고, 수치는 담당 에이전트가 준 값만 쓴다. 담당이 확인하지 못한 내용은 "확인 필요"로 남긴다.

서브에이전트 관리 창​

서브에이전트 관리 버튼을 누르면 서브에이전트 관리 창이 열립니다. 창 제목 아래에는 "이 에이전트가 작업을 위임할 수 있는 서브에이전트를 추가하거나 제거합니다."라는 설명이 있습니다. 왼쪽 현재 서브에이전트에는 지금 연결된 서브에이전트가 괄호 안 개수와 함께 나오고, 하나도 없으면 현재 서브에이전트 (0) 아래에 "서브에이전트가 없습니다"가 보입니다. 오른쪽 사용 가능한 에이전트에는 붙일 수 있는 에이전트가 내 에이전트 탭과 워크스페이스 에이전트 탭으로 나뉘어 나옵니다. 창을 열면 내 에이전트 탭이 먼저 보입니다. 오른쪽 위 "에이전트 검색..." 칸에 낱말을 넣으면 이름이나 설명에 그 낱말이 들어간 에이전트만 남습니다.

에이전트 카드에는 이름과 설명 앞부분이 보이고, 카드를 누르면 창이 닫히고 그 에이전트의 에이전트 편집 화면으로 이동합니다. 카드의 추가를 누르면 그 에이전트가 바로 서브에이전트로 연결됩니다. "서브에이전트가 추가되었습니다" 알림이 나오고 카드가 왼쪽 현재 서브에이전트로 옮겨 갑니다. 연결은 이 순간 적용되어 대화와 테스트 탭에서 바로 새 구성으로 실행됩니다. 현재 버전에 기록하는 방법은 아래 "저장하고 확인하기"에서 설명합니다.

서브에이전트 관리 창

번호메뉴기능이런 때 사용하세요
1내 에이전트내가 만든 에이전트 가운데 붙일 수 있는 것을 보여 줍니다. 창을 열면 이 탭이 먼저 보입니다. 옆의 워크스페이스 에이전트 탭은 아래 "워크스페이스 에이전트 붙이기"에서 설명합니다.내가 만들어 둔 회의록 요약 도우미를 붙일 때
2검색란"에이전트 검색..." 칸에 낱말을 넣으면 이름이나 설명에 그 낱말이 들어간 에이전트만 남깁니다. 최대 255자까지 입력할 수 있습니다.에이전트가 많아 "회의록"이 들어간 에이전트만 찾고 싶을 때
3에이전트 카드에이전트 이름과 설명 앞부분이 보입니다. 누르면 창이 닫히고 그 에이전트의 에이전트 편집 화면으로 이동합니다.붙이기 전에 담당 에이전트의 지침이 맞는지 열어 볼 때
4추가그 에이전트를 바로 서브에이전트로 연결합니다. 누르면 "서브에이전트가 추가되었습니다" 알림이 나오고 카드가 왼쪽 현재 서브에이전트로 옮겨 갑니다.회의록 요약 도우미를 업무 총괄 비서의 담당으로 붙일 때

이럴 때 쓰세요: 김그루 사원은 담당을 붙이기 직전에 판매 데이터 분석가 카드를 눌러 그 에이전트 편집 화면으로 넘어가, 지침에 집계 기간을 받아 쓰는 규칙이 있는지 확인합니다. 총괄 지침에 "판매 엑셀 파일 이름과 집계 기간을 함께 넘긴다"고 적어도 담당이 기간을 쓰지 않으면 주간 보고에 엉뚱한 기간의 합계가 들어가기 때문입니다. 확인을 마치면 업무 총괄 비서로 돌아와 서브에이전트 관리 창을 다시 열고 추가를 누릅니다.

내 에이전트 탭에는 붙일 수 없는 에이전트가 처음부터 빠져 있습니다. 지금 설정 중인 에이전트 자신, 이미 붙인 에이전트, 붙이면 두 에이전트가 서로를 맡기게 되는 에이전트, SUPER AI 에이전트는 목록에 나오지 않습니다. 검색한 낱말에 맞는 에이전트가 없으면 "검색과 일치하는 에이전트가 없습니다", 붙일 에이전트가 하나도 없으면 "추가할 수 있는 에이전트가 없습니다"가 표시됩니다.

세 담당을 붙인 상태​

세 담당을 모두 붙이면 왼쪽 제목이 **현재 서브에이전트 (3)**으로 바뀌고, 붙인 에이전트의 이름과 설명이 붙인 순서대로 보입니다. 이미 붙인 에이전트는 오른쪽 목록에서 빠지므로, 검색란에 "보고서"를 넣어도 주간 업무 보고서 도우미는 오른쪽에 나오지 않습니다. 왼쪽 목록의 이름을 누르면 그 에이전트의 에이전트 편집 화면으로 이동하고, 휴지통을 누르면 "서브에이전트가 제거되었습니다" 알림과 함께 서브에이전트에서 빠집니다. 에이전트 자체는 지워지지 않습니다.

아래 그림은 세 담당을 붙인 뒤 검색란에 "보고서"를 넣은 모습입니다.

서브에이전트 세 개를 붙인 상태

번호메뉴기능이런 때 사용하세요
1현재 서브에이전트 (3)연결된 서브에이전트 개수입니다. 추가나 삭제를 누르면 숫자가 바로 바뀝니다.방금 누른 추가가 반영됐는지 확인할 때
2연결된 서브에이전트붙인 에이전트의 이름과 설명이 붙인 순서대로 보입니다. 누르면 그 에이전트의 에이전트 편집 화면으로 이동합니다.담당 에이전트의 지침을 고치러 넘어갈 때
3삭제(휴지통)이 에이전트를 서브에이전트에서 뺍니다. 누르면 "서브에이전트가 제거되었습니다" 알림이 나옵니다. 에이전트 자체는 지워지지 않습니다.잘못 붙인 에이전트를 뺄 때
4검색란입력한 낱말이 들어간 에이전트만 남기고, 아래 오른쪽에 입력한 글자 수를 "3/255"처럼 보여 줍니다.이름이 비슷한 에이전트가 여럿일 때

따라 해 보기​

  1. 홈 화면에서 에이전트 직접 만들기를 누릅니다.
  2. 새 에이전트 만들기 창의 에이전트 이름에 "업무 총괄 비서", **에이전트 설명 (선택)**에 "회의록 요약, 판매 실적 집계, 주간 보고서 작성을 담당 에이전트에게 나눠 맡기고 결과를 모아 보고합니다."를 입력하고 확인을 누릅니다.
  3. 에이전트 편집 화면의 지침 입력란에 위의 지침을 입력하고 헤더의 저장을 누릅니다.
  4. 서브에이전트 칸 오른쪽 톱니바퀴(서브에이전트 관리)를 누릅니다.
  5. 내 에이전트 탭에서 회의록 요약 도우미 카드의 추가를 누르고, 왼쪽 제목이 **현재 서브에이전트 (1)**로 바뀌는지 봅니다.
  6. 같은 방법으로 주간 업무 보고서 도우미와 판매 데이터 분석가를 추가합니다. 목록이 길면 검색란에 "보고서", "판매"를 넣어 찾습니다.
  7. 창 바깥을 누르거나 오른쪽 위 닫기를 눌러 창을 닫습니다.
  8. 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 누릅니다.

팁: 이름이 비슷한 에이전트가 여럿이면 카드의 설명까지 읽고 붙이세요. 잘못 붙였다면 왼쪽 목록의 휴지통으로 빼면 됩니다.

워크스페이스 에이전트 붙이기​

워크스페이스 에이전트 탭에는 워크스페이스에 게시된 에이전트가 워크스페이스 이름별로 묶여 나옵니다. 내 에이전트가 아니어도, 실행 권한이 있는 워크스페이스에 게시된 에이전트라면 서브에이전트로 붙일 수 있습니다. 그림은 브레인크루 워크스페이스에 게시된 주간 업무 보고서 도우미가 후보로 보이는 모습입니다.

워크스페이스 에이전트 탭

번호메뉴기능이런 때 사용하세요
1워크스페이스 에이전트워크스페이스에 게시된 에이전트 후보를 보여 줍니다. 검색란의 낱말이 이 탭에도 적용됩니다.다른 팀이 게시한 에이전트를 담당으로 쓰고 싶을 때
2워크스페이스 이름후보가 게시된 워크스페이스 이름입니다. 그 아래에 그 워크스페이스의 에이전트가 모여 있습니다.같은 이름의 에이전트가 여러 워크스페이스에 있을 때 어느 쪽인지 구분할 때
3추가그 워크스페이스 에이전트를 서브에이전트로 연결합니다. 연결된 항목은 왼쪽 목록에 워크스페이스 표시와 함께 나옵니다.다른 팀의 게시 에이전트를 담당으로 붙일 때

이럴 때 쓰세요: 영업팀 동료가 워크스페이스에 게시한 판매 실적 집계용 에이전트가 팀 집계 기준을 더 잘 따른다면, 김그루 사원은 내 판매 데이터 분석가 대신 그 에이전트를 업무 총괄 비서의 담당으로 붙입니다. 집계 기준이 바뀌면 영업팀이 자기 에이전트를 고쳐 다시 배포하면 되므로, 김그루 사원이 같은 규칙을 따로 관리하지 않아도 됩니다. 다만 게시가 내려가면 왼쪽 목록에 "사용할 수 없는 워크스페이스 에이전트"로 표시되므로, 주간 보고 전날 서브에이전트 칸을 한 번 확인합니다.

후보가 하나도 없으면 이 탭에 "실행 권한이 있는 워크스페이스에 게시된 에이전트만 서브에이전트로 추가할 수 있습니다."라는 안내가 나옵니다. 워크스페이스 에이전트 화면에서 본 에이전트가 이 탭에 없다면 실행 권한이 있는지 확인하세요.

워크스페이스 에이전트 카드에 실행 불가 표시가 붙어 있으면 "실행에 필요한 모델이나 게시 릴리스가 없어 추가할 수 없습니다"라는 설명이 함께 나오고 추가가 눌리지 않습니다. 워크스페이스 에이전트 카드를 누르면 에이전트 편집 화면 대신 그 에이전트의 대화 화면으로 이동합니다. 이미 붙인 워크스페이스 에이전트가 나중에 삭제되거나 권한이 바뀌면 왼쪽 목록에 "사용할 수 없는 워크스페이스 에이전트"로 표시됩니다. 이때는 휴지통으로 빼고 다른 담당을 붙이세요.

저장하고 확인하기​

창을 닫으면 서브에이전트 칸에 붙인 이름이 바로 보입니다. 담당이 세 개라 앞의 두 이름 뒤에 "+1"이 붙습니다.

서브에이전트 추가와 제거는 추가나 휴지통을 누른 순간 적용됩니다. 헤더의 저장을 누르지 않아도 대화와 테스트 탭에서 바로 새 구성으로 실행됩니다. 다만 이 변경은 아직 현재 버전에 기록되지 않았습니다. 그래서 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 나타나고 저장을 누를 수 있게 바뀝니다. 저장을 누르면 지금 구성이 현재 버전에 기록되고, 표시가 사라지며 저장 버튼이 다시 흐리게 바뀝니다.

워크스페이스 등록은 저장된 버전을 기준으로 합니다. 서브에이전트 변경을 저장하지 않은 채 워크스페이스 등록을 요청하면 "저장되지 않은 서브에이전트가 있습니다. 저장한 뒤 다시 시도하세요."라는 안내가 나오고 요청할 수 없습니다. 서브에이전트를 붙이거나 뺀 뒤에는 등록하기 전에 꼭 저장을 누르세요.

비주얼 보기에서 확인하기​

비주얼을 누르면 총괄 에이전트 상자에서 서브 에이전트 상자로 선이 이어진 그림이 나옵니다. 모델, 도구, 스킬, 지식, 미들웨어 상자도 함께 보입니다. 에이전트 상자에는 총괄 에이전트의 이름, 설명, 지침 앞부분(INSTRUCTIONS)이 보이고, 아래 Edit in Form을 누르면 폼 보기로 돌아갑니다. 상자 배치가 흐트러졌다면 오른쪽 위 기본 레이아웃을 누르면 처음 배치로 돌아갑니다.

비주얼 보기의 서브에이전트

번호메뉴기능이런 때 사용하세요
1총괄 에이전트 이름에이전트 상자의 이름입니다. 아래에 설명과 지침 앞부분이 이어집니다.지침에 분담 규칙이 들어 있는지 훑어볼 때
2서브 에이전트 상자총괄 에이전트와 선으로 이어진 서브에이전트 묶음입니다. 연결이 없으면 "No sub-agents"로 표시됩니다.담당이 실제로 연결됐는지 그림으로 확인할 때
3서브에이전트 이름연결된 회의록 요약 도우미, 주간 업무 보고서 도우미, 판매 데이터 분석가입니다. 이름을 누르면 그 에이전트 편집 화면으로 이동할지 묻는 "에이전트 편집" 확인 창이 나오고, 이동하기를 누르면 그 에이전트의 에이전트 편집 화면으로 이동합니다.담당 에이전트의 지침을 바로 고치러 갈 때
4서브에이전트 추가서브에이전트 관리 창을 엽니다. 폼 보기의 톱니바퀴와 같은 창입니다.그림을 보다가 바로 담당을 더 붙일 때

대화 화면에서 연결 확인하기​

설정을 마치고 사이드바의 이 에이전트와 새 대화를 누르면 대화 화면이 열립니다. 입력란 아래 왼쪽의 서브에이전트 버튼을 누르면 세 담당이 펼쳐집니다. 여기서는 목록을 보기만 하고, 추가나 삭제는 에이전트 편집 화면에서 합니다. 화면 모습은 멀티에이전트 개념의 "대화 화면에서 서브에이전트 확인하기"를 참고하세요.

대화로 만들 때 서브에이전트 추천 받기​

홈 화면에서 대화로 새 에이전트를 만들면, 만들기 도우미가 진행 상황의 "6단계: 함께 일할 도우미 에이전트 추천"에서 서브에이전트 목록 확인으로 내 에이전트를 살펴본 뒤 담당으로 붙일 만한 에이전트를 서브에이전트 추천 카드로 보여 줍니다. 추천마다 에이전트 이름, 내부 식별값(UID), **사유:**가 나옵니다. 카드를 승인하면 추천한 에이전트가 새 에이전트의 서브에이전트로 붙습니다. 대화로 만들기 전체 순서는 에이전트 만들기를 참고하세요.

대화로 만들기의 서브에이전트 추천

번호메뉴기능이런 때 사용하세요
1추천 에이전트 이름서브에이전트 추천 카드에 담당으로 추천된 내 에이전트 이름입니다. 그림에서는 요청에 적은 회의록 요약 도우미와 주간 업무 보고서 도우미가 추천되었습니다.추천된 에이전트가 내가 생각한 담당과 같은지 확인할 때
2사유:그 에이전트를 추천한 이유입니다.추천이 요구사항과 맞는지 판단할 때
3승인추천대로 서브에이전트를 붙이고 다음 단계로 넘어갑니다.추천이 마음에 들 때
4수정 요청누르면 "수정 의견을 입력하세요..." 칸이 열립니다. 바라는 점을 적고 다시 수정 요청을 누르면 의견이 전달되고, 취소를 누르면 칸이 닫힙니다.추천 가운데 빼거나 더할 에이전트가 있을 때

따라 해 보기​

홈 화면 입력창에 보낼 요청은 다음과 같습니다.

프롬프트: 매주 금요일 주간 보고를 도와주는 총괄 비서를 만들고 싶어요. 회의록 요약은 회의록 요약 도우미에게, 주간 보고서 작성은 주간 업무 보고서 도우미에게 맡기게 해 주세요.

  1. 홈 화면 입력창에 위 요청을 입력하고 보냅니다.
  2. 만들기 도우미가 묻는 확인 질문에 답합니다. 도구, 동작 방식, 스킬 추천 카드가 차례로 나오면 내용을 보고 승인합니다.
  3. 서브에이전트 추천 카드가 나오면 추천된 이름과 **사유:**를 읽습니다.
  4. 원하는 담당이 모두 들어 있으면 승인을 누릅니다. 빼거나 더할 담당이 있으면 수정 요청을 누르고 "판매 데이터 분석가도 함께 붙여 주세요"처럼 적은 뒤 다시 수정 요청을 누릅니다.
  5. "9단계: 에이전트 생성 완료"까지 끝나고 "에이전트가 완성됐어요!" 안내 아래 바로 이용하기가 나오면 누릅니다. 새 에이전트의 대화 화면이 열리면 사이드바의 에이전트 설정을 눌러 서브에이전트 칸에서 연결을 확인합니다.

팁: 확인 질문이 여러 개 한꺼번에 나오면 "2개의 확인이 필요합니다"처럼 개수가 표시됩니다. 질문마다 답을 고르고 제출을 누르거나, 다음 질문으로 넘기며 모두 고른 뒤 전체 제출을 누르세요.

워크스페이스에 등록할 때​

서브에이전트를 붙인 총괄 에이전트를 동료와 함께 쓰려면 워크스페이스에 등록합니다. 이때 서브에이전트도 먼저 배포되어 있어야 합니다. 서브에이전트가 배포되지 않았거나, 배포된 버전이 총괄 에이전트가 참조하는 버전과 다르면 총괄 에이전트를 배포 요청할 수 없습니다. 배포 전반은 커뮤니티를 참고하세요.

에이전트 편집 화면 헤더의 워크스페이스 등록 아이콘을 누르면 워크스페이스에 에이전트 등록 창이 열립니다. 왼쪽에서 워크스페이스를 고르면 오른쪽 게시 현황 아래에 서브에이전트마다 배포 상태가 나옵니다. 그림은 브레인크루 워크스페이스를 고른 화면으로, 회의록 요약 도우미가 미배포, 판매 데이터 분석가가 저장 필요라서 등록 요청이 막혀 있습니다. 이때 0개 등록 요청 버튼은 눌리지 않습니다.

서브에이전트 미배포로 등록이 막힌 화면

번호메뉴기능이런 때 사용하세요
1워크스페이스 선택등록할 워크스페이스에 체크합니다. 오른쪽에 그 워크스페이스의 게시 현황이 나옵니다.총괄 에이전트를 어느 워크스페이스에 올릴지 고를 때
2서브에이전트 상태서브에이전트 이름 옆에 미배포, 배포됨, 저장 필요 같은 상태가 붙습니다.어느 담당이 등록을 막고 있는지 찾을 때
3제외 안내"배포되지 않은 서브에이전트가 있어 제외됩니다."가 표시되면 그 워크스페이스에는 아직 등록 요청을 보낼 수 없습니다. 서브에이전트가 서로를 맡기는 구성이면 "서브에이전트 순환 참조로 제외됩니다."가 나옵니다.등록 요청 버튼이 눌리지 않는 이유를 확인할 때
4커뮤니티 에이전트 관리에서 서브에이전트 먼저 배포하기커뮤니티 에이전트 관리 화면의 배포 요청 탭으로 이동합니다.담당 에이전트부터 배포 요청하러 갈 때

배포 요청 탭에서 업무 총괄 비서의 배포 요청을 누르면 커뮤니티 에이전트 배포 요청 창이 열립니다. 이 버전에 포함된 구성에는 서브에이전트 3개처럼 담당 목록과 각 담당의 상태가 나옵니다. 상태가 미배포인 담당에는 먼저 배포 요청 버튼이, 버전 불일치인 담당에는 "V2으로 배포 요청"처럼 버전이 붙은 버튼이 나옵니다. 아래에는 "서브에이전트가 모두 배포되고 배포 버전이 이 버전이 참조하는 버전과 같아야 배포 요청할 수 있습니다. 위에 표시된 서브에이전트를 먼저 처리해 주세요."라는 안내가 보이고, 창 아래 배포 요청 버튼은 눌리지 않습니다.

서브에이전트를 먼저 배포하라는 안내

번호메뉴기능이런 때 사용하세요
1서브에이전트 3개이 버전에 포함된 서브에이전트 목록입니다. 이름 옆에 담당마다 상태가 나옵니다. 예를 들어 배포됨 V1, 미배포, 저장 필요, 버전 불일치입니다.어느 담당이 아직 배포되지 않았는지 확인할 때
2미배포 상태아직 배포되지 않은 담당입니다. "미배포 · 게시 예정 v1"처럼 배포될 버전도 함께 보입니다.먼저 처리해야 할 담당을 찾을 때
3먼저 배포 요청그 담당 에이전트의 배포 요청을 엽니다. 요청이 심사 중이면 "승인 후 다시 시도해 주세요"로 바뀝니다.미배포 담당을 하나씩 배포 요청할 때
4배포 차단 안내서브에이전트를 모두 처리하기 전에는 총괄 에이전트를 배포 요청할 수 없다는 안내입니다.총괄 에이전트 요청이 막힌 이유를 확인할 때

따라 해 보기​

  1. 업무 총괄 비서의 에이전트 편집 화면에서 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 먼저 저장을 누릅니다. 그다음 헤더의 워크스페이스 등록을 누르고 등록할 워크스페이스에 체크합니다.
  2. "배포되지 않은 서브에이전트가 있어 제외됩니다."가 보이면 커뮤니티 에이전트 관리에서 서브에이전트 먼저 배포하기를 누릅니다.
  3. 배포 요청 탭에서 업무 총괄 비서의 배포 요청을 누르고, 이 버전에 포함된 구성에서 미배포 담당마다 먼저 배포 요청을 누릅니다. 저장 필요로 표시된 담당은 그 에이전트의 편집 화면에서 먼저 저장합니다.
  4. 관리자가 담당 에이전트의 배포를 승인하면 업무 총괄 비서로 돌아와 다시 워크스페이스 등록을 누릅니다.

팁: 담당 에이전트를 배포한 뒤 그 에이전트를 고쳐 저장하면 "배포됨 V1 · 배포 이후 저장된 변경이 있습니다"처럼 버전 차이가 표시됩니다. 총괄 에이전트를 다시 배포하기 전에 담당 에이전트도 같은 버전으로 다시 배포 요청하세요.

붙이기 전에 확인할 것​

상황화면 표시할 일
붙이려는 에이전트가 목록에 없음"추가할 수 있는 에이전트가 없습니다" 또는 "검색과 일치하는 에이전트가 없습니다"지금 설정 중인 에이전트 자신이거나, 이미 붙였거나, 서로 맡기는 구성이 되는 에이전트인지 확인합니다.
추가를 눌렀는데 연결되지 않음추가에 실패했다는 알림잠시 뒤 창을 다시 열어 시도합니다.
워크스페이스 에이전트를 붙이는 사이 다른 곳에서 같은 에이전트를 고침"다른 곳에서 에이전트가 변경되었습니다. 목록을 새로 불러왔으니 다시 시도해 주세요."새로 불러온 목록을 확인하고 다시 추가합니다.
붙이려던 워크스페이스 에이전트를 더 쓸 수 없음"이 워크스페이스 에이전트는 더 이상 추가할 수 없습니다. 목록을 새로 불러왔습니다."게시가 내려갔거나 권한이 바뀐 것입니다. 다른 담당을 고릅니다.
서브에이전트로 쓰이는 에이전트를 삭제하려 함예: "회의록 요약 도우미" 에이전트는 다른 에이전트의 서브에이전트로 등록되어 있습니다. 삭제하면 해당 참조가 자동으로 제거됩니다. 계속하시겠습니까?그 에이전트를 쓰는 총괄 에이전트가 있는지 먼저 확인합니다. 삭제하면 총괄 에이전트의 서브에이전트 칸에서도 빠집니다.
  • 총괄 에이전트의 지침에 서브에이전트 이름과 맡길 일을 적어 두세요. 지침에 이름이 없으면 총괄 에이전트가 어느 담당에게 맡길지 판단할 근거가 약해집니다.
  • 담당 에이전트의 지침을 고치면 그 담당을 쓰는 모든 총괄 에이전트의 결과가 함께 바뀝니다.
