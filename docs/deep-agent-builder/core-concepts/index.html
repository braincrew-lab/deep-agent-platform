핵심 개념 이해하기

Deep Agent Builder 화면에는 에이전트, 모델, 도구함, 스킬, 지식함, 미들웨어, 서브에이전트, 캔버스, 아티팩트, 워크스페이스, 라운지라는 말이 자주 나옵니다. 이 페이지는 각 용어를 브레인크루 김그루 사원의 업무에 빗대어 설명하고, 실제 화면 어디에서 보이는지 알려 드립니다.

이 페이지에서 할 수 있는 일

  • 에이전트와 지침, 모델, 도구, 스킬, 지식이 각각 무슨 일을 맡는지 구별합니다.
  • 미들웨어와 서브에이전트가 에이전트의 동작에 어떻게 끼어드는지 이해합니다.
  • 문서작성 에이전트와 캔버스, 아티팩트가 결과물을 어떻게 보여 주는지 알아봅니다.
  • 워크스페이스, 템플릿, 라운지, SUPER AI 에이전트, 스레드(채팅)가 무엇을 가리키는지 확인합니다.

한눈에 보는 개념 대응표​

새 업무를 담당자에게 맡기는 장면을 떠올리면 이해가 쉽습니다. 담당자를 정하고, 업무 지시서와 참고 자료를 건네고, 지켜야 할 보안 규칙을 알려 준 뒤 일을 시키는 순서와 같습니다.

개념브레인크루 업무에 빗대면화면에서 보이는 곳
에이전트특정 업무를 맡긴 담당자. 예: 주간 보고서를 전담하는 주간 업무 보고서 도우미사이드바 에이전트 목록
지침담당자에게 준 업무 지시서에이전트 편집 화면의 지침
모델담당자의 두뇌. 글을 읽고 답을 쓰는 AI 엔진에이전트 편집 화면의 모델, 대화 화면 오른쪽 위
도구·도구함담당자가 쓰는 업무 시스템과 그 목록에이전트 편집 화면의 도구함, 입력란 아래 왼쪽의 도구
스킬부서 업무 매뉴얼. 정해진 절차와 형식에셋 화면의 스킬 탭, 에이전트 편집 화면 오른쪽 스킬 탭
지식·지식함담당자 책상 위 참고 자료철에이전트 편집 화면의 지식함
미들웨어결재 전 검토 절차. 예: 개인정보 가리기에이전트 편집 화면의 미들웨어, 입력란 아래 왼쪽의 미들웨어
서브에이전트일을 나눠 맡기는 팀원에이전트 편집 화면의 서브에이전트, 입력란 아래 왼쪽의 서브에이전트
문서작성 에이전트·캔버스PPT·문서 담당자와 결과물을 펼쳐 보는 책상에이전트 편집 화면 설정 탭의 에이전트 모드, 대화 화면 오른쪽 문서 캔버스
아티팩트답변 안에서 바로 열어 보는 결과물 묶음입력란 아래 오른쪽의 아티팩트
워크스페이스회사 공용 게시판. 여러 사람이 함께 쓰는 공간사이드바 워크스페이스 에이전트 탭, 프로필의 기본 워크스페이스
템플릿이미 잘 쓰이는 에이전트를 본뜬 서식사이드바 에이전트 템플릿, 홈 화면 템플릿 카드
라운지사내 게시판사이드바 아래 라운지
SUPER AI 에이전트질문을 받아 알맞은 담당자에게 넘겨 주는 안내 데스크더 보기 메뉴의 SUPER AI 에이전트
스레드(채팅)업무 건별 대화 기록에이전트를 열었을 때 사이드바의 채팅 목록

에이전트와 지침​

에이전트는 한 가지 업무를 맡긴 담당자입니다. 주간 업무 보고서 도우미는 주간 보고서를, 회의록 요약 도우미는 회의록 정리를 맡습니다. 업무 범위가 좁을수록 답변이 안정적입니다.

지침은 그 담당자에게 준 업무 지시서입니다. "보고서는 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표, 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓴다"처럼 매번 지켜야 할 원칙을 적습니다. 이번 주 메모처럼 건마다 달라지는 자료는 지침이 아니라 대화에서 건넵니다.

에이전트는 두 가지 모드 중 하나로 동작합니다. 에이전트 편집 화면 오른쪽 설정 탭의 에이전트 모드에서 일반 에이전트와 문서작성 에이전트 중 하나를 고릅니다. 모드는 고르는 즉시 반영됩니다.

에이전트 편집 화면은 대화 화면 사이드바의 에이전트 설정을 누르면 열립니다. 가운데 편집 영역에는 지침, 서브에이전트, 모델, 도구함, 지식함, 미들웨어 칸이 있고, 오른쪽에는 수정·시험·실행 설정을 다루는 Fix 에이전트, 테스트, 오프너, 파일, 스킬, 스케줄, 설정 탭이 있습니다.

에이전트 편집 화면의 구성 요소

번호메뉴기능이런 때 사용하세요
1지침에이전트의 역할과 답변 기준을 적는 곳입니다. 아래에 현재 글자 수가 함께 표시됩니다.답변 형식이나 하지 말아야 할 일을 정할 때
2서브에이전트 관리서브에이전트 칸의 버튼입니다. 이 에이전트가 일을 나눠 맡길 다른 에이전트를 연결합니다.업무 총괄 비서처럼 여러 담당에게 일을 나눌 때
3모델 설정모델 칸의 버튼입니다. 이 에이전트가 답을 쓸 때 쓰는 AI 모델을 정합니다.답변 품질이나 속도를 비교하며 모델을 바꿀 때
4도구도구함 칸의 버튼입니다. 에이전트가 실행할 수 있는 도구를 연결합니다.웹 검색이나 외부 시스템 조회가 필요할 때

지식함, 미들웨어, 오른쪽 탭

번호메뉴기능이런 때 사용하세요
1지식지식함 칸의 버튼입니다. 답변 근거로 삼을 지식을 연결합니다.사내 규정 문서를 근거로 답하게 할 때
2미들웨어미들웨어 칸의 버튼입니다. 요청과 응답을 처리하기 전후에 거치는 규칙을 연결합니다. 그림의 에이전트에는 개인정보 보호 미들웨어가 붙어 있습니다.계약서 속 이름과 연락처를 가리고 처리하게 할 때
3오른쪽 탭 줄Fix 에이전트, 테스트, 오프너, 파일, 스킬, 스케줄, 설정 탭으로 수정, 시험, 실행 설정을 다룹니다.고친 에이전트를 바로 시험하거나 스킬과 스케줄을 붙일 때

화면의 각 칸을 다루는 방법은 에이전트 수정에 있습니다.

모델​

모델은 담당자의 두뇌에 해당하는 AI 엔진입니다. 질문을 읽고, 지침과 자료를 참고해 답을 씁니다. 에이전트마다 모델을 하나씩 정합니다. 에이전트 편집 화면의 모델 칸에 지금 쓰는 모델 이름이 보이고, 칸 오른쪽의 톱니바퀴 모델 설정을 눌러 바꿉니다. 쓸 수 있는 모델 목록은 사이드바의 에셋설정을 눌러 여는 에셋 화면의 모델 탭에서 확인합니다. API 키가 등록되지 않은 모델에는 [API 키 미등록] 표시가 붙습니다.

대화 화면 오른쪽 위에는 지금 쓰는 모델 이름이 보이고, 대화가 진행되면 그 아래에 입력·출력 토큰 수가 함께 표시됩니다. 토큰은 모델이 읽고 쓴 글의 양을 세는 단위입니다. 질문과 첨부 자료가 길수록 입력이, 답이 길수록 출력이 커집니다. 자세한 내용은 모델 구성에 있습니다.

도구와 도구함​

도구는 담당자가 쓰는 업무 시스템입니다. 웹 검색, 외부 서비스 호출처럼 모델 혼자서는 할 수 없는 일을 실행합니다. 도구함은 에이전트 하나에 연결된 도구의 목록입니다.

도구는 에셋 화면의 도구 탭에서 등록하거나, 더 보기의 유틸리티에서 찾아 설치합니다. 그런 다음 에이전트 편집 화면 도구함의 도구 버튼으로 에이전트에 연결합니다. 대화 화면 입력란 아래 왼쪽의 도구를 누르면 지금 연결된 도구 목록을 볼 수 있습니다. 자세한 구성은 도구와 스킬 구성에서 다룹니다.

스킬​

스킬은 부서 업무 매뉴얼입니다. 도구가 "무엇을 실행할 수 있는가"라면, 스킬은 "이 업무는 이런 순서와 형식으로 한다"는 절차입니다. 예를 들어 브레인크루 보고서 작성 규칙을 스킬로 올려 두면 여러 에이전트가 같은 형식으로 보고서를 씁니다.

스킬은 에셋 화면의 스킬 탭에서 올리고, 에이전트 편집 화면 오른쪽 스킬 탭에서 에이전트에 붙입니다. 이 탭은 문서 작성 스킬과 일반 스킬로 나뉩니다. 대화 중에는 입력란 아래 왼쪽의 스킬에서 스킬을 고르면 그 스킬을 써서 답해 달라는 문장이 입력란에 채워집니다. 만드는 방법은 스킬 만들기와 업로드에 있습니다.

지식과 지식함​

지식은 에이전트가 답할 때 근거로 삼는 문서 모음입니다. 지식함은 담당자 책상 위에 둔 참고 자료철로, 에이전트 하나에 연결된 지식의 목록입니다.

지식은 Deep Connector에 등록된 컬렉션입니다. Deep Agent Builder 안에는 문서를 올려 지식을 만드는 화면이 없고, 에이전트 편집 화면 지식함의 지식 버튼을 눌러 내가 쓸 수 있는 지식을 골라 연결만 합니다. 원하는 지식이 목록에 없다면 관리자에게 접근 권한을 요청하세요. 사내 규정 Q&A 도우미처럼 문서 근거가 중요한 에이전트는 지침에 "지식함의 문서에 근거해 답하고, 문서에 없는 내용은 모른다고 답한다"고 함께 적습니다. 자세한 순서는 지식으로 근거 있는 답변 받기에 있습니다.

미들웨어​

미들웨어는 결재 전에 거치는 검토 절차와 같습니다. 에이전트가 요청을 처리하기 전이나 답을 내보내기 전에 정해진 규칙을 적용합니다.

대표적인 미들웨어는 개인정보(PII) 보호입니다. 계약서 검토 도우미에 이 미들웨어를 붙이면 계약서에 들어 있는 개인정보(예: 이름, 전화번호, 계좌번호)를 찾아 가리거나 마스킹한 뒤 처리합니다. 적용 지점은 사용자 입력, 모델 응답, 도구 결과 중에서 고릅니다. 설정 방법은 미들웨어와 개인정보 보호에서 다룹니다.

서브에이전트​

서브에이전트는 다른 에이전트가 일을 나눠 맡기는 팀원입니다. 업무 총괄 비서에 주간 업무 보고서 도우미, 회의록 요약 도우미, 이메일 초안 도우미를 서브에이전트로 연결해 두면, 총괄 비서가 요청을 보고 알맞은 담당에게 일을 넘깁니다.

서브에이전트로는 내 에이전트와 워크스페이스 에이전트를 연결할 수 있습니다. 개념과 연결 방법은 멀티에이전트 개념과 서브에이전트 할당하기에 있습니다.

문서작성 에이전트와 캔버스​

문서작성 에이전트는 모든 대화를 문서 작성 모드로 실행하는 에이전트입니다. PPT, 워드 문서, 엑셀 파일을 직접 만들고, 다 만든 파일을 대화 화면 오른쪽 문서 캔버스에 올립니다. 제안서 PPT 작성기와 교육 자료 제작 도우미가 이 모드로 동작합니다.

캔버스는 만든 파일을 페이지나 슬라이드 단위로 미리 보는 화면입니다. 캔버스 위쪽에는 파일 이름과 처리 상태(다 만들어지면 준비됨)가 보이고, 파일이 여러 개면 파일마다 탭이 생깁니다. 캔버스 안에서 글자를 직접 고칠 수는 없습니다. 고치고 싶은 부분이 있으면 문서 요소 선택으로 슬라이드나 문단을 골라 메시지에 붙이고, 어떻게 고칠지 대화로 요청합니다. 파일은 캔버스의 내보내기에서 원본 그대로 내려받거나 다른 형식으로 내보냅니다. 지난 답변에서 만든 파일은 답변 속 결과물 카드의 캔버스에서 열기를 눌러 다시 캔버스에 엽니다.

문서작성 에이전트와 캔버스

번호메뉴기능이런 때 사용하세요
1결과물 카드의 캔버스에서 열기답변 속 파일 카드를 눌러 그 파일을 캔버스에 엽니다.지난 답변에서 만든 PPT를 다시 볼 때
2문서 캔버스의 슬라이드 미리보기만든 파일을 페이지나 슬라이드 단위로 미리 봅니다.제안서 슬라이드 구성을 훑어볼 때
3준비됨파일 이름 옆에 보이는 처리 상태입니다. 파일이 다 만들어져 캔버스에 올라가면 준비됨으로 표시됩니다.파일이 완성되었는지 확인할 때
4내보내기원본 파일을 내려받거나 다른 형식으로 내보냅니다.완성한 PPT를 내 PC에 저장할 때

캔버스 사용법은 캔버스로 문서·PPT·표 만들기, 문서작성 에이전트를 만드는 방법은 PPT·문서 만들기에 있습니다.

아티팩트​

아티팩트는 에이전트의 답변 결과를 대화 화면에서 바로 열어 보고, 필요한 파일 형식으로 내보낼 수 있는 미리보기입니다. 웹페이지, 문서, 발표자료, 데이터 표가 아티팩트로 만들어지며, 입력란 아래 오른쪽의 아티팩트를 누르면 이 대화의 아티팩트를 모아 볼 수 있습니다.

아티팩트는 에이전트 지침에 아티팩트로 답하도록 적혀 있을 때, 또는 엑셀이나 CSV 데이터로 표를 만들거나 분석할 때 만들어집니다. 에이전트가 만든 파일도 아티팩트 목록에 모이므로 이곳에서 내려받을 수 있습니다. 문서작성 에이전트가 만든 파일은 캔버스에서, 일반 에이전트의 아티팩트는 아티팩트 창에서 본다고 기억하면 쉽습니다.

워크스페이스​

워크스페이스는 여러 사람이 에이전트를 함께 쓰는 공용 공간입니다. 내가 만든 에이전트는 처음에는 나만 보이는 내 에이전트입니다. 에이전트 편집 화면의 워크스페이스 등록으로 워크스페이스에 등록을 요청하면, 관리자 심사를 거쳐 게시되거나 워크스페이스 설정에 따라 바로 게시됩니다. 게시된 에이전트는 같은 워크스페이스 사람이 대화할 수 있습니다.

사이드바의 워크스페이스 에이전트 탭에는 내가 대화한 워크스페이스 에이전트가 모입니다. 워크스페이스 에이전트는 설정을 바꿀 수 없고 대화와 즐겨찾기만 할 수 있습니다. 내가 속한 기본 워크스페이스는 프로필의 기본 워크스페이스에서 확인합니다. 자세한 내용은 즐겨찾기·워크스페이스·다운로드에 있습니다.

템플릿​

템플릿은 워크스페이스에 게시된 에이전트를 본떠 내 에이전트를 만드는 서식입니다. 사이드바의 에이전트 템플릿을 누르면 템플릿 목록이 전체와 워크스페이스 탭으로 나뉘어 보이고, 템플릿으로 제작을 누르면 그 구성을 복사한 내 에이전트가 생겨 에이전트 편집 화면이 열립니다. 홈 화면 입력란 아래의 템플릿 카드도 같은 방식으로 동작합니다. 템플릿에 필요한 도구가 내게 없으면 도구가 자동으로 내려받아진다는 안내가 나옵니다. 만드는 순서는 에이전트 만들기에 있습니다.

라운지​

라운지는 Deep Agent Builder 사용자들이 함께 쓰는 사내 게시판입니다. 사이드바 아래쪽 라운지를 누르면 열리며, 유즈케이스, 사용 가이드, FAQ, 문의 및 오류, 기능 개선 제안, 커뮤니티, 공지사항 게시판이 있습니다. 유즈케이스, 사용 가이드, FAQ, 공지사항은 관리자가 쓰고, 문의 및 오류, 기능 개선 제안, 커뮤니티는 글쓰기 권한이 있는 사용자가 쓸 수 있습니다. 자세한 사용법은 커뮤니티에 있습니다.

SUPER AI 에이전트​

SUPER AI 에이전트는 내 에이전트 전체를 알고 있는 안내 데스크입니다. 사이드바 더 보기의 SUPER AI 에이전트를 처음 누르면 내 계정에 하나가 만들어지고, 그 뒤로는 같은 에이전트의 대화 화면이 열립니다. 인사나 간단한 질문에는 직접 답하고, 요청이 내 에이전트 중 하나의 업무와 맞으면 그 에이전트에게 일을 넘기면서 어느 에이전트를 골랐는지 짧게 알려 줍니다. 어떤 에이전트에게 물어야 할지 모를 때 먼저 SUPER AI 에이전트에게 요청해 보세요.

스레드(채팅)​

스레드는 업무 건별 대화 기록이며, 화면에는 주로 "채팅"으로 표시됩니다. 에이전트에게 첫 메시지를 보내면 채팅 하나가 생기고, 이어지는 질문은 같은 채팅에 쌓입니다. 다른 건을 맡길 때는 사이드바의 이 에이전트와 새 대화를 눌러 새 채팅을 엽니다. 같은 채팅에 여러 건을 섞으면 앞의 자료와 지시가 다음 답변에 섞일 수 있습니다.

지난 채팅은 에이전트를 열었을 때 사이드바의 채팅 목록에 남고, 채팅 검색... 입력란으로 찾을 수 있습니다. 토큰 사용량 상세 창처럼 일부 화면에는 채팅이 Thread로 표시됩니다. 자세한 사용법은 대화 화면과 채팅 목록에 있습니다.
