캔버스로 문서·PPT·표 만들기

문서작성 에이전트로 설정한 에이전트에게 문서를 요청하면, 에이전트가 PowerPoint, Word, Excel 파일을 직접 만들어 대화 화면 오른쪽 문서 캔버스에 올립니다. 캔버스에서는 만든 문서를 바로 미리 보고, 고칠 부분을 골라 수정을 요청하고, 원본이나 PDF로 내려받을 수 있습니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 제안서 PPT 작성기로 "문서 자동화 패키지 도입 제안서" PPT를 만들고, 표 한 장을 고치고, 가격표 엑셀까지 받는 과정을 화면 순서대로 설명합니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면 설정 탭에서 에이전트 모드를 문서작성 에이전트로 바꿉니다.
  • 문서를 요청하고, 대화에 생긴 결과 카드에서 캔버스에서 열기로 문서를 엽니다.
  • 캔버스를 넓게보기, 나란히보기로 바꾸고, 폭을 조절하고, 캔버스 접기로 닫습니다.
  • 슬라이드·페이지·시트를 미리 보고, 시트에서는 셀 값과 수식을 복사하고 범위의 개수·합계·평균을 봅니다.
  • 문서 요소 선택으로 고칠 부분을 골라 수정을 요청합니다.
  • 내보내기 메뉴에서 원본 다운로드로 받거나, 문서 종류에 따라 PPTX 형식으로 내보내기, DOCX 형식으로 내보내기, XLSX 형식으로 내보내기, PDF 형식으로 내보내기로 바꿔 받습니다.

일반 에이전트가 만드는 아티팩트(슬라이드·웹페이지 미리보기)와의 차이는 PPT·문서 만들기에서 비교합니다.

시작하기 전에​

항목내용
에이전트제안서 PPT 작성기. 에이전트 모드가 문서작성 에이전트여야 캔버스에 문서가 올라옵니다.
준비 파일브레인크루_AI업무도구_시장메모.md(가상 경쟁 도구 4종과 고객 인터뷰 12개사 요약)
첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm
권한다른 형식으로 내보내기와 문서 요소 선택에는 에이전트 조회와 실행 권한이 필요합니다.

캔버스는 읽기 전용입니다. 캔버스 안에서 글자를 직접 고칠 수는 없고, 고칠 내용은 대화로 요청합니다.

문서작성 에이전트로 바꾸기​

에이전트 모드는 에이전트마다 정합니다. 문서작성 에이전트로 바꾸면 그 에이전트의 모든 대화가 문서 작성 모드로 실행되어, 에이전트가 Word·PowerPoint·Excel 파일을 만들고 캔버스에 게시하는 도구를 씁니다. 모드는 고르는 즉시 저장되어 대화와 테스트에 바로 쓰입니다. 다만 현재 버전에는 아직 기록되지 않아 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이며, 헤더의 저장을 눌러야 현재 버전에 들어갑니다.

에이전트 모드 바꾸기

번호메뉴기능이런 때 사용하세요
1설정에이전트 편집 화면 오른쪽 패널의 실행 설정 탭입니다.에이전트 모드를 바꾸러 갈 때
2에이전트 모드일반 에이전트와 문서작성 에이전트 중 하나를 고릅니다. 고르는 즉시 저장되고 "에이전트 모드가 저장되었습니다" 알림이 나옵니다.PPT·Word·Excel 결과물을 주로 받을 에이전트를 만들 때
3안내 문구"전환하는 즉시 저장됩니다. 문서작성 에이전트는 모든 대화를 문서 작성 모드로 실행합니다."바꾸기 전에 영향 범위를 확인할 때

따라 해 보기​

  1. 제안서 PPT 작성기가 없다면 사례: PPT 생성 에이전트의 "에이전트 만들기"대로 사이드바 새 에이전트에서 대화로 만듭니다. 빌더가 만든 지침에는 "제안서는 6장으로 구성: 표지, 고객 과제, 해결 방안, 기대 효과, 도입 일정과 비용, 다음 단계", 슬라이드마다 핵심 메시지 한 문장을 제목으로, 본문은 3~5줄 개조식, 브레인크루 제품 정보와 가격은 사용자가 준 내용만 쓰고 모르는 숫자는 "확인 필요"로 표시하는 규칙이 들어 있습니다.
  2. 사이드바에서 제안서 PPT 작성기를 누르고 에이전트 설정을 누릅니다.
  3. 오른쪽 패널 설정 탭을 누르고 에이전트 모드에서 문서작성 에이전트를 고릅니다.
  4. "에이전트 모드가 저장되었습니다" 알림을 확인하고, 헤더의 저장을 눌러 바뀐 모드를 현재 버전에 기록합니다. 그다음 사이드바 이 에이전트와 새 대화를 눌러 대화 화면으로 갑니다.

문서 요청과 결과 카드​

문서작성 에이전트에게 요청을 보내면 에이전트가 여러 단계를 차례로 실행합니다. 예를 들어 이 사례에서 PPT를 만들 때는 스킬 파일 가져오기, 작업 파일 작성, 코드 실행, 문서 구조 확인, 문서를 캔버스에 게시, 문서 내보내기 단계가 이어졌습니다. 각 단계는 대화에 한 줄씩 쌓이고, 누르면 펼쳐져 내용을 볼 수 있습니다. 게시가 끝나면 답변 끝에 결과 카드가 생깁니다. 카드에는 만든 파일 이름과 종류, 캔버스에서 열기가 적혀 있습니다. 캔버스는 저절로 열리지 않으며, 카드나 오른쪽 끝 캔버스 열기 버튼을 눌러 엽니다. 캔버스 열기 아래 숫자는 이 채팅의 캔버스에 올라온 문서 수이고, 문서가 없으면 누를 수 없습니다.

결과 카드

번호메뉴기능이런 때 사용하세요
1실행 단계에이전트가 실행한 단계 이름입니다(그림은 문서를 캔버스에 게시). 누르면 펼쳐져 내용을 볼 수 있습니다.파일이 언제 만들어지고 캔버스에 게시됐는지 확인할 때
2결과 카드만든 파일 이름과 종류(예: 프레젠테이션), 캔버스에서 열기가 적혀 있습니다. 누르면 캔버스가 그 문서로 열립니다.만든 PPT를 바로 열어 볼 때
3캔버스 열기캔버스를 엽니다. 아래 숫자는 이 채팅의 캔버스에 올라온 문서 수입니다. 문서가 없으면 누를 수 없습니다.카드를 찾지 않고 캔버스를 다시 열 때

결과 카드의 종류는 만든 파일에 따라 정해집니다.

카드 종류대상 파일
프레젠테이션.pptx
스프레드시트.xlsx
문서.docx, .md, .markdown
웹 페이지.html, .htm
파일그 밖의 파일(예: .pdf, .txt, .csv, .png, .json)

같은 문서를 다음 요청에서 고치면 그 요청의 답변 끝에 새 카드가 생깁니다. 앞 요청의 카드를 누르면 그때 게시된 문서가 읽기 전용으로 열려, 고치기 전과 후를 비교할 수 있습니다. 캔버스에 올라온 문서는 입력란 아래 오른쪽의 아티팩트 버튼으로 여는 아티팩트 창 목록에도 함께 모입니다.

따라 해 보기​

  1. 제안서 PPT 작성기 대화 화면에서 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드로 브레인크루_AI업무도구_시장메모.md를 붙입니다.

  3. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 시장 메모를 근거로, 중견기업 고객에게 브레인크루 "문서 자동화 패키지" 도입을 제안하는 PPT를 6장으로 만들어 주세요. 고객 인터뷰에서 나온 요구 순위와 경쟁 도구 A~D 비교표를 꼭 넣어 주세요. 표지 날짜는 2026년 11월로 해 주세요.

  4. 에이전트가 먼저 할 일 목록과 슬라이드별 설계안을 보여 주면, 아래처럼 진행해 달라고 답합니다.

    프롬프트: 좋아요. 이 설계안대로 6장짜리 PPT 파일을 만들어 캔버스에 게시해 주세요. 표지 날짜는 2026년 11월로 해 주세요.

  5. 실행 단계가 끝나고 답변 끝에 프레젠테이션 카드가 생기면 카드를 누릅니다.

문서 캔버스 화면​

캔버스가 열리면 대화 오른쪽에 문서 캔버스가 나란히 놓입니다. 위쪽 머리줄에서 문서 제목과 상태(작성 중…, 준비됨, 오류 중 하나)를 보고, 화면 크기와 내보내기를 다룹니다.

  • 캔버스 접기: 캔버스를 닫고 대화만 넓게 봅니다. 다시 열 때는 캔버스 열기를 누릅니다.
  • 넓게보기: 캔버스를 화면 전체로 펼칩니다. 펼친 상태에서는 같은 자리가 나란히보기로 바뀌며, 이 버튼이나 Esc 키를 누르면 대화와 나란히 보는 화면으로 돌아갑니다.
  • 내보내기: 원본이나 다른 형식으로 내려받는 메뉴를 엽니다.
  • 문서 요소 선택: 미리보기에서 고칠 부분을 골라 다음 메시지에 붙이는 모드를 켜고 끕니다.
  • 미리보기: 이전·다음 페이지, 썸네일, 확대·축소, 너비에 맞춤, 기준 배율 100%, 페이지 전체 맞춤, 가운데 "2 / 6" 같은 페이지로 이동으로 살펴봅니다. 스프레드시트에는 위쪽에 읽기 전용 표시가 붙습니다.
  • 캔버스 폭 조절: 대화와 캔버스 사이 경계선을 끌거나, 경계선을 선택한 뒤 방향키로 폭을 바꿉니다. 바꾼 비율은 다음에 열 때도 유지됩니다.

문서 캔버스 머리줄

번호메뉴기능이런 때 사용하세요
1캔버스 접기캔버스를 닫고 대화만 넓게 봅니다. 다시 열 때는 캔버스 열기를 누릅니다.수정 요청을 길게 쓸 때
2제목과 상태지금 보는 문서의 제목과 상태입니다. 상태는 작성 중…, 준비됨, 오류 중 하나입니다.에이전트가 아직 문서를 고치는 중인지 확인할 때
3넓게보기캔버스를 화면 전체로 펼칩니다. 펼친 상태에서는 같은 자리가 나란히보기로 바뀌며, 누르거나 Esc 키를 누르면 대화와 나란히 보는 화면으로 돌아갑니다.슬라이드의 작은 글씨와 표를 크게 볼 때
4내보내기원본이나 다른 형식으로 내려받는 메뉴를 엽니다.완성된 제안서를 파일로 받을 때

머리줄 아래에는 문서 요소 선택, 문서 탭, 미리보기가 차례로 놓입니다.

문서 캔버스 미리보기

번호메뉴기능이런 때 사용하세요
1문서 요소 선택미리보기에서 고칠 부분을 골라 다음 메시지에 붙이는 모드를 켜고 끕니다. .pptx, .docx, .xlsx 문서가 준비됨 상태이고 에이전트가 작업 중이 아닐 때 누를 수 있습니다.특정 슬라이드의 표만 고쳐 달라고 할 때
2미리보기 도구 줄썸네일, 확대·축소, 기준 배율 100%, 너비에 맞춤, 페이지 전체 맞춤, 이전·다음 페이지, 가운데 "2 / 6" 같은 페이지로 이동이 모여 있습니다. 아래에 문서 내용이 보입니다.장마다 내용과 숫자를 검토할 때
3캔버스 폭 조절대화와 캔버스 사이 경계선입니다. 끌거나, 경계선을 선택한 뒤 방향키로 폭을 바꿉니다. 바꾼 비율은 다음에 열 때도 유지됩니다.대화를 보면서 캔버스를 넓게 쓰고 싶을 때

캔버스에 문서가 여러 개 올라오면 위쪽에 문서별 탭이 생겨, 탭을 눌러 오가며 볼 수 있습니다. 브라우저 창이 좁으면 대화와 나란히 나뉘지 않고 캔버스가 화면을 차지합니다.

미리보기를 그릴 수 없는 문서에는 "미리보기를 사용할 수 없습니다. 원본 파일을 다운로드해 주세요."가 표시됩니다. 이때는 내보내기 > 원본 다운로드로 받아 확인합니다.

시트 미리보기​

스프레드시트 문서를 열면 미리보기 위쪽에 읽기 전용 표시와 셀 정보 줄이 함께 보입니다. 셀을 고르면 그 셀의 주소와 수식, 값이 표시됩니다. 값 복사나 수식 복사를 누르면 선택한 셀의 값이나 수식이 복사됩니다. 시트 탭과 범위 요약은 시트 아래쪽에 있습니다. 시트 탭을 눌러 시트를 바꾸고, 여러 셀을 끌어 고르면 "개수 · 합계 · 평균" 범위 요약이 나옵니다. 범위 요약은 저장된 숫자 값 기준이며 수식 결과는 빼고 셉니다. 브라우저 창 높이가 낮으면 시트 탭과 범위 요약이 캔버스 아래쪽에 가려질 수 있으니, 이때는 창을 키워서 봅니다.

시트 미리보기

번호메뉴기능이런 때 사용하세요
1문서 탭이 채팅의 캔버스에 올라온 문서입니다. 여기서는 제안서 PPT와 가격표 엑셀 두 개이고, 엑셀 탭을 고른 상태입니다. 탭을 눌러 오가고, 탭의 X로 닫습니다.PPT와 엑셀을 번갈아 볼 때
2읽기 전용캔버스에서는 셀을 직접 고칠 수 없다는 표시입니다.셀 값을 바꾸고 싶을 때(대화로 요청합니다)
3수식고른 셀의 수식(예: =B2*C2)입니다. 왼쪽 칸에 셀 주소(예: D2), 오른쪽 값 칸에 저장된 결과가 보입니다. 파일에 저장된 결과가 없는 수식 칸은 값에 "저장된 결과가 비어 있거나 없습니다"가 보입니다.합계 칸이 어떤 수식으로 계산됐는지 확인할 때
4수식 복사선택한 셀의 수식을 복사합니다. 바로 왼쪽 값 복사는 값을 복사합니다.수식을 내 엑셀에 옮기거나 계산 결과를 메일에 붙일 때

시트의 수식 결과는 파일에 저장된 값을 보여 줍니다. "수식 결과는 파일에 저장된 값이며 최신 값과 다를 수 있습니다."라는 안내가 붙어 있으므로, 숫자가 이상하면 에이전트에게 수식을 다시 계산해 달라고 요청하거나 내려받은 엑셀에서 확인합니다.

따라 해 보기​

  1. 같은 채팅에서 아래 프롬프트를 보냅니다.

    프롬프트: 제안서의 도입 일정에 맞춰 "문서 자동화 패키지 제안 가격표"를 Excel로 만들어 주세요. 시트는 가격표 하나로 하고, 열은 항목, 사용자 수, 월 단가, 월 합계로 하되 월 합계는 수식으로 넣어 주세요. 월 단가는 자료에 없으니 비워 두고 표 아래에 "단가 협의 필요"라고 적어 주세요.

  2. 답변 끝의 스프레드시트 카드를 누릅니다. 캔버스 위쪽 문서 탭에 PPT와 엑셀이 함께 보입니다.

  3. 월 합계 칸(D2)을 눌러 수식이 =B2*C2인지 확인하고 수식 복사를 누릅니다. 이 사례에서는 월 단가를 비워 두었기 때문에 값에는 "저장된 결과가 비어 있거나 없습니다"가 보였습니다.

  4. 사용자 수(B2)부터 월 합계(D2)까지 끌어 고르면 범위 요약이 "개수 1 · 합계 10 · 평균 10"으로 나옵니다. 수식 칸인 월 합계는 세지 않습니다.

고칠 부분을 골라 수정 요청하기​

캔버스는 읽기 전용이므로, 고칠 곳은 문서 요소 선택으로 골라 대화로 요청합니다. 고른 요소는 다음 메시지에 첨부되어 에이전트가 정확히 그 부분을 고칩니다. 문서 요소 선택은 .pptx, .docx, .xlsx 문서가 준비됨 상태이고 에이전트가 작업 중이 아닐 때 누를 수 있습니다. 켜지면 옆에 "요소를 선택하면 다음 메시지에 첨부됩니다."가 표시됩니다. 미리보기에서 요소(예: 제목, 문단, 표)를 누르면 첨부됨으로 바뀌고, 시트에서는 범위를 끈 뒤 선택한 범위 첨부를 누릅니다. 고른 요소는 입력창 위 선택한 문서 요소에 모이며, 요소마다 선택 삭제로 뺄 수 있습니다. 한 번에 20개까지 첨부할 수 있습니다.

문서 요소 선택

번호메뉴기능이런 때 사용하세요
1문서 요소 선택선택 모드를 켭니다. 켜지면 옆에 "요소를 선택하면 다음 메시지에 첨부됩니다."가 표시되고, 미리보기 위에는 "요소를 선택하여 메시지에 첨부하세요."가 보입니다.고칠 곳을 말로 설명하기 어려울 때
2고른 요소미리보기에서 누른 요소입니다. 예를 들어 제목, 문단, 표를 고를 수 있습니다. 누르면 테두리가 강조되고 다음 메시지에 첨부됩니다. 시트에서는 범위를 끈 뒤 선택한 범위 첨부를 누릅니다.3장 비교표만 콕 집어 고칠 때
3선택한 문서 요소입력창 위에 첨부된 요소가 Slide 3 · Table 6처럼 "장 번호 · 요소 이름" 칩으로 보입니다. 칩의 X(선택 삭제)로 뺄 수 있습니다. 한 번에 20개까지 첨부할 수 있습니다.잘못 고른 요소를 뺄 때
4메시지 입력란고른 요소를 어떻게 바꿀지 적습니다."이 표에 행을 추가해 주세요"처럼 바꿀 내용을 적을 때

알아 둘 점은 다음과 같습니다.

  • 20개를 넘게 고르면 "문서 요소는 최대 20개까지 첨부할 수 있습니다."가 표시됩니다.
  • 요소를 고른 뒤 에이전트가 문서를 다시 고치면, 앞에서 고른 요소에 이전 버전 표시가 붙고 "선택한 문서가 변경되었습니다. 이전 선택을 삭제하고 요소를 다시 선택해 주세요."가 안내됩니다. 선택 삭제로 빼고 새 문서에서 다시 고릅니다.
  • 문서에 따라 "이 문서에서는 정확한 요소 선택을 사용할 수 없습니다." 또는 "이 페이지에 선택 가능한 요소가 없습니다."가 나올 수 있습니다. 이때는 몇 장의 무엇을 바꿀지 말로 적어 요청합니다.

따라 해 보기​

  1. 캔버스 위쪽 문서 탭에서 제안서 PPT를 고르고 문서 요소 선택을 누릅니다.

  2. 경쟁 도구 A~D 비교표가 있는 장(이 사례에서는 3장)으로 가서 표를 누릅니다. 입력창 위 선택한 문서 요소에 Slide 3 · Table 6 칩이 붙습니다.

  3. 아래 프롬프트를 보냅니다.

    프롬프트: 선택한 비교표 맨 아래에 "브레인크루 문서 자동화 패키지" 행을 추가해 주세요. 가격은 시장 메모에 없으니 "확인 필요"로 적고, 출처는 "시장 메모"로 적어 주세요.

  4. 답변 끝에 새 프레젠테이션 카드가 생기면 그 카드의 캔버스에서 열기를 눌러 고친 표를 직접 확인합니다.

팁: 답변 문장만 믿지 말고 캔버스에서 결과를 꼭 확인합니다. 이 사례에서 에이전트는 처음에 "표 범위(5행 5열)에 한정되어 추가 행 배정이 되지 않는다"며 방법을 물었고, "표를 6행 구조로 갱신하는 방법으로 진행해 주세요"라고 답하자 행을 추가했다고 답했습니다. 그러나 캔버스와 내려받은 파일의 3장 표는 여전히 A~D 네 행뿐이었습니다. 수정이 반영되지 않았으면 몇 장의 어떤 표를 어떻게 바꿀지 다시 구체적으로 요청합니다.

내보내기​

캔버스 머리줄의 내보내기를 누르면 메뉴가 열립니다. 첫 항목은 늘 원본 다운로드이고, 그 아래에 문서 종류별로 바꿀 수 있는 형식이 PPTX 형식으로 내보내기처럼 붙습니다. 받는 중에는 버튼이 **다운로드 중…**으로 바뀝니다.

내보내기 메뉴

번호메뉴기능이런 때 사용하세요
1내보내기내려받기 메뉴를 엽니다.완성본을 파일로 받을 때
2원본 다운로드에이전트가 만든 파일을 그대로 받습니다.내 PC의 PowerPoint에서 바로 고쳐 쓸 때
3PPTX 형식으로 내보내기PowerPoint 파일로 변환해 받습니다.PowerPoint 파일이 꼭 필요한 곳에 보낼 때
4PDF 형식으로 내보내기PDF로 변환해 받습니다.고객에게 수정할 수 없는 파일로 보낼 때

문서 종류별로 메뉴에 나오는 항목은 다음과 같습니다.

원본메뉴 항목
.pptx원본 다운로드, PPTX 형식으로 내보내기, PDF 형식으로 내보내기
.docx, .md, .markdown원본 다운로드, DOCX 형식으로 내보내기, PDF 형식으로 내보내기
.xlsx원본 다운로드, XLSX 형식으로 내보내기
.html, .htm원본 다운로드, PDF 형식으로 내보내기
.pdf, .txt, .png, .csv, .json원본 다운로드
  • 스프레드시트는 PDF로 내보내지 않습니다. 인쇄용이 필요하면 받은 엑셀에서 PDF로 저장합니다.
  • 웹 페이지의 PDF 형식으로 내보내기는 에이전트가 게시한 문서면 PDF 파일로 받고, 그렇지 않으면 브라우저 인쇄 창이 열립니다. 인쇄 창에서 PDF로 저장을 고릅니다.
  • 내려받지 못하면 캔버스 위쪽에 "다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."가 나옵니다. 에이전트 조회·실행 권한이 있는지 관리자에게 확인합니다.

따라 해 보기​

  1. 캔버스 위쪽 문서 탭에서 제안서 PPT를 고릅니다.
  2. 내보내기 > PDF 형식으로 내보내기를 누르고, 브라우저 다운로드 목록에서 PDF를 확인합니다. 이 사례에서는 파일 이름이 PPT와 같은 6쪽짜리 .pdf 파일을 받았습니다.
  3. 다시 내보내기 > 원본 다운로드로 .pptx를 받아 PowerPoint에서 열어 봅니다.
  4. 문서 탭에서 가격표 엑셀을 고르고 내보내기를 누르면 원본 다운로드와 XLSX 형식으로 내보내기만 나오는 것을 확인합니다.

정리​

  • 캔버스는 문서작성 에이전트 모드인 에이전트의 대화에서 씁니다. 모드는 에이전트 편집 화면 설정 탭에서 바꾸며 바로 저장되어 대화에 쓰이고, 헤더의 저장을 눌러야 현재 버전에 기록됩니다.
  • 캔버스는 결과 카드의 캔버스에서 열기나 캔버스 열기로 엽니다. 저절로 열리지 않습니다.
  • 캔버스는 읽기 전용입니다. 고칠 곳은 문서 요소 선택으로 골라(최대 20개) 대화로 요청합니다.
  • 내보내기의 첫 항목은 원본 다운로드이고, PPT·Word는 PDF로도, 엑셀은 XLSX로만 내보냅니다.
