사례: PPT 생성 에이전트

이 페이지는 김그루 사원이 제안서 PPT 작성기를 만들어, 가상 고객사 가온상사에 보낼 "AI 회의록 솔루션 도입 제안" PPT 6장을 받는 과정을 처음부터 끝까지 따라 합니다. 문서작성 에이전트가 만든 PPT를 캔버스에서 한 장씩 넘겨 보고, 문서 요소 선택으로 한 장만 고친 뒤 PPTX와 PDF로 내려받습니다.

이 페이지에서 할 수 있는 일

  • 대화로 제안서 PPT 작성기를 만들고 에이전트 모드를 문서작성 에이전트로 바꿉니다.
  • 요청 문장 하나로 6장짜리 제안서 PPT를 받고, 캔버스의 슬라이드 뷰어로 확인합니다.
  • 문서 요소 선택으로 비용 슬라이드의 한 부분만 골라 고쳐 달라고 요청합니다.
  • 내보내기 메뉴에서 PPTX 파일과 PDF 파일을 내려받습니다.

목표​

항목내용
만들 결과물가상 고객사 가온상사(임직원 300명)에 보낼 "AI 회의록 솔루션 도입 제안" PPT 6장
슬라이드 구성1장 표지, 2장 고객 과제, 3장 해결 방안, 4장 기대 효과, 5장 도입 일정과 비용, 6장 다음 단계
받는 파일PPTX 파일 1개, 같은 내용의 PDF 파일 1개
걸리는 시간에이전트 만들기 약 5분, PPT 작성 몇 분

가온상사는 사례를 위해 만든 가상의 고객사입니다. 실제 제안서에는 내 고객사 이름과 조건을 넣습니다.

준비물​

준비할 것내용
입력 파일필요 없습니다. 제안 내용은 요청 문장에 적습니다.
참고 자료를 함께 줄 때 올릴 수 있는 형식.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (한 번에 최대 10개. 파일 한 개당 .md, .markdown, .txt, .html, .htm은 10MB, .pdf, 이미지, .docx, .hwp, .hwpx는 20MB, .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt는 50MB까지)
에이전트 모드문서작성 에이전트 (캔버스는 이 모드에서만 나타납니다)
따로 연결할 도구없습니다. 문서 작성 도구는 문서작성 에이전트에 기본으로 들어 있습니다. 예를 들어 작업 파일 작성, 코드 실행, 문서를 캔버스에 게시, 문서 내보내기가 있습니다.
권한에이전트를 만들고 실행할 수 있는 계정. 새 에이전트가 눌리지 않으면 관리자에게 권한을 요청합니다.

팁: 기존 회사 소개 PPT나 제품 소개서를 함께 올리면 문장과 숫자를 그 자료에서 가져오게 할 수 있습니다. 이때도 요청 문장에 "첨부한 자료에 있는 내용만 쓰라"고 적습니다.

에이전트 만들기​

제안서 PPT 작성기는 대화로 만듭니다. 사이드바 새 에이전트를 눌러 "생성하려는 에이전트에 대해 알려주세요" 화면의 입력창(5자 이상)에 만들려는 에이전트를 설명하고 전송을 누르면, 빌더가 진행 상황에 1단계부터 9단계까지 만드는 순서를 보여 주며 진행합니다. 부족한 정보가 있으면 확인 질문을 하고, 답을 받아 지침과 구성을 정리합니다.

대화로 제안서 PPT 작성기 만들기

번호메뉴기능이런 때 사용하세요
1새 에이전트"생성하려는 에이전트에 대해 알려주세요" 화면을 엽니다. 입력창에 5자 이상 적어야 보낼 수 있습니다.새 에이전트를 만들기 시작할 때
2확인 질문빌더가 부족한 정보를 묻습니다. 질문이 여러 개면 "3개의 확인이 필요합니다"처럼 묶여 나오고, 번호 단추나 아래 화살표로 질문을 오갑니다. 보기 하나를 고르거나 **직접 입력 (원하는 내용을 자유롭게 작성)**을 고른 뒤 제출을 누릅니다.각 장의 내용 범위나 결과물 형태처럼 빌더가 정하지 못한 것을 답할 때
3전체 제출답한 질문 수가 "(0/3)"처럼 표시되고, 모든 질문에 답하면 눌러 한꺼번에 보냅니다.확인 질문에 모두 답했을 때
4메시지 입력창빌더에게 추가로 요청할 내용을 적습니다.확인 질문 밖의 조건을 덧붙일 때

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 입력창에 아래 문장을 붙여 넣고 전송을 누릅니다.

    프롬프트: 고객사 제안서를 PPT로 만들어 주는 "제안서 PPT 작성기"를 만들고 싶어요. 기본 구성은 표지, 고객 과제, 해결 방안, 기대 효과, 도입 일정과 비용, 다음 단계 순서의 6장입니다. 슬라이드마다 핵심 메시지 한 문장을 제목으로 쓰고, 본문은 3~5줄 개조식으로 써 주세요. 브레인크루 제품 정보와 가격은 사용자가 알려 준 내용만 쓰고, 모르는 숫자는 "확인 필요"로 남겨 주세요.

  3. 확인 질문이 나오면 보기를 고르고 제출을 누릅니다. 질문은 여러 번에 나눠 나올 수 있습니다. 이 사례에서는 참고 자료를 묻는 질문에 사용자가 제공하는 정보만 사용, 결과물 형태를 묻는 질문에 슬라이드별 핵심 메시지와 개조식 본문을 고르는 식으로 답했습니다. 한 묶음의 질문에 모두 답하면 전체 제출을 누릅니다.

  4. 빌더가 도구, 동작 방식(미들웨어), 스킬, 함께 일할 도우미 에이전트를 차례로 추천합니다. 추천 카드마다 승인이나 수정 요청을 누릅니다. 이 사례에서는 도구 추천에 수정 요청을 눌러 "도구는 추가하지 말아 주세요. 제품 정보와 가격은 사용자가 대화에서 알려 준 내용만 씁니다."라고 적었고, 나머지 추천은 승인했습니다.

  5. "9단계 완료: 에이전트가 완성됐어요"가 나오면 바로 이용하기를 누릅니다. 사이드바 내 에이전트에 제안서 PPT 작성기가 생깁니다.

빌더가 만든 지침에는 요청한 대로 "제안서는 6장으로 구성: 표지, 고객 과제, 해결 방안, 기대 효과, 도입 일정과 비용, 다음 단계", "슬라이드마다 핵심 메시지 한 문장을 제목으로 작성", "본문은 3~5줄의 개조식", 모르는 숫자는 "확인 필요"로 표시하는 규칙이 들어갑니다. 지침은 에이전트 편집 화면 지침에서 확인하고 고칠 수 있습니다. 함께 추천되는 미들웨어, 스킬, 도우미 에이전트는 계정에 있는 자원에 따라 달라집니다.

에이전트 모드를 문서작성 에이전트로 바꾸기​

PPT 파일을 만들고 캔버스에서 보려면 에이전트 모드가 문서작성 에이전트여야 합니다. 에이전트 편집 화면의 설정 탭에서 바꿉니다.

에이전트 모드 바꾸기

번호메뉴기능이런 때 사용하세요
1에이전트 설정지금 대화 중인 에이전트의 에이전트 편집 화면을 엽니다.에이전트 구성을 바꿀 때
2설정 탭에이전트 실행 설정을 모아 둔 탭입니다.에이전트 모드, 최대 처리 단계 수를 볼 때
3에이전트 모드일반 에이전트와 문서작성 에이전트 중 하나를 고릅니다. 전환하는 즉시 저장됩니다.PPT, Word, 엑셀 파일을 만들어 캔버스로 보고 싶을 때

따라 해 보기​

  1. 사이드바에서 제안서 PPT 작성기를 누른 뒤 에이전트 설정을 누릅니다.
  2. 오른쪽 패널의 설정 탭을 누릅니다.
  3. 에이전트 모드에서 문서작성 에이전트를 고릅니다. "에이전트 모드가 저장되었습니다" 알림이 뜨면 대화에는 바로 적용됩니다.
  4. 헤더에 "저장되지 않은 변경이 있습니다"가 보이면 헤더의 저장을 눌러 바뀐 모드를 현재 버전에도 기록합니다.

팁: 문서작성 에이전트는 모든 대화를 문서 작성 모드로 실행합니다. 같은 에이전트로 일반 질의응답도 하고 싶다면 일반 에이전트를 하나 더 두는 편이 낫습니다.

단계별 실행​

1단계. 제안서 PPT 요청하기​

에이전트와 새 대화를 열고, 고객사와 제품 조건을 담은 요청을 보냅니다. 문서작성 에이전트는 먼저 할 일 목록과 슬라이드별 설계안을 보여 주고, 진행해 달라고 답하면 PPT를 만들어 캔버스에 게시합니다. 만드는 동안 실행 기록을 하나씩 보여 주고, 다 만들면 답변 끝에 결과물 카드를 붙입니다.

제안서 PPT 요청

번호메뉴기능이런 때 사용하세요
1문서 작성 실행 기록에이전트가 거친 단계가 차례로 나타납니다(그림은 마지막 문서 내보내기). 이 사례에서는 스킬 목록, 스킬 불러오기, 스킬 파일 가져오기, 작업 파일 작성, 코드 실행, 문서 구조 확인, 문서를 캔버스에 게시, 문서 내보내기가 보였습니다. 누르면 펼쳐집니다.파일이 언제 만들어지고 게시됐는지 볼 때
2프레젠테이션 카드완성된 PPT 파일 카드입니다. 파일 이름과 "프레젠테이션 · 캔버스에서 열기"가 적혀 있고, 누르면(캔버스에서 열기) 오른쪽 문서 캔버스에 열립니다. 같은 파일이 다른 이름으로 한 장 더 붙을 수 있습니다.결과물을 캔버스에서 열 때
3캔버스 열기화면 오른쪽 끝 버튼입니다. 아래 숫자는 이 채팅의 캔버스에 올라온 문서 수입니다.카드를 찾지 않고 캔버스를 다시 열 때

따라 해 보기​

  1. 사이드바에서 제안서 PPT 작성기를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다.

    프롬프트: 가상 고객사 가온상사(임직원 300명, 매주 회의 약 120건)에 보낼 "AI 회의록 솔루션 도입 제안" PPT를 6장으로 만들어 주세요. 1장 표지(제안사 브레인크루, 발표자 AI혁신팀 김그루), 2장 가온상사의 회의록 작성 과제, 3장 AI 회의록 솔루션 소개(회의 요약, 결정사항 정리, 액션 아이템 추출), 4장 기대 효과, 5장 도입 일정과 비용(4주 일정, 단가 390,000원, 수량 50개 기준 표), 6장 다음 단계. 숫자는 제가 준 것만 쓰고, 비용 표에는 합계를 계산해 넣어 주세요.

  3. 실행 기록이 이어지는 동안 기다립니다. 마지막에 문서를 캔버스에 게시가 나타나고 프레젠테이션 카드가 붙으면 완성입니다.

2단계. 캔버스에서 슬라이드 확인하기​

캔버스에서 열기를 누르면 화면 오른쪽에 문서 캔버스가 열리고 슬라이드 뷰어로 PPT를 보여 줍니다. 캔버스는 읽기 전용이라 직접 글자를 고칠 수는 없고, 고칠 곳은 대화로 요청합니다.

캔버스 슬라이드 뷰어

번호메뉴기능이런 때 사용하세요
1문서 캔버스 제목과 상태열린 파일 이름과 상태(작성 중…, 준비됨, 오류)를 보여 줍니다.에이전트가 아직 파일을 고치는 중인지 볼 때
2썸네일슬라이드 6장을 작은 그림으로 늘어놓습니다. 누르면 그 장으로 이동합니다.전체 흐름을 한눈에 볼 때
3이전 페이지 / 다음 페이지한 장씩 넘깁니다. 가운데에 "1 / 6"처럼 현재 장과 전체 장수가 보입니다.슬라이드를 순서대로 읽을 때
4확대/축소축소·확대, 기준 배율 100%, 너비에 맞춤, 페이지 전체 맞춤으로 보기 크기를 바꿉니다.작은 글씨나 표를 크게 볼 때

머리줄 오른쪽 넓게보기는 캔버스를 넓게 펼치고(펼치면 나란히보기로 바뀜), 왼쪽 끝 캔버스 접기는 캔버스를 닫습니다. 다시 열 때는 오른쪽의 캔버스 열기를 누릅니다.

따라 해 보기​

  1. 프레젠테이션 카드의 캔버스에서 열기를 누릅니다.
  2. 아래쪽 장수 표시가 "1 / 6"인지 확인합니다.
  3. 썸네일을 눌러 6장의 순서가 표지, 고객 과제, 해결 방안, 기대 효과, 도입 일정과 비용, 다음 단계인지 봅니다.
  4. 5장을 열어 비용 표의 숫자를 확인합니다. 단가 390,000원 × 50개 = 19,500,000원이어야 합니다.

3단계. 문서 요소 선택으로 한 장만 고치기​

전체를 다시 만들지 않고 특정 부분만 고치려면 문서 요소 선택을 씁니다. 캔버스에서 고칠 요소를 누르면 그 요소가 다음 메시지에 첨부되고, 에이전트는 첨부된 요소만 고칩니다. 여기서는 5장의 비용 표를 수량 100개 기준으로 바꿉니다.

문서 요소 선택으로 비용 표 고치기

번호메뉴기능이런 때 사용하세요
1문서 요소 선택선택 모드를 켭니다. 선택할 수 있는 요소에 테두리가 생깁니다. 문서가 완성되고 에이전트가 쉬고 있을 때만 켤 수 있습니다.슬라이드의 제목, 본문 상자, 표 하나만 고칠 때
2선택한 요소5장의 비용 표입니다. 누르면 테두리가 강조되고 다음 메시지에 첨부됩니다.고칠 대상을 정확히 짚을 때
3선택한 문서 요소입력창 위에 첨부된 요소가 Slide 5 · Table 6 같은 칩으로 보입니다. 한 번에 최대 20개까지 첨부할 수 있습니다.무엇을 고쳐 달라고 보내는지 마지막으로 확인할 때
4전송입력창에 적은 수정 내용을 첨부한 요소와 함께 보냅니다.요소를 고른 뒤 수정 요청을 보낼 때

잘못 고른 요소는 칩 오른쪽의 선택 삭제(× 표시)를 눌러 첨부에서 뺍니다.

따라 해 보기​

  1. 캔버스를 5장으로 넘깁니다.

  2. 문서 요소 선택을 누르고 비용 표를 누릅니다. 입력창 위 선택한 문서 요소에 Slide 5 · Table 6 칩이 붙었는지 봅니다.

  3. 아래 프롬프트를 입력하고 전송을 누릅니다.

    프롬프트: 선택한 비용 표를 수량 100개 기준으로 바꾸고 합계를 다시 계산해 주세요. 표 아래에 "부가세 별도" 문구를 한 줄 넣어 주세요. 다른 슬라이드는 그대로 두세요.

  4. 답변 끝에 새 프레젠테이션 카드가 붙으면 그 카드의 캔버스에서 열기를 누르고 5장을 다시 엽니다.

팁: 요소를 고른 뒤 문서가 바뀌면 선택한 요소에 이전 버전 표시가 붙습니다. 이때는 선택 삭제로 이전 선택을 지우고 요소를 다시 고릅니다.

4단계. PPTX와 PDF로 내려받기​

캔버스 위쪽의 내보내기에서 원본 파일이나 다른 형식으로 내려받습니다. PPT 파일에는 원본 다운로드, PPTX 형식으로 내보내기, PDF 형식으로 내보내기가 나옵니다.

PPTX와 PDF로 내보내기

번호메뉴기능이런 때 사용하세요
1내보내기내려받기 메뉴를 엽니다. 받는 동안 "다운로드 중…"으로 바뀝니다.완성된 PPT를 내 PC에 저장할 때
2원본 다운로드에이전트가 만든 파일을 그대로 받습니다.원본 파일을 보관할 때
3PPTX 형식으로 내보내기PowerPoint 파일로 받습니다.PowerPoint에서 디자인을 더 다듬을 때
4PDF 형식으로 내보내기PDF 파일로 받습니다.고객사에 수정할 수 없는 파일로 보낼 때

따라 해 보기​

  1. 캔버스 위쪽의 내보내기를 누릅니다.
  2. PPTX 형식으로 내보내기를 눌러 PowerPoint 파일을 받습니다.
  3. 다시 내보내기를 누르고 PDF 형식으로 내보내기를 눌러 PDF 파일을 받습니다.
  4. "다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."가 나오면 관리자에게 에이전트 실행 권한을 확인합니다.

결과물 예시​

문서 요소 선택으로 고친 뒤 캔버스에서 5장을 엽니다. 장수 표시는 "5 / 6"으로 전체 6장 그대로여야 하고, 비용 표에는 단가 390,000, 수량 100, 합계 39,000,000과 표 아래 "부가세 별도" 한 줄이 보여야 합니다(표 위에 "단위=원"이 적혀 있습니다). 이 사례에서는 표만 골라 보냈기 때문에 슬라이드 제목은 처음 만든 "도입 일정과 비용(50개 이용권, 4주 기준)" 그대로 남았습니다.

수정된 비용 슬라이드

번호메뉴기능이런 때 사용하세요
1장수 표시"5 / 6"입니다. 전체 장수는 6장 그대로입니다.수정 중에 슬라이드가 늘거나 줄지 않았는지 볼 때
2비용 표 합계 열이용권 행과 합계 행이 모두 39,000,000입니다. 같은 표의 단가는 390,000, 수량은 100입니다.고객사에 보낼 금액을 확인할 때
3"부가세 별도" 문구표 아래에 새로 들어간 한 줄입니다.요청한 수정이 반영됐는지 볼 때
4슬라이드 제목선택하지 않은 제목은 "50개 이용권, 4주 기준"으로 처음 그대로 남아 있습니다.선택하지 않은 부분이 바뀌지 않았는지, 함께 고칠 곳이 남았는지 볼 때

팁: 표와 제목을 함께 고치려면 문서 요소 선택에서 표와 제목을 둘 다 누른 뒤 요청을 보냅니다.

결과 확인 포인트

  • 1장 표지에 제안사 브레인크루, 발표자 AI혁신팀 김그루가 들어 있는지 봅니다. 이 사례에서는 요청하지 않은 날짜 "2024년 6월"이 표지에 들어갔습니다. 표지 날짜가 필요하면 요청 문장에 "표지 날짜는 2026년 11월"처럼 적고, 아니면 날짜를 빼 달라고 요청합니다.
  • 5장 합계를 직접 계산합니다. 처음 만든 표는 390,000원 × 50개 = 19,500,000원, 고친 표는 390,000원 × 100개 = 39,000,000원입니다.
  • 4장 기대 효과에 요청 문장에 없던 숫자가 들어갔다면 근거가 없는 값입니다. 이 사례에서는 "회의 기록 시간 70% 단축 예상"이 들어갔습니다. "확인 필요"로 바꾸거나 실제 자료를 주고 다시 요청합니다.
  • 슬라이드 아래쪽의 쪽 번호(02~06)가 캔버스 장수 표시와 같은지 봅니다. 1장 표지에는 쪽 번호가 없습니다.
  • 내려받은 PPTX와 PDF를 열어 장수가 6장이고 5장 숫자가 캔버스와 같은지 봅니다. 이 사례에서 받은 PPTX는 6장, PDF는 6쪽이었고 5장 표는 수량 100, 합계 39,000,000이었습니다.

응용 팁​

  • 고객사마다 달라지는 부분(고객사 이름, 인원, 수량)만 바꿔 같은 요청을 보내면 같은 구성의 제안서를 빠르게 만들 수 있습니다. 자주 쓰는 요청은 커맨드와 재사용으로 저장합니다.
  • 회사 디자인 가이드나 문서 작성 규칙이 있으면 에이전트 편집 화면 스킬 탭의 문서 작성 스킬로 붙입니다. 방법은 스킬 만들기와 업로드에 있습니다.
  • 슬라이드 순서를 바꾸거나 한 장을 더 넣을 때도 대화로 요청합니다. 예: "4장 뒤에 고객 사례 슬라이드를 한 장 추가해 주세요."
  • 판매 실적 숫자를 넣은 보고용 PPT가 필요하면 사례: 엑셀 판매 데이터 분석에서 계산한 값을 요청 문장에 그대로 붙여 넣습니다.
