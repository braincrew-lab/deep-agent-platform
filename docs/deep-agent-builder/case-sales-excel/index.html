사례: 엑셀 판매 데이터 분석

이 페이지는 김그루 사원이 판매 데이터 분석가에게 브레인크루의 2026년 판매 실적 엑셀 파일을 맡겨 지역별 목표 대비 달성률, 제품별 월별 매출 추이 차트를 받고, 결과를 엑셀 파일로 내려받는 과정을 따라 합니다. 에이전트가 낸 숫자를 맞춰 볼 수 있도록 예시 파일로 직접 계산한 기준값과, 이 사례에서 에이전트가 실제로 보여 준 값을 함께 적었습니다.

이 페이지에서 할 수 있는 일

  • 대화로 판매 데이터 분석가를 만들고, 엑셀 파일을 첨부해 분석을 맡깁니다.
  • 데이터 분석 실행 기록을 펼쳐 에이전트가 어떤 계산으로 숫자를 냈는지 확인합니다.
  • 지역별 목표 대비 달성률 표와 제품별 월별 매출 추이 차트를 받고, 틀린 값은 바로잡아 다시 받습니다.
  • 분석 결과를 시트 2개짜리 엑셀 파일로 받아 아티팩트 창에서 미리 보고 내려받습니다.

목표​

항목내용
알고 싶은 것2026년 1~10월 누적 매출이 지역별 연간 목표의 몇 %인지, 제품별 매출이 달마다 어떻게 움직였는지
받는 결과지역별 달성률 표, 제품별 월별 매출 추이 꺾은선 차트, 결과 엑셀 파일(브레인크루_판매분석_결과.xlsx)
쓰는 곳영업본부 월간 회의 자료, 지역별 하반기 목표 점검

준비물​

준비할 것내용
예시 파일브레인크루_2026_판매실적.xlsx (가상 자료)
파일 구성시트 "판매내역" 200행(월, 지역, 제품, 판매수량, 단가(원), 매출(원), 담당팀), 시트 "목표" 5행(지역, 연간 목표 매출(원))
데이터 범위2026-01~2026-10, 지역 5곳(서울, 경기, 부산, 대구, 광주), 제품 4종(AI 회의록 솔루션, 문서 자동화 패키지, 데이터 분석 구독, 교육 컨설팅)
같은 방법으로 분석할 수 있는 형식.xlsx, .xls, .xlsb, .xlsm, .csv (파일 한 개당 50MB 이하, 한 번에 최대 10개)
에이전트 모드일반 에이전트
따로 연결할 도구없습니다. 첨부한 표를 읽고 코드를 실행하는 데이터 분석, 데이터 시각화는 일반 에이전트에 기본으로 들어 있습니다.
  • 첫 행에 열 이름이 있어야 합니다. 병합된 제목 줄이 있으면 지우고 올립니다.
  • 고객 이름, 연락처처럼 개인을 알아볼 수 있는 열은 지우고 집계에 필요한 열만 남깁니다.
  • 50MB를 넘는 파일은 올라가지 않습니다. 시트를 나누거나 필요한 기간만 남겨 파일을 줄입니다.

팁: 대화로 에이전트를 만드는 화면에서는 엑셀 파일(.xlsx, .xls, .xlsb, .xlsm, .csv)을 첨부할 수 없습니다. 엑셀 파일은 에이전트를 다 만든 뒤 대화 화면에서 올립니다.

에이전트 만들기​

판매 데이터 분석가는 대화로 만듭니다. 어떤 계산을 어떤 형식으로 받고 싶은지 처음에 적어 두면 지침에 그대로 들어갑니다. 요청을 보내면 빌더가 진행 상황 목록을 띄우고, 부족한 정보를 확인 질문으로 묻습니다.

대화로 판매 데이터 분석가 만들기

번호메뉴기능이런 때 사용하세요
1새 에이전트에이전트 만들기 첫 화면을 엽니다.새 에이전트를 만들기 시작할 때
2입력창만들고 싶은 에이전트를 설명하거나 빌더에게 추가로 말합니다.분석 대상과 결과 형식을 알려 줄 때
3확인 질문빌더가 부족한 정보를 묻습니다. 이 사례에서는 질문 3개(데이터 범위, 결과 형태, 지켜야 할 조건)가 1, 2, 3 번호로 나뉘어 나왔습니다. 보기를 고르거나 직접 입력으로 적고 제출을 누릅니다.빌더가 정하지 못한 것을 답할 때

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 입력창에 아래 문장을 붙여 넣고 전송을 누릅니다.

    프롬프트: 엑셀 판매 실적 파일을 받아 지역별, 제품별, 월별로 집계해 주는 "판매 데이터 분석가"를 만들고 싶어요. 계산은 반드시 코드를 실행해서 하고, 결과 표에는 단위(원, %, %p)를 붙여 주세요. 처음에는 읽은 파일의 행 수, 기간, 지역과 제품 개수를 먼저 알려 주세요. 요청하면 차트를 그리고, 결과를 엑셀 파일로 만들어 내려받을 수 있게 해 주세요.

  3. 확인 질문에 답합니다. 이 사례에서는 아래처럼 답하고 전체 제출을 눌렀습니다.

    • 데이터 범위: 모든 기간의 데이터 포함
    • 결과 형태(직접 입력): "답변에는 결과 표를 먼저 보여 주고, 요청하면 차트를 그리거나 결과를 엑셀 파일로 만들어 내려받게 해 주세요."
    • 지켜야 할 조건(직접 입력): "금액은 원 단위, 천 단위 쉼표로 적어 주세요. 계산은 반드시 코드를 실행해서 하고, 파일에 없는 숫자는 만들지 마세요."

  4. 빌더가 단계마다 추천을 보여 주면 승인 또는 수정 요청을 누릅니다. 이 사례에서는 도구 추천 없음, 동작 방식으로 도구 재시도(일시적 오류가 나면 자동으로 다시 시도), 스킬 추천 없음, 함께 일할 도우미 에이전트로 설문 결과 분석가가 추천되어 모두 승인했습니다. 도우미 에이전트가 필요 없으면 그 단계에서 수정 요청으로 빼 달라고 합니다.

  5. "에이전트가 완성됐어요!"가 나오면 바로 이용하기를 누릅니다. 사이드바 내 에이전트에 판매 데이터 분석가가 생기고, 그 에이전트의 대화 화면이 열립니다.

단계별 실행​

1단계. 엑셀 파일 첨부하고 달성률 묻기​

판매 데이터 분석가와 새 대화를 열고 판매 실적 엑셀 파일을 첨부한 뒤, 지역별 목표 대비 달성률을 묻습니다. 새 대화는 에이전트 대화 화면 사이드바의 이 에이전트와 새 대화로 엽니다.

엑셀 파일 첨부와 첫 질문

번호메뉴기능이런 때 사용하세요
1파일 업로드내 PC에서 파일을 골라 첨부합니다.판매 실적 엑셀 파일을 올릴 때
2첨부 파일올린 파일 이름과 형식(XLSX)이 입력창 위에 보입니다. 새 대화에서는 전송을 누를 때 파일이 올라가고, "파일 처리 중..."이 끝나면 질문이 전달됩니다.맞는 파일을 올렸는지 확인할 때
3입력창계산할 내용을 적습니다.어떤 기준으로 계산할지 밝힐 때
4전송파일과 질문을 함께 보냅니다.파일과 질문을 모두 넣었을 때

따라 해 보기​

  1. 사이드바에서 판매 데이터 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 눌러 브레인크루_2026_판매실적.xlsx를 고릅니다. 새 대화에서는 파일이 입력창 위에 파일 이름으로 남아 있다가 전송을 누를 때 올라갑니다.

  3. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다. "업로드 중...", "파일 처리 중..."이 차례로 지나간 뒤 질문이 전달됩니다.

    프롬프트: 첨부한 엑셀의 "판매내역" 시트와 "목표" 시트로 지역별 1~10월 누적 매출과 연간 목표 대비 달성률을 표로 만들어 주세요. 달성률이 높은 순으로 정렬하고, 10개월이 지난 시점의 기준(연간 목표의 10/12) 대비 진도율과 연간 목표까지 남은 금액도 함께 계산해 주세요.

2단계. 실행 기록과 달성률 표 확인하기​

에이전트는 먼저 파일 구조를 확인하는 코드를 실행하고, 이어서 달성률을 계산하는 코드를 실행한 뒤 결과 표를 답변에 붙입니다. 계산에 쓴 코드는 실행 기록에 그대로 남습니다.

지역별 목표 대비 달성률

번호메뉴기능이런 때 사용하세요
1데이터 분석첫 번째 실행 기록입니다. 파일의 시트와 열을 확인하는 코드가 들어 있습니다."판매내역"과 "목표" 두 시트를 모두 읽었는지 볼 때
2출력 (데이터 분석)첫 번째 코드가 실제로 낸 결과입니다.시트와 열 이름이 제대로 읽혔는지 볼 때
3데이터 분석(펼친 상태)달성률을 계산한 코드입니다. 판매내역의 월을 날짜로 바꿔 1~10월만 고르고, 지역별 매출(원) 합계를 목표 시트의 연간 목표 매출(원)과 합쳐 달성률과 진도율을 계산한 과정이 보입니다.매출을 어떤 열로 합쳤는지, 달성률을 무엇으로 나눴는지 확인할 때
4데이터 표 카드결과 표를 카드로 보여 줍니다. 지역별 누적 매출, 연간 목표, 달성률(%), 10개월 기준 목표, 진도율(%), 목표까지 남은 금액이 달성률 높은 순으로 나옵니다.표를 크게 열거나 파일로 받을 때

따라 해 보기​

  1. 답변 위쪽의 두 번째 데이터 분석을 눌러 펼치고, "매출(원)" 열을 지역별로 합친 코드인지 봅니다.
  2. 달성률 표를 아래 기준값과 비교합니다.

예시 파일로 직접 계산한 기준값입니다. 달성률은 1월부터 10월까지의 누적 매출 ÷ 연간 목표, 진도율은 같은 누적 매출 ÷ (연간 목표 × 10/12)입니다.

이 사례에서 에이전트가 보여 준 표는 지역 다섯 줄의 금액이 기준값과 모두 같았습니다. 다만 달성률과 진도율을 소수 둘째 자리까지(경기 69.76, 83.71) % 기호 없이 적었고, 합계 행은 붙이지 않았습니다. 첫 줄에 행 수, 기간, 지역·제품 개수를 먼저 알려 달라고 했지만 답변에는 "1~10월 매출 데이터, 5개 지역"만 적혔습니다. 행 수가 필요하면 "판매내역 시트를 몇 행 읽었는지 알려 주세요"라고 이어서 묻습니다.

팁: 같은 질문을 다시 보내면 데이터 분석 기록이 여러 개로 나뉘어 나올 수 있습니다. 에이전트가 파일 구조를 먼저 확인하고 계산을 나눠 실행하기 때문입니다. 마지막 기록의 결과가 답변 표와 같은지 보면 됩니다.

3단계. 제품별 월별 추이 차트 받기​

같은 대화에서 이어서 차트를 요청합니다. 앞에서 읽은 파일을 그대로 쓰므로 파일을 다시 올리지 않아도 됩니다.

제품별 월별 매출 추이 차트

번호메뉴기능이런 때 사용하세요
1데이터 시각화차트를 그린 실행 기록입니다.차트가 어떤 숫자로 그려졌는지 확인할 때
2꺾은선 차트제품 4종의 2026-01~2026-10 월별 매출을 한 그림에 보여 줍니다. 오른쪽 위 다운로드 버튼으로 그림을 받을 수 있습니다.회의 자료에 붙일 그림을 고를 때

따라 해 보기​

  1. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다.

    프롬프트: 같은 파일로 제품별 월별 매출 추이를 꺾은선 차트로 그려 주세요. 가로축은 2026-01부터 2026-10까지의 월, 세로축은 매출(원)입니다. 차트 아래에 제품별 1~10월 누적 매출과 매출이 가장 많았던 달을 표로 정리해 주세요.

  2. 차트에서 3월과 9월에 선이 올라가는지 봅니다.

  3. 차트 아래 제품별 표를 기준값과 비교합니다. 이 사례에서는 누적 매출은 맞았지만, 매출이 가장 많았던 달이 AI 회의록 솔루션 2026-03, 데이터 분석 구독 2026-10, 문서 자동화 패키지 2026-02로 틀리게 나왔습니다. 같은 답변의 월별 표와 맞지 않으므로 다시 묻습니다.

에이전트가 같은 답변 안에서 서로 맞지 않는 숫자를 내면, 어디가 틀렸는지 예를 들어 알려 주고 코드로 다시 찾게 합니다.

4단계. 결과를 엑셀 파일로 받기​

앞에서 만든 표 두 개를 엑셀 파일 하나로 모아 달라고 요청합니다. 에이전트가 시트를 나눠 파일을 만들고, 답변에 파일 이름으로 된 다운로드 링크를 붙입니다.

결과 엑셀 파일 받기

번호메뉴기능이런 때 사용하세요
1시트 구성 설명만든 파일 이름과 시트 이름(지역별_달성률, 제품별_월별_추이)을 알려 줍니다.파일을 열기 전에 필요한 시트가 다 들어갔는지 확인할 때
2다운로드 링크만든 엑셀 파일(브레인크루_판매분석_결과.xlsx)입니다. 누르면 내 PC에 저장됩니다.결과를 팀 공유 폴더에 올리거나 메일로 보낼 때
3아티팩트이 대화에서 만든 표와 파일을 한 창에 모아 보여 줍니다. 숫자 배지는 아티팩트 개수입니다.파일을 내려받기 전에 화면에서 먼저 열어 볼 때

따라 해 보기​

  1. 아래 프롬프트를 입력창에 붙여 넣고 전송을 누릅니다.

    프롬프트: 지금까지 만든 지역별 달성률 표와 제품별 월별 매출 표를 시트 2개짜리 엑셀 파일로 만들어 주세요. 시트 이름은 "지역별_달성률", "제품별_월별_추이", 파일 이름은 브레인크루_판매분석_결과.xlsx로 해 주세요.

  2. 답변의 시트 구성 설명에서 시트 2개를 확인합니다.

  3. 다운로드 링크를 눌러 저장합니다. 이 사례에서 받은 파일은 지역별_달성률 시트 5행(지역 다섯 곳, 합계 행 없음), 제품별_월별_추이 시트 10행(2026-01~2026-10, 제품 4열)이었고 숫자는 기준값과 같았습니다.

팁: 만든 파일은 일정 기간이 지나면 "기간이 만료되어 다운로드 받을 수 없습니다."로 바뀝니다. 필요한 파일은 받은 날 바로 저장해 둡니다.

결과물 예시​

입력란 아래 오른쪽의 아티팩트를 누르면 이 대화에서 만든 데이터 표와 엑셀 파일이 한 창에 모입니다. 엑셀 파일은 내려받기 전에 여기서 시트별로 미리 봅니다. 왼쪽 목록에는 답변에 붙었던 데이터 표 네 개가 행·열 수와 함께 차례로 보이고, 맨 아래에 엑셀 파일이 있습니다. 목록 아래 내보내기는 목록에서 고른 데이터 표를 Excel로 내보내기나 CSV로 내보내기 같은 다른 형식으로 저장할 때 씁니다.

결과 엑셀 파일 미리보기

번호메뉴기능이런 때 사용하세요
1엑셀 파일브레인크루_판매분석_결과.xlsx입니다. 형식과 크기(XLSX · 6.21 KB)가 함께 보입니다.내려받은 파일과 같은 파일인지 이름으로 확인할 때
2미리보기고른 파일의 내용을 표로 봅니다. 옆의 코드는 원본 형태를 보여 주지만, 엑셀 파일을 고르면 흐리게 바뀌어 누를 수 없습니다.내려받기 전에 숫자를 훑어볼 때
3달성률 열지역별_달성률 시트의 달성률(%) 열입니다. 경기 69.76이 맨 위, 광주 64.69가 맨 아래에 있습니다. 아래쪽 시트 탭으로 제품별_월별_추이 시트로 바꿀 수 있습니다.정렬과 숫자가 답변과 같은지 볼 때
4다운로드보고 있는 파일을 내려받습니다.미리 본 파일이 맞으면 바로 저장할 때

결과 확인 포인트

  • 달성률 순서가 경기 69.8%, 서울 68.8%, 대구 67.1%, 부산 66.6%, 광주 64.7%인지 확인합니다. 이 사례의 표처럼 소수 둘째 자리(69.76, 68.80, 67.12, 66.62, 64.69)로 나와도 반올림하면 같은 값입니다. 전체 달성률 68.0%, 전체 진도율 81.6%는 합계 행을 붙여 달라고 해야 나옵니다.
  • 달성률을 "연간 목표 대비"로 계산했는지, "10개월 기준 대비"로 계산했는지 표 머리에서 구분합니다. 둘을 섞으면 같은 지역도 크게 달라 보입니다. 예를 들어 서울은 연간 목표 대비 달성률이 68.8%이지만, 10개월 기준 대비 진도율은 82.6%입니다.
  • 제품별 누적 매출 네 개를 더하면 3,748,720,000원으로 지역별 합계와 같아야 합니다.
  • 같은 답변 안에서 차트, 월별 표, 요약 표의 숫자가 서로 맞는지 봅니다. 이 사례의 매출 최대 월처럼 요약 표만 틀리는 경우가 있습니다.
  • 매출(원)은 판매수량 × 단가(원)입니다. 의심 가는 행이 있으면 "판매내역에서 매출이 판매수량 × 단가와 다른 행이 있는지 확인해 주세요"라고 묻습니다. 예시 파일에는 그런 행이 없습니다.

응용 팁​

  • 매달 같은 분석을 반복한다면 1단계 프롬프트를 커맨드와 재사용의 커맨드로 저장합니다. 커맨드는 고르는 즉시 프롬프트만 보내고 입력창에 붙어 있는 파일은 보내지 않으므로, 새 달 파일을 첨부해 "이번 달 판매실적 파일입니다."처럼 짧은 문장과 함께 먼저 보내고, 답이 온 뒤에 입력창에 / 를 입력해 커맨드를 고릅니다.
  • 담당팀별로 보고 싶다면 이어서 묻습니다. 예: "담당팀별 누적 매출과 목표 달성률도 같은 표로 정리해 주세요." 예시 파일에서 서울과 경기는 영업1팀, 부산과 대구는 영업2팀, 광주는 영업3팀입니다.
  • 분석한 숫자로 보고용 슬라이드가 필요하면 사례: PPT 생성 에이전트의 제안서 PPT 작성기에 결과 표를 붙여 넣어 요청합니다.
  • 파일이 50MB를 넘어 올라가지 않으면 파일 첨부 정책과 가드레일의 크기 한도와 줄이는 방법을 봅니다.
