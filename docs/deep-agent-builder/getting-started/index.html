시작하기

이 페이지는 Deep Agent Builder에 처음 로그인해 홈 화면을 둘러보고, 주간 업무 보고서 도우미에게 첫 요청을 보내 답을 읽은 뒤 로그아웃하는 과정까지 화면 순서대로 안내합니다. 따라 하는 데 10분 정도 걸립니다.

이 페이지에서 할 수 있는 일

  • 이메일과 비밀번호로 로그인하는 순서를 확인합니다.
  • 홈 화면의 사이드바와 가운데 영역이 각각 무슨 일을 하는지 구별합니다.
  • 주간 업무 보고서 도우미에게 한 주 업무 메모를 보내 보고서 초안을 받습니다.
  • 답변 아래 버튼과 사용량 표시를 읽고, 업무를 마친 뒤 로그아웃합니다.

준비물​

항목내용
계정회사에서 받은 이메일과 비밀번호. 예시에서는 브레인크루 AI혁신팀 김그루 사원의 계정을 씁니다.
에이전트내 에이전트 목록의 주간 업무 보고서 도우미. 아직 없다면 에이전트 만들기에서 먼저 만듭니다.
보낼 자료김그루 사원의 한 주 업무 메모. 아래 따라 해 보기에 그대로 붙여 넣을 수 있는 문장이 있습니다.

로그인 화면​

회사에서 안내한 Deep Agent Builder 주소로 접속하면 로그인 화면이 열립니다. 로그인 화면에는 이메일과 비밀번호 칸, 로그인 버튼이 있고, 그 주변에 비밀번호 찾기와 "계정이 없으신가요? 회원가입"이 있습니다. 이미 로그인한 상태에서 주소로 접속하면 로그인 화면 없이 바로 홈 화면이 열립니다.

항목하는 일이런 때 사용하세요
이메일회사 이메일 주소를 입력합니다.출근해 처음 접속하거나 로그아웃한 뒤 다시 들어올 때
비밀번호비밀번호를 입력합니다. 입력한 글자는 가려져 보입니다.이메일 다음 칸에 본인 비밀번호를 적을 때
비밀번호 찾기비밀번호를 다시 정하는 화면으로 이동합니다.비밀번호가 기억나지 않을 때
로그인입력한 이메일과 비밀번호로 로그인합니다.두 칸을 모두 채웠을 때
회원가입새 계정을 만드는 화면으로 이동합니다.회사에서 직접 가입하라고 안내받았을 때

따라 해 보기​

  1. 이메일에 김그루 사원의 회사 이메일을 입력합니다.
  2. 비밀번호에 비밀번호를 입력합니다.
  3. 로그인을 누릅니다. 홈 화면이 열리면 로그인된 것입니다.

팁: 로그인되지 않으면 이메일 주소와 비밀번호의 대소문자를 다시 확인합니다. 새로 가입한 계정은 관리자가 가입을 승인한 뒤에 쓸 수 있습니다.

홈 화면과 사이드바​

로그인하면 홈 화면이 열립니다. 홈은 새 에이전트를 만드는 화면이면서, 왼쪽 사이드바에서 이미 있는 에이전트를 골라 대화를 시작하는 출발점입니다. 가운데 위쪽에는 "생성하려는 에이전트에 대해 알려주세요"가 보입니다.

사이드바 맨 위에는 홈 화면으로 돌아오는 Deep Agent Builder 로고와 사이드바를 좁게 접는 사이드바 축소가 있고, 그 아래에 새 에이전트, 에이전트 템플릿, 더 보기가 있습니다. 이어서 내 에이전트와 워크스페이스 에이전트 탭, 그리고 마우스를 올리면 이름이 보이는 목록 도구 아이콘(에이전트 검색, 숨겨진 에이전트 보기, 에이전트 관리, 폴더 생성)이 있습니다. 에이전트 목록은 폴더별로 묶이며, 폴더를 정하지 않은 에이전트는 미분류에 모입니다. 사이드바 맨 아래에는 즐겨찾기, 에셋설정, 라운지, 환경설정과 내 이름이 있고, 이름을 누르면 프로필, 로그아웃 메뉴가 열립니다.

가운데 입력란에 만들고 싶은 에이전트를 5자 이상 적어 보내면 대화로 에이전트 만들기가 시작됩니다. 입력란 아래에는 워크스페이스에 게시된 에이전트를 보여 주는 템플릿 카드와, 빈 에이전트를 만드는 에이전트 직접 만들기, 내보낸 ZIP 파일을 불러오는 에이전트 가져오기가 있습니다.

홈 화면의 사이드바

번호메뉴기능이런 때 사용하세요
1새 에이전트지금 보고 있는 에이전트 만들기 화면을 엽니다.다른 화면에서 새 에이전트를 만들러 돌아올 때
2에이전트 템플릿템플릿 목록을 열어 이미 만들어진 구성으로 에이전트를 만듭니다.처음부터 만들기보다 비슷한 에이전트를 본떠 시작하고 싶을 때
3더 보기유틸리티, 작업, 평가, SUPER AI 에이전트를 고르는 메뉴를 엽니다.백그라운드 작업을 확인하거나 평가 화면을 열 때
4에이전트 이름폴더별 에이전트 목록에서 이름과 설명이 보입니다. 누르면 그 에이전트와 대화하는 화면이 열립니다.주간 업무 보고서 도우미를 눌러 대화를 시작할 때

로고, 사이드바 축소, 목록 탭과 목록 도구, 아래쪽 메뉴와 사용자 이름은 메뉴 안내에서 하나씩 설명합니다.

홈 화면 가운데 영역

번호메뉴기능이런 때 사용하세요
1에이전트 설명 입력란만들고 싶은 에이전트를 5자 이상 적어 보내면 대화로 에이전트 만들기가 시작됩니다."회의록에서 할 일을 뽑아 주는 도우미를 만들어 줘"처럼 새 도우미가 필요할 때
2템플릿 카드워크스페이스에 게시된 에이전트를 카드로 보여 줍니다. 누르면 그 구성으로 내 에이전트를 만듭니다.동료가 잘 쓰는 에이전트를 바로 본떠 만들 때
3에이전트 직접 만들기이름과 설명만 입력해 빈 에이전트를 만들고 에이전트 편집 화면으로 이동합니다.지침을 처음부터 직접 쓰고 싶을 때
4에이전트 가져오기내보내기로 받은 에이전트 ZIP 파일을 불러옵니다.동료가 보내 준 에이전트 파일을 쓸 때

목록이 길면 에이전트 검색을 눌러 이름 일부를 입력합니다. 에이전트를 만드는 방법은 에이전트 만들기에서, 메뉴별 상세 설명은 메뉴 안내에서 다룹니다.

에이전트 대화 화면 열기​

사이드바에서 에이전트 이름을 누르면 그 에이전트의 대화 화면이 열립니다. 이때 사이드바 위쪽 메뉴가 이 에이전트 전용 메뉴(뒤로, 이 에이전트와 새 대화, 에이전트 설정, 채팅 검색...)로 바뀌고, 에이전트 목록 자리에 이 에이전트와 나눈 채팅 목록이 최근 것부터 나타납니다. 아직 대화한 적이 없으면 목록이 비어 있습니다.

화면 위쪽에는 지금 대화하는 에이전트의 이름과 설명이, 오른쪽에는 모델 이름과 별 모양의 에이전트 즐겨찾기가 있습니다. 가운데에는 "주간 업무 보고서 도우미와 대화하세요"와 함께, 에이전트에 챗 오프너가 정해져 있으면 바로 눌러 보낼 수 있는 예시 질문이 보입니다. 아래쪽 메시지 입력란("메시지 주간 업무 보고서 도우미..."가 흐리게 보이는 칸)에 요청을 적고 전송을 누릅니다. 에이전트 설정을 누르면 이 에이전트의 에이전트 편집 화면이 열립니다.

에이전트 대화 화면의 사이드바

번호메뉴기능이런 때 사용하세요
1뒤로사이드바를 원래의 메뉴와 에이전트 목록으로 되돌립니다.다른 에이전트로 옮겨 갈 때
2이 에이전트와 새 대화같은 에이전트와 새 채팅을 엽니다.이번 주 보고서를 마치고 다른 건을 새로 맡길 때
3에이전트 설정이 에이전트의 에이전트 편집 화면을 엽니다.보고서 형식을 바꾸려고 지침을 고칠 때
4채팅 검색...이 에이전트와 나눈 채팅을 이름으로 찾습니다. 아래 채팅 목록에는 채팅이 최근 것부터 쌓이고, 채팅마다 첫 메시지와 날짜·시간이 보입니다.지난주에 받은 보고서를 다시 찾을 때

에이전트 대화 화면의 입력란과 위쪽 버튼

번호메뉴기능이런 때 사용하세요
1모델 표시이 에이전트가 쓰는 모델 이름입니다. 대화를 나누면 아래에 사용량이 함께 보입니다.어떤 모델로 답했는지 확인할 때
2에이전트 즐겨찾기별 모양 버튼으로 이 에이전트를 즐겨찾기에 넣거나 뺍니다.매주 쓰는 도우미를 빠르게 찾고 싶을 때
3메시지 입력란요청을 입력합니다. 입력란에는 "메시지 주간 업무 보고서 도우미..."가 흐리게 보입니다.업무 메모를 붙여 넣을 때
4전송입력한 메시지를 보냅니다. 입력란이 비어 있으면 누를 수 없습니다.요청을 다 적고 보낼 때

입력란 아래 왼쪽의 도구, 서브에이전트, 미들웨어, 스킬과 오른쪽의 아티팩트, 파일 업로드, 백그라운드 모드 버튼은 메뉴 안내에서 설명합니다.

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 주간 업무 보고서 도우미를 누릅니다.

  2. 아래 프롬프트를 메시지 입력란에 붙여 넣습니다. 줄을 바꿀 때는 Shift와 Enter를 함께 누릅니다.

    프롬프트: 아래는 이번 주(11월 2일부터 6일까지) 제 업무 메모입니다. 박지원 팀장님께 올릴 주간 업무 보고서로 정리해 주세요.

    • 월: 영업본부 파일럿 사용자 문의 7건 응대(첨부파일 형식 문의 4건, 권한 2건, 기타 1건)
    • 화: 주간 보고서 에이전트 프롬프트 개선, 지시문에 '지난주 대비' 비교 항목 추가
    • 수: 사내 교육 '에이전트 만들기 실습' 보조 강사(참석 24명)
    • 목: 판매 실적 대시보드용 엑셀 정리, 9월 매출 이상치 3건 확인 요청
    • 금: 라운지에 '회의록 요약 에이전트' 공유 게시글 작성, 댓글 5건 답변
    • 이슈: 50MB 넘는 결산 엑셀 업로드 실패, 시트 분리 안내
    • 다음 주: 경영지원팀 확대 준비, 교안 개정 착수

  3. 전송을 누릅니다. 답변이 나타날 때까지 기다립니다.

팁: 메모 파일이 따로 있다면 입력란 아래 오른쪽의 파일 업로드로 첨부해 보낼 수도 있습니다. 첨부할 수 있는 파일 형식과 크기는 첨부파일 지원에 있습니다.

답변 읽기​

요청을 보내면 내 메시지가 오른쪽에, 에이전트의 답변이 그 아래에 나타납니다. 답변 본문은 지침에 정한 순서와 형식으로 정리된 주간 업무 보고서입니다. 예시에서는 이번 주 핵심 성과, 업무별 진행 표, 이슈와 조치, 다음 주 계획, 확인 필요 순서로 정리되었고, 메모의 숫자(문의 7건, 참석 24명, 이상치 3건, 댓글 5건)가 그대로 들어갔습니다. 답변이 끝나면 답변 아래에 복사 버튼과 이 답변의 입력·출력 토큰 수가 붙습니다. 복사는 답변 내용을 복사하고, 토큰 수를 누르면 토큰 사용량 상세 창이 열립니다.

화면 오른쪽 위 모델 이름 아래에는 이 채팅 전체의 입력·출력 토큰 수가 보이고, 누르면 스레드 토큰 요약 창이 열립니다. 화면 아래에는 "AI 생성 콘텐츠와 답변은 정확하지 않을 수 있습니다."라는 안내가 있으니, 결과를 그대로 쓰기 전에 사실을 확인합니다.

답변 화면

번호메뉴기능이런 때 사용하세요
1보낸 메시지내가 보낸 요청이 오른쪽에 표시됩니다. 그 아래로 에이전트가 정리한 주간 업무 보고서가 지침에 정한 순서와 형식으로 이어집니다.어떤 요청에 대한 답인지 확인할 때
2업무별 진행 표의 수치 열메모에 적은 숫자(문의 7건, 참석 24명, 이상치 3건, 댓글 5건)가 그대로 옮겨졌는지 보여 줍니다.팀장에게 올리기 전에 숫자가 바뀌지 않았는지 검토할 때

답변 아래 버튼과 사용량

번호메뉴기능이런 때 사용하세요
1복사답변 내용을 복사합니다.보고서를 메일이나 메신저에 옮길 때
2토큰 표시이 답변에 쓴 입력·출력 토큰 수입니다. 누르면 토큰 사용량 상세 창이 열립니다.긴 자료를 다룬 답변의 사용량을 볼 때
3채팅 사용량모델 이름 아래에 이 채팅 전체의 입력·출력 토큰 수가 보입니다. 누르면 스레드 토큰 요약 창이 열립니다.채팅 하나에서 사용량이 얼마나 쌓였는지 볼 때
4안내 문구"AI 생성 콘텐츠와 답변은 정확하지 않을 수 있습니다."가 표시됩니다.결과를 그대로 쓰기 전에 사실을 확인해야 한다는 점을 떠올릴 때

따라 해 보기​

  1. 답변 본문에 메모의 숫자(문의 7건, 참석 24명, 이상치 3건, 댓글 5건)가 바뀌지 않고 들어갔는지 확인합니다.

  2. 메모에 없는 업무나 숫자가 덧붙지 않았는지 확인합니다.

  3. 고칠 곳이 있으면 같은 채팅에 이어서 요청합니다.

    프롬프트: 이슈 항목에 '다음 주 수요일까지 시트 분리 가이드를 라운지에 올릴 예정'을 덧붙여 주세요.

  4. 고친 답변이 이슈와 조치 항목에 요청한 문장을 덧붙였는지 확인합니다.

  5. 마음에 들면 복사를 눌러 보고서를 옮깁니다.

팁: 같은 방식으로 자주 고쳐 달라고 하게 된다면 요청을 반복하기보다 지침을 고치는 편이 낫습니다. Fix 에이전트에서 말로 지침을 고치는 방법을 볼 수 있습니다.
