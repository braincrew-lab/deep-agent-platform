Deep Agent Builder 시작하기

사용 목적​

이 문서는 Deep Agent Builder에 처음 로그인한 사용자가 첫 에이전트를 만들고 대화를 시작하기까지의 과정을 순서대로 안내합니다. 로그인부터 에이전트 생성, 첫 대화, 확인까지 한 번에 따라 할 수 있도록 구성했습니다.

화면 위치​

로그인 화면은 별도 인증 화면으로 이메일과 비밀번호를 입력하는 두 개의 입력란과 로그인 버튼으로 구성됩니다. 로그인에 성공하면 왼쪽 사이드바가 있는 작업 공간으로 이동합니다. 새 에이전트 메뉴를 누르면 에이전트를 만드는 화면이 나타나고, 이후 에이전트별 대화 화면으로 이동합니다. 대화 화면 하단에는 메시지 입력란이 있습니다.

단계​

  1. 로그인 화면에서 비즈니스 이메일 입력란과 비밀번호 입력란을 채운 뒤 로그인 버튼을 누릅니다. 인증하는 동안 버튼 문구가 로그인 중으로 바뀝니다.
  2. 로그인 후 사이드바 맨 위의 새 에이전트를 누릅니다.
  3. 만들고 싶은 에이전트를 설명하는 입력란에 최소 5자 이상으로 목적을 적습니다. 예를 들어 고객 문의에 답변하는 상담 에이전트를 만들어달라는 식으로 구체적으로 적을수록 결과가 좋습니다.
  4. 에이전트 직접 만들기 버튼을 누릅니다. 버튼 문구가 생성 중으로 바뀌고, 완료되면 새로 만들어진 에이전트의 대화 화면으로 자동 이동합니다.
  5. 화면 하단 입력란에 메시지를 입력하고 전송 버튼을 눌러 대화를 시작합니다. 아직 아무 대화도 하지 않았다면 화면 가운데에 대화를 시작하라는 안내 문구가 보입니다.
  6. 에이전트가 추가 정보가 필요하면 직접 입력 항목과 제출 버튼이 있는 확인 절차가 나타날 수 있습니다. 필요한 내용을 입력하고 제출을 누르면 대화가 이어집니다.

결과 확인​

에이전트 생성이 끝나면 새 대화 화면으로 자동 전환되고 사이드바 목록에 방금 만든 에이전트가 추가됩니다. 메시지를 보낸 뒤에는 전송 버튼이 잠깐 중지 상태로 바뀌었다가 응답이 끝나면 다시 입력할 수 있는 상태로 돌아옵니다.

문제 해결​

로그인이 계속 실패한다면 이메일과 비밀번호를 다시 확인하고, 그래도 안 되면 관리자에게 계정 상태를 문의합니다. 에이전트 생성 버튼이 계속 비활성 상태라면 설명 입력란에 최소 5자 이상을 입력했는지 확인합니다. 메시지를 보냈는데 응답이 오지 않고 멈춰 있다면 새로고침 후 다시 시도하고, 반복되면 관리자에게 알립니다. 첫 에이전트 생성 이후에는 Deep Agent Builder 주요 기능 문서에서 공유, 내보내기, 백그라운드 실행 같은 추가 기능을 확인할 수 있습니다.
