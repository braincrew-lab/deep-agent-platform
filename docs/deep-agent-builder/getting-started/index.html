Deep Agent Builder 시작하기

이번 실습의 목표와 준비물​

가상 모임 안내문 도우미를 만들고 첫 안내문을 받아 봅니다. 도우미를 만들어 달라는 제작 요청과 완성된 도우미에게 주는 업무 질문은 서로 다른 단계입니다. 이번 실습에서는 파일이나 외부 도구 없이 텍스트만 사용합니다.

제작 요청이 완료되면 사용 화면으로 이동한 뒤 첫 업무를 시험합니다. 결과가 기준에 맞지 않으면 바로 업무에 투입하지 않고 수정 요청이나 지침 수정 후 다시 확인합니다.

로그인할 이메일과 비밀번호, 에이전트 생성 권한이 필요합니다. 사용할 수 있는 모델이 준비되어 있는지 담당자에게 확인하세요. 생성 권한이 없다는 안내가 나오면 새 계정이나 연결 값을 임의로 만들지 말고 해당 권한을 요청합니다.

1. 제작 요청을 보내기​

  1. 로그인 화면에 이메일과 비밀번호를 입력해 로그인합니다.
  2. 새 에이전트 화면을 엽니다. 목적을 적는 큰 입력란을 찾습니다.
  3. 다음 제작 요청을 입력합니다.

가상 모임 안내문을 작성하는 도우미를 만들어 주세요. 사용자가 준 시간, 장소, 준비물을 유지하고 제목 한 줄과 본문 세 문장으로 작성해 주세요. 빠진 정보는 추측하지 말고 확인이 필요하다고 알려 주세요. 외부 자료를 찾지 않고 제공된 내용만 사용합니다.

입력란의 전송 버튼을 누릅니다. 목적 설명은 앞뒤 공백을 제외하고 5자 이상, 2000자 이하여야 합니다. 위 문장은 이 범위에 들어갑니다. 에이전트 직접 만들기는 별도의 수동 생성 경로이므로 이 실습에서는 누르지 않습니다.

2. 제작 대화를 끝내고 사용 화면으로 이동하기​

요청을 보내면 제작 대화 화면이 열립니다. 추가로 정할 내용을 묻는 경우 가상 모임 안내문이라는 목적에 맞게 답합니다. 예를 들어 말투를 물으면 “참석자에게 보내는 친절한 존댓말”이라고 답할 수 있습니다. 실제 화면에 제시된 질문이나 선택 항목에 응답하세요.

제작이 완료되어 바로 이용하기 버튼이 나타나면 누릅니다. 이 버튼을 통해 생성된 에이전트의 사용 화면으로 이동합니다. 제작 대화에 문장이 표시된 것만으로 완료로 판단하지 마세요. 오류가 표시되거나 완료 버튼이 나오지 않으면 문제 해결을 확인합니다.

3. 완성된 도우미에게 첫 업무를 맡기기​

이제 생성된 에이전트의 대화 입력란에 다음 연습 자료를 보냅니다.

가상 모임 안내문을 작성해 주세요. 시간은 금요일 오후 3시, 장소는 작은 회의실입니다. 준비물은 읽고 싶은 책 제목 하나입니다.

자신의 질문이 표시되고 응답이 도착하는지 확인합니다. 제작 요청을 다시 보내는 것이 아니라 방금 만든 도우미에게 실제로 처리할 자료를 준 것입니다.

4. 첫 결과 검토하기​

확인 항목이번 실습의 완료 기준
사실금요일 오후 3시, 작은 회의실, 책 제목 하나가 유지됩니다.
형식제목과 본문을 구별할 수 있고 요청한 세 문장 구성을 따릅니다.
추가 정보회비, 신청 마감일 등 제공하지 않은 조건을 만들지 않습니다.

모델에 따라 표현은 달라질 수 있습니다. 사실이 빠졌다면 “장소인 작은 회의실을 포함해 다시 작성해 주세요”처럼 수정 요청을 보냅니다. 같은 문제가 반복되면 반복 업무에서 지침을 수정하고 다시 시험하세요.

다음 단계​

주요 기능에서 수정 화면의 지침과 저장 동작을 익힙니다. 서로 다른 입력에서도 원하는 행동을 하는지 확인하려면 활용 사례의 비교 실습으로 이동하세요.
