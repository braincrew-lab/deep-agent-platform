챗 오프너

챗 오프너(Chat Opener)는 에이전트와 새 대화를 열었을 때 입력창 위에 버튼처럼 보이는 예시 질문입니다. 처음 쓰는 동료도 버튼 하나로 질문을 시작할 수 있어, 에이전트가 어떤 요청을 잘 처리하는지 따로 설명하지 않아도 됩니다. 이 페이지는 김그루 사원이 "회의록 요약 도우미"에 예시 질문 네 개를 넣고, 대화 화면에서 어떻게 보이는지 확인하는 순서로 설명합니다. 같은 네 질문을 사례: 회의록 요약과 액션 아이템에서도 씁니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면의 오프너 탭에서 예시 질문을 최대 12개까지 추가합니다.
  • 이미 넣은 예시 질문의 문구를 고치거나 지웁니다. 바꾼 내용은 헤더의 저장을 누르지 않아도 대화 화면에 바로 반영됩니다.
  • 새 대화 화면에서 예시 질문 칩을 눌러 입력창에 채우고, 필요하면 고친 뒤 보냅니다.

오프너 탭​

예시 질문은 에이전트 편집 화면 오른쪽 탭 가운데 오프너 탭에서 관리합니다. 에이전트 대화 화면 왼쪽 사이드바의 에이전트 설정을 누르면 에이전트 편집 화면이 열립니다. 처음에는 목록이 비어 있고 "설정된 Chat Opener가 없습니다"와 "첫 번째 Chat Opener를 추가해보세요"가 보입니다. 탭 위쪽에는 "사용자가 대화를 시작할 수 있는 예시 질문을 설정하세요" 안내, 등록한 개수 표시, 추가 버튼이 있습니다. 목록의 줄에 마우스를 올리면 그 줄 오른쪽에 연필 모양의 수정과 휴지통 모양의 삭제 아이콘이 나타납니다.

오프너 탭

번호메뉴기능이런 때 사용하세요
1오프너예시 질문 목록과 추가 버튼을 보여 주는 탭을 엽니다.지금 어떤 예시 질문이 걸려 있는지 확인할 때
2안내"사용자가 대화를 시작할 수 있는 예시 질문을 설정하세요"라는 안내가 있습니다.이 탭의 용도를 확인할 때
3개수 표시지금 등록된 예시 질문 수와 최대 개수를 "4/12"처럼 보여 줍니다.질문을 더 넣을 여유가 있는지 볼 때
4추가예시 질문을 입력하는 "Chat Opener 추가" 창을 엽니다.새 예시 질문을 하나 더 넣을 때

목록의 줄에 마우스를 올리면 아래 그림처럼 그 줄 오른쪽에 아이콘 두 개가 나타납니다.

예시 질문 목록과 수정·삭제 아이콘

번호메뉴기능이런 때 사용하세요
1예시 질문 목록등록한 순서대로 번호와 문구가 보입니다. 긴 문구는 "…"로 줄여 보입니다. 대화 화면에도 이 순서로 나옵니다.가장 자주 쓰는 질문이 앞에 오는지 확인할 때
2수정연필 모양 아이콘입니다. 줄에 마우스를 올리면 보이며, 누르면 그 자리에서 문구를 고칩니다.질문을 더 구체적으로 바꿀 때
3삭제휴지통 모양 아이콘입니다. 줄에 마우스를 올리면 보이며, 누르면 확인 창 없이 바로 지워지고 "Chat Opener가 삭제되었습니다"가 나옵니다.더 이상 쓰지 않는 질문을 정리할 때

오프너는 이름·설명·지침과 저장 방식이 다릅니다. 추가, 수정, 삭제는 누르는 즉시 반영되며 "Chat Opener가 추가되었습니다"처럼 알림이 나옵니다. 대화 화면과 테스트 탭에서 쓰려고 헤더의 저장을 누를 필요는 없습니다. 헤더의 버전 안내에도 "도구, 모델, 오프너 등 고급 설정은 변경하는 즉시 저장됩니다."라고 적혀 있습니다.

다만 오프너를 바꾸면 헤더의 저장 옆에 "저장되지 않은 변경이 있습니다"가 나타나고 저장을 누를 수 있게 됩니다. 바뀐 오프너가 아직 현재 버전에 기록되지 않았다는 뜻입니다. 워크스페이스 등록은 저장된 버전으로 하므로, 에이전트를 워크스페이스에 등록하기 전에는 헤더의 저장을 눌러 오프너까지 현재 버전에 기록합니다.

12개가 모두 차면 개수 표시가 "12/12"가 되고 추가 버튼이 흐려져 누를 수 없습니다. 쓰지 않는 질문을 지운 뒤 다시 추가합니다.

Chat Opener 추가 창​

추가를 누르면 질문 한 줄을 넣는 "Chat Opener 추가" 창이 열립니다. 창에는 "대화 시작을 위한 예시 질문을 입력하세요" 안내와 질문 입력란, 취소, 추가 버튼이 있습니다. 입력란에 문장을 적고 창의 추가를 누르면(Enter를 눌러도 됩니다) 목록 끝에 들어가고 "Chat Opener가 추가되었습니다"가 나옵니다.

Chat Opener 추가 창

번호메뉴기능이런 때 사용하세요
1안내 문구"대화 시작을 위한 예시 질문을 입력하세요"라고 알려 줍니다.무엇을 넣는 창인지 확인할 때
2질문 입력란예시 질문 문구를 적습니다. 비어 있으면 "예: 오늘 날씨가 어때요?"가 흐리게 보입니다.동료가 실제로 쓸 말투로 질문을 적을 때
3취소입력한 내용을 버리고 창을 닫습니다.문구를 다시 정리한 뒤 넣고 싶을 때
4추가목록 끝에 질문을 넣고 창을 닫습니다.질문을 다 적었을 때

예시 질문 고치기​

목록에서 수정을 누르면 그 줄이 입력란으로 바뀌고, 오른쪽에 체크 모양의 저장과 X 모양의 취소 아이콘이 나타납니다. 이 줄의 저장은 고친 문구만 확정하는 버튼으로, 헤더의 저장과는 다릅니다. 누르면 "Chat Opener가 수정되었습니다"가 나옵니다. 아래 그림은 두 번째 질문 끝에 "담당이 정해지지 않은 항목은 맨 아래에 모아 주세요."를 덧붙이는 중인 모습입니다.

예시 질문 수정

번호메뉴기능이런 때 사용하세요
1수정 입력란지금 문구가 채워진 채로 열립니다. 고칠 부분만 바꿉니다.질문에 조건을 덧붙일 때
2저장체크 모양 아이콘입니다. 고친 문구로 바꿉니다. "Chat Opener가 수정되었습니다"가 나옵니다.고친 문구를 확정할 때
3취소X 모양 아이콘입니다. 고치기 전 문구로 되돌리고 입력란을 닫습니다.원래 문구가 낫다고 판단했을 때

따라 해 보기​

김그루 사원이 회의록 요약 도우미에 자주 쓰는 질문 네 개를 넣는 순서입니다.

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 누르고, 사이드바의 에이전트 설정을 누릅니다.
  2. 오른쪽 탭에서 오프너를 엽니다.
  3. 추가를 누르고 "첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요."를 입력한 뒤 창의 추가를 누릅니다.
  4. 같은 방법으로 아래 세 문장을 차례로 넣습니다.
    • 액션 아이템을 담당자별로 다시 묶어 주세요.
    • 기한이 다음 회의 전인 액션 아이템만 골라 주세요.
    • 참석자에게 보낼 회의 결과 공유 메일 초안을 써 주세요.
  5. 목록에 네 질문이 넣은 순서대로 보이고 개수 표시가 "4/12"인지 확인합니다.

팁: 예시 질문은 에이전트가 실제로 잘 답할 수 있는 범위 안에서 고르세요. 회의록 요약 도우미는 첨부한 회의록을 정리하는 에이전트이므로, 회의록 없이 답할 수 없는 질문에는 "첨부한 회의록에서"처럼 무엇을 함께 넣어야 하는지 드러나게 씁니다.

대화 화면에서 보이는 모습​

예시 질문은 에이전트와 새 대화를 열었을 때, 첫 메시지를 보내기 전 화면에 칩으로 보입니다. "회의록 요약 도우미와 대화하세요" 문구와 에이전트 설명 아래에 한 번에 네 개까지 보이며, 긴 문장은 칩 안에서 세 줄까지 보이고 나머지는 "…"로 줄여집니다. 김그루 사원처럼 네 개를 넣었다면 네 칩이 모두 한 줄에 보이고 화살표는 나타나지 않습니다. 다섯 개 이상 넣으면 칩 양옆에 이전, 다음 화살표가 나타나 다음 네 개로 넘겨 볼 수 있습니다.

새 대화 화면의 예시 질문 칩

번호메뉴기능이런 때 사용하세요
1이 에이전트와 새 대화지난 대화와 섞이지 않게 새 대화를 엽니다. 예시 질문은 이 화면에서 보입니다.다른 회의록을 새로 정리할 때
2대화 안내"회의록 요약 도우미와 대화하세요"와 그 아래 에이전트 설명이 보입니다.맞는 에이전트를 열었는지 확인할 때
3예시 질문 칩오프너 탭에 넣은 질문이 넣은 순서대로 보입니다. 그림은 첫 번째 칩입니다.무엇을 물으면 되는지 모를 때
4메시지 입력창직접 질문을 적는 칸입니다.예시 질문에 없는 내용을 물을 때

워크스페이스에 등록된 에이전트를 동료가 열면, 등록된 버전에 들어 있는 예시 질문이 같은 방식으로 보입니다. 등록 전에 헤더의 저장을 누르지 않았다면 최근에 바꾼 오프너가 등록된 버전에 빠져 있을 수 있습니다.

예시 질문을 눌렀을 때​

예시 질문 칩을 누르면 바로 보내지지 않고 입력창에 문장만 채워집니다. 누른 칩은 첫 메시지를 보내기 전까지 화면에 남아 있습니다. 파일을 첨부하거나 조건을 덧붙인 뒤 보낼 수 있습니다.

예시 질문을 누른 뒤의 입력창

번호메뉴기능이런 때 사용하세요
1누른 예시 질문방금 누른 칩입니다. 첫 메시지를 보내기 전까지 화면에 남아 있습니다.다른 예시 질문으로 바꾸고 싶을 때
2첨부 파일파일 업로드로 붙인 브레인크루_AI혁신팀_주간회의록_1110.txt입니다.정리할 회의록을 함께 보낼 때
3메시지 입력창누른 예시 질문의 문장이 채워집니다. 그대로 두거나 고칩니다.질문 끝에 "담당자 이름순으로 정렬해 주세요"를 덧붙일 때
4전송입력창의 문장을 보냅니다.문장과 첨부를 확인한 뒤 보낼 때

따라 해 보기​

  1. 회의록 요약 도우미 대화 화면에서 왼쪽 사이드바의 이 에이전트와 새 대화를 누릅니다.
  2. 입력창 위에 예시 질문 칩 네 개가 보이는지 확인합니다.
  3. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_AI혁신팀_주간회의록_1110.txt를 첨부합니다.
  4. "첨부한 회의록을 요약하고 결정사항과 액션 아이템 표(할 일, 담당, 기한)로 정리해 주세요." 칩을 누릅니다. 입력창에 같은 문장이 채워집니다.
  5. 전송을 누릅니다. 지침 순서대로 회의 개요, 세 줄 요약, 결정사항, 액션 아이템 표(할 일, 담당자, 기한, 관련 안건), 다음 회의 일시가 나오는지 회의록과 맞춰 봅니다. 김그루 사원이 보냈을 때는 결정사항에 안건 1~3의 결정 3건과 4번 기타 안건의 보안 점검 안내가 함께 정리되었고, 액션 아이템 표 6줄 가운데 회의록에 기한이 없는 항목은 "확인 필요"로 표시되었습니다.
