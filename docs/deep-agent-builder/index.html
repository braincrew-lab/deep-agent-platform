Deep Agent Builder 소개

이 매뉴얼은 개발 지식이 없는 회사원이 Deep Agent Builder로 자기 업무를 맡을 AI 에이전트를 만들고, 매일 쓰고, 다듬는 방법을 화면 순서대로 설명합니다. 모든 예시는 가상 회사 브레인크루의 AI혁신팀 김그루 사원이 실제로 쓰는 장면으로 통일했습니다.

이 페이지에서 할 수 있는 일

  • Deep Agent Builder에게 어떤 업무를 맡길 수 있는지 확인합니다.
  • 로그인하면 처음 보이는 홈 화면의 큰 구역을 구별합니다.
  • 지식 자료를 준비하는 다른 제품과 어떻게 이어지는지 알아봅니다.
  • 매뉴얼 전체 구성을 보고 지금 필요한 장으로 바로 이동합니다.

Deep Agent Builder로 하는 일​

Deep Agent Builder는 반복되는 업무를 에이전트에게 맡기는 작업 공간입니다. 에이전트는 미리 정해 둔 지침에 따라 글을 쓰고, 자료를 요약하고, 엑셀 데이터를 분석하고, PPT와 문서를 만듭니다. 만들고 싶은 에이전트를 말로 설명하면 대화를 나누며 에이전트를 만들어 주므로, 처음 쓰는 사람도 시작할 수 있습니다.

홈 화면 한눈에 보기​

로그인하면 홈 화면이 열립니다. 왼쪽 사이드바 위쪽에는 새 에이전트, 에이전트 템플릿, 더 보기 메뉴와, 내 에이전트·워크스페이스 에이전트 탭으로 나뉜 에이전트 목록이 있습니다. 사이드바 아래쪽에는 즐겨찾기, 에셋설정, 라운지, 환경설정과 내 이름(프로필 메뉴)이 있습니다. 가운데에는 만들고 싶은 에이전트를 5자 이상 설명해 보내면 대화로 에이전트 만들기가 시작되는 입력란이 있습니다.

Deep Agent Builder 홈 화면

번호메뉴기능이런 때 사용하세요
1새 에이전트사이드바 위쪽 첫 메뉴입니다. 이 홈 화면으로 돌아와 새 에이전트를 만듭니다. 아래의 에이전트 템플릿, 더 보기는 템플릿과 평가 같은 화면으로 이동합니다.에이전트를 새로 만들 때
2에이전트 목록의 에이전트내 에이전트와 워크스페이스 에이전트 탭으로 나뉜 목록에서 에이전트 이름을 누르면 그 에이전트와 대화하는 화면이 열립니다.매일 쓰는 주간 업무 보고서 도우미를 열 때
3에이전트 설명 입력란만들고 싶은 에이전트를 5자 이상 설명해 보내면 대화로 에이전트 만들기가 시작됩니다."회의록을 요약하는 도우미를 만들어 줘"처럼 새 에이전트가 필요할 때
4에셋설정사이드바 아래쪽 메뉴입니다. 도구, 모델, 스킬, API 키 같은 에셋을 관리하는 화면으로 이동합니다. 옆에는 즐겨찾기, 라운지, 환경설정이 있고, 그 아래 내 이름을 누르면 프로필 메뉴가 열립니다.도구·모델·스킬을 관리할 때. 화면 글자 크기는 환경설정에서 바꿉니다

내 목록의 에이전트 수와 순서는 사람마다 다릅니다. 화면 각 부분의 자세한 이름은 시작하기와 메뉴 안내에서 설명합니다.

다른 제품과의 연결​

에이전트가 사내 문서를 근거로 답하게 하려면 그 문서가 먼저 지식으로 준비되어 있어야 합니다. Deep Agent Builder 안에는 문서를 직접 올려 지식을 만드는 화면이 없습니다. 지식 자료는 다른 제품에서 준비하고, Deep Agent Builder에서는 준비된 지식을 골라 에이전트에 연결합니다.

단계제품하는 일안내 페이지
1. 문서 정리Deep Docurator원본 문서를 읽어 검색하기 좋은 조각으로 나눕니다.Deep Docurator 시작하기
2. 컬렉션 등록Deep Connector정리한 문서를 컬렉션(검색 범위로 묶은 문서 모음)에 올려 둡니다.Deep Connector 시작하기
3. 지식함 연결Deep Agent Builder에이전트 편집 화면의 지식함에서 내가 쓸 수 있는 컬렉션을 골라 연결합니다.지식으로 근거 있는 답변 받기
4. 근거 있는 답변Deep Agent Builder에이전트가 연결된 지식에서 근거를 찾아 답합니다.지식으로 근거 있는 답변 받기

컬렉션을 쓸 수 있는 권한은 관리자가 정합니다. 지식함에 원하는 지식이 보이지 않으면 관리자에게 접근 권한을 요청하세요.
