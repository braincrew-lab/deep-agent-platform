활용 사례 모음

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 Deep Agent Builder로 실제 업무를 처리하는 사례 9개를 한곳에 모은 안내판입니다. 사례마다 어떤 에이전트를 만들고, 어떤 파일을 올리고, 어떤 기능을 쓰는지 표로 먼저 확인한 뒤 사례 페이지로 이동해 그대로 따라 합니다.

이 페이지에서 할 수 있는 일

  • 9개 사례의 목표, 주요 기능, 준비 파일을 한 표에서 비교하고 내 업무와 가까운 사례를 고릅니다.
  • "이 일에는 어떤 기능을 쓰나"를 업무 기준으로 찾아, 기능 설명 페이지로 바로 이동합니다.
  • 사례에서 쓰는 예시 에이전트가 사이드바의 어디에 보이는지 확인합니다.
  • 사례를 내 업무로 옮길 때 공통으로 확인할 점을 미리 읽습니다.

메뉴를 하나씩 직접 눌러 익히고 싶다면 사례보다 실습 묶음 안내의 실습 여섯 가지를 먼저 해 보세요.

사례에서 쓰는 에이전트​

사례 페이지의 에이전트는 모두 김그루 사원이 만든 에이전트이며, 사이드바 내 에이전트 목록에 이름 그대로 보입니다. 사례를 처음부터 따라 하면 같은 이름의 에이전트가 내 목록에도 하나씩 생깁니다.

사례에서 쓰는 에이전트 목록

번호메뉴기능이런 때 사용하세요
1새 에이전트에이전트 만들기 첫 화면으로 이동합니다. 여기서 대화로 만들거나 에이전트 직접 만들기를 고릅니다.사례의 에이전트를 처음 만들 때
2내 에이전트 탭사람 모양 아이콘입니다. 내가 만든 에이전트 목록을 보여 줍니다.사례에서 만든 에이전트를 다시 찾을 때
3에이전트 검색돋보기 아이콘입니다. 누르면 "에이전트 이름 검색..." 칸이 열리고, 입력한 글자가 이름에 들어 있는 에이전트만 남습니다.목록이 길어 원하는 에이전트가 바로 보이지 않을 때
4미분류 폴더폴더에 넣지 않은 에이전트가 모여 있는 폴더이며, 괄호 안에 개수가 보입니다. 폴더 이름 줄을 누르면 목록을 접거나 펼칩니다. 김그루 사원의 목록에는 사례용 에이전트 9개(주간 업무 보고서 도우미, 회의록 요약 도우미, 제안서 PPT 작성기, 이메일 초안 도우미, 설문 결과 분석가, 교육 자료 제작 도우미, 계약서 검토 도우미, 판매 데이터 분석가, 시장 조사 리서처)와 다른 페이지에서 쓰는 에이전트가 함께 들어 있습니다.사례 페이지의 에이전트와 같은 것을 골라 대화를 시작할 때

따라 해 보기​

  1. 사이드바의 내 에이전트 탭을 누릅니다.
  2. 에이전트 검색을 누르고 "회의록"을 입력해 회의록 요약 도우미만 남는지 봅니다.
  3. 아직 없는 에이전트는 아래 표의 사례 페이지를 열어 에이전트를 만드는 단계부터 따라 합니다.

팁: 사례용 에이전트가 많아지면 목록 위쪽의 폴더 생성으로 "활용 사례" 폴더를 만들어 한곳에 묶어 두면 찾기 쉽습니다. 방법은 메뉴 안내에 있습니다.

사례를 업무에 옮길 때​

  • 결과의 숫자, 날짜, 담당자 이름은 원본 파일과 한 번 대조한 뒤 보고서나 메일에 옮깁니다. 사례 페이지마다 예시 파일로 직접 계산한 기준값을 적어 두었습니다.
  • 에이전트가 "확인 필요"로 남긴 칸은 사람이 채웁니다. 에이전트에게 채워 달라고 다시 요청하면 근거 없는 값이 들어갈 수 있습니다.
  • 같은 요청을 다시 보내도 문장과 표의 모양은 조금씩 달라질 수 있습니다. 사례의 "결과물 예시"는 확인할 항목을 기준으로 읽고, 문장이 똑같은지는 비교하지 않습니다.
  • 파일은 한 번에 최대 10개, 파일 한 개당 50MB까지 올릴 수 있습니다. 형식별 한도는 첨부파일 지원에 있습니다.
  • 고객사 이름, 개인 연락처처럼 밖으로 나가면 안 되는 정보는 입력하기 전에 지우거나, 개인정보 보호 미들웨어가 연결된 에이전트에서 다룹니다.
