Deep Agent Builder 활용 사례

연습 상황: 정보가 부족하면 질문하는 안내 도우미​

이 사례는 가상의 모임 안내 업무를 사용한 제작·검토 연습입니다. 실제 고객의 사용 사례나 성과를 뜻하지 않습니다. 목표는 보기 좋은 문장 하나를 얻는 데서 끝내지 않고, 정보가 없는 상황에서도 추측하지 않는지 살펴보는 것입니다.

시작하기에서 만든 도우미를 사용합니다. 지침을 직접 확인하려면 대화 화면의 수정 버튼을 열어 보세요. 검토에 사용할 기준은 제공된 사실 유지, 지정한 형식, 누락 정보 확인의 세 가지입니다.

지침과 입력 자료 준비하기​

수정 화면의 지침에 다음 기준이 있는지 확인하고 필요하면 저장합니다.

사용자가 제공한 모임 정보만으로 안내문 초안을 작성합니다. 시간, 장소, 준비물을 유지합니다. 제목 한 줄과 본문 세 문장을 사용합니다. 필요한 정보가 빠져 있으면 추측하지 말고 빠진 항목을 질문합니다.

첫 번째 입력은 정보가 모두 들어 있습니다.

가상의 독서 모임 안내를 작성해 주세요. 시간은 금요일 오후 3시입니다. 장소는 작은 회의실입니다. 각자 읽고 싶은 책 제목 하나를 준비합니다.

두 번째 입력은 별도의 가상 업무입니다. 첫 입력에서 받은 정보를 그대로 적용하지 않도록 자료의 독립성을 명시합니다.

앞의 모임과 다른 가상 모임입니다. 이번 안내에는 아래 정보만 사용해 주세요. 시간은 토요일 오전 10시입니다. 장소와 준비물은 아직 정하지 않았습니다. 안내문을 작성해 주세요.

순서대로 시험하기​

  1. 지침을 저장한 뒤 에이전트의 대화 화면으로 돌아갑니다.
  2. 첫 번째 입력을 보내고 시간, 장소, 준비물과 문장 구성을 확인합니다.
  3. 두 번째 입력을 보냅니다. 토요일 모임의 장소로 작은 회의실을 가져오거나 준비물을 임의로 정하는지 살펴봅니다.
  4. 누락 정보를 묻는다면 “장소는 큰 회의실, 준비물은 필기도구입니다”라고 후속 답변을 줍니다.
  5. 최종 초안에서 토요일 오전 10시, 큰 회의실, 필기도구가 함께 유지되는지 확인합니다.

질문이나 답변의 말투는 모델에 따라 달라질 수 있습니다. 정확한 문구 대신 정보 처리 방식으로 평가하세요.

결과를 비교하는 기준​

상황기대하는 행동수정이 필요한 행동
정보가 모두 있음제공된 세 항목을 안내문에 포함합니다.시간을 바꾸거나 장소를 빠뜨립니다.
장소·준비물이 미정필요한 정보를 묻거나 미정임을 명확히 드러냅니다.앞선 모임의 장소를 그대로 넣습니다.
후속 정보를 제공함새로 준 장소와 준비물을 사용합니다.질문만 반복하거나 이전 값을 유지합니다.

지침과 다른 답변이 나오면 해당 답변을 기준으로 어떤 조건을 보완할지 정합니다. “더 잘 써 주세요”보다 “장소가 미정이면 먼저 질문해 주세요”처럼 검토 가능한 수정이 도움이 됩니다.

내 업무에 적용할 때​

실제 안내 업무에서는 독자가 행동하는 데 꼭 필요한 항목을 먼저 정하세요. 행사 안내라면 시간과 장소, 제출 안내라면 제출 대상과 기한이 해당할 수 있습니다. 조직 규정이나 최신 정보를 자동으로 알고 있다고 가정하지 말고 입력 자료로 제공하거나 확인된 구성을 사용합니다.

원본 도우미를 유지하면서 다른 안내 형식을 시험하려면 반복 업무의 복제 절차를 사용하세요. 생성·저장·응답 단계가 막히면 문제 해결로 이동합니다.
