평가 결과 읽기와 비교

평가 실행이 끝나면 실행 상세에 전체 정답률과 문항별 채점 결과가 남습니다. 이 페이지는 이메일 초안 도우미를 "이메일 초안 기본 10문항"과 **완전성 (Completeness)**으로 평가한 실행을 예로, 요약 카드, 결과 표, 문항별 결과 상세, 진단 요약을 읽는 방법과 결과를 Excel로 내려받는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 요약 카드에서 전체 정답률, 데이터셋, 평가 방식, 평균 토큰을 확인합니다.
  • 결과 표를 통과/실패로 거르고, 토큰이나 소요 시간 순으로 정렬해 눈여겨볼 문항을 찾습니다.
  • 문항을 눌러 에이전트 답변과 채점 사유를 읽고, 지침에서 고칠 점을 정합니다.
  • 결과를 Excel 파일로 내려받고, 같은 데이터셋의 다른 실행과 비교하는 화면을 엽니다.

실행 요약 카드​

평가 실행 탭에서 에이전트를 고르고 목록에서 끝난 실행을 누르면 오른쪽에 실행 상세가 열립니다. 맨 위에 요약 카드가 놓입니다. 그림은 이메일 초안 도우미의 첫 실행(#1)으로, 10문항 가운데 9문항을 통과했습니다.

실행 요약 카드

번호메뉴기능이런 때 사용하세요
1지표 버전지표 정의 버전입니다(그림에서는 v3). 버전이 다른 실행끼리는 비교하지 않습니다.비교할 두 실행의 지표 버전이 같은지 확인할 때
2전체 정답률통과한 문항 수를 전체 문항 수로 나눈 값과 분수입니다. 그림에서는 90.0%(9/10)입니다. 오류나 시간 초과로 끝난 문항도 오답으로 셉니다.이번 실행이 몇 문항을 통과했는지 볼 때
3실행 유효성실행 도중 문서 도구가 환경 문제로 실패하지 않았는지를 정상, 주의, 무효 (환경) 가운데 하나로 보여 줍니다. 그림에서는 정상과 "문서 도구 0번 호출, 환경 실패 없음"입니다.점수를 믿어도 되는 실행인지 볼 때
4평균 토큰문항 하나에 에이전트가 쓴 입력/출력 토큰의 평균입니다. 그림에서는 13.9K / 159입니다.지침을 바꾼 뒤 답변이 지나치게 길어졌는지 볼 때

요약 카드는 다음과 같습니다. 실행에 따라 재질의 정확도 카드는 나오지 않을 수 있습니다.

  • 평가 실행: "#1 · 이메일 초안 도우미"처럼 실행 번호와 에이전트 이름이 나오고, 그 아래에 시작 시각과 지표 버전이 보입니다. 카드 오른쪽 위 데이터 새로고침(둥근 화살표)은 이 실행과 결과, 진단, 옆의 실행 목록을 다시 불러옵니다. 실행이 진행 중이면 제목 옆에 실행 취소가 나옵니다.
  • 전체 정답률: 통과한 문항 수를 전체 문항 수로 나눈 값이 크게 나오고, 옆에 "(9/10)"처럼 통과 문항 수와 전체 문항 수가 붙습니다. 오류나 시간 초과로 끝난 문항도 오답으로 셉니다. 오류가 있으면 아래에 오류 건수가 빨간 글씨로 붙습니다.
  • 실행 유효성: 무효 (환경)인 실행은 정답률이 흐리게 보이며 다른 실행과 비교할 수 없습니다. 지식을 찾아 답하는 에이전트를 평가할 때 꼭 확인합니다.
  • 재질의 정확도: 재질의 평가를 설정한 문항이 있는 실행에만 나옵니다. 기대한 대로 되묻거나 바로 답한 문항의 비율과 함께 모호한 질문에 재질의, 명확한 질문에 재질의, 물어본 항목 일치가 나옵니다.
  • 데이터셋: 실행에 쓴 데이터셋 이름과 "문항 10개"처럼 문항 수가 나옵니다.
  • 평가 방식: 채점 방식이 크게 나옵니다. 통과/실패로 채점하는 평가기는 통과/실패, 점수로 채점하는 평가기는 "5점 척도"처럼 최고 점수가 보입니다. 그 아래에는 평가기 이름과 점수 범위가 "완전성 (Completeness) · 0 / 1"처럼 최소 / 최대 순서로 나옵니다.
  • 평균 토큰: 문항 하나에 에이전트가 쓴 입력 토큰과 출력 토큰의 평균이 "입력 / 출력" 순서로 나옵니다.

결과 표​

요약 카드 아래 진단 요약을 지나면 결과 제목과 함께 문항별 결과 표가 있습니다.

결과 표

번호메뉴기능이런 때 사용하세요
1결과 (처리 수)"(10 / 10)"처럼 처리한 문항 수와 전체 문항 수입니다.모든 문항이 처리되었는지 볼 때
2Excel 내보내기이 실행의 결과를 Excel 파일로 내려받습니다. 실행이 끝났고 결과가 하나 이상 있을 때만 나옵니다. 끝나면 "Excel 파일이 다운로드되었습니다."가 뜹니다.결과를 팀에 공유하거나 보고서에 붙일 때
3결과 열제목 옆 필터 아이콘을 누를 때마다 전체, 통과만(P), 실패만(F) 순서로 바뀝니다.실패한 문항만 모아 볼 때
4결과 칸"1/1 · 통과", "0/1 · 실패"처럼 점수와 판정이 보이고, 실행이 끝나지 못한 문항은 오류로 보입니다. 그림에서 실패한 것은 6번 문항(설문 응답 감사 메일) 하나입니다.어느 문항이 떨어졌는지 찾을 때

결과 표에는 문항마다 입력, 참조 답변, 에이전트 답변, 결과, 근거, 입력 토큰, 출력 토큰, 소요 시간 열이 있고, 한 쪽에 10문항씩 나옵니다. 거르기와 정렬은 열 제목을 눌러서 합니다.

  • 입력, 참조 답변, 에이전트 답변은 문항의 질문, 데이터셋의 참조 답변, 에이전트가 실제로 쓴 답변입니다.
  • 근거는 정답 근거를 적은 문항에서 에이전트가 근거 문서를 찾았는지 보여 줍니다. 근거를 적지 않은 문항에는 "못 찾음"이 보이지만 판정 대상은 아닙니다.
  • 결과 제목을 누를 때마다 전체, 통과만, 실패만, 다시 전체 순서로 바뀝니다. 거르는 동안에는 제목 옆에 통과만이면 P, 실패만이면 F가 붙습니다.
  • 입력 토큰, 출력 토큰, 소요 시간 가운데 하나의 제목을 누르면 그 값이 큰 문항부터 정렬됩니다. 같은 제목을 다시 누를 때마다 작은 값부터와 큰 값부터가 번갈아 바뀝니다. 정렬 중인 열 제목에는 큰 값부터일 때 아래쪽 화살표, 작은 값부터일 때 위쪽 화살표가 붙습니다.
  • 문항 행을 누르면 오른쪽에 결과 상세가 열립니다.

결과 상세​

문항 행을 누르면 오른쪽에 "결과 상세" 패널이 열립니다. 표에서는 잘리는 답변 전문과 채점 사유를 읽을 수 있습니다. 맨 위에는 "병목 단계: 도구 미사용"처럼 이 문항에서 문제가 생긴 단계가 안내되는데, 이메일 초안 도우미처럼 도구 없이 답하는 에이전트에서는 늘 "도구 미사용"으로 나오므로 신경 쓰지 않아도 됩니다. 패널이 길어 위쪽과 아래쪽을 나눠 보여 줍니다. 그림은 첫 실행에서 실패한 6번 문항입니다.

결과 상세 위쪽

번호메뉴기능이런 때 사용하세요
1입력문항의 질문 전문입니다.무엇을 요청한 문항인지 다시 볼 때
2참조 답변데이터셋에 적은 꼭 들어가야 할 내용입니다.빠진 항목을 참조 답변과 맞춰 볼 때
3에이전트 답변에이전트가 쓴 메일 초안 전문입니다.실제로 어떤 메일이 나왔는지 읽을 때
4채점 사유채점 모델이 통과나 실패를 준 이유입니다. 질문이 한국어면 한국어로 적힙니다. 그림에서는 "120명이라는 응답 인원이 명시적으로 언급되지 않았"다는 이유로 실패했습니다.지침에서 무엇을 고쳐야 할지 정할 때

에이전트 답변과 채점 사유 사이의 스킬 버전은 이 문항에 답할 때 쓴 스킬과 그 버전입니다. 스킬을 쓰지 않았으면 "이 문항에서는 스킬을 쓰지 않았습니다."로 보입니다. 패널을 아래로 내리면 결과와 사용량이 이어집니다.

결과 상세 아래쪽

번호메뉴기능이런 때 사용하세요
1결과점수와 판정입니다. 오류로 끝난 문항은 오류 내용과 원본 오류 보기가 함께 나옵니다.오답인지, 실행이 끝나지 못한 것인지 가를 때
2입력 토큰 / 출력 토큰이 문항에서 에이전트가 쓴 토큰입니다. 아래에 소요 시간이 이어집니다.답변이 길거나 느린 문항을 찾을 때
3채점 모델 사용량채점에 쓴 입력 토큰, 출력 토큰, 추론 토큰, 호출 횟수입니다.채점에 드는 양을 가늠할 때
4실행 기록이 문항을 처리한 대화 ID와 실행 ID입니다. 옆 버튼으로 복사할 수 있습니다.관리자에게 특정 문항의 처리 기록을 알려 줄 때

맨 아래 도구 호출에는 에이전트가 이 문항에서 부른 도구 요약이, 검색 근거에는 도구가 가져온 결과 수가 나옵니다. 도구를 쓰지 않은 문항은 "도구를 호출하지 않았습니다", "도구 호출이 없습니다."로 보입니다. 오른쪽 위 X를 누르면 패널이 닫힙니다.

따라 해 보기​

이메일 초안 도우미의 첫 실행에서 실패한 문항을 모아 고칠 점을 정합니다.

  1. 평가 실행 탭에서 이메일 초안 도우미를 고르고, 목록에서 상태가 완료인 실행을 누릅니다.
  2. 전체 정답률과 그 아래 오류 건수를 확인합니다. 오류가 있으면 오답 가운데 일부는 답변 품질이 아니라 실행 문제 때문입니다.
  3. 결과 표의 결과 제목 옆 필터를 두 번 눌러 실패한 문항만 남깁니다.
  4. 실패한 문항을 하나씩 눌러 채점 사유를 읽고, 빠졌다고 지적된 항목을 적어 둡니다. 첫 실행에서는 6번 문항의 "응답 인원 120명"이 빠졌다는 사유 하나가 나왔습니다.
  5. 여러 문항에서 같은 항목이 빠졌으면 그것이 지침에서 고칠 점입니다. 고치고 다시 평가하는 순서는 회귀 평가와 개선에 있습니다.
  6. 결과를 팀과 나누려면 Excel 내보내기를 눌러 파일을 받습니다.

팁: 채점 사유가 납득되지 않으면 참조 답변부터 다시 봅니다. 참조 답변이 메일 전문이거나 모호하면 채점 모델도 흔들립니다. 참조 답변을 고치는 방법은 평가 문항 설계에 있습니다.

진단 요약​

요약 카드 아래 진단 요약에는 이 실행의 지표가 표로 정리됩니다. 오류, 시간 초과, 빈 답변 문항도 분모에 남기고 오답으로 센다는 안내가 함께 있습니다.

진단 요약

번호메뉴기능이런 때 사용하세요
1이 실행 열해결률 (해결/기대 근거가 있는 문항), 채점 통과율 (통과/전체 문항, 오류=실패), 결과 분류, 문항 토큰 p50 / p95, 해결 1건당 토큰, 소요 시간 p50 / p95 (초), 해결 1건당 시간 (초), 문항당 도구 호출 p50 / p95의 값입니다. 첫 실행은 채점 통과율 90.0% (9/10), 결과 분류 "오답 1 · 근거 미지정 9"입니다. 해결률처럼 정답 근거가 있어야 계산되는 지표는 근거를 적은 문항이 있을 때만 값이 나오고, 없으면 "—"로 보입니다.답변 길이와 응답 시간의 흔들림을 숫자로 볼 때
2도구 진단도구별 호출 수, 빈 결과, 오류 비율입니다. 도구를 쓰지 않은 실행은 "도구 호출 진단이 있는 결과가 없습니다."로 보입니다.도구를 쓰는 에이전트에서 어느 도구가 자주 실패하는지 볼 때
3실행 비교같은 데이터셋으로 돌린 다른 실행과 나란히 비교하는 창을 펼칩니다.지침을 고치기 전과 뒤의 결과를 견줄 때

실행 비교로 두 실행을 고르고 상승·하락한 문항을 읽는 방법은 회귀 평가와 개선에서 이어서 설명합니다.
