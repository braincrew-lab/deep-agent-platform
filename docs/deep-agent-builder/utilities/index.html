Deep Agent Builder 유틸리티

유틸리티는 회사와 워크스페이스에 등록된 도구, 모델, 스킬을 찾아보고 내 에셋에 설치하는 화면입니다. 같은 화면의 등록 요청 관리에서는 내가 만든 도구·스킬을 워크스페이스에 올려 달라고 요청하고, 워크스페이스 관리자는 등록된 리소스를 구성원에게 한꺼번에 배포합니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원의 화면으로 각 메뉴를 설명합니다. 설치한 도구를 에이전트에 붙이는 방법은 도구와 스킬 구성에 있습니다.

이 페이지에서 할 수 있는 일

  • 회사 전체 탭과 워크스페이스 탭에서 쓸 수 있는 리소스를 찾고 거릅니다.
  • 리소스 상세 창에서 설명과 기본 정보를 읽고 설치합니다.
  • 등록 요청 관리에서 내 도구를 워크스페이스에 등록 요청합니다.
  • Danger Zone의 일괄 배포 방식(증분 업데이트, 전체 동기화)의 차이를 압니다.

유틸리티 화면 열기​

사이드바 위쪽 더 보기를 누르고 유틸리티를 고릅니다. 제목 아래 "사용 가능한 도구, 모델, 미들웨어를 찾아보고 추가하세요"가 보입니다.

유틸리티 화면

번호메뉴기능이런 때 사용하세요
1기본 워크스페이스 탭(브레인크루)내 기본 워크스페이스에 등록된 리소스를 보여 줍니다. 탭 이름은 기본 워크스페이스 이름이며, 기본 워크스페이스가 없으면 전체로 보입니다. 아래에 "총 75개"처럼 개수가 보입니다.회사 공통으로 제공하는 도구를 볼 때
2워크스페이스워크스페이스 선택 칸이 나오고, 고른 팀 워크스페이스(예: AI혁신팀)의 리소스를 보여 줍니다.다른 팀이 올린 도구를 찾을 때
3등록 요청 관리리소스를 워크스페이스에 등록 요청하거나 일괄 배포하는 창을 엽니다. 워크스페이스가 리소스 등록을 허용할 때만 보입니다.내가 만든 도구를 팀이 함께 쓰게 할 때

탭 아래에서 도구, 모델, 스킬로 종류를 바꾸고, **검색...**으로 이름과 설명을 찾습니다. 유형: 필터는 전체, 설치됨, 미설치와 분야(커머스, 커뮤니케이션, 이미지, 지식, 법률, 생산성, 리서치, 안전)로 거릅니다. 처음에는 전체가 골라져 있습니다. 카드에는 이름, 설명, 분야, 버전과 설치됨 또는 미설치가 보입니다.

관리자 화면 접근 권한이 있는 계정에는 숨긴 항목을 함께 보는 숨김 표시와 항목의 표시 이름·설명·태그·공개 여부를 바꾸는 관리 버튼이 더 보입니다.

이럴 때 쓰세요: 김그루 사원이 시장 조사 리서처에 백과사전 검색을 붙이고 싶을 때, 유틸리티 도구 탭에서 지식 분야와 미설치를 함께 골라 아직 설치하지 않은 지식 도구만 남기고 wikipedia 카드를 엽니다.

리소스 상세와 설치​

카드를 누르면 상세 창이 열립니다.

리소스 상세 창

번호메뉴기능이런 때 사용하세요
1설치 상태미설치 또는 설치됨입니다. 위쪽 도구 설명에는 이 도구가 하는 일과 잘 맞는 질문, 맞지 않는 질문이 적혀 있습니다.이미 설치했는지 확인할 때
2기본 정보유형(분야), 버전, 등록자, 등록일입니다(그림에서 등록자 이메일은 흐리게 가렸습니다).누가 올린 도구인지, 최신 버전인지 볼 때
3설치내 에셋에 추가합니다. 설치한 도구는 에셋 화면 도구 탭과 에이전트의 도구 추가 창에 나타납니다. 설치 권한이 없으면 흐리게 보이며 "설치 권한이 없습니다. 관리자에게 문의하세요."가 안내됩니다.에이전트에 붙일 도구를 가져올 때

그림의 설치가 흐린 것은 이 환경에서 김그루 사원 계정에 설치 권한이 없기 때문입니다. 이때는 워크스페이스 관리자에게 설치를 요청하거나, 관리자가 아래 Danger Zone으로 일괄 배포해 주기를 기다립니다. 설치한 리소스에 새 버전이 나오면 카드에 동기화가 보입니다.

웹 검색, 뉴스, 쇼핑처럼 외부 서비스 키가 필요한 도구는 설치해도 회사에 키가 등록되어 있지 않으면 실행되지 않습니다. 설치 전에 관리자에게 키 등록 여부를 확인합니다.

등록 요청 관리​

등록 요청 관리를 누르면 "항목을 워크스페이스에 등록 요청하거나 해제합니다." 창이 열립니다.

등록 요청 관리 창

번호메뉴기능이런 때 사용하세요
1도구 / 모델 / 스킬요청할 리소스 종류를 고릅니다. 왼쪽 **등록됨 (75)**에는 이미 워크스페이스에 등록된 항목이 보입니다.종류별로 등록 상태를 볼 때
2항목 검색...오른쪽 등록 요청 가능한 항목(내가 만든 리소스 가운데 아직 등록되지 않은 것)을 이름으로 찾습니다.내 도구가 많을 때
3등록 요청고른 항목을 워크스페이스에 등록해 달라고 요청합니다. 워크스페이스 설정에 따라 바로 등록되거나 "관리자 승인 후 반영됩니다". 요청 중인 항목은 요청 취소로 거둘 수 있습니다.내 사내 지식 검색 도구를 팀 전체가 쓰게 할 때
4Danger Zone워크스페이스에 등록된 리소스를 구성원에게 일괄 배포하는 탭입니다.관리자가 팀 전체에 도구를 한꺼번에 깔아 줄 때

등록 요청에는 도구에 들어 있는 주소와 설명이 함께 올라갑니다. 개인 토큰을 직접 넣은 도구는 팀원도 그 토큰으로 호출하게 되므로, 토큰은 시크릿(환경변수) 참조로 바꾼 뒤 요청합니다. 시크릿 참조는 도구 등록 화면에서 설명합니다.

이럴 때 쓰세요: 김그루 사원이 만든 deep_connector_kb 도구를 영업팀도 쓰고 싶어 하면, 등록 요청 관리 → 도구 → deep_connector_kb의 등록 요청을 누릅니다. 승인되면 영업팀원은 유틸리티 워크스페이스 탭에서 설치합니다.

Danger Zone: 일괄 배포 및 동기화​

Danger Zone 탭은 "워크스페이스에 등록된 리소스를 대상 구성원에게 일괄 배포합니다." 실행하면 구성원 전원의 에셋이 바뀌므로 워크스페이스 관리자가 신중히 씁니다.

일괄 배포 및 동기화

번호메뉴기능이런 때 사용하세요
1리소스 유형도구, 모델, 스킬 가운데 배포할 종류를 고릅니다.이번에는 도구만 배포할 때
2증분 업데이트(안전)"구성원이 기존에 보유한 리소스는 유지하고, 워크스페이스에 등록된 신규 항목만 추가합니다."새로 등록한 도구를 팀원 모두에게 깔아 줄 때. 처음에는 이것을 고릅니다
3전체 동기화(주의)"구성원의 리소스를 워크스페이스 서버 상태로 덮어씁니다. 기존에 개별 수정한 설정이 초기화됩니다."구성원별 설정이 꼬여 서버 상태로 되돌려야 할 때만
4실행고른 유형과 방식으로 배포합니다.대상과 방식을 확인한 뒤

전체 동기화는 구성원이 도구 기본값이나 모델 설정을 따로 바꿔 둔 것까지 지웁니다. 실행 전에 팀에 미리 알리고, 대부분은 증분 업데이트로 충분합니다.

설정값 표​

항목기본값의미
처음 열리는 탭기본 워크스페이스 탭기본 워크스페이스가 없으면 전체
종류 탭도구모델, 스킬로 바꿀 수 있습니다.
유형: 필터전체설치됨, 미설치, 분야별
배포 방식정해져 있지 않음증분 업데이트(유지 + 신규 추가) 또는 전체 동기화(덮어쓰기) 중 골라야 실행됩니다.
