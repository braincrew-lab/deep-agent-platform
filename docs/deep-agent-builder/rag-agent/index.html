Deep Agent Builder RAG 에이전트 만들기

RAG 에이전트는 에이전트 지침만으로 답하지 않고, 연결한 지식 컬렉션을 실행 입력에 함께 사용하는 에이전트입니다. 이 페이지에서는 지식을 에이전트에 연결하고, 질문 결과가 실제 지식에 근거하는지 확인하는 판단 순서를 설명합니다.

시작하기 전에 확인할 것​

다음 조건을 먼저 확인합니다.

  • 에이전트를 조회하고 수정할 권한이 있습니다.
  • 사용할 지식 컬렉션이 현재 사용자에게 연결 가능한 상태입니다.
  • 질문에 답할 수 있는 비식별 테스트 문서가 지식 컬렉션에 들어 있습니다.
  • 지식 컬렉션의 검색과 실행에 필요한 연결 상태와 권한을 담당자에게 확인했습니다.

지식 컬렉션이 목록에 보인다는 사실만으로 검색 결과가 올바르거나 실행에 사용할 수 있다고 판단하지 마세요. 지식 목록을 조회할 권한이 필요하며, 삭제된 지식은 새 연결 목록에서 제외될 수 있습니다.

RAG 에이전트의 구성​

Deep Agent Builder에서 지식은 에이전트에 연결하는 자원으로 관리됩니다. 에이전트 상세에는 도구와 지식 연결이 함께 남고, 화면은 두 자원을 구분해 보여 줍니다.

이 구조 때문에 다음 두 목록을 구분해야 합니다.

목록용도지식 표시 방식
에이전트 상세현재 에이전트에 연결된 자원 확인지식 연결도 유지
사용자 도구 목록도구 선택지식 자원은 기본적으로 제외
사용자 지식 목록에이전트에 연결할 지식 선택연결 가능한 지식 항목 표시

지식 여부는 중앙 카탈로그 정보를 우선해 판단합니다. 카탈로그를 조회할 수 없을 때는 저장된 자원 유형을 기준으로 판단합니다. 카탈로그 조회가 지연돼도 목록 전체를 실패시키지 않고 저장된 정보로 전환하는 경계가 있습니다.

지식을 연결하고 질문하기​

1. 테스트용 질문과 근거를 정합니다​

지식 문서에서 확인할 수 있는 사실 하나를 골라 질문을 만듭니다. 문서에 없는 내용을 묻거나 여러 문서를 한꺼번에 평가하지 마세요. 첫 검증은 답이 맞는지와 어떤 자료를 사용했는지를 분리해서 확인할 수 있어야 합니다.

예를 들어 비식별 운영 문서에 있는 만료 기준 하나를 질문하고, 답변에 그 기준이 실제 문서와 일치하는지 대조합니다.

2. 에이전트에 지식을 연결합니다​

에이전트 수정 화면에서 연결 가능한 지식 목록을 확인하고 테스트할 컬렉션을 선택합니다. 선택한 항목은 에이전트의 지식 연결 목록에 남아야 합니다. 저장 뒤에는 에이전트 상세를 다시 열어 연결한 지식이 사라지지 않았는지 확인합니다.

목록에서 지식이 보이지 않으면 다음 순서로 판단합니다.

  1. 현재 사용자에게 지식 조회 권한이 있는지 확인합니다.
  2. 컬렉션이 삭제 상태인지 확인합니다.
  3. 현재 에이전트의 작업 공간과 컬렉션의 소유 범위가 맞는지 확인합니다.
  4. 목록에는 없지만 기존 에이전트에 연결된 지식이 도구함에 섞여 보이는지 확인합니다.

연결된 지식을 도구 목록에서 임의로 제거하지 마세요. 에이전트 상세에는 지식 연결도 함께 남아 있어야 저장 과정에서 연결이 끊기지 않습니다.

3. 테스트 질문을 보냅니다​

지식을 연결한 에이전트의 대화에서 준비한 질문을 보냅니다. 답변이 표시되면 다음 세 가지를 따로 기록합니다.

  1. 답변이 질문에 직접 답했는가
  2. 답변의 핵심 내용이 지식 문서와 일치하는가
  3. 제품이 제공하는 출처 또는 검색 근거가 실제 입력 문서와 연결되는가

답변이 그럴듯하다는 사실만으로 지식 검색이 성공했다고 보지 마세요. 출처나 검색 근거를 확인할 수 없는 경우에는 답변 품질만 확인된 것으로 기록하고, 지식이 사용됐다고 단정하지 않습니다.

4. 연결 전후 결과를 비교합니다​

같은 질문을 지식 연결 전후에 각각 보내 결과를 비교합니다. 비교할 때는 문장 표현보다 문서에만 있는 사실이 답변에 반영됐는지를 먼저 봅니다. 지식 연결 전에도 같은 답이 나오면 다음 가능성을 나눠 확인합니다.

  • 질문의 답이 에이전트 지침이나 일반 모델 지식만으로도 생성됐습니다.
  • 지식 연결이 저장되지 않았습니다.
  • 지식 컬렉션의 검색 또는 실행 권한이 준비되지 않았습니다.
  • 제품 화면에 지식 사용 근거가 표시되지 않습니다.

이 비교는 기능 지원 여부를 확인하는 테스트이지, 한 번의 답변으로 검색 품질 전체를 보증하는 절차가 아닙니다.

결과를 확인하는 기준​

RAG 에이전트의 완료 조건은 지식 컬렉션을 선택했다는 상태가 아닙니다. 다음 조건을 모두 확인해야 합니다.

  • 에이전트 상세에서 연결한 지식이 지식 자원으로 남아 있습니다.
  • 지식 연결 전후의 동일 질문 결과를 비교했습니다.
  • 테스트 문서에만 있는 사실이 결과에 반영되는지 확인했습니다.
  • 제공되는 출처 또는 근거가 있다면 원문과 대조했습니다.
  • 답변에 없는 내용을 추측으로 보충하지 않았습니다.

지식이 실행 시점에 어떤 하위 작업으로 펼쳐지는지와 내부 원장 구조는 이 페이지의 근거 범위에 포함하지 않습니다. 해당 동작을 확인해야 한다면 실행 로그나 별도 제품 계약을 먼저 확인하세요.

대표적인 실패와 다음 판단​

증상먼저 확인할 것다음 행동
지식 목록이 비어 있음사용자 권한, 컬렉션 상태, 작업 공간권한과 컬렉션 소유 범위를 확인한 뒤 다시 조회
연결 뒤 지식이 도구 목록에 섞임에이전트 상세와 목록의 구분 상태연결을 다시 저장하기보다 지식 판정과 목록 조회 상태를 담당자에게 전달
질문 결과가 일반 답변과 같음연결 저장 여부, 검색·실행 권한, 테스트 문서 내용비식별 문서의 고유 사실로 다시 비교
답변은 나왔지만 근거를 확인할 수 없음화면 또는 결과에 출처 표시가 있는지지식 사용을 성공으로 단정하지 말고 결과와 확인 불가 범위를 기록
연결된 지식이 갑자기 목록에서 사라짐삭제 상태와 카탈로그 조회 상태기존 연결과 새 연결 가능 여부를 나눠 확인

질문에 민감한 문서나 비밀값을 넣지 마세요. 지식 검색을 시험할 때는 고객 자료 대신 승인된 비식별 테스트 문서를 사용합니다.
