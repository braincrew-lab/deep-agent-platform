지식으로 근거 있는 답변 받기

사내 규정처럼 근거가 중요한 질문에는 에이전트가 사내 문서를 찾아 읽고 답해야 합니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 사내 규정 Q&A 도우미의 도구함에 사내 문서 검색 도구를 붙이고, 출장비 질문의 답이 실제로 어느 문서에서 나왔는지 확인하는 과정을 화면 순서대로 설명합니다.

이 페이지에서 할 수 있는 일

  • 사내 문서가 Deep Connector 컬렉션에서 에이전트의 답변까지 어떤 길로 오는지 압니다.
  • 에이전트 편집 화면 지식함의 지식 추가 창이 비어 있을 때 무엇을 뜻하는지 압니다.
  • 도구함에 사내 문서 검색 도구를 붙이고, 지침에 문서 검색 원칙을 적습니다.
  • 답변 위에 쌓이는 도구 실행 기록에서 에이전트가 무엇으로 검색했는지, 답변이 어느 문서와 조항을 근거로 했는지 확인합니다.
  • 지침에 원칙을 넣어, 문서에 없는 내용은 금액을 지어내지 않고 담당 부서 확인을 안내하게 합니다.
  • 에이전트 편집 화면 파일 탭에 올린 자료 목록을 대화에서 확인합니다.

사내 문서가 답변까지 오는 길​

Deep Agent Builder 안에는 문서를 올려 사내 지식을 만드는 화면이 없습니다. 문서는 Deep Connector의 컬렉션에 올리고, 에이전트는 Deep Connector가 제공하는 MCP 검색 도구로 그 컬렉션을 찾아 읽습니다. 순서는 다음과 같습니다.

순서하는 곳하는 일참고
1Deep Connector문서를 컬렉션에 올리고 처리를 끝냅니다.Deep Connector 시작하기
2Deep Connector컬렉션을 검색할 때 쓸 MCP 토큰을 발급받습니다.Deep Connector 시작하기
3Deep Agent Builder 에셋 화면도구 탭의 도구 추가에서 MCP 서버를 도구로 등록하고 토큰을 넣습니다.MCP와 에이전트의 MCP화
4에이전트 편집 화면도구함에 그 도구를 붙이고 지침에 검색 원칙을 적습니다.이 페이지
5대화 화면질문하면 에이전트가 도구로 문서를 검색해 답하고, 답변 위에 도구 실행 기록이 남습니다.이 페이지

이 페이지의 예에서는 1~3단계가 이미 끝나 있습니다. 김그루 사원의 에셋 화면 도구 탭에 deep_connector_kb 도구가 있고, 상세 정보에 유형 MCP, 출처 사용자 등록, 설명 "브레인크루 사내 지식(Deep Connector) 검색 MCP"가 보입니다. 상세 아래 필수 환경변수에 등록됨이 보이면 토큰이 들어 있는 상태입니다. 같은 상세의 세부 도구 (sub-tools) 표에는 문서 검색(search_documents), 컬렉션 탐색(glob_paths, list_collections), 문서 읽기(read_document) 같은 하위 도구가 나옵니다. 하위 도구 가운데에는 컬렉션이나 문서를 만들고 지우는 것(create_collection, delete_document 등)도 들어 있으니, 토큰을 받을 때 어떤 권한이 있는 토큰인지 Deep Connector 담당자에게 확인하세요.

이 페이지의 예시 컬렉션은 다음과 같습니다. 모두 매뉴얼 연습용 가상 자료입니다.

컬렉션설명들어 있는 문서
사내 규정브레인크루 취업규칙·출장비 규정·사내 AI 사용 가이드 (가상 자료)브레인크루_출장비_규정.docx, 브레인크루_출장비_규정.pdf(같은 내용), 브레인크루_취업규칙_2026.docx, 브레인크루_AI사용_가이드.md

출장비 규정 문서의 내용은 다음과 같습니다. 아래 확인 포인트는 모두 이 내용을 기준으로 합니다.

조항내용
1. 적용 범위국내·해외 출장과 업무 경비 처리에 적용
2. 국내 출장일비 1일 3만 원, 숙박비 1박 10만 원 한도(서울 12만 원), 교통 KTX 일반실 기준
3. 해외 출장일비 1일 미화 60달러, 6시간 이상 비행 시 프리미엄 이코노미 허용
4. 정산출장 종료 후 7일 이내 영수증을 첨부해 경비 시스템에 정산, 법인카드 사용분도 같은 기한

팁: 규정 문서에 판(예: 2025년판, 2026년판) 구분이 없습니다. 질문에 "2026년판 기준"이라고 쓰면 답변이 그 표현을 따라 적을 수 있지만, 실제로 검색되는 문서는 위 한 가지입니다.

지식함과 지식 추가 창​

에이전트 편집 화면의 폼 보기 아래쪽에는 도구함, 지식함, 미들웨어 칸이 나란히 있습니다. 지식함의 + 지식을 누르면 지식 추가 창이 열립니다. 이 창은 Deep Agent Builder에 연동된 지식을 골라 붙이는 곳인데, 이 페이지의 환경에는 연동된 지식이 없어 창 왼쪽에 "추가할 지식이 없습니다", 오른쪽에 "지식을 선택하세요"만 보입니다. 이때 사내 문서는 아래에서 설명하는 도구함의 검색 도구로 연결합니다.

고를 지식이 없는 지식 추가 창

번호메뉴기능이런 때 사용하세요
1검색란입력한 글자로 지식 목록을 좁혀 찾는 칸입니다. 255자까지 입력합니다.연동된 지식이 많을 때
2"추가할 지식이 없습니다"이 에이전트에 붙일 수 있는 지식이 목록에 없다는 뜻입니다.사내 문서를 도구함의 검색 도구로 연결해야 하는지 판단할 때
3"지식을 선택하세요"오른쪽 상세 영역에 고른 지식이 없다는 뜻입니다.목록에서 지식을 먼저 골라야 할 때

창은 닫기를 눌러 닫습니다. 지식함에 "추가된 지식이 없습니다"가 보여도 도구함에 사내 문서 검색 도구가 붙어 있으면 에이전트는 사내 문서를 찾아 답할 수 있습니다.

도구함에 사내 문서 검색 도구 붙이기​

도구함의 + 도구를 누르면 도구 추가 창이 열립니다. 왼쪽 목록에는 내가 쓸 수 있는 도구가 이름, 유형, 설명과 함께 보이고, 위쪽 **도구 검색...**으로 좁혀 찾을 수 있습니다. 아무것도 고르지 않으면 오른쪽에 "도구를 선택하면 상세 정보를 볼 수 있습니다"가 보이고, 도구를 고르면 오른쪽에 상세와 도구 추가 버튼이 나타납니다.

도구 추가 창에서 사내 문서 검색 도구 고르기

번호메뉴기능이런 때 사용하세요
1도구 검색...입력한 글자로 도구 목록을 좁힙니다.도구가 많을 때 "deep"으로 찾을 때
2도구 목록도구 이름, 유형(MCP), 설명입니다. 누르면 오른쪽에 상세가 열립니다.사내 문서 검색 도구를 고를 때
3상세 정보고른 도구의 이름, 유형, 설명입니다.붙이기 전에 설명으로 맞는 도구인지 확인할 때
4도구 추가고른 도구를 이 에이전트의 도구함에 붙입니다.붙일 도구를 정했을 때

도구를 붙이면 "도구가 에이전트에 추가되었습니다" 알림이 잠시 보이고, 도구함에 도구 이름이 나타납니다.

사내 문서 검색 도구를 붙인 도구함

번호메뉴기능이런 때 사용하세요
1+ 도구도구 추가 창을 엽니다.사내 문서 검색 도구를 붙일 때
2연결된 도구이 에이전트가 쓸 수 있는 도구 이름입니다. 칸이 좁으면 이름 끝이 줄어 보입니다.동료가 만든 도우미가 어떤 도구를 쓰는지 확인할 때
3도구 설정이 에이전트에서만 쓸 도구 값을 바꿉니다.에이전트마다 검색 조건을 다르게 둘 때. 도구와 스킬 구성 참고
4삭제도구 연결을 뺍니다. 빼면 "도구가 에이전트에서 제거되었습니다" 알림이 뜹니다.더 이상 쓰지 않을 도구를 정리할 때

같은 편집 화면에서 지식함과 오른쪽 테스트 탭도 함께 확인합니다.

비어 있는 지식함과 테스트 탭

번호메뉴기능이런 때 사용하세요
1지식함연동된 지식을 붙이는 칸입니다. 이 예에서는 "추가된 지식이 없습니다"로 비어 있습니다.지식이 아니라 도구로 사내 문서를 찾는다는 것을 확인할 때
2테스트 탭에이전트 편집 화면을 벗어나지 않고 바로 질문해 봅니다.도구를 붙인 직후 출장비 질문 하나로 답을 확인할 때

도구를 붙이거나 빼면 바로 대화와 테스트 탭에 반영됩니다. 헤더 저장 왼쪽에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 눌러 현재 버전에도 기록해 둡니다. 워크스페이스 등록은 저장된 버전을 쓰기 때문입니다.

따라 해 보기​

김그루 사원이 사내 규정 Q&A 도우미에 사내 문서 검색 도구를 붙이는 순서입니다.

  1. 사이드바 내 에이전트에서 사내 규정 Q&A 도우미를 누르고 에이전트 설정을 누릅니다.

  2. 도구함의 + 도구를 누릅니다.

  3. 목록에서 deep_connector_kb를 누르고, 오른쪽 설명이 "브레인크루 사내 지식(Deep Connector) 검색 MCP"인지 확인한 뒤 도구 추가를 누릅니다.

  4. "도구가 에이전트에 추가되었습니다" 알림을 확인하고 창을 닫습니다. 도구함에 deep_connector_kb가 보입니다.

  5. 지침 칸에 아래 내용을 넣고 헤더의 저장을 누릅니다. "저장되었습니다" 알림이 뜹니다. 지침은 도구와 달리 저장을 눌러야 반영됩니다.

    프롬프트: 당신은 브레인크루 임직원의 사내 규정 질문에 답하는 도우미입니다. 1) 사내 규정 질문에는 먼저 도구함의 사내 문서 검색 도구로 규정 문서를 찾아 읽고 답합니다. 답변 첫 줄에 근거로 쓴 문서 이름과 조항을 적습니다. 같은 규정이 여러 판이면 어느 판을 기준으로 했는지 밝힙니다. 2) 한국어 존댓말로, 결론을 먼저 쓰고 계산은 표로 보여 줍니다.

답변의 근거 확인하기​

검색 도구가 붙은 에이전트는 질문을 받으면 도구로 사내 문서를 검색한 뒤 답합니다. 이 과정은 답변 위에 도구 실행 기록으로 한 줄씩 쌓입니다. 사내 규정처럼 근거가 중요한 답변은 기록과 답변의 근거 표기를 함께 보고 씁니다.

답변 위의 도구 실행 기록과 근거 표기

번호표시의미이런 때 확인하세요
1도구 실행 기록에이전트가 부른 도구 이름(deep_connector_kb__search_documents)과 걸린 시간입니다. 누르면 펼쳐지고 다시 누르면 접힙니다.에이전트가 사내 문서를 검색했는지 볼 때
2펼친 입력도구에 넘긴 검색어입니다. 이 예에서는 "국내 출장비 규정"으로 검색했습니다.질문에 맞는 말로 검색했는지 볼 때
3출력 (도구 이름)바로 위 도구가 돌려준 결과입니다. 펼치면 검색된 문서 본문이 시스템 형식 그대로 보입니다.답변 숫자가 문서 원문과 같은지 직접 대조할 때
4답변 첫 줄지침대로 근거 문서 이름과 조항이 적힙니다. 이 예에서는 "근거: 브레인크루_출장비_규정.pdf 2. 국내 출장, 4. 정산"입니다.어느 문서의 어느 조항을 썼는지 볼 때

답변을 아래로 내리면 계산 표와 끝부분의 근거 표기가 이어집니다.

답변의 계산 표와 문서 근거

번호표시의미이런 때 확인하세요
1계산 표지침대로 계산을 표로 보여 줍니다.금액을 문서 내용과 대조할 때
2문서 근거답변 끝에 다시 적힌 근거 문서와 조항입니다.답변을 다른 사람에게 전달하기 전에 출처를 붙일 때

이럴 때 쓰세요: 영업팀 동료가 메신저로 출장비 한도를 물어 오면, 김그루 사원은 사내 규정 Q&A 도우미의 답을 그대로 옮기지 않고 답변 끝의 문서 근거 줄을 함께 붙여 보냅니다. 받는 사람이 규정 문서의 해당 조항을 직접 찾아볼 수 있어 같은 질문이 다시 오는 일이 줄어듭니다. 금액이 들어간 답은 보내기 전에 계산 표의 숫자를 출력 기록의 문서 원문과 한 번 대조합니다.

질문에 따라 기록 줄이 여러 개 쌓이기도 합니다. 예를 들어 컬렉션을 둘러보는 deep_connector_kb__glob_paths, 컬렉션 목록을 보는 deep_connector_kb__list_collections가 검색 앞뒤에 나올 수 있고, 문서를 통째로 읽으면 deep_connector_kb__read_document 줄이 생깁니다. 이름 앞부분 deep_connector_kb는 도구 이름이고, 뒷부분이 실제로 부른 하위 도구입니다.

출력 줄을 펼치면 영문 항목 이름과 검색 설정, 문서 내려받기 주소 같은 시스템 정보가 함께 보입니다. 화면을 공유하거나 캡처해 보고서에 붙일 때는 출력을 접어 둡니다. 도구 실행 기록이 하나도 없다면 문서를 검색하지 않고 답한 것이므로 지침의 1)번 원칙을 다시 확인하세요.

따라 해 보기​

김그루 사원이 서울 출장 전에 받을 수 있는 금액을 확인하는 순서입니다.

  1. 사이드바에서 사내 규정 Q&A 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 서울로 2박 3일 국내 출장을 갑니다. 출장비 규정 기준으로 일비와 숙박비 상한을 각각 계산하고, 정산 기한도 알려 주세요. 근거 문서 이름과 조항을 함께 적어 주세요.

  3. 답변 위에 deep_connector_kb로 시작하는 도구 실행 기록이 있는지 봅니다. 없으면 문서를 검색하지 않고 답한 것이므로 그대로 쓰지 않습니다.

  4. 기록 줄을 눌러 검색어가 질문에 맞는지 봅니다.

  5. 답변 첫 줄의 근거 문서와 조항, 계산 표의 금액을 아래 확인 포인트와 대조합니다.

결과를 이렇게 확인하세요​

  • 근거 문서는 브레인크루_출장비_규정.docx나 브레인크루_출장비_규정.pdf입니다. 두 파일은 내용이 같아 어느 쪽이 적혀도 됩니다. 조항은 2. 국내 출장과 4. 정산입니다.
  • 일비는 1일 3만 원이므로 3일이면 9만 원입니다.
  • 숙박비 상한은 서울이라 1박 12만 원이 적용되어 2박이면 24만 원입니다. 1박 10만 원으로 계산했다면 서울 예외를 빠뜨린 것입니다.
  • 정산은 출장 종료 후 7일 이내에 영수증을 첨부해 경비 시스템에 합니다. 법인카드 사용분도 같은 기한입니다.
  • 출장비 규정에는 사전 승인 조항이 없습니다. 사전 승인 기한을 물었는데 답변이 구체적인 날짜나 승인 방법을 적었다면 문서에 없는 내용이므로 담당 부서에 확인합니다.

근거가 없을 때의 답변 정하기​

문서에 없는 내용을 물으면 에이전트가 문서를 검색한 뒤에도 비슷한 조항이나 일반 상식으로 빈자리를 채울 수 있습니다. 예를 들어 김그루 사원이 지침에 "근거를 찾지 못하면 추측으로 답하지 말라"는 원칙만 넣고 "출장 중 렌터카를 빌리면 하루에 얼마까지 정산되나요?"라고 물었을 때, 규정에는 렌터카 조항이 없는데도 답변이 교통 기준(KTX 일반실)을 근거로 삼아 "KTX 일반실 요금 한도 내에서 정산"이라고 단정했습니다. 비슷한 조항을 찾은 것만으로 근거를 찾았다고 판단한 것입니다. 사내 규정 안내에서는 이런 추론이 오히려 혼란을 만듭니다.

그래서 원칙에는 "질문한 항목이 문서에 직접 적혀 있는지"를 기준으로 적습니다. 지침 끝에 아래 원칙을 3)번으로 이어 붙이고 저장합니다.

프롬프트: 3) 찾은 문서에 질문한 항목이 직접 적혀 있지 않으면 1)의 근거 표기 대신 첫 문장을 "사내 규정에서 찾지 못했습니다."로 시작하고, 비슷한 조항으로 미루어 답하거나 일반 상식, 추측으로 답하지 말고 담당 부서에 확인하라고만 안내합니다.

원칙을 넣은 뒤 "해외 출장 숙박비는 1박에 얼마까지 지원되나요?"라고 물으면, 규정의 해외 출장 조항에는 일비와 항공 기준만 있으므로 숙박비 한도가 없다고 답하고 담당 부서 문의를 안내합니다.

이럴 때 쓰세요: 사내 규정 Q&A 도우미가 규정에 명시되어 있지 않다고 답한 질문은, 김그루 사원이 목록으로 모아 두었다가 매달 경영지원팀에 규정 보완 요청으로 전달합니다. 담당 부서가 내용을 정해 규정 문서를 고치면 Deep Connector 컬렉션의 문서도 바꿔 달라고 요청하고, 같은 질문을 다시 보내 이번에는 근거 조항과 함께 답하는지 확인합니다. 근거가 없다는 답을 실패로 보지 않고 규정의 빈칸을 찾는 신호로 쓰는 셈입니다.

원칙을 넣어도 첫 문장이 지침의 문구("사내 규정에서 찾지 못했습니다.")와 글자 그대로 같지 않을 수 있습니다. 위 화면에서도 첫 줄에 근거 조항을 적은 뒤 "명시되어 있지 않습니다"로 결론을 냈습니다. 문구보다 중요한 것은 문서에 없는 금액을 지어내지 않았는지입니다.

따라 해 보기​

  1. 사내 규정 Q&A 도우미의 에이전트 설정에서 지침 끝에 위 원칙을 붙이고 저장을 누릅니다.

  2. 이 에이전트와 새 대화를 열고 아래 프롬프트를 보냅니다.

    프롬프트: 해외 출장 숙박비는 1박에 얼마까지 지원되나요?

  3. 답변이 해외 숙박비 금액을 지어내지 않고, 규정에 없다는 결론과 담당 부서 안내를 주는지 봅니다.

  4. 이어서 새 대화에서 앞의 서울 출장 질문을 다시 보내, 근거 있는 질문에는 평소처럼 금액을 답하는지 확인합니다.

같은 질문을 다시 보내도 도구를 쓰는 순서나 횟수, 답변 문구는 매번 조금씩 달라질 수 있습니다. 원칙을 넣은 뒤에는 문서에 있는 질문과 없는 질문을 섞어 몇 번 보내 보세요.

에이전트에 올린 파일 목록 확인하기​

사내 문서 검색 도구와 별개로, 에이전트 편집 화면 파일 탭에 올린 자료는 그 에이전트에만 붙는 자료입니다. 파일 탭에는 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .hwp, .hwpx 파일을 올릴 수 있습니다. 올린 파일 목록은 대화에서 기본 커맨드로 확인합니다.

일반 대화 화면 입력란에 "/"를 입력하면 커맨드 목록이 열리고, 기본 커맨드 묶음에 /list_agent_files가 보입니다.

정리​

  • 사내 문서는 Deep Connector 컬렉션에 두고, Deep Connector의 MCP 검색 도구를 에셋 화면에 등록한 뒤 에이전트 도구함에 붙여 씁니다. 지식 추가 창에 고를 지식이 없어도 이 방법으로 사내 문서를 검색할 수 있습니다.
  • 답변의 근거는 답변 위 도구 실행 기록(무엇으로 검색했는지)과 답변 첫 줄의 근거 문서·조항으로 확인하고, 금액은 원문과 대조합니다.
  • 문서에 없는 내용에 어떻게 답할지는 지침에 직접 적어 두고, 문서에 있는 질문과 없는 질문을 섞어 확인합니다.
