사례: 시장 조사 리포트

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 "시장 조사 리서처" 에이전트를 만들어, 사내 시장 메모를 바탕으로 경쟁 도구 비교표와 시사점 보고서를 받고 Word 파일로 내려받는 과정을 화면 순서대로 보여 줍니다. 웹 검색 도구가 없는 환경에서도 끝까지 따라 할 수 있고, 웹 검색 도구가 있으면 어디에 붙이는지도 함께 안내합니다.

이 페이지에서 할 수 있는 일

  • 대화로 시장 조사 리서처 에이전트를 만듭니다.
  • 시장 메모 파일을 첨부해 경쟁 도구 4종의 비교표를 받습니다.
  • 고객 인터뷰 결과와 비교표를 묶어 시사점 보고서를 받습니다.
  • 보고서를 Word 파일로 내려받습니다.
  • 답변의 숫자가 원본 메모와 같은지 확인합니다.

목표​

  • 경쟁 도구 A, B, C, D를 가격, 강점, 약점, 도입 조건으로 나눈 비교표 1개
  • 고객 인터뷰 순위와 비교표를 연결한 시사점 3가지와 다음 행동 제안
  • 팀장 보고에 바로 붙일 수 있는 Word 보고서 1개

준비물​

항목내용
예시 파일브레인크루_AI업무도구_시장메모.md (가상 자료. 경쟁 도구 4종과 고객 인터뷰 12개사 요약)
대화에 첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (한 번에 최대 10개, 파일 1개당 최대 50MB. 마크다운·텍스트·HTML은 10MB, PDF·이미지·Word·한글 문서는 20MB까지)
에이전트 모드일반 에이전트
도구기본 구성으로 충분합니다. 도구함의 도구 추가 창에 웹 검색 도구가 있으면 붙여서 최신 공개 정보를 함께 찾게 할 수 있습니다.
권한새 에이전트를 만들 수 있는 권한. 권한이 없으면 새 에이전트가 눌리지 않습니다.

예시 파일의 마크다운(.md) 형식은 대화 첨부와 에이전트 만들기 첨부 모두에서 받습니다. 회사 내부 시장 자료가 PDF나 Word로 되어 있어도 위 목록의 형식이면 같은 방법으로 쓸 수 있습니다.

에이전트 만들기​

사이드바의 새 에이전트를 누르면 "생성하려는 에이전트에 대해 알려주세요" 화면이 열립니다. 입력란에 맡길 일을 적어 보내면 에이전트 만들기 도우미가 질문을 이어 가며 도구, 모델, 지침을 정리합니다.

따라 해 보기​

  1. 사이드바의 새 에이전트를 누릅니다.

  2. 입력란에 아래 요청을 붙여 넣고 보냅니다.

    프롬프트: 시장 조사 리서처를 만들어 주세요. 내가 첨부한 시장 메모와 인터뷰 자료를 읽고 경쟁 제품 비교표(제품, 가격, 강점, 약점, 도입 조건)와 시사점 보고서를 써 주는 에이전트입니다. 자료에 없는 가격이나 수치는 지어내지 말고 "자료에 없음"으로 적고, 출처가 첨부 자료인지 웹 검색인지 표마다 밝혀 주세요. 보고서는 한국어로, 요약 3줄, 비교표, 시사점 3가지, 다음 행동 순서로 써 주세요.

  3. 도우미가 확인 질문을 띄우면 답을 고르고 전체 제출을 누릅니다. 웹 검색 도구를 추천받으면 쓸지 정해 답합니다.

  4. 완료 카드가 나오면 바로 이용하기를 누릅니다. 에이전트 이름이 "시장 조사 리서처"가 아니면 에이전트 편집 화면 위쪽 이름 칸에서 고친 뒤 헤더의 저장을 누릅니다.

팁: 도우미가 묻는 질문은 요청 내용에 따라 달라집니다. 이 페이지에서 예로 든 질문이 나오지 않아도 같은 기준(자료에 없는 숫자 금지, 출처 표시)으로 답하면 됩니다.

웹 검색 도구 붙이기(있을 때만)​

웹 검색 도구는 회사 환경에 등록되어 있을 때만 보입니다. 없으면 이 절을 건너뛰고 첨부 자료만으로 진행합니다. 도구는 에이전트 편집 화면 가운데 편집 영역의 도구함에서 붙입니다. 붙인 도구는 헤더의 저장을 누르지 않아도 바로 대화와 테스트 탭에 쓰입니다.

따라 해 보기​

  1. 사이드바에서 시장 조사 리서처를 누르고 에이전트 설정을 누릅니다.
  2. 가운데 편집 영역의 도구함에서 + 도구를 눌러 도구 추가 창을 엽니다.
  3. 목록에 웹 검색 도구가 있으면 고르고 도구 추가를 누릅니다. 없으면 창을 닫습니다.
  4. 오른쪽 테스트 탭에서 "오늘 날짜 기준으로 찾을 수 있는 공개 정보만 알려 주세요"처럼 짧게 시험해 봅니다.

팁: 목록에 없는 도구는 직접 만들 수 없을 수 있습니다. 필요하면 관리자에게 웹 검색 도구 등록을 요청하세요. 도구 구성은 도구와 스킬 구성에 있습니다.

단계별 실행​

1단계: 메모 첨부와 경쟁 비교표​

시장 조사 리서처와 새 대화를 열고 시장 메모를 첨부해 경쟁 도구 4종의 비교표를 받습니다.

따라 해 보기

  1. 사이드바에서 시장 조사 리서처를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드를 눌러 브레인크루_AI업무도구_시장메모.md를 고릅니다. 파일 칩의 처리 표시가 끝날 때까지 기다립니다.

  3. 아래 프롬프트를 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 시장 메모로 경쟁 도구 A, B, C, D 비교표를 만들어 주세요. 열은 제품, 유형, 가격, 강점, 약점·제약, 도입 조건, 출처로 하고, 메모에 없는 값은 "자료에 없음"으로 적어 주세요.

  4. 답변 위쪽의 첨부 읽기 기록을 펼쳐 메모를 읽었는지 보고, 답변의 비교표가 제품, 유형, 가격, 강점, 약점·제약, 도입 조건, 출처 열로 되어 있는지 확인합니다.

2단계: 시사점 보고서​

같은 대화에서 비교표와 메모의 고객 인터뷰 결과를 묶어 시사점 보고서를 받습니다.

따라 해 보기

  1. 같은 대화에서 아래 프롬프트를 보냅니다.

    프롬프트: 방금 만든 비교표와 메모의 고객 인터뷰(12개사) 결과를 연결해 시사점 보고서를 써 주세요. 요약 3줄, 고객 니즈 순위 표(응답 기업 수와 비율), 경쟁 도구가 채우지 못한 빈틈, 브레인크루가 취할 시사점 3가지, 다음 행동 순서로 써 주세요. 근거가 메모의 어느 줄인지도 괄호로 밝혀 주세요.

  2. 고객 니즈 표의 비율과 시사점의 근거 표시를 확인합니다.

  3. 웹 검색 도구를 붙였다면 추가로 "각 도구의 공개 가격이 메모와 다른지 웹에서 확인하고 출처를 함께 적어 주세요"라고 요청합니다. 웹에서 찾은 내용은 출처 열에 웹 검색으로 표시되어야 합니다.

3단계: Word 파일로 내려받기​

보고서 답변을 Word 파일로 받는 방법은 세 가지입니다. 일반 에이전트에서는 에이전트에게 파일을 만들어 달라고 요청하는 방법이 가장 간단합니다.

따라 해 보기

  1. 같은 대화에서 아래 프롬프트를 보냅니다.

    프롬프트: 1단계 비교표와 2단계 시사점 보고서를 Word 파일(.docx) 하나로 만들어 주세요. 파일 이름은 브레인크루_AI업무도구_시장조사.docx로 하고, 요약 3줄, 비교표, 고객 니즈 표, 시사점, 다음 행동 순서로 넣어 주세요.

  2. 답변에 붙은 파일의 다운로드를 눌러 저장합니다. 같은 파일은 입력란 아래 오른쪽의 아티팩트를 눌러 여는 창에도 모입니다.

  3. 내려받은 파일을 열어 표가 깨지지 않았는지 확인합니다.

답변의 표가 아티팩트로 만들어졌다면 아티팩트 창에서 미리보기로 내용을 확인한 뒤 내보내기 > Word로 내보내기로 .doc 파일을 받을 수도 있습니다. 아티팩트 내보내기 형식은 PPT·문서 만들기에 정리되어 있습니다.

팁: 세 번째 방법은 문서작성 에이전트입니다. 보고서를 캔버스에서 쪽 단위로 미리 보며 받고 싶으면 에이전트 편집 화면의 설정 탭에서 에이전트 모드를 문서작성 에이전트로 바꾼 뒤 보고서를 다시 요청합니다. 결과가 오른쪽 문서 캔버스에 열리고, 내보내기에서 원본 다운로드, DOCX 형식으로 내보내기, PDF 형식으로 내보내기를 고를 수 있습니다. 캔버스 사용법은 캔버스로 문서·PPT·표 만들기에 있습니다.

결과물 예시​

예시 메모로 받은 결과에서 아래 값이 맞는지 확인합니다. 값은 원본 메모에서 직접 셀 수 있습니다.

확인할 것원본 메모 기준 값
비교 대상 수4종(A, B, C, D)
A의 가격과 약점월 1인 1.5만 원, 사내 지식 연결 미지원
B의 가격과 약점월 1인 3만 원, 평가 기능 없음
C의 가격과 강점월 1인 4만 원, 엑셀 연동 강점
D의 가격과 도입 조건월 단가는 메모에 없음(연간 계약만), 구축 기간 3개월
고객 니즈 1위사내 문서 근거 답변, 12개사 중 9개사(75%)
고객 니즈 2위보고서 자동 작성, 12개사 중 7개사(약 58%)
고객 니즈 3위권한 관리, 12개사 중 6개사(50%)

결과를 이렇게 확인하세요​

  • D의 월 가격이 숫자로 적혀 있으면 지어낸 값입니다. "자료에 없음"으로 고쳐 달라고 요청합니다.
  • 비율의 분모가 12개사인지 봅니다. 응답 기업 수를 더한 22(9 + 7 + 6)로 나누면 틀린 계산입니다. 한 회사가 여러 기능을 골랐기 때문입니다.
  • 시사점이 메모의 빈틈과 이어지는지 봅니다. 예를 들어 1위 니즈인 사내 문서 근거 답변을 A가 지원하지 않는다는 점, B에 평가 기능이 없다는 점이 근거로 쓰였는지 확인합니다.
  • 메모는 가상 자료이고 인터뷰 표본이 12개사뿐입니다. 보고서에 "표본이 작다"는 한계가 적혀 있는지 봅니다.

응용 팁​

  • 조사 주제가 바뀌면 메모 파일만 바꿔 같은 프롬프트를 씁니다. 자주 쓰는 요청은 커맨드로 저장해 두면 / 를 눌러 바로 보낼 수 있습니다. 방법은 커맨드와 재사용에 있습니다.
  • 대화를 시작할 때마다 같은 첫 질문을 쓴다면 챗 오프너로 등록합니다. 챗 오프너를 참고하세요.
  • 보고서를 발표 자료로 바꾸려면 이 대화의 비교표를 복사해 제안서 PPT 작성기에 넘깁니다. 사례: PPT 생성 에이전트를 보세요.
  • 웹 검색 결과는 회사 밖 정보입니다. 보고에 쓰기 전에 출처를 직접 열어 확인합니다.
