문제 해결

이 페이지는 Deep Agent Builder를 쓰다가 화면에서 만날 수 있는 안내 문구를 증상, 원인, 직접 해 볼 일로 정리합니다. 안내 문구는 화면에 나오는 문장 그대로 적었으므로, 본 문구의 앞부분으로 이 페이지에서 찾으면 됩니다.

이 페이지에서 할 수 있는 일

  • 화면 문구로 증상을 찾아 원인과 해 볼 일을 확인합니다.
  • 파일 업로드, 에이전트 만들기, 권한, 실행 중단, 캔버스, 스킬 업로드, 가져오기 문제를 나눠 봅니다.
  • 실행이 중간에 멈출 때 최대 처리 단계 수를 올립니다.
  • 관리자에게 문의할 때 필요한 실행 번호를 찾습니다.

증상별 바로 찾기​

화면에서 본 것아래 절
"지원하지 않는 파일 형식입니다", "파일 크기가 업로드 제한…", "빈 파일은…", "문서를 처리하고 있어요…", "만료됨"파일 첨부와 업로드
"에이전트 생성 권한이 없습니다…", "사용 가능한 모델이 없어…", 전송 버튼이 눌리지 않음에이전트 만들기와 모델
"설치 권한이 없습니다…", "이 게시판에 글을 작성할 권한이 없습니다", "다음 리소스에 사용 권한이 없어…"권한 안내
"작업 한계에 도달했습니다", "개인정보 보호 정책으로 실행을 멈췄습니다", 정책 차단 문구가 답변으로 표시됨실행이 중간에 멈춤
"미리보기를 사용할 수 없습니다…", "다운로드에 실패했습니다…", "이전 버전"캔버스와 다운로드
"SKILL.md 파일이 반드시 포함되어야 합니다.", "올바른 ZIP 파일이 아닙니다…"스킬 업로드
"Only .zip files are accepted", 가져오기 실패에이전트 가져오기

파일 첨부와 업로드​

입력란 아래 오른쪽의 파일 업로드로 파일을 붙이면 형식과 크기를 먼저 확인하고, 올린 뒤 문서 내용을 읽을 수 있게 처리합니다. 붙지 않거나 전송되지 않으면 아래 표에서 문구를 찾습니다.

화면 문구원인직접 해 볼 일
"지원하지 않는 파일 형식입니다"대화에서 받지 않는 형식입니다. 오른쪽 칸의 받는 형식 21가지에 없는 확장자는 모두 해당합니다. 예를 들어 예전 Word 형식(.doc), 압축 파일(.zip), .tiff, .bmp 이미지, .xhtml 웹 문서는 붙지 않습니다.받는 형식으로 바꿔 다시 붙입니다. 대화에서 받는 형식: .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm
"Excel 파일 크기가 제한(50MB)을 초과합니다. 현재 크기: …"처럼 형식 이름이 붙은 문구형식별 크기 한도를 넘었습니다. PDF·이미지·Word·한글 문서 20MB, 마크다운·텍스트·HTML 10MB, Excel·CSV·PowerPoint 50MB입니다.파일을 나누거나(엑셀은 시트별로 분리) 이미지 해상도를 줄여 다시 붙입니다.
"파일 크기가 업로드 제한(50MB)을 초과합니다."파일 한 개의 업로드 제한인 50MB를 넘었습니다. 대화, 에이전트 만들기 첨부, 에이전트 파일, 라운지 첨부에 모두 같은 한도가 적용됩니다.50MB 이하로 나눠 올립니다.
"빈 파일은 업로드할 수 없습니다."크기가 0인 파일입니다.원본 프로그램에서 다시 저장한 파일을 붙입니다.
"파일 확장자와 실제 파일 형식이 일치하지 않습니다."확장자만 바꾼 파일입니다. 예를 들어 .csv 파일 이름을 .xlsx로 바꾼 경우입니다.원본 프로그램에서 원하는 형식으로 "다른 이름으로 저장"해 붙입니다.
"암호나 권한 보호(DRM)가 걸린 문서는 업로드할 수 없습니다. 보호를 해제한 뒤 다시 올려 주세요."암호나 DRM이 걸린 문서입니다.보호를 해제한 사본을 만들어 붙입니다. 해제 권한이 없으면 문서 담당자에게 요청합니다.
"문서를 처리하고 있어요. 잠시 후 다시 시도해 주세요."올린 문서를 아직 읽는 중입니다.첨부 파일 칩의 처리 표시가 끝난 뒤 다시 전송을 누릅니다.
"문서 처리에 실패한 파일이 있어 전송하지 않았어요. 실패한 파일을 삭제한 뒤 다시 보내 주세요."붙인 파일 중 내용을 읽지 못한 파일이 있습니다.실패 표시가 붙은 파일 칩을 빼고 다시 보냅니다. 필요하면 PDF로 바꿔 다시 붙입니다.
"첨부한 파일을 모두 올리지 못해 전송하지 않았습니다. 파일을 확인한 뒤 다시 보내 주세요."붙인 파일이 모두 거부됐습니다.위 문구들로 각 파일의 이유를 확인해 고친 뒤 다시 보냅니다.
파일 칩에 "만료됨"예전에 올린 파일의 보관 기간이 지났습니다. "업로드가 만료되어 파일을 더 이상 열 수 없습니다. 다시 업로드해 주세요."같은 파일을 다시 올립니다.
"최대 10개 파일만 업로드할 수 있습니다"한 번에 붙일 수 있는 파일은 10개입니다.나눠서 보냅니다.

에이전트 만들기 화면에서는 엑셀 형식(.xlsx, .xls, .xlsb, .xlsm, .csv)을 받지 않습니다. 엑셀 파일은 에이전트를 만든 뒤 대화에서 첨부합니다. 형식과 한도 전체는 파일 첨부 정책과 가드레일에 있습니다.

에이전트 만들기와 모델​

화면 문구원인직접 해 볼 일
"에이전트 생성 권한이 없습니다. 관리자에게 문의하세요."계정에 에이전트를 만들 권한이 없습니다. 새 에이전트도 눌리지 않습니다.관리자에게 생성 권한을 요청합니다. 그동안은 사이드바 위쪽 에이전트 템플릿의 워크스페이스 탭에서 워크스페이스에 등록된 에이전트를 찾아 상세 창의 대화하기로 씁니다. 한 번 대화한 에이전트는 사이드바 워크스페이스 에이전트 탭에 모입니다.
입력란 아래 "최소 5자 이상 입력해 주세요", 전송 버튼이 눌리지 않음요청 문장이 5자보다 짧습니다.맡길 일을 한 문장으로 적습니다. 예: "회의록을 요약하고 액션 아이템을 표로 정리하는 도우미"
"사용 가능한 모델이 없어 이 에이전트를 실행할 수 없습니다. 모델을 등록하면 바로 사용할 수 있습니다."내가 쓸 수 있는 모델이 등록되어 있지 않습니다.배너의 모델 등록을 누르거나, 관리자에게 모델 등록을 요청합니다. 모델 구성은 모델 구성에 있습니다.
"에이전트 생성을 진행하지 못했습니다"만들기 도우미 실행 중 문제가 생겼습니다. 아래에 이유 문장이 함께 표시됩니다.이유 문장이 "잠시 후 같은 내용을 다시 보내 주세요"면 다시 보내고, "관리자에게 문의해 주세요"면 문의합니다. 연결이 끊긴 경우 다시 연결을 누릅니다.
"이미지 첨부만 지원합니다."확인 질문에 답할 때는 이미지만 붙일 수 있습니다.문서 파일은 처음 요청을 보낼 때 붙이거나, 에이전트를 만든 뒤 대화에서 붙입니다.

권한 안내​

화면 문구원인직접 해 볼 일
"설치 권한이 없습니다. 관리자에게 문의하세요."유틸리티에서 도구, 모델, 미들웨어, 스킬을 설치할 권한이 없습니다.필요한 항목 이름을 적어 관리자에게 설치를 요청합니다.
"이 게시판에 글을 작성할 권한이 없습니다"라운지의 유즈케이스, 사용 가이드, FAQ, 공지사항 게시판은 관리자만 씁니다.질문은 문의 및 오류, 제안은 기능 개선 제안, 일반 글은 커뮤니티 게시판에 씁니다. 이 게시판에도 쓸 수 없으면 관리자에게 권한을 요청합니다.
워크스페이스 에이전트 대화 화면에 "다음 리소스에 사용 권한이 없어 채팅이 비활성화되었습니다:"배포된 에이전트가 쓰는 모델, 도구, 미들웨어 중 내가 쓸 권한이 없는 것이 있습니다. 문구 아래에 해당 리소스가 표시됩니다.표시된 리소스 이름을 적어 워크스페이스 관리자에게 사용 권한을 요청합니다.
"접근 권한이 없습니다"이 화면을 볼 권한이 없습니다.돌아가기를 누르고 필요한 화면 이름을 적어 관리자에게 문의합니다.
"이 에이전트를 실행할 권한이 없습니다. 관리자에게 권한을 요청해 주세요."에이전트를 실행할 권한이 없습니다.관리자에게 실행 권한을 요청합니다.

권한 구조는 시크릿과 권한에, 라운지 게시판별 작성 권한은 커뮤니티에 있습니다.

실행이 중간에 멈춤​

작업 한계에 도달했습니다​

증상: 답변이 끝나지 않고 "작업 한계에 도달했습니다" 알림과 함께 "에이전트가 한 번에 진행할 수 있는 작업 한계에 도달해 응답이 중단되었습니다."가 표시됩니다. 자료를 많이 모으거나 문서를 여러 개 만드는 요청에서 생깁니다.

원인: 한 번의 응답에서 거칠 수 있는 처리 단계(모델 호출과 도구 실행) 수가 에이전트에 정한 최대 처리 단계 수에 닿았습니다.

따라 해 보기

  1. 같은 대화에서 "이어서 진행해 주세요"라고 보내 남은 작업을 계속합니다.
  2. 자주 멈추면 사이드바의 에이전트 설정을 눌러 에이전트 편집 화면을 열고 오른쪽 설정 탭을 엽니다.
  3. Recursion Limit의 최대 처리 단계 수를 지금보다 높게(예: 800) 바꾸고, 탭 맨 위 오른쪽의 저장을 누릅니다. "에이전트 설정이 저장되었습니다" 알림이 뜨면 바로 적용됩니다.
  4. 같은 요청을 다시 보내 끝까지 진행되는지 확인합니다.

팁: 최대 처리 단계 수를 올리면 긴 작업이 멈추기 전에 더 많은 단계를 진행할 수 있는 대신, 그만큼 처리 시간과 비용이 늘어날 수 있습니다. 필요한 만큼만 올리고, 그래도 멈추면 요청을 두세 번으로 나눠 보냅니다. 값을 낮추면 끝나지 않고 계속 도는 실행을 더 일찍 멈출 수 있습니다.

개인정보 보호 정책으로 실행을 멈췄습니다​

화면 문구원인직접 해 볼 일
"보호 대상 개인정보가 포함되어 개인정보 보호 정책에 따라 실행을 멈췄습니다. 해당 정보를 빼고 다시 요청해 주세요."에이전트의 개인정보 보호 미들웨어가 처리 방식 차단으로 설정되어 있고, 요청이나 첨부에 보호 대상 정보가 있었습니다. 괄호 안에 종류가 표시되기도 합니다.개인정보를 지운 뒤 다시 보냅니다. 업무상 일부만 보여도 되면 에이전트 담당자에게 처리 방식을 마스킹이나 가리기로 바꿀 수 있는지 문의합니다.
"개인정보 검사를 마치지 못해 실행을 멈췄습니다. 잠시 후 다시 시도하고, 반복되면 관리자에게 문의하세요."개인정보 검사가 제한 시간 안에 끝나지 않았습니다. 큰 첨부 파일에서 생기기 쉽습니다.잠시 뒤 다시 보내고, 첨부 파일을 나눠 봅니다.

미들웨어 설정은 미들웨어와 개인정보 보호에 있습니다.

정책 차단 문구가 답변으로 표시됨​

증상: 답변 자리에 회사 보안 정책으로 요청을 처리할 수 없다는 문장이 표시되고, 그 이상 진행되지 않습니다.

원인: 회사가 설정한 가드레일 정책이 이 요청을 거부했습니다. 문구는 회사 정책 설정에 따라 다릅니다.

직접 해 볼 일: 문구에 차단 사유가 있으면 그 내용을 빼거나 바꿔 다시 보냅니다. 업무상 꼭 필요한 요청이면 문구 그대로와 시각을 적어 관리자에게 문의합니다. 같은 요청을 반복해 보내지 않습니다.

그 밖의 실행 오류​

화면 문구직접 해 볼 일
"요청을 처리하지 못했어요. 잠시 후 다시 시도해 주세요."잠시 뒤 다시 보냅니다.
"요청이 많아 모델 사용이 잠시 제한되었습니다. 잠시 후 다시 시도해 주세요."몇 분 기다린 뒤 다시 보냅니다.
"에이전트에 모델이 설정되어 있지 않습니다. …"에이전트 편집 화면 모델 설정에서 모델을 고릅니다.
"이 모델의 API 키가 설정되지 않았습니다. …"모델을 등록한 사람이나 관리자에게 API 키 등록을 요청합니다.

캔버스와 다운로드​

문서작성 에이전트의 결과물은 대화 오른쪽 문서 캔버스에 열립니다.

화면 문구원인직접 해 볼 일
"미리보기를 사용할 수 없습니다. 원본 파일을 다운로드해 주세요."캔버스에서 미리 볼 수 없는 파일이거나 미리보기를 만들지 못했습니다.내보내기의 원본 다운로드로 받아 PC에서 엽니다.
"문서를 불러오지 못했습니다. 다시 시도해 주세요."문서를 가져오는 중 연결이 끊겼습니다.다시 시도를 누릅니다.
"다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."내보내기에 필요한 권한(에이전트 보기, 실행)이 없거나 변환에 실패했습니다.다시 시도하고, 계속되면 원본 다운로드로 받습니다. 그래도 안 되면 관리자에게 권한을 문의합니다.
선택 목록에 "이전 버전"요소를 고른 뒤 문서가 새 버전으로 바뀌었습니다. "선택한 문서가 변경되었습니다. 이전 선택을 삭제하고 요소를 다시 선택해 주세요."선택 삭제로 이전 선택을 지우고 문서 요소 선택으로 다시 고릅니다.
"문서 요소는 최대 20개까지 첨부할 수 있습니다."한 번에 고를 수 있는 요소는 20개입니다.나눠서 수정을 요청합니다.
다운로드 링크에 "기간이 만료되어 다운로드 받을 수 없습니다."에이전트가 만든 파일의 다운로드 기간이 지났습니다.같은 대화에서 파일을 다시 만들어 달라고 요청합니다.
캔버스가 보이지 않음, "아직 캔버스에 파일이 없습니다"일반 에이전트이거나 아직 게시된 문서가 없습니다.에이전트 편집 화면 설정 탭의 에이전트 모드가 문서작성 에이전트인지 확인합니다.

캔버스 기능 전체는 캔버스로 문서·PPT·표 만들기에 있습니다.

스킬 업로드​

사이드바의 에셋설정을 눌러 여는 에셋 화면의 스킬 탭에서 스킬 업로드를 쓰거나, 에이전트 편집 화면 스킬 탭의 문서 작성 스킬에서 ZIP 업로드를 쓸 때 나오는 문구입니다.

화면 문구원인직접 해 볼 일
"SKILL.md 파일이 반드시 포함되어야 합니다.".md 파일로 올릴 때 SKILL.md가 빠졌습니다.SKILL.md를 함께 고릅니다. .md 파일은 최대 30개까지 올릴 수 있습니다.
"업로드할 .md 파일을 선택해 주세요."파일을 고르지 않았습니다..md 파일이나 ZIP 파일 1개를 고릅니다.
"ZIP 파일은 한 개만, .md 파일과 섞지 않고 올릴 수 있습니다."ZIP과 .md를 섞어 골랐거나 ZIP을 여러 개 골랐습니다.ZIP 하나만 고르거나 .md 파일만 고릅니다.
"ZIP 파일만 업로드할 수 있습니다"문서 작성 스킬에 ZIP이 아닌 파일을 골랐습니다.스킬 폴더를 ZIP으로 압축해 올립니다.
"올바른 ZIP 파일이 아닙니다. ZIP 파일을 다시 만들어 올려 주세요."손상됐거나 ZIP이 아닌 파일입니다.압축 프로그램으로 다시 압축합니다.
"ZIP 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 합니다."SKILL.md가 너무 깊은 폴더에 있거나 없습니다.SKILL.md를 ZIP 맨 위나 하나뿐인 최상위 폴더 바로 안에 둡니다.
"SKILL.md 맨 앞에 --- 줄로 감싼 머리말(frontmatter)이 있어야 합니다."SKILL.md 첫머리에 머리말이 없습니다.맨 앞에 --- 줄 두 개를 두고 그 사이에 name 값을 적습니다. name이 없으면 "SKILL.md 머리말(frontmatter)에 name 값이 있어야 합니다."가 표시됩니다.
"SKILL.md의 name이 스킬 이름 규칙에 맞지 않습니다. …"이름이 소문자로 시작하지 않거나, 허용되지 않은 글자가 있거나, 64자를 넘거나, anthropic, claude가 들어 있습니다.소문자 영문, 숫자, 밑줄, 하이픈만 써서 고칩니다.
"허용 확장자: …"ZIP 안에 받지 않는 확장자의 파일이 있습니다. 하나만 있어도 전체가 거부됩니다.ZIP 안에는 md, txt, json, yaml, yml, csv, py, sh, js, ts, html, xml, toml, docx, pptx, xlsx, pdf, png, jpg, jpeg, gif 파일만 둡니다. svg는 받지 않습니다.
"파일 크기가 업로드 제한(50MB)을 초과합니다."ZIP 파일이 50MB를 넘었습니다.큰 예제 파일을 빼고 다시 압축합니다.
"파일 또는 스킬 크기가 너무 큽니다. 파일 하나는 최대 256KB입니다."편집기에서 다루는 텍스트 파일 하나가 256KB를 넘었습니다.파일을 나눕니다.

스킬 구조와 올리는 순서는 스킬 만들기와 업로드에 있습니다.

에이전트 가져오기​

증상원인직접 해 볼 일
"Only .zip files are accepted"에이전트 가져오기에는 ZIP 파일만 올릴 수 있습니다.다른 사람이 에이전트 내보내기로 만든 ZIP 파일을 그대로 올립니다. 압축을 풀었다 다시 묶지 않습니다.
가져오기 창에는 "최대 200MB"라고 보이지만 50MB가 넘는 ZIP은 가져오기에 실패함실제로 올릴 수 있는 크기는 50MB까지입니다.내보낸 에이전트에서 큰 파일을 빼고 다시 내보내 50MB 이하로 만듭니다.
가져오기 요약에 "…누락되었습니다 (마스터 매칭 실패)"원본 에이전트가 쓰던 도구나 모델 중 이 환경에 없는 것이 있습니다.에이전트 편집 화면에서 빠진 도구와 모델을 확인하고 다시 붙입니다.
가져오기 요약에 "원본 첨부 파일은 제외되었습니다 — 필요 시 다시 업로드하세요"가져오기에는 원본 첨부 파일이 들어가지 않습니다.에이전트 편집 화면 파일 탭에서 필요한 파일을 다시 올립니다.

자세한 순서는 에이전트 가져오기와 내보내기에 있습니다.

문의할 때 필요한 정보 찾기​

관리자가 문제를 빨리 찾으려면 어느 답변인지 정확히 알아야 합니다. 답변 오른쪽 아래의 토큰 배지를 누르면 토큰 사용량 상세 창이 열리고, 맨 아래 추적 정보에 문의에 필요한 Run ID(답변 하나의 실행 번호)가 전체 값으로 나옵니다. 추적 정보에는 Run ID, Thread ID, Trace ID(기록된 경우에만), 생성 시간, 상태가 있고, 각 번호 옆에서 값을 복사할 수 있습니다. 대화 화면 오른쪽 위 모델과 대화 합계를 눌러 여는 스레드 토큰 요약 창의 턴별 상세에도 답변마다 Run ID가 보이지만 앞 여덟 자리만 나옵니다. 그 줄을 누르면 해당 답변의 토큰 사용량 상세 창이 열리므로, 전체 Run ID는 언제나 추적 정보에서 복사합니다. 창 위쪽 성능에는 지연 시간과 TTFT가, 도구 사용에는 이 답변에서 부른 도구가 나옵니다.
