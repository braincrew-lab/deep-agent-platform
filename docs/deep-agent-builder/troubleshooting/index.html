Deep Agent Builder 문제 해결

문제가 생기면 같은 작업을 반복하기보다 현재 화면과 마지막으로 성공한 단계를 먼저 확인합니다. 생성, 저장, 실행, 목록 조회는 서로 다른 단계이므로 오류가 발생한 지점을 나눠 봐야 합니다.

제작 요청의 전송 버튼이 비활성화되어 있습니다​

새 에이전트 화면의 목적 입력란을 확인합니다. 앞뒤 공백을 제외한 설명이 5자 이상 2000자 이하인지 살펴보세요. 짧은 제목만 입력했다면 어떤 도우미가 필요한지 한 문장으로 적습니다. 파일을 붙인 것만으로 목적 설명을 대신할 수는 없습니다.

생성 중인 상태인지, 생성 권한이 없다는 안내가 있는지도 확인합니다. 권한 안내가 있으면 관리자에게 계정의 생성 권한과 사용할 작업 공간을 문의하세요. 설명 길이를 고친 뒤 전송할 수 있는지 다시 확인합니다.

계속 막히면 다음 정보를 남겨 담당자에게 전달합니다.

  • 입력한 설명의 글자 수
  • 화면에 표시된 안내 문구
  • 문제가 발생한 시간
  • 선택한 작업 공간

비밀번호, 연결 키, 민감한 지침 전문은 전달하지 않습니다.

제작 대화는 보이는데 만든 에이전트로 이동하지 않습니다​

목적을 전송하면 제작 대화가 시작됩니다. 추가 질문이나 오류가 있는지 확인하고, 제작이 완료되어 바로 이용하기가 표시되면 그 버튼을 누릅니다. 제작 대화가 보인다는 사실만으로 에이전트 생성이 끝났다고 판단하지 마세요.

에이전트 직접 만들기를 눌렀다면 이름과 설명을 입력한 뒤 수정 화면으로 이동하는 별도 경로입니다. 현재 화면이 제작 대화인지 수정 화면인지 먼저 구별하세요. 오류로 완료되지 않았다면 오류 문구를 기록하고, 같은 요청을 반복하기 전에 이미 만들어진 에이전트가 있는지 확인합니다.

저장 버튼을 누를 수 없거나 변경이 남지 않습니다​

수정 화면에서 저장 버튼이 비활성화된 경우 변경 사항이 없는지, 저장 요청이 진행 중인지 먼저 확인합니다. 지침이나 이름을 실제로 바꿨는지도 살펴보세요. 비활성화된 버튼만으로 계정 권한이 없다고 판단하지 않습니다.

저장 요청이 끝나면 에이전트 이름을 확인해 다른 에이전트를 열지 않았는지 살펴봅니다. 수정 화면을 다시 열어 변경한 문장이 유지되는지도 확인하세요. 변경이 남지 않거나 오류가 반복되면 바꾼 항목, 저장 시 표시된 안내, 발생 시간을 담당자에게 전달합니다.

답변이 지침과 다릅니다​

먼저 현재 에이전트의 지침에 원하는 기준이 있는지 확인합니다. 마지막 수정이 저장됐는지, 대화에서 별도로 준 조건이 지침과 충돌하지 않는지도 읽어 보세요. 답변이 표시됐다면 생성이나 로그인 문제와 구별해 답변 내용 자체를 검토합니다.

짧은 입력으로 다시 시험하고, 어떤 사실이 추가되거나 누락됐는지 표시합니다. 같은 문제가 반복되면 지침을 한 항목씩 바꾸어 결과를 비교하세요. 한 번의 답변이 맞았다는 이유로 모든 질문에서 같은 응답이 나온다고 가정하지 않습니다.

실행 중 오류가 표시됩니다​

대화 맥락이 모델의 처리 한도를 넘으면 실행이 중단될 수 있습니다. 이 경우 새 대화를 시작하거나 이전 맥락을 요약한 뒤 다시 실행합니다. 같은 스레드에서 요청을 반복해도 이미 커진 맥락이 줄어들지는 않습니다.

오류 안내가 보이지 않거나 실행이 계속 실패하면 마지막으로 보낸 요청, 오류가 표시된 시각, 사용한 스레드를 기록합니다. 오류 안내가 없는 상태에서 실행이 끝났다면 화면을 새로고침하기 전에 대화의 마지막 상태를 확인합니다.

목록이나 복제 결과가 기대와 다릅니다​

목록이 비었다는 이유만으로 새 에이전트를 다시 만들지 마세요. 현재 계정과 작업 공간, 목록의 로딩 상태, 오류 표시를 차례로 확인합니다.

복제한 뒤에는 새 에이전트의 수정 화면과 이름을 확인해 원본과 구별합니다. 복제 요청이 실패했다면 원본이 바뀌었다고 단정하지 말고 원본과 새 에이전트의 상태를 각각 확인하세요.

문제가 계속되면 작업 공간, 에이전트 이름, 수행한 작업, 실제 오류 문구를 담당자에게 전달합니다. 연결 키나 비밀번호는 제외합니다. 해결 후에는 해당 에이전트의 수정 화면과 짧은 대화까지 확인한 뒤 업무를 재개합니다. 기본 절차는 시작하기에 있습니다.
