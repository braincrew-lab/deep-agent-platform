평가 실행

평가 실행은 데이터셋의 문항을 에이전트에게 하나씩 보내 답변을 받고, 고른 평가기와 채점 모델로 채점하는 한 번의 작업입니다. 이 페이지는 이메일 초안 도우미를 "이메일 초안 기본 10문항"과 완전성 (Completeness) 평가기로 실행하고, 진행 상황을 지켜보고, 필요하면 멈추는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 평가 실행 탭에서 평가할 에이전트를 고릅니다.
  • 평가 시작으로 "평가 실행 생성" 창을 열고 데이터셋, 평가기, 채점 모델을 골라 실행 시작을 누릅니다.
  • 실행이 대기 중에서 완료로 바뀌는 동안 결과가 채워지는 모습을 봅니다.
  • 잘못 시작한 실행을 실행 취소로 멈춥니다.

에이전트 고르기​

평가 화면의 평가 실행 탭을 엽니다. 오른쪽 위 에이전트 선택 상자에서 평가할 에이전트를 고르기 전에는 평가 시작이 흐리게 보이고, 가운데에 "에이전트를 선택하면 대시보드가 표시됩니다"가 나옵니다. 에이전트를 고르면 왼쪽에 그 에이전트의 평가 실행 목록, 오른쪽에 실행 상세 자리가 생깁니다. 목록 제목 옆 데이터 새로고침(둥근 화살표)은 목록을 다시 불러옵니다.

평가 실행 탭

번호메뉴기능이런 때 사용하세요
1에이전트평가할 에이전트를 고릅니다. 누르면 "에이전트 이름으로 찾기" 검색란과 내 에이전트 목록이 펼쳐집니다.이메일 초안 도우미를 고를 때
2평가 시작"평가 실행 생성" 창을 엽니다. 에이전트를 고르기 전에는 누를 수 없고, 마우스를 올리면 "에이전트를 먼저 선택해 주세요."가 보입니다.고른 에이전트로 새 평가를 시작할 때
3빈 실행 목록 안내고른 에이전트의 실행이 최신순으로 나오는 평가 실행 목록 자리입니다. 실행이 없으면 "아직 평가 실행이 없습니다."와 "‘평가 시작’을 눌러 첫 평가를 실행해 주세요."가 보입니다.처음 평가하는 에이전트인지 확인할 때
4실행 상세 안내목록에서 실행을 고르면 이 자리에 결과가 열립니다. 고르기 전에는 "실행을 선택하여 상세 내용을 확인하세요."가 보입니다.실행 하나의 결과를 볼 때

실행이 하나라도 있으면 탭을 열 때 가장 최근 실행이 자동으로 골라집니다.

평가 실행 생성 창​

평가 시작을 누르면 "평가 실행 생성" 창이 열립니다. 창 설명은 "데이터셋과 평가기를 고른 뒤 평가를 시작합니다."입니다. 칸이 많아 같은 창을 두 장으로 나눠 보여 줍니다.

평가 실행 생성 창: 데이터셋, 평가기, 모델

번호메뉴기능이런 때 사용하세요
1데이터셋실행할 데이터셋을 고릅니다. 위쪽 검색란으로 이름을 찾을 수 있습니다. 이름 옆에 문항 수가 괄호로 나옵니다. 문항이 없는 데이터셋은 "(케이스 없음)"이 붙고 고를 수 없습니다. 데이터셋이 하나도 없으면 "선택할 수 있는 데이터셋이 없습니다. 데이터셋 탭에서 먼저 만들어 주세요."가 나옵니다."이메일 초안 기본 10문항"을 고를 때
2평가기채점에 쓸 평가기를 고릅니다. 기본 평가기에는 "(기본)", 사용자 평가기에는 "(워크스페이스)"가 붙어 함께 나옵니다.요청 내용이 빠짐없이 들어갔는지 볼 때 **완전성 (Completeness)**을 고릅니다
3모델 (선택 사항)채점 모델을 고릅니다. 비워 두면 사용자 기본값 사용으로 내 기본 모델이 채점합니다. 목록의 모델 이름 앞 점은 API 키가 등록되어 쓸 수 있는지(사용 가능)를 보여 주고, 키가 없는 모델은 "API 키가 등록되지 않았습니다"와 함께 흐리게 보여 고를 수 없습니다.평소와 다른 모델로 채점해 보고 싶을 때
4실행 시작평가를 시작합니다. 데이터셋과 평가기를 고르기 전에는 누를 수 없습니다. 왼쪽 취소는 실행하지 않고 창을 닫습니다.설정을 확인한 뒤 실행할 때

평가 실행 생성 창: 실행 방식

번호메뉴기능이런 때 사용하세요
1근거 추출 실행채점하지 않고, 질문별 근거 문서에서 원문 문장을 찾아 데이터셋에 저장하는 실행으로 바꿉니다. 근거 문서나 근거 설명이 적힌 문항이 하나도 없으면 실행되지 않습니다.지식을 찾아 답하는 에이전트의 데이터셋에 근거 문장을 채울 때(이메일 초안 점검에서는 끕니다)
2반복 횟수같은 설정으로 입력한 횟수만큼 연속 실행합니다. 1~10회이고 기본값은 1입니다. 5회 이상이면 반복별 정답률을 함께 보여 줍니다.같은 질문에도 답이 흔들리는지 보려고 여러 번 돌릴 때
3실행 전 도구 점검 결과에이전트에 연결된 지식의 문서 도구를 미리 시험 호출한 결과입니다. 지식 도구가 없는 에이전트는 "에이전트에 지식 도구가 없어 점검하지 않았습니다."라고만 나옵니다. 오른쪽 다시 점검으로 다시 시험합니다.지식을 찾아 답하는 에이전트를 실행하기 전에 문서 도구가 응답하는지 볼 때

**모델 (선택 사항)**을 비워 두었는데 기본 모델이 정해져 있지 않으면 "기본 채점 모델이 설정되지 않았습니다. 평가를 실행할 모델을 선택하세요."가 나옵니다. 이때는 목록에서 사용 가능인 모델을 고릅니다. 기본 모델을 정하는 방법은 모델 구성, API 키를 등록하는 방법은 시크릿과 권한에 있습니다.

지식이 연결된 에이전트에서 실행 전 도구 점검이 실패하면 "문서 도구가 환경 문제로 실패합니다. 이대로 실행하면 결과가 무효가 됩니다. 원인을 고친 뒤 다시 점검해 주세요."가 나오고 실행 시작이 막힙니다. 잠시 뒤 다시 점검을 누르거나, 점검 대상이 아닌 다른 문제를 보려고 일부러 돌릴 때만 점검 없이 시작을 누릅니다.

실행이 시작되지 않을 때​

실행 시작을 눌렀는데 창 안에 빨간 안내가 뜨면 아래를 확인합니다.

안내원인과 할 일
"동시에 실행할 수 있는 평가 실행 수를 넘었습니다. 진행 중인 실행이 끝난 뒤 다시 시도해 주세요."한 사용자가 동시에 돌릴 수 있는 평가 실행 수를 넘었습니다. 기본 설정에서는 2개입니다. 진행 중인 실행이 끝나거나 취소된 뒤 다시 누릅니다.
"데이터셋에 케이스가 없습니다. 케이스를 추가한 뒤 실행하세요."문항이 없는 데이터셋을 골랐습니다. 평가 문항 설계대로 문항을 넣은 뒤 실행합니다.
"채점 모델의 API 키가 등록되지 않았습니다. 키를 등록한 뒤 다시 시도하세요."고른 채점 모델에 필요한 키가 없습니다. 키를 등록하거나 사용 가능인 다른 모델을 고릅니다.
"평가기 정의가 올바르지 않습니다. 평가기를 수정한 뒤 다시 시도하세요."사용자 평가기의 프롬프트나 점수 범위가 규칙에 맞지 않습니다. 평가기 구성대로 고칩니다.
"이 모델 또는 리소스를 사용할 권한이 없습니다."고른 모델이나 에이전트의 자원을 쓸 권한이 없습니다. 관리자에게 권한을 요청합니다.

따라 해 보기​

김그루 사원이 이메일 초안 도우미를 처음 평가합니다.

  1. 평가 화면에서 평가 실행 탭을 엽니다.
  2. 에이전트를 누르고 검색란에 "이메일"을 입력해 "이메일 초안 도우미"를 고릅니다.
  3. 평가 시작을 누릅니다.
  4. 데이터셋에서 "이메일 초안 기본 10문항", 평가기에서 **완전성 (Completeness)**를 고릅니다.
  5. **모델 (선택 사항)**은 사용자 기본값 사용 그대로, 근거 추출 실행은 끈 채로, 반복 횟수는 1로 둡니다.
  6. 실행 시작을 누릅니다. "평가를 시작했습니다." 안내가 뜨고 창이 닫히면서 방금 만든 실행이 목록 맨 위에 골라집니다.

실행 진행 보기​

실행을 만든 직후에는 목록의 상태가 대기 중이고, 문항 처리가 시작되면 실행 중으로 바뀝니다. 실행 상세 아래쪽 결과 옆에 처리한 문항 수가 "(6 / 10)"처럼 나오고, 실행이 끝나기 전에는 Excel 내보내기가 나오지 않습니다. 결과 표에는 아직 채점되지 않은 문항도 질문과 참조 답변이 먼저 보이고, 채점이 끝나는 대로 에이전트 답변과 결과가 채워집니다. 화면은 저절로 다시 불러오므로 다른 화면에 다녀와도 실행은 계속됩니다. 그림은 지침을 고친 뒤 다시 돌린 세 번째 실행이 진행 중인 모습입니다.

실행 중인 평가

번호메뉴기능이런 때 사용하세요
1실행 목록의 실행"#3 · 이메일 초안 도우미"와 상태 실행 중이 보입니다. 아래 줄에 시작 시각, 데이터셋 이름, 지금까지 채점된 문항의 정답률이 나옵니다.여러 실행 가운데 지금 돌고 있는 것을 찾을 때
2실행 취소진행 중인 실행을 멈추는 확인 창을 엽니다. 실행을 시작한 사람에게만 보입니다.잘못된 데이터셋이나 평가기로 시작한 것을 알았을 때
3전체 정답률 (진행 중)지금까지 채점된 문항만으로 계산한 정답률입니다. 그림에서는 6문항을 채점해 "(6/6)"입니다. 실행이 끝나면 전체 문항 기준으로 바뀝니다.끝나기 전에 흐름을 미리 볼 때(최종 판단은 끝난 뒤에 합니다)

실행 상태는 다음 중 하나입니다.

상태뜻
대기 중실행이 만들어졌고 문항 처리를 기다리고 있습니다.
실행 중문항을 에이전트에 보내고 채점하고 있습니다.
완료모든 문항 처리가 끝났습니다.
오류실행이 오류로 중단되었습니다. 실행 상세 위쪽에 "평가 실행이 오류로 중단되었습니다." 같은 안내와 원본 오류 보기가 나옵니다.
취소됨실행 취소로 멈췄습니다. 그때까지 채점된 결과는 남습니다.
시간 초과정해진 시간 안에 끝나지 않아 중단되었습니다.

실행 취소​

실행 상세의 실행 취소를 누르면 평가 실행 취소 확인 창이 열리고 "진행 중인 평가를 중단합니다. 지금까지 채점된 결과는 남고 나머지 문항은 실행되지 않습니다."라는 설명이 나옵니다. 계속 진행을 누르면 창이 닫히고 실행이 그대로 이어집니다. 창 안의 실행 취소를 누르면 실행이 멈추고 "평가 실행을 취소했습니다." 안내와 함께 상태가 취소됨으로 바뀝니다. 실행 취소 버튼은 실행을 시작한 사람에게만 보입니다.

평가 실행 취소 확인 창

번호메뉴기능이런 때 사용하세요
1평가 실행 취소창 제목입니다. 아래에 "진행 중인 평가를 중단합니다. 지금까지 채점된 결과는 남고 나머지 문항은 실행되지 않습니다."라는 설명이 있습니다.취소하면 무엇이 남는지 확인할 때
2계속 진행창을 닫고 실행을 그대로 이어 갑니다.남은 문항이 몇 개 안 되어 끝까지 보기로 했을 때
3실행 취소실행을 멈춥니다. "평가 실행을 취소했습니다." 안내가 뜨고 상태가 취소됨으로 바뀝니다.잘못된 평가기로 시작했을 때

취소된 실행이나 일부 문항만 처리된 실행의 점수로 에이전트 전체 품질을 판단하지 않습니다. 같은 설정으로 다시 실행해 끝까지 처리된 결과를 씁니다.

팁: 평가 실행은 사이드바 작업 화면에 나오지 않습니다. 평가 진행 상황은 항상 평가 실행 탭에서 봅니다. 작업 화면과 실행 상태를 함께 보는 방법은 모니터링과 실행 상태 확인에 있습니다.
