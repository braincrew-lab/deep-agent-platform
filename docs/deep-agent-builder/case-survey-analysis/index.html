사례: 설문 결과 분석

이 페이지는 브레인크루 AI혁신팀 김그루 사원이 "설문 결과 분석가"에게 사내교육 만족도 설문 CSV를 맡겨 과정별 평균, NPS, 부서별 차이, 자유의견 주제 분류, 차트, 개선안을 차례로 받는 과정을 보여 줍니다. 에이전트가 코드를 실행해 계산하므로, 답변의 숫자를 아래 기준값과 대조해 검증하는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 설문 결과 분석가를 만들고 CSV 파일을 첨부해 질문합니다.
  • 과정별 4개 문항 평균과 추천의향 기반 NPS를 받습니다.
  • 부서별 차이를 보고, 표본이 작은 집단을 해석할 때 주의할 점을 확인합니다.
  • 자유의견을 주제별로 분류하고 차트와 개선안을 받습니다.
  • 결과 표를 Excel이나 CSV로 내보냅니다.

목표​

  • 교육과정 3개의 문항별 평균 표와 NPS 표
  • 부서 6곳의 평균과 NPS 비교 표
  • 자유의견 7가지 문장을 5개 주제로 묶은 건수 표와 과정별 분포(무응답 포함)
  • 과정별 NPS 막대 차트 1개
  • 다음 회차를 위한 과정별 개선안

준비물​

항목내용
예시 파일브레인크루_사내교육_만족도설문.csv (가상 자료. 응답 120명, 열 10개: 응답번호, 부서, 직급, 교육과정, 전반만족도(1-5), 내용유익성(1-5), 강사만족도(1-5), 업무적용도(1-5), 추천의향(0-10), 자유의견)
표 데이터로 첨부할 수 있는 파일.xlsx, .xls, .xlsb, .xlsm, .csv (파일 1개당 최대 50MB)
그 밖에 대화에 첨부할 수 있는 파일.pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm (한 번에 최대 10개. 파일 1개당 .md, .markdown, .txt, .html, .htm은 10MB, .pdf, 이미지, .docx, .hwp, .hwpx는 20MB, .pptx, .ppt는 50MB까지)
에이전트 모드일반 에이전트 (첨부한 표 데이터를 코드로 분석합니다)
권한새 에이전트를 만들 수 있는 권한

설문 파일에 이름, 이메일, 연락처처럼 응답자를 알아볼 수 있는 열이 있으면 지운 뒤 올립니다. 예시 파일에는 이런 열이 없습니다.

에이전트 만들기​

사이드바의 새 에이전트를 눌러 대화로 에이전트를 만드는 첫 화면을 열고, 입력란에 설문 결과 분석가가 할 일을 적어 보냅니다.

설문 결과 분석가 만들기 요청

번호메뉴기능이런 때 사용하세요
1새 에이전트대화로 에이전트를 만드는 첫 화면을 엽니다.새 에이전트를 만들 때
2입력란만들 에이전트가 할 일을 적습니다.아래 요청 문장을 붙여 넣을 때
3전송요청을 보내 만들기 대화를 시작합니다.요청 문장을 다 적었을 때

따라 해 보기​

  1. 사이드바의 새 에이전트를 누르고 아래 요청을 보냅니다.

    프롬프트: 설문 결과 분석가를 만들어 주세요. 설문 결과 CSV나 엑셀 파일을 첨부하면 코드를 실행해 집단별 평균, NPS(추천의향 910점은 추천, 78점은 중립, 0~6점은 비추천, NPS는 추천 비율에서 비추천 비율을 뺀 값), 집단 간 차이를 계산하고, 자유의견을 주제별로 분류해 표와 차트로 보여 주는 에이전트입니다. 모든 표에 응답 수(n)를 함께 적고, 응답이 30명 미만인 집단은 해석에 주의하라고 알려 주세요. 원인은 단정하지 말고 가설로 적어 주세요.

  2. 만들기 대화가 범위, 주의할 조건, 결과 형태를 묻는 선택지 카드 세 개를 보여 줍니다. 각 카드에서 선택지(예: "CSV와 엑셀 파일로 받은 설문 결과만 분석", "응답 수 30명 미만 집단은 해석에 주의 알림 포함", "표와 차트로 시각화된 결과")를 고르고 제출을 누른 뒤 전체 제출을 누릅니다. 원인 표현 방식처럼 추가 질문이 오면 "원인은 단정하지 않고 가설로만 작성"을 고릅니다.

  3. 도구, 동작 방식, 스킬, 도우미 에이전트 추천 단계마다 승인을 누릅니다. "🎉 에이전트가 완성됐어요!"가 보이면 바로 이용하기를 누릅니다.

팁: 만들기 대화가 "도구 재시도" 미들웨어나 이미 있는 다른 에이전트를 도우미(서브에이전트)로 추천할 수 있습니다. 필요 없으면 완성 뒤 에이전트 설정에서 서브에이전트 관리를 열어 삭제로 빼고, 지침에 남은 서브에이전트 위임 문장도 지운 뒤 저장합니다. 이 사례에서는 도우미 에이전트를 빼고 썼습니다.

단계별 실행​

1단계: 파일 첨부와 과정별 평균​

설문 CSV를 첨부하고 파일 구조와 교육과정별 문항 평균을 먼저 받습니다.

과정별 평균의 코드 실행 기록

번호메뉴기능이런 때 사용하세요
1데이터 분석에이전트가 계산 코드를 실행한 기록입니다. 오른쪽에 걸린 시간이 보이고, 누르면 코드가 펼쳐집니다.평균을 어떻게 냈는지 확인할 때
2데이터 표코드 실행 결과로 나온 표입니다. 답변 본문 표와 같은 숫자인지 대조합니다.계산 결과를 그대로 확인할 때
3내려받기데이터 표 오른쪽 위 첫 번째 버튼으로 표를 내려받습니다.표를 따로 저장할 때
4크게 보기데이터 표 오른쪽 위 두 번째 버튼으로 표를 크게 엽니다.표를 넓게 볼 때

기록 아래로 답변 본문이 이어집니다.

과정별 평균 답변과 아티팩트 버튼

번호메뉴기능이런 때 사용하세요
1데이터 구조답변 첫 부분의 행 수, 열 목록, 결측값 요약입니다.파일이 제대로 읽혔는지 볼 때
2아티팩트이 대화에서 만든 데이터 표를 모아 보는 창을 엽니다. 버튼 위 숫자는 모인 표 개수입니다.결과 표를 내보낼 때

따라 해 보기

  1. 사이드바에서 설문 결과 분석가를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 입력란 아래 오른쪽의 파일 업로드로 브레인크루_사내교육_만족도설문.csv를 첨부합니다.

  3. 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 설문 파일의 구조(행 수, 열, 결측값)를 먼저 알려 주고, 교육과정별 응답 수와 전반만족도, 내용유익성, 강사만족도, 업무적용도, 추천의향 평균을 소수 둘째 자리까지 표로 보여 주세요. 4개 문항의 평균도 한 열로 붙여 주세요.

  4. 답변 위 데이터 표의 숫자와 답변 표가 같은지 봅니다. 이 사례에서는 구조(120행, 결측값은 자유의견 25건)와 과정별 평균이 기준값과 같았고, 생성형 AI 기초의 4개 문항 평균만 4.18로 나왔습니다(기준값 4.19, 아래 "결과를 이렇게 확인하세요" 참고).

2단계: NPS​

같은 대화에서 추천의향 점수로 과정별 NPS를 계산합니다.

과정별 NPS

번호영역기능이런 때 사용하세요
1계산 방법NPS를 어떤 순서로 계산하고 반올림했는지 적은 문장입니다.반올림 방식이 기준과 같은지 확인할 때
2NPS 표 열 이름표의 열 순서입니다. 과정별 응답 수(n), 추천·중립·비추천 인원과 비율, NPS가 차례로 나옵니다.과정 간 추천 의향을 비교할 때
3전체 행120명 전체의 NPS입니다.보고서 첫 줄에 쓸 대표 숫자를 고를 때
4산식NPS를 추천 비율에서 비추천 비율을 빼서 냈다는 설명입니다.회사 정의와 같은지 확인할 때

따라 해 보기

  1. 같은 대화에서 아래 프롬프트를 보냅니다.

    프롬프트: 추천의향(0-10)으로 과정별 NPS를 계산해 주세요. 910점은 추천, 78점은 중립, 0~6점은 비추천입니다. 과정별 추천·중립·비추천 인원, 비율, NPS를 표로 만들고 전체 행도 넣어 주세요.

  2. 과정별 인원을 더하면 응답 수와 같은지 확인합니다. 이 사례의 첫 답변은 비율을 먼저 소수 첫째 자리로 반올림한 뒤 빼서 에이전트 만들기 실습 53.2, 전체 20.9로 나왔습니다. "NPS는 반올림하기 전의 추천 비율과 비추천 비율로 계산한 뒤 마지막에 소수 첫째 자리까지 반올림해 주세요."라고 다시 요청하자 53.1, 20.8로 기준값과 같아졌습니다(위 그림은 다시 요청한 답변).

3단계: 부서별 차이​

부서별로 평균과 NPS를 비교하고, 부서 차이가 수강 과정 구성 때문인지 함께 봅니다.

부서별 차이

번호영역기능이런 때 사용하세요
1부서 열부서별 표의 한 행이 한 부서입니다. 행마다 응답 수(n), 4개 문항 평균, 전반만족도 평균, NPS가 이어집니다.부서 간 차이를 볼 때
2부서 내 과정별 인원부서마다 어느 과정을 몇 명이 들었는지입니다.부서 차이가 과정 차이 때문인지 볼 때
3주의 문구모든 부서의 응답 수가 30명 미만이라 해석에 주의하라는 안내입니다.부서 평가에 숫자를 쓰기 전에
4해석(가설)부서 차이가 수강 과정 구성 때문일 수 있다는 가설입니다.원인을 단정하지 않고 보고할 때

따라 해 보기

  1. 아래 프롬프트를 보냅니다.

    프롬프트: 부서별 응답 수, 4개 문항 평균, 전반만족도 평균, NPS를 표로 비교해 주세요. 부서마다 어느 과정을 몇 명이 들었는지도 함께 보여 주고, 부서 차이가 수강 과정 구성 때문일 수 있는지 설명해 주세요.

  2. 부서별 응답 수가 모두 30명 미만이라는 주의 문구가 있는지 확인합니다.

4단계: 자유의견 주제 분류​

자유의견을 주제별로 묶어 건수와 과정별 분포를 받습니다.

자유의견 주제 분류

번호영역기능이런 때 사용하세요
1데이터 분석의견을 세고 묶은 코드 실행 기록입니다.어떻게 분류했는지 확인할 때
2데이터 표코드가 낸 과정별 주제 건수입니다.답변 표와 숫자를 대조할 때
3무응답과정마다 의견을 적지 않은 응답 수입니다. 합하면 25건입니다.의견 비율의 분모를 확인할 때
4응답수와일치바로 왼쪽 총합 열(한 행의 합)이 그 과정의 응답 수와 같은지 검증한 열입니다.빠진 응답이 없는지 확인할 때

표의 한 행은 한 과정이고, 주제 열마다 그 과정에서 나온 의견 건수가 들어 있습니다. 과정별 개선 과제를 정할 때 이 분포를 봅니다.

따라 해 보기

  1. 아래 프롬프트를 보냅니다.

    프롬프트: 자유의견을 주제별로 분류해 주세요. 주제마다 건수와 대표 의견을 적고, 과정별로 어떤 주제가 많은지 표로 보여 주세요. 빈 의견은 무응답으로 따로 세어 주세요.

  2. 첫 분류가 어색하면 다시 요청합니다. 이 사례의 첫 답변은 "자료를 미리 받고 싶습니다"와 "후속 심화 과정"을 한 주제(37건)로 묶고 온라인 수강 요청을 칭찬으로 분류했으며, 과정별 무응답을 모두 0으로 적었습니다. 아래 순서로 다시 요청해 위 그림의 표를 받았습니다.

    프롬프트: 분류를 다시 해 주세요. 먼저 서로 다른 의견 문장과 건수를 모두 나열하고, 뜻이 같은 문장끼리 주제로 묶어 주세요. 온라인 수강 요청은 칭찬이 아니라 수강 방식 요청입니다. 과정별 표에는 무응답도 과정마다 세어 넣어 주세요.

    프롬프트: 네, 과정별 응답 수에서 그 과정의 의견 건수 합을 빼서 무응답 수를 계산해 넣어 주세요. 각 행의 합이 과정 응답 수와 같은지도 열로 보여 주세요.

  3. 다시 받은 분류는 실습/적용 32건(예제가 좋았음 18, 실습 시간 연장 14), 난이도/심화 28건(난이도 15, 후속 심화 13), 강사/설명 13건, 수강 방식 요청 12건, 자료/사전 안내 10건이고, 과정별 무응답은 데이터 분석 실무 7, 생성형 AI 기초 13, 에이전트 만들기 실습 5건이었습니다.

5단계: 차트​

과정별 NPS 차트

번호메뉴기능이런 때 사용하세요
1데이터 시각화차트를 그린 코드 실행 기록입니다. 바로 아래 **출력 (데이터 시각화) (1 figure)**에 그림 한 개가 나왔다는 표시가 붙습니다.차트에 쓴 값을 확인할 때
2차트과정별 NPS 막대 차트입니다. 막대 위에 값, 0 위치에 점선 기준선이 보입니다.보고서에 붙일 그림이 필요할 때

차트를 이미지 파일로 저장해 달라고 요청하면 답변 끝에 다운로드 링크가 붙습니다.

번호메뉴기능이런 때 사용하세요
1다운로드 링크차트를 이미지 파일(.png)로 저장해 달라고 요청하면 답변에 "nps_bar.png 다운로드" 같은 링크가 붙습니다. 누르면 내 PC에 저장됩니다.발표 자료에 차트를 넣을 때

이 사례에서는 첫 실행이 코드 오류로 멈추자 에이전트가 스스로 코드를 고쳐 데이터 시각화를 한 번 더 실행했습니다. 기록이 두 줄이면 마지막 줄이 차트를 만든 실행입니다.

따라 해 보기

  1. 아래 프롬프트를 보냅니다.

  2. 차트의 막대 값이 2단계 NPS 표와 같은지 확인합니다.

  3. 답변의 다운로드 링크를 눌러 저장합니다.

6단계: 개선안과 결과 내보내기​

지금까지의 숫자를 근거로 과정별 개선안을 받고, 결과 표를 Excel 파일과 CSV 파일로 내보냅니다.

아티팩트 창과 내보내기

번호메뉴기능이런 때 사용하세요
1데이터 표 목록이 대화에서 만든 데이터 표입니다. 표마다 행과 열 수가 보이고, 고르면 오른쪽에 미리보기가 열립니다.내보낼 표를 고를 때
2내보내기고른 표를 저장할 형식을 고르는 메뉴를 엽니다. 메뉴에는 Word로 내보내기, PPTX로 내보내기, HTML 다운로드, Excel로 내보내기, CSV로 내보내기가 있습니다.결과 표를 엑셀이나 다른 프로그램에서 다시 쓸 때
3Excel로 내보내기고른 표를 Excel 파일로 저장합니다.엑셀에서 표를 다시 다듬을 때
4CSV로 내보내기고른 표를 CSV 파일로 저장합니다.다른 프로그램에 바로 불러올 때

개선안 답변은 과정마다 근거 숫자와 가설을 함께 적었습니다. 예를 들어 데이터 분석 실무에는 "난이도 조정 및 후속 심화 프로그램 마련(근거: 난이도/심화 의견 11건, 4개 문항 평균 3.69, NPS -18.4)", "자료 및 사전 안내 강화(근거: 자료/사전 안내 요청 7건)"가 들어갔습니다.

따라 해 보기

  1. 아래 프롬프트를 보냅니다.

    프롬프트: 지금까지 결과를 근거로 과정별 개선안을 3개씩 제안해 주세요. 각 개선안에는 근거가 된 숫자(평균, NPS, 의견 건수)를 함께 적어 주세요.

  2. 입력란 아래 오른쪽의 아티팩트를 눌러 왼쪽 목록에서 과정별 평균 표(3행 × 8열)를 고르고 내보내기에서 Excel로 내보내기를 누릅니다.

  3. 다른 프로그램에 바로 불러올 파일이 필요하면 같은 표에서 내보내기를 다시 눌러 CSV로 내보내기를 누릅니다.

결과를 이렇게 확인하세요​

  • 데이터 분석 실무만 NPS가 음수(-18.4)이고 비추천이 17명으로 추천(10명)보다 많습니다. 이 과정에서 "자료를 미리 받고 싶습니다"가 7건으로 가장 많은 의견입니다. 개선안에 사전 자료 배포가 들어갔는지 봅니다.

  • 답변의 평균이 기준값과 0.01만 다르면 반올림 방식 차이일 수 있습니다. 예를 들어 생성형 AI 기초의 4개 문항 평균이 4.18, 전체 추천의향 평균이 7.92로 나오면 끝자리 5를 버린 결과입니다. "소수 셋째 자리에서 반올림해 5 이상은 올려 주세요"라고 다시 요청합니다.
