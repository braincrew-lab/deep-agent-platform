에이전트 가져오기와 내보내기

잘 만든 에이전트를 동료에게 넘기거나 같은 구성을 하나 더 두고 싶을 때는 에이전트를 ZIP 파일로 내보내고, 받은 쪽에서 그 파일을 가져옵니다. 이 페이지는 김그루 사원이 회의록 요약 도우미를 내보내 영업1팀 최하늘 책임에게 전달하고, 받은 파일을 가져와 이름을 바꿔 쓰는 흐름을 따라갑니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면의 저장 옵션 메뉴에서 에이전트 내보내기로 에이전트를 ZIP 파일 하나로 내려받습니다.
  • 새 에이전트 화면의 에이전트 가져오기로 ZIP 파일을 올려 같은 구성의 새 에이전트를 만듭니다.
  • 가져오기 요약의 각 줄이 무엇을 뜻하는지 읽고, 빠진 항목이 있으면 채웁니다.
  • 가져온 에이전트의 이름을 바꾸고 지침, 모델, 연결 항목을 원본과 비교합니다.

내보내기에 들어가는 것과 빠지는 것​

구분내용
들어가는 것에이전트 이름, 설명, 지침, 모델 설정, 오프너(예시 질문), 연결된 도구·미들웨어·모델·스킬 정보, 서브에이전트 구성
빠지는 것에이전트 편집 화면 파일 탭에 올린 파일(원본 첨부 파일), 대화 기록, 시크릿 값

ZIP 파일에는 현재 버전에 마지막으로 저장된 내용이 들어갑니다. 지침을 고쳤거나, 도구나 모델처럼 바로 반영되는 항목을 바꿔 헤더에 "저장되지 않은 변경이 있습니다"가 보이면 먼저 헤더의 저장을 누르고 내보냅니다. 도구가 시크릿을 쓰는 경우 시크릿 값은 들어가지 않으므로, 가져온 쪽에서 같은 이름의 시크릿을 따로 등록해야 합니다. 시크릿 등록은 시크릿과 권한을 참고하세요.

에이전트 내보내기​

내보내기는 에이전트 편집 화면의 헤더에서 시작합니다. 대화 화면 왼쪽 사이드바의 에이전트 설정을 누르면 이 화면이 열립니다. 헤더의 저장 오른쪽 화살표인 저장 옵션 더 보기를 누르면 새 버전으로 저장과 에이전트 내보내기가 보입니다. 에이전트 내보내기를 누르면 에이전트 이름을 딴 ZIP 파일(예: 회의록 요약 도우미.zip)이 내려받아지고 "에이전트가 성공적으로 내보내졌습니다"가 나옵니다. 넘기기 전 상태를 따로 남기고 싶으면 먼저 새 버전으로 저장을 해 둡니다. 헤더 버튼 각각의 설명은 에이전트 수정에 있습니다.

저장 옵션 메뉴의 에이전트 내보내기

번호메뉴기능이런 때 사용하세요
1저장이름, 설명, 지침의 변경을 현재 버전에 저장합니다. 바꾼 내용이 없으면 흐리게 보입니다.지침을 고친 뒤 내보내기 전에 저장할 때
2저장 옵션 더 보기저장 오른쪽 화살표입니다. 메뉴를 엽니다.내보내기 메뉴를 찾을 때
3새 버전으로 저장현재 설정을 복사해 새 버전을 만듭니다.넘기기 전에 지금 상태를 별도 버전으로 남길 때
4에이전트 내보내기에이전트를 ZIP 파일로 내려받습니다. 파일 이름은 에이전트 이름을 따릅니다(예: 회의록 요약 도우미.zip). 완료되면 "에이전트가 성공적으로 내보내졌습니다"가 나옵니다.동료에게 에이전트 구성을 넘길 때

내보내기 권한이 없으면 메뉴 옆에 "내보내기 권한이 없습니다. 관리자에게 문의하세요."가 보이고 누를 수 없습니다. 내보내기에 실패하면 "에이전트 내보내기에 실패했습니다"가 나옵니다.

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 누르고, 사이드바의 에이전트 설정을 누릅니다.
  2. 헤더의 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이는지 확인합니다. 보이면 아직 현재 버전에 기록되지 않은 변경이 있으니 먼저 저장을 누릅니다.
  3. 저장 오른쪽의 저장 옵션 더 보기를 누르고 에이전트 내보내기를 누릅니다.
  4. 내려받은 회의록 요약 도우미.zip을 사내 메일이나 공유 폴더로 최하늘 책임에게 전달합니다.

팁: 내보낸 ZIP 파일 안의 내용은 직접 고치지 마세요. 이름이나 지침을 바꾸고 싶다면 가져온 뒤 에이전트 편집 화면에서 바꿉니다.

에이전트 가져오기​

받은 ZIP 파일은 새 에이전트 화면에서 가져옵니다. 사이드바의 새 에이전트를 누르면 이 화면이 열립니다. 입력란 아래의 에이전트 가져오기를 누르면 ZIP 파일을 올리는 에이전트 가져오기 창이 열립니다. 바로 옆의 에이전트 직접 만들기는 파일 없이 빈 에이전트를 만드는 창이므로 헷갈리지 않게 합니다.

새 에이전트 화면의 에이전트 가져오기

번호메뉴기능이런 때 사용하세요
1새 에이전트에이전트를 새로 만들거나 가져오는 화면을 엽니다.받은 에이전트 파일을 올리러 갈 때
2에이전트 직접 만들기이름과 설명을 넣어 빈 에이전트를 만드는 창을 엽니다.파일 없이 처음부터 만들 때
3에이전트 가져오기ZIP 파일을 올리는 에이전트 가져오기 창을 엽니다.동료에게서 받은 에이전트 파일을 올릴 때

에이전트 가져오기 창​

창에는 "ZIP 파일을 드래그하거나 클릭하세요 (최대 200MB)"라는 안내가 보입니다. ZIP 파일을 창에 끌어다 놓거나 파일 선택을 눌러 고르면 바로 가져오기가 시작되고 "가져오는 중..."이 보입니다.

에이전트 가져오기 창

안내 문구 아래 점선 상자가 파일을 놓는 곳입니다. ZIP 파일을 이곳에 끌어다 놓으면 바로 가져오기가 시작됩니다.

번호메뉴기능이런 때 사용하세요
1안내 문구"ZIP 파일을 드래그하거나 클릭하세요 (최대 200MB)"라고 보입니다.올릴 파일 형식을 확인할 때
2파일 선택파일 선택 창을 열어 ZIP 파일을 고릅니다. 고르면 바로 가져오기가 시작되고 "가져오는 중..."이 보입니다.다운로드 폴더에서 파일을 찾아 올릴 때

가져올 수 있는 파일은 .zip 하나뿐입니다. 다른 형식을 고르면 "Only .zip files are accepted"라는 영문 안내가 나옵니다. 창의 안내 문구에는 최대 200MB라고 적혀 있지만, 실제로 올릴 수 있는 크기는 50MB까지입니다. 50MB를 넘는 ZIP 파일은 가져오기에 실패합니다.

가져오기에 실패하면 "에이전트 가져오기에 실패했습니다"와 사유가 나옵니다. 다시 시도를 눌러 다른 파일을 고를 수 있습니다.

같은 이름의 스킬이 이미 있을 때​

ZIP 파일 안의 스킬과 이름이 같은 스킬을 내가 이미 갖고 있으면, 가져오기 창이 "파일 안의 일부 스킬이 이미 가지고 있는 스킬과 이름이 같습니다. 스킬마다 어떻게 할지 선택해 주세요."로 바뀝니다. 스킬마다 내 스킬 유지 또는 파일의 내용으로 덮어쓰기를 고르거나, 모두 유지, 모두 덮어쓰기로 한 번에 정한 뒤 가져오기 계속을 누릅니다. 덮어쓰면 기존 스킬의 내용이 바뀌며 되돌릴 수 없으므로, 확실하지 않으면 내 스킬 유지를 고릅니다.

가져오기 결과와 요약 읽기​

파일을 올리면 같은 창에 결과와 가져오기 요약이 나타납니다. 맨 위에 "에이전트가 성공적으로 가져와졌습니다"와 새로 만들어진 에이전트 이름(원본과 같은 이름)이 보이고, 그 아래 가져오기 요약에 이번 가져오기로 만들어지거나 연결된 항목 수가 줄마다 나옵니다. 에이전트로 이동을 누르면 창이 닫히고 가져온 에이전트의 에이전트 편집 화면이 열립니다.

가져오기 결과와 요약

번호메뉴기능이런 때 사용하세요
1결과 안내"에이전트가 성공적으로 가져와졌습니다"와 새로 만들어진 에이전트 이름이 보입니다. 이름은 원본과 같습니다.올린 파일이 맞는 에이전트였는지 확인할 때
2가져오기 요약의 줄이번 가져오기로 만들어지거나 연결된 항목 수를 줄마다 보여 줍니다. 아래 표에서 각 줄의 뜻을 설명합니다.빠진 항목이 없는지 확인할 때
3에이전트로 이동창을 닫고 가져온 에이전트의 에이전트 편집 화면을 엽니다.바로 이름을 바꾸고 설정을 확인할 때

가져오기 요약에는 해당하는 줄만 나옵니다. 김그루 사원이 회의록 요약 도우미.zip을 가져왔을 때는 "1개의 에이전트가 생성되었습니다", "1개의 리소스가 기존 항목에 연결되었습니다", "원본 첨부 파일은 제외되었습니다 — 필요 시 다시 업로드하세요" 세 줄이 나왔습니다. 원본은 도구, 지식, 미들웨어 없이 모델(GPT-4.1)만 쓰는 에이전트라 연결된 리소스가 1개이고, 원본의 파일 탭에 회의록 파일을 올려 둔 상태로 내보냈기 때문에 첨부 파일 제외 줄이 함께 나왔습니다.

요약 문구뜻할 일
"1개의 에이전트가 생성되었습니다"새로 만들어진 에이전트 수입니다. 서브에이전트가 있는 에이전트를 가져오면 서브에이전트까지 함께 세어집니다.올린 파일의 에이전트 수와 맞는지 봅니다.
"1개의 리소스가 기존 항목에 연결되었습니다"ZIP에 적힌 도구, 모델, 스킬 가운데 내가 이미 갖고 있던 항목(같은 이름이거나 같은 원본에서 온 항목)에 그대로 연결된 수입니다.따로 할 일은 없습니다.
"1개의 리소스가 새로 생성되었습니다"내 에셋에는 없었지만 내 워크스페이스에 설치된 원본이 있어, 그 원본을 바탕으로 내 에셋에 새로 추가된 수입니다.사이드바의 에셋설정을 눌러 여는 에셋 화면에서 새로 생긴 항목을 확인합니다.
"1개의 리소스가 누락되었습니다 (마스터 매칭 실패)"원본 항목을 찾지 못했거나, 내 워크스페이스에 설치되어 있지 않거나, 내게 그 항목을 추가할 권한이 없어 연결하지 못한 수입니다. 이 항목은 가져온 에이전트에서 빠집니다.유틸리티에서 해당 도구나 모델을 설치한 뒤 에이전트 편집 화면에서 직접 연결하거나, 설치 후 다시 가져옵니다. 설치 권한이 없으면 관리자에게 문의합니다.
"원본 첨부 파일은 제외되었습니다 — 필요 시 다시 업로드하세요"원본 에이전트의 파일 탭에 올라 있던 파일은 ZIP에 들어가지 않았다는 뜻입니다.필요한 파일을 원본 담당자에게 받아 파일 탭에 다시 올립니다.

다른 워크스페이스에서 내보낸 파일이면 "다른 워크스페이스에서 가져온 에이전트입니다."라는 안내가 함께 보입니다. 이때는 모델과 도구가 우리 워크스페이스에서 쓸 수 있는지 특히 꼼꼼히 확인합니다.

가져온 에이전트는 원본과 별개인 새 에이전트입니다. 가져온 쪽에서 지침을 고쳐도 원본에는 영향이 없습니다.

가져온 에이전트 확인하기​

가져온 직후에는 원본과 이름이 같아 목록에서 구분하기 어렵습니다. 에이전트 편집 화면에서 이름부터 바꾸고 헤더의 저장을 누릅니다. 그다음 원본의 지침이 그대로 들어왔는지, 모델 줄의 모델이 원본과 같은지, 도구함, 지식함, 미들웨어에 가져온 연결 항목이 있는지 확인합니다. 가져오기 요약에서 누락된 항목이 있었다면 이 칸에서 직접 채웁니다. 원본의 파일 탭에 있던 파일은 들어오지 않으므로 가져온 에이전트의 파일 탭은 "업로드된 파일이 없습니다"로 비어 있습니다.

사이드바의 뒤로를 눌러 내 에이전트 목록으로 돌아가면 "회의록 요약 도우미"와 "회의록 요약 도우미 (영업1팀용)"이 함께 보여 둘을 구분할 수 있습니다. 에이전트 편집 화면에서는 뒤로를 한 번 누르면 그 에이전트의 대화 화면으로, 한 번 더 누르면 목록으로 돌아갑니다.

받은 파일을 가져와 팀용 사본을 만드는 순서입니다. 이 예시에서는 김그루 사원이 자기 계정에서 직접 가져와 봅니다.

  1. 사이드바의 새 에이전트를 누르고, 입력란 아래의 에이전트 가져오기를 누릅니다.

  2. 파일 선택을 누르고 회의록 요약 도우미.zip을 고릅니다.

  3. 결과 창에 "에이전트가 성공적으로 가져와졌습니다"와 "1개의 에이전트가 생성되었습니다"가 보이는지 확인합니다. 누락이나 첨부 파일 제외 줄이 있으면 위 표의 할 일을 메모합니다. 김그루 사원의 경우 "1개의 리소스가 기존 항목에 연결되었습니다"와 첨부 파일 제외 줄이 함께 나왔습니다.

  4. 에이전트로 이동을 누릅니다.

  5. 에이전트 이름을 "회의록 요약 도우미 (영업1팀용)"으로 바꾸고 헤더의 저장을 누릅니다.

  6. 오른쪽 오프너 탭에서 원본의 예시 질문 네 개가 같은 순서로 들어와 개수 표시가 "4/12"인지 확인합니다.

  7. 오른쪽 테스트 탭에서 브레인크루_AI혁신팀_주간회의록_1110.txt를 첨부하고 아래 프롬프트를 보내, 원본과 같은 형식으로 답하는지 봅니다.

    프롬프트: 첨부한 회의록에서 결정 사항과 담당자, 기한을 표로 정리해 주세요.
