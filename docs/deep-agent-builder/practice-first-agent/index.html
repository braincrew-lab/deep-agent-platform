Deep Agent Builder 실습 1: 대화로 첫 에이전트 만들기

이 실습은 빌더와 대화해 에이전트 하나를 처음부터 끝까지 만들고, 바로 첫 질문을 보내 답을 확인합니다. 예시는 브레인크루 AI혁신팀 김그루 사원이 고객 문의 메일에 답장 초안을 써 주는 고객 문의 답장 도우미를 만드는 과정입니다. 화면 하나하나의 설명은 에이전트 만들기에 있고, 이 페이지는 손을 움직이는 순서에 집중합니다.

이 페이지에서 할 수 있는 일

  • 업무 설명 한 단락과 기준 문서 한 개로 제작 요청을 보냅니다.
  • 빌더의 확인 질문에 보기를 고르거나 직접 입력으로 답합니다.
  • 도구·동작 방식·스킬·도우미 에이전트 추천을 승인하고 완성된 에이전트를 엽니다.
  • 완성된 에이전트에 실제 고객 문의를 보내 기준대로 답하는지 확인합니다.

목표​

항목내용
만들 것고객 문의 답장 도우미(대화로 만든 에이전트)
결과물문의 유형을 분류하고 결론, 근거, 다음 안내 세 단락으로 쓴 답장 초안
걸리는 시간요청 작성 3분, 빌더 대화 5분 안팎, 첫 질문 1분
난이도★☆☆☆☆

준비물​

파일내용형식
브레인크루_고객문의_응대기준.md응대 원칙(결론 → 근거 → 다음 안내, 가격·계약·일정은 [담당자 확인 필요]로 표시), 문의 유형 네 가지와 담당, 마무리 문장(가상 자료)md

같은 내용을 다른 형식으로 만들어도 됩니다. 제작 요청에는 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm 파일을 한 번에 10개까지(합계 50MB 이하) 붙일 수 있습니다. 표 파일(.xlsx, .xls, .xlsb, .xlsm, .csv)은 제작 요청에 붙지 않으니, 에이전트를 만든 뒤 대화 화면이나 편집 화면 파일 탭에 올립니다.

1단계. 제작 요청 보내기​

제작 요청 입력

번호메뉴입력하거나 고를 값
1설명 입력란아래 프롬프트. 5자 이상이어야 보낼 수 있습니다.
2파일 업로드브레인크루_고객문의_응대기준.md를 고릅니다. 붙이면 입력란 위에 파일 이름이 보입니다.
3전송요청을 보내고 제작 대화를 시작합니다.
  1. 사이드바 위쪽 새 에이전트를 누릅니다.
  2. 파일 업로드로 응대 기준 파일을 붙입니다.
  3. 입력란에 다음 요청을 적고 전송을 누릅니다.

프롬프트: 고객 문의 메일이나 메신저 문의를 붙여 넣으면 브레인크루 응대 기준에 맞춰 답장 초안을 써 주는 에이전트를 만들어 주세요. 문의 유형(제품 기능, 계약·견적, 장애·오류, 교육·도입)을 먼저 분류하고, 결론-근거-다음 안내 순서로 세 단락 이내로 답해 주세요. 가격·계약 조건·일정은 확정하지 말고 [담당자 확인 필요]로 표시해 주세요. 첨부한 응대 기준을 꼭 따르게 해 주세요.

요청에는 "누가 무엇을 넣으면 무엇을 받는지"와 "하지 말아야 할 일"을 함께 적습니다. 그래야 빌더가 확인 질문을 덜 하고 지침도 정확해집니다.

2단계. 확인 질문에 답하기​

요청을 보내면 화면에 "1단계: 에이전트 만들기 준비"부터 "9단계: 에이전트 생성 완료"까지의 진행 목록이 생기고, 빌더가 요구사항을 확인하는 질문 묶음을 띄웁니다. 이 실습에서는 "3개의 확인이 필요합니다" 묶음으로 꼭 지킬 규칙, 답장 작성 방식, 받고 싶은 형태를 물었습니다. 질문 내용과 개수는 요청에 따라 매번 다릅니다.

확인 질문에 답하기

번호메뉴입력하거나 고를 값
1보기첫 질문 "응대 기준에서 꼭 지켜야 할 규칙이나 주의사항이 있나요?"에서 "가격·계약 조건·일정은 확정하지 말고 [담당자 확인 필요]로 표시"를 고릅니다.
2제출이 질문의 답을 확정합니다. 확정하면 버튼 자리에 "응답 완료됨"이 보입니다.
3전체 제출괄호 안 숫자가 3/3이 되면 눌러 세 답을 한꺼번에 보냅니다.
  1. 첫 질문의 보기를 고르고 제출을 누릅니다.
  2. 묶음 위쪽 질문 번호 2와 3을 차례로 눌러 같은 방법으로 답합니다. 이 실습에서는 2번에 "문의 유형을 분류하고 결론-근거-다음 안내 순서로 세 단락 이내 작성", 3번에 "결론-근거-다음 안내 순서의 세 단락 이내"를 골랐습니다.
  3. **전체 제출 (3/3)**을 누릅니다.
  4. 이어서 "이 에이전트를 부를 이름을 정해 주세요." 질문이 나오면 직접 입력을 고르고 "고객 문의 답장 도우미"를 적은 뒤 제출을 누릅니다.

보기에 원하는 답이 없을 때는 직접 입력을 고르고 적습니다. 답을 바꾼 뒤 그 질문의 제출을 다시 누르지 않으면 "변경한 항목을 다시 제출해주세요."가 나옵니다.

3단계. 추천을 승인하고 완성하기​

답을 모두 보내면 빌더가 도구 추천, 미들웨어 추천(화면 진행 목록에서는 "작업에 맞는 동작 방식 추천"), 스킬 추천, 서브에이전트 추천(화면 진행 목록에서는 "함께 일할 도우미 에이전트 추천")을 카드로 차례로 보여 줍니다. 카드마다 추천 이름과 "사유:"를 읽고 승인 또는 수정 요청을 누릅니다. 이 실습에서는 네 카드 모두 승인했습니다. 그 뒤 빌더가 지침(시스템 프롬프트)을 쓰고 이름과 설명을 저장하면 완성 요약이 나옵니다.

완성 요약과 바로 이용하기

번호메뉴기능이런 때 사용하세요
1바로 이용하기완성된 에이전트의 대화 화면을 엽니다. 사이드바 내 에이전트 목록에도 같은 이름이 생깁니다.만든 에이전트에 바로 질문해 볼 때

이 실습의 완성 요약은 다음과 같았습니다. 추천 결과는 계정에 설치된 도구·스킬과 요청 내용에 따라 달라집니다.

항목이 실습의 결과
에이전트 이름고객 문의 답장 도우미
사용할 기능(도구)deep_connector_kb(브레인크루 사내 지식 검색)
동작 방식 설정(미들웨어)도구 재시도 — 문서 검색이 실패하면 자동으로 한 번 더 찾습니다
업무 노하우(스킬)브레인크루 보고서 스타일, 문서 서식, 보고서 작성 규칙
함께 일할 도우미 에이전트없음
모델기본 설정(GPT-4.1)

추천이 업무와 맞지 않으면 그 카드에서 수정 요청을 누르고 이유를 적습니다. 예를 들어 "답장 초안만 쓰면 되니 보고서 스킬은 빼 주세요"라고 적으면 빌더가 추천을 다시 고릅니다. 완성한 뒤에도 에이전트 편집 화면에서 언제든 빼거나 더할 수 있습니다.

4단계. 첫 문의 보내기​

첫 문의 입력

번호메뉴입력하거나 고를 값
1메시지 입력란아래 프롬프트(가상 고객 문의)
2전송문의를 보냅니다.

프롬프트: 아래 고객 문의에 답장 초안을 써 주세요. 보낸 사람: 가나다물산 박지훈 과장. 내용: 안녕하세요. 지난주 데모에서 본 회의록 요약 기능을 영업팀 20명이 쓰려고 합니다. 연간 계약 시 할인 조건과 다음 달 초 도입 가능 일정이 궁금합니다.

결과​

첫 답장 초안

번호항목확인할 것
1결론 단락할인 조건과 도입 일정을 확정하지 않고 "[담당자 확인 필요]"로 표시했는지
2복사답장 전체를 복사해 메일 창에 붙여 넣습니다.

이 실습에서 받은 답장은 "문의하신 회의록 요약 기능의 연간 계약 할인 조건 및 도입 일정에 대해 안내드립니다."로 시작해, 할인 조건과 일정은 "[담당자 확인 필요]"로 남기고, 마지막 단락에서 담당자를 통해 개별 안내하겠다고 마무리했습니다. 다만 분류한 문의 유형은 답에 따로 적히지 않았고, 둘째 단락에는 "영업팀 20명 기준으로 충분한 용량과 지원을 제공할 수 있으며"처럼 응대 기준에 없는 약속이 들어갔습니다. 모델의 답은 실행할 때마다 표현이 조금씩 다를 수 있으니, 답을 그대로 보내지 말고 결론-근거-다음 안내 순서와 확정 금지 표시가 지켜졌는지, 응대 기준에 없는 약속이 섞이지 않았는지 응대 기준 문서와 대조해 봅니다. 분류한 유형을 답 첫 줄에 보이게 하려면 편집 화면 지침에 "답 첫 줄에 문의 유형을 적으세요"를 더합니다.

이럴 때 쓰세요: 김그루 사원은 매주 고객 문의 메일 열 건 남짓에 답장을 씁니다. 문의를 붙여 넣기만 하면 유형 분류와 세 단락 초안이 나오므로, 사람은 [담당자 확인 필요] 자리만 영업팀에 확인해 채우면 됩니다. 처음 만들 때 응대 기준 문서를 함께 붙여 두면 팀의 말투와 금지 사항이 지침에 그대로 들어갑니다.

흔한 실수와 해결​

증상원인해결
전송이 눌리지 않습니다.설명이 5자보다 짧거나, 에이전트 생성 권한이 없습니다.설명을 더 적습니다. "에이전트 생성 권한이 없습니다"가 보이면 관리자에게 권한을 요청합니다.
엑셀 파일을 붙였는데 올라가지 않습니다.제작 요청에는 표 파일이 붙지 않습니다.에이전트를 만든 뒤 대화 화면이나 편집 화면 파일 탭에 올립니다.
전체 제출이 흐립니다.아직 제출하지 않은 질문이 있습니다.괄호 안 숫자를 보고 비어 있는 질문 번호를 눌러 답합니다.
질문에 답할 때 문서 파일을 붙였더니 "이미지 첨부만 지원합니다."가 나옵니다.확인 질문에 답할 때는 이미지(.jpg, .jpeg, .png, .gif, .webp)만 붙일 수 있습니다.문서는 첫 제작 요청에 붙이고, 답할 때는 글로 적습니다.
추천된 스킬이 업무와 맞지 않습니다.계정에 설치된 스킬 가운데 가까운 것을 골랐습니다.그 카드에서 수정 요청을 누르거나, 완성 후 편집 화면 스킬 탭에서 끕니다.

응용 과제​

  1. 같은 요청에 "답장 끝에 문의 유형별 담당 부서를 한 줄로 안내해 주세요"를 더해 새 에이전트를 만들고, 첫 에이전트와 답을 비교해 보세요.
  2. 장애·오류 문의(예: "로그인 후 화면이 하얗게 나옵니다")를 보내 기술지원 안내로 마무리하는지 확인해 보세요.
  3. 만든 에이전트의 편집 화면을 열어 빌더가 쓴 지침을 읽고, 응대 기준 문서의 어느 문장이 지침에 들어갔는지 찾아보세요.
