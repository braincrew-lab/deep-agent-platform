평가 문항 설계

데이터셋의 점수는 어떤 질문을 넣었는지와 참조 답변을 어떻게 적었는지에 따라 달라집니다. 이 페이지는 이메일 초안 도우미 점검용 "이메일 초안 기본 10문항"을 예로, 넣을 질문을 고르는 기준과 데이터셋 화면에서 문항을 확인하고 고치고 더하고 지우는 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 에이전트가 실제로 받는 요청을 골고루 담도록 문항을 고릅니다.
  • 메일처럼 정답 문장이 하나가 아닌 답변을, 채점할 수 있는 참조 답변으로 적습니다.
  • 데이터셋 화면에서 문항을 열어 보고, 문항 추가, 편집, 삭제로 문항을 다듬습니다.
  • 지식이 연결된 에이전트라면 컬렉션에서 만들기, 질문으로 만들기, 싫어요에서 만들기로 문항 초안을 만듭니다.

넣을 질문 고르기​

데이터셋은 에이전트가 평소에 받는 요청을 줄여 놓은 표본입니다. 이메일 초안 도우미라면 아래처럼 메일 종류를 나누고, 종류마다 한두 문항씩 넣습니다.

메일 종류데이터셋의 문항이 문항으로 확인하는 것
일정 안내·변경1번 데모 일정 확정, 3번 교육 일정 변경날짜, 시간, 장소가 정확히 옮겨지는지
요청·회신 기한2번 계약서 검토 의견 요청, 4번 견적서 송부기한과 문의처가 빠지지 않는지
보고·사과5번 주간 보고 지연 사과윗사람에게 맞는 어조와 새 제출 시점
감사·공유6번 설문 응답 감사, 7번 회의 결정 사항 공유여러 항목과 담당자가 모두 들어가는지
거절8번 세미나 발표 거절정중하게 거절하면서 다음 기회를 남기는지
공지9번 연말 휴무 안내, 10번 장애 공지와 사과기간, 재개일, 사과와 조치가 함께 있는지

질문을 고를 때는 다음을 지킵니다.

  • 질문 안에 받는 사람, 날짜, 장소, 기한, 담당자를 적습니다. 질문에 없는 사실은 에이전트가 지어낼 수밖에 없어 채점할 수 없습니다.
  • 한 문항에는 메일 한 통만 요청합니다. "세 가지 버전으로 써 줘"처럼 여러 결과를 한꺼번에 요청하면 무엇을 기준으로 채점할지 흐려집니다.
  • 지침을 고친 뒤 비교할 때도 같은 질문을 그대로 씁니다. 문항을 바꾸면 이전 실행과 점수를 견줄 수 없습니다.

참조 답변 적기​

메일은 같은 내용을 여러 문장으로 쓸 수 있으므로, 참조 답변에 메일 전문을 적으면 채점 모델이 문장이 다르다는 이유로 실패를 줄 수 있습니다. 참조 답변에는 메일에 꼭 들어가야 할 내용만 ①, ②처럼 번호로 나눠 적습니다.

나쁜 예좋은 예
12월 3일 세미나 발표를 정중히 거절하는 메일① 발표 요청에 대한 감사 ② 12월 3일 사내 일정으로 참석이 어렵다는 거절 ③ 다음 기회 참여 의사 ④ 정중하고 완곡한 어조

이렇게 적으면 완전성 (Completeness) 평가기가 "참조 답변의 주요 내용을 모두 포함하는지"를 항목별로 따져 채점합니다. 평가기마다 보는 것은 평가기 구성에 정리되어 있습니다.

데이터셋 화면​

데이터셋 목록에서 "이메일 초안 기본 10문항"을 누르면 데이터셋 화면이 열립니다. 문항은 한 쪽에 10개씩 나옵니다. 화면 위쪽 이름 옆에는 만들 때 적은 이름과 설명이, 오른쪽 위에는 데이터셋 정보와 문항을 다시 불러오는 데이터 새로고침(둥근 화살표)이 있습니다. 요약 줄 아래 평가 설정은 이 데이터셋의 채점 설정을 펼치며, 자세한 내용은 평가 데이터셋 만들기에 있습니다.

데이터셋 화면

번호메뉴기능이런 때 사용하세요
1목록으로 돌아가기데이터셋 목록으로 돌아갑니다.다른 데이터셋을 열 때
2삭제데이터셋을 지우는 확인 창을 엽니다.더 쓰지 않는 데이터셋을 정리할 때
3요약 줄"총 10개", 생성일, 수정일이 나옵니다.문항이 모두 올라갔는지, 언제 마지막으로 고쳤는지 볼 때
4문항 추가새 문항을 넣는 창을 엽니다.빠진 메일 종류를 한 문항 더할 때

문항 추가 왼쪽의 컬렉션에서 만들기, 질문으로 만들기, 싫어요에서 만들기는 에이전트의 지식 도구로 문항 초안을 만드는 창을 엽니다. 아래 "지식이 연결된 에이전트의 문항 초안"을 봅니다.

문항 표의 행마다 고치고 지우는 버튼이 있습니다.

문항 행

번호메뉴기능이런 때 사용하세요
1문항 행번호, 입력(질문), 참조 답변이 보입니다. 행을 누르면 오른쪽에 문항 상세가 열립니다.문항 내용을 확인할 때
2편집(연필)그 문항을 고치는 창을 엽니다.참조 답변을 번호 목록으로 다듬을 때
3삭제(휴지통)그 문항을 지우는 확인 창을 엽니다.다른 문항과 겹치는 문항을 뺄 때

데이터셋 오른쪽 위 삭제와 문항 행의 휴지통은 다릅니다. 앞의 것은 데이터셋 전체를, 뒤의 것은 문항 하나를 지웁니다.

문항 상세​

문항 행을 누르면 오른쪽에 "문항 상세" 패널이 열립니다. 표에서는 세 줄까지만 보이는 긴 질문과 참조 답변을 전부 읽을 수 있습니다.

문항 상세

번호메뉴기능이런 때 사용하세요
1입력문항의 질문 전문입니다.질문에 받는 사람과 날짜가 다 들어 있는지 볼 때
2참조 답변참조 답변 전문입니다.번호 항목이 빠짐없이 적혀 있는지 볼 때
3정답 근거근거를 적지 않은 문항은 "근거 없음 — 이 문항은 답변 판정만 나옵니다."로 보입니다.이 문항이 근거 지표 없이 답변만 채점된다는 것을 확인할 때
4닫기패널을 닫습니다.문항 표 전체로 돌아갈 때

문항 고치기와 더하기​

편집(연필)을 누르면 "문항 수정" 창, 문항 추가를 누르면 "문항 추가" 창이 열립니다. 두 창의 입력 칸은 같습니다. 그림은 8번 문항의 참조 답변을 번호 목록으로 고치는 모습입니다.

문항 수정 창

번호메뉴기능이런 때 사용하세요
1질문질문을 고칩니다. 꼭 입력해야 하며 아래에 지금 글자 수와 최대 글자 수(50,000자)가 보입니다.질문에 빠진 날짜나 받는 사람을 더할 때
2참조 답변참조 답변을 고칩니다. 꼭 입력해야 하며 100,000자까지 넣을 수 있습니다.메일 전문 대신 꼭 들어갈 내용을 번호로 적을 때
3정답 근거 (선택)정답 근거 문서와 원문 구절을 적는 칸입니다. 근거를 적어야 근거 지표(예를 들어 Context Recall)가 계산되고, 적지 않으면 답변 판정만 나옵니다. **문서에 답이 없는 질문 (근거 지표에서 제외)**도 여기서 표시합니다.지식을 찾아 답하는 에이전트의 문항에 근거를 달 때(이메일 초안 도우미는 비워 둡니다)
4저장고친 내용을 저장합니다. 바꾼 것이 없으면 왼쪽에 "변경한 내용이 없습니다."가 보입니다.고친 문항을 확정할 때

그 아래 재질의 평가는 모호한 질문에 에이전트가 필요한 조건을 되묻는지 평가할 때 고릅니다. 기본값은 사용 안 함이고, 재질의해야 함, 바로 답해야 함을 고를 수 있습니다. 맨 아래 취소는 저장하지 않고 창을 닫습니다. 고친 내용이 있으면 "저장하지 않은 변경사항" 확인 창이 먼저 뜹니다.

진행 중인 평가 실행이 이 데이터셋을 쓰고 있으면 문항을 고치거나 지울 수 없고 "진행 중인 평가가 있어 수정할 수 없습니다."가 나옵니다. 실행이 끝나거나 취소된 뒤에 고칩니다.

따라 해 보기​

CSV로 올린 8번 문항의 참조 답변이 "12월 3일 세미나 발표를 정중히 거절하는 메일" 한 줄이라, 채점 기준이 흐립니다. 번호 목록으로 고칩니다.

  1. "이메일 초안 기본 10문항" 데이터셋 화면을 엽니다.

  2. 8번 행의 편집(연필)을 누릅니다.

  3. 참조 답변을 지우고 아래 내용을 넣습니다.

    프롬프트: ① 발표 요청에 대한 감사 ② 12월 3일 사내 일정으로 참석이 어렵다는 거절 ③ 다음 기회 참여 의사 ④ 정중하고 완곡한 어조

  4. **정답 근거 (선택)**와 재질의 평가는 그대로 두고 저장을 누릅니다. "문항을 저장했습니다." 안내가 뜹니다.

  5. 8번 행을 눌러 문항 상세에서 참조 답변이 네 항목으로 바뀌었는지 확인합니다.

팁: 새 메일 종류를 점검하고 싶으면 기존 문항을 고치지 말고 문항 추가로 더합니다. 기존 문항을 바꾸면 그 전에 돌린 실행과 비교할 수 없습니다.

문항 지우기​

문항 행의 휴지통을 누르면 "문항 삭제" 확인 창이 열리고 "이 문항이 영구적으로 삭제됩니다."라고 나옵니다. 삭제를 누르면 지워지고 "문항을 삭제했습니다." 안내가 뜹니다.

지식이 연결된 에이전트의 문항 초안​

지식(Deep Connector 컬렉션)을 찾아 답하는 에이전트를 평가할 때는 데이터셋 화면의 세 버튼으로 문항 초안을 만들 수 있습니다. 세 버튼 모두 에이전트를 골라 그 에이전트의 지식 도구로 문서를 검색하므로, 이메일 초안 도우미처럼 지식이 없는 에이전트로는 초안이 만들어지지 않습니다.

버튼하는 일이런 때 사용하세요
컬렉션에서 만들기에이전트가 읽을 수 있는 문서에서 구절을 골라 질문, 참조 답변, 근거 문장을 만들고 한 번 더 검토합니다. 검토를 통과한 문항만 처음부터 체크되어 있고, 저장할 문항을 골라 저장합니다. 5문항씩 나눠 만듭니다.질문이 하나도 없을 때
질문으로 만들기붙여 넣은 질문으로 컬렉션을 검색해 참조 답변과 근거 문장을 만듭니다.현업 질문 목록은 있는데 답변이 없을 때
싫어요에서 만들기포털에서 싫어요를 받은 질문을 골라 참조 답변과 근거 문장을 만듭니다. 민감 실행 조회 권한이 있어야 합니다.사용자가 불만을 표시한 답변이 다시 틀리지 않는지 볼 때

근거가 없는 문항이 있으면 답변·근거 채우기 버튼도 나타납니다. 지식을 연결하는 방법은 지식으로 근거 있는 답변 받기에 있습니다.
