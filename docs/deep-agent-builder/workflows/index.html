반복 업무

매주, 매월 같은 형식으로 돌아오는 일은 요청을 매번 새로 쓰기보다 커맨드, 스케줄, 백그라운드 모드, 즐겨찾기, 챗 오프너를 묶어 두면 빨라집니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 반복하는 업무 네 가지를 기능 조합과 순서로 정리합니다.

이 페이지에서 할 수 있는 일

  • 매주 보고서 요청을 커맨드로 저장하고, 스케줄로 매주 금요일 17시에 보고서 초안을 자동으로 받습니다.
  • 회의가 끝나고 30분 안에 회의록 요약, 액션 아이템, 공유 메일 초안을 받습니다.
  • 월말 판매 분석을 백그라운드 모드로 맡기고 작업 화면에서 결과를 확인합니다.
  • 교육 자료 제작부터 설문 분석, 자료 개정까지 교육 운영 한 바퀴를 돕니다.

매주 금요일: 주간 업무 보고 자동화​

김그루 사원은 금요일 오후마다 한 주 메모를 정리해 주간 보고서를 씁니다. 매주 금요일 17시에는 스케줄로 초안을 자동으로 받고, 같은 형식의 보고 요청은 커맨드로 저장해 두었다가 필요할 때 직접 부릅니다.

커맨드 저장​

커맨드는 사이드바 아래의 에셋설정을 눌러 여는 에셋 화면의 커맨드 탭에서 만듭니다. 김그루 사원은 주간 보고 요청을 weekly_report라는 커스텀 커맨드로 저장해 두었습니다.

커맨드 탭의 커스텀 커맨드

번호메뉴기능이런 때 사용하세요
1에셋설정사이드바 아래의 메뉴입니다. 누르면 에셋 화면이 열립니다.커맨드를 만들거나 지울 때
2커맨드커맨드 탭입니다. 수정할 수 없는 기본 커맨드와 내가 만든 커스텀 커맨드가 나뉘어 있습니다.내가 만든 커맨드를 확인할 때
3커맨드 추가커맨드, 설명, 프롬프트 칸이 있는 새 커맨드 양식을 엽니다.자주 보내는 요청을 저장할 때
4커스텀 커맨드저장한 커맨드 이름(/weekly_report), 설명(주간보고), 프롬프트 앞부분이 보입니다. 오른쪽 휴지통 아이콘으로 지웁니다.저장한 문장을 확인하거나 지울 때

따라 해 보기

  1. 사이드바 아래 에셋설정을 눌러 에셋 화면을 열고 커맨드 탭을 엽니다.

  2. 커맨드 추가를 누르고 아래처럼 입력한 뒤 양식 아래의 저장을 누릅니다. 커맨드는 32자, 설명은 255자까지 쓸 수 있고 칸 아래에 글자 수가 보입니다.

    • 커맨드: weekly_report
    • 설명: 주간보고
    • 프롬프트: 아래 문장

    프롬프트: 이 대화에 올린 주간 업무 메모로 주간 업무 보고서 초안을 작성해 주세요. 형식은 매주 같게 맞춥니다. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 개조식으로 쓰고, 메모에 없는 내용은 만들지 말고 "확인 필요"로 표시해 주세요.

  3. 커스텀 커맨드 목록에 /weekly_report가 생겼는지 확인합니다. 자세한 사용법은 커맨드와 재사용에 있습니다.

스케줄 걸기​

스케줄은 에이전트 편집 화면 오른쪽의 스케줄 탭에서 겁니다. 스케줄 추가를 누르면 탭 안에 양식이 열리고, 실행 시각, 타임존, 실행 메시지를 정한 뒤 생성을 누릅니다.

스케줄 추가

번호메뉴기능이런 때 사용하세요
1스케줄에이전트 편집 화면 오른쪽의 스케줄 탭입니다. "에이전트 자동 실행 스케줄을 관리합니다"가 보입니다.이 에이전트의 자동 실행을 관리할 때
2스케줄 추가탭 안에 새 스케줄 양식을 엽니다.정해진 시각에 실행을 걸 때
3폼 / 스케줄 표현식폼에서는 분, 시, 일, 월, 요일을 목록에서 고르고, 아래 미리보기에 "0 17 * * 5"처럼 표현식이 보입니다. 스케줄 표현식 탭에서는 "분 시 일 월 요일" 형식으로 직접 적습니다.금요일 17시처럼 시각을 정할 때

스케줄 추가 입력

번호메뉴기능이런 때 사용하세요
1타임존실행 시각의 기준 시간대입니다. 기본값은 Asia/Seoul입니다.한국 시간 기준인지 확인할 때
2실행 메시지정해진 시각에 에이전트에게 보낼 문장입니다(10000자 이하). 스케줄은 파일을 첨부할 수 없으므로 메시지만 보냅니다.자동으로 시킬 일을 적을 때
3생성스케줄을 만듭니다. 옆의 취소를 누르면 양식을 닫습니다.입력을 마쳤을 때

따라 해 보기

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 에이전트 설정을 누릅니다. 오른쪽 파일 탭에 김그루_주간업무메모_1106.md를 올려 둔 뒤 스케줄 탭을 엽니다.

  2. 스케줄 추가를 누르고 폼에서 분은 0, 시는 17, 요일은 금요일로 고릅니다. 미리보기가 "0 17 * * 5"인지 봅니다.

  3. 타임존이 Asia/Seoul인지 확인하고, 실행 메시지에 아래 문장을 적은 뒤 생성을 누릅니다.

    프롬프트: 파일 탭에 올려 둔 이번 주 업무 메모를 읽고 주간 업무 보고서 초안을 작성해 주세요. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓰고, 메모에 없는 내용은 만들지 말고 "확인 필요"로 표시해 주세요.

  4. 더 보기의 작업 화면 스케줄 작업 탭에 새 스케줄이 생기고, 다음 실행이 돌아오는 금요일 오후 5시(예: 11/13/2026, 5:00:00 PM)로 보이는지 확인합니다.

결과 확인과 보고서 마무리​

스케줄 실행 결과는 사이드바 더 보기 안의 작업 화면에서 확인합니다. 작업 기록 탭에는 실행 기록이, 스케줄 작업 탭에는 등록된 스케줄이 보입니다.

작업 화면의 스케줄 작업

번호메뉴기능이런 때 사용하세요
1백그라운드 작업사이드바 더 보기에서 작업을 누르면 열리는 화면입니다. "백그라운드 작업을 모니터링하고 관리하세요"가 보입니다.자동 실행 결과를 찾을 때
2작업 기록 / 스케줄 작업실행 기록과 등록된 스케줄을 나눠 봅니다.스케줄이 실행됐는지, 다음 실행은 언제인지 볼 때
3스케줄 줄표현식과 타임존, 실행 메시지, 상태, 다음 실행, 실행 횟수가 보입니다. 오른쪽 아이콘은 차례로 수정(연필), 켜기·끄기(전원), 삭제(휴지통)입니다.스케줄을 잠시 끄거나 고칠 때

따라 해 보기

  1. 금요일 17시가 지나면 사이드바 더 보기에서 작업을 엽니다.
  2. 작업 기록에서 출처를 스케줄로 거르고, 주간 업무 보고서 도우미 실행을 눌러 보고서 초안을 확인합니다. 스케줄은 실행할 때마다 새 대화로 시작하므로, 결과는 그 주의 새 대화에 들어 있습니다.
  3. 17시 전에 미리 받거나 메모를 고쳐 다시 받고 싶으면, 주간 업무 보고서 도우미와 새 대화를 열고 김그루_주간업무메모_1106.md를 첨부해 "이번 주 업무 메모입니다. 내용을 확인해 주세요"라고 먼저 보냅니다.
  4. 답이 오면 입력창에 / 를 입력하고 weekly_report를 고릅니다.
  5. 초안의 숫자가 메모와 같은지 봅니다. 예시 메모에서는 사용자 문의 7건(첨부파일 형식 4건, 권한 2건, 기타 1건), 교육 참석 24명, 댓글 답변 5건입니다.

팁: 스케줄은 첨부 파일 없이 실행 메시지만 보냅니다. 매주 바뀌는 메모는 금요일 오전에 에이전트 편집 화면 파일 탭의 파일을 그 주 메모로 바꿔 올립니다. 스케줄을 잠시 멈추려면 스케줄 작업에서 그 줄의 전원 아이콘을 누릅니다.

회의 직후: 30분 루틴​

회의가 끝나면 30분 안에 회의록 요약, 담당·기한이 붙은 액션 아이템, 참석자 공유 메일을 보내는 것을 목표로 합니다. 화면 기능만 순서대로 묶으면 됩니다.

시간할 일에이전트와 기능
0~5분회의록 파일 첨부, 챗 오프너로 요약 요청회의록 요약 도우미, 즐겨찾기, 챗 오프너
5~15분결정 사항과 액션 아이템 표 확인, 빠진 담당·기한 보완같은 대화
15~25분공유 메일 초안 받기이메일 초안 도우미, 이 에이전트와 새 대화
25~30분메일 검토 후 발송, 다음 회의 안건 메모메일 프로그램

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 엽니다. 대화 화면 위쪽의 별 모양 에이전트 즐겨찾기를 눌러 두면 사이드바 아래 즐겨찾기에서 더 빨리 열 수 있습니다. 방법은 즐겨찾기·워크스페이스·다운로드에 있습니다.

  2. 이 에이전트와 새 대화를 누르고 브레인크루_AI혁신팀_주간회의록_1110.txt를 첨부한 뒤, 첫 화면의 챗 오프너를 누르거나 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 회의록을 안건별 요약, 결정 사항, 액션 아이템(담당, 기한, 할 일) 표로 정리해 주세요. 담당이나 기한이 회의록에 없는 항목은 "확인 필요"로 표시해 주세요.

  3. 안건 1~3의 결정 3건이 모두 들어 있는지, 액션 아이템의 담당과 기한이 회의록과 같은지 봅니다. 예시 회의록에서는 이서준 선임 파일 크기 점검 11월 20일, 김그루 사원 데이터 분석 실무 교안 개정안 11월 24일, 정다은 대리 디자인 가이드 스킬 초안 11월 17일이고, 다음 회의는 11월 17일(화) 10:00입니다.

  4. 표를 복사해 이메일 초안 도우미와 새 대화에 붙여 넣고 아래 프롬프트를 보냅니다.

    프롬프트: 아래 회의 결과를 참석자(박지원 팀장, 이서준 선임, 최하늘 책임, 정다은 대리)에게 공유하는 메일 초안을 써 주세요. 제목, 인사, 결정 사항 3가지, 담당별 할 일과 기한, 다음 회의 일정 순서로 짧게 써 주세요.

  5. 메일 초안을 검토해 메일 프로그램으로 보냅니다.

팁: 회의록 요약 도우미에 요약 요청을 챗 오프너로 등록해 두면 2단계에서 버튼 하나로 보낼 수 있습니다. 사례: 회의록 요약과 액션 아이템에서는 챗 오프너 네 개를 등록합니다. 등록 방법은 챗 오프너에 있습니다. 화면별 자세한 결과는 사례: 회의록 요약과 액션 아이템과 사례: 이메일 초안 작성을 보세요.

매월 말: 판매 분석과 보고 슬라이드​

월말 판매 분석은 계산이 많아 답이 오래 걸릴 수 있습니다. 백그라운드 모드로 맡겨 두고 다른 일을 한 뒤, 작업 화면에서 결과를 확인합니다. 백그라운드 모드는 입력란 아래 오른쪽의 백그라운드 모드 버튼으로 켜고 끕니다.

백그라운드 모드

번호메뉴기능이런 때 사용하세요
1첨부 파일이번 달 판매 실적 파일입니다. 파일 이름 옆에 형식(XLSX)이 보입니다.분석할 파일이 맞는지 볼 때
2백그라운드 모드 (ON)시계 모양 버튼입니다. 마우스를 올리면 지금 상태가 "백그라운드 모드 (ON)"처럼 보입니다. 켜고 보낸 요청은 화면을 떠나도 뒤에서 처리되고 작업 화면에 기록이 남습니다.분석이 길어질 것 같을 때
3전송요청을 보냅니다. 백그라운드 모드가 켜져 있으면 "백그라운드 실행 시작"과 "요청이 백그라운드에서 처리되고 있습니다."가 표시됩니다.파일과 요청을 다 넣었을 때

따라 해 보기​

  1. 판매 데이터 분석가와 새 대화를 열고 브레인크루_2026_판매실적.xlsx를 첨부합니다. 표 데이터 파일은 .xlsx, .xls, .xlsb, .xlsm, .csv 형식을 받고, 파일 1개당 최대 50MB입니다.

  2. 입력란 아래 오른쪽의 백그라운드 모드 버튼을 눌러 백그라운드 모드 (ON) 으로 켜고 아래 프롬프트를 보냅니다.

    프롬프트: 첨부한 판매 실적 파일에서 2026년 10월 지역별·제품별 매출과 판매수량을 집계하고, 9월 대비 증감과 목표 시트 대비 누적 달성률을 표로 보여 주세요. 달성률이 가장 낮은 지역은 제품별로 나눠 원인 가설을 적어 주세요.

  3. 다른 일을 하다가 사이드바 더 보기의 작업을 열고 작업 기록에서 이 요청의 상태가 완료로 바뀌었는지 확인합니다. 그 줄을 누르면 판매 데이터 분석가의 해당 대화로 이동합니다.

  4. 분석 숫자를 원본과 대조한 뒤 표를 복사해 제안서 PPT 작성기에 보냅니다. 제안서 PPT 작성기는 지침에 6장 구성(표지, 고객 과제, 해결 방안, 기대 효과, 도입 일정과 비용, 다음 단계)이 정해져 있으므로, 월간 판매 보고도 같은 자리에 맞춰 6장으로 요청합니다.

    프롬프트: 아래 표로 월간 판매 보고 슬라이드를 6장으로 만들어 주세요. 1장 표지(2026년 10월 판매 보고, 발표자 AI혁신팀 김그루), 2장 10월 실적 요약과 과제, 3장 지역별·제품별 매출 표, 4장 목표 대비 누적 달성률, 5장 달성률이 가장 낮은 지역의 제품별 원인 가설, 6장 다음 달 계획. 숫자는 표에 있는 것만 쓰고, 표에 없는 값은 "확인 필요"로 남겨 주세요.

  5. 캔버스 아래쪽 장수 표시가 "1 / 6"인지 확인하고, 결과를 문서 캔버스에서 넘겨 본 뒤 내려받습니다.

팁: 같은 분석을 매달 하려면 2단계 프롬프트를 커맨드로 저장해 둡니다. 커맨드는 저장한 뒤 고칠 수 없어 달이 바뀔 때마다 지우고 다시 만들어야 하므로, 달은 커맨드에 넣지 않습니다. 프롬프트의 "2026년 10월"은 "앞 메시지에 적은 달"로, "9월"은 "그 전달"로 바꿔 저장합니다. 커맨드를 고르면 저장한 프롬프트만 바로 전송되고 입력란에 올려 둔 파일은 함께 가지 않습니다. 그래서 새 달 파일을 "11월 판매 실적 파일입니다. 분석할 달은 2026년 11월입니다."처럼 분석할 달을 적은 문장과 함께 먼저 보내고, 답을 받은 뒤 커맨드를 고릅니다. 커맨드는 백그라운드 모드를 켜 두어도 일반 대화로 전송됩니다. 숫자 검증 방법은 사례: 엑셀 판매 데이터 분석과 데이터 분석에, 슬라이드 만들기는 사례: PPT 생성 에이전트에 있습니다.

교육 차수마다: 교육 운영​

교육 한 차수는 자료 준비, 교육, 설문 분석, 자료 개정으로 한 바퀴를 돕니다. 두 에이전트를 순서대로 씁니다.

순서할 일에이전트결과물
1교육 슬라이드, 실습 워크시트, 퀴즈 만들기교육 자료 제작 도우미(문서작성 에이전트).pptx, .docx, .xlsx 파일
2교육 진행과 만족도 설문 수집(사람이 진행)설문 결과 CSV
3과정별 평균, NPS, 자유의견 분석설문 결과 분석가결과 표, 차트, 개선안
4개선안을 반영해 다음 차수 자료 개정교육 자료 제작 도우미새 버전 자료

따라 해 보기​

  1. 사례: 교육 자료 만들기 순서대로 "에이전트 만들기 실습" 교육 자료를 만들고 PDF로 내려받아 배포합니다.

  2. 교육이 끝나면 설문 결과 CSV를 사례: 설문 결과 분석 순서대로 분석합니다. 예시 설문에서 에이전트 만들기 실습 과정은 응답 32명, NPS 53.1로 세 과정 중 가장 높지만, "난이도가 조금 높았습니다" 5건과 "실습 시간이 더 길었으면 좋겠습니다" 4건이 나왔습니다.

  3. 설문 결과 분석가의 개선안 답변에서 에이전트 만들기 실습 과정 부분을 복사해 교육 자료 제작 도우미에 아래처럼 보냅니다.

    프롬프트: 아래 설문 개선안을 반영해 "에이전트 만들기 실습" 다음 차수 교육 슬라이드를 고쳐 주세요. 난이도 의견에 맞춰 네 번째 장(대화로 에이전트 만들기 순서) 뒤에 화면 이름을 정리한 슬라이드를 넣고, 실습 시간을 늘린 일정표를 마지막 장에 넣어 주세요.

  4. 문서 캔버스에서 새 버전을 확인하고 내려받습니다.

팁: 1단계와 3단계의 요청 문장은 차수마다 거의 같습니다. 커맨드로 저장해 두면 담당자가 바뀌어도 같은 형식으로 받을 수 있습니다. 커맨드를 고르면 저장한 문장만 바로 전송되므로, 3단계처럼 개선안을 함께 넘겨야 할 때는 개선안을 먼저 메시지로 보내 답을 받은 뒤 커맨드를 고르고, 커맨드 문장은 "아래 설문 개선안" 대신 "앞에서 보낸 설문 개선안"으로 적어 둡니다.

정리​

  • 매주 같은 요청은 커맨드로, 정해진 시각에 할 준비 작업은 스케줄로 겁니다. 스케줄 결과는 작업 화면에서 봅니다.
  • 회의 직후에는 즐겨찾기와 챗 오프너로 시작 시간을 줄이고, 요약과 메일 초안을 다른 에이전트에 나눠 맡깁니다.
  • 오래 걸리는 분석은 백그라운드 모드로 맡기고, 숫자를 검증한 뒤 슬라이드로 넘깁니다.
  • 교육 운영처럼 결과가 다음 차수로 이어지는 일은 두 에이전트를 순서대로 묶어 한 바퀴를 돕니다.
