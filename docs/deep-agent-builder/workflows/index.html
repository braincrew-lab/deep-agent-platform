Deep Agent Builder 반복 업무

반복되는 답변 문제를 지침으로 고치기​

같은 누락이나 추측이 여러 답변에서 나타난다면 개별 대화에서만 정정하기보다 에이전트의 지침을 살펴보세요. 이 절차에서는 안내문 도우미가 제공하지 않은 내용을 덧붙이는 문제를 예로 듭니다.

  1. 수정할 에이전트의 대화 화면을 열고 이름을 확인합니다.
  2. 상단 수정 버튼을 눌러 지침을 읽습니다. 현재 지침에서 정보가 부족할 때 어떻게 처리하도록 적혀 있는지 찾습니다.
  3. 다음 기준을 추가하거나 모순되는 문장을 정리합니다. “사용자가 주지 않은 시간, 장소, 비용은 만들지 않습니다. 안내문에 필요한 정보가 없으면 빠진 항목을 질문합니다.”
  4. 저장을 누르고 저장 중 상태가 끝나는지 확인합니다. 설정을 다시 열었을 때 수정한 문장이 남아 있는지도 확인합니다.
  5. 대화 화면으로 돌아가 “가상 모임은 금요일 오후 3시입니다. 안내문을 작성해 주세요”라고 질문합니다. 장소를 지어내는지, 장소가 빠졌다고 묻는지 확인합니다.

기준이 많아졌다는 사실보다 실제 응답이 바뀌었는지가 중요합니다. 원하는 행동이 나오지 않으면 서로 충돌하는 지침이 없는지 먼저 읽어 보세요.

복제하여 다른 용도를 시험하기​

원래 도우미를 유지하면서 다른 형식을 시험하려면 에이전트 복제를 사용합니다. 복제 전에 필요한 변경 내용을 저장해 두세요.

  1. 원본의 수정 화면에서 이름과 지침을 확인합니다. 저장하지 않은 변경이 있다면 저장을 마칩니다.
  2. 상단 복사 아이콘의 에이전트 복제를 선택합니다.
  3. 새 에이전트의 수정 화면으로 이동하면 이름을 “모임 안내 한 문장 연습”으로 바꿉니다. 원본 이름과 구별되는지 확인합니다.
  4. 지침의 출력 형식을 “시간, 장소, 준비물을 한 문장으로 작성한다”로 수정하고 저장합니다.
  5. 원본과 복제본에 같은 가상 입력을 보내 원하는 형식의 차이가 나타나는지 비교합니다. 원본이 어느 것인지 이름과 지침으로 다시 확인합니다.

복제 성공을 품질 검토의 대체로 보지 마세요. 구성을 가져온 뒤에도 변경한 목적에 맞는 질문으로 시험해야 합니다.

변경 전후를 비교할 작은 질문 묶음 만들기​

매번 다른 질문만 사용하면 어떤 변경이 도움이 되었는지 판단하기 어렵습니다. 아래 두 질문을 반복해서 사용하는 방법을 권합니다.

질문비교할 행동
금요일 오후 3시, 작은 회의실, 책 제목 하나를 준비하는 모임 안내를 써 주세요.필요한 사실을 유지하고 지정한 형식을 따르는지 확인합니다.
금요일 오후 3시 모임의 안내를 써 주세요.장소와 준비물이 없다는 점을 묻거나 드러내는지 확인합니다.

결과 문구를 똑같이 만드는 것이 목표가 아닙니다. 변경한 기준이 적용되는지와 기존에 잘하던 사실 보존이 유지되는지를 함께 보세요. 이전 대화에서 추가로 알려 준 정보가 섞일 수 있으므로 비교할 때는 대화에 이미 들어 있는 정보도 확인합니다.

업무에 다시 사용하기 전​

저장한 설정이 남아 있고, 완전한 입력과 불완전한 입력에서 요구한 기준을 만족하는지 확인합니다. 검토한 질문과 결과의 차이를 기록해 두면 다음 수정의 이유가 분명해집니다. 더 상세한 예시는 활용 사례, 저장이나 복제가 완료되지 않을 때는 문제 해결을 참고하세요.
