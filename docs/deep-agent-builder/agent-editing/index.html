에이전트 수정

에이전트의 이름, 설명, 지침과 연결 자원을 바꾼 뒤 실제로 저장됐는지 확인하는 방법을 설명합니다. 이 페이지는 수정 화면에서 확인할 수 있는 항목과 저장·버전 전환·복제·삭제를 구분해 다룹니다. 화면의 실제 메뉴 배치와 일부 상태 문구는 제품 환경에서 촬영 전 확인이 필요합니다.

수정 화면에서 먼저 확인할 것​

에이전트 목록에서 대상 에이전트를 연 뒤 수정 화면으로 이동합니다. 화면에 표시된 이름, 설명, 지침, 모델과 연결 자원을 먼저 확인하고 한 번에 한 종류의 변경만 적용하면 결과를 비교하기 쉽습니다.

수정 권한과 실행 권한은 별개입니다. 항목을 볼 수 있어도 저장하거나 실행하지 못할 수 있으므로 저장이 되지 않을 때 실행 권한부터 확인하지 마세요. 접근할 수 없는 항목이 있으면 관리자에게 에이전트 이름과 필요한 작업을 전달해 권한을 확인합니다.

이름, 설명, 지침 저장하기​

이름과 설명은 목록에서 에이전트를 구분하는 정보이고, 지침은 에이전트가 대화에서 따를 기준입니다. 이름이나 설명만 바꿔도 답변 규칙이 자동으로 바뀌지는 않습니다.

  1. 수정 화면에서 이름, 설명 또는 지침을 바꿉니다.
  2. 저장할 항목이 바뀌었는지 확인한 뒤 저장을 실행합니다.
  3. 저장이 끝나면 수정 화면을 다시 열거나 새로고침해 변경한 값이 남아 있는지 확인합니다.
  4. 지침을 바꿨다면 정상 입력과 정보가 부족한 입력을 각각 보내 변경 전후의 결과를 비교합니다.

저장 실패 안내가 표시되면 입력값과 수정 권한을 확인한 뒤 다시 저장합니다. 실패가 반복되면 여러 항목을 동시에 바꾸지 말고 마지막에 바꾼 항목부터 되돌려 원인을 좁힙니다.

연결 자원과 실행 설정 확인하기​

도구, 미들웨어, 모델, 서브에이전트, 오프너, 파일, 스킬과 일정이 화면에 표시되면 각각의 연결 상태와 사용 목적을 확인합니다. 자원을 연결하거나 제거한 뒤에는 목록에 보이는지와 실제 실행에서 사용할 수 있는지를 따로 확인합니다.

서브에이전트를 연결할 때는 제품 화면에서 자기 참조나 순환 호출에 대한 안내가 있는지 확인합니다. 연결된 자원을 제거하기 전에는 다른 설정이나 업무가 그 자원을 참조하는지도 확인하세요.

실행 설정을 바꿀 때는 제품 화면에 표시되는 저장 방식과 허용 범위를 먼저 확인합니다. 화면에서 저장 범위나 기본값을 확인하지 못한 항목은 제품 환경의 안내를 우선합니다. 이 문서에서는 확인되지 않은 기본값을 단정하지 않습니다.

버전으로 저장하고 전환하기​

현재 수정 내용을 별도 버전으로 남겨야 하면 새 버전으로 저장을 선택합니다. 버전 이름은 1자 이상 25자 이하이고 설명은 100자 이하입니다. 새 버전을 만든 뒤에는 목록에서 새 버전이 보이는지, 이름과 설명이 의도한 값인지 확인합니다.

버전 전환 전에 저장하지 않은 변경이 있으면 경고가 표시될 수 있습니다. 변경을 남기려면 저장 후 이동을 선택하고, 버릴 내용이면 저장 없이 이동을 선택합니다. 전환 뒤에는 이름, 설명, 지침과 연결 자원이 어느 버전에 속한 값인지 다시 확인합니다.

편집 중 다른 곳에서 같은 버전이 바뀌었다는 안내가 나오면 내 편집 내용을 버릴지, 최신 버전 위에서 계속 편집할지 선택합니다. 어느 내용이 최신인지 모르면 안내를 닫고 화면의 값을 다시 확인한 뒤 결정합니다.

새 버전으로 저장하는 작업이 네트워크 문제로 끝났는지 분명하지 않다면 같은 작업을 바로 반복하지 마세요. 먼저 버전 목록을 새로고침해 생성 여부를 확인한 뒤 다시 시도합니다.

복제하고 삭제하기​

복제 기능을 실행한 뒤에는 새 에이전트 화면으로 이동했는지 확인합니다. 원본과 새 에이전트의 이름을 구분하고 지침, 모델, 도구와 파일이 새 업무에 맞는지 다시 확인하세요. 같은 입력을 양쪽에 보내 결과를 비교하면 원본을 바꾸지 않고 차이를 확인할 수 있습니다.

삭제하기 전에는 대상 에이전트의 이름과 다른 에이전트에서 서브에이전트로 참조하는지 확인합니다. 삭제를 시작하면 확인 대화상자에서 대상 이름을 다시 확인한 뒤 진행합니다. 다른 에이전트가 참조 중이라는 안내가 표시되면 참조를 함께 정리할지 먼저 결정합니다.

삭제 권한이 없으면 삭제 제어를 사용할 수 없거나 권한 안내가 표시됩니다. 이 경우 관리자에게 삭제 대상과 사유를 전달합니다. 삭제 결과를 확인하지 못했다면 목록을 새로고침해 대상이 남아 있는지 확인하고, 상태가 불분명한 동안 같은 삭제를 반복하지 않습니다.

수정 후 완료 확인​

수정 작업은 다음을 모두 확인했을 때 완료로 판단합니다.

  1. 바꾸려던 항목만 변경됐습니다.
  2. 저장 또는 새 버전 생성 결과가 화면에 남아 있습니다.
  3. 수정 화면을 다시 열어 이름, 설명, 지침과 연결 자원의 상태를 확인했습니다.
  4. 필요한 권한으로 정상 입력과 정보가 부족한 입력을 실행해 결과를 비교했습니다.
  5. 의도하지 않은 변화가 있으면 버전을 전환하거나 복제본에서 다시 비교했습니다.

저장 성공은 답변 품질이나 실행 결과가 기대와 같다는 뜻이 아닙니다. 설정 화면의 저장 상태와 실제 대화 결과를 각각 확인해야 합니다.

화면 캡처와 확인 범위​

이 페이지의 본문은 코드와 저장 계약으로 확인한 범위만 설명합니다. 실제 메뉴 경로, 저장 성공 알림, 버전 전환 경고, 복제·삭제 확인 화면은 비식별 테스트 환경에서 확인한 뒤 캡처해야 합니다. 실제 화면을 확인하기 전에는 버튼 이름과 화면 배치를 추가로 단정하지 않습니다.
