멀티에이전트 실행 흐름

이 페이지는 서브에이전트를 붙인 총괄 에이전트에 일을 맡겼을 때 대화 화면에 무엇이 어떤 순서로 나타나는지 설명합니다. 예시는 브레인크루 AI혁신팀 김그루 사원이 11월 10일(화) 팀 주간회의를 마친 뒤 "업무 총괄 비서"에 그날 회의록, 지난주(11월 2일~6일) 업무 메모, 판매 실적 엑셀을 첨부하고 주간 보고 준비를 맡기는 대화입니다. 총괄 에이전트를 만들고 서브에이전트를 붙이는 방법은 서브에이전트 할당하기를 먼저 보세요.

이 페이지에서 할 수 있는 일

  • 총괄 에이전트에 자료를 첨부하고 담당별로 일을 나눠 달라고 요청합니다.
  • 서브에이전트 호출 상자로 지금 어느 담당이 일하고 있는지 확인합니다.
  • 호출 상자를 펼쳐 총괄 에이전트가 담당에게 넘긴 요청과 담당이 돌려준 결과를 읽습니다.
  • 마지막 답변의 수치가 담당의 결과와 같은지 맞춰 봅니다.
  • SUPER AI 에이전트가 담당을 골라 맡기는 화면을 읽습니다.

준비물​

  • 서브에이전트 세 개(회의록 요약 도우미, 주간 업무 보고서 도우미, 판매 데이터 분석가)를 붙인 업무 총괄 비서
  • 첨부 파일 세 개(모두 가상 자료)
    • 브레인크루_AI혁신팀_주간회의록_1110.txt — 이번 주 화요일인 11월 10일 AI혁신팀 주간회의, 결정 3건과 담당·기한
    • 김그루_주간업무메모_1106.md — 김그루 사원의 지난주(11월 2일~6일) 업무 메모
    • 브레인크루_2026_판매실적.xlsx — 2026년 1월부터 10월까지 지역별·제품별 판매 내역과 지역별 연간 목표

대화 화면에 첨부할 수 있는 파일은 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm입니다. 한 번에 최대 10개까지 올릴 수 있습니다. 파일 하나의 크기 한도는 형식마다 다릅니다. .pdf, .jpg, .jpeg, .png, .gif, .webp, .docx, .hwp, .hwpx는 20MB, .md, .markdown, .txt, .html, .htm은 10MB, .xlsx, .xls, .xlsb, .xlsm, .csv, .pptx, .ppt는 50MB까지입니다. 자세한 기준은 첨부파일 지원을 참고하세요.

한눈에 보는 순서​

단계화면에 보이는 것누가 일하나요
1. 요청첨부 파일과 요청 문장 말풍선사용자
2. 위임서브에이전트 이름이 붙은 호출 상자서브에이전트
3. 정리총괄 에이전트의 마지막 답변총괄 에이전트

서브에이전트가 일하는 동안에는 화면이 한동안 멈춘 것처럼 보일 수 있습니다. 호출 상자 이름 앞 아이콘이 돌고 있으면 아직 일하는 중이니 창을 닫지 말고 기다리세요. 이 예시에서는 요청을 보내고 2분 안에 마지막 답변이 나왔습니다.

1. 요청 보내기​

사이드바 내 에이전트 목록에서 업무 총괄 비서를 누르고, 사이드바 위쪽의 이 에이전트와 새 대화를 누르면 대화 화면이 열립니다. 총괄 에이전트에게는 어떤 일을 어느 담당에게 맡길지 문장으로 적어 보내면 분담이 더 분명해집니다.

총괄 에이전트에 요청 보내기

번호메뉴기능이런 때 사용하세요
1첨부 파일파일 업로드(클립)로 올린 파일이 입력창 위에 파일 이름과 형식(TXT, MD, XLSX)으로 표시됩니다. 여기서는 회의록, 업무 메모, 판매 실적 엑셀 세 개입니다.담당에게 넘길 자료를 함께 보낼 때
2메시지 입력란총괄 에이전트에게 보낼 요청을 적습니다. 그림의 요청에는 맡길 일과 담당 이름이 함께 들어 있습니다."회의록은 요약 도우미에게, 엑셀은 분석가에게"처럼 분담을 지정할 때
3백그라운드 모드시계 모양 버튼으로, 백그라운드 실행을 켜고 끕니다. 켜고 보낸 요청은 작업 화면에서 이어서 확인합니다. 그림은 꺼진 상태입니다.이 페이지처럼 대화 화면에서 진행 과정을 지켜볼 때는 끈 상태로 둡니다.
4전송요청을 보냅니다.요청 문장을 다 쓰고 보낼 때

입력란 아래 왼쪽의 사람 모양 서브에이전트 버튼을 누르면 이 에이전트에 연결된 서브에이전트 목록이 펼쳐집니다. 보내기 전에 세 담당이 모두 연결되어 있는지 확인할 때 씁니다.

보낼 요청은 다음과 같습니다.

프롬프트: 주간 보고를 준비해 주세요. 첨부한 이번 주 화요일(11월 10일) 회의록은 회의록 요약 도우미에게 맡겨 결정 사항과 담당자, 기한을 정리하고, 판매 실적 엑셀은 판매 데이터 분석가에게 맡겨 2026년 10월 지역별 매출과 연간 목표 대비 누적 달성률을 집계해 주세요. 마지막으로 지난주(11월 2일~6일) 업무 메모와 두 결과를 주간 업무 보고서 도우미에게 넘겨 주간 보고서 초안을 만들어 주세요.

2. 위임 표시 읽기​

요청을 보내면 총괄 에이전트가 지침에 적힌 순서대로 담당을 부르고, 부를 때마다 그 서브에이전트 이름이 붙은 호출 상자가 요청 말풍선 아래에 하나씩 생깁니다. 그림은 회의록 요약 도우미가 일을 마치고 판매 데이터 분석가가 일하는 중인 화면입니다. 주간 업무 보고서 도우미는 앞의 두 결과를 받아야 하므로 마지막에 불립니다.

서브에이전트 호출 상자

번호메뉴기능이런 때 사용하세요
1요청 말풍선보낸 요청과 첨부 파일이 남습니다.총괄 에이전트가 무엇을 받았는지 다시 볼 때
2완료된 호출 상자"회의록 요약 도우미"처럼 서브에이전트 이름이 붙은 상자입니다. 이름 앞 초록 체크는 일을 마쳤다는 뜻이고, 오른쪽 "6.4s" 같은 숫자는 그 담당이 일한 시간(초)입니다.실제로 담당에게 일이 넘어가 끝났는지 확인할 때
3일하는 중인 호출 상자이름 앞 아이콘이 돌고 있으면 그 담당이 아직 일하는 중입니다. 일을 마치면 초록 체크와 걸린 시간으로 바뀝니다.지금 어느 담당이 일하고 있는지 볼 때
4취소응답이 만들어지는 동안 전송 버튼 자리에 나타납니다. 누르면 진행 중인 응답을 멈춥니다.요청을 잘못 보내 처음부터 다시 하고 싶을 때

3. 담당에게 넘긴 요청과 결과 보기​

서브에이전트 호출 상자를 누르면 펼쳐집니다. 맨 위 상자에는 담당 이름과 총괄 에이전트가 넘긴 요청이 나오고, 그 아래에는 담당이 일하면서 쓴 도구 기록이 차례로 보입니다. 판매 데이터 분석가는 첨부 목록, 첨부 읽기로 엑셀을 읽은 뒤 데이터 분석을 여러 번 실행해 표를 만듭니다.

서브에이전트에게 넘긴 요청과 작업 기록

번호메뉴기능이런 때 사용하세요
1호출 상자(펼침)누르면 열리고 다시 누르면 접힙니다.담당에게 무엇을 시켰는지 보고 싶을 때
2넘긴 요청맨 위 상자에 담당 이름과 총괄 에이전트가 보낸 요청 전문이 나옵니다. 그림의 요청에는 파일 이름, 집계 기간, 집계 항목이 들어 있습니다.담당의 결과가 이상할 때 요청이 제대로 넘어갔는지 확인할 때
3첨부 목록담당이 첨부 파일 목록을 확인한 기록입니다. 아래 첨부 읽기에서 읽은 파일 이름이 보입니다.담당이 올바른 파일을 읽었는지 볼 때
4데이터 분석담당이 코드를 실행해 데이터를 계산한 기록입니다. 펼치면 실행 결과 표가 보입니다.담당이 어떤 계산을 했는지 따라가 볼 때

도구 기록 아래로 내려가면 담당이 돌려준 결과가 나옵니다. 마지막 데이터 분석 기록에는 계산 결과가 데이터 표로 보이고, 그 아래에 담당이 총괄 에이전트에게 돌려준 답이 이어집니다.

서브에이전트가 돌려준 결과

번호메뉴기능이런 때 사용하세요
1데이터 표담당이 계산한 결과 표입니다. 그림은 지역별 연간 목표 매출, 누적 매출, 달성률입니다.수치가 어떤 계산에서 나왔는지 확인할 때
2담당의 결과담당이 총괄 에이전트에게 돌려준 답입니다. 아래에 10월 지역별 매출 표와 연간 목표 대비 달성률 표가 이어집니다.담당의 원래 답을 총괄 에이전트의 정리와 비교할 때

총괄 에이전트의 지침에는 "수치는 담당 에이전트가 준 값만 쓴다"는 규칙이 있습니다. 따라서 마지막 답변에 나온 숫자는 이 결과와 같아야 합니다. 이 예시에서는 서울 10월 매출 134,560,000원, 서울 누적 달성률 68.8%가 마지막 답변에도 그대로 쓰였습니다.

4. 마지막 답변 확인​

세 담당의 일이 끝나면 호출 상자 세 개 모두에 초록 체크가 붙고, 총괄 에이전트가 결과를 모아 답변을 씁니다. 지침대로 맨 위에 "주간 핵심 3줄"이 나오고, 그 아래에 주간 업무 보고서 도우미의 초안이 "■ 지난주 주요 업무", "■ 회의록 요약", "■ 판매 데이터 집계", "■ 이슈 및 특이사항" 순서로 이어집니다.

총괄 에이전트의 마지막 답변

번호메뉴기능이런 때 사용하세요
1주간 업무 보고서 도우미 호출 상자세 번째 담당을 부른 기록입니다. 펼치면 업무 메모와 앞의 두 결과가 함께 넘어간 것을 볼 수 있습니다.보고서가 어떤 자료로 만들어졌는지 확인할 때
2주간 핵심 3줄지침대로 맨 위에 쓴 보고 핵심입니다. 회의 결정과 판매 실적 수치가 함께 들어갑니다.팀장 보고용 요약을 바로 옮겨 쓸 때
3주간 보고서 초안지난주 업무, 회의록 요약, 판매 실적, 이슈가 한 보고서로 정리된 부분입니다.보고서를 복사해 사내 메일이나 문서로 옮길 때
4아티팩트이 대화에서 만들어진 파일 목록을 엽니다.담당이 만든 표나 파일을 내려받을 때

담당이 한 번에 일을 끝내지 못하면 총괄 에이전트가 이유를 적고 같은 담당을 다시 부를 수 있습니다. 이때는 같은 이름의 호출 상자가 두 번 나옵니다. 응답이 중간에 끊기면 같은 대화에 다음과 같이 보내세요. 이미 끝난 담당의 결과는 대화에 남아 있습니다.

프롬프트: 이어서 완성해 주세요.

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 업무 총괄 비서를 누르고, 사이드바 위쪽의 이 에이전트와 새 대화를 누릅니다.
  2. 입력란 아래 왼쪽의 서브에이전트 버튼을 눌러 세 담당이 보이는지 확인합니다.
  3. 입력란 아래 오른쪽의 파일 업로드(클립)로 회의록, 업무 메모, 판매 실적 엑셀 세 파일을 올립니다.
  4. 위 "1. 요청 보내기"의 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.
  5. "회의록 요약 도우미", "판매 데이터 분석가", "주간 업무 보고서 도우미" 호출 상자가 차례로 생기는지 봅니다.
  6. 판매 데이터 분석가 상자를 눌러 넘긴 요청을 읽고, 아래로 내려가 담당이 돌려준 수치를 확인합니다.
  7. 마지막 답변이 나오면 주간 핵심 3줄의 수치를 분석가의 결과와 맞춰 봅니다.
  8. 아티팩트를 눌러 만들어진 파일이 있는지 확인합니다.

서브에이전트를 쓸 수 없을 때​

실행할 때 담당 에이전트를 쓸 수 없으면 알림이 나오고, 총괄 에이전트는 그 담당 없이 일을 계속합니다. 알림 문구로 이유를 알 수 있습니다.

알림 문구뜻과 할 일
삭제된 서브에이전트라 사용하지 못했습니다.담당 에이전트가 삭제되었습니다. 에이전트 편집 화면에서 다른 담당을 붙입니다.
숨겨진 서브에이전트라 사용하지 못했습니다.담당 에이전트가 숨김 상태입니다. 숨김을 풀거나 다른 담당을 붙입니다.
승인 대기 중인 서브에이전트라 사용하지 못했습니다.워크스페이스 에이전트의 게시 승인이 아직 나지 않았습니다. 승인 뒤 다시 요청합니다.
승인이 거절된 서브에이전트라 사용하지 못했습니다.워크스페이스 에이전트 게시가 반려되었습니다. 다른 담당을 붙입니다.
서브에이전트를 실행할 권한이 없어 사용하지 못했습니다.그 담당을 실행할 권한이 없습니다. 관리자에게 권한을 요청합니다.
서브에이전트에 필요한 리소스를 사용할 권한이 없어 사용하지 못했습니다.담당이 쓰는 도구나 모델의 사용 권한이 없습니다. 관리자에게 문의합니다.
실행에 필요한 모델이나 릴리스를 찾을 수 없는 서브에이전트라 사용하지 못했습니다.담당의 모델이 없거나 게시본이 없습니다. 담당 에이전트의 모델 설정을 확인합니다.
서브에이전트를 준비하지 못해 사용하지 못했습니다.담당을 준비하는 중 문제가 생겼습니다. 잠시 뒤 다시 요청합니다.
일부 서브에이전트를 사용할 수 없습니다.그 밖의 이유입니다. 담당 에이전트를 혼자 열어 대화가 되는지 먼저 확인합니다.

알림이 나왔다면 마지막 답변에서 그 담당이 맡을 부분이 비어 있거나 총괄 에이전트가 직접 채웠을 수 있습니다. 보고에 쓰기 전에 그 부분을 따로 확인하세요.

SUPER AI 에이전트가 맡기는 화면​

SUPER AI 에이전트는 서브에이전트를 미리 붙여 두지 않아도 요청에 맞는 에이전트를 골라 맡깁니다. 사이드바 위쪽 더 보기 메뉴의 SUPER AI 에이전트로 엽니다. 맡긴 기록은 에이전트에 위임 상자로 남고, 답변 첫머리에 어느 에이전트에게 맡겼는지 밝힙니다. 그림은 회의록을 첨부하고 아래 프롬프트를 보낸 뒤 에이전트에 위임 상자를 펼친 화면입니다.

SUPER AI 에이전트의 위임 화면

번호메뉴기능이런 때 사용하세요
1에이전트에 위임고른 에이전트에게 일을 넘긴 기록입니다. 오른쪽에 걸린 시간이 나오고, 누르면 펼쳐집니다.실제로 다른 에이전트에게 일이 넘어갔는지 확인할 때
2넘긴 요청SUPER AI 에이전트가 맡긴 에이전트에게 보낸 요청입니다. 첨부 파일 이름과 정리할 항목이 들어 있습니다.요청이 제대로 전달됐는지 볼 때
3맡긴 에이전트"회의록 요약 도우미에게 맡겨 아래와 같이 정리했습니다."처럼 어느 에이전트에게 맡겼는지 밝힌 문장입니다.엉뚱한 에이전트에게 맡기지 않았는지 확인할 때
4결과 표맡은 에이전트가 돌려준 결과입니다. 그림은 결정사항/할 일, 담당자, 기한 표이며, 회의록에 없는 값은 "확인 필요"로 남았습니다.결과를 그대로 쓸 수 있는지 확인할 때

SUPER AI 에이전트가 고를 수 있는 에이전트는 내가 실행할 수 있는 내 에이전트와 워크스페이스 에이전트입니다. 원하는 에이전트를 고르지 않으면 요청에 그 에이전트 이름을 넣어 보내세요.

프롬프트: 회의록 요약 도우미에게 맡겨서, 첨부한 회의록의 결정 사항과 담당자, 기한을 표로 정리해 주세요.

결과를 볼 때 확인할 것​

  • 호출 상자마다 초록 체크가 붙었는지 봅니다. 아이콘이 돌고 있으면 그 담당은 아직 일하는 중이고, 빨간 X는 오류입니다.
  • 담당의 이름이 붙은 호출 상자가 실제로 나왔는지 봅니다. 상자가 없으면 총괄 에이전트가 직접 답을 만든 것입니다.
  • 마지막 답변에 나온 수치를 호출 상자 안 담당의 결과와 맞춰 봅니다. 다르면 보고에 쓰기 전에 다시 물어보세요.
  • 담당이 다시 불렸다면 총괄 에이전트의 중간 문장에 이유가 적혀 있습니다. 첫 결과가 왜 모자랐는지 읽어 두면 지침을 고칠 때 도움이 됩니다.
  • 매주 같은 요청을 보낸다면 스케줄링과 백그라운드 모드로 자동 실행을 걸어 둘 수 있습니다. 다만 스케줄 실행은 매번 새 대화로 시작되고 파일을 첨부할 수 없으므로, 이 페이지처럼 파일을 첨부해야 하는 요청은 그대로 옮길 수 없습니다. 스케줄에는 실행 메시지만으로 끝나는 요청을 겁니다.
