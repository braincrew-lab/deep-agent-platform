Deep Agent Builder 멀티에이전트 실행 흐름

이 페이지는 서브에이전트가 포함된 작업이 시작된 뒤 어떤 순서로 확인되고, 결과가 사용자와 부모 에이전트에 어떻게 전달되는지 설명합니다. 연결을 저장하는 방법은 서브에이전트 할당하기, 연결 조건은 멀티에이전트 개념에서 확인하세요.

실행은 세 단계로 진행됩니다​

멀티에이전트 작업은 연결을 저장한 순간 끝나지 않습니다. 실행할 때 다시 확인하는 단계가 있고, 실행 결과가 사용자와 부모 에이전트에 전달되는 방식도 다를 수 있습니다.

단계사용자가 확인할 내용
실행 준비선택한 부모 에이전트와 대화, 연결된 자원이 현재 작업에 사용 가능한지 확인합니다.
실행 전 확인실행 권한과 작업 정보가 현재 요청과 맞는지 다시 확인합니다. 하나라도 맞지 않으면 작업을 시작하지 않습니다.
실행과 결과 전달작업 결과가 사용자 화면에 표시되는지, 부모 에이전트가 후속 작업에 사용할 수 있는지 각각 확인합니다.

연결이 저장되어 있어도 실행 시점에 권한이 바뀌었거나 연결된 자원을 사용할 수 없으면 실행이 시작되지 않을 수 있습니다.

1. 실행을 준비할 때 확인할 것​

실행을 시작하기 전에 다음 항목을 확인합니다.

  1. 실행할 부모 에이전트와 대화가 맞는지 확인합니다.
  2. 부모 에이전트가 사용할 모델, 도구, 스킬, 서브에이전트가 현재 구성에 포함되어 있는지 확인합니다.
  3. 저장된 연결과 이번 실행에 사용할 구성이 같은지 확인합니다.

이 단계는 저장된 설정을 읽는 과정입니다. 여기서 사용 가능하다고 표시되더라도 실행 직전에 권한과 자원 상태를 다시 확인합니다.

2. 실행 전에 권한을 다시 확인합니다​

실행을 시작하기 직전에 다음 조건을 확인합니다.

  1. 이번 실행에 사용할 권한 정보가 아직 유효한지 확인합니다.
  2. 권한 정보가 현재 실행과 연결되어 있는지 확인합니다.
  3. 같은 권한 정보를 이미 사용한 실행이 없는지 확인합니다.
  4. 부모 에이전트가 사용할 모델, 도구, 스킬, 서브에이전트가 허용된 구성에 포함되어 있는지 확인합니다.
  5. 각 자원을 이번 실행에서 사용할 권한이 있는지 확인합니다.

다음과 같은 경우에는 실행을 시작하지 않습니다.

확인 결과사용자 판단
실행 권한이 거부됨관리자에게 해당 에이전트와 자원을 사용할 권한을 요청합니다.
권한 확인이 정해진 시간 안에 끝나지 않음잠시 후 다시 실행하고, 반복되면 관리자에게 문의합니다.
권한 정보가 만료됨최신 설정을 다시 불러온 뒤 실행합니다.
같은 권한 정보가 이미 사용됨같은 요청을 즉시 반복하지 말고 새 실행을 시작합니다.
실행 대상이나 사용 자원이 현재 요청과 맞지 않음부모 에이전트의 연결과 이번 요청을 다시 확인합니다.

이 단계에서 실패하면 서브에이전트 작업을 시작하지 않습니다. 실행이 시작되지 않을 때는 에이전트 수정 화면만 반복해서 확인하지 말고, 실행 권한과 연결된 자원이 현재 요청과 맞는지 먼저 확인하세요.

3. 실행 결과가 전달되는 방식​

실행 전 확인을 통과하면 서브에이전트가 작업을 수행하고 결과를 반환합니다. 사용자 화면에는 작업 결과가 표시될 수 있습니다.

부모 에이전트가 다음 작업을 이어갈 때는 결과 전체가 그대로 전달되지 않고, 결과를 다시 찾을 수 있는 요약 표시만 전달될 수 있습니다. 이 경우 부모 에이전트는 필요한 순간에 결과를 다시 조회합니다.

결과 형식이 올바르지 않으면 요약 표시로 바꾸지 않고 원래 메시지를 그대로 전달할 수 있습니다. 이 경우에도 부모 에이전트가 원문을 사용했다고 단정하지 말고, 후속 조회가 있었는지 별도로 확인하세요.

따라서 다음 두 가지를 구분해야 합니다.

  • 사용자 화면에 원본 결과가 표시되었는가
  • 부모 에이전트가 후속 작업에 결과 내용을 사용할 수 있는가

사용자 화면에서 결과를 봤다는 사실만으로 부모 에이전트가 그 내용을 자동으로 사용했다고 판단하지 마세요. 후속 작업에 원문이 필요하면 부모 에이전트가 결과를 다시 조회하는지 확인해야 합니다.

부모 에이전트가 결과를 다시 확인하는 경우​

부모 에이전트가 후속 작업에 원문을 사용해야 할 때는 결과 목록이나 실행 결과에서 해당 항목을 다시 확인합니다.

  1. 먼저 현재 다시 확인할 수 있는 결과 목록과 요약을 확인합니다.
  2. 필요한 결과를 선택해 본문을 확인합니다.
  3. 결과가 현재 실행 화면에 보이지 않으면 실행 이력이나 결과 보관 위치를 확인합니다.
  4. 존재하지 않는 결과를 선택했다면 표시된 결과 목록에서 올바른 항목을 다시 고릅니다.

결과를 다시 확인한 본문은 사용자 화면에 표시된 결과와 같은 방식으로 반복 렌더링되지 않을 수 있습니다. 결과를 찾았는지와 화면에 중복 표시되지 않았는지를 나누어 확인하세요.

다시 확인한 본문에서 표시용 태그가 제거되면 같은 결과가 화면에 결과 카드로 다시 나타나지 않습니다. 화면에 결과가 두 번 보인다면 결과 자체의 중복인지, 원문 조회와 화면 표시를 함께 확인한 것인지 구분하세요.

실행 결과를 확인하는 순서​

실행이 끝난 뒤에는 다음 순서로 판단합니다.

  1. 실행이 권한 확인 단계에서 중단됐는지, 실제 작업까지 시작됐는지 확인합니다.
  2. 권한 확인을 통과했다면 서브에이전트 작업 결과가 도착했는지 확인합니다.
  3. 사용자 화면에 결과가 한 번 표시됐는지 확인합니다.
  4. 부모 에이전트가 요약만 받은 상태인지, 후속 조회로 본문을 확인했는지 구분합니다.
  5. 부모 에이전트의 다음 답변에 결과가 반영됐는지 원문과 대조합니다.

결과가 보이지 않을 때는 먼저 실행이 시작됐는지 확인하세요. 실행이 시작되지 않았다면 연결 저장 문제가 아니라 권한, 만료된 실행 정보, 또는 현재 요청과 맞지 않는 자원 때문일 수 있습니다.
