파일 첨부 정책과 가드레일

Deep Agent Builder에서 파일을 올리는 곳은 채팅만이 아닙니다. 에이전트 편집 화면의 파일 탭과 스킬 탭, 새 에이전트 만들기, 에이전트 가져오기, 라운지 게시글, 에셋 화면의 스킬 업로드, 평가 데이터셋에도 파일을 올리며, 곳마다 받는 확장자와 크기 한도가 조금씩 다릅니다. 이 페이지는 그 규칙을 표로 모으고, 파일이 거부될 때의 사유와 안내 문구, 조직의 가드레일 정책이 요청을 막았을 때 화면에 나타나는 모습을 정리합니다. 화면을 따라 하는 방법은 각 기능 페이지에 있고, 여기서는 "이 파일을 여기에 올릴 수 있는가"를 빠르게 확인할 때 씁니다.

이 페이지에서 할 수 있는 일

  • 업로드 위치별로 받는 확장자, 파일 한 개의 크기 한도, 개수 한도를 확인합니다.
  • 받지 않는 형식과, 형식이 맞아도 거부되는 경우(내용 불일치, 암호·DRM, 빈 파일)를 확인합니다.
  • 올린 파일이 언제 만료되는지 확인합니다.
  • 가드레일 정책이 요청을 막았을 때 화면에 무엇이 나오고 무엇을 하면 되는지 확인합니다.

채팅 입력란 아래 오른쪽의 파일 업로드로 붙이는 파일의 규칙입니다. 에이전트 편집 화면 파일 탭도 같은 확장자와 크기 한도를 따릅니다.

표를 읽을 때 알아 둘 점은 다음과 같습니다.

  • 새 에이전트 만들기의 제작 요청에는 엑셀·표 파일(.xlsx, .xls, .xlsb, .xlsm, .csv)을 붙일 수 없습니다. 표 자료는 에이전트를 만든 뒤 채팅이나 파일 탭에 올립니다.
  • 만들기 도중 확인 질문에 이미지가 아닌 파일을 붙여 보내면 "이미지 첨부만 지원합니다."가 나오고 전송되지 않습니다.
  • 라운지 게시글 첨부에서 받지 않는 형식을 고르면 "첨부할 수 없는 파일 형식입니다. 이미지나 문서 파일만 올릴 수 있습니다"가, 20MB를 넘으면 "파일은 20MB 이하여야 합니다"가 나옵니다. 본문 이미지는 "JPEG, PNG, GIF, WebP 이미지만 허용됩니다", "이미지는 10MB 이하여야 합니다"로 안내됩니다.
  • 에이전트 가져오기 창에는 "최대 200MB"라고 보이지만, 실제로 올릴 수 있는 크기는 50MB까지입니다.
  • 평가 데이터셋 CSV에는 question, answer 열이 있어야 합니다. 열이 없으면 "CSV 헤더에 question, answer 열이 있어야 합니다.", 5MB를 넘으면 "파일이 최대 업로드 크기를 초과했습니다.", 1,000행을 넘으면 "CSV는 최대 1000행까지 업로드할 수 있습니다."가 나옵니다.

이럴 때 쓰세요: 신규 입사자 교육 자료를 준비할 때 김그루 사원은 이 표로 자료마다 올릴 곳을 먼저 정합니다. 교안 PowerPoint는 채팅에 바로 붙이고, 실습용 판매 엑셀은 제작 요청에 붙지 않으므로 에이전트를 만든 뒤 파일 탭에 올리며, 교육 뒤 답변 점검에 쓸 질문 묶음은 question, answer 열이 있는 5MB 이하 CSV로 만들어 평가 데이터셋에 올립니다.

스킬 ZIP 안에 넣을 수 있는 파일​

스킬 ZIP은 최상위 또는 하나뿐인 최상위 폴더 안에 SKILL.md가 있어야 하고, 안에 든 파일은 모두 다음 확장자여야 합니다. 하나라도 다른 확장자가 있으면 ZIP 전체가 거부되고 "허용되지 않은 확장자의 파일이 포함되어 있어 업로드할 수 없습니다: 파일 이름."과 함께 "허용 확장자: …"가 안내됩니다.

구분확장자
텍스트.md, .txt, .json, .yaml, .yml, .csv, .py, .sh, .js, .ts, .html, .xml, .toml
문서·이미지.docx, .pptx, .xlsx, .pdf, .png, .jpg, .jpeg, .gif

.svg 파일은 넣을 수 없습니다. 화면에서 바로 열어 고칠 수 있는 텍스트 파일은 한 개에 256KB까지입니다.

받지 않는 형식​

채팅 첨부, 에이전트 편집 화면 파일 탭, 새 에이전트의 제작 요청 첨부는 앞의 표에 없는 확장자를 모두 받지 않습니다. 자주 문의가 오는 형식과 바꾸는 방법은 다음과 같습니다. 이 가운데 압축 파일(.zip)만 다른 업로드 위치 세 곳에서 받고, 나머지 형식은 어느 업로드 위치에서도 받지 않습니다. 받지 않는 형식은 같은 내용을 받는 형식으로 다시 저장해 올립니다.

형식바꾸는 방법
옛 Word 문서(.doc)Word에서 .docx로 다시 저장합니다.
.tiff, .bmp 이미지.png나 .jpg로 바꿉니다.
.xhtml 웹 문서브라우저에서 .html로 저장하거나 PDF로 인쇄합니다.
AsciiDoc, LaTeX 원고.md나 PDF로 바꿉니다.
HWP 3.0 같은 옛 한글 문서한글에서 HWP 5.x 이상이나 .hwpx로 다시 저장합니다.
압축 파일(.zip)채팅, 에이전트 편집 화면 파일 탭, 새 에이전트 제작 요청에는 올릴 수 없습니다. 풀어서 필요한 파일만 올립니다. .zip은 에셋 화면 스킬 탭의 스킬 업로드, 에이전트 편집 화면 스킬 탭 문서 작성 스킬의 ZIP 업로드, 에이전트 가져오기 세 곳에서만 받습니다.

형식이 맞아도 거부되는 경우​

확장자가 표에 있어도 내용을 확인하는 단계에서 거부될 수 있습니다.

경우화면 안내할 일
업로드 제한 초과"파일 크기가 업로드 제한(50MB)을 초과합니다."파일을 나누거나 필요한 쪽·시트만 저장해 50MB 아래로 줄입니다.
종류별 한도 초과"PDF 파일 크기가 제한(20MB)을 초과합니다. 현재 크기: …"처럼 종류와 한도, 현재 크기종류별 한도 아래로 줄입니다.
빈 파일"빈 파일은 업로드할 수 없습니다."원본을 다시 저장해 내용이 들어 있는지 확인합니다.
확장자와 내용 불일치"파일 확장자와 실제 파일 형식이 일치하지 않습니다."이름만 바꾼 파일이 아닌지 확인하고, 원본 프로그램에서 그 형식으로 다시 저장합니다.
암호·권한 보호(DRM)"암호나 권한 보호(DRM)가 걸린 문서는 업로드할 수 없습니다. 보호를 해제한 뒤 다시 올려 주세요."암호나 DRM을 해제한 사본을 올립니다. 해제 권한이 없으면 문서 담당자에게 요청합니다.
받지 않는 형식"지원하지 않는 파일 형식입니다"위 "받지 않는 형식" 표대로 바꿉니다.

김그루 사원이 이미 대화가 있는 채팅에서 "이 메모를 요약해 주세요"라고 적어 둔 채, 텍스트 메모의 확장자만 .pdf로 바꾼 파일(김그루_주간업무메모_1106.pdf)을 붙이면 화면 오른쪽 위에 "김그루_주간업무메모_1106.pdf: 파일 확장자와 실제 파일 형식이 일치하지 않습니다."처럼 파일 이름과 거부 사유가 알림으로 나옵니다. 파일 칩은 입력창에 남지만 파일은 올라가지 않은 상태이고, 적어 둔 질문도 그대로 남습니다. 이 상태로 전송을 누르면 "첨부한 파일을 모두 올리지 못해 전송하지 않았습니다. 파일을 확인한 뒤 다시 보내 주세요."와 파일별 사유가 나오고 질문은 보내지지 않습니다. 칩을 빼고, 원본 프로그램에서 그 형식으로 다시 저장한 파일을 붙여 다시 보냅니다.

확장자와 내용이 다른 파일의 거부 알림

번호표시뜻이런 때 사용하세요
1거부 알림거부된 파일 이름과 사유입니다.어떤 파일이 왜 빠졌는지 확인할 때
2거부된 파일 칩올라가지 않은 파일입니다. 아래 입력란에 적어 둔 질문은 그대로 남습니다.칩 오른쪽 X 버튼으로 뺀 뒤 고친 파일을 다시 붙일 때

채팅에서는 올라간 뒤 문서 처리 단계에서도 실패할 수 있습니다. 처리 한도 초과, 암호 보호, 처리 시간 초과, 변환 실패 같은 사유가 파일 칩 아래에 표시되며, 사유별 안내는 첨부파일 지원의 "처리에 실패한 파일"에 있습니다.

만료​

대상보관만료되면
채팅에 붙인 파일올린 지 7일파일이 지워지고 대화의 첨부 칩에 만료됨이 붙습니다. "업로드가 만료되어 파일을 더 이상 열 수 없습니다. 다시 업로드해 주세요."
에이전트 편집 화면 파일 탭에 올린 파일직접 지울 때까지만료되지 않습니다.
아티팩트 창의 다운로드 파일(에이전트가 만든 파일)정해진 내려받기 기간 동안"기간이 만료되어 다운로드 받을 수 없습니다."가 나옵니다. 에이전트에게 파일을 다시 만들어 달라고 요청합니다.

같은 자료를 오래 두고 써야 한다면 채팅마다 올리지 말고 파일 탭에 올려 둡니다.

가드레일 정책이 요청을 막았을 때​

조직에 따라 관리자가 AI 게이트웨이나 가드레일 서비스로 대화 정책을 걸어 둘 수 있습니다. 정책이 질문이나 답변을 막으면, 에이전트 답변 자리에 정책이 정한 문장이 그대로 표시됩니다. 이 문장은 화면이 만든 고정 문구가 아니라 각 조직의 정책이 정한 것이어서, 조직마다 표현이 다릅니다. 막힌 안내도 대화 기록에 남으므로 채팅을 다시 열어도 같은 자리에 보입니다.

확인할 것내용
어디에 보이나막힌 질문 바로 아래, 에이전트 답변 말풍선 자리
무엇이 보이나조직 정책이 정한 안내 문장(조직마다 다름)
무엇이 막히나조직 정책이 정한 기준에 걸린 질문이나 답변. 어떤 내용이 막히는지는 조직마다 다르므로, 기준이 궁금하면 조직의 관리자에게 확인합니다.
정책 운영조직의 관리자가 정합니다. 정책을 쓰지 않는 조직에서는 이런 안내가 나오지 않습니다.

막혔을 때는 다음 순서로 확인합니다.

  1. 안내 문장에 사유가 적혀 있으면 그 사유부터 확인합니다.
  2. 질문이나 붙인 파일에 개인정보, 고객 정보, 사내 비밀처럼 정책에 걸릴 만한 내용이 없는지 확인하고, 있으면 지우거나 가린 뒤 다시 보냅니다.
  3. 같은 질문이 계속 막히면 시각, 에이전트 이름, 안내 문장을 적어 관리자에게 문의합니다. 답변 아래 토큰 배지를 눌러 토큰 사용량 상세의 추적 정보를 함께 전달하면 관리자가 해당 요청을 찾기 쉽습니다.

이럴 때 쓰세요: 가나다물산 문의 메일을 서명란까지 통째로 붙여 답장 초안을 맡겼다가 정책 안내 문장이 나오면, 김그루 사원은 담당자 전화번호와 이메일을 지운 뒤 같은 요청을 다시 보냅니다. 그 뒤로는 고객 메일을 붙이기 전에 연락처부터 지우는 것을 습관으로 삼고, 그래도 막히면 추적 정보를 챙겨 관리자에게 문의합니다.

에이전트에 직접 개인정보 보호 규칙을 거는 방법은 미들웨어와 개인정보 보호에서 설명합니다.

정리​

  • 채팅과 파일 탭은 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm을 받습니다. 파일 한 개는 어느 업로드 위치에서든 50MB까지입니다.
  • .doc, .tiff, .bmp, .xhtml, AsciiDoc, LaTeX는 어디에도 올릴 수 없습니다. .zip은 스킬 업로드, 문서 작성 스킬의 ZIP 업로드, 에이전트 가져오기에서만 받습니다.
  • 빈 파일, 확장자와 내용이 다른 파일, 암호·DRM이 걸린 파일은 거부됩니다.
  • 채팅에 붙인 파일은 7일 뒤 만료되고, 파일 탭 파일은 만료되지 않습니다.
  • 가드레일 정책이 막으면 조직 정책의 안내 문장이 답변 자리에 나옵니다. 내용을 고쳐 다시 보내고, 계속되면 관리자에게 문의합니다.
