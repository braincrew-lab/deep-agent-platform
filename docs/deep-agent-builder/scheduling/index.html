스케줄링과 백그라운드 모드

스케줄은 정해 둔 시각에 에이전트에게 같은 메시지를 자동으로 보내는 기능이고, 백그라운드 모드는 지금 보낸 요청을 화면을 떠나도 계속 실행하게 하는 기능입니다. 이 페이지는 주간 업무 보고서 도우미가 매주 금요일 17시에 주간보고 초안을 쓰도록 스케줄을 만들고, 실행 기록을 작업 화면에서 확인하는 과정을 화면 순서대로 안내합니다. 대화 중에 오래 걸리는 요청을 백그라운드 모드로 맡기는 방법도 함께 다룹니다.

이 페이지에서 할 수 있는 일

  • 에이전트 편집 화면의 스케줄 탭에서 자동 실행 스케줄을 만들고, 고치고, 끄고, 지웁니다.
  • 폼과 스케줄 표현식 중 편한 방법으로 실행 시각을 정하고, 타임존과 실행 메시지를 입력합니다.
  • 작업 화면의 스케줄 작업 탭에서 모든 에이전트의 스케줄을 한곳에서 관리합니다.
  • 작업 기록 탭에서 스케줄로 실행된 작업과 직접 맡긴 작업을 상태·출처·기간으로 걸러 보고, 결과 대화를 엽니다.
  • 대화 화면 입력란 아래 오른쪽의 백그라운드 모드를 켜고 요청을 맡긴 뒤 다른 일을 합니다.

스케줄 만들기 전에 준비할 것​

스케줄은 메시지만 보낼 수 있고 파일을 첨부할 수 없습니다. 매주 바뀌는 자료는 에이전트 편집 화면의 파일 탭에 올려 두고, 실행 메시지에서 그 파일을 읽으라고 적습니다. 이 페이지의 예시는 주간 업무 보고서 도우미의 파일 탭에 김그루_주간업무메모_1106.md를 올려 둔 상태에서 시작합니다. 김그루 사원은 매주 금요일 오전에 이 파일을 그 주 메모로 바꿔 올립니다.

  • 스케줄은 내 에이전트의 에이전트 편집 화면에서 만듭니다. 워크스페이스 에이전트에는 스케줄을 만들 수 없습니다.
  • 스케줄 실행처럼 단계가 많은 작업은 에이전트 편집 화면 설정 탭의 최대 처리 단계 수(Recursion Limit)를 기본값 500 이상으로 둡니다. 값을 올리면 긴 작업이 멈추기 전에 더 많은 단계를 실행할 수 있지만 처리 시간과 비용도 늘 수 있습니다. 설정 방법은 세부 설정과 메모리에 있습니다.
  • 스케줄은 내가 화면을 열어 두지 않아도 실행됩니다. 실행될 때마다 그 에이전트에 새 대화가 하나씩 만들어지고, 결과는 그 대화에 남습니다.

에이전트 편집 화면의 스케줄 탭​

사이드바에서 에이전트를 고른 뒤 에이전트 설정을 누르면 에이전트 편집 화면이 열립니다. 오른쪽 탭 줄의 스케줄을 누르면 이 에이전트의 스케줄 목록과 스케줄 추가 버튼이 보입니다. 스케줄이 없으면 "등록된 스케줄이 없습니다"가 표시됩니다.

스케줄 추가를 누르면 입력 칸이 열립니다. 실행 시각은 폼에서 분, 시, 일, 월, 요일을 골라 정하거나, 스케줄 표현식에서 직접 입력합니다. 폼에서 고른 값은 미리보기에 스케줄 표현식으로 보입니다. 타임존에는 처음에 내 브라우저의 시간대(예: Asia/Seoul)가 들어 있습니다. 실행 메시지에는 정해진 시각에 에이전트에게 보낼 메시지를 적습니다. 비어 있으면 만들 수 없고 최대 10,000자입니다. 다 넣고 생성을 누르면 "스케줄이 생성되었습니다" 알림이 뜨고 목록에 추가됩니다.

스케줄 추가

번호메뉴기능이런 때 사용하세요
1스케줄 탭이 에이전트의 자동 실행 스케줄을 관리합니다. 위쪽에 "에이전트 자동 실행 스케줄을 관리합니다"가 보입니다.주간 업무 보고서 도우미에 걸어 둔 스케줄을 확인할 때
2스케줄 추가새 스케줄을 입력하는 칸을 열고 닫습니다.매주 금요일 실행을 새로 걸 때
3폼 / 스케줄 표현식실행 시각을 정하는 방법을 고릅니다. 폼은 목록에서 고르고, 스케줄 표현식은 직접 입력합니다.목록으로 고르기 어려운 시각을 직접 적을 때
4요일폼에서 실행 요일을 고릅니다. 위의 분, 시, 일, 월도 같은 방식으로 고릅니다. 매번 실행하려면 시에서 매시, 일에서 매일, 월에서 매월, 요일에서 매일을 고릅니다.금요일 17시 0분을 고를 때

스케줄 추가 입력

번호메뉴기능이런 때 사용하세요
1미리보기고른 시각을 스케줄 표현식으로 보여 줍니다. 금요일 17시 0분은 "0 17 * * 5"입니다.고른 값이 원하는 시각인지 확인할 때
2타임존실행 시각의 기준 시간대입니다. 처음에는 내 브라우저의 시간대(예: Asia/Seoul)가 들어 있습니다.해외 출장 중에도 한국 시각 기준으로 실행되게 할 때
3실행 메시지정해진 시각에 에이전트에게 보낼 메시지입니다. 비어 있으면 만들 수 없습니다. 최대 10,000자입니다.매주 같은 형식으로 보고서를 받도록 요청 내용을 적을 때
4생성스케줄을 저장합니다. "스케줄이 생성되었습니다" 알림이 뜨고 목록에 추가됩니다.입력을 마치고 스케줄을 걸 때

스케줄 표현식 탭에서는 "분 시 일 월 요일" 순서로 직접 입력합니다. 입력란 아래에 "분 시 일 월 요일 (예: 0 9 * * * = 매일 오전 9시)" 안내가 보입니다. 요일은 일요일이 0, 월요일이 1, 금요일이 5입니다.

따라 해 보기​

AI혁신팀 김그루 사원은 매주 금요일 17시에 주간 업무 보고서 초안을 받아 퇴근 전에 검토합니다.

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 에이전트 설정을 누릅니다.

  2. 오른쪽 탭 줄에서 스케줄을 누르고 스케줄 추가를 누릅니다.

  3. 폼 탭에서 분은 0, 시는 17, 일은 매일, 월은 매월, 요일은 금요일을 고릅니다.

  4. 미리보기가 "0 17 * * 5"인지 확인합니다.

  5. 타임존이 Asia/Seoul인지 확인합니다. 다르면 지우고 Asia/Seoul을 입력합니다.

  6. 실행 메시지에 아래 문장을 붙여 넣습니다.

    프롬프트: 파일 탭에 올려 둔 이번 주 업무 메모를 읽고 주간 업무 보고서 초안을 작성해 주세요. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓰고, 메모에 없는 내용은 만들지 말고 [확인 필요]로 표시해 주세요.

  7. 생성을 누르고 목록에 스케줄이 추가됐는지 확인합니다.

스케줄 목록 읽기와 관리​

스케줄을 만들면 스케줄 탭 목록에 카드가 생깁니다. 카드마다 실행 시각과 타임존(예: "0 17 * * 5 (Asia/Seoul)"), 메시지 앞부분, 다음 실행 시각과 실행 횟수가 보이고, 실행된 적이 있으면 상태로 최근 실행 결과가 붙습니다. 오른쪽 버튼으로 고치거나 끄거나 지웁니다.

  • 수정(연필): 스케줄 수정 창에서 실행 시각, 타임존, 실행 메시지를 바꾸고 변경 사항 저장을 누릅니다.
  • 비활성화 / 활성화(전원): 스케줄을 끄고 켭니다. 꺼진 스케줄은 흐리게 표시되고 실행되지 않습니다.
  • 삭제(휴지통): 스케줄을 지웁니다. 이 탭에서는 확인 창 없이 바로 지워집니다.

스케줄 목록

번호메뉴기능이런 때 사용하세요
1스케줄 표현식과 타임존"0 17 * * 5 (Asia/Seoul)"처럼 실행 시각과 기준 시간대입니다.실행 시각이 맞게 저장됐는지 볼 때
2실행 메시지실행 때 보낼 메시지 앞부분입니다.여러 스케줄 중 어떤 요청인지 구별할 때
3다음 실행다음에 실행될 날짜와 시각입니다.이번 주 금요일 17시에 실행되는지 확인할 때
4실행 횟수지금까지 실행된 횟수입니다. 실행된 적이 있으면 옆에 상태로 최근 실행 결과가 붙습니다.지난주 금요일에 실제로 실행됐는지 확인할 때

스케줄 카드 버튼

번호메뉴기능이런 때 사용하세요
1수정(연필)스케줄 수정 창을 엽니다. 실행 시각, 타임존, 실행 메시지를 바꾸고 변경 사항 저장을 누릅니다.보고 시각을 16시로 앞당길 때
2비활성화 / 활성화(전원)스케줄을 끄고 켭니다. 꺼진 스케줄은 흐리게 표시되고 실행되지 않습니다.휴가 주간에 잠시 멈출 때
3삭제(휴지통)스케줄을 지웁니다. 이 탭에서는 확인 창 없이 바로 지워집니다.더 쓰지 않는 스케줄을 정리할 때

팁: 휴가처럼 잠시 멈출 때는 지우지 말고 비활성화를 누르세요. 다시 활성화하면 같은 설정으로 이어서 실행됩니다.

작업 화면의 스케줄 작업 탭​

여러 에이전트에 스케줄을 걸어 두었다면 사이드바 위쪽 더 보기 > 작업을 눌러 한곳에서 봅니다. 작업 화면의 스케줄 작업 탭에 등록된 모든 스케줄이 모입니다. 스케줄이 없으면 "등록된 스케줄 작업이 없습니다"와 "에이전트 편집 패널에서 스케줄을 생성하세요"가 보입니다. 새 스케줄은 이 탭이 아니라 에이전트 편집 화면 스케줄 탭에서 만듭니다.

카드에는 스케줄 표현식과 타임존, 에이전트 식별 번호 끝 8자리와 실행 메시지, 활성 또는 비활성 상태, 다음 실행, 실행 횟수가 보입니다. 에이전트 이름은 카드에 표시되지 않으니 카드를 눌러 상세 창에서 확인합니다. 수정, 켜기·끄기, 삭제는 에이전트 편집 화면의 스케줄 탭과 같은 동작이지만, 여기서 삭제를 누르면 "이 스케줄을 삭제하시겠습니까?" 확인 창이 먼저 열립니다.

스케줄 작업 탭

번호메뉴기능이런 때 사용하세요
1스케줄 작업 탭등록된 모든 스케줄 작업을 보여 줍니다.내가 건 스케줄을 에이전트 구분 없이 한 번에 볼 때
2스케줄 표현식과 타임존실행 시각과 기준 시간대입니다.금요일 17시 스케줄을 찾을 때
3에이전트 표시와 메시지에이전트 식별 번호 끝 8자리와 실행 메시지입니다. 에이전트 이름은 표시되지 않으니, 카드를 눌러 상세 창 위쪽의 에이전트 이름으로 확인합니다.어느 에이전트의 스케줄인지 구별할 때
4상태, 다음 실행, 실행 횟수활성 또는 비활성 상태, 다음 실행 시각, 실행 횟수입니다. 실행된 적이 있으면 최근 상태도 붙습니다.꺼 둔 스케줄이 있는지 확인할 때

카드 오른쪽의 수정, 켜기·끄기, 삭제 버튼은 에이전트 편집 화면의 스케줄 탭과 같은 동작입니다. 여기서 삭제를 누르면 "이 스케줄을 삭제하시겠습니까?" 확인 창이 먼저 열립니다.

카드를 누르면 상세 창이 열립니다. 위쪽에 에이전트 이름과 설명이 보이고, 그 아래에 모델과 스케줄 정보(스케줄, 타임존, 메시지, 실행 횟수)가 이어집니다. 에이전트에 도구, 미들웨어, 스킬이 연결되어 있으면 그 목록도 함께 보입니다. 에이전트로 이동을 누르면 그 에이전트 화면으로 갑니다.

스케줄 상세

번호메뉴기능이런 때 사용하세요
1에이전트 이름과 설명이 스케줄로 실행될 에이전트입니다.카드의 식별 번호가 어느 에이전트인지 확인할 때
2모델스케줄 실행에 쓰일 모델입니다. 도구, 미들웨어, 스킬이 연결된 에이전트라면 그 목록도 여기에 함께 보입니다.실행에 필요한 도구가 빠지지 않았는지 볼 때
3메시지스케줄 정보의 실행 메시지 전문입니다. 같은 칸에 스케줄 표현식, 타임존, 실행 횟수도 함께 보입니다.메시지 전문을 확인할 때
4에이전트로 이동그 에이전트 화면으로 이동합니다.결과 대화를 보거나 지침을 고치러 갈 때

작업 기록에서 실행 결과 확인​

작업 화면의 첫 탭 작업 기록에는 스케줄로 실행된 작업과 백그라운드 모드로 직접 맡긴 작업이 함께 쌓입니다. 목록은 시간, 제목, 상태, 에이전트 열로 나뉘고, 제목을 누르면 그 작업의 결과 대화가 열립니다. 스케줄로 실행된 작업은 실행 메시지가 제목으로 쓰이고, 출처 필터의 스케줄로 따로 걸러 볼 수 있습니다.

  • 상태 필터(전체, 진행중, 완료됨), 출처 필터(전체, 수동, 스케줄), 기간 필터(전체, 1시간, 오늘, 이번 주, 날짜 선택)로 목록을 거릅니다. 날짜 선택은 달력에서 날짜를 고르고, 날짜 초기화로 되돌립니다.
  • 상태는 대기, 진행중, 완료, 실패, 취소됨, 시간 초과, 중단됨 중 하나입니다. 진행 중이면 취소 버튼이 함께 보입니다.
  • 기록에서 삭제(휴지통)는 작업을 목록에서만 지웁니다. 결과 대화는 에이전트의 채팅 목록에 그대로 남습니다.
  • 정리를 누르면 삭제된 에이전트 정리와 대화 히스토리 전체 삭제 메뉴가 열립니다. 완료된 작업이 없으면 누를 수 없습니다.

작업 기록

번호메뉴기능이런 때 사용하세요
1작업 기록 탭백그라운드로 실행된 작업 목록입니다. 화면을 열면 이 탭이 먼저 보입니다.이번 주에 실행된 작업을 한눈에 볼 때
2상태 필터(전체, 진행중, 완료됨)작업을 진행 상태로 거릅니다. 진행 중인 작업이 있으면 진행중 옆에 개수가 붙습니다.아직 끝나지 않은 작업만 골라 볼 때
3출처 필터(전체, 수동, 스케줄)직접 맡긴 작업과 스케줄로 실행된 작업을 나눠 봅니다.금요일 스케줄 실행만 보려고 스케줄을 고를 때
4기간 필터(전체, 1시간, 오늘, 이번 주, 날짜 선택)작업이 시작된 시점으로 거릅니다. 날짜 선택은 달력에서 날짜를 고르고, 날짜 초기화로 되돌립니다.지난 금요일에 실행된 작업만 찾을 때

작업 기록 목록

목록은 시간, 제목, 상태, 에이전트 순으로 열이 나뉩니다.

번호메뉴기능이런 때 사용하세요
1제목작업의 제목입니다. 스케줄로 실행된 작업은 실행 메시지가 제목으로 쓰입니다. 누르면 결과 대화가 열립니다.금요일 보고서 초안을 바로 열어 볼 때
2상태대기, 진행중, 완료, 실패, 취소됨, 시간 초과, 중단됨 중 하나입니다. 진행 중이면 취소 버튼이 함께 보입니다. 그림의 작업은 실패로 끝났습니다.실행이 실패했는지 확인할 때
3기록에서 삭제(휴지통)이 작업을 작업 기록에서 지웁니다. 결과 대화는 에이전트의 채팅 목록에 그대로 남습니다.확인을 마친 작업을 목록에서 정리할 때
4정리삭제된 에이전트 정리와 대화 히스토리 전체 삭제 메뉴를 엽니다. 완료된 작업이 없으면 누를 수 없습니다.분기 말에 오래된 작업 기록을 한꺼번에 정리할 때

작업 상태가 실패나 시간 초과로 끝났다면 결과 대화를 열어 어디서 멈췄는지 보고, 에이전트 편집 화면의 테스트 탭에서 같은 메시지를 보내 원인을 찾습니다. 상태별 의미와 오류를 읽는 방법은 모니터링과 실행 상태 확인에 있습니다.

백그라운드 모드로 요청 맡기기​

스케줄 없이 지금 바로 맡기되 결과를 기다리지 않으려면 입력란 아래 오른쪽의 백그라운드 모드(시계 아이콘)를 켜고 보냅니다. 누를 때마다 켜지고 꺼지며, 마우스를 올리면 백그라운드 모드 (ON) 또는 **백그라운드 모드 (OFF)**로 지금 상태가 보입니다. 처음에는 꺼져 있고, 켜 두면 이 화면에서 보내는 메시지마다 적용됩니다. 켠 채로 전송을 누르면 "백그라운드 실행 시작" 알림과 "요청이 백그라운드에서 처리되고 있습니다."가 잠깐 뜹니다. 백그라운드 모드로 보낸 요청은 화면을 떠나도 계속 실행되고, 작업 기록에 수동 작업으로 남습니다.

백그라운드 모드로 요청 보내기

번호메뉴기능이런 때 사용하세요
1첨부 파일파일 업로드로 올린 파일의 이름과 형식이 입력창 위에 표시됩니다.보고에 쓸 메모 파일이 제대로 붙었는지 보내기 전에 확인할 때
2메시지 입력창요청 내용을 적습니다.보고서 항목과 형식을 정해 적을 때
3백그라운드 모드(시계)누를 때마다 켜지고 꺼집니다. 마우스를 올리면 백그라운드 모드 (ON) 또는 **백그라운드 모드 (OFF)**로 지금 상태가 보입니다. 처음에는 꺼져 있고, 켜 두면 이 화면에서 보내는 메시지마다 적용됩니다.답을 기다리지 않고 바로 다른 일을 하려 할 때
4전송요청을 보냅니다. 백그라운드 모드가 켜져 있으면 "백그라운드 실행 시작" 알림과 "요청이 백그라운드에서 처리되고 있습니다."가 잠깐 뜹니다.첨부와 요청을 확인한 뒤 보낼 때

따라 해 보기​

금요일 오후, 스케줄 시각 전에 보고서를 미리 받아 보고 싶을 때 백그라운드 모드로 맡깁니다.

  1. 사이드바에서 주간 업무 보고서 도우미를 누르고 이 에이전트와 새 대화를 누릅니다.

  2. 파일 업로드를 눌러 김그루_주간업무메모_1106.md를 올립니다.

  3. 입력란 아래 오른쪽의 백그라운드 모드(시계 아이콘)를 눌러 켭니다. 마우스를 올려 **백그라운드 모드 (ON)**인지 확인합니다.

  4. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다.

    프롬프트: 첨부한 이번 주 업무 메모로 주간 업무 보고서 초안을 작성해 주세요. 제목, 이번 주 핵심 성과 3줄, 업무별 진행 표(업무, 진행 내용, 수치, 상태), 이슈와 조치, 다음 주 계획, 확인 필요 순서로 쓰고, 메모에 없는 내용은 만들지 말고 [확인 필요]로 표시해 주세요.

  5. "백그라운드 실행 시작" 알림을 확인한 뒤 다른 업무를 봅니다.

  6. 사이드바 더 보기 > 작업에서 작업 상태가 완료로 바뀌면 제목을 눌러 결과를 읽습니다. 진행 중인 작업이 있는 동안에는 작업 메뉴 옆에 개수가 표시됩니다.

  7. 다 쓴 뒤에는 백그라운드 모드를 다시 눌러 끕니다. 켜 둔 채로 두면 다음 메시지도 백그라운드로 실행됩니다.

백그라운드 작업 완료

번호메뉴기능이런 때 사용하세요
1수동직접 맡긴 작업만 남깁니다.스케줄 실행과 섞이지 않게 내가 맡긴 작업만 볼 때
2제목보낸 요청의 앞부분이 제목으로 쓰입니다. 누르면 결과 대화가 열립니다.방금 맡긴 보고서 초안을 열어 볼 때
3상태완료로 바뀌었는지 확인합니다.결과를 열기 전에 작업이 끝났는지 볼 때

결과 대화에서 보고서의 숫자를 메모와 대조합니다. 이 예시에서는 파일럿 사용자 문의 7건, 교육 참석 24명, 댓글 답변 5건, 다음 주 계획(경영지원팀 확대 준비, 교안 개정 착수)이 메모와 같아야 합니다.

팁: 입력창에서 / 로 부른 커맨드는 백그라운드 모드를 켜 두어도 일반 대화로 전송되어 작업 기록에 남지 않습니다. 커맨드는 커맨드와 재사용에서 설명합니다.

정리​

  • 스케줄은 내 에이전트의 에이전트 편집 화면 스케줄 탭에서 만들고, 작업 > 스케줄 작업 탭에서 모아 관리합니다.
  • 스케줄은 메시지만 보냅니다. 매주 바뀌는 자료는 에이전트 편집 화면 파일 탭에 올려 두고 메시지에서 그 파일을 읽으라고 적습니다.
  • 스케줄 실행과 백그라운드 모드로 맡긴 요청은 모두 작업 기록에 남고, 출처 필터의 스케줄과 수동으로 나눠 봅니다.

  • 사례: 주간 업무 보고서 작성 — 주간 업무 보고서 도우미를 만들고 보고서를 받는 전체 흐름
