Deep Agent Builder 실습 4: 캔버스로 PPT·Word·표 산출물 받기

이 실습은 새 에이전트를 직접 만들고 문서작성 에이전트로 바꾼 뒤, 한 대화에서 보고용 PPT, 요약 Word, 집계 엑셀 세 가지 파일을 받아 캔버스에서 살펴보고 내려받는 과정을 손으로 따라 합니다. 예시는 브레인크루 AI혁신팀 김그루 사원이 3분기 영업실적 보고서 초안과 판매 데이터를 붙여 팀장 보고 자료를 한 번에 준비하는 상황입니다. 캔버스 화면 하나하나의 설명은 캔버스로 문서·PPT·표 만들기에 있으므로, 이 페이지는 처음부터 끝까지 직접 눌러 보는 순서에 집중합니다.

이 페이지에서 할 수 있는 일

  • 새 에이전트를 만들고 설정 탭에서 에이전트 모드를 문서작성 에이전트로 바꿉니다.
  • 자료 파일 두 개를 붙여 PPT, Word, 엑셀 세 산출물을 한 대화에서 차례로 받습니다.
  • 결과 카드로 캔버스를 열고, 탭 전환, 넓게보기와 나란히보기, 캔버스 접기, 폭 조절, 미리보기 도구를 써 봅니다.
  • 시트에서 셀의 수식과 값을 복사하고, 범위를 끌어 합계와 평균을 봅니다.
  • 문서 요소 선택으로 슬라이드 한 장의 문구만 고치고, 형식별로 내보냅니다.

목표​

항목내용
만들 것문서작성 에이전트 "분기 보고 자료 도우미"

걸리는 시간에이전트 만들기 5분, 세 산출물 생성 3분 안팎, 캔버스 조작과 내보내기 10분

준비물​

파일내용형식
3분기_영업실적_보고서_초안.docx브레인크루 2026년 3분기 영업 실적 보고서 초안(가상). 요약, 지역별 실적(서울·부산·대전), 제품별 동향, 4분기 계획, 검토 요청 다섯 부분이며 수치는 "판매 데이터 확정 후 갱신 예정"으로 비어 있습니다.docx
브레인크루_판매데이터_2026.xlsx2026년 1~9월 주문 396건(가상). 판매내역 시트(주문일, 주문번호, 지역, 채널, 담당자, 제품, 수량, 단가, 매출액), 월별요약 시트, 목표 시트xlsx

대화 화면의 파일 업로드로는 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm 파일을 같은 방법으로 붙일 수 있습니다. 보고서 초안 대신 AI업무혁신_추진현황.pptx 같은 발표자료를 붙여 같은 연습을 해도 됩니다.

1단계. 새 에이전트 만들기​

새 에이전트 만들기

번호메뉴입력하거나 고를 값
1에이전트 이름분기 보고 자료 도우미
2에이전트 설명 (선택)분기 실적 자료를 받아 보고용 PPT, 요약 Word, 집계 엑셀을 만들어 캔버스에 올립니다.
3확인누르면 새 에이전트의 에이전트 편집 화면이 열립니다.
  1. 사이드바 새 에이전트를 누릅니다.
  2. 홈 화면 아래쪽 에이전트 직접 만들기를 누릅니다.
  3. 새 에이전트 만들기 창에 이름과 설명을 적고 확인을 누릅니다.

2단계. 지침을 쓰고 문서작성 에이전트로 바꾸기​

지침과 에이전트 모드

번호메뉴입력하거나 고를 값
1지침아래 지침 전문을 붙여 넣습니다.
2설정오른쪽 패널 맨 끝 탭을 누릅니다.
3문서작성 에이전트에이전트 모드에서 고릅니다. 고르는 즉시 저장됩니다.

지침 입력란에 붙여 넣을 내용은 다음과 같습니다.

프롬프트: 너는 브레인크루 AI혁신팀의 분기 보고 자료 도우미야. 사용자가 첨부한 보고서 초안과 판매 데이터만 근거로 보고 자료를 만든다.

  1. PPT는 5장 이내로 만들고, 장마다 제목에 핵심 메시지 한 문장, 본문은 3~5줄 개조식으로 쓴다.
  2. 요약 Word는 1쪽 분량으로 요약, 지역별 실적, 4분기 계획 순서로 쓴다.
  3. 엑셀 표에는 단위(원)를 붙이고 합계는 수식으로 넣는다.
  4. 수치는 판매 데이터에서 계산한 값만 쓰고, 자료에 없는 값은 "확인 필요"로 적는다.
  5. 파일을 만들면 캔버스에 게시하고, 답변에는 무엇을 만들었는지 세 줄 이내로 알려 준다.
  1. 지침 입력란에 위 지침을 붙여 넣고 헤더의 저장을 누릅니다.
  2. 오른쪽 패널 설정 탭을 누르고 에이전트 모드에서 문서작성 에이전트를 고릅니다.
  3. 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 한 번 더 눌러 바뀐 모드를 현재 버전에 기록합니다.
  4. 사이드바 이 에이전트와 새 대화를 누릅니다.

3단계. 자료를 붙이고 PPT 요청하기​

자료 첨부와 PPT 요청

번호메뉴입력하거나 고를 값
1첨부 파일3분기_영업실적_보고서_초안.docx(DOCX)
2첨부 파일브레인크루_판매데이터_2026.xlsx(XLSX)
3메시지 입력란아래 PPT 요청 프롬프트
4전송누르면 요청이 시작됩니다.

프롬프트: 첨부한 3분기 영업실적 보고서 초안과 판매 데이터로 팀장 보고용 3분기 실적 PPT를 5장으로 만들어 주세요. 먼저 판매내역 시트의 매출액을 Python으로 합산해 7~9월 지역별 매출 표를 답변에 보여 주고, 그 수치로 표지, 3분기 요약, 지역별 매출 표, 제품별 동향, 4분기 계획 순서의 PPT를 만들어 캔버스에 게시해 주세요.

  1. 입력란 아래 파일 업로드(클립)를 눌러 두 파일을 함께 고릅니다. 입력창 위에 파일 이름과 형식이 붙습니다.

  2. 위 프롬프트를 붙여 넣고 전송을 누릅니다.

  3. 에이전트가 표만 보여 주고 "이제 PPT를 제작해 게시하겠습니다"처럼 멈추면, 같은 대화에 아래처럼 보냅니다.

    프롬프트: 좋아요. 이 수치로 PPT를 만들어 캔버스에 게시해 주세요.

수치를 먼저 표로 보여 달라고 하면, PPT에 들어갈 숫자를 만들기 전에 한 번 검토할 수 있습니다. 이 실습에서는 첫 답에 경기 24,042,000원, 광주 28,710,000원, 대구 32,947,000원, 대전 44,357,000원, 부산 53,868,000원, 서울 18,842,000원 표가 나왔습니다.

4단계. 결과 카드로 캔버스 열기​

결과 카드와 캔버스 열기

번호메뉴기능이런 때 사용하세요
1문서를 캔버스에 게시에이전트가 파일을 캔버스에 올린 실행 단계입니다. 그 뒤에 문서 내보내기 단계가 이어집니다.파일이 언제 만들어졌는지 확인할 때
2결과 카드파일 이름 분기실적_보고_PPT.pptx와 프레젠테이션 · 캔버스에서 열기가 적혀 있습니다. 누르면 캔버스가 이 문서로 열립니다.방금 만든 PPT를 열 때
3캔버스 열기화면 오른쪽 끝 버튼입니다. 아래 숫자는 이 채팅의 캔버스에 올라온 문서 수입니다.카드를 찾지 않고 캔버스를 다시 열 때
  1. 실행 단계가 끝나고 답변 끝에 프레젠테이션 카드가 생길 때까지 기다립니다. 이 실습에서는 두 번째 메시지를 보내고 30초 안에 카드가 생겼습니다.
  2. 카드를 누릅니다. 캔버스는 저절로 열리지 않으므로 꼭 카드나 캔버스 열기를 누릅니다.

5단계. 캔버스 접기와 폭 조절​

나란히 보기 상태의 캔버스

번호메뉴기능이런 때 사용하세요
1캔버스 접기캔버스를 닫고 대화만 넓게 봅니다. 다시 열 때는 캔버스 열기를 누릅니다.수정 요청을 길게 쓸 때
2넓게보기캔버스를 화면 전체로 펼칩니다.슬라이드의 작은 글씨를 크게 볼 때
3캔버스 폭 조절대화와 캔버스 사이 경계선입니다. 끌거나, 선택한 뒤 방향키로 폭을 바꿉니다. 바꾼 비율은 다음에 열 때도 유지됩니다.대화를 보면서 캔버스를 조금 더 넓게 쓸 때
  1. 캔버스 접기를 눌러 캔버스를 닫았다가, 오른쪽 끝 캔버스 열기로 다시 엽니다.
  2. 대화와 캔버스 사이 경계선을 왼쪽으로 끌어 캔버스를 넓힙니다.
  3. 넓게보기를 누릅니다.

6단계. 넓게 보며 장마다 살펴보기​

넓게보기와 미리보기 도구

번호메뉴기능이런 때 사용하세요
1나란히보기넓게보기 상태에서 같은 자리에 보이는 버튼입니다. 누르거나 Esc 키를 누르면 대화와 나란히 보는 화면으로 돌아갑니다.다음 요청을 보내러 대화로 돌아갈 때
2썸네일왼쪽 장 목록을 보이거나 감춥니다. 목록의 장을 누르면 그 장으로 갑니다.5장 가운데 원하는 장으로 바로 갈 때
3페이지 전체 맞춤한 장이 화면에 다 들어오게 맞춥니다. 왼쪽의 축소, 기준 배율 100%, 확대, 너비에 맞춤도 같은 줄에 있습니다.표가 있는 장을 한눈에 볼 때
4페이지로 이동지금 보는 장 번호(예: 3 / 5)입니다. 양옆 화살표로 이전·다음 장으로 갑니다.장 번호로 위치를 확인할 때
  1. 왼쪽 썸네일에서 3장을 눌러 "7~9월 지역별 매출 현황" 표를 봅니다.
  2. 표의 숫자가 3단계 답변의 표와 같은지 맞춰 봅니다.
  3. 2장과 4장도 열어, 초안에 없는 내용이 들어가지 않았는지 읽습니다. 이 실습에서는 2장 첫 줄에 자료에 없는 "3분기 전체 매출 전년 동기 대비 증가"가 들어가 있어 10단계에서 고칩니다.
  4. 나란히보기를 눌러 대화로 돌아옵니다.

7단계. 요약 Word 받고 탭 오가기​

문서 탭 전환

번호메뉴기능이런 때 사용하세요
1결과 카드분기실적_보고_요약.docx와 문서 · 캔버스에서 열기가 적힌 카드입니다.새로 만든 Word를 열 때
2PPT 탭앞에서 만든 분기실적_보고_PPT.pptx 탭입니다. 누르면 PPT로 돌아갑니다. 옆의 X는 탭 닫기입니다.PPT와 Word의 수치를 비교할 때
3Word 탭지금 보고 있는 분기실적_보고_요약.docx 탭입니다.Word 미리보기로 돌아올 때

프롬프트: 같은 자료로 팀장님께 드릴 1쪽짜리 3분기 실적 요약 Word 문서도 만들어 캔버스에 게시해 주세요. 요약, 지역별 실적 표, 4분기 계획 순서로 쓰고, 지역별 실적은 PPT와 같은 수치를 써 주세요.

  1. 같은 대화에 위 프롬프트를 보냅니다. 이 실습에서는 40초 안에 문서 카드가 생겼습니다.
  2. 카드를 누르면 캔버스 위쪽에 탭이 두 개가 됩니다.
  3. PPT 탭과 Word 탭을 번갈아 눌러, Word의 지역별 표가 PPT 3장과 같은지 봅니다.

8단계. 엑셀 표 받고 셀 수식 확인하기​

프롬프트: 마지막으로 판매 데이터에서 7~9월 지역별·월별 매출을 집계한 엑셀 표를 만들어 캔버스에 게시해 주세요. 시트는 하나, 열은 지역, 7월, 8월, 9월, 3분기 합계로 하고, 3분기 합계 열과 맨 아래 합계 행은 SUM 수식으로 넣어 주세요. 단위는 원입니다.

시트의 선택한 셀과 수식

번호메뉴기능이런 때 사용하세요
1고른 셀경기의 3분기 합계 칸(E2)입니다. 누르면 위쪽 선택한 셀에 E2가 나옵니다.합계가 어떻게 계산됐는지 볼 칸을 고를 때
2수식고른 셀의 수식 =SUM(B2:D2)입니다. 오른쪽 값 칸에는 파일에 저장된 결과가 나옵니다.합계 칸이 수식으로 들어갔는지 확인할 때
3값 복사고른 셀의 값을 복사합니다.숫자를 메일이나 메모에 붙일 때
4수식 복사고른 셀의 수식을 복사합니다.같은 수식을 내 엑셀에 옮길 때
  1. 같은 대화에 위 프롬프트를 보냅니다. 이 실습에서는 30초 안에 스프레드시트 카드가 생기고 캔버스 탭이 세 개가 되었습니다.
  2. 시트 아래쪽을 보려면 넓게보기를 누릅니다.
  3. 3분기 합계 열의 첫 칸(E2)을 누릅니다. 수식에 =SUM(B2:D2)가 보이고, 값에는 "저장된 결과가 비어 있거나 없습니다"가 보입니다. 에이전트가 수식만 넣고 계산 결과를 저장하지 않았기 때문이며, 내려받아 엑셀에서 열면 계산됩니다.
  4. 7월 칸(B2)을 누르면 수식 없이 값에 8898000이 보입니다. 값 복사를 눌러 복사해 봅니다.

9단계. 범위를 끌어 합계와 평균 보기​

범위 합계와 평균

번호메뉴기능이런 때 사용하세요
1고른 범위B2부터 D7까지, 여섯 지역의 7·8·9월 매출 칸입니다.여러 칸의 합계를 바로 보고 싶을 때
2범위 요약"개수 · 합계 · 평균"이 나옵니다. 저장된 숫자 값 기준이며 수식 결과는 빼고 셉니다.엑셀을 내려받지 않고 총합을 검산할 때
  1. 경기 7월 칸(B2)을 누른 채 서울 9월 칸(D7)까지 끕니다.
  2. 아래쪽 범위 요약을 읽습니다. 이 실습에서는 "개수 18 · 합계 202,766,000 · 평균 11,264,777.7778"이 나왔습니다. 합계는 3단계 표의 여섯 지역을 더한 값과 같습니다.
  3. 브라우저 창 높이가 낮아 범위 요약이 가려지면 넓게보기로 보거나 창을 키웁니다.
  4. 나란히보기를 눌러 대화로 돌아옵니다.

10단계. 한 장만 골라 고치기​

캔버스는 읽기 전용입니다. 캔버스 안에서 글자를 고칠 수는 없고, 고칠 부분을 문서 요소 선택으로 골라 대화로 요청합니다.

문서 요소 선택

번호메뉴기능이런 때 사용하세요
1문서 요소 선택선택 모드를 켭니다. 켜지면 옆에 "요소를 선택하면 다음 메시지에 첨부됩니다."가 보입니다.고칠 곳을 말로 설명하기 어려울 때
2고른 요소2장 첫 항목 "3분기 전체 매출 전년 동기 대비 증가" 글상자입니다. 누르면 테두리가 강조되고 첨부됨으로 바뀝니다.한 장의 한 문구만 바꿀 때
3선택한 문서 요소입력창 위에 Slide 2 · TextBox 6처럼 "장 번호 · 요소 이름" 칩이 붙습니다. 칩의 X(선택 삭제)로 뺍니다.잘못 고른 요소를 뺄 때
4메시지 입력란고른 요소를 어떻게 바꿀지 적습니다.바꿀 문구를 정확히 적을 때

프롬프트: 선택한 문구는 자료에 없는 전년 비교입니다. "3분기 매출 2억 276만 원, 전 분기 대비 3.1% 증가"로 바꿔 주세요. 다른 장은 그대로 둡니다.

  1. 캔버스 위쪽 PPT 탭을 누르고 2장으로 갑니다.
  2. 문서 요소 선택을 누르고, 2장 첫 항목을 누릅니다.
  3. 입력창 위에 Slide 2 · TextBox 6 칩이 붙었는지 보고 위 프롬프트를 보냅니다. 3.1%는 2분기 합계 196,702,000원과 9단계의 3분기 합계 202,766,000원으로 계산한 값입니다.

고친 결과 확인

번호메뉴기능이런 때 사용하세요
1새 결과 카드수정 요청의 답변 끝에 생긴 새 프레젠테이션 카드입니다. 앞 요청의 카드를 누르면 고치기 전 문서가 열립니다.고치기 전과 후를 비교할 때
2고친 문구2장 첫 항목이 "3분기 매출 2억 276만 원, 전 분기 대비 3.1% 증가"로 바뀌었습니다.요청이 실제로 반영됐는지 볼 때
  1. 답변의 실행 단계에 캔버스 파일 가져오기, 문서 구조 확인, 슬라이드 텍스트 채우기, 문서를 캔버스에 게시가 이어지는지 봅니다.
  2. 새 카드를 눌러 2장을 직접 확인합니다. 답변 문장만 믿지 말고 캔버스에서 꼭 확인합니다.

11단계. 형식별로 내보내기​

내보내기 메뉴

번호메뉴기능이런 때 사용하세요
1내보내기내려받기 메뉴를 엽니다. 메뉴 항목은 지금 고른 탭의 문서 종류에 따라 달라집니다.완성본을 파일로 받을 때
2원본 다운로드에이전트가 만든 파일을 그대로 받습니다.내 PC의 PowerPoint·Word·Excel에서 고쳐 쓸 때
3PDF 형식으로 내보내기PDF로 바꿔 받습니다. 바로 위 PPTX 형식으로 내보내기는 PowerPoint 파일로 바꿔 받습니다.팀장님께 수정할 수 없는 파일로 보낼 때
  1. PPT 탭에서 내보내기 > PDF 형식으로 내보내기를 누릅니다. 이 실습에서는 5쪽짜리 분기실적_보고_PPT.pdf를 받았고, 2쪽에 10단계에서 고친 문구가 들어 있었습니다.
  2. Word 탭에서 내보내기를 누르면 원본 다운로드, DOCX 형식으로 내보내기, PDF 형식으로 내보내기가 나옵니다. 원본 다운로드로 분기실적_보고_요약.docx를 받습니다.
  3. 엑셀 탭에서 내보내기를 누르면 원본 다운로드와 XLSX 형식으로 내보내기만 나옵니다. 엑셀은 PDF로 내보내지 않습니다.

원본 형식별로 내보내기 메뉴에 나오는 형식은 다음과 같습니다.

원본 형식내보낼 수 있는 형식
에이전트가 슬라이드 형식으로 게시한 문서PPTX, PDF
에이전트가 표 형식으로 게시한 문서XLSX

모든 형식에서 메뉴 첫 항목은 원본 다운로드입니다.

설정값 표​

설정위치이 실습에서 고른 값기본값과 의미
에이전트 모드에이전트 편집 화면 > 설정 탭문서작성 에이전트기본은 일반 에이전트입니다. 문서작성 에이전트는 모든 대화를 문서 작성 모드로 실행해 Word·PowerPoint·Excel 파일을 만들고 캔버스에 게시합니다. 고르는 즉시 저장되고, 헤더 저장을 눌러야 현재 버전에 기록됩니다.
지침에이전트 편집 화면 > 폼 > 지침2단계 지침 전문기본은 빈 값입니다. 장 수, 문서 순서, 단위, 근거 규칙을 적어 두면 요청마다 같은 형식으로 만듭니다.
모델에이전트 편집 화면 > 폼 > 모델바꾸지 않음(GPT-4.1)새 에이전트는 기본 모델로 만들어집니다.
캔버스 폭대화 화면 > 캔버스 폭 조절조금 넓힘처음은 나란히보기입니다. 바꾼 비율은 다음에 열 때도 유지됩니다.

결과​

한 대화의 캔버스에 탭 세 개가 생기면 성공입니다.

  • 분기실적_보고_PPT.pptx: 표지 "2026년 3분기 영업 실적 보고", 2장 요약, 3장 "7~9월 지역별 매출 현황" 표(부산 53,868,000원이 가장 크고 서울 18,842,000원이 가장 작음), 4장 제품별 동향, 5장 4분기 계획(파트너 교육 프로그램 확대, 온라인 채널 프로모션, 대전 집중 방문)
  • 분기실적_보고_요약.docx: 제목 "2026년 3분기 영업 실적 요약", 요약 4줄, "3분기 실적 및 시사점" 문단, 2026년 3분기 지역별 매출 표, 4분기 영업 계획 세 줄
  • 분기_지역별_월별매출.xlsx: 시트 3분기_지역별_월별매출, 열 지역·7월(원)·8월(원)·9월(원)·3분기 합계(원), 합계 열과 맨 아래 합계 행은 =SUM 수식

수정 요청 뒤 에이전트는 "2장 요약 문구를 "3분기 매출 2억 276만 원, 전 분기 대비 3.1% 증가"로 수정했습니다. 다른 슬라이드는 변경 없이 그대로 유지했습니다."라고 답했고, 캔버스와 내려받은 PDF 모두에서 반영을 확인했습니다.

다만 그대로 쓰기 전에 직접 읽어야 할 곳도 있었습니다. Word의 요약에는 자료에 없는 "전년 동기 대비 증가"가 남아 있었고, PPT 4장에는 초안에서 크루 인사이트의 동향인 "공공 부문 문의"가 크루 도큐 아래에 들어가 있었습니다. 모델의 답과 파일 내용은 실행할 때마다 다를 수 있으므로, 숫자와 문구는 늘 원본 자료와 맞춰 봅니다.

이럴 때 쓰세요: 김그루 사원은 분기마다 같은 판매 엑셀과 보고서 초안으로 팀장 보고용 PPT, 결재용 요약 Word, 재무팀 공유용 집계 엑셀을 따로 만들어 왔습니다. 분기 보고 자료 도우미에게 두 파일을 한 번 붙이고 세 번 요청하면 같은 수치로 세 산출물이 한 캔버스에 모입니다. 틀린 문구는 문서 요소 선택으로 그 부분만 고치고, PPT는 PDF로, 엑셀은 원본으로 내려받아 각각 보냅니다.

흔한 실수와 해결​

증상원인해결
답변에 파일이 없고 결과 카드도 생기지 않습니다.에이전트 모드가 일반 에이전트입니다.에이전트 편집 화면 설정 탭에서 문서작성 에이전트를 고르고, 새 대화에서 다시 요청합니다.
에이전트가 표나 설계안만 보여 주고 멈춥니다.파일을 만들기 전에 확인을 기다리는 중입니다."좋아요. 이 수치로 PPT를 만들어 캔버스에 게시해 주세요."처럼 진행해 달라고 보냅니다.
카드를 눌렀는데 "미리보기를 사용할 수 없습니다. 원본 파일을 다운로드해 주세요."가 나옵니다.미리보기를 그리지 못했습니다. 이 실습에서는 Word 문서에서 한 번 나왔습니다.페이지 다시 시도를 누르거나, 브라우저를 새로 고친 뒤 카드를 다시 누릅니다. 그래도 안 되면 내보내기 > 원본 다운로드로 받아 확인합니다.
캔버스에서 셀 값이나 문구를 바로 고칠 수 없습니다.캔버스는 읽기 전용입니다.문서 요소 선택으로 고칠 곳을 골라 대화로 요청합니다.
수식 칸의 값이 "저장된 결과가 비어 있거나 없습니다"로 나옵니다.에이전트가 수식만 넣고 계산 결과를 저장하지 않았습니다.내려받아 엑셀에서 열거나, 계산 결과를 저장해 달라고 요청합니다.
시트 아래 범위 요약이 보이지 않습니다.브라우저 창 높이가 낮아 캔버스 아래쪽이 가려졌습니다.넓게보기로 보거나 창을 키웁니다.
엑셀 탭의 내보내기에 PDF가 없습니다.스프레드시트는 PDF로 내보내지 않습니다.원본 다운로드로 받은 뒤 엑셀에서 PDF로 저장합니다.

응용 과제​

  1. 6단계에서 찾은 PPT 4장의 제품 동향을 문서 요소 선택으로 골라 "공공 부문 문의는 크루 인사이트, 시범 도입 증가는 크루 도큐"로 바로잡아 보세요.
  2. 엑셀 탭에서 9월 열(D2부터 D7)만 끌어 고르고, 범위 요약의 합계가 판매 데이터의 9월 매출과 같은지 확인해 보세요.
  3. 보고서 초안 대신 AI업무혁신_추진현황.pptx를 붙이고, 같은 에이전트에게 "4장짜리 발표자료를 6장으로 늘려 주세요"라고 요청해 PPT를 받은 뒤 PDF로 내보내 보세요.
