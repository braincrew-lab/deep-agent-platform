대화 화면과 채팅 목록

에이전트와 나눈 대화는 하나씩 채팅으로 저장됩니다. 에이전트를 열면 사이드바가 그 에이전트의 채팅 목록으로 바뀌어, 지난주에 정리한 회의록 채팅을 다시 열고 같은 맥락에서 이어 물을 수 있습니다. 이 페이지는 브레인크루 AI혁신팀 김그루 사원이 회의록 요약 도우미와 나눈 채팅을 예로 들어, 대화 화면의 구성과 채팅 목록을 정리하는 메뉴, 토큰 사용량 확인 방법을 설명합니다.

이 페이지에서 할 수 있는 일

  • 대화 화면에서 사이드바 메뉴, 채팅 목록, 모델과 토큰 표시, 답변, 입력창이 어디에 있는지 확인합니다.
  • 이 에이전트와 새 대화로 새 채팅을 열고, 지난 채팅을 다시 열어 이어 묻습니다.
  • 채팅 검색으로 지난 채팅을 이름으로 찾고, 이름 변경, 고정, 삭제로 목록을 정리합니다.
  • 답변 하나의 토큰 사용량 상세와 채팅 전체의 스레드 토큰 요약을 엽니다.
  • 오래 걸리는 요청을 백그라운드 모드로 맡기고, 에이전트가 만든 결과물을 아티팩트와 캔버스에서 엽니다.
  • 에이전트가 도구를 실행하기 전에 승인을 요청하면 승인, 수정/승인, 거절로 답합니다.

질문에 파일을 붙이는 방법은 첨부파일 지원에서 설명합니다.

대화 화면 둘러보기​

사이드바에서 에이전트를 누르면 사이드바 위쪽이 뒤로, 이 에이전트와 새 대화, 에이전트 설정 세 메뉴로 바뀌고, 그 아래에 이 에이전트의 채팅 목록이 나옵니다. 가운데에는 대화가, 오른쪽 끝에는 캔버스 버튼이 있습니다.

입력창 아래에는 "AI 생성 콘텐츠와 답변은 정확하지 않을 수 있습니다."라는 안내가 늘 표시됩니다. 대화를 위로 올려 읽고 있을 때는 입력창 위에 아래로 스크롤 버튼이 나타나며, 누르면 마지막 답변으로 내려갑니다. 캔버스는 캔버스로 문서·PPT·표 만들기에서 자세히 설명합니다.

입력창의 버튼​

입력란 아래에는 버튼이 한 줄로 놓입니다. 입력란 아래 왼쪽의 도구, 서브에이전트, 미들웨어, 스킬은 이 에이전트에 연결된 도구, 서브에이전트, 미들웨어, 스킬 목록을 펼쳐 보여 줍니다. 스킬 목록에서 스킬을 고르면 "그 스킬을 사용하여 답변해 주세요."라는 요청이 바로 보내집니다. 입력란 아래 오른쪽에는 아티팩트, 파일 업로드, 백그라운드 모드, 전송이 있습니다. 아티팩트는 이 채팅에서 만든 결과물을 모아 보는 창을 열고, 결과물이 있으면 개수가 표시됩니다. 파일 업로드는 질문에 붙일 파일을 고르고, 백그라운드 모드는 다음 요청을 백그라운드 작업으로 보낼지 정합니다. 전송은 질문과 첨부파일을 보내며, 에이전트가 답하는 동안에는 이 자리에 취소가 나타나 작업을 멈출 수 있습니다.

아티팩트 창과 내보내기는 PPT·문서 만들기에서 설명합니다.

따라 해 보기​

김그루 사원이 회의록 요약 도우미와 새 채팅을 열어 주간회의록을 요약받는 순서입니다. 회의록 요약 도우미가 아직 없다면 에이전트 만들기에서 먼저 만듭니다.

  1. 사이드바 내 에이전트 목록에서 회의록 요약 도우미를 누릅니다.

  2. 사이드바 위쪽 이 에이전트와 새 대화를 누릅니다. 가운데에 "회의록 요약 도우미와 대화하세요"라는 첫 화면이 열립니다. 에이전트에 챗 오프너가 있으면 그 아래 예시 질문이 함께 보입니다.

  3. 입력란 아래 오른쪽의 파일 업로드를 눌러 브레인크루_AI혁신팀_주간회의록_1110.txt를 고릅니다. 입력란 위에 파일 칩이 붙습니다.

  4. 아래 프롬프트를 입력란에 붙여 넣고 전송을 누릅니다. 파일이 올라가고 처리가 끝나면 질문이 전달됩니다.

    프롬프트: 첨부한 11월 10일 AI혁신팀 주간회의록을 결정 사항, 액션 아이템(담당·기한), 다음 회의 안건으로 나눠 요약해 주세요.

  5. 답변을 받은 뒤 같은 채팅에서 이어 묻습니다.

    프롬프트: 액션 아이템만 담당자별로 묶어 표로 다시 정리해 주세요.

  6. 사이드바 채팅 목록 맨 위에 첫 질문이 이름인 채팅이 생긴 것을 확인합니다.

팁: 주제가 바뀌면 같은 채팅에 계속 묻지 말고 이 에이전트와 새 대화로 새 채팅을 여세요. 한 채팅에 여러 회의가 섞이면 앞 회의의 담당자나 기한이 다음 답변에 섞여 들어갈 수 있습니다.

채팅 목록 정리​

채팅 이름은 처음에는 첫 질문으로 정해집니다. 개인정보 보호 미들웨어를 붙인 에이전트는 첫 질문을 이름으로 쓰지 않아 새 채팅으로 보일 수 있습니다. 채팅에 마우스를 올리면 오른쪽에 작업 버튼이 나타나고, 누르면 정리 메뉴가 열립니다.

채팅 이름 변경​

이름은 최대 255자까지 쓸 수 있습니다. "[주간회의]"처럼 업무 구분을 앞에 붙여 두면 검색할 때 한 번에 모아 볼 수 있습니다.

채팅 삭제​

삭제는 확인 창을 한 번 더 거칩니다. 창의 안내대로 삭제한 채팅은 되돌릴 수 없으므로, 남겨야 할 답변은 복사로 따로 옮겨 둔 뒤 지우세요.

채팅 검색​

**채팅 검색...**에 단어를 입력하면 이름에 그 단어가 들어간 채팅만 목록에 남습니다. 찾는 대상은 채팅 이름이며, 답변 본문에만 있는 단어로는 찾을 수 없습니다. 채팅이 많아 목록을 아직 다 불러오지 않았다면 결과 아래에 "아직 불러오지 않은 채팅이 더 있습니다"가 표시됩니다. 이때는 목록을 아래로 내려 더 불러온 뒤 다시 확인합니다.

따라 해 보기​

  1. 채팅 목록에서 앞에서 만든 회의록 채팅에 마우스를 올리고 작업 > 이름 변경을 누릅니다.
  2. "[주간회의] 11월 10일 AI혁신팀"을 입력하고 저장을 누릅니다.
  3. 다시 작업 > 고정을 누릅니다. 채팅이 압정 표시와 함께 목록 맨 위로 올라갑니다.
  4. **채팅 검색...**에 "주간회의"를 입력해 이 채팅만 남는지 확인하고, 입력란을 비웁니다.
  5. 시험으로 만든 채팅이 있으면 작업 > 삭제를 누르고 확인 창에서 삭제를 누릅니다.

토큰 사용량 확인​

토큰은 모델이 읽고 쓴 글의 양을 세는 단위입니다. 답변 하나의 사용량은 답변 아래 토큰 배지에서, 채팅 전체의 사용량은 화면 위쪽 모델 이름 아래에서 확인합니다.

토큰 사용량 상세​

답변 아래 토큰 배지를 누르면 그 답변 하나의 토큰 사용량 상세 창이 열립니다. 답변이 늦거나 이상해 관리자에게 문의할 때 이 창의 내용을 함께 전달하면 원인을 찾기 쉽습니다.

스레드 토큰 요약​

화면 위쪽 오른쪽의 모델 이름과 토큰 표시를 누르면 채팅 전체의 스레드 토큰 요약 창이 열립니다. 채팅에서 아직 사용량이 생기지 않았으면 모델 이름만 보이고 누를 수 없습니다.

백그라운드 모드로 맡기기​

오래 걸리는 요청은 입력창의 백그라운드 모드 (OFF) 버튼을 눌러 **백그라운드 모드 (ON)**으로 바꾼 뒤 보내면 백그라운드 작업으로 실행됩니다. 입력창에서 Ctrl + Enter로 보내도 백그라운드로 실행됩니다. 보내면 "백그라운드 실행 시작" 알림과 함께 "요청이 백그라운드에서 처리되고 있습니다."가 나옵니다. 작업이 도는 동안 사이드바 채팅 이름 앞에 상태 표시가 붙고, 마우스를 올리면 백그라운드 작업 진행 중, 완료됨, 오류 중 지금 상태가 보입니다.

백그라운드 작업 목록과 정해진 시각에 자동으로 실행하는 스케줄은 스케줄링과 백그라운드 모드에서 설명합니다.

실행 전 승인 요청에 답하기​

에이전트에 사람 승인 미들웨어가 붙어 있으면, 지정한 도구를 실행하기 직전에 에이전트가 멈추고 대화 안에 승인 요청을 띄웁니다. 메일 발송이나 파일 삭제처럼 되돌리기 어려운 작업을 사람이 확인하도록 할 때 쓰는 구성이며, 미들웨어를 붙이는 방법은 미들웨어와 개인정보 보호에서 설명합니다.

승인 요청에는 실행하려는 도구에 넘길 값이 항목별로 보이고, 미들웨어에서 허용한 결정만 버튼으로 나옵니다.

  • 승인: 에이전트가 정한 값 그대로 도구를 실행하게 합니다. 값을 고칠 수 없는 요청에서는 넘길 값 아래에 승인 버튼 하나만 보입니다.
  • 수정/승인: 수정이 허용된 요청에서는 이 제목 아래에 넘길 값이 항목마다 고칠 수 있는 칸으로 열립니다. 값을 고치지 않았으면 아래 버튼이 승인으로 보이고 누르면 그대로 실행됩니다. 값을 고치면 버튼이 제출로 바뀌고, 누르면 고친 값으로 실행됩니다. 오른쪽 위 초기화를 누르면 고친 값이 처음 값으로 돌아갑니다. 받는 사람이나 제목만 바꿔 실행할 때 씁니다.
  • 거절: 거절이 허용된 요청에서는 "또는" 아래에 거절 칸이 나옵니다. 사유 칸에 실행하면 안 되는 이유를 적고 거절 제출을 누르면 도구를 실행하지 않고 그 사유를 에이전트에 전달합니다. 사유를 비워 두면 "거절 사유를 입력해주세요."가 나오고 제출되지 않습니다.

에이전트가 한 번에 여러 도구 실행을 요청하면 작업 1, 작업 2처럼 나뉘어 표시되고, 이전, 다음으로 오가며 각각 결정합니다. 모두 승인해도 되는 요청이면 모두 승인을 누르고, 하나씩 정했다면 전체 N개 결정 제출로 한 번에 보냅니다.

정리​

  • 채팅은 에이전트별로 따로 쌓입니다. 다른 에이전트와 나눈 채팅은 그 에이전트를 열어야 보입니다.
  • 검색은 채팅 이름 기준입니다. 자주 찾을 채팅은 이름을 바꾸고 고정해 두세요.
  • 삭제한 채팅은 되돌릴 수 없습니다.
  • 답변 하나의 사용량은 토큰 배지에서, 채팅 전체의 사용량은 위쪽 모델 이름 아래에서 확인합니다.
