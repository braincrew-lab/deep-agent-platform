즐겨찾기·워크스페이스·다운로드

이 페이지는 자주 쓰는 에이전트를 즐겨찾기에 모아 두고, 워크스페이스에 배포된 에이전트를 찾아 쓰고, 에이전트가 만든 파일을 내려받는 방법을 다룹니다. 예시는 김그루 사원이 매주 여는 주간 업무 보고서 도우미를 즐겨찾기에 넣고, 워크스페이스에 게시된 주간 업무 보고서 도우미를 워크스페이스 폴더로 정리해 쓰고, 판매 데이터 분석가가 만든 엑셀 파일을 내려받는 장면입니다.

이 페이지에서 할 수 있는 일

  • 에이전트 대화 화면 머리글의 별 버튼으로 에이전트를 즐겨찾기에 넣고, 사이드바 즐겨찾기에서 바로 엽니다.
  • 즐겨찾기 창에서 내 에이전트와 워크스페이스 에이전트를 구분해 보고, 더 쓰지 않는 에이전트를 뺍니다.
  • 사이드바 워크스페이스 에이전트 탭에서 대화한 워크스페이스 에이전트를 찾고, 워크스페이스 폴더로 정리합니다.
  • 워크스페이스 에이전트 대화에서 할 수 있는 일과 할 수 없는 일을 구분합니다.
  • 프로필에서 내 기본 워크스페이스와 역할을 확인합니다.
  • 별도 다운로드 메뉴 없이, 파일을 내려받는 네 곳(아티팩트 창, 캔버스, 스킬 ZIP 내보내기, 에이전트 내보내기)을 찾아갑니다.

에이전트 즐겨찾기​

에이전트 대화 화면 오른쪽 위, 모델과 토큰 사용량 표시 옆의 별 버튼이 에이전트 즐겨찾기입니다. 누르면 별이 채워지고 "즐겨찾기에 추가되었습니다" 알림이 잠깐 뜹니다.

에이전트 즐겨찾기

번호메뉴기능이런 때 사용하세요
1에이전트 이름과 설명지금 대화 중인 에이전트입니다.즐겨찾기에 넣으려는 에이전트가 맞는지 확인할 때
2모델과 토큰 사용량이 에이전트가 쓰는 모델과 이 대화에서 쓴 토큰 수입니다.주간 업무 보고서 도우미가 어떤 모델로 답하는지 확인할 때
3에이전트 즐겨찾기(별)누르면 즐겨찾기에 넣고, 채워진 별을 다시 누르면 뺍니다.매주 금요일 여는 주간 업무 보고서 도우미를 즐겨찾기에 넣을 때
4즐겨찾기사이드바 아래쪽 바로가기입니다. 즐겨찾기한 에이전트를 모은 창을 엽니다.사이드바 목록을 내려 찾지 않고 바로 열 때

따라 해 보기​

  1. 사이드바 내 에이전트 목록에서 주간 업무 보고서 도우미를 누릅니다.
  2. 대화 화면 오른쪽 위의 별 버튼(에이전트 즐겨찾기)을 누릅니다.
  3. 별이 채워지고 "즐겨찾기에 추가되었습니다" 알림이 뜨는지 확인합니다.
  4. 같은 방법으로 판매 데이터 분석가도 넣어 둡니다.

팁: 내 에이전트를 워크스페이스에 배포했다면, 내 에이전트와 배포본 중 한쪽만 즐겨찾기할 수 있습니다. 다른 쪽이 이미 즐겨찾기되어 있으면 별 버튼에 "내 에이전트와 워크스페이스 배포본 중 다른 쪽이 이미 즐겨찾기되어 있습니다"가 표시되고 눌리지 않습니다. 바꾸려면 다른 쪽 즐겨찾기를 먼저 해제합니다.

즐겨찾기 창​

사이드바 아래쪽 즐겨찾기를 누르면 즐겨찾기한 에이전트가 최근에 넣은 순서로 한 목록에 보입니다. 내 에이전트와 워크스페이스 에이전트가 함께 나오고, 표시로 구분합니다. 즐겨찾기한 에이전트가 없으면 "즐겨찾기한 에이전트가 없습니다"가 표시됩니다.

줄마다 별 버튼, 에이전트 이름과 설명, 개인 또는 워크스페이스 표시, 즐겨찾기에 넣은 날짜가 보입니다. 개인은 내 에이전트, 워크스페이스는 워크스페이스에 배포된 에이전트라는 뜻입니다. 이름을 누르면 창이 닫히고 그 에이전트 대화 화면이 열립니다. 별 버튼을 누르면 즐겨찾기에서 빠지는데, 내 에이전트는 확인 창이 먼저 열리고 워크스페이스 에이전트는 바로 빠집니다.

즐겨찾기 창

번호메뉴기능이런 때 사용하세요
1별 버튼이 에이전트를 즐겨찾기에서 뺍니다. 내 에이전트는 확인 창이 먼저 열리고, 워크스페이스 에이전트는 바로 빠집니다.담당 업무가 바뀌어 더 쓰지 않는 도우미를 정리할 때
2에이전트 이름이름 아래에 설명 앞부분이 보입니다. 누르면 창이 닫히고 그 에이전트 대화 화면이 열립니다.출근하자마자 판매 데이터 분석가를 열 때
3개인 / 워크스페이스 표시개인은 내 에이전트, 워크스페이스는 워크스페이스에 배포된 에이전트라는 뜻입니다. 그림에는 내 에이전트만 있어 개인만 보입니다.내가 만든 도우미와 다른 사람이 배포한 도우미를 구분할 때
4날짜즐겨찾기에 넣은 날입니다.오래전에 넣어 둔 항목을 정리할 때

창 맨 위 제목 즐겨찾기로 지금 연 창이 즐겨찾기 목록인지 확인할 수 있습니다.

한 화면에 8개까지 보이고, 더 많으면 창 아래에 쪽 번호가 나타납니다.

즐겨찾기에서 빼기​

내 에이전트의 별 버튼을 누르면 에이전트 즐겨찾기 확인 창이 열리고 "이 에이전트의 즐겨찾기를 해제하시겠습니까?"가 보입니다. 즐겨찾기 해제를 눌러야 실제로 빠지고, 취소를 누르면 아무것도 바뀌지 않습니다. 즐겨찾기에서 빼도 에이전트 자체는 지워지지 않고 사이드바 목록에 그대로 남습니다.

즐겨찾기 해제 확인

번호메뉴기능이런 때 사용하세요
1에이전트 즐겨찾기확인 창 제목입니다. 아래에 "이 에이전트의 즐겨찾기를 해제하시겠습니까?"가 보입니다.빼려던 에이전트가 맞는지 다시 확인할 때
2취소아무것도 바꾸지 않고 창을 닫습니다.별을 잘못 눌렀을 때
3즐겨찾기 해제즐겨찾기에서 뺍니다. 에이전트 자체는 지워지지 않고 사이드바 목록에 그대로 남습니다.분기 업무가 끝나 즐겨찾기를 정리할 때

워크스페이스 에이전트​

워크스페이스는 같은 회사나 조직의 사용자가 에이전트와 자원을 함께 쓰는 공간입니다. 내 에이전트를 워크스페이스 등록으로 배포 요청하고 관리자가 승인하면, 같은 워크스페이스 사용자가 그 에이전트와 대화할 수 있습니다. 등록과 배포 요청은 커뮤니티에서 설명합니다.

처음 쓰는 워크스페이스 에이전트는 사이드바 위쪽 에이전트 템플릿의 템플릿 카드를 눌러 연 상세 창에서 대화하기로 엽니다. 한 번 대화한 워크스페이스 에이전트는 사이드바 워크스페이스 에이전트 탭에 모입니다. 아직 없으면 "아직 대화한 워크스페이스 에이전트가 없습니다."가 보입니다. 이 탭에서는 워크스페이스 폴더 아래에 내가 만든 폴더가 이름과 에이전트 수와 함께 보이고, 폴더에 넣지 않은 에이전트는 미분류에 모입니다. 에이전트 검색으로 이름을 찾을 수 있고, 내 에이전트 탭을 누르면 내가 만든 에이전트 목록으로 돌아갑니다.

워크스페이스 에이전트 탭

번호메뉴기능이런 때 사용하세요
1워크스페이스 에이전트대화한 적 있는 워크스페이스 에이전트 목록을 보여 줍니다. 아직 없으면 "아직 대화한 워크스페이스 에이전트가 없습니다."가 보입니다. 왼쪽 사람 모양 내 에이전트를 누르면 내가 만든 에이전트 목록으로 돌아갑니다.지난주에 쓴 배포 에이전트를 다시 찾을 때
2워크스페이스 폴더워크스페이스 폴더 아래에 내가 만든 폴더(예: 회의·보고)가 들어 있는 에이전트 수와 함께 보입니다.회의·보고처럼 업무별로 묶어 찾을 때
3미분류폴더에 넣지 않은 워크스페이스 에이전트입니다. 누르면 펼쳐지거나 접힙니다.새로 대화한 에이전트를 폴더로 옮기기 전에 찾을 때
4에이전트 검색목록에서 이름으로 워크스페이스 에이전트를 찾습니다.대화한 에이전트가 많아 이름으로 바로 찾을 때

워크스페이스 폴더를 만들고 에이전트를 넣는 에이전트 관리 버튼은 내 에이전트 탭 목록 머리글에 있습니다.

워크스페이스 폴더로 정리하기​

에이전트 관리 창의 워크스페이스 에이전트 탭에서 워크스페이스 폴더를 만들고 에이전트를 넣습니다. 창을 열면 내 에이전트 탭이 먼저 보이므로 탭을 바꿉니다. 이 탭의 변경은 변경사항 적용 없이 바로 반영되며, "워크스페이스 폴더 변경은 바로 적용됩니다. 폴더를 삭제해도 에이전트는 삭제되지 않습니다." 안내가 보입니다. 폴더 생성을 누르면 폴더 생성 창이 열리고, 이름을 적고 생성을 누르면 폴더가 만들어집니다. 폴더 줄에는 폴더 이름과 들어 있는 에이전트 수가 보입니다. 에이전트 분류에서는 에이전트마다 오른쪽 선택 상자(처음에는 폴더 없음)로 넣을 폴더를 고릅니다. 대화한 적 없는 에이전트도 넣을 수 있지만, 에이전트 이름과 설명은 바꿀 수 없습니다.

워크스페이스 폴더 관리

번호메뉴기능이런 때 사용하세요
1워크스페이스 에이전트 탭워크스페이스 폴더 관리 화면으로 바꿉니다. 창을 열면 내 에이전트 탭이 먼저 보입니다. 탭 아래에 "워크스페이스 폴더 변경은 바로 적용됩니다. 폴더를 삭제해도 에이전트는 삭제되지 않습니다."가 보입니다.워크스페이스 에이전트를 정리하려 할 때
2폴더 생성폴더 생성 창을 열어 새 워크스페이스 폴더를 만듭니다."회의·보고" 폴더를 새로 만들 때
3에이전트 수폴더 줄에 폴더 이름과 함께 들어 있는 에이전트 수(예: 에이전트 0개)가 보입니다.폴더에 몇 개가 들어 있는지 볼 때
4폴더 선택 상자에이전트 분류 목록에서 에이전트마다 넣을 폴더를 고릅니다. 처음에는 폴더 없음입니다. 대화한 적 없는 에이전트도 넣을 수 있습니다. 이름과 설명은 바꿀 수 없습니다.주간 업무 보고서 도우미를 "회의·보고" 폴더에 넣을 때

따라 해 보기​

  1. 사이드바에서 내 에이전트 탭을 누르고, 목록 머리글의 에이전트 관리를 누릅니다.
  2. 창에서 워크스페이스 에이전트 탭을 고릅니다.
  3. 폴더 생성을 누르고 이름에 "회의·보고"를 적은 뒤 생성을 누릅니다.
  4. 에이전트 분류에서 주간 업무 보고서 도우미 오른쪽 선택 상자를 눌러 "회의·보고"를 고릅니다.
  5. 창을 닫고 사이드바 워크스페이스 에이전트 탭의 회의·보고 폴더에 들어간 에이전트 수를 확인합니다.

워크스페이스 에이전트와 대화할 때​

워크스페이스 에이전트는 배포한 사람의 구성 그대로 실행됩니다. 대화와 즐겨찾기는 할 수 있지만 구성을 고칠 수는 없습니다. 사이드바 메뉴에는 뒤로와 이 에이전트와 새 대화만 보이고, 내 에이전트에 있던 에이전트 설정은 없습니다. 별 버튼은 즐겨찾기 추가 / 즐겨찾기 해제로 표시되며, 같은 에이전트의 내 에이전트 쪽이 이미 즐겨찾기되어 있으면 눌리지 않습니다. 입력란 아래에는 내 에이전트 대화의 목록 버튼 네 개 대신 사용 중인 자원 보기가 있어, 이 에이전트가 쓰는 도구, 서브에이전트, 미들웨어, 스킬을 볼 수 있습니다. 쓰는 자원이 없으면 "표시할 자원이 없습니다."가 보입니다.

워크스페이스 에이전트 대화

번호메뉴기능이런 때 사용하세요
1이 에이전트와 새 대화이 워크스페이스 에이전트와 새 대화를 시작합니다. 사이드바 메뉴에는 위쪽 뒤로와 이 버튼만 보이고, 내 에이전트에 있던 에이전트 설정은 없습니다.지침이나 도구를 고칠 수 없다는 것을 확인할 때
2즐겨찾기(별)즐겨찾기 추가 / 즐겨찾기 해제로 즐겨찾기에 넣고 뺍니다. 내 에이전트 쪽이 이미 즐겨찾기되어 있으면 "내 에이전트와 워크스페이스 배포본 중 다른 쪽이 이미 즐겨찾기되어 있습니다"가 표시되고 눌리지 않습니다.자주 쓰는 배포 에이전트를 즐겨찾기 창에 모을 때
3사용 중인 자원 보기이 에이전트가 쓰는 도구, 서브에이전트, 미들웨어, 스킬을 보여 줍니다. 없으면 "표시할 자원이 없습니다."가 보입니다. 내 에이전트 대화의 목록 버튼 네 개 대신 보입니다.이 에이전트가 어떤 도구로 답하는지 확인할 때
4메시지 입력창일반 대화처럼 질문하고 파일을 첨부합니다.업무 메모를 올려 보고서 초안을 받을 때

워크스페이스 에이전트 대화에는 아래 안내가 나타날 수 있습니다.

  • "사용 권한이 없는 자원이 있어 일부 기능이 동작하지 않을 수 있습니다:" — 에이전트가 쓰는 자원 중 내가 쓸 권한이 없는 것이 있습니다. 관리자에게 권한을 요청합니다.
  • "이 에이전트가 v1에서 v2으로 업데이트되었습니다. 다음 메시지부터 새 버전으로 실행됩니다." 같은 버전 안내 — 배포한 사람이 새 버전을 올렸다는 뜻입니다.
  • "이 에이전트를 실행할 권한이 없습니다. 관리자에게 문의하세요.", "숨겨진 에이전트라 새 메시지를 보낼 수 없습니다.", "삭제된 에이전트라 대화를 이어갈 수 없습니다." — 메시지를 보낼 수 없는 상태입니다.

구성을 바꿔 쓰고 싶으면 에이전트 템플릿 상세 창에서 템플릿으로 제작으로 내 에이전트를 만든 뒤 고칩니다. 방법은 에이전트 만들기에 있습니다.

프로필에서 워크스페이스 확인​

내가 어느 워크스페이스에 속해 있는지는 사이드바 아래쪽 사용자 이름을 누르고 프로필을 열어 확인합니다. 워크스페이스 영역의 기본 워크스페이스에 지금 쓰는 워크스페이스 이름(예: 브레인크루)과 내 역할(소유자, 관리자, 매니저, 멤버 중 하나)이 표시됩니다. 선택 상자 모양이지만 화면에서 바꿀 수는 없습니다. 보이는 워크스페이스 에이전트나 모델이 동료와 다르면 여기서 같은 워크스페이스인지 확인합니다.

프로필의 기본 워크스페이스

번호메뉴기능이런 때 사용하세요
1워크스페이스프로필의 워크스페이스 영역입니다.내 계정이 어느 워크스페이스에 속했는지 볼 때
2기본 워크스페이스지금 쓰는 워크스페이스 이름과 내 역할(소유자, 관리자, 매니저, 멤버 중 하나)이 표시됩니다. 선택 상자 모양이지만 화면에서 바꿀 수는 없습니다.보이는 워크스페이스 에이전트나 모델이 동료와 달라, 같은 워크스페이스인지 확인할 때

다른 워크스페이스로 옮겨야 하면 관리자에게 요청하세요.

파일을 내려받는 곳​

Deep Agent Builder에는 다운로드만 모아 보는 메뉴가 따로 없습니다. 무엇을 내려받는지에 따라 아래 네 곳에서 받습니다.

내려받을 것위치받는 방법
대화에서 에이전트가 만든 파일과 데이터 표입력란 아래 오른쪽의 아티팩트 버튼으로 여는 아티팩트 창파일은 다운로드, 데이터 표는 내보내기
문서작성 에이전트가 만든 PPT·문서·표대화 화면 오른쪽 문서 캔버스내보내기 > 원본 다운로드 또는 형식별 내보내기
스킬에셋 화면의 스킬 탭 > 스킬 파일 창ZIP 내보내기
에이전트 구성 전체에이전트 편집 화면 머리글의 저장 옵션 더 보기에이전트 내보내기(ZIP)

아티팩트 창에서 내려받기​

에이전트에게 엑셀이나 문서 파일을 만들어 달라고 하면, 답변 안에 파일 이름이 링크로 붙고 입력란 아래 오른쪽의 아티팩트 버튼에 모인 개수가 표시됩니다. 아티팩트 창은 저절로 열리지 않으므로 이 버튼을 눌러 엽니다. 창 왼쪽 목록에는 데이터 표(행·열 수 표시)와 파일이 만들어진 순서대로 보이고, 파일은 이름, 형식, 크기가 함께 표시됩니다. 파일을 고르면 오른쪽 미리보기에 내용이 보이고(엑셀 파일은 아래쪽 시트 탭으로 시트를 바꿔 봅니다), 미리보기 오른쪽 위의 다운로드 아이콘으로 그대로 내려받습니다. 데이터 표는 목록 아래 내보내기에서 Word로 내보내기, PPTX로 내보내기, HTML 다운로드, Excel로 내보내기, CSV로 내보내기 중 하나로 받습니다. 파일을 고른 동안에는 내보내기가 흐리게 보입니다.

아티팩트 창에서 파일 내려받기

번호메뉴기능이런 때 사용하세요
1아티팩트이 대화에서 만든 표와 파일을 모아 보는 창을 엽니다.내려받기 전에 파일 내용을 미리 볼 때
2브레인크루_판매분석_결과.xlsx아티팩트 목록의 파일 항목입니다. 이름, 형식, 크기(예: XLSX · 6.21 KB)가 함께 보이고, 고르면 오른쪽 미리보기에 내용이 열립니다.이번 대화에서 만든 엑셀 파일을 고를 때
3다운로드미리보기 오른쪽 위 아이콘입니다. 고른 파일을 그대로 내려받습니다.브레인크루_판매분석_결과.xlsx를 내 PC에 저장할 때
4내보내기데이터 표를 Word로 내보내기, PPTX로 내보내기, HTML 다운로드, Excel로 내보내기, CSV로 내보내기 중 하나로 내보냅니다. 파일을 고른 동안에는 흐리게 보입니다.답변 속 순위 표를 Excel이나 PPT 파일로 바꿀 때

목록에는 데이터 표(행·열 수 표시)와 파일이 만들어진 순서대로 보입니다. 오른쪽 미리보기는 고른 항목의 내용을 표나 문서 모양으로 보여 주고, 옆의 코드 탭으로 바꿔 볼 수도 있습니다. 엑셀 파일은 아래쪽 시트 탭(예: 지역별_달성률, 제품별_월별_추이)으로 시트를 바꿉니다. 내려받기 전에 시트의 숫자가 답변의 표와 같은지 미리보기로 확인하세요.

HTML, Excel, CSV 파일은 바로 미리 볼 수 있습니다. 그 밖의 파일(예: Word, PPT, PDF)은 고르면 "아래 버튼을 눌러 다운로드 받으세요."와 다운로드 버튼이 보입니다. 에이전트가 만든 파일은 일정 기간이 지나면 "기간이 만료되어 다운로드 받을 수 없습니다."가 표시되고 내려받을 수 없습니다. 이때는 같은 대화에서 파일을 다시 만들어 달라고 요청합니다.

따라 해 보기​

데이터 분석에서 판매 데이터 분석가에게 받은 브레인크루_판매분석_결과.xlsx를 저장합니다.

  1. 분석을 마친 대화에서 입력란 아래 오른쪽의 아티팩트를 누릅니다.
  2. 목록에서 브레인크루_판매분석_결과.xlsx를 고릅니다.
  3. 미리보기의 지역별_달성률 시트에서 서울 1~10월 누적 매출 1,307,210,000원이 답변의 표와 같은지 확인합니다.
  4. 미리보기 오른쪽 위의 다운로드를 눌러 파일을 저장합니다.

캔버스에서 내려받기​

문서작성 에이전트(예: 교육 자료 제작 도우미, 제안서 PPT 작성기)가 만든 결과물은 대화 화면 오른쪽 문서 캔버스에 열립니다. 캔버스가 접혀 있으면 오른쪽 끝의 캔버스 열기를 누릅니다. 한 대화에서 여러 문서를 만들었다면 캔버스 위쪽 탭으로 문서를 바꿔 봅니다. 캔버스는 읽기 전용이라 화면에서 고칠 수 없고, 위쪽 내보내기 메뉴로 내려받습니다. 메뉴 맨 위에는 항상 원본 다운로드가 있어 에이전트가 만든 파일을 그대로 받고, 그 아래에 원본에 따라 XLSX 형식으로 내보내기, PPTX 형식으로 내보내기처럼 바꿔 받을 형식이 붙습니다. 받는 동안에는 버튼이 "다운로드 중…"으로 바뀝니다.

캔버스 내보내기

번호메뉴기능이런 때 사용하세요
1문서 이름캔버스에 지금 열린 문서 이름과 상태(예: 준비됨)입니다.내려받으려는 문서가 맞는지 확인할 때
2내보내기내려받기 메뉴를 엽니다. 받는 동안에는 "다운로드 중…"으로 바뀝니다.완성된 퀴즈 파일을 저장할 때
3원본 다운로드에이전트가 만든 파일을 그대로 받습니다. 메뉴 맨 위에 항상 있습니다.만든 형식 그대로 받을 때
4형식별 내보내기"XLSX 형식으로 내보내기"처럼 원본에 따라 고를 수 있는 형식이 붙습니다.다른 형식으로 바꿔 받을 때

원본별로 고를 수 있는 형식은 캔버스로 문서·PPT·표 만들기에 표로 정리되어 있습니다. 내려받지 못하면 "다운로드에 실패했습니다. 권한을 확인하고 다시 시도해 주세요."가 표시됩니다.

스킬과 에이전트 내려받기​

  • 스킬: 사이드바의 에셋설정을 눌러 여는 에셋 화면의 스킬 탭에서 스킬 카드를 눌러 스킬 파일 창을 열고 ZIP 내보내기를 누릅니다. 내려받은 ZIP은 다른 계정에서 스킬 업로드로 올려 쓸 수 있습니다. 자세한 순서는 스킬 만들기와 업로드에 있습니다.
  • 에이전트: 에이전트 편집 화면 머리글 저장 옆 저장 옵션 더 보기를 눌러 에이전트 내보내기를 고르면 ZIP 파일로 받습니다. 메뉴에는 새 버전으로 저장과 에이전트 내보내기가 있고, 받는 동안 "내보내는 중..."이 보입니다. 받은 ZIP은 에이전트 가져오기로 다시 만들 수 있습니다. 자세한 순서는 에이전트 가져오기와 내보내기에 있습니다.

에이전트 내보내기

번호메뉴기능이런 때 사용하세요
1저장 옵션 더 보기저장 옆 화살표입니다. 새 버전으로 저장과 에이전트 내보내기가 들어 있습니다.저장 말고 다른 동작을 고를 때
2에이전트 내보내기에이전트 구성을 ZIP 파일로 내려받습니다. 받는 동안 "내보내는 중..."이 보입니다.주간 업무 보고서 도우미를 다른 팀에 넘겨줄 때

팁: 개인정보가 들어간 대화에서 만든 파일은 내려받기 전에 미리보기로 개인정보가 가려졌는지 확인하세요. 내려받은 파일은 사내 보안 기준에 맞는 위치에 저장합니다.

정리​

  • 별 버튼으로 넣은 에이전트는 사이드바 즐겨찾기 창에서 바로 엽니다. 내 에이전트와 워크스페이스 에이전트가 한 목록에 개인, 워크스페이스 표시로 나옵니다.
  • 워크스페이스 에이전트는 워크스페이스 에이전트 탭과 워크스페이스 폴더로 찾고, 대화와 즐겨찾기만 할 수 있습니다.
  • 워크스페이스는 프로필의 기본 워크스페이스로 확인만 합니다.
  • 다운로드 메뉴는 따로 없습니다. 대화 파일은 아티팩트 창, 문서작성 결과물은 캔버스 내보내기, 스킬은 ZIP 내보내기, 에이전트는 에이전트 내보내기에서 받습니다.
