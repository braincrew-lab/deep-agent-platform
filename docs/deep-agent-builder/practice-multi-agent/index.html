Deep Agent Builder 실습 5: 총괄 에이전트에 서브에이전트를 붙여 멀티에이전트 만들기

이 실습은 담당 에이전트 하나를 새로 만들고, 이미 있는 판매 데이터 분석가와 함께 새 총괄 에이전트의 서브에이전트로 붙인 뒤, 요청 하나로 두 담당에게 일이 나뉘어 넘어가는 모습을 직접 확인합니다. 예시는 브레인크루 AI혁신팀 김그루 사원이 3분기 실적 브리핑을 준비하면서, 숫자 집계는 분석 담당에게, 보고서 초안 정리는 요점 정리 담당에게 맡기는 상황입니다. 서브에이전트 관리 창과 위임 표시의 버튼별 설명은 서브에이전트 할당하기와 멀티에이전트 실행 흐름에 있으므로, 이 페이지는 처음부터 손으로 만들어 돌려 보는 순서에 집중합니다.

이 페이지에서 할 수 있는 일

  • 담당 에이전트를 직접 만들고 테스트 탭에서 혼자 제대로 동작하는지 확인합니다.
  • 총괄 에이전트를 만들고 지침에 담당별 위임 규칙을 적습니다.
  • 폼 보기의 서브에이전트 관리 창에서 기존 에이전트와 새 에이전트를 함께 붙입니다.
  • 비주얼 보기로 연결을 확인합니다.
  • 대화 화면에서 요청을 보내고, 서브에이전트 호출 상자를 펼쳐 위임 내용과 최종 답을 확인합니다.

목표​

항목내용
만들 것담당 에이전트 "실적 보고서 요점 정리 도우미", 총괄 에이전트 "분기 실적 브리핑 총괄"
결과물판매 데이터 분석가와 실적 보고서 요점 정리 도우미에게 나눠 맡긴 뒤 모아 쓴 3분기 실적 브리핑(핵심 3줄, 지역별 매출 표, 이슈와 4분기 계획)
걸리는 시간담당 만들기와 테스트 7분, 총괄 만들기와 연결 8분, 실행 1분 안팎, 확인 5분
난이도★★★★☆

준비물​

파일내용형식
3분기_영업실적_보고서_초안.docx브레인크루 2026년 3분기 영업 실적 보고서 초안(가상). 지역별 실적(서울·부산·대전), 제품별 동향, 4분기 계획이 들어 있고 수치는 비어 있습니다.docx
브레인크루_판매데이터_2026.xlsx2026년 1~9월 주문 396건(가상). 주문일, 지역, 채널, 제품, 수량, 단가, 매출액xlsx

이 밖에 판매 데이터 분석가 에이전트가 있어야 합니다. 없다면 사례: 엑셀 판매 데이터 분석대로 먼저 만들어 둡니다. 대화 화면과 테스트 탭의 파일 업로드로는 .pdf, .jpg, .jpeg, .png, .gif, .webp, .md, .markdown, .txt, .xlsx, .xls, .xlsb, .xlsm, .csv, .docx, .pptx, .ppt, .hwp, .hwpx, .html, .htm 파일을 같은 방법으로 붙일 수 있습니다.

1단계. 담당 에이전트를 만들고 혼자 테스트하기​

담당 에이전트 만들기와 테스트

번호메뉴입력하거나 고를 값
1지침아래 담당 지침 전문
2테스트오른쪽 패널 탭을 누릅니다.
3첨부 파일3분기_영업실적_보고서_초안.docx
4테스트 답변지역별 이슈, 제품 동향, 다음 분기 계획 세 묶음으로 나오는지 확인합니다.

프롬프트: 너는 브레인크루 영업 보고서의 요점 정리 담당이야. 첨부된 영업실적 보고서 초안(docx)을 읽고 아래 세 묶음으로 정리해.

  1. 지역별 이슈: 지역 이름과 초안에 적힌 상황을 한 줄씩
  2. 제품 동향: 제품 이름과 초안에 적힌 동향을 한 줄씩
  3. 다음 분기 계획: 초안의 계획 항목을 그대로 초안에 없는 숫자는 만들지 말고, "(작성 중)"처럼 확정되지 않은 내용은 "확인 필요"로 표시해. 판매 수치 계산은 하지 않는다.
  1. 사이드바 새 에이전트 > 에이전트 직접 만들기를 누릅니다.
  2. 에이전트 이름에 "실적 보고서 요점 정리 도우미", **에이전트 설명 (선택)**에 "영업실적 보고서 초안에서 지역별 이슈, 제품 동향, 다음 분기 계획을 뽑아 요점으로 정리합니다."를 적고 확인을 누릅니다. 이 설명은 나중에 총괄 에이전트가 담당을 고를 때도 읽습니다.
  3. 지침에 위 지침을 붙여 넣고 헤더의 저장을 누릅니다.
  4. 오른쪽 테스트 탭에서 파일 업로드로 보고서 초안을 붙이고 "첨부한 보고서 초안의 요점을 정리해 주세요."를 보냅니다.
  5. 답이 "지역별 이슈 / 제품 동향 / 다음 분기 계획" 순서로 나오는지 봅니다. 이 실습에서는 "서울: 목표 달성 예상", "부산: 신규 파트너 2곳 계약", "대전: 목표 대비 부진, 원인 분석 필요"가 나오고, 3분기 실적 수치는 "확인 필요"로 남았습니다.

혼자서 엉뚱한 답을 내는 담당은 서브에이전트로 붙여도 같은 답을 냅니다. 붙이기 전에 꼭 혼자 테스트합니다.

2단계. 총괄 에이전트 만들고 위임 규칙 쓰기​

총괄 에이전트와 위임 규칙

번호메뉴입력하거나 고를 값
1지침아래 총괄 지침 전문
2서브에이전트 칸아직 "서브에이전트가 없습니다"입니다.
3서브에이전트 관리다음 단계에서 누를 톱니바퀴 버튼입니다.

총괄 에이전트의 지침에는 담당 이름을 그대로 적고, 담당마다 맡길 일과 넘길 자료, 마지막 답변 형식을 적습니다.

프롬프트: 너는 브레인크루 AI혁신팀의 분기 실적 브리핑 총괄이야. 직접 계산하거나 보고서를 요약하지 말고, 아래 규칙대로 담당 에이전트에게 맡긴 뒤 결과를 모아 답해.

  1. 판매 수치(지역별·월별 매출, 합계, 전 분기 대비 증감)는 "판매 데이터 분석가"에게 맡긴다. 판매 엑셀 파일 이름과 집계 기간을 함께 넘긴다.
  2. 보고서 초안의 지역별 이슈, 제품 동향, 다음 분기 계획은 "실적 보고서 요점 정리 도우미"에게 맡긴다. 보고서 파일 이름을 함께 넘긴다.
  3. 두 담당은 서로의 결과가 필요 없으니 순서와 상관없이 맡긴다.
  4. 마지막 답변은 "핵심 3줄 → 지역별 매출 표 → 이슈와 다음 분기 계획" 순서로 쓴다. 수치는 판매 데이터 분석가가 준 값만 쓰고, 담당이 확인하지 못한 내용은 "확인 필요"로 남긴다.
  1. 사이드바 새 에이전트 > 에이전트 직접 만들기를 누릅니다.
  2. 에이전트 이름에 "분기 실적 브리핑 총괄", **에이전트 설명 (선택)**에 "판매 수치 집계와 보고서 요점 정리를 담당 에이전트에게 나눠 맡기고, 결과를 모아 팀장 브리핑을 씁니다."를 적고 확인을 누릅니다.
  3. 지침에 위 지침을 붙여 넣고 헤더의 저장을 누릅니다.

3단계. 서브에이전트 관리 창에서 담당 붙이기​

서브에이전트 관리 창

번호메뉴입력하거나 고를 값
1내 에이전트창을 열면 먼저 고른 상태입니다. 그대로 둡니다.
2검색란처음에는 "판매", 두 번째는 "실적 보고서"를 적습니다.
3에이전트 카드이름과 설명 앞부분을 읽고 붙일 담당이 맞는지 봅니다. 카드를 누르면 그 에이전트 편집 화면으로 넘어가니 주의합니다.
4추가누르면 바로 서브에이전트로 연결되고 카드가 왼쪽 현재 서브에이전트로 옮겨 갑니다.
  1. 서브에이전트 칸 오른쪽 톱니바퀴(서브에이전트 관리)를 누릅니다.
  2. 검색란에 "판매"를 적고 판매 데이터 분석가 카드의 추가를 누릅니다. 이미 있는 에이전트를 그대로 재사용하는 것이므로 판매 데이터 분석가의 설정은 바뀌지 않습니다.
  3. 검색란을 "실적 보고서"로 바꾸고 실적 보고서 요점 정리 도우미의 추가를 누릅니다. 그림은 판매 데이터 분석가를 먼저 붙이고 두 번째 담당을 찾은 상태입니다.

담당 두 개를 붙인 상태

번호메뉴입력하거나 고를 값
1현재 서브에이전트 (2)숫자가 2인지 확인합니다.
2연결된 서브에이전트판매 데이터 분석가 아래에 실적 보고서 요점 정리 도우미가 붙었는지 확인합니다.
3삭제(휴지통)잘못 붙였을 때만 누릅니다. 에이전트 자체는 지워지지 않습니다.
4닫기확인이 끝나면 창을 닫습니다.
  1. 왼쪽 제목이 **현재 서브에이전트 (2)**가 되었는지 보고 창을 닫습니다.
  2. 헤더 저장 옆에 "저장되지 않은 변경이 있습니다"가 보이면 저장을 누릅니다. 서브에이전트 추가는 누른 순간 대화에 적용되지만, 저장을 눌러야 현재 버전에 기록됩니다.

4단계. 비주얼 보기로 연결 확인하기​

비주얼 보기의 연결

번호메뉴기능이런 때 사용하세요
1총괄 에이전트 이름에이전트 상자의 이름입니다. 아래 Instructions에 지침 앞부분이 보입니다.지침에 위임 규칙이 들어갔는지 훑어볼 때
2판매 데이터 분석가서브 에이전트 상자에 연결된 첫 담당입니다. 누르면 그 에이전트 편집 화면으로 이동할지 묻습니다.담당의 지침을 고치러 갈 때
3실적 보고서 요점 정리 도우미두 번째로 붙인 담당입니다.새로 만든 담당이 제대로 연결됐는지 볼 때
4서브에이전트 추가3단계의 서브에이전트 관리 창을 엽니다.그림을 보다가 담당을 더 붙일 때
  1. 편집 영역 위쪽 비주얼을 누릅니다.
  2. 에이전트 상자에서 서브 에이전트 상자로 선이 이어져 있고, 그 안에 담당 두 개가 보이는지 확인합니다. 상자가 작게 보이면 왼쪽 아래 확대 버튼이나 오른쪽 위 기본 레이아웃을 씁니다.
  3. 폼을 눌러 폼 보기로 돌아온 뒤 사이드바 이 에이전트와 새 대화를 누릅니다.

5단계. 대화 화면에서 요청 보내기​

총괄 에이전트에 요청 보내기

번호메뉴입력하거나 고를 값
1첨부 파일3분기_영업실적_보고서_초안.docx와 브레인크루_판매데이터_2026.xlsx 두 개를 붙입니다(그림에는 첫 파일에 번호).
2메시지 입력란아래 요청 프롬프트
3서브에이전트 목록입력란 아래 사람 모양 서브에이전트 버튼을 누르면 펼쳐집니다. 판매 데이터 분석가와 실적 보고서 요점 정리 도우미가 보여야 합니다.
4전송누르면 요청이 시작됩니다.

프롬프트: 3분기 실적 브리핑을 준비해 주세요. 판매 데이터의 7~9월 지역별 매출과 2분기 대비 증감은 판매 데이터 분석가에게, 보고서 초안의 지역별 이슈와 4분기 계획은 실적 보고서 요점 정리 도우미에게 맡겨 주세요.

  1. 파일 업로드(클립)로 두 파일을 붙입니다.
  2. 위 프롬프트를 붙여 넣습니다.
  3. 서브에이전트 버튼을 눌러 담당 두 개가 보이는지 확인하고, Esc로 목록을 닫습니다.
  4. 전송을 누릅니다.

6단계. 위임 표시와 최종 답 확인하기​

위임 표시와 최종 답

번호메뉴기능이런 때 사용하세요
1판매 데이터 분석가 호출 상자총괄 에이전트가 판매 데이터 분석가에게 일을 넘긴 기록입니다. 초록 체크는 끝났다는 뜻이고 오른쪽 16.3s는 일한 시간입니다.수치 집계가 실제로 담당에게 넘어갔는지 볼 때
2실적 보고서 요점 정리 도우미 호출 상자두 번째 담당에게 넘긴 기록입니다(3.3s).보고서 정리가 새 담당에게 넘어갔는지 볼 때
3핵심 3줄지침 4번대로 맨 위에 쓴 요약입니다.팀장 보고 첫 줄로 옮겨 쓸 때
4지역별 매출 표2분기 매출, 3분기 매출, 증감액, 증감률 열의 표입니다.담당의 수치와 맞춰 볼 때
  1. 요청 말풍선 아래에 호출 상자 두 개가 생기는지 봅니다. 이름 앞 아이콘이 돌고 있으면 그 담당이 아직 일하는 중입니다.
  2. 두 상자 모두 초록 체크가 붙으면 총괄 에이전트의 답이 이어집니다. 이 실습에서는 보낸 뒤 30초 안에 답이 끝났습니다.
  3. 답이 "핵심 3줄 → 지역별 매출 및 증감 표 → 이슈와 4분기 계획" 순서인지 확인합니다.

7단계. 호출 상자를 펼쳐 넘긴 요청 보기​

서브에이전트에게 넘긴 요청

번호메뉴기능이런 때 사용하세요
1호출 상자(펼침)누르면 열리고 다시 누르면 접힙니다.담당에게 무엇을 시켰는지 볼 때
2넘긴 요청총괄 에이전트가 담당에게 보낸 요청 전문입니다. 지침 1번대로 집계 기간과 파일 이름이 들어 있습니다.위임 규칙이 지켜졌는지 확인할 때
3읽은 파일첨부 읽기 아래에 담당이 읽은 파일 이름이 보입니다.담당이 올바른 파일을 읽었는지 볼 때
4데이터 분석담당이 코드를 실행해 계산한 기록입니다. 아래로 내려가면 결과 데이터 표와 담당이 돌려준 답이 이어집니다.수치가 어떤 계산에서 나왔는지 따라갈 때
  1. 판매 데이터 분석가 호출 상자를 누릅니다.
  2. 맨 위 넘긴 요청을 읽습니다. 이 실습에서는 "2026년 3분기(7~9월) 지역별 매출과 2분기 대비 증감을 표로 집계하고, 수치에 단위를 붙여 정리해 주세요. 데이터 파일은 '브레인크루_판매데이터_2026.xlsx'입니다."였습니다.
  3. 아래로 내려가 담당이 돌려준 표의 숫자가 6단계 최종 답의 표와 같은지 맞춰 봅니다.
  4. 상자를 접고 실적 보고서 요점 정리 도우미 상자도 펼쳐 봅니다. 넘긴 요청은 "'3분기_영업실적_보고서_초안.docx'에서 3분기 지역별 이슈와 4분기 계획을 요점만 정리해 주세요."였고, 첨부 읽기로 보고서 초안만 읽었습니다.

설정값 표​

설정위치이 실습에서 고른 값기본값과 의미
지침(담당)실적 보고서 요점 정리 도우미 > 폼 > 지침1단계 담당 지침기본은 빈 값입니다. 맡은 일 하나만 적고 "판매 수치 계산은 하지 않는다"처럼 하지 않을 일도 적어 두면 총괄의 다른 담당과 겹치지 않습니다.
에이전트 설명(담당)새 에이전트 만들기 창, 편집 화면 헤더맡는 일을 한 문장으로선택 항목입니다. 서브에이전트 관리 창의 카드와 총괄 에이전트가 담당을 고를 때 이 설명을 씁니다.
지침(총괄)분기 실적 브리핑 총괄 > 폼 > 지침2단계 위임 규칙기본은 빈 값입니다. 담당 이름을 그대로 쓰고, 담당마다 맡길 일·넘길 자료·답변 형식을 적습니다.
서브에이전트총괄 > 폼 > 서브에이전트 > 서브에이전트 관리판매 데이터 분석가, 실적 보고서 요점 정리 도우미기본은 없음입니다. 추가를 누른 순간 대화와 테스트에 적용되고, 헤더 저장으로 현재 버전에 기록됩니다.
모델각 에이전트 > 폼 > 모델바꾸지 않음(GPT-4.1)새 에이전트는 기본 모델로 만들어집니다. 담당마다 따로 바꿀 수 있습니다.

결과​

대화 화면에 판매 데이터 분석가와 실적 보고서 요점 정리 도우미 호출 상자 두 개가 모두 초록 체크로 끝나고, 그 아래에 총괄 에이전트의 브리핑이 나오면 성공입니다. 이 실습의 실제 최종 답은 다음과 같았습니다.

  • 핵심 3줄: "2026년 3분기 전체 매출은 전 분기 대비 일부 지역에서 감소, 대전·부산은 크게 증가.", "대전 지역은 210%p 급증, 부산은 61%p 증가. 반면 경기·서울·대구·광주는 감소.", "4분기에는 파트너 교육 확대, 온라인 프로모션, 대전 지역 집중 방문 계획."
  • 지역별 매출 및 증감 표(단위: 원): 경기 2분기 41,134,000 → 3분기 24,042,000(-41.6), 광주 31,848,000 → 28,710,000(-9.9), 대구 47,476,000 → 32,947,000(-30.6), 대전 14,284,000 → 44,357,000(+210.5), 부산 33,380,000 → 53,868,000(+61.4), 서울 28,580,000 → 18,842,000(-34.1)
  • 이슈와 4분기 계획: "서울(목표 달성 예상), 부산(신규 파트너 2곳 계약), 대전(목표 대비 부진, 원인 분석 필요)", "파트너 교육 프로그램 확대, 온라인 채널 프로모션, 대전 지역 집중 방문"

표의 숫자는 판매 데이터 분석가 호출 상자 안의 결과와 같았고, 이슈와 계획은 요점 정리 도우미의 결과와 같았습니다. 지침대로 총괄 에이전트가 직접 계산하지 않고 담당의 값을 옮겨 쓴 것입니다. 다만 핵심 3줄의 요약 문장은 표와 그대로 맞지 않을 수 있습니다. 이 실습에서도 첫 줄은 "일부 지역에서 감소"라고만 썼지만, 표의 여섯 지역을 더하면 2분기 196,702,000원에서 3분기 202,766,000원으로 전체 매출은 약 3.1% 늘었습니다. 요약 문장의 수치와 방향은 반드시 위 표와 대조하고, 다르면 표를 기준으로 고쳐 씁니다. 또 담당은 증감률을 "%p"로 표기했는데, 매출 증감률은 "%"가 맞으므로 보고에 쓸 때는 단위를 고쳐 씁니다. 모델의 답은 실행할 때마다 다를 수 있습니다.

SUPER AI 에이전트와 무엇이 다른가요​

사이드바 더 보기의 SUPER AI 에이전트도 요청에 맞는 에이전트에게 일을 넘기지만, 미리 붙여 둔 담당 없이 내 에이전트 전체 가운데 하나를 그때그때 고르고, 맡긴 기록은 에이전트에 위임 상자로 남습니다. 이 실습의 총괄 에이전트는 내가 고른 담당만 서브에이전트로 붙이고, 지침에 "판매 수치는 판매 데이터 분석가에게, 보고서 정리는 요점 정리 도우미에게"처럼 분담과 답변 형식을 못 박아 둡니다. 어느 에이전트에게 물을지 모를 때는 SUPER AI 에이전트를, 매 분기 같은 담당 조합으로 같은 형식의 결과를 받아야 할 때는 총괄 에이전트를 씁니다. SUPER AI 에이전트의 위임 화면은 멀티에이전트 실행 흐름에 있습니다.

이럴 때 쓰세요: 김그루 사원은 분기마다 판매 엑셀 집계와 보고서 초안 정리를 서로 다른 에이전트에게 따로 물어보고, 두 답을 손으로 합쳐 팀장 브리핑을 써 왔습니다. 분기 실적 브리핑 총괄을 만들어 두면 두 파일을 한 번 붙이고 요청 하나만 보내면 됩니다. 숫자는 판매 데이터 분석가가, 이슈와 계획은 요점 정리 도우미가 맡고, 총괄은 정해 둔 순서대로 모아 씁니다. 결과가 이상하면 호출 상자를 펼쳐 어느 담당에서 틀렸는지 바로 찾습니다.

흔한 실수와 해결​

증상원인해결
호출 상자가 하나도 없이 총괄이 바로 답합니다.지침에 담당 이름과 맡길 일이 없거나, 서브에이전트가 연결되지 않았습니다.지침에 담당 이름을 그대로 적고, 입력란 아래 서브에이전트 버튼으로 연결을 확인합니다.
서브에이전트 관리 창에서 붙이려는 에이전트가 보이지 않습니다.지금 설정 중인 에이전트 자신이거나, 이미 붙였거나, 서로를 맡기게 되는 에이전트입니다.왼쪽 현재 서브에이전트에 이미 있는지 보고, 검색란 낱말을 바꿔 찾습니다.
카드를 눌렀더니 다른 에이전트 편집 화면으로 넘어갔습니다.추가가 아니라 카드 본문을 눌렀습니다.사이드바 뒤로로 돌아와 카드 오른쪽 추가를 누릅니다.
한 담당만 불리고 다른 담당의 몫을 총괄이 직접 씁니다.요청이나 지침에서 그 담당의 일이 분명하지 않습니다.요청에 "~은 실적 보고서 요점 정리 도우미에게 맡겨 주세요"처럼 담당 이름을 넣어 다시 보냅니다.
최종 답의 숫자가 담당의 결과와 다릅니다.총괄이 숫자를 다시 계산하거나 반올림했습니다.지침에 "수치는 판매 데이터 분석가가 준 값만 쓴다"를 넣고, 호출 상자 안의 결과를 기준으로 고칩니다.
워크스페이스 등록 요청이 막힙니다.서브에이전트가 배포되지 않았거나 서브에이전트 변경을 저장하지 않았습니다.헤더 저장을 먼저 누르고, 서브에이전트 할당하기의 "워크스페이스에 등록할 때"대로 담당부터 배포합니다.

응용 과제​

  1. 담당을 하나 더 붙여 보세요. 예를 들어 이메일 초안 도우미를 추가하고, 총괄 지침에 "5. 브리핑이 끝나면 이메일 초안 도우미에게 팀장님께 보낼 공유 메일 초안을 맡긴다"를 더한 뒤, 호출 상자가 세 개 나오는지 확인합니다.
  2. 실적 보고서 요점 정리 도우미의 지침에 "제품 동향도 꼭 포함한다"를 더하고 같은 요청을 다시 보내, 최종 답에 제품 동향이 들어오는지 비교해 보세요. 담당의 지침을 고치면 그 담당을 쓰는 모든 총괄의 결과가 함께 바뀝니다.
  3. 같은 요청을 SUPER AI 에이전트에게 보내, 어느 에이전트를 고르고 결과가 어떻게 다른지 이 실습의 결과와 비교해 보세요.
